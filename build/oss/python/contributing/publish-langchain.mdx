**让你的集成对社区可用。**

<Warning>
**重要提示：新的集成应该是独立包，而不是对 LangChain 单体仓库（monorepo）的 PR。**

虽然 LangChain 在主仓库中维护了一小部分第一方和高用量集成（如 OpenAI、Anthropic 和 Ollama），但**新的集成应该发布为单独的 PyPI 包和仓库**（例如 `langchain-yourservice`），用户需要与核心 LangChain 包一起安装。**你不应该**提交 PR 将你的集成直接添加到主 LangChain 仓库中。
</Warning>

现在你的包已经实现并经过测试，你可以发布它并添加文档，以便社区可以发现它。

## 发布你的包

<Info>
    本指南假设你已经实现了你的包并为其编写了测试。如果没有，请参考 [实现指南](/oss/python/contributing/implement-langchain) 和 [测试指南](/oss/python/contributing/standard-tests-langchain)。
</Info>

在本指南中，我们将使用 PyPI 作为包注册中心。如果你愿意，可以选择发布到其他注册中心；说明会有所不同。

### 设置凭证

首先，请确保你有一个 PyPI 账户：

<AccordionGroup>
    <Accordion title="如何创建 PyPI Token" icon="key">
        <Steps>
            <Step title="创建账户">
                访问 [PyPI 网站](https://pypi.org/) 并创建一个账户
            </Step>

            <Step title="验证邮件">
                点击 PyPI 发送给你的链接来验证你的电子邮件地址
            </Step>

            <Step title="启用 2FA">
                进入你的账户设置并点击 "Generate Recovery Codes" 以启用 2FA。要生成 API Token，你**必须**启用 2FA
            </Step>

            <Step title="生成 Token">
                进入你的账户设置并[生成一个新的 API Token](https://pypi.org/manage/account/token/)
            </Step>
        </Steps>
    </Accordion>
</AccordionGroup>

## 添加文档

要在本站的 [集成标签页](/oss/python/integrations/providers/overview) 下为你的包添加文档，你需要创建相关的文档页面，并在 [LangChain 文档仓库](https://github.com/langchain-ai/docs) 中打开一个 PR。

### 编写文档

根据你构建的集成类型，你需要创建不同类型的文档页面。LangChain 提供了不同类型集成的模板来帮助你入门。

    要引用现有文档，你可以查看 [集成列表](/oss/python/integrations/providers/overview) 并找到与你相似的集成。

    要在原始 Markdown 中查看给定的文档页面，请使用页面右上角 "Copy page" 旁边的下拉按钮，然后选择 "View as Markdown"。
</Tip>

### 提交 PR

在个人 GitHub 账户下 Fork [LangChain 文档仓库](https://github.com/langchain-ai/docs) 仓库，并将其克隆到本地。为你的集成创建一个新分支。复制模板并使用你最喜欢的 Markdown 文本编辑器对其进行修改。编写文档时，请务必参考并遵循 [文档指南](/oss/python/contributing/documentation)。

<Warning>
    如果出现以下情况，我们可能会拒绝 PR 或要求修改：
    - CI 检查失败
    - 存在严重的语法错误或拼写错误
    - [Mintlify 组件](/oss/python/contributing/documentation#mintlify-components) 使用不正确
    - 页面缺少 [前置元数据](/oss/python/contributing/documentation#page-structure)
    - 缺少 [本地化](/oss/python/contributing/documentation#localization)（如果适用）
    - [代码示例](/oss/python/contributing/documentation#in-code-documentation) 无法运行或存在错误
    - 未达到 [质量标准](/oss/python/contributing/documentation#quality-standards)
</Warning>

请耐心等待，因为我们处理大量的 PR。我们会尽快审查你的 PR 并提供反馈或合并。**不要反复标记维护人员关于你的 PR 的问题。**
