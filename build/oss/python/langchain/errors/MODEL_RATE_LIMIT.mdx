---
title: MODEL_RATE_LIMIT
---

<Note>
    目前仅在 `langchainjs`（JavaScript/TypeScript）中使用。
</Note>

您已达到模型提供商在给定时间段内允许的最大请求数，因此暂时被阻止访问。

当您在特定时间窗口内超过模型提供商允许的最大请求数时，就会出现此错误，导致暂时被阻止。此限制通常是暂时的，并在限制重置后解除。

## 故障排除

要解决此错误，您可以采取以下措施：

1. **实施速率限制 (Rate Limiting)**：部署速率限制器来调节发送给模型的请求频率。请参阅[速率限制](/oss/python/langchain/models#rate-limiting)文档。
2. **实施响应缓存 (Response Caching)**：当传入的查询具有重复性时，使用模型响应缓存来减少不必要的重复请求。
3. **使用多个提供商**：如果您的应用程序架构支持，请将请求分配到多个不同的模型提供商之间。
4. **联系您的提供商**：联系您的模型提供商，请求增加您的速率限制。
