title: 安装 LangChain
sidebarTitle: 安装
---

要安装 LangChain 包：

<CodeGroup>
    ```bash pip
    pip install -U langchain
    # 需要 Python 3.10+
    ```

    ```bash uv
    uv add langchain
    # 需要 Python 3.10+
    ```
</CodeGroup>




LangChain 提供了与数百个 LLM（大型语言模型）和数千个其他集成的支持。这些集成位于独立的提供商包中。

<CodeGroup>
    ```bash pip
    # 安装 OpenAI 集成
    pip install -U langchain-openai

    # 安装 Anthropic 集成
    pip install -U langchain-anthropic
    ```
    ```bash uv
    # 安装 OpenAI 集成
    uv add langchain-openai

    # 安装 Anthropic 集成
    uv add langchain-anthropic
    ```
</CodeGroup>





<Tip>
有关可用集成列表，请参阅 [集成（Integrations）](/oss/python/integrations/providers/overview) 选项卡。
</Tip>

现在您已经安装了 LangChain，可以通过遵循 [快速开始指南](/oss/python/langchain/quickstart) 来入门。
