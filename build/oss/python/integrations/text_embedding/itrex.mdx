加载由 Intel® 扩展程序（Intel® Extension for Transformers, ITREX）生成的量化 BGE 嵌入模型，并利用 ITREX 的 [Neural Engine](https://github.com/intel/intel-extension-for-transformers/blob/main/intel_extension_for_transformers/llm/runtime/deprecated/docs/Installation.md)（这是一个高性能的 NLP 后端）来加速模型的推理过程，而不会损失准确性。

有关更多详细信息，请参阅我们的博客文章：[使用 Intel 扩展程序实现高效的自然语言嵌入模型](https://medium.com/intel-analytics-software/efficient-natural-language-embedding-models-with-intel-extension-for-transformers-2b6fcd0f8f34) 和 [BGE 优化示例](https://github.com/intel/intel-extension-for-transformers/tree/main/examples/huggingface/pytorch/text-embedding/deployment/mteb/bge)。

```python
from langchain_community.embeddings import QuantizedBgeEmbeddings

model_name = "Intel/bge-small-en-v1.5-sts-int8-static-inc"
encode_kwargs = {"normalize_embeddings": True}  # 设置为 True 以计算余弦相似度

model = QuantizedBgeEmbeddings(
    model_name=model_name,
    encode_kwargs=encode_kwargs,
    query_instruction="用这句话来表示要搜索的相关段落： ",
)
```
