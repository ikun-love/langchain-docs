## 设置 (Setup)

要访问 AzureOpenAI 嵌入模型，您需要创建一个 Azure 帐户、获取一个 API 密钥，并安装 `langchain-openai` 集成包。

### 凭证 (Credentials)

您需要有一个已部署的 Azure OpenAI 实例。您可以在 Azure 门户中按照本[指南](https://learn.microsoft.com/en-us/azure/ai-services/openai/how-to/create-resource?pivots=web-portal)进行部署。

一旦您的实例运行起来，请确保您知道实例的名称和密钥。您可以在 Azure 门户中，在实例的“密钥和终结点”部分找到密钥。

```bash
AZURE_OPENAI_ENDPOINT=<YOUR API ENDPOINT>
AZURE_OPENAI_API_KEY=<YOUR_KEY>
AZURE_OPENAI_API_VERSION="2024-02-01"
```

```python
import getpass
import os

if not os.getenv("AZURE_OPENAI_API_KEY"):
    os.environ["AZURE_OPENAI_API_KEY"] = getpass.getpass(
        "Enter your AzureOpenAI API key: "
    )
```

要启用模型调用的自动跟踪，请设置您的 [LangSmith](https://docs.smith.langchain.com/) API 密钥：

```python
os.environ["LANGSMITH_TRACING"] = "true"
os.environ["LANGSMITH_API_KEY"] = getpass.getpass("Enter your LangSmith API key: ")
```

### 安装 (Installation)

LangChain AzureOpenAI 的集成位于 `langchain-openai` 包中：

```python
pip install -qU langchain-openai
```

## 实例化 (Instantiation)

现在我们可以实例化模型对象并生成聊天补全：

```python
from langchain_openai import AzureOpenAIEmbeddings

embeddings = AzureOpenAIEmbeddings(
    model="text-embedding-3-large",
    # dimensions: Optional[int] = None, # 可以使用新的 text-embedding-3 模型指定维度
    # azure_endpoint="https://<your-endpoint>.openai.azure.com/", 如果未提供，将读取环境变量 AZURE_OPENAI_ENDPOINT
    # api_key=... # 可以直接提供 API 密钥。如果缺失，将读取环境变量 AZURE_OPENAI_API_KEY
    # openai_api_version=..., # 如果未提供，将读取环境变量 AZURE_OPENAI_API_VERSION
)
```

## 索引和检索 (Indexing and Retrieval)

嵌入模型通常用于检索增强生成 (RAG) 工作流中，既作为数据索引的一部分，也可以用于后续的数据检索。有关更详细的说明，请参阅我们的 [RAG 教程](/oss/python/langchain/rag)。

下面展示了如何使用我们上面初始化的 `embeddings` 对象进行数据索引和检索。在此示例中，我们将使用 `InMemoryVectorStore` 来索引和检索一个示例文档。

```python
# 使用一个示例文本创建一个向量存储
from langchain_core.vectorstores import InMemoryVectorStore

text = "LangChain is the framework for building context-aware reasoning applications"

vectorstore = InMemoryVectorStore.from_texts(
    [text],
    embedding=embeddings,
)

# 使用向量存储作为检索器
retriever = vectorstore.as_retriever()

# 检索最相似的文本
retrieved_documents = retriever.invoke("What is LangChain?")

# 显示检索到文档的内容
retrieved_documents[0].page_content
```

```output
'LangChain is the framework for building context-aware reasoning applications'
```

## 直接使用 (Direct Usage)

在底层，向量存储和检索器的实现分别调用 `embeddings.embed_documents(...)` 和 `embeddings.embed_query(...)` 来为 `from_texts` 和检索 `invoke` 操作中使用的文本创建嵌入向量。

您可以直接调用这些方法来获取用于自身用例的嵌入向量。

### 嵌入单个文本 (Embed single texts)

您可以使用 `embed_query` 来嵌入单个文本或文档：

```python
single_vector = embeddings.embed_query(text)
print(str(single_vector)[:100])  # 显示向量的前 100 个字符
```

```output
[-0.0011676070280373096, 0.007125577889382839, -0.014674457721412182, -0.034061674028635025, 0.01128
```

### 嵌入多个文本 (Embed multiple texts)

您可以使用 `embed_documents` 来嵌入多个文本：

```python
text2 = (
    "LangGraph is a library for building stateful, multi-actor applications with LLMs"
)
two_vectors = embeddings.embed_documents([text, text2])
for vector in two_vectors:
    print(str(vector)[:100])  # 显示向量的前 100 个字符
```

```output
[-0.0011966148158535361, 0.007160289213061333, -0.014659193344414234, -0.03403077274560928, 0.011280
[-0.005595256108790636, 0.016757294535636902, -0.011055258102715015, -0.031094247475266457, -0.00363
```
