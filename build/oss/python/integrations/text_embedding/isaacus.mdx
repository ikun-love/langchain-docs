本指南将引导您完成使用 [Isaacus](/oss/python/integrations/providers/isaacus) LangChain 集成生成法律嵌入（legal embeddings）的入门步骤。

## 1. 设置您的账户

请前往 [Isaacus 平台](https://platform.isaacus.com/accounts/signup/) 创建一个新账户。

注册后，请[添加付款方式](https://platform.isaacus.com/billing/)以领取您的[免费点数](https://docs.isaacus.com/pricing/credits)。

添加付款方式后，请[创建一个新的 API 密钥](https://platform.isaacus.com/users/api-keys/)。

请务必妥善保管您的 API 密钥。创建后您将无法再次查看它。但不必担心，您可以随时生成一个新的。

## 2. 安装 Isaacus API 客户端

现在您的账户已设置完毕，请安装 [Isaacus LangChain](https://pypi.org/project/langchain-isaacus/) 集成包。

<CodeGroup>
```bash pip
pip install langchain-isaacus
```

```bash uv
uv add langchain-isaacus
```
</CodeGroup>

## 3. 嵌入文档

安装了我们的 API 客户端后，让我们来嵌入您的第一个法律查询和文档。

首先，您需要**使用您的 API 密钥初始化客户端**。您可以通过设置 `ISAACUS_API_KEY` 环境变量来实现，或者像本示例中一样直接传入密钥。

我们将使用 [Kanon 2 Embedder](https://isaacus.com/blog/introducing-kanon-2-embedder)，它是截至 2025 年 10 月 20 日在 [Massive Legal Embedding Benchmark](https://isaacus.com/blog/introducing-mleb) 上表现最准确的法律嵌入模型。

```python
from langchain_isaacus import IsaacusEmbeddings

# 使用 Kanon 2 Embedder 创建一个 Isaacus API 客户端。
client = IsaacusEmbeddings(
    model="kanon-2-embedder",
    api_key="PASTE_YOUR_API_KEY_HERE",
    # dimensions=1792, # 您可以选择性地指定较低的维度。
)
```
接下来，我们获取一个需要嵌入的法律文档。在此示例中，我们将使用 [GitHub 的服务条款](https://github.com/terms)。

```python
import isaacus

tos = isaacus.Isaacus().get(path="https://examples.isaacus.com/github-tos.md", cast_to=str)
```

我们的目标是，给定一个关于 GitHub 服务条款的搜索查询，然后检索该条款的内容。

为此，我们将首先使用 API 客户端的 `.embed_documents()` 方法嵌入文档。使用此方法表明我们正在嵌入**文档**（而不是搜索查询），这对于确保我们的嵌入针对检索进行了优化非常重要（相比于分类或句子相似性等其他任务）。

```python
document_embedding = client.embed_documents(texts=[tos])[0]
```

现在，让我们嵌入两个搜索查询：一个与文档明显相关，另一个明显不相关。这次我们使用 API 客户端的 `.embed_query()` 方法，这表明我们正在嵌入一个**搜索查询**。

```python
relevant_query_embedding = client.embed_query(text="What are GitHub's billing policies?")
irrelevant_query_embedding = client.embed_query(text="What are Microsoft's billing policies?")
```

为了评估查询与文档的相关性，我们可以计算其嵌入向量与文档嵌入向量之间的余弦相似度。

余弦相似度衡量两组数字的相似程度（具体来说，是在内积空间中两个向量之间夹角的余弦值）。理论上，它的范围是 $$-1$$ 到 $$1$$，其中 $$1$$ 表示向量完全相同，$$0$$ 表示它们正交（即完全不相似），而 $$-1$$ 表示它们完全相反。但在实际应用中，文本嵌入（因为它们通常是非负数）的相似度范围往往在 $$0$$ 到 $$1$$ 之间。

Isaacus 的嵌入器经过优化，其产生的余弦相似度大致对应于原始文本在含义上的相似程度。然而，与 Isaacus 的通用分类器不同，Isaacus 嵌入器的得分未经校准，不能解释为概率，只能作为相对的相似性度量，因此它们最常用于搜索结果的排序。

为了方便起见，我们的 Python 示例使用了 [`numpy`](https://numpy.org/) 的 `dot` 函数来计算我们嵌入向量的点积（由于我们的所有嵌入向量都经过 L2 归一化，这等同于它们的余弦相似度）。如果您愿意，您可以使用其他库来计算余弦相似度（例如，使用 [`torch`](https://pytorch.org/) 通过 `torch.nn.functional.cosine_similarity`），或者您可以编写自己的实现。

```python
import numpy as np

relevant_similarity = np.dot(relevant_query_embedding, document_embedding)
irrelevant_similarity = np.dot(irrelevant_query_embedding, document_embedding)

print(f"Similarity of relevant query to the document: {relevant_similarity * 100:.2f}")
print(f"Similarity of irrelevant query to the document: {irrelevant_similarity * 100:.2f}")
```

输出应类似于以下内容：
```
Similarity of relevant query to the document: 52.87
Similarity of irrelevant query to the document: 24.86
```

正如您所见，相关查询与文档的相似度得分远高于不相关查询，这表明我们的嵌入器已成功捕获了这些文本的语义含义。

这样就完成了！您刚刚使用 LangChain 上的 Isaacus API 成功嵌入了一个法律文档和查询。
