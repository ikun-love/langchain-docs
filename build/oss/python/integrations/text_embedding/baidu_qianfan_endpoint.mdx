title: 百度千帆

百度 AI 云千帆平台是面向企业开发者的 **一站式大模型开发与服务运营平台**。千帆不仅提供了包括文心一言（ERNIE-Bot）及第三方开源模型在内的模型服务，还提供了丰富的 AI 开发工具和全套开发环境，从而方便客户轻松地使用和开发大模型应用。

从基本功能上来说，这些模型被划分为以下类型：

- Embedding（嵌入）
- Chat（对话）
- Completion（补全）

在本教程（Notebook）中，我们将主要介绍如何使用 `langchain` 结合 [Qianfan（千帆）](https://cloud.baidu.com/doc/WENXINWORKSHOP/index.html)，重点关注 `langchain` 包 `langchain/embeddings` 中对应的 `Embedding` 功能。

## API 初始化

要使用基于百度千帆的 LLM 服务，您需要初始化以下参数：

您可以选择在环境变量中初始化 `AK`（Access Key）和 `SK`（Secret Key），或者直接在代码中初始化参数：

```base
export QIANFAN_AK=XXX
export QIANFAN_SK=XXX
```

```python
"""基础初始化和调用"""
import os

from langchain_community.embeddings import QianfanEmbeddingsEndpoint

os.environ["QIANFAN_AK"] = "your_ak"
os.environ["QIANFAN_SK"] = "your_sk"

embed = QianfanEmbeddingsEndpoint(
    # qianfan_ak='xxx',
    # qianfan_sk='xxx'
)
res = embed.embed_documents(["hi", "world"])


async def aioEmbed():
    # 异步查询单个文本进行嵌入
    res = await embed.aembed_query("qianfan")
    print(res[:8])


await aioEmbed()


async def aioEmbedDocs():
    # 异步查询文档列表进行嵌入
    res = await embed.aembed_documents(["hi", "world"])
    for r in res:
        print("", r[:8])


await aioEmbedDocs()
```

## 在千帆中使用不同的模型

如果您想部署基于文心大模型（Ernie Bot）或第三方开源模型，您可以按照以下步骤操作：

- 1. （可选，如果模型包含在默认模型列表中，则跳过此步骤）在千帆控制台部署您的模型，获取自定义的部署端点（deploy endpoint）。
- 2. 在初始化时设置 `endpoint` 字段：

```python
embed = QianfanEmbeddingsEndpoint(model="bge_large_zh", endpoint="bge_large_zh")

res = embed.embed_documents(["hi", "world"])
for r in res:
    print(r[:8])
```
