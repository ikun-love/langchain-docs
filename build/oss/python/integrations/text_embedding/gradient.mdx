`Gradient` 允许您通过简单的 Web API 来创建 [`Embeddings`](https://reference.langchain.com/python/langchain_core/embeddings/#langchain_core.embeddings.embeddings.Embeddings)（嵌入向量），以及对大型语言模型（LLMs）进行微调和获取补全（completions）。

本示例 Notebook 将介绍如何将 LangChain 与来自 [Gradient](https://gradient.ai/) 的 Embeddings 结合使用。

## 导入 (Imports)

```python
from langchain_community.embeddings import GradientEmbeddings
```

## 设置环境变量 API 密钥

请确保从 Gradient AI 获取您的 API 密钥。您将获得 $10 的免费点数，可用于测试和微调不同的模型。

```python
import os
from getpass import getpass

if not os.environ.get("GRADIENT_ACCESS_TOKEN", None):
    # 访问令牌链接：https://auth.gradient.ai/select-workspace
    os.environ["GRADIENT_ACCESS_TOKEN"] = getpass("gradient.ai access token:")
if not os.environ.get("GRADIENT_WORKSPACE_ID", None):
    # 可以在 `$ gradient workspace list` 命令中查看 `ID`
    # 或者在登录后访问 https://auth.gradient.ai/select-workspace 页面查看
    os.environ["GRADIENT_WORKSPACE_ID"] = getpass("gradient.ai workspace id:")
```

可选：使用 `gradientai` Python 包来验证您的环境变量 `GRADIENT_ACCESS_TOKEN` 和 `GRADIENT_WORKSPACE_ID` 是否正确，以便获取当前已部署的模型列表。

```python
pip install -qU  gradientai
```

## 创建 Gradient 实例

```python
documents = [
    "Pizza is a dish.",
    "Paris is the capital of France",
    "numpy is a lib for linear algebra",
]
query = "Where is Paris?"
```

```python
embeddings = GradientEmbeddings(model="bge-large")

# 对文档列表进行嵌入向量化
documents_embedded = embeddings.embed_documents(documents)
# 对查询语句进行嵌入向量化
query_result = embeddings.embed_query(query)
```

```python
# (演示) 计算相似度
import numpy as np

# 使用点积计算嵌入向量的相似度分数
scores = np.array(documents_embedded) @ np.array(query_result).T
dict(zip(documents, scores))
```
