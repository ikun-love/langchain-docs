Oracle AI Vector Search 专为人工智能（AI）工作负载设计，它允许你根据**语义**而非关键字来查询数据。
Oracle AI Vector Search 最大的优势之一是，它可以将对非结构化数据的语义搜索与对业务数据的关系搜索在**同一个系统**中结合起来。
这不仅功能强大，而且效率更高，因为它消除了在多个系统之间进行数据分片的困扰，无需添加专门的向量数据库。

此外，你的向量还可以受益于 Oracle 数据库所有最强大的功能，例如：

* [分区支持 (Partitioning Support)](https://www.oracle.com/database/technologies/partitioning.html)
* [Real Application Clusters 可扩展性](https://www.oracle.com/database/real-application-clusters/)
* [Exadata 智能扫描 (Exadata smart scans)](https://www.oracle.com/database/technologies/exadata/software/smartscan/)
* [跨地理分布式数据库的分片处理 (Shard processing across geographically distributed databases)](https://www.oracle.com/database/distributed-database/)
* [事务处理 (Transactions)](https://docs.oracle.com/en/database/oracle/oracle-database/23/cncpt/transactions.html)
* [并行 SQL (Parallel SQL)](https://docs.oracle.com/en/database/oracle/oracle-database/21/vldbg/parallel-exec-intro.html#GUID-D28717E4-0F77-44F5-BB4E-234C31D4E4BA)
* [灾难恢复 (Disaster recovery)](https://www.oracle.com/database/data-guard/)
* [安全性 (Security)](https://www.oracle.com/security/database-security/)
* [Oracle 机器学习 (Oracle Machine Learning)](https://www.oracle.com/artificial-intelligence/database-machine-learning/)
* [Oracle 图数据库 (Oracle Graph Database)](https://www.oracle.com/database/integrated-graph-database/)
* [Oracle 空间与图 (Oracle Spatial and Graph)](https://www.oracle.com/database/spatial/)
* [Oracle 区块链 (Oracle Blockchain)](https://docs.oracle.com/en/database/oracle/oracle-database/23/arpls/dbms_blockchain_table.html#GUID-B469E277-978E-4378-A8C1-26D3FF96C9A6)
* [JSON](https://docs.oracle.com/en/database/oracle/oracle-database/23/adjsn/json-in-oracle-database.html)

本指南演示了如何使用 Oracle AI Vector Search 中的嵌入能力（Embedding Capabilities）来为文档生成嵌入向量，具体是使用 `OracleEmbeddings`。

如果你刚开始接触 Oracle 数据库，可以考虑探索 [免费的 Oracle 23 AI](https://www.oracle.com/database/free/#resources)，它为你设置数据库环境提供了很好的入门介绍。在使用数据库时，通常建议默认避免使用系统用户（system user）；相反，你可以创建自己的用户以增强安全性和自定义性。有关创建用户的详细步骤，请参阅我们的 [端到端指南](https://github.com/langchain-ai/langchain/blob/v0.3/cookbook/oracleai_demo.ipynb)，该指南还展示了如何在 Oracle 中设置用户。此外，理解用户权限对于有效管理数据库安全至关重要。你可以在官方的 [Oracle 用户账户和安全管理指南](https://docs.oracle.com/en/database/oracle/oracle-database/19/admqs/administering-user-accounts-and-security.html#GUID-36B21D72-1BBB-46C9-A0C9-F0D2A8591B8D) 中了解有关此主题的更多信息。

### 连接到 Oracle 数据库 (Connect to Oracle Database)

下面的示例代码将展示如何连接到 Oracle 数据库。默认情况下，`python-oracledb` 以“Thin”模式运行，该模式直接连接到 Oracle 数据库，不需要 Oracle 客户端库。然而，当 `python-oracledb` 使用这些库时，会提供一些额外的功能。当使用 Oracle 客户端库时，称 `python-oracledb` 处于“Thick”模式。这两种模式都全面支持 Python Database API v2.0 规范。请参阅以下 [指南](https://python-oracledb.readthedocs.io/en/latest/user_guide/appendix_a.html#featuresummary)，了解每种模式支持的功能。如果薄模式（thin-mode）无法使用，你可能希望切换到厚模式（thick-mode）。

```python
import sys

import oracledb

# 请用你的用户名、密码、主机名、端口和服务名进行更新
username = "<username>"
password = "<password>"
dsn = "<hostname>:<port>/<service_name>"

connection = oracledb.connect(user=username, password=password, dsn=dsn)
print("Connection successful!")
```

对于嵌入向量的生成，用户可以选择多种提供程序选项，包括在数据库内部生成嵌入以及使用第三方服务，如 OcigenAI、Hugging Face 和 OpenAI。选择第三方提供程序的用户必须建立包含所需身份验证信息的凭据。或者，如果用户选择“database”作为提供程序，则他们需要将 ONNX 模型加载到 Oracle 数据库中以促进生成嵌入。

### 加载 ONNX 模型 (Load ONNX Model)

Oracle 支持多种嵌入提供程序，使用户可以在专有的数据库解决方案和 HuggingFace 等第三方服务之间进行选择。这一选择决定了生成和管理嵌入向量的方法。

***重要提示***：如果用户选择数据库选项，他们必须将 ONNX 模型上传到 Oracle 数据库中。相反，如果选择第三方提供程序来生成嵌入向量，则无需将 ONNX 模型上传到 Oracle 数据库。

直接在 Oracle 内部使用 ONNX 模型的一个显著优势是它提供了增强的安全性和性能，因为它无需将数据传输给外部方。此外，这种方法避免了通常与网络或 REST API 调用相关的延迟。

以下是向 Oracle 数据库上传 ONNX 模型的示例代码：

```python
from langchain_oracledb.embeddings.oracleai import OracleEmbeddings

# 更新你的 ONNX 模型的目录和文件名
# 确保系统中存在 onnx 文件
onnx_dir = "DEMO_DIR"
onnx_file = "tinybert.onnx"
model_name = "demo_model"

try:
    OracleEmbeddings.load_onnx_model(conn, onnx_dir, onnx_file, model_name)
    print("ONNX model loaded.")
except Exception as e:
    print("ONNX model loading failed!")
    sys.exit(1)
```

### 创建凭据 (Create Credential)

在选择第三方提供程序来生成嵌入向量时，用户需要建立凭据来安全地访问提供程序的端点。

***重要提示：*** 在选择“database”提供程序来生成嵌入向量时，不需要任何凭据。但是，如果用户决定使用第三方提供程序，他们必须创建特定于所选提供程序的凭据。

下面是一个说明性示例：

```python
try:
    cursor = conn.cursor()
    cursor.execute(
        """
       declare
           jo json_object_t;
       begin
           -- HuggingFace
           dbms_vector_chain.drop_credential(credential_name  => 'HF_CRED');
           jo := json_object_t();
           jo.put('access_token', '<access_token>');
           dbms_vector_chain.create_credential(
               credential_name   =>  'HF_CRED',
               params            => json(jo.to_string));

           -- OCIGENAI
           dbms_vector_chain.drop_credential(credential_name  => 'OCI_CRED');
           jo := json_object_t();
           jo.put('user_ocid','<user_ocid>');
           jo.put('tenancy_ocid','<tenancy_ocid>');
           jo.put('compartment_ocid','<compartment_ocid>');
           jo.put('private_key','<private_key>');
           jo.put('fingerprint','<fingerprint>');
           dbms_vector_chain.create_credential(
               credential_name   => 'OCI_CRED',
               params            => json(jo.to_string));
       end;
       """
    )
    cursor.close()
    print("Credentials created.")
except Exception as ex:
    cursor.close()
    raise
```

### 生成嵌入向量 (Generate Embeddings)

Oracle AI Vector Search 提供了多种生成嵌入向量的方法，可以利用本地托管的 ONNX 模型或第三方 API。有关配置这些替代方案的全面说明，请参阅 [Oracle AI Vector Search 指南](https://docs.oracle.com/en/database/oracle/oracle-database/23/arpls/dbms_vector_chain1.html#GUID-C6439E94-4E86-4ECD-954E-4B73D53579DE)。

***注意：*** 用户可能需要配置代理（proxy）才能使用第三方嵌入生成提供程序，而使用 ONNX 模型的 'database' 提供程序则不需要。

```python
# 实例化 summary 和 embedder 对象时使用的代理
proxy = "<proxy>"
```

下面的示例代码将展示如何生成嵌入向量：

```python
from langchain_oracledb.embeddings.oracleai import OracleEmbeddings
from langchain_core.documents import Document

"""
# 使用 ocigenai
embedder_params = {
    "provider": "ocigenai",
    "credential_name": "OCI_CRED",
    "url": "https://inference.generativeai.us-chicago-1.oci.oraclecloud.com/20231130/actions/embedText",
    "model": "cohere.embed-english-light-v3.0",
}

# 使用 huggingface
embedder_params = {
    "provider": "huggingface",
    "credential_name": "HF_CRED",
    "url": "https://api-inference.huggingface.co/pipeline/feature-extraction/",
    "model": "sentence-transformers/all-MiniLM-L6-v2",
    "wait_for_model": "true"
}
"""

# 使用加载到 Oracle 数据库的 ONNX 模型
embedder_params = {"provider": "database", "model": "demo_model"}

# 如果你的环境不需要代理，你可以省略下面的 'proxy' 参数
embedder = OracleEmbeddings(conn=conn, params=embedder_params, proxy=proxy)
embed = embedder.embed_query("Hello World!")

""" 验证 """
print(f"Embedding generated by OracleEmbeddings: {embed}")
```
