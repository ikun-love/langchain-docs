Model2Vec 是一种技术，可以将任何句子转换器（sentence transformer）转换为一个非常小的静态模型。
[model2vec](https://github.com/MinishLab/model2vec) 可用于生成嵌入（embeddings）。

## 安装设置 (Setup)

```bash
pip install -U langchain-community
```

## 实例化 (Instantiation)

确保已安装 `model2vec`

```bash
pip install -U model2vec
```

## 索引和检索 (Indexing and Retrieval)

```python
from langchain_community.embeddings import Model2vecEmbeddings
```

```python
embeddings = Model2vecEmbeddings("minishlab/potion-base-8M")
```

```python
query_text = "This is a test query."
query_result = embeddings.embed_query(query_text)
```

```python
document_text = "This is a test document."
document_result = embeddings.embed_documents([document_text])
```

## 直接使用 (Direct Usage)

以下是如何直接利用 `model2vec` 的示例：

```python
from model2vec import StaticModel

# 从 HuggingFace hub 加载一个模型（此处为 potion-base-8M 模型）
model = StaticModel.from_pretrained("minishlab/potion-base-8M")

# 生成嵌入
embeddings = model.encode(["It's dangerous to go alone!", "It's a secret to everybody."])

# 生成 Token 级别的嵌入序列
token_embeddings = model.encode_as_sequence(["It's dangerous to go alone!", "It's a secret to everybody."])
```
