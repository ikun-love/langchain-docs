`Infinity` 允许使用基于 MIT 许可的 Embedding Server 来创建 [`Embeddings`](https://reference.langchain.com/python/langchain_core/embeddings/#langchain_core.embeddings.embeddings.Embeddings)（嵌入向量）。

本 Notebook 将介绍如何将 LangChain 与 Embeddings 结合使用，并展示 [Infinity GitHub 项目](https://github.com/michaelfeil/infinity)。

## 导入 (Imports)

```python
from langchain_community.embeddings import InfinityEmbeddings, InfinityEmbeddingsLocal
```

```python
documents = [
    "Baguette is a dish.",
    "Paris is the capital of France.",
    "numpy is a lib for linear algebra",
    "You escaped what I've escaped - You'd be in Paris getting fucked up too",
]
query = "Where is Paris?"
```

```python
embeddings = InfinityEmbeddingsLocal(
    model="sentence-transformers/all-MiniLM-L6-v2",
    # revision (版本)
    revision=None,
    # 保持在 32 效果最佳
    batch_size=32,
    # 通过 torch 用于 AMD/Nvidia GPU
    device="cuda",
    # 在执行前预热模型
)


async def embed():
    # TODO: 此函数仅用于展示您的调用可以异步运行。

    # 重要提示：在 `async with` 语句中使用 engine 才能启动/停止批处理引擎。
    async with embeddings:
        # 避免频繁关闭和启动引擎。
        # 最好保持它运行。
        # 如果您确定要手动以更精细的方式启动/停止执行，您可以调用 `await embeddings.__aenter__()` 和 `__aexit__()`

        documents_embedded = await embeddings.aembed_documents(documents)
        query_result = await embeddings.aembed_query(query)
        print("embeddings created successful")
    return documents_embedded, query_result
```

# 选项 2：运行服务器并通过 API 连接

#### 可选：确保启动了 Infinity 实例

要安装 infinity，请使用以下命令。有关详细信息，请查阅 [GitHub 上的文档](https://github.com/michaelfeil/infinity)。

```bash
pip install infinity_emb[all]
```

# 安装 infinity 包

pip install -qU  infinity_emb[all]

启动服务器——最好在一个单独的终端中进行，而不是在 Jupyter Notebook 中

```bash
model=sentence-transformers/all-MiniLM-L6-v2
port=7797
infinity_emb --port $port --model-name-or-path $model
```

或者，您可以使用 docker：

```bash
model=sentence-transformers/all-MiniLM-L6-v2
port=7797
docker run -it --gpus all -p $port:$port michaelf34/infinity:latest --model-name-or-path $model --port $port
```

## 使用您的 Infinity 实例嵌入文档

```python
documents = [
    "Baguette is a dish.",
    "Paris is the capital of France.",
    "numpy is a lib for linear algebra",
    "You escaped what I've escaped - You'd be in Paris getting fucked up too",
]
query = "Where is Paris?"
```

```python
#
infinity_api_url = "http://localhost:7797/v1"
# 目前模型未经验证。
embeddings = InfinityEmbeddings(
    model="sentence-transformers/all-MiniLM-L6-v2", infinity_api_url=infinity_api_url
)
try:
    documents_embedded = embeddings.embed_documents(documents)
    query_result = embeddings.embed_query(query)
    print("embeddings created successful")
except Exception as ex:
    print(
        "请确保 infinity 实例正在运行。请点击 "
        f"{infinity_api_url.replace('v1', 'docs')} 进行验证 异常: {ex}. "
    )
```
