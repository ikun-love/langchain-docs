title: 在 Hugging Face 上使用 Instruct Embedding
---

> [Hugging Face sentence-transformers](https://huggingface.co/sentence-transformers) 是一个用于实现最先进的句子、文本和图像嵌入（Embeddings）的 Python 框架。
> 其中一种 Instruct Embedding 模型被用在了 `HuggingFaceInstructEmbeddings` 类中。

```python
from langchain_community.embeddings import HuggingFaceInstructEmbeddings
```

```python
embeddings = HuggingFaceInstructEmbeddings(
    query_instruction="Represent the query for retrieval: "
)
```

```output
load INSTRUCTOR_Transformer
max_seq_length  512
```

```python
text = "This is a test document."
```

```python
query_result = embeddings.embed_query(text)
```
