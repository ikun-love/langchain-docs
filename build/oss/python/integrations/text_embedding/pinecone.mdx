---
title: Pinecone 嵌入（Embeddings）
---

Pinecone 的推理 API 可以通过 `PineconeEmbeddings` 访问，它通过 Pinecone 服务提供文本嵌入（Text Embeddings）功能。我们首先安装所需的依赖库：

```python
!pip install -qU "langchain-pinecone>=0.2.0"
```

接下来，我们需要[注册/登录 Pinecone](https://app.pinecone.io) 以获取我们的 API 密钥：

```python
import os
from getpass import getpass

os.environ["PINECONE_API_KEY"] = os.getenv("PINECONE_API_KEY") or getpass(
    "请输入您的 Pinecone API 密钥: "
)
```

请查阅文档以了解可用的[模型](https://docs.pinecone.io/models/overview)。现在我们像下面这样初始化嵌入模型：

```python
from langchain_pinecone import PineconeEmbeddings

embeddings = PineconeEmbeddings(model="multilingual-e5-large")
```

从这里开始，我们可以同步或异步地创建嵌入。我们先从同步操作开始！我们使用 `embed_query` 来嵌入单个文本，作为查询嵌入（即我们在 RAG 中用来搜索的内容）：

```python
docs = [
    "Apple is a popular fruit known for its sweetness and crisp texture.",
    "The tech company Apple is known for its innovative products like the iPhone.",
    "Many people enjoy eating apples as a healthy snack.",
    "Apple Inc. has revolutionized the tech industry with its sleek designs and user-friendly interfaces.",
    "An apple a day keeps the doctor away, as the saying goes.",
]
```

```python
doc_embeds = embeddings.embed_documents(docs)
doc_embeds
```

```python
query = "Tell me about the tech company known as Apple"
query_embed = embeddings.embed_query(query)
query_embed
```
