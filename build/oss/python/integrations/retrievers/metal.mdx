>[Metal](https://github.com/getmetal/metal-python) 是一个用于管理 ML 嵌入（ML Embeddings）的服务。

本 Notebook 演示了如何使用 [Metal](https://docs.getmetal.io/introduction) 的检索器（retriever）。

首先，您需要注册 Metal 账户并获取一个 API 密钥。您可以在 [此处](https://docs.getmetal.io/misc-create-app) 完成注册。

```python
pip install -qU  metal_sdk
```

```python
from metal_sdk.metal import Metal

API_KEY = ""
CLIENT_ID = ""
INDEX_ID = ""

metal = Metal(API_KEY, CLIENT_ID, INDEX_ID)
```

## 嵌入文档 (Ingest Documents)

仅当您尚未设置索引时，才需要执行此操作。

```python
metal.index({"text": "foo1"})
metal.index({"text": "foo"})
```

```output
{'data': {'id': '642739aa7559b026b4430e42',
  'text': 'foo',
  'createdAt': '2023-03-31T19:51:06.748Z'}}
```

## 查询 (Query)

现在我们的索引已经设置好了，我们可以配置检索器并开始对其进行查询。

```python
from langchain_community.retrievers import MetalRetriever
```

```python
retriever = MetalRetriever(metal, params={"limit": 2})
```

```python
retriever.invoke("foo1")
```
