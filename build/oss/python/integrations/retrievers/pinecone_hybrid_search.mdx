>[Pinecone](https://docs.pinecone.io/docs/overview) 是一个功能广泛的向量数据库。

本 Notebook 将介绍如何使用一个底层基于 Pinecone 和混合搜索（Hybrid Search）的检索器。

此检索器的逻辑取自[此文档](https://docs.pinecone.io/docs/hybrid-search)。

要使用 Pinecone，您必须拥有一个 API 密钥和一个环境（Environment）。
以下是[安装说明](https://docs.pinecone.io/docs/quickstart)。

```python
pip install -qU  pinecone pinecone-text pinecone-notebooks
```

```python
# 连接到 Pinecone 并获取 API 密钥。
from pinecone_notebooks.colab import Authenticate

Authenticate()

import os

api_key = os.environ["PINECONE_API_KEY"]
```

```python
from langchain_community.retrievers import (
    PineconeHybridSearchRetriever,
)
```

我们希望使用 `OpenAIEmbeddings`，因此需要获取 OpenAI API 密钥。

```python
import getpass

if "OPENAI_API_KEY" not in os.environ:
    os.environ["OPENAI_API_KEY"] = getpass.getpass("OpenAI API Key:")
```

## 设置 Pinecone

您应该只需要执行此部分一次。

```python
import os

from pinecone import Pinecone, ServerlessSpec

index_name = "langchain-pinecone-hybrid-search"

# 初始化 Pinecone 客户端
pc = Pinecone(api_key=api_key)

# 创建索引
if index_name not in pc.list_indexes().names():
    pc.create_index(
        name=index_name,
        dimension=1536,  # 稠密模型的维度
        metric="dotproduct",  # 稀疏值仅支持点积 (dotproduct)
        spec=ServerlessSpec(cloud="aws", region="us-east-1"),
    )
```

```output
WhoAmIResponse(username='load', user_label='label', projectname='load-test')
```

索引创建完毕后，我们就可以使用它了。

```python
index = pc.Index(index_name)
```

## 获取嵌入向量（Embeddings）和稀疏编码器（Sparse Encoders）

嵌入向量用于稠密向量，分词器（tokenizer）用于稀疏向量。

```python
from langchain_openai import OpenAIEmbeddings

embeddings = OpenAIEmbeddings()
```

要将文本编码为稀疏值，您可以选择 SPLADE 或 BM25。对于**域外任务 (out of domain tasks)**，我们推荐使用 BM25。

有关稀疏编码器的更多信息，您可以查看 pinecone-text 库的[文档](https://pinecone-io.github.io/pinecone-text/pinecone_text.html)。

```python
from pinecone_text.sparse import BM25Encoder

# 如果您希望使用 SPLADE，可以改为：from pinecone_text.sparse import SpladeEncoder

# 使用默认的 tf-idf 值
bm25_encoder = BM25Encoder().default()
```

上述代码使用了默认的 tf-idf 值。强烈建议您根据自己的语料库（corpus）来拟合（fit）这些 tf-idf 值。您可以按如下方式操作：

```python
corpus = ["foo", "bar", "world", "hello"]

# 在您的语料库上拟合 tf-idf 值
bm25_encoder.fit(corpus)

# 将值保存到 json 文件
bm25_encoder.dump("bm25_values.json")

# 从 json 文件加载到您的 BM25Encoder 对象中
bm25_encoder = BM25Encoder().load("bm25_values.json")
```

## 加载检索器

现在我们可以构造检索器了！

```python
retriever = PineconeHybridSearchRetriever(
    embeddings=embeddings, sparse_encoder=bm25_encoder, index=index
)
```

## 添加文本（如果需要）

我们可以选择性地向检索器添加文本（如果它们尚未存在于其中）。

```python
retriever.add_texts(["foo", "bar", "world", "hello"])
```


## 使用检索器

我们现在可以使用检索器了！

```python
result = retriever.invoke("foo")
```
