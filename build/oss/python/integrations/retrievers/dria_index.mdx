title: Dria
---

>[Dria](https://dria.co/) 是一个公共 RAG 模型中心，开发者可以在其中贡献和利用一个共享的嵌入湖（embedding lake）。本 Notebook 演示如何使用 `Dria API` 来执行数据检索任务。

# 安装

请确保已安装 `dria` 包。您可以使用 pip 进行安装：

```python
pip install -qU dria
```

# 配置 API 密钥

设置您的 Dria API 密钥以进行访问授权。

```python
import os

os.environ["DRIA_API_KEY"] = "DRIA_API_KEY"
```

# 初始化 Dria 检索器

创建一个 `DriaRetriever` 实例。

```python
from langchain_community.retrievers import DriaRetriever

api_key = os.getenv("DRIA_API_KEY")
retriever = DriaRetriever(api_key=api_key)
```

# **创建知识库 (Knowledge Base)**

在 [Dria 的知识中心](https://dria.co/knowledge) 创建一个知识库。

```python
contract_id = retriever.create_knowledge_base(
    name="法国的人工智能发展",
    embedding=DriaRetriever.models.jina_embeddings_v2_base_en.value,
    category="Artificial Intelligence",
    description="探索法国在人工智能领域的发展和贡献。",
)
```

# 添加数据

将数据加载到您的 Dria 知识库中。

```python
texts = [
    "要添加到 Dria 的第一段文本。",
    "需要存储的另一个信息片段。",
    "要包含在 Dria 知识库中的更多数据。",
]

ids = retriever.add_texts(texts)
print("数据已添加，ID 为:", ids)
```

# 检索数据

给定一个查询，使用检索器查找相关的文档。

```python
query = "查找关于 Dria 的信息。"
result = retriever.invoke(query)
for doc in result:
    print(doc)
```
