> [支持向量机 (SVM)](https://scikit-learn.org/stable/modules/svm.html#support-vector-machines) 是一组监督学习方法，可用于分类、回归和异常值检测。

本教程将介绍如何使用一个底层依赖 `scikit-learn` 包中的 `SVM` 的检索器。

主要参考了 [github.com/karpathy/randomfun/blob/master/knn_vs_svm.html](https://github.com/karpathy/randomfun/blob/master/knn_vs_svm.html)

```python
from langchain_community.retrievers import SVMRetriever
from langchain_openai import OpenAIEmbeddings
```

## 使用文本创建新的检索器 (Retriever)

```python
retriever = SVMRetriever.from_texts(
    ["foo", "bar", "world", "hello", "foo bar"], OpenAIEmbeddings()
)
```

## 使用检索器

我们现在可以使用这个检索器了！

```python
result = retriever.invoke("foo")
```
