>[RAGatouille](https://github.com/bclavie/RAGatouille) 使其使用 `ColBERT` 变得尽可能简单！[ColBERT](https://github.com/stanford-futuredata/ColBERT) 是一个快速且准确的检索模型，它可以在毫秒级别的时间内对大型文本集合实现可扩展的、基于 BERT 的搜索。

请参阅 [ColBERTv2: Effective and Efficient Retrieval via Lightweight Late Interaction](https://arxiv.org/abs/2112.01488) 论文。

我们可以通过多种方式使用 RAGatouille。

## 安装 (Setup)

集成存在于 `ragatouille` 包中。

```bash
pip install -U ragatouille
```

## 检索器 (Retriever)

我们可以将 RAGatouille 用作检索器 (Retriever)。有关此方面的更多信息，请参阅 [RAGatouille Retriever](/oss/python/integrations/retrievers/ragatouille)

## 文档压缩器 (Document Compressor)

我们也可以在现成 (off-the-shelf) 的情况下使用 RAGatouille 作为重排序器 (reranker)。这将允许我们使用 ColBERT 对从任何通用检索器检索到的结果进行重新排序。这样做的好处是我们可以基于任何现有索引执行此操作，因此我们不需要创建新的索引。

## 设置通用检索器 (Setup Vanilla Retriever)

首先，我们设置一个通用的检索器作为示例。

```python
import requests
from langchain_community.vectorstores import FAISS
from langchain_openai import OpenAIEmbeddings
from langchain_text_splitters import RecursiveCharacterTextSplitter


def get_wikipedia_page(title: str):
    """
    检索维基百科页面的完整文本内容。

    :param title: str - 维基百科页面的标题。
    :return: str - 页面的完整文本内容，以原始字符串形式返回。
    """
    # 维基百科 API 端点
        URL = "https://en.wikipedia.org/w/api.php"

    # API 请求参数
        params = {
        "action": "query",
        "format": "json",
        "titles": title,
        "prop": "extracts",
        "explaintext": True,
    }

    # 自定义 User-Agent 标头以符合维基百科的最佳实践
        headers = {"User-Agent": "RAGatouille_tutorial/0.0.1 (ben@clavie.eu)"}

        response = requests.get(URL, params=params, headers=headers)
        data = response.json()

    # 提取页面内容
        page = next(iter(data["query"]["pages"].values()))
    return page["extract"] if "extract" in page else None


text = get_wikipedia_page("Hayao_Miyazaki")
text_splitter = RecursiveCharacterTextSplitter(chunk_size=500, chunk_overlap=0)
texts = text_splitter.create_documents([text])
```

```python
retriever = FAISS.from_documents(texts, OpenAIEmbeddings()).as_retriever(
        search_kwargs={"k": 10}
)
```

```python
docs = retriever.invoke("What animation studio did Miyazaki found")
docs[0]
```

## 使用 ColBERT 作为重排序器 (Using ColBERT as a reranker)

```python
from langchain_classic.retrievers.contextual_compression import ContextualCompressionRetriever

compression_retriever = ContextualCompressionRetriever(
        base_compressor=RAG.as_langchain_document_compressor(), base_retriever=retriever
)

compressed_docs = compression_retriever.invoke(
    "What animation studio did Miyazaki found"
)
```
