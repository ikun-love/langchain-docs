title: Tavily
---

[Tavily](https://tavily.com) 是一款专门为 AI Agent 设计的搜索引擎。
Tavily 同时提供搜索（Search）和提取（Extract）API，AI 开发者可以轻松地将其应用程序与**实时在线信息**集成。Tavily 的主要目标是**从受信任的来源提供事实性、可靠的信息**，从而提高 AI 生成内容和推理的准确性和可靠性。

## 安装与设置 (Installation and Setup)

<CodeGroup>
```bash pip
pip install langchain-tavily
```

```bash uv
uv add langchain-tavily
```
</CodeGroup>
