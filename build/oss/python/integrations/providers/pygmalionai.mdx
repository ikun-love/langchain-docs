> [PygmalionAI](https://pygmalion.chat/) 是一家支持开源模型的公司，它为 [Aphrodite Engine](https://github.com/PygmalionAI/aphrodite-engine) 提供推理端点（inference endpoint）服务。

## 安装和设置 (Installation and Setup)

<CodeGroup>
```bash pip
pip install aphrodite-engine
```

```bash uv
uv add aphrodite-engine
```
</CodeGroup>

## 大型语言模型 (LLMs)

```python
from langchain_community.llms import Aphrodite
```
