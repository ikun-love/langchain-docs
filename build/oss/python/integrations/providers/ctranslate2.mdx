>[CTranslate2](https://opennmt.net/CTranslate2/quickstart.html) 是一个 C++ 和 Python 库，用于对 Transformer 模型进行高效的推理（Inference）。

该项目实现了一个自定义的运行时（runtime），它应用了许多性能优化技术，例如权重量化（weights quantization）、层融合（layers fusion）、批次重排序（batch reordering）等，以在 CPU 和 GPU 上加速 Transformer 模型并减少其内存占用。

完整的特性列表和支持的模型可以在[项目仓库](https://opennmt.net/CTranslate2/guides/transformers.html)中找到。要开始使用，请查阅官方的[快速入门指南](https://opennmt.net/CTranslate2/quickstart.html)。

## 安装和设置

安装 Python 包：

<CodeGroup>
```bash pip
pip install ctranslate2
```

```bash uv
uv add ctranslate2
```
</CodeGroup>
