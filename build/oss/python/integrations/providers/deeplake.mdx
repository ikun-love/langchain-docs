[Deeplake](https://www.deeplake.ai/) 是一个**专为人工智能和深度学习应用优化**的数据库。

## 安装和设置

<CodeGroup>
```bash pip
pip install langchain-deeplake
```

```bash uv
uv add langchain-deeplake
```
</CodeGroup>
