> [Blackboard Learn](https://en.wikipedia.org/wiki/Blackboard_Learn)（先前称为 `Blackboard Learning Management System`）是由 Blackboard 公司开发的一款基于 Web 的虚拟学习环境和学习管理系统 (LMS)。该软件具有课程管理、可定制的开放式架构以及可扩展的设计，允许与学生信息系统和身份验证协议进行集成。它可以安装在本地服务器上，由 `Blackboard ASP Solutions` 托管，或者作为托管在 Amazon Web Services 上的软件即服务 (SaaS) 提供。其主要目的包括为传统面对面课程增加在线元素，以及开发几乎不需要或完全不需要面对面会议的纯在线课程。

## 安装与设置

对于 Blackboard 来说，没有特殊的设置要求。
