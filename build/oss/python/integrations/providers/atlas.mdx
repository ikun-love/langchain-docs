> [Nomic Atlas](https://docs.nomic.ai/index.html) 是一个用于与小规模和互联网规模的非结构化数据集进行交互的平台。

## 安装和设置

- 使用 `pip install nomic` 安装 Python 包
- `Nomic` 也包含在 LangChain 的 poetry 附加项中：`poetry install -E all`

## 向量存储 (VectorStore)

请参阅 [使用示例](/oss/python/integrations/vectorstores/atlas)。

```python
from langchain_community.vectorstores import AtlasDB
```
