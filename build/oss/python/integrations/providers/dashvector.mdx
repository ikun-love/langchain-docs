> [DashVector](https://help.aliyun.com/document_detail/2510225.html) 是一个**全托管的向量数据库服务**，它支持高维度的稠密（dense）和稀疏（sparse）向量，具备实时插入和过滤搜索能力。该服务旨在**自动扩展**，以适应不同的应用需求。

本文档演示了如何在 LangChain 生态系统中使用 DashVector。具体来说，它展示了如何安装 DashVector，以及如何将其作为 `VectorStore` 插件集成到 LangChain 中。

本文档分为两个部分：安装和配置，以及特定 DashVector 封装器的引用说明。

## 安装和配置 (Installation and Setup)

安装 Python SDK:

<CodeGroup>
```bash pip
pip install dashvector
```

```bash uv
uv add dashvector
```
</CodeGroup>

您必须拥有一个 API 密钥。这里是 [安装指南](https://help.aliyun.com/document_detail/2510223.html)。

## 嵌入式模型 (Embedding models)

```python
from langchain_community.embeddings import DashScopeEmbeddings
```

请参阅 [使用示例](/oss/python/integrations/vectorstores/dashvector)。

## 向量存储 (Vector Store)

DashVector Collection 被封装成一个熟悉的 `VectorStore` 接口，以便在 LangChain 中原生使用。这使得它可以立即用于各种场景，例如**语义搜索**或**示例选择**。

您可以通过以下方式导入这个向量存储：
```python
from langchain_community.vectorstores import DashVector
```

有关 DashVector 封装器的详细演练，请参阅 [此 Notebook](/oss/python/integrations/vectorstores/dashvector)。
