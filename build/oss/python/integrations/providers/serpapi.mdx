本页面介绍如何在 LangChain 中使用 SerpAPI 搜索 API。
内容分为两部分：安装和设置，以及特定 SerpAPI 包装器的参考。

## 安装和设置
- 使用 `pip install google-search-results` 安装所需依赖
- 获取 SerpAPI 的 API 密钥，并将其设置为环境变量（`SERPAPI_API_KEY`）

## 包装器 (Wrappers)

### 工具类 (Utility)

存在一个包装此 API 的 SerpAPI 工具类。要导入此工具类：

```python
from langchain_community.utilities import SerpAPIWrapper
```

有关此包装器的更详细的逐步指南，请参阅[本示例笔记本](/oss/python/integrations/tools/serpapi)。

### 工具 (Tool)

您也可以轻松地将此包装器加载为“工具”（Tool，用于与 Agent 一起使用）。
您可以通过以下方式实现：
```python
from langchain_community.agent_toolkits.load_tools import load_tools
tools = load_tools(["serpapi"])
```

有关此内容的更多信息，请参阅[此页面](/oss/python/integrations/tools)。
