> [SQLite](https://en.wikipedia.org/wiki/SQLite) 是一个用 C 编程语言编写的数据库引擎。它不是一个独立的应用程序，而是一个软件开发者嵌入到其应用中的库。因此，它属于内嵌式数据库（embedded databases）家族。它是部署最广泛的数据库引擎，因为它被一些顶级的网页浏览器、操作系统、手机以及其他嵌入式系统所使用。

## 安装和设置 (Installation and Setup)

我们需要安装 `SQLAlchemy` Python 包。

<CodeGroup>
```bash pip
pip install SQLAlchemy
```

```bash uv
uv add SQLAlchemy
```
</CodeGroup>
