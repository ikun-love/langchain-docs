本页面介绍如何在 LangChain 中使用 Marqo 生态系统。

### **什么是 Marqo？**

Marqo 是一个张量（tensor）搜索引擎，它使用存储在内存中 HNSW 索引中的嵌入向量（embeddings）来实现尖端的搜索速度。Marqo 可以通过水平索引分片（horizontal index sharding）扩展到数亿文档的索引，并支持异步和非阻塞的数据上传和搜索。Marqo 使用来自 PyTorch、Huggingface、OpenAI 等的最新机器学习模型。您可以从预先配置好的模型开始，也可以自带模型。内置的 ONNX 支持和转换允许在 CPU 和 GPU 上实现更快的推理和更高的吞吐量。

由于 Marqo 包含自己的推理（inference）能力，因此您的文档可以混合文本和图像。您可以将包含来自其他系统数据的 Marqo 索引带入 LangChain 生态系统，而无需担心嵌入向量的兼容性问题。

Marqo 的部署非常灵活，您可以使用我们的 Docker 镜像自行开始，或者[联系我们了解我们的托管云服务！](https://www.marqo.ai/pricing)

要使用我们的 Docker 镜像在本地运行 Marqo，[请参阅我们的入门指南](https://docs.marqo.ai/latest/)。

## 安装与设置

- 使用 `pip install marqo` 安装 Python SDK

## 封装器（Wrappers）

### VectorStore

Marqo 索引有一个封装器，允许您在 vectorstore 框架内使用它们。Marqo 允许您从一系列模型中选择用于生成嵌入向量的模型，并暴露了一些预处理配置。

Marqo vectorstore 也可以处理现有的多模态索引，即您的文档包含图像和文本的混合。有关更多信息，请参阅[我们的文档](https://docs.marqo.ai/latest/#multi-modal-and-cross-modal-search)。请注意，使用现有多模态索引实例化 Marqo vectorstore 会禁用通过 LangChain vectorstore 的 `add_texts` 方法向其中添加任何新文档的功能。

要导入此 vectorstore：

```python
from langchain_community.vectorstores import Marqo
```

有关 Marqo 封装器及其一些独特功能的更详细演练，请参阅[此 Notebook](/oss/python/integrations/vectorstores/marqo)
