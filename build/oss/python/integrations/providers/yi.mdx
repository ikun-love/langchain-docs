> [01.AI](https://www.lingyiwanwu.com/en) 由李开复博士创立，是一家处于 AI 2.0 前沿的全球性公司。他们提供尖端的[大型语言模型](https://baike.baidu.com/item/%E5%A4%A7%E5%9E%8B%E8%AF%AD%E8%A8%80%E6%A8%A1%E5%9E%8B/7735310)，包括 Yi 系列模型，参数规模从 60 亿（6B）到数百亿不等。01.AI 还提供多模态模型、开放的 API 平台，以及像 Yi-34B/9B/6B 和 Yi-VL 这样的开源选项。

## 安装与设置

请在[中国站点](https://platform.lingyiwanwu.com/apikeys)或[全球站点](https://platform.01.ai/apikeys)注册并获取 API 密钥。

## LLM（大型语言模型）

有关使用示例，请参阅 [usage example](/oss/python/integrations/llms/yi)。

```python
from langchain_community.llms import YiLLM
```

## Chat Models（聊天模型）

有关使用示例，请参阅 [usage example](/oss/python/integrations/chat/yi)。

```python
from langchain_community.chat_models import ChatYi
```
