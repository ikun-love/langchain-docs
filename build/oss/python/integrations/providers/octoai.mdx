> [OctoAI](https://docs.octoai.cloud/docs) 提供了便捷的方式来访问高效的计算资源，并使用户能够将其选择的 AI 模型集成到应用程序中。`OctoAI` 计算服务可以帮助您轻松地运行、微调和扩展 AI 应用。

## 安装和设置 (Installation and Setup)

- 安装 `openai` Python 包：
  ```bash
  pip install openai
  ```
- 在 `OctoAI` 上注册，并从 [您的 OctoAI 账户页面](https://octoai.cloud/settings) 获取 API 令牌 (API Token)。

## 聊天模型 (Chat models)

请参阅 [使用示例](/oss/python/integrations/chat/octoai)。

```python
from langchain_community.chat_models import ChatOctoAI
```

## LLM 模型 (LLMs)

请参阅 [使用示例](/oss/python/integrations/llms/octoai)。

```python
from langchain_community.llms.octoai_endpoint import OctoAIEndpoint
```

## 嵌入模型 (Embedding models)

```python
from langchain_community.embeddings.octoai_embeddings import OctoAIEmbeddings
```
