> [Everly AI](https://everlyai.xyz/) 允许您在云端大规模运行机器学习模型。
> 它还为 [多个 LLM 模型](https://everlyai.xyz/) 提供了 API 访问权限。

## 安装与设置 (Installation and Setup)

要使用 `Everly AI`，您需要一个 API 密钥。请访问
[Everly AI](https://everlyai.xyz/) 在您的个人资料中创建 API 密钥。

## 聊天模型 (Chat models)

请参阅 [使用示例](/oss/python/integrations/chat/everlyai)。

```python
from langchain_community.chat_models import ChatEverlyAI
```
