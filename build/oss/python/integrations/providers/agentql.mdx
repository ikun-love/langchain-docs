---
title: AgentQL
---

[AgentQL](https://www.agentql.com/) 能够使用 AgentQL **查询语句**（[AgentQL query](https://docs.agentql.com/agentql-query)）或**自然语言提示**（Natural Language prompt）从任何网页提取结构化数据并进行网页交互。AgentQL 可以在多种语言和网页上使用，并且具有很好的稳定性，不会随时间的网页变化而失效。

## 安装与设置

安装集成包：

<CodeGroup>
```bash pip
pip install langchain-agentql
```

```bash uv
uv add langchain-agentql
```
</CodeGroup>

## API 密钥

请从我们的 [Dev Portal](https://dev.agentql.com/) 获取 API 密钥，并将其添加到您的环境变量中：
```
export AGENTQL_API_KEY="your-api-key-here"
```

## DocumentLoader (文档加载器)
AgentQL 的文档加载器能够使用 AgentQL 查询语句从任何网页提取结构化数据。

```python
from langchain_agentql.document_loaders import AgentQLLoader
```
请参阅我们的 [文档加载器文档和使用示例](/oss/python/integrations/document_loaders/agentql)。

## Tools and Toolkits (工具和工具包)
AgentQL 工具集提供网页交互功能，并能使用 AgentQL 查询语句或自然语言提示从任何网页提取结构化数据。

```python
from langchain_agentql.tools import ExtractWebDataTool, ExtractWebDataBrowserTool, GetWebElementBrowserTool
from langchain_agentql import AgentQLBrowserToolkit
```
请参阅我们的 [工具文档和使用示例](/oss/python/integrations/tools/agentql)。
