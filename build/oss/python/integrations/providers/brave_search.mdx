>[Brave Search](https://en.wikipedia.org/wiki/Brave_Search) 是由 Brave Software 开发的一个搜索引擎。
> - `Brave Search` 使用其自有的网页索引。截至 2022 年 5 月，它覆盖了超过 100 亿个页面，并且有 92% 的搜索结果是无需依赖任何第三方即可提供的，其余部分是通过服务器端从 Bing API（或在用户选择加入的基础上，客户端从 Google）检索的。根据 Brave 的说法，该索引被“故意设置为比 Google 或 Bing 的索引小”，以帮助避免垃圾信息和其他低质量内容。其缺点是“Brave Search 在恢复长尾查询方面还不如 Google”。
>- `Brave Search Premium`：截至 2023 年 4 月，Brave Search 是一个无广告的网站，但它最终将转向一种包含广告的新模式，届时付费（Premium）用户将获得无广告体验。默认情况下，包括 IP 地址在内的用户数据不会被收集。如果需要选择加入数据收集，则需要一个付费账户。

## 安装和设置

要访问 Brave Search API，您需要[创建一个账户并获取一个 API 密钥](https://api.search.brave.com/app/dashboard)。
