本页面介绍如何在 LangChain 中使用 [MariaDB](https://github.com/mariadb/) 生态系统。
内容分为两部分：安装与配置，以及特定于 PGVector 的封装器引用。

## 安装 (Installation)
- 安装 C/C++ 连接器

在 Debian, Ubuntu 上：
```bash
sudo apt install libmariadb3 libmariadb-dev
```

在 CentOS, RHEL, Rocky Linux 上：
```bash
sudo yum install MariaDB-shared MariaDB-devel
```

- 使用 `pip install mariadb` 安装 Python 连接器包

## 配置 (Setup)
1. 第一步是安装 MariaDB 11.7.1 或更高版本。

    使用 Docker 镜像是开始此过程最简单的方法。

## 封装器 (Wrappers)

### 向量存储 (VectorStore)

我们提供了一个围绕 MariaDB 向量数据库的封装器，允许您将其用作向量存储（Vectorstore），无论是用于语义搜索还是示例选择。

要导入此向量存储：
```python
from langchain_mariadb import MariaDBStore
```
