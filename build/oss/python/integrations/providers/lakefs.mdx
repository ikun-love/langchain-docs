> [lakeFS](https://docs.lakefs.io/) 为数据湖提供可扩展的版本控制，它使用类似 Git 的语义来创建和访问这些版本。

## 安装和设置

获取 `ENDPOINT`、`LAKEFS_ACCESS_KEY` 和 `LAKEFS_SECRET_KEY`。
您可以在[此处](https://docs.lakefs.io/quickstart/launch.html)找到安装说明。


## 文档加载器 (Document Loader)

请参阅[此处](/oss/python/integrations/document_loaders/lakefs)的一个使用示例。

```python
from langchain_community.document_loaders import LakeFSLoader
```
