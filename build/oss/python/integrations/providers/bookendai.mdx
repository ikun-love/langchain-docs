LangChain 实现了与 [bookend.ai](https://bookend.ai/) 提供的嵌入（Embeddings）功能的集成。

## 安装和设置

您需要在 [bookend.ai](https://bookend.ai/) 网站上注册并获取 `API_KEY`。

## 嵌入模型

请参阅 [使用示例](/oss/python/integrations/text_embedding/bookend)。

```python
from langchain_community.embeddings import BookendEmbeddings
```
