>[Dria](https://dria.co/) 是一个面向开发者的公共 RAG 模型中心，开发者可以在此贡献和使用一个共享的嵌入式数据湖（embedding lake）。

有关 LangChain 与 Dria 集成的更多详细信息，请参阅[此页面](https://dria.co/docs/integrations/langchain)。

## 安装和设置 (Installation and Setup)

您需要安装一个 Python 包：

<CodeGroup>
```bash pip
pip install dria
```

```bash uv
uv add dria
```
</CodeGroup>

您需要从 Dria 获取一个 API 密钥。您可以通过在 [Dria](https://dria.co/) 注册来获得它。

## 检索器 (Retrievers)

请参阅 [Dria 索引](/oss/python/integrations/retrievers/dria_index) 的使用示例。

```python
from langchain_community.retrievers import DriaRetriever
```
