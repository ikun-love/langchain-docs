title: MCP 工具箱
---

LangChain 中的 [MCP 工具箱](https://googleapis.github.io/genai-toolbox/getting-started/introduction/) 允许您为智能体配备一系列工具。当智能体收到查询时，它可以智能地选择并使用 MCP 工具箱提供的最合适的工具来完成请求。

## 是什么？

MCP 工具箱本质上是您工具的**容器**。您可以将其视为智能体的“多功能工具设备”；它可以容纳您创建的任何工具。然后，智能体会根据用户的输入决定使用哪个特定的工具。

当您的智能体需要执行各种需要不同能力的任务时，这一点尤其有用。

## 安装

要开始使用，您需要安装必要的包：

<CodeGroup>
```bash pip
pip install toolbox-langchain
```

```bash uv
uv add toolbox-langchain
```
</CodeGroup>
