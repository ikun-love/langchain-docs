>[Fiddler](https://www.fiddler.ai/) 提供了一个统一的平台，用于在企业规模下监控、解释、分析和改进机器学习（ML）的部署。

## 安装和设置 (Installation and Setup)

通过以下信息将您的模型接入 Fiddler：[with Fiddler](https://demo.fiddler.ai):

* 您用于连接到 Fiddler 的 URL
* 您的组织 ID (`organization ID`)
* 您的授权令牌 (`authorization token`)

安装 Python 包：

<CodeGroup>
```bash pip
pip install fiddler-client
```

```bash uv
uv add fiddler-client
```
</CodeGroup>

## 回调 (Callbacks)

```python
from langchain_community.callbacks.fiddler_callback import FiddlerCallbackHandler
```
