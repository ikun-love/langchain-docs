title: Vectorize

> [Vectorize](https://vectorize.io/) 帮助您更快、更省心地构建 AI 应用。
> 它能自动执行数据提取，利用 RAG 评估找到最佳的向量化策略，
> 并允许您快速为非结构化数据部署实时的 RAG 管道（Pipelines）。
> 您的向量搜索索引将保持最新，并且它可以与您现有的向量数据库集成，
> 因此您可以完全掌控自己的数据。
> Vectorize 负责繁重的工作，让您可以专注于构建强大可靠的 AI 解决方案，而无需被数据管理工作所困扰。

# 安装和设置

安装以下 Python 软件包：

<CodeGroup>
```bash pip
pip install langchain-vectorize
```

```bash uv
uv add langchain-vectorize
```
</CodeGroup>

在此处 [免费注册一个 Vectorize 账户](https://platform.vectorize.io/)
在 [访问令牌 (Access Token)](https://docs.vectorize.io/rag-pipelines/retrieval-endpoint#access-tokens) 部分生成一个 API 令牌
收集您的组织 ID。您可以从浏览器 URL 中提取 `/organization/` 之后的部分 UUID 作为组织 ID。

设置以下环境变量（或变量）：
```python
VECTORIZE_ORG_ID="your-organization-id"
VECTORIZE_API_TOKEN="your-api-token"
```

## 检索器 (Retriever)

```python
from langchain_vectorize import VectorizeRetriever

retriever = VectorizeRetriever(
    api_token=VECTORIZE_API_TOKEN,
    organization=VECTORIZE_ORG_ID,
    pipeline_id="...",
)
retriever.invoke("query")
```

在 [示例 Notebook](/oss/python/integrations/retrievers/vectorize) 中了解更多信息。
