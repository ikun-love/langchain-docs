> [Joplin](https://joplinapp.org/) 是一款开源的笔记应用。它可以捕捉您的想法，并让您从任何设备安全地访问它们。

## 安装与设置

`Joplin API` 需要一个访问令牌（access token）。
您可以在[此处](https://joplinapp.org/api/references/rest_api/)找到安装说明。

## 文档加载器（Document Loader）

请参阅[此处](/oss/python/integrations/document_loaders/joplin)的用法示例。

```python
from langchain_community.document_loaders import JoplinLoader
```
