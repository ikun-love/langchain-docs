本文档介绍了如何在 LangChain 中使用 [Lantern](https://github.com/lanterndata/lantern)。
内容分为两部分：设置（Setup），以及对特定 Lantern 包装器的引用（Wrappers）。

## 设置 (Setup)
1. 第一步是创建一个安装了 `lantern` 扩展的数据库。

    请遵循 [Lantern 安装指南](https://github.com/lanterndata/lantern#-quick-install) 中的步骤来安装数据库和该扩展。使用 Docker 镜像是最简单的入门方式。

## 包装器 (Wrappers)

### 向量存储 (VectorStore)

有一个针对 Postgres 向量数据库的包装器，允许您将其用作向量存储，无论用于语义搜索还是示例选择。

导入此向量存储的方法如下：
```python
from langchain_community.vectorstores import Lantern
```
