[Vearch](https://github.com/vearch/vearch) 是一个可扩展的分布式系统，旨在实现深度学习向量的高效相似性搜索。

# 安装和设置

Vearch Python SDK 使得可以在本地使用 Vearch。可以通过 `pip install vearch` 轻松安装 Vearch Python SDK。

# 向量存储 (Vectorstore)

Vearch 也可以用作向量存储。更多详细信息请参阅[此笔记本](/oss/python/integrations/vectorstores/vearch)

```python
from langchain_community.vectorstores import Vearch
```
