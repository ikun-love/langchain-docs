>[NLP Cloud](https://docs.nlpcloud.com/#introduction) 是一个人工智能平台，它允许您使用最先进的 AI 引擎，甚至可以使用您自己的数据来训练您自己的引擎。

## 安装和设置

- 安装 `nlpcloud` 包。

<CodeGroup>
```bash pip
pip install nlpcloud
```

```bash uv
uv add nlpcloud
```
</CodeGroup>

- 获取一个 NLPCloud API 密钥，并将其设置为环境变量（`NLPCLOUD_API_KEY`）

## LLM (大型语言模型)

参阅 [使用示例](/oss/python/integrations/llms/nlpcloud)。

```python
from langchain_community.llms import NLPCloud
```
