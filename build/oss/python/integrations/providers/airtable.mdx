>[Airtable](https://en.wikipedia.org/wiki/Airtable) 是一种云协作服务。
`Airtable` 是一种电子表格/数据库混合应用，它具备数据库的功能，但界面和操作方式更类似于电子表格。
> Airtable 表中的字段类似于电子表格中的单元格，但它们支持特定的类型，如 `'checkbox'`（复选框）、`'phone number'`（电话号码）和 `'drop-down list'`（下拉列表），并且可以引用文件附件（例如图片）。

>用户可以创建数据库、设置列的类型、添加记录、将表格之间相互链接、进行协作、对记录进行排序，并将视图发布到外部网站。

## 安装和设置

```bash
pip install pyairtable
```

* 获取你的 [API 密钥](https://support.airtable.com/docs/creating-and-using-api-keys-and-access-tokens)。
* 获取你的 [Base ID](https://airtable.com/developers/web/api/introduction)（数据库 ID）。
* 从表格 URL 中获取 [Table ID](https://www.highviewapps.com/kb/where-can-i-find-the-airtable-base-id-and-table-id/#:~:text=Both%20the%20Airtable%20Base%20ID,URL%20that%20begins%20with%20tbl)（表 ID）。
