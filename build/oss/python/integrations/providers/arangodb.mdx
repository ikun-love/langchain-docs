> [ArangoDB](https://github.com/arangodb/arangodb) 是一个可扩展的图数据库系统，旨在更快地从互联数据中发掘价值。它通过单一的查询语言提供原生图、集成搜索引擎和 JSON 支持。ArangoDB 可以在本地、云端——任何地方运行。

## 安装与设置 (Installation and Setup)

使用以下命令安装 [ArangoDB Python 驱动程序](https://github.com/ArangoDB-Community/python-arango) 包：

<CodeGroup>
```bash pip
pip install python-arango
```

```bash uv
uv add python-arango
```
</CodeGroup>

## 图形问答链 (Graph QA Chain)

将您的 `ArangoDB` 数据库与聊天模型连接起来，以获取有关数据洞察。

请参阅此处的笔记本示例 [here](/oss/python/integrations/graphs/arangodb)。

```python
from arango import ArangoClient

from langchain_community.graphs import ArangoGraph
from langchain.chains import ArangoGraphQAChain
```
