---
title: Datadog 追踪 (Tracing)
---

>[ddtrace](https://github.com/DataDog/dd-trace-py) 是一个 Datadog 应用程序性能监控 (APM) 库，它提供了一个集成，用于监控您的 LangChain 应用程序。

ddtrace 集成针对 LangChain 的主要功能包括：
- **追踪 (Traces)**：捕获 LangChain 请求、参数、Prompt 完成情况，并帮助可视化 LangChain 操作。
- **指标 (Metrics)**：捕获 LangChain 请求延迟、错误以及 Token/成本使用情况（适用于 OpenAI LLM 和聊天模型）。
- **日志 (Logs)**：为每次 LangChain 操作存储 Prompt 完成数据。
- **仪表板 (Dashboard)**：将指标、日志和追踪数据组合到一个平面中，用于监控 LangChain 请求。
- **监控 (Monitors)**：对 LangChain 请求延迟或错误率的激增提供警报。

注意：`ddtrace` LangChain 集成目前为 LLM、聊天模型、文本嵌入模型 (Text Embedding Models)、Chains 和 Vectorstores 提供追踪功能。

## 安装和设置

1. 在您的 Datadog Agent 中启用 APM 和 StatsD，并配置 Datadog API 密钥。例如，在 Docker 中：

```
docker run -d --cgroupns host \
              --pid host \
              -v /var/run/docker.sock:/var/run/docker.sock:ro \
              -v /proc/:/host/proc/:ro \
              -v /sys/fs/cgroup/:/host/sys/fs/cgroup:ro \
              -e DD_API_KEY=<DATADOG_API_KEY> \
              -p 127.0.0.1:8126:8126/tcp \
              -p 127.0.0.1:8125:8125/udp \
              -e DD_DOGSTATSD_NON_LOCAL_TRAFFIC=true \
              -e DD_APM_ENABLED=true \
              gcr.io/datadoghq/agent:latest
```

2. 安装 Datadog APM Python 库。

<CodeGroup>
```shell pip
pip install "ddtrace>=1.17"
```

```shell uv
uv add "ddtrace>=1.17"
```
</CodeGroup>


3. 当您使用 `ddtrace-run` 命令前缀来启动您的 LangChain Python 应用程序命令时，可以自动启用 LangChain 集成：

```
DD_SERVICE="my-service" DD_ENV="staging" DD_API_KEY=<DATADOG_API_KEY> ddtrace-run python <your-app>.py
```

**注意**：如果 Agent 使用了非默认的主机名或端口，请确保同时设置了 `DD_AGENT_HOST`、`DD_TRACE_AGENT_PORT` 或 `DD_DOGSTATSD_PORT` 环境变量。

此外，也可以通过在应用程序中首次导入 `langchain` 之前添加 `patch_all()` 或 `patch(langchain=True)` 来以编程方式启用 LangChain 集成。

请注意，使用 `ddtrace-run` 或 `patch_all()` 也会启用 `requests` 和 `aiohttp` 集成（用于追踪到 LLM 服务的 HTTP 请求），以及 `openai` 集成（用于追踪到 OpenAI 库的请求）。

```python
from ddtrace import config, patch

# 注意：在调用 `patch()` 之前，请确保配置了集成！
# 例如：config.langchain["logs_enabled"] = True

patch(langchain=True)

# 追踪同步 HTTP 请求
# patch(langchain=True, requests=True)

# 追踪异步 HTTP 请求（到 OpenAI 库）
# patch(langchain=True, aiohttp=True)

# 包含来自 OpenAI 集成的底层 OpenAI Span
# patch(langchain=True, openai=True)patch_all
```

有关更高级的用法，请参阅 [APM Python 库文档](https://ddtrace.readthedocs.io/en/stable/installation_quickstart.html)。


## 配置

有关所有可用的配置选项，请参阅 [APM Python 库文档](https://ddtrace.readthedocs.io/en/stable/integrations.html#langchain)。


### Prompt 和 Completion 日志采样

要启用 Prompt 和 Completion 日志采样，请设置环境变量 `DD_LANGCHAIN_LOGS_ENABLED=1`。默认情况下，10% 的被追踪请求会输出包含 Prompt 和 Completion 数据的日志。

要调整日志采样率，请参阅 [APM 库文档](https://ddtrace.readthedocs.io/en/stable/integrations.html#langchain)。

**注意**：日志提交要求在运行 `ddtrace-run` 时指定了 `DD_API_KEY`。
