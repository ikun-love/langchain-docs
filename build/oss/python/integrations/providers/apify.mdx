title: Apify
---

>[Apify](https://apify.com) 是一个用于网页抓取和数据提取的云平台，它提供了一个包含一千多个预制应用的生态系统，这些应用被称为 “Actor”（执行者），可用于各种抓取、爬取和提取场景。

此集成使您能够在 `Apify` 平台上运行 Actor，并将它们的结果加载到 LangChain 中，以便用来自网页的文档和数据来填充您的向量索引。例如，这样可以根据网站文档、博客或知识库生成答案。

## 安装和设置

- 使用以下命令为 Python 安装 LangChain Apify 包：
<CodeGroup>
```bash pip
pip install langchain-apify
```

```bash uv
uv add langchain-apify
```
</CodeGroup>
- 获取您的 [Apify API 令牌](https://console.apify.com/account/integrations)，然后将其设置为环境变量（`APIFY_API_TOKEN`），或者在构造函数中将其作为 `apify_api_token` 传入。

## 工具 (Tool)

您可以使用 `ApifyActorsTool` 将 Apify Actor 与代理（Agents）一起使用。

```python
from langchain_apify import ApifyActorsTool
```

有关工具使用的示例，以及使用 LangGraph 结合工具调用的完整示例，请参阅 [此 Notebook](/oss/python/integrations/tools/apify_actors)，或者查看 [Apify LangGraph Agent Actor 模板](https://apify.com/templates/python-langgraph)。

如需了解如何使用此工具的更多信息，请访问 [Apify 集成文档](https://docs.apify.com/platform/integrations/langgraph)。

## 包装器 (Wrapper)

您可以使用 `ApifyWrapper` 在 Apify 平台上运行 Actor。

```python
from langchain_apify import ApifyWrapper
```

如需了解如何使用此包装器的更多信息，请参阅 [Apify 集成文档](https://docs.apify.com/platform/integrations/langchain)。

## 文档加载器 (Document Loader)

您还可以使用 `ApifyDatasetLoader` 从 Apify 数据集中获取数据。

```python
from langchain_apify import ApifyDatasetLoader
```

有关此加载器的更详细演练，请参阅 [此 Notebook](/oss/python/integrations/document_loaders/apify_dataset)。

此集成的源代码可在 [LangChain Apify 仓库](https://github.com/apify/langchain-apify) 中找到。
