> [TigerGraph](https://www.tigergraph.com/tigergraph-db/) 是一个原生的、分布式的、高性能图数据库。
> 数据以顶点（vertices）和边（edges）的图格式存储，这使得数据关系丰富，**非常适合用于增强 LLM 的响应生成（Grounding LLM responses）**。

## 安装和设置 (Installation and Setup)

请按照[如何连接到 `TigerGraph` 数据库](https://docs.tigergraph.com/pytigergraph/current/getting-started/connection)中的说明进行操作。

安装 Python SDK：

<CodeGroup>
```bash pip
pip install pyTigerGraph
```

```bash uv
uv add pyTigerGraph
```
</CodeGroup>

## 图存储 (Graph store)

### TigerGraph

请参阅[使用示例](/oss/python/integrations/graphs/tigergraph)。

```python
from langchain_community.graphs import TigerGraph
```
