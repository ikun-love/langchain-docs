> [ClickHouse](https://clickhouse.com/) 是一个快速、资源高效的开源数据库，专为实时应用和分析设计。它提供完整的 SQL 支持以及广泛的函数，以帮助用户编写分析查询。它内置了数据结构、距离搜索函数（如 `L2Distance`）以及[近似最近邻搜索索引](https://clickhouse.com/docs/en/engines/table-engines/mergetree-family/annindexes)。这使得 ClickHouse 能够作为高性能、可扩展的向量数据库来存储和使用 SQL 进行向量搜索。

## 安装和设置

我们需要安装 `clickhouse-connect` Python 包。

<CodeGroup>
```bash pip
pip install clickhouse-connect
```

```bash uv
uv add clickhouse-connect
```
</CodeGroup>
