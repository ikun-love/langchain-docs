>[Apache 软件基金会 (维基百科)](https://en.wikipedia.org/wiki/The_Apache_Software_Foundation)
> 是一个去中心化的开源开发者社区。他们开发和分发的软件遵循 Apache 许可证的条款，这是一个对自由和开源软件 (FOSS) 宽松、开放的许可证。Apache 项目的特点是协作式、基于共识的开发流程，以及一个开放且务实的软件许可证，这意味着它允许免费获得软件的开发者在非免费的条款下重新分发它。每个项目由一个自选的技术专家团队管理，这些专家是该项目的活跃贡献者。

## Apache AGE

>[Apache AGE](https://age.apache.org/) 是一个 `PostgreSQL` 扩展，提供了图数据库功能。`AGE` 是 `A Graph Extension`（图扩展）的首字母缩写，其灵感来源于 Bitnine 对 `PostgreSQL 10` 的 fork 版本 `AgensGraph`，`AgensGraph` 是一个多模型数据库。该项目的目标是创建一个可以同时处理关系模型和图模型数据的单一存储，使用户能够使用标准的 ANSI SQL 配合图查询语言 `openCypher`。`Apache AGE` 存储的数据元素包括节点、连接它们的边，以及节点和边的属性。

了解更多关于 [与 Apache AGE 集成](/oss/python/integrations/graphs/apache_age) 的信息。

## Apache Cassandra

>[Apache Cassandra](https://cassandra.apache.org/) 是一个 NoSQL、面向行的、高可扩展且高可用的数据库。从 5.0 版本开始，该数据库内置了向量搜索功能。

了解更多关于 [与 Apache Cassandra 集成](/oss/python/integrations/providers/cassandra/) 的信息。

## Apache Doris

>[Apache Doris](https://doris.apache.org/) 是一个现代化的实时分析数据仓库。它能对大规模的实时数据提供闪电般快速的分析。
> 通常情况下，`Apache Doris` 被归类为 OLAP (在线分析处理)，并且在 ClickBench（一个分析型 DBMS 的基准测试）中表现出色的性能。由于它拥有超快的向量化执行引擎，它也可以被用作一个快速的向量数据库 (vectordb)。

了解更多关于 [与 Apache Doris 集成](/oss/python/integrations/providers/apache_doris/) 的信息。

## Apache Kafka

>[Apache Kafka](https://github.com/apache/kafka) 是一个分布式消息系统，用于发布和订阅记录流。

## Apache Spark

>[Apache Spark](https://spark.apache.org/) 是一个用于大规模数据处理的统一分析引擎。它提供 Scala、Java、Python 和 R 的高级 API，以及支持用于数据分析的通用计算图的优化引擎。它还支持一套丰富的上层工具，包括用于 SQL 和 DataFrame 的 `Spark SQL`、用于 pandas 工作负载的 `pandas API on Spark`、用于机器学习的 `MLlib`、用于图处理的 `GraphX`，以及用于流处理的 `Structured Streaming`。

了解更多关于 [与 Apache Spark 集成](/oss/python/integrations/providers/spark) 的信息。
