本页面介绍如何在 LangChain 中使用 [Nebula](https://symbl.ai/nebula)（[Symbl.ai](https://symbl.ai/) 的 LLM 生态系统）。
内容分为两个部分：**安装与设置**，以及**特定的 Nebula 封装（Wrapper）引用**。

## 安装与设置

- 获取一个 [Nebula API 密钥](https://info.symbl.ai/Nebula_Private_Beta.html)，并将其设置为环境变量 `NEBULA_API_KEY`。
- 更多详细信息，请参阅 [Nebula 文档](https://docs.symbl.ai/docs/nebula-llm)。

### LLM

这里提供了一个 Nebula LLM 的封装（Wrapper），您可以通过以下方式访问它：

```python
from langchain_community.llms import Nebula
llm = Nebula()
```
