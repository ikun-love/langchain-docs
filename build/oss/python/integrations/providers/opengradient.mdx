[OpenGradient](https://www.opengradient.ai/) 是一个去中心化的 AI 计算网络，旨在提供全球可访问、无需许可且可验证的机器学习模型推理服务。

OpenGradient 的 `langchain` 软件包目前提供了一个工具包（toolkit），它允许开发者为其在 OpenGradient 网络上的模型构建自定义的机器学习推理工具。这在以前是一个挑战，因为大型模型的参数有“污染上下文窗口”的特性——想象一下不得不为你的 Agent 提供一个 200x200 的浮点数数据数组！

该工具包通过将所有数据处理逻辑封装在工具定义本身内部来解决这个问题。这种方法保持了 Agent 上下文窗口的整洁，同时让开发者完全灵活地为其 ML 模型实现自定义数据处理和实时数据检索。

## 安装与设置

您需要拥有一个 OpenGradient API 密钥才能访问 OpenGradient 网络。如果您已经有了 API 密钥，只需设置环境变量：

```python
!export OPENGRADIENT_PRIVATE_KEY="your-api-key"
```

如果您需要设置一个新的 API 密钥，请下载 opengradient SDK 并按照说明初始化新的配置。

```python
!pip install opengradient
!opengradient config init
```

设置好 API 密钥后，安装 `langchain-opengradient` 软件包：

```python
pip install -U langchain-opengradient
```

## OpenGradient 工具包

`OpenGradientToolkit` 赋予开发者能力，可以基于部署在 OpenGradient 去中心化网络上的 [ML 模型](https://hub.opengradient.ai/models) 和 [工作流](https://docs.opengradient.ai/developers/sdk/ml_workflows.html) 创建专业化的工具。这种集成使得 LangChain Agent 能够访问强大的 ML 能力，同时还能保持高效的上下文使用。

### 主要优势

* 🔄 实时数据集成 - 在您的工具内部处理实时数据流。

* 🎯 动态处理 - 适应特定 Agent 输入的自定义数据管道。

* 🧠 上下文效率 - 处理复杂的 ML 操作而不会淹没您的上下文窗口。

* 🔌 无缝部署 - 与 OpenGradient 网络上已有的模型轻松集成。

* 🔧 完全定制化 - 通过 [OpenGradient SDK](https://docs.opengradient.ai/developers/sdk/model_management.html) 创建和部署您自己的特定模型，然后基于它们构建自定义工具。

* 🔐 可验证推理 - 所有推理都在去中心化的 OpenGradient 网络上运行，允许用户选择各种安全机制，例如 ZKML 和 TEE，以实现无需信任、可验证的模型执行。

有关详细示例和实现指南，请查看我们的 [综合教程](/oss/python/integrations/tools/opengradient_toolkit.ipynb)。
