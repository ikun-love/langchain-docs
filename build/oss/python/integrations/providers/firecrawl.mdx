> [FireCrawl](https://firecrawl.dev/?ref=langchain) 可以抓取并转换任何网站，生成可供大型语言模型（LLM）使用的结构化数据工具。
> 它会自动抓取所有可访问的子页面，并为每个页面提供干净的 Markdown 格式和相应的元数据（metadata）。**无需提供站点地图（sitemap）**。

## 安装与设置 (Installation and Setup)

安装 Python SDK：

<CodeGroup>
```bash pip
pip install firecrawl-py==0.0.20
```

```bash uv
uv add "firecrawl-py==0.0.20"
```
</CodeGroup>

## 文档加载器 (Document loader)

请参阅[使用示例](/oss/python/integrations/document_loaders/firecrawl)。

```python
from langchain_community.document_loaders import FireCrawlLoader
```
