title: Scrapeless
---

[Scrapeless](https://scrapeless.com) 提供灵活且功能丰富的[数据采集](https://scrapeless.com)服务，支持广泛的参数定制和多格式导出。

## 安装和设置

<CodeGroup>
```bash pip
pip install langchain-scrapeless
```

```bash uv
uv add langchain-scrapeless
```
</CodeGroup>

您需要设置您的 Scrapeless API 密钥：

```python
import os
os.environ["SCRAPELESS_API_KEY"] = "your-api-key"
```

## 工具 (Tools)

Scrapeless 集成提供了以下几种工具：

- [ScrapelessDeepSerpGoogleSearchTool](/oss/python/integrations/tools/scrapeless_scraping_api) - 能够提取所有类型 Google 搜索结果页面 (SERP) 的全面数据。
- [ScrapelessDeepSerpGoogleTrendsTool](/oss/python/integrations/tools/scrapeless_scraping_api) - 从 Google 检索关键词趋势数据，包括随时间变化的流行度、区域兴趣和相关搜索。
- [ScrapelessUniversalScrapingTool](/oss/python/integrations/tools/scrapeless_universal_scraping) - 访问和提取通常会阻止机器人的 JS 渲染网站上的数据。
- [ScrapelessCrawlerCrawlTool](/oss/python/integrations/tools/scrapeless_crawl) - 爬取一个网站及其链接页面，以提取全面的数据。
- [ScrapelessCrawlerScrapeTool](/oss/python/integrations/tools/scrapeless_crawl) - 从单个网页中提取信息。
