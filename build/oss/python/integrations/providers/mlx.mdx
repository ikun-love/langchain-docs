> [MLX](https://ml-explore.github.io/mlx/build/html/index.html) 是一个类似 `NumPy` 的数组框架，由 `Apple machine learning research` 团队打造，专为在 `Apple` 芯片上实现高效且灵活的机器学习而设计。

## 安装与设置 (Installation and Setup)

安装以下几个 Python 包：

<CodeGroup>
```bash pip
pip install mlx-lm transformers huggingface_hub
```

```bash uv
uv add mlx-lm transformers huggingface_hub
```
</CodeGroup>


## 对话模型 (Chat models)
