title: SparkLLM
---

>[SparkLLM](https://xinghuo.xfyun.cn/spark) 是科大讯飞独立研发的大规模认知模型。
它通过学习海量文本、代码和图像，具备了跨领域知识和语言理解能力。
它可以理解并基于自然对话来执行任务。

## 聊天模型 (Chat models)

请参阅 [使用示例](/oss/python/integrations/chat/sparkllm)。

```python
from langchain_community.chat_models import ChatSparkLLM
```

## 大型语言模型 (LLMs)

请参阅 [使用示例](/oss/python/integrations/llms/sparkllm)。

```python
from langchain_community.llms import SparkLLM
```

## 嵌入模型 (Embedding models)

请参阅 [使用示例](/oss/python/integrations/text_embedding/sparkllm)

```python
from langchain_community.embeddings import SparkLLMTextEmbeddings
```
