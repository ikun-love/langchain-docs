>[百川智能](https://www.baichuan-ai.com/) (Baichuan Inc.) 是一家处于 AGI 时代背景下的中国初创公司，
> 致力于解决人类最基本的需求：效率（Efficiency）、健康（Health）和幸福（Happiness）。

## 安装与设置

请[在此处](https://platform.baichuan-ai.com/)注册并获取 API 密钥。

## 大语言模型 (LLMs)

请参阅[使用示例](/oss/python/integrations/llms/baichuan)。

```python
from langchain_community.llms import BaichuanLLM
```

## 聊天模型 (Chat models)

请参阅[使用示例](/oss/python/integrations/chat/baichuan)。

```python
from langchain_community.chat_models import ChatBaichuan
```

## 嵌入模型 (Embedding models)

请参阅[使用示例](/oss/python/integrations/text_embedding/baichuan)。

```python
from langchain_community.embeddings import BaichuanTextEmbeddings
```
