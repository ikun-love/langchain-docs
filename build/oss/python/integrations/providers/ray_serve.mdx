[Ray Serve](https://docs.ray.io/en/latest/serve/index.html) 是一个可扩展的模型服务库，用于构建在线推理 API。Serve 特别适合系统组合（system composition），它允许你使用纯 Python 代码构建一个复杂的推理服务，该服务可以包含多个链式结构（chains）和业务逻辑。

## 本 Notebook 的目标

本 Notebook 展示了一个将 OpenAI 链式结构（chain）部署到生产环境的简单示例。你可以将其扩展，用于部署自己的自托管模型，并轻松定义模型在生产环境中高效运行时所需的硬件资源量（GPU 和 CPU）。有关自动扩缩容（autoscaling）等可用选项的更多信息，请参阅 Ray Serve 的 [文档](https://docs.ray.io/en/latest/serve/getting_started.html)。

## 设置 Ray Serve

使用 `pip install ray[serve]` 安装 ray。

## 通用骨架

部署服务的通用骨架如下所示：

```python
# 0: 导入 ray serve 和 starlette 的 request
from ray import serve
from starlette.requests import Request


# 1: 定义一个 Ray Serve 部署。
@serve.deployment
class LLMServe:
    def __init__(self) -> None:
        # 所有初始化代码都放在这里
        pass

    async def __call__(self, request: Request) -> str:
        # 可以在这里解析请求
        # 并返回一个响应
        return "Hello World"


# 2: 绑定模型到部署
deployment = LLMServe.bind()

# 3: 运行部署
serve.api.run(deployment)
```

```python
# 关闭部署
serve.api.shutdown()
```

## 部署具有自定义提示的 OpenAI 链的示例

从 [这里](https://platform.openai.com/account/api-keys) 获取一个 OpenAI API 密钥。运行以下代码时，系统将提示你输入 API 密钥。

```python
from langchain.chains import LLMChain
from langchain_core.prompts import PromptTemplate
from langchain_openai import OpenAI
```

```python
from getpass import getpass

OPENAI_API_KEY = getpass()
```

```python
@serve.deployment
class DeployLLM:
    def __init__(self):
        # 我们在这里初始化 LLM、模板和链
        llm = OpenAI(openai_api_key=OPENAI_API_KEY)
        template = "Question: {question}\n\nAnswer: Let's think step by step."
        prompt = PromptTemplate.from_template(template)
        self.chain = LLMChain(llm=llm, prompt=prompt)

    def _run_chain(self, text: str):
        return self.chain(text)

    async def __call__(self, request: Request):
        # 1. 解析请求
        text = request.query_params["text"]
        # 2. 运行链
        resp = self._run_chain(text)
        # 3. 返回响应
        return resp["text"]
```

现在我们可以绑定部署了。

```python
# 绑定模型到部署
deployment = DeployLLM.bind()
```

当我们想要运行部署时，可以指定端口号和主机。

```python
# 示例端口号
PORT_NUMBER = 8282
# 运行部署
serve.api.run(deployment, port=PORT_NUMBER)
```

现在服务已部署在端口 `localhost:8282` 上，我们可以发送一个 POST 请求来获取结果。

```python
import requests

text = "What NFL team won the Super Bowl in the year Justin Beiber was born?"
response = requests.post(f"http://localhost:{PORT_NUMBER}/?text={text}")
print(response.content.decode())
```
