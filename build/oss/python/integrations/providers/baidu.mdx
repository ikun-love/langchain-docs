> [百度智能云](https://cloud.baidu.com/) 是由 `Baidu, Inc.`（百度公司）提供的云服务，总部位于北京。它提供云存储服务、客户端软件、文件管理、资源共享以及第三方集成。

## 安装和设置

请在此处 [注册并获取 `Qianfan` 的 `AK` 和 `SK` 密钥](https://cloud.baidu.com/product/wenxinworkshop)。

## 大语言模型（LLMs）

### 百度千帆

请参阅 [使用示例](/oss/python/integrations/llms/baidu_qianfan_endpoint)。

```python
from langchain_community.llms import QianfanLLMEndpoint
```
