title: Nomic
---

>[Nomic](https://www.nomic.ai/) 致力于构建工具，使用户能够在消费级计算机上与 AI 规模的数据集进行交互并运行 AI 模型。
>
>`Nomic` 目前提供两款产品：
>
>- `Atlas`：可视化数据引擎 (the Visual Data Engine)
>- `GPT4All`：开源的边缘端语言模型生态系统 (the Open Source Edge Language Model Ecosystem)

Nomic 的集成存在于两个合作包中：[langchain-nomic](https://pypi.org/project/langchain-nomic/)
和 [langchain-community](https://pypi.org/project/langchain-community/)。

## 安装

您可以使用以下命令安装它们：

<CodeGroup>
```bash pip
pip install -U langchain-nomic
pip install -U langchain-community
```

```bash uv
uv add langchain-nomic
uv add langchain-community
```
</CodeGroup>

## LLM（大型语言模型）

### GPT4All

请参阅[使用示例](/oss/python/integrations/llms/gpt4all)。

```python
from langchain_community.llms import GPT4All
```

## 嵌入模型（Embedding models）

### NomicEmbeddings

请参阅[使用示例](/oss/python/integrations/text_embedding/nomic)。

```python
from langchain_nomic import NomicEmbeddings
```

### GPT4All

请参阅[使用示例](/oss/python/integrations/text_embedding/gpt4all)。

```python
from langchain_community.embeddings import GPT4AllEmbeddings
```

## 向量存储（Vector store）

### Atlas

请参阅[使用示例和安装说明](/oss/python/integrations/vectorstores/atlas)。

```python
from langchain_community.vectorstores import AtlasDB
```
