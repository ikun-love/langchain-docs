> [llamafile](https://github.com/Mozilla-Ocho/llamafile) 允许你将大型语言模型 (LLM) 作为一个**单一文件**进行分发和运行。

>`llamafile` 使开源 LLM 对开发者和最终用户都更加易于访问。`llamafile` 通过将 [llama.cpp](https://github.com/ggerganov/llama.cpp) 与 [Cosmopolitan Libc](https://github.com/jart/cosmopolitan) 结合到一个统一的框架中来实现这一点。该框架将 LLM 的所有复杂性浓缩成一个**单一文件可执行程序**（称为“llamafile”），该程序无需任何安装即可在大多数计算机上本地运行。

## 安装和设置

请参阅[安装说明](https://github.com/Mozilla-Ocho/llamafile?tab=readme-ov-file#quickstart)。

## LLM 模型

请参阅[使用示例](/oss/python/integrations/llms/llamafile)。

```python
from langchain_community.llms.llamafile import Llamafile
```

## 嵌入模型

```python
from langchain_community.embeddings import LlamafileEmbeddings
```
