>[Psychic](https://www.psychic.dev/) 是一个平台，用于通过 OAuth 与 `Notion`、`Zendesk`、`Confluence` 和 `Google Drive` 等 SaaS 工具集成，并将这些应用程序中的文档同步到您的 SQL 或向量数据库。您可以将其视为非结构化数据的 Plaid。

## 安装与设置

<CodeGroup>
```bash pip
pip install psychicapi
```

```bash uv
uv add psychicapi
```
</CodeGroup>

Psychic 易于设置——您导入 `react` 库，并使用您从 [Psychic 控制面板](https://dashboard.psychic.dev/) 获取的 `Sidekick API` 密钥进行配置。当您连接这些应用程序时，您可以从控制面板查看这些连接，并使用服务器端库检索数据。

1. 在[控制面板](https://dashboard.psychic.dev/)中创建一个账户。
2. 使用[React 库](https://docs.psychic.dev/sidekick-link)将 Psychic Link 模态框添加到您的前端 React 应用中。您将使用它来连接 SaaS 应用。
3. 创建连接后，您可以遵循[示例 Notebook](/oss/python/integrations/document_loaders/psychic)来使用 `PsychicLoader`。


## 相较于其他文档加载器的优势

1.	**统一 API：** 无需为每个 SaaS 应用构建 OAuth 流程和学习其 API，您只需集成 Psychic 一次，即可利用我们的统一 API 来检索数据。
2.	**数据同步：** 客户 SaaS 应用中的数据可能会很快过时。使用 Psychic，您可以配置 Webhook，以便按日或实时保持您的文档处于最新状态。
3.	**简化的 OAuth：** Psychic 端到端地处理 OAuth，这样您就不必花费时间为每次集成创建 OAuth 客户端、保持访问令牌的新鲜度以及处理 OAuth 重定向逻辑。
