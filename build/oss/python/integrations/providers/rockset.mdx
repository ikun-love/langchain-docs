> [Rockset](https://rockset.com/product/) 是一种实时分析数据库服务，旨在以规模化的方式，为低延迟、高并发的分析查询提供服务。它在结构化和半结构化数据上构建了一个 Converged Index™，并提供了一个高效的向量嵌入（vector embeddings）存储。它支持对无模式（schemaless）数据运行 SQL，这使其成为使用元数据过滤器运行向量搜索的理想选择。

## 安装和设置

请确保您拥有 Rockset 账户，并前往其 Web 控制台获取 API 密钥。相关详细信息可以在 [官方网站](https://rockset.com/docs/rest-api/) 上找到。

<CodeGroup>
```bash pip
pip install rockset
```

```bash uv
uv add rockset
```
</CodeGroup>
