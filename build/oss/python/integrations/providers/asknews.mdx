title: AskNews

[AskNews](https://asknews.app/) 通过处理和索引每日超过 300,000 篇文章，用**最新**的全球或历史新闻来增强语言模型的能力。它通过低延迟的终端节点提供**针对提示词优化**的响应，并确保新闻报道的透明度和多样性。

## 安装和设置

首先，你需要安装 `asknews` Python 包。

<CodeGroup>
```bash pip
pip install asknews
```

```bash uv
uv add asknews
```
</CodeGroup>

你还需要设置 AskNews API 凭证，这些凭证可以在 [AskNews 控制台](https://my.asknews.app/) 生成。

## 检索器 (Retriever)

请参阅[使用示例](/oss/python/integrations/retrievers/asknews)。

```python
from langchain_community.retrievers import AskNewsRetriever
```
