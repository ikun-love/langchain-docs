所有与 Konko 相关的操作和功能

>[Konko AI](https://www.konko.ai/) 为应用程序开发者提供了一个完全托管的 API，以帮助他们：

>1. **选择**适合其应用的开源或专有大型语言模型 (LLMs)。
>2. 通过与领先应用框架的集成和完全托管的 API，更快地**构建**应用程序。
>3. **微调**较小的开源 LLMs，以极低的成本实现行业领先的性能。
>4. **部署**满足安全、隐私、吞吐量和延迟服务水平协议 (SLA) 的生产规模 API，无需进行基础设施设置或管理，这一切都得益于 Konko AI 满足 SOC 2 合规性的多云基础设施。

## 安装和设置

1. 登录我们的 Web 应用，以 [创建 API 密钥](https://platform.konko.ai/settings/api-keys)，以便通过我们的端点访问模型，包括 [聊天补全](https://docs.konko.ai/reference/post-chat-completions) 和 [补全](https://docs.konko.ai/reference/post-completions)。
2. 启用 Python 3.8+ 环境。
3. 安装 SDK

<CodeGroup>
```bash pip
pip install konko
```

```bash uv
uv add konko
```
</CodeGroup>

4. 将 API 密钥设置为环境变量 (`KONKO_API_KEY`, `OPENAI_API_KEY`)

```bash
export KONKO_API_KEY={your_KONKO_API_KEY_here}
export OPENAI_API_KEY={your_OPENAI_API_KEY_here} #可选
```

有关更多详细信息，请参阅 [Konko 文档](https://docs.konko.ai/docs/getting-started)。


## LLM

**探索可用模型：** 首先在 Konko 上浏览 [可用模型](https://docs.konko.ai/docs/list-of-models)。每个模型都针对不同的用例和能力。

查找运行在 Konko 实例上的模型列表的另一种方法是通过此 [端点](https://docs.konko.ai/reference/get-models)。

查看使用 [示例](/oss/python/integrations/llms/konko)。

### 端点使用示例

- **使用 mistralai/Mistral-7B-v0.1 进行补全：**

  ```python
  from langchain_community.llms import Konko
  llm = Konko(max_tokens=800, model='mistralai/Mistral-7B-v0.1')
  prompt = "Generate a Product Description for Apple Iphone 15"
  response = llm.invoke(prompt)
  ```

## 聊天模型

查看使用 [示例](/oss/python/integrations/chat/konko)。


- **使用 Mistral-7B 进行聊天补全：**

  ```python
  from langchain.messages import HumanMessage
  from langchain_community.chat_models import ChatKonko
  chat_instance = ChatKonko(max_tokens=10, model = 'mistralai/mistral-7b-instruct-v0.1')
  msg = HumanMessage(content="Hi")
  chat_response = chat_instance([msg])
  ```
