`rank_bm25` (链接至：[https://github.com/dorianbrown/rank_bm25](https://github.com/dorianbrown/rank_bm25)) 是一个开源算法集合，旨在查询文档并返回最相关的结果，它常用于构建搜索引擎。

有关可用的具体算法，请参阅其 [项目页面](https://github.com/dorianbrown/rank_bm25)。


## 安装与设置

首先，您需要安装 `rank_bm25` Python 包。

<CodeGroup>
```bash pip
pip install rank_bm25
```

```bash uv
uv add rank_bm25
```
</CodeGroup>


## 检索器 (Retriever)

请参阅 [使用示例](/oss/python/integrations/retrievers/bm25)。

```python
from langchain_community.retrievers import BM25Retriever
```
