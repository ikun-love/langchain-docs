[Abso](https://abso.ai/#router) 是一个开源的 LLM（大语言模型）代理（Proxy）工具。它能够根据提示（Prompt）的复杂性，自动在快速模型和慢速模型之间进行路由选择。它使用多种启发式算法来选择最合适的模型。它具有非常高的速度和低延迟特性。

## 安装和设置

```bash
pip install langchain-abso
```
