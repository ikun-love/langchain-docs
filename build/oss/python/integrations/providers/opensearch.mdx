本页面介绍如何在 LangChain 中使用 OpenSearch 生态系统。
内容分为两个部分：**安装与设置**，以及特定 OpenSearch 组件的**封装器（Wrappers）引用**。

## 安装与设置
使用 `pip install opensearch-py` 安装 Python 软件包。
## 封装器 (Wrappers)

### 向量存储 (VectorStore)

我们提供了一个围绕 OpenSearch 向量数据库的封装器，允许您将其用作向量存储，用于语义搜索。该搜索可以利用 Lucene、NMSLib 和 Faiss 引擎提供的**近似向量搜索**，或者使用 Painless 脚本和脚本评分函数进行**暴力搜索**。

要导入此向量存储：
```python
from langchain_community.vectorstores import OpenSearchVectorSearch
```

有关 OpenSearch 封装器的更详细的逐步指南，请参阅[此笔记本](/oss/python/integrations/vectorstores/opensearch)。
