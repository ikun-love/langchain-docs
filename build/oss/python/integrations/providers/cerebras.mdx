在 Cerebras，我们开发了全球最大、最快的 AI 处理器——晶圆级引擎 3 (Wafer-Scale Engine-3, WSE-3)。由 WSE-3 驱动的 Cerebras CS-3 系统，代表了一种新型的 AI 超级计算机，它以无与伦比的性能和可扩展性，为生成式 AI 的训练和推理树立了新的行业标准。

将 Cerebras 作为您的推理提供商，您可以实现：
- 为 AI 推理工作负载带来前所未有的速度
- 以高吞吐量实现商业化部署
- 利用我们无缝的集群技术，轻松扩展您的 AI 工作负载

我们的 CS-3 系统可以快速、轻松地进行集群化，从而构建全球最大的 AI 超级计算机，让部署和运行最大型的模型变得简单。领先的企业、研究机构和政府目前正在使用 Cerebras 解决方案来开发专有模型，并训练流行的开源模型。

想体验 Cerebras 的强大功能吗？请访问我们的[官方网站](https://cerebras.ai)获取更多资源，并探索通过 Cerebras Cloud 或本地部署（on-premise）访问我们技术的方法！

有关 Cerebras Cloud 的更多信息，请访问 [cloud.cerebras.ai](https://cloud.cerebras.ai/)。我们的 API 参考文档位于 [inference-docs.cerebras.ai](https://inference-docs.cerebras.ai/)。

## 安装与设置
安装集成包：

<CodeGroup>
```bash pip
pip install langchain-cerebras
```

```bash uv
uv add langchain-cerebras
```
</CodeGroup>

## API 密钥
从 [cloud.cerebras.ai](https://cloud.cerebras.ai/) 获取一个 API 密钥，并将其添加到您的环境变量中：
```
export CEREBRAS_API_KEY="your-api-key-here"
```
