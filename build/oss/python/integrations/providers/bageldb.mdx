> [BagelDB](https://www.bageldb.ai/)（`AI 领域的开放向量数据库`），就像是 AI 数据的 GitHub。
它是一个协作平台，用户可以在其中创建、
共享和管理向量数据集。它能够支持独立开发人员的私有项目、
企业内部的协作项目，以及数据 DAO 的公开贡献。

## 安装和设置 (Installation and Setup)

<CodeGroup>
```bash pip
pip install betabageldb
```

```bash uv
uv add betabageldb
```
</CodeGroup>
