> [pg_embedding](https://github.com/neondatabase/pg_embedding) 是一个开源软件包，它使用 `Postgres` 和 `Hierarchical Navigable Small Worlds` (HNSW) 算法来进行向量相似性搜索和近似最近邻搜索。

## 安装与设置

我们需要安装几个 Python 包。

<CodeGroup>
```bash pip
pip install psycopg2-binary
```

```bash uv
uv add psycopg2-binary
```
</CodeGroup>

## 向量存储 (Vector Store)

请参阅 [使用示例](/oss/python/integrations/vectorstores/pgembedding)。

```python
from langchain_community.vectorstores import PGEmbedding
```
