> [IEIT Systems](https://en.ieisystem.com/) 是一家成立于 1999 年的中国信息技术公司。它提供 IT 基础设施产品、解决方案和服务，以及跨越云计算、大数据和人工智能领域的创新 IT 产品和解决方案。

```python
from langchain_community.llms.yuan2 import Yuan2
```

## Chat models (聊天模型)

查看 [安装说明](/oss/python/integrations/chat/yuan2/#setting-up-your-api-server)。

Yuan2.0 提供了一个与 OpenAI 兼容的 API，并且 ChatYuan2 是通过使用 `OpenAI client` 集成的。
因此，请确保已安装 `openai` 包。

<CodeGroup>
```bash pip
pip install openai
```

```bash uv
uv add openai
```
</CodeGroup>

查看一个 [使用示例](/oss/python/integrations/chat/yuan2)。

```python
from langchain_community.chat_models import ChatYuan2
```
