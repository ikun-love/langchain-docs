> [Embedchain](https://github.com/embedchain/embedchain) 是一个**检索增强生成 (RAG)** 框架，用于创建数据管道。它可以加载、索引、检索和同步所有数据。
>
>它既可以作为[开源软件包](https://github.com/embedchain/embedchain)使用，也可以作为[托管平台解决方案](https://app.embedchain.ai/)使用。

## 安装和设置

使用 pip 安装该软件包：

<CodeGroup>
```bash pip
pip install embedchain
```

```bash uv
uv add embedchain
```
</CodeGroup>

## 检索器 (Retriever)

请参阅[使用示例](/oss/python/integrations/retrievers/embedchain)。

```python
from langchain_community.retrievers import EmbedchainRetriever
```
