> [Typesense](https://typesense.org) 是一个开源的、内存中的搜索引 নির্বাচনী擎，您可以选择将其[自我托管](https://typesense.org/docs/guide/install-typesense.html#option-2-local-machine-self-hosting)或在 [Typesense Cloud](https://cloud.typesense.org/) 上运行。
> `Typesense` 的核心优势在于性能，它将整个索引存储在 RAM 中（同时在磁盘上提供备份），并且通过简化可用选项和设置合理的默认值，致力于提供开箱即用的开发者体验。

## 安装与设置

<CodeGroup>
```bash pip
pip install typesense openapi-schema-pydantic
```

```bash uv
uv add typesense openapi-schema-pydantic
```
</CodeGroup>
