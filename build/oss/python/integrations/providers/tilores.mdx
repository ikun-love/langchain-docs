[Tilores](https://tilores.io) 是一个提供先进实体解析（Entity Resolution）解决方案的平台，旨在支持数据集成与管理。Tilores 利用尖端的算法、机器学习技术和用户友好的界面，帮助组织匹配、解析和整合来自不同来源的数据，从而确保数据的高质量和一致性。

## 安装和设置

```python
pip install -U tilores-langchain
```

要访问 Tilores，您需要[创建一个并配置实例](https://app.tilores.io)。如果您希望先试用 Tilores，可以使用[只读演示凭证](https://github.com/tilotech/identity-rag-customer-insights-chatbot?tab=readme-ov-file#1-configure-customer-data-access)。

```python
import os

from tilores import TiloresAPI

os.environ["TILORES_API_URL"] = "<api-url>"
os.environ["TILORES_TOKEN_URL"] = "<token-url>"
os.environ["TILORES_CLIENT_ID"] = "<client-id>"
os.environ["TILORES_CLIENT_SECRET"] = "<client-secret>"

tilores = TiloresAPI.from_environ()
```

请参阅[Tilores 文档](https://docs.tilotech.io/tilores/publicsaaswalkthrough/)，了解如何创建您自己的实例。

## 工具包 (Toolkits)

您可以使用 [`TiloresTools`](/oss/python/integrations/tools/tilores) 从 Tilores 查询数据：

```python
from tilores_langchain import TiloresTools
```
