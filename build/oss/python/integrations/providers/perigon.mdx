>[Perigon](https://perigon.io/) 是一个全面的新闻 API，它提供了对来自全球数千个来源的新闻文章、故事、元数据和维基百科页面的实时上下文信息的访问。
>

## 安装与设置

`Perigon` 集成存在于其专用的[合作伙伴包](https://pypi.org/project/langchain-perigon/)中。您可以使用以下命令进行安装：

```python
pip install -qU langchain-perigon
```

为了使用该包，您还需要将 `PERIGON_API_KEY` 环境变量设置为您的 Perigon API 密钥。

## 检索器 (Retrievers)

Perigon 提供了两个检索器：

### ArticlesRetriever (文章检索器)

此检索器根据给定的查询和可选的过滤器检索文章。

请参阅[完整的使用示例](/oss/python/integrations/retrievers/perigon#using-articlesretriever)。

```python
# 确保 PERIGON_API_KEY 环境变量已设置为您的 Perigon API 密钥
from langchain_perigon import ArticlesRetriever, ArticlesFilter

# 创建带有特定结果数量的检索器
retriever = ArticlesRetriever(k=12)

# 配置过滤器选项以排除转载内容并专注于美国文章
options: ArticlesFilter = {
    "showReprints": False,  # 排除重复/转载的文章
    "filter": {"country": "us"},  # 仅限美国新闻
}

try:
    documents = retriever.invoke("Recent big tech layoffs", options=options)

    # 在访问之前检查是否获得了结果
    if documents:
        print(f"第一份文档: {documents[0].page_content[:200]}...")
    else:
        print("未找到与给定查询匹配的文章。")
except Exception as e:
    print(f"检索文章时出错: {e}")
```

### WikipediaRetriever (维基百科检索器)

此检索器根据给定的查询和可选的过滤器检索维基百科页面。

请参阅[完整的使用示例](/oss/python/integrations/retrievers/perigon#using-wikipediaretriever)。

```python
# 确保 PERIGON_API_KEY 环境变量已设置为您的 Perigon API 密钥
from langchain_perigon import WikipediaRetriever

# 创建带有特定结果数量的检索器
retriever = WikipediaRetriever(k=12)

try:
    documents = retriever.invoke("machine learning")

    # 安全地访问结果并包含错误处理
    if documents:
        print(f"第一份文档: {documents[0].page_content[:200]}...")
    else:
        print("未找到匹配的维基百科文章。")
except Exception as e:
    print(f"检索维基百科文章时出错: {e}")
```
