> [Diffbot](https://docs.diffbot.com/docs) 是一套基于机器学习（ML）的产品套件，可以轻松地将网页数据结构化并集成。

## 安装与设置

请[获取免费的 Diffbot API 令牌](https://app.diffbot.com/get-started/)，并[遵循这些说明](https://docs.diffbot.com/reference/authentication)来验证您的请求（进行身份验证）。

## 文档加载器 (Document Loader)

Diffbot 的 [Extract API](https://docs.diffbot.com/reference/extract-introduction) 是一项服务，用于对网页数据进行结构化和标准化处理。

与传统的网页抓取工具不同，`Diffbot Extract` **不需要任何规则**即可读取页面上的内容。它使用计算机视觉模型将页面分类为 20 种可能的类型之一，然后将原始的 HTML 标记转换为 JSON 格式。生成的结构化 JSON 遵循一致的[基于类型的本体论](https://docs.diffbot.com/docs/ontology)，这使得使用**相同的模式**从多个不同的网页源中提取数据变得非常容易。

请参阅[使用示例](/oss/python/integrations/document_loaders/diffbot)。

```python
from langchain_community.document_loaders import DiffbotLoader
```

## 图谱 (Graphs)

Diffbot 的[自然语言处理 API](https://www.diffbot.com/products/natural-language/) 允许从非结构化文本数据中提取实体（entities）、关系（relationships）以及语义信息。

请参阅[使用示例](/oss/python/integrations/graphs/diffbot)。

```python
from langchain_experimental.graph_transformers.diffbot import DiffbotGraphTransformer
```
