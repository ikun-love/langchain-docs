> [DuckDuckGo Search](https://github.com/deedy5/duckduckgo_search) 是一个包，它使用 `DuckDuckGo.com` 搜索引擎来搜索单词、文档、图片、视频、新闻、地图和文本翻译。它会将文件和图片下载到本地硬盘。

## 安装和设置

你需要安装一个 Python 包：

<CodeGroup>
```bash pip
pip install duckduckgo-search
```

```bash uv
uv add duckduckgo-search
```
</CodeGroup>

## 工具 (Tools)

请参阅 [使用示例](/oss/python/integrations/tools/ddg)。

有两个可用的工具：

```python
from langchain_community.tools import DuckDuckGoSearchRun
from langchain_community.tools import DuckDuckGoSearchResults
```
