> [PubMed®](https://pubmed.ncbi.nlm.nih.gov/) 是由 `The National Center for Biotechnology Information, National Library of Medicine`（美国国家生物技术信息中心、美国国家医学图书馆）提供的服务，它包含了超过 3500 万条生物医学文献的引文，这些文献来源于 `MEDLINE`、生命科学期刊和在线书籍。引文可能包含指向 `PubMed Central` 和出版商网站上全文内容的链接。

## 设置 (Setup)
你需要安装一个 Python 包。

<CodeGroup>
```bash pip
pip install xmltodict
```

```bash uv
uv add xmltodict
```
</CodeGroup>

### 检索器 (Retriever)

```python
from langchain_classic.retrievers import PubMedRetriever
```

### 文档加载器 (Document Loader)

请参阅[使用示例](/oss/python/integrations/document_loaders/pubmed)。

```python
from langchain_community.document_loaders import PubMedLoader
```
