> [Connery SDK](https://github.com/connery-io/connery-sdk) 是一个 NPM 包，它同时包含了 SDK 和 CLI，专门用于开发插件（plugins）和动作（actions）。
>
> CLI 能够自动化开发过程中的许多繁琐事务。而 SDK 则提供了一个 JavaScript API，用于定义插件和动作，并将它们打包成一个插件服务器。该服务器会根据元数据自动生成标准化的 REST API。插件服务器负责处理身份验证（authorization）、输入验证（input validation）和日志记录（logging）。这样，您就可以专注于您动作的核心逻辑开发。
>
> 请参阅 [Connery SDK 文档](https://sdk.connery.io/docs/use-cases/) 中的用例和示例。
