> [Hologres](https://www.alibabacloud.com/help/en/hologres/latest/introduction) 是阿里云自主研发的统一实时数据仓库服务。您可以使用 Hologres 实时写入、更新、处理和分析海量数据。
> `Hologres` 支持标准的 `SQL` 语法，兼容 `PostgreSQL`，并支持大部分 PostgreSQL 函数。Hologres 能够对高达 PB 级别的数据进行在线分析处理（OLAP）和即席查询（Ad hoc analysis），并提供高并发、低延迟的在线数据服务。

> `Hologres` 通过采用 [Proxima](https://www.alibabacloud.com/help/en/hologres/latest/vector-processing) 来提供**向量数据库**功能。
> `Proxima` 是由 `Alibaba DAMO Academy`（达摩院）开发的ன்ன高性能软件库。它使您能够搜索向量的最近邻（Nearest Neighbors）。Proxima 提供了比 Faiss 等类似的开源软件更高的稳定性和性能。Proxima 能够在高吞吐量和低延迟下支持文本或图像嵌入（embeddings）的相似性搜索。Hologres 与 Proxima 深度集成，以提供高性能的向量搜索服务。

## 安装和设置

点击 [此处](https://www.alibabacloud.com/zh/product/hologres) 可以快速部署一个 Hologres 云实例。

<CodeGroup>
```bash pip
pip install hologres-vector
```

```bash uv
uv add hologres-vector
```
</CodeGroup>
