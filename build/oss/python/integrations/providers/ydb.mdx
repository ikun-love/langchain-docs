所有与 YDB 相关的操作功能。

> [YDB](https://ydb.tech/) 是一个多功能开源的分布式 SQL 数据库，它将高可用性和可伸缩性与强一致性和 ACID 事务相结合。它可以同时处理事务性 (OLTP)、分析性 (OLAP) 和流式工作负载。

## 安装和设置

<CodeGroup>
```bash pip
pip install langchain-ydb
```

```bash uv
uv add langchain-ydb
```
</CodeGroup>

## 向量存储 (Vector Store)

要导入 YDB 向量存储：

```python
from langchain_ydb.vectorstores import YDB
```

有关 YDB 向量存储的更详细演练，请参阅[此 Notebook](/oss/python/integrations/vectorstores/ydb)。
