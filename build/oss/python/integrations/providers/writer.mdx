所有与 WRITER 相关的[^1]功能

> 本页面将介绍如何在 LangChain 中使用 [WRITER](https://writer.com/) 生态系统。更多信息请参阅 Writer 的 [文档](https://dev.writer.com/home/introduction)。
>[Palmyra](https://writer.com/blog/palmyra/) 是 `WRITER` 开发的大型语言模型 (LLM)。
>
> [Writer API](https://dev.writer.com/api-guides/introduction) 由一套多样化的 Palmyra 子模型提供支持，这些子模型具有不同的能力和定价点。

## 安装和设置

使用以下命令安装集成包：
<CodeGroup>
```bash pip
pip install langchain-writer
```

```bash uv
uv add langchain-writer
```
</CodeGroup>

获取一个 WRITER API 密钥，并将其设置为环境变量（`WRITER_API_KEY`）。

## 聊天模型 (Chat model)

```python
from langchain_writer import ChatWriter
```
参见 [详情](/oss/python/integrations/chat/writer)。

## PDF 解析器 (PDF Parser)

```python
from langchain_writer.pdf_parser import PDFParser
```
<Warning>
**弃用通知**：`parse PDF` 工具已被弃用，并计划于 **2025 年 12 月 22 日** 移除。

**迁移路径**：我们计划引入一个用于聊天补全的预构建 PDF 解析工具，它将提供类似的功能。此工具的工作方式将类似于其他预构建工具。一旦该替代方案可用，我们将提供更多详细信息。
</Warning>

参见 [详情](/oss/python/integrations/document_loaders/parsers/writer_pdf_parser)。
