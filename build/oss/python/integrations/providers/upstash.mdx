Upstash 为开发者提供**无服务器（serverless）**数据库和消息传递平台，使他们无需担心大规模运行数据库的运维复杂性，即可构建强大的应用程序。

Upstash 的一个显著优势是其数据库支持 HTTP 协议，并且所有的 SDK 都使用 HTTP。这意味着你可以在不支持 TCP 连接的无服务器平台、边缘计算环境或任何其他平台上运行它。

目前，LangChain 中有两种可用的 Upstash 集成：
1.  **Upstash Vector**：用作向量嵌入数据库。
2.  **Upstash Redis**：用作缓存和内存存储。

# Upstash Vector

Upstash Vector 是一个无服务器向量数据库，可用于存储和查询向量。

## 安装

在 [Upstash Console](https://console.upstash.com/vector) 创建一个新的无服务器向量数据库实例。
根据你使用的模型选择首选的距离度量（distance metric）和维度数量（dimension count）。

使用 `pip install upstash-vector` 安装 Upstash Vector Python SDK。
LangChain 中的 Upstash Vector 集成是 Upstash Vector Python SDK 的一个封装（wrapper）。因此，必须安装 `upstash-vector` 包。

## 集成

使用从 Upstash Console 获取的凭证创建一个 `UpstashVectorStore` 对象。
你还需要传入一个 [`Embeddings`](https://reference.langchain.com/python/langchain_core/embeddings/#langchain_core.embeddings.embeddings.Embeddings) 对象，该对象可以将文本转换为向量嵌入。

```python
from langchain_community.vectorstores.upstash import UpstashVectorStore
import os

os.environ["UPSTASH_VECTOR_REST_URL"] = "<UPSTASH_VECTOR_REST_URL>"
os.environ["UPSTASH_VECTOR_REST_TOKEN"] = "<UPSTASH_VECTOR_REST_TOKEN>"

store = UpstashVectorStore(
    embedding=embeddings
)
```

`UpstashVectorStore` 的另一种用法是传入 `embedding=True`。这是 `UpstashVectorStore` 的一个独特特性，得益于 Upstash Vector 索引可以关联嵌入模型的能力。在这种配置下，我们想要插入的文档或我们想要搜索的查询只需以纯文本形式发送给 Upstash Vector。在后台，Upstash Vector 会嵌入这些文本并使用这些嵌入执行请求。要使用此功能，请通过[选择模型创建一个 Upstash Vector 索引](https://upstash.com/docs/vector/features/embeddingmodels#using-a-model)，然后简单地传入 `embedding=True`：

```python
from langchain_community.vectorstores.upstash import UpstashVectorStore
import os

os.environ["UPSTASH_VECTOR_REST_URL"] = "<UPSTASH_VECTOR_REST_URL>"
os.environ["UPSTASH_VECTOR_REST_TOKEN"] = "<UPSTASH_VECTOR_REST_TOKEN>"

store = UpstashVectorStore(
    embedding=True
)
```

有关嵌入模型的更多详细信息，请参阅[Upstash Vector 文档](https://upstash.com/docs/vector/features/embeddingmodels)。

## 命名空间（Namespaces）
你可以使用命名空间来划分索引中的数据。当你查询海量数据并希望分区数据以加快查询速度时，命名空间非常有用。使用命名空间时，将不会进行结果的后过滤（post-filtering），从而使查询结果更加精确。

```python
from langchain_community.vectorstores.upstash import UpstashVectorStore
import os

os.environ["UPSTASH_VECTOR_REST_URL"] = "<UPSTASH_VECTOR_REST_URL>"
os.environ["UPSTASH_VECTOR_REST_TOKEN"] = "<UPSTASH_VECTOR_REST_TOKEN>"

store = UpstashVectorStore(
    embedding=embeddings
    namespace="my_namespace"
)
```

### 插入向量

```python
from langchain.text_splitter import CharacterTextSplitter
from langchain_community.document_loaders import TextLoader
from langchain_openai import OpenAIEmbeddings

loader = TextLoader("../../modules/state_of_the_union.txt")
documents = loader.load()
text_splitter = CharacterTextSplitter(chunk_size=1000, chunk_overlap=0)
docs = text_splitter.split_documents(documents)

# 创建一个新的嵌入对象
embeddings = OpenAIEmbeddings()

# 创建一个新的 UpstashVectorStore 对象
store = UpstashVectorStore(
    embedding=embeddings
)

# 将文档嵌入存储到存储器中
store.add_documents(docs)
```

插入文档时，首先使用 [`Embeddings`](https://reference.langchain.com/python/langchain_core/embeddings/#langchain_core.embeddings.embeddings.Embeddings) 对象对它们进行嵌入处理。

大多数嵌入模型可以一次处理多个文档，因此文档会被分批并行嵌入。
批次大小可以使用 `embedding_chunk_size` 参数进行控制。

嵌入的向量随后存储在 Upstash Vector 数据库中。当发送向量时，多个向量会被批量处理，以减少 HTTP 请求的数量。
批次大小可以使用 `batch_size` 参数进行控制。在免费套餐中，Upstash Vector 对每个批次有 1000 个向量的限制。

```python
store.add_documents(
    documents,
    batch_size=100,
    embedding_chunk_size=200
)
```

### 查询向量

向量可以通过文本查询或另一个向量进行查询。

返回值是 `Document` 对象的列表。

```python
result = store.similarity_search(
    "The United States of America",
    k=5
)
```

或者使用向量：

```python
vector = embeddings.embed_query("Hello world")

result = store.similarity_search_by_vector(
    vector,
    k=5
)
```

在搜索时，你还可以利用 `filter` 参数，该参数允许你按元数据进行过滤：

```python
result = store.similarity_search(
    "The United States of America",
    k=5,
    filter="type = 'country'"
)
```

有关元数据过滤的更多详细信息，请参阅[Upstash Vector 文档](https://upstash.com/docs/vector/features/filtering)。

### 删除向量

可以通过 ID 删除向量。

```python
store.delete(["id1", "id2"])
```

### 获取有关存储的信息

你可以使用 `info` 函数获取有关数据库的信息，例如距离度量和维度。

当发生插入操作时，数据库会进行索引（indexing）。在此过程中，新的向量不能被查询。`pendingVectorCount` 代表当前正在索引中的向量数量。

```python
info = store.info()
print(info)

# 输出：
# {'vectorCount': 44, 'pendingVectorCount': 0, 'indexSize': 2642412, 'dimension': 1536, 'similarityFunction': 'COSINE'}
```

# Upstash Redis

此页面介绍了如何将 [Upstash Redis](https://upstash.com/redis) 与 LangChain 结合使用。

## 安装和设置
- 可以使用 `pip install upstash-redis` 安装 Upstash Redis Python SDK。
- 可在 [Upstash Console](https://console.upstash.com) 创建一个全局分布式、低延迟且高可用的数据库。


## 集成
所有 Upstash-LangChain 集成都是基于 `upstash-redis` Python SDK 的封装形式来利用 LangChain 的功能。
该 SDK 通过系统提供从控制台获取的 `UPSTASH_REDIS_REST_URL` 和 `UPSTASH_REDIS_REST_TOKEN` 参数来使用 Upstash Redis DB。


### 缓存（Cache）

[Upstash Redis](https://upstash.com/redis) 可用作 LLM 提示（prompts）和响应的缓存。

导入缓存的方式如下：
```python
from langchain.cache import UpstashRedisCache
```

与 LLM 结合使用方式如下：
```python
import langchain
from upstash_redis import Redis

URL = "<UPSTASH_REDIS_REST_URL>"
TOKEN = "<UPSTASH_REDIS_REST_TOKEN>"

langchain.llm_cache = UpstashRedisCache(redis_=Redis(url=URL, token=TOKEN))
```
