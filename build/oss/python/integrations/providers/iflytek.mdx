> [iFlytek](https://www.iflytek.com) 是一家成立于 1999 年的中国信息技术公司。该公司专注于语音识别软件和基于语音的互联网/移动产品，业务覆盖教育、通信、音乐和智能玩具等行业。

## 安装与设置

1.  从 [iFlytek SparkLLM API 控制台](https://console.xfyun.cn/services/bm3) 获取 `SparkLLM` 的 `app_id`、`api_key` 和 `api_secret`（更多信息请参阅 [iFlytek SparkLLM 介绍](https://xinghuo.xfyun.cn/sparkapi)）。
2.  安装 Python 包（嵌入式模型除外）：

<CodeGroup>
```bash pip
pip install websocket-client
```

```bash uv
uv add websocket-client
```
</CodeGroup>

## 大语言模型 (LLMs)

请参阅 [使用示例](/oss/python/integrations/llms/sparkllm)。

```python
from langchain_community.llms import SparkLLM
```

## 对话模型 (Chat models)

请参阅 [使用示例](/oss/python/integrations/chat/sparkllm)。

```python
from langchain_community.chat_models import ChatSparkLLM
```

## 嵌入模型 (Embedding models)

```python
from langchain_community.embeddings import SparkLLMTextEmbeddings
```
