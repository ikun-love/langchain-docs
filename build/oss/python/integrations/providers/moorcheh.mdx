# Moorcheh (摩尔切)

>[Moorcheh](https://www.moorcheh.ai/) 是一个闪电般快速的语义搜索引擎和向量存储库。Moorcheh 没有使用 L2 或余弦相似度等简单距离度量，而是采用最大信息二值化（MIB）和信息论得分（ITS）来检索高度准确的文档块。

本页面介绍如何在 LangChain 中使用 Moorcheh 进行向量存储、语义搜索和生成式 AI 响应。

## 安装与设置 (Installation and Setup)

安装 Python 集成包：

```bash
pip install langchain-moorcheh
```

从 [Moorcheh Console](https://console.moorcheh.ai/) 获取 Moorcheh API 密钥，并将其设置为环境变量：

```bash
export MOORCHEH_API_KEY="your-api-key-here"
```

## 向量存储 (Vector Store)

Moorcheh 提供了一个向量存储封装（wrapper），允许您高效地存储、搜索和检索文档嵌入（embeddings）。

有关详细使用示例，请参阅 [详细用法示例](/oss/python/integrations/vectorstores/moorcheh)。

```python
from langchain_moorcheh import MoorchehVectorStore

# 初始化向量存储
store = MoorchehVectorStore(
    api_key="your-api-key",
    namespace="your_namespace",
    namespace_type="text"  # 或 "vector"
)

# 添加文档
from langchain_core.documents import Document
documents = [
    Document(page_content="Your document content here", metadata={"source": "example"})
]
store.add_documents(documents=documents)
```

## 生成式 AI (Generative AI)

Moorcheh 支持使用各种 LLM 模型（包括 Claude 3）进行生成式 AI 响应，这使您能够基于已存储的文档获取 AI 生成的答案。

```python
# 获取基于您的文档的 AI 生成答案
query = "What are the main topics covered in the documents?"
answer = store.generative_answer(
    query,
    ai_model="anthropic.claude-sonnet-4-5-20250929-v1:0"
)
print(answer)
```

## 核心特性 (Core Features)

- **文档管理 (Document Management)**：使用唯一 ID 添加和删除文档
- **语义搜索 (Semantic Search)**：使用自然语言查询查找相关文档
- **生成式 AI (Generative AI)**：使用各种 LLM 模型获取 AI 生成的答案
- **命名空间组织 (Namespace Organization)**：将数据组织到不同的命名空间中
- **元数据支持 (Metadata Support)**：存储和检索带有自定义元数据的文档

有关更详细的示例和高级用法，请参阅 [Moorcheh 向量存储集成](/oss/python/integrations/vectorstores/moorcheh)。
