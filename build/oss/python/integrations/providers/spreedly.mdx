> [Spreedly](https://docs.spreedly.com/) 是一项服务，它允许您安全地存储信用卡信息，并使用这些信息向任意数量的支付网关和第三方 API 进行交易。它通过同时提供卡信息标记化/保险库服务（card tokenization/vault service）以及网关和接收方集成服务来实现这一点。Spreedly 标记化的支付方式存储在 `Spreedly` 中，这使得您可以独立地存储一张卡，然后根据您的业务需求将该卡传递给不同的终端点。
