>[Meta Platforms, Inc.](https://www.facebook.com/)（商业名称为 `Meta`），前身为 `Facebook, Inc.` 和 `TheFacebook, Inc.`，是一家美国跨国科技集团。该公司拥有并运营 `Facebook`、`Instagram`、`Threads` 和 `WhatsApp` 等多种产品与服务。

## 嵌入模型 (Embedding Models)

### LASER

>[LASER](https://github.com/facebookresearch/LASER) 是由 `Meta AI Research` 团队开发的一个 Python 库，用于为[截至 2024 年 2 月 25 日的 147 多种语言](https://github.com/facebookresearch/flores/blob/main/flores200/README.md#languages-in-flores-200)创建多语言句子嵌入（Sentence Embeddings）。

<CodeGroup>
```bash pip
pip install laser_encoders
```

```bash uv
uv add laser_encoders
```
</CodeGroup>

参见[使用示例](/oss/python/integrations/text_embedding/laser)。

```python
from langchain_community.embeddings.laser import LaserEmbeddings
```

## 文档加载器 (Document Loaders)

### Facebook Messenger

>[Messenger](https://en.wikipedia.org/wiki/Messenger_(software)) 是一款由 `Meta Platforms` 开发的即时通讯应用和平台。它最初于 2008 年作为 `Facebook Chat` 开发，随后该公司于 2010 年对其消息服务进行了重大改造。

参见[使用示例](/oss/python/integrations/document_loaders/facebook_chat)。

```python
from langchain_community.document_loaders import FacebookChatLoader
```

## 向量存储 (Vector Stores)

### Facebook Faiss

>[Facebook AI Similarity Search (Faiss)](https://engineering.fb.com/2017/03/29/data-infrastructure/faiss-a-library-for-efficient-similarity-search/) 是一个用于高效相似性搜索和稠密向量聚类的库。它包含了可以在任何大小的向量集（甚至是不可能完全载入内存的集合）中进行搜索的算法。此外，它还提供了用于评估和参数调整的支持代码。

[Faiss 文档](https://faiss.ai/)。

我们需要安装 `faiss` Python 包。

<CodeGroup>
```bash pip
pip install faiss-gpu # 适用于支持 CUDA 7.5+ 的 GPU。
```

```bash uv
uv add faiss-gpu # 适用于支持 CUDA 7.5+ 的 GPU。
```
</CodeGroup>

或者

<CodeGroup>
```bash pip
pip install faiss-cpu # 用于 CPU 安装
```

```bash uv
uv add faiss-cpu # 用于 CPU 安装
```
</CodeGroup>

参见[使用示例](/oss/python/integrations/vectorstores/faiss)。

```python
from langchain_community.vectorstores import FAISS
```
