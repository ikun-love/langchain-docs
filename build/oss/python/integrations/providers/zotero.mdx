title: Zotero
---

[Zotero](https://www.zotero.org/) 是一个开源的参考文献管理系统，旨在帮助用户管理书目数据及相关的研究材料。你可以通过 [API](https://www.zotero.org/support/dev/web_api/v3/start) 访问你的个人图书馆以及共享的群组图书馆。这个检索器（Retriever）的实现利用了 [PyZotero](https://github.com/urschrei/pyzotero) 来访问这些图书馆。

## 安装

```bash
pip install pyzotero
```

## 检索器 (Retriever)

请参阅 [使用示例](/oss/python/integrations/retrievers/zotero)。

```python
from langchain_zotero_retriever.retrievers import ZoteroRetriever
```
