### 基本用法 (Basic Usage)

```python
from langchain_zeusdb import ZeusDBVectorStore
from langchain_openai import OpenAIEmbeddings
from zeusdb import VectorDatabase

# 初始化嵌入模型
embeddings = OpenAIEmbeddings(model="text-embedding-3-small")

# 创建 ZeusDB 索引
vdb = VectorDatabase()
index = vdb.create(
    index_type="hnsw",
    dim=1536,
    space="cosine"
)

# 创建向量存储
vector_store = ZeusDBVectorStore(
    zeusdb_index=index,
    embedding=embeddings
)

# 添加文档
from langchain_core.documents import Document

docs = [
    Document(page_content="ZeusDB is fast", metadata={"source": "docs"}),
    Document(page_content="LangChain is powerful", metadata={"source": "docs"}),
]

vector_store.add_documents(docs)

# 搜索
results = vector_store.similarity_search("fast database", k=2)
print(f"找到了 {len(results)} 个结果:")
print(results)
```

**预期结果:**

```text

```

```python
results = vector_store_texts.similarity_search("Hello", k=1)

```

## 高级功能 (Advanced Features)

ZeusDB 的企业级功能已完全集成到 LangChain 生态系统中，提供了量化、持久化、高级搜索功能以及许多其他企业能力。

### 使用量化实现内存高效设置 (Memory-Efficient Setup with Quantization)

对于大型数据集，使用乘积量化（Product Quantization, PQ）来减少内存占用：

```python
# 创建量化索引以提高内存效率
quantization_config = {
    'type': 'pq',
    'subvectors': 8,
    'bits': 8,
    'training_size': 10000
}

vdb = VectorDatabase()
index = vdb.create(
    index_type="hnsw",
    dim=1536,
    space="cosine",
    quantization_config=quantization_config
)

vector_store = ZeusDBVectorStore(
    zeusdb_index=index,
    embedding=embeddings
)
```

请参阅我们的[文档](https://docs.zeusdb.com/en/latest/vector_database/product_quantization.html)，了解有关设置量化的有用配置指南和建议。

<br />

### 持久性 (Persistence)

ZeusDB 持久性允许您将完全填充的索引保存到磁盘，并在以后加载它，实现完整状态恢复。这包括向量、元数据、HNSW 图结构以及（如果启用）乘积量化模型。

保存的内容包括：

- 向量和 ID
- 元数据
- HNSW 图结构
- 量化配置、质心（centroids）和训练状态（如果启用了 PQ）

#### 如何保存向量存储

```python
# 保存索引
vector_store.save_index("my_index.zdb")
```

#### 如何加载向量存储

```python
# 加载索引
loaded_store = ZeusDBVectorStore.load_index(
    path="my_index.zdb",
    embedding=embeddings
)

# 加载后验证
print("向量数量:", loaded_store.get_vector_count())
print("索引信息:", loaded_store.info())
print("存储预览:", loaded_store.zeusdb_index.list(2))
```

#### 注意事项

- `path` 是一个目录，而不是单个文件。请确保目标目录具有写入权限。
- 保存的索引是跨平台的，并包含格式/版本信息以进行兼容性检查。
- 如果您使用了 PQ，压缩模型和状态都会被保留——加载后无需重新训练。
- 您可以在加载后的 `loaded_store` 上继续使用所有向量存储 API（如 `similarity_search`、`retrievers` 等）。

有关更多详细信息（包括文件结构和更全面的示例），请参阅[文档](https://docs.zeusdb.com/en/latest/vector_database/persistence.html)。

<br />

### 高级搜索选项 (Advanced Search Options)

使用这些选项来控制搜索过程中的评分、多样性、元数据过滤以及检索器集成。

#### 带分数的相似性搜索 (Similarity search with scores)

从 ZeusDB 返回 `(Document, raw_distance)` 对——**距离越小，相似度越高**。
如果您更喜欢归一化的相关性分数在 `[0, 1]` 范围内，请使用 `similarity_search_with_relevance_scores`。

```python
# 带分数的相似性搜索
results_with_scores = vector_store.similarity_search_with_score(
    query="machine learning",
    k=5
)

print(results_with_scores)
```

**预期结果:**

```text
[
  (Document(id='ac0eaf5b-9f02-4ce2-8957-c369a7262c61', metadata={'source': 'docs'}, page_content='LangChain is powerful'), 0.8218843340873718),
  (Document(id='faae3adf-7cf3-463c-b282-3790b096fa23', metadata={'source': 'docs'}, page_content='ZeusDB is fast'), 0.9140053391456604)
]
```

#### MMR 搜索（用于多样性） (MMR search for diversity)

MMR（最大边际相关性，Maximal Marginal Relevance）平衡了两个因素：与查询的相关性以及所选结果之间的多样性，从而减少重复的答案。使用 `lambda_mult` 控制这种权衡（`1.0` 表示全部相关性，`0.0` 表示全部多样性）。

```python
# MMR 搜索（用于多样性）
mmr_results = vector_store.max_marginal_relevance_search(
    query="AI applications",
    k=5,
    fetch_k=20,
    lambda_mult=0.7  # 平衡相关性与多样性
)

print(mmr_results)
```

#### 带元数据过滤的搜索 (Search with metadata filtering)

在添加文档时，使用文档的元数据来过滤结果。

```python
# 带元数据过滤的搜索
results = vector_store.similarity_search(
    query="database performance",
    k=3,
    filter={"source": "documentation"}
)
```

有关支持的元数据查询类型和操作符，请参阅[文档](https://docs.zeusdb.com/en/latest/vector_database/metadata_filtering.html)。

#### 作为检索器 (As a Retriever)

将向量存储转换为检索器，可以获得标准的 LangChain 接口，从而使链（例如 RetrievalQA）能够调用它来获取上下文。底层它使用您选择的搜索类型（相似性或 mmr）和 `search_kwargs`。

```python
# 转换为检索器，以便在链中使用
retriever = vector_store.as_retriever(
    search_type="mmr",
    search_kwargs={"k": 3, "lambda_mult": 0.8}
)

# 使用 LangChain 表达式语言 (LCEL) - 只需 `langchain-core`
from langchain_core.prompts import ChatPromptTemplate
from langchain_core.output_parsers import StrOutputParser
from langchain_core.runnables import RunnablePassthrough
from langchain_openai import ChatOpenAI

def format_docs(docs):
    return "\n\n".join([d.page_content for d in docs])

template = """根据以下上下文回答问题:
{context}

问题: {question}
"""

prompt = ChatPromptTemplate.from_template(template)
llm = ChatOpenAI()

# 使用 LCEL 创建链
chain = (
    {"context": retriever | format_docs, "question": RunnablePassthrough()}
    | prompt
    | llm
    | StrOutputParser()
)

# 使用链
answer = chain.invoke("What is ZeusDB?")
print(answer)
```

**预期结果:**

```text
ZeusDB is a fast database management system.
```

## 异步支持 (Async Support)

ZeusDB 支持异步操作，用于非阻塞、并发的向量操作。

**何时使用异步:** Web 服务器（FastAPI/Starlette）、同时执行并行搜索的代理/管道，或在笔记本电脑中需要非阻塞/并发检索的场景。如果您只是编写简单的脚本，使用同步方法即可。

这些是**异步操作**——常规同步方法的 async/await 版本。以下是每个操作的作用：

1. `await vector_store.aadd_documents(documents)` - 异步将文档添加到向量存储中（`add_documents()` 的异步版本）
2. `await vector_store.asimilarity_search("query", k=5)` - 异步执行相似性搜索（`similarity_search()` 的异步版本）
3. `await vector_store.adelete(ids=["doc1", "doc2"])` - 根据 ID 异步删除文档（`delete()` 的异步版本）

当出现以下情况时，异步版本非常有用：

- 您正在构建异步应用程序（使用 `asyncio`、FastAPI 等）
- 您希望非阻塞操作能够并发运行
- 您正在同时处理多个请求
- 您在 I/O 密集型应用中希望获得更好的性能

例如，与在添加文档时阻塞不同：

```python
# 同步（阻塞）
vector_store.add_documents(docs)  # 阻塞直到完成

# 异步（非阻塞）
await vector_store.aadd_documents(docs)  # 在此运行时可以执行其他工作
```

所有操作都支持 async/await：

**脚本版本 (`python my_script.py`):**

```python
import asyncio
from langchain_zeusdb import ZeusDBVectorStore
from langchain_openai import OpenAIEmbeddings
from langchain_core.documents import Document
from zeusdb import VectorDatabase

# 设置
embeddings = OpenAIEmbeddings(model="text-embedding-3-small")
vdb = VectorDatabase()
index = vdb.create(index_type="hnsw", dim=1536, space="cosine")
vector_store = ZeusDBVectorStore(zeusdb_index=index, embedding=embeddings)

docs = [
    Document(page_content="ZeusDB is fast", metadata={"source": "docs"}),
    Document(page_content="LangChain is powerful", metadata={"source": "docs"}),
]

async def main():
    # 异步添加文档
    ids = await vector_store.aadd_documents(docs)
    print("添加的 ID:", ids)

    # 并发运行多个搜索
    results_fast, results_powerful = await asyncio.gather(
        vector_store.asimilarity_search("fast", k=2),
        vector_store.asimilarity_search("powerful", k=2),
    )
    print("快速结果:", [d.page_content for d in results_fast])
    print("强大结果:", [d.page_content for d in results_powerful])

    # 异步删除文档
    deleted = await vector_store.adelete(ids=ids[:1])
    print("删除了第一个文档:", deleted)

if __name__ == "__main__":
    asyncio.run(main())
```

### 企业级日志记录 (Enterprise Logging)


## 配置选项 (Configuration Options)

### 索引参数 (Index Parameters)

```python
vdb = VectorDatabase()
index = vdb.create(
    index_type="hnsw",           # 索引算法
    dim=1536,                    # 向量维度
    space="cosine",              # 距离度量：cosine（余弦）、l2（L2）、l1（L1）
    m=16,                        # HNSW 连接度
    ef_construction=200,         # 构建时的搜索广度
    expected_size=100000,        # 预期的向量数量
    quantization_config=None     # 量化配置（可选）
)
```

### 搜索参数 (Search Parameters)

```python
results = vector_store.similarity_search(
    query="search query",
    k=5,                         # 结果数量
    ef_search=None,              # 运行时搜索广度（None 表示自动）
    filter={"key": "value"}      # 元数据过滤器
)
```
