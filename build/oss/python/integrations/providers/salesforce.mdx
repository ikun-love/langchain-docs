[Salesforce](https://www.salesforce.com/) 是一家基于云的软件公司，提供客户关系管理（CRM）解决方案，以及专注于销售、客户服务、营销自动化和分析的企业级应用程序套件。

[langchain-salesforce](https://pypi.org/project/langchain-salesforce/) 实现了相关工具，使大型语言模型（LLMs）能够与 Salesforce 数据进行交互。


## 安装与设置 (Installation and Setup)

<CodeGroup>
```bash pip
pip install langchain-salesforce
```

```bash uv
uv add langchain-salesforce
```
</CodeGroup>
