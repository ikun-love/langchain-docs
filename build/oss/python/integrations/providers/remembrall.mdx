> [Remembrall](https://remembrall.dev/) 是一个平台，它为语言模型提供了**长期记忆**、**检索增强生成 (RAG)** 功能以及**完整的可观测性**。

## 安装与设置

要开始使用，请在 Remembrall 平台上使用 GitHub [登录](https://remembrall.dev/login)，并从“设置”页面复制您的 [API 密钥](https://remembrall.dev/dashboard/settings)。
