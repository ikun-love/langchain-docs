[Bodo DataFrames](https://github.com/bodo-ai/Bodo) 是一个高性能的 DataFrame 库，专为大规模 Python 数据处理而设计，是 Pandas 的**即插即用替代品**。只需简单地将：

```python
import pandas as pd
```

替换为：

```python
import bodo.pandas as pd
```

即可自动扩展和加速 Pandas 工作负载。由于 Bodo DataFrames 与 Pandas 兼容，它是大型语言模型 (LLM) 代码生成的理想目标，因为生成的代码易于验证、高效，并且能够扩展到超过 Pandas 常见的局限性。

我们的集成包提供了一个工具包，可使用 Bodo DataFrames 来高效、可扩展地回答关于大型数据集的问题。

在底层，Bodo DataFrames 采用**惰性求值 (lazy evaluation)** 来优化一系列 Pandas 操作，通过操作符流式传输数据以处理**超过内存大小 (larger-than-memory)** 的数据集，并利用基于 MPI 的高性能计算技术进行高效的并行执行，可以轻松地从笔记本电脑扩展到大型集群。

## 安装与设置

```bash pip
pip install -U langchain_bodo
```

## 工具集 (Toolkit)

[langchain-bodo 包](https://pypi.org/project/langchain-bodo/) 提供了创建智能体 (agents) 的功能，这些智能体可以使用 Bodo DataFrames 来回答关于大型数据集的问题。有关更详细的使用示例，请参阅 [Bodo DataFrames 工具页面](/oss/python/integrations/tools/bodo)。

**注意：此功能在底层使用了 `Python` 智能体，它会执行 LLM生成的 Python 代码——如果 LLM 生成的 Python 代码存在恶意行为，这可能是有风险的。请谨慎使用。**

```python
from langchain_bodo import create_bodo_dataframes_agent
```

### 用法示例

在运行下面的代码之前，请复制 [泰坦尼克数据集](https://raw.githubusercontent.com/pandas-dev/pandas/main/doc/data/titanic.csv) 并将其本地保存为 `titanic.csv`。

```python
import bodo.pandas as pd
from langchain_openai import OpenAI

df = pd.read_csv("titanic.csv")
agent = create_bodo_dataframes_agent(
    OpenAI(temperature=0), df, verbose=True, allow_dangerous_code=True
)
```

```python
agent.invoke("how many rows are there?")
```
