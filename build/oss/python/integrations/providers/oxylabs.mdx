title: Oxylabs

[Oxylabs](https://oxylabs.io/) 是一个市场领先的 Web 情报收集平台，它遵循最高的商业、道德和合规标准，使全球企业能够解锁由数据驱动的洞察。

[langchain-oxylabs](https://pypi.org/project/langchain-oxylabs/) 实现了工具，使 LLM 能够与 Oxylabs Web Scraper API 进行交互。

## 安装和设置

<CodeGroup>
```bash pip
pip install langchain-oxylabs
```

```bash uv
uv add langchain-oxylabs
```
</CodeGroup>
