本文档介绍如何在 LangChain 中使用 StochasticAI 生态系统。
内容分为两部分：安装和设置（Installation and Setup），以及对特定 StochasticAI 封装器的引用（References to specific StochasticAI wrappers）。

## 安装和设置 (Installation and Setup)
- 使用 `pip install stochasticx` 进行安装。
- 获取一个 StochasticAI API 密钥，并将其设置为环境变量 (`STOCHASTICAI_API_KEY`)。

## 封装器 (Wrappers)

### LLM

存在一个 StochasticAI LLM 封装器，您可以通过以下方式访问它：
```python
from langchain_community.llms import StochasticAI
```
