本页面介绍了如何在 LangChain 中使用 Petals 生态系统。
内容分为两部分：**安装和设置**，以及对特定 Petals 包装器的引用。

## 安装和设置
- 使用 `pip install petals` 命令进行安装
- 获取一个 Hugging Face API 密钥，并将其设置为环境变量（`HUGGINGFACE_API_KEY`）

## 包装器 (Wrappers)

### LLM

存在一个 Petals LLM 包装器，您可以通过以下方式访问它：
```python
from langchain_community.llms import Petals
```
