---
title: 权限许可
---

[Permit.io](https://permit.io/) 提供细粒度的访问控制和策略执行。通过 LangChain，您可以集成 Permit 校验，以确保只有经过授权的用户才能在您的 LLM 应用中访问或检索数据。

## 安装与设置 (Installation and Setup)

<CodeGroup>
```bash pip
pip install langchain-permit
pip install permit
```

```bash uv
uv add langchain-permit
uv add permit
```
</CodeGroup>

为您的 Permit PDP（策略决策点）和凭证设置环境变量：

```python
export PERMIT_API_KEY="your_permit_api_key"
export PERMIT_PDP_URL="http://localhost:7766"   # 或者使用您真实的 PDP 端点
```

请确保您的 PDP 正在运行且已正确配置。关于策略设置，请参阅 [Permit 文档](https://docs.permit.io/sdk/python/quickstart-python/#2-setup-your-pdp-policy-decision-point-container)。
