> [Trello](https://www.atlassian.com/software/trello) 是一个基于 Web 的项目管理和协作工具，它允许个人和团队组织和跟踪他们的任务与项目。它提供了一个称为“看板”（board）的**可视化界面**，用户可以在其中创建列表（lists）和卡片（cards）来表示他们的任务和活动。
> `TrelloLoader` 允许我们从一个 `Trello` 看板中加载卡片信息。

## 安装与设置 (Installation and Setup)

<CodeGroup>
```bash pip
pip install py-trello beautifulsoup4
```

```bash uv
uv add py-trello beautifulsoup4
```
</CodeGroup>

请参阅[设置说明](/oss/python/integrations/document_loaders/trello)。
