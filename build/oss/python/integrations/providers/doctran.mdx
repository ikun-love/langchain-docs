>[Doctran](https://github.com/psychic-api/doctran) 是一个 Python 包。它使用大型语言模型（LLMs）和开源自然语言处理（NLP）库，将原始文本转换为干净、结构化、信息密集的文档，这些文档经过优化，非常适合向量空间检索。您可以将 `Doctran` 视为一个黑匣子：混乱的字符串进入，清晰、干净、带有标签的字符串出来。

## 安装和设置 (Installation and Setup)

<CodeGroup>
```bash pip
pip install doctran
```

```bash uv
uv add doctran
```
</CodeGroup>
