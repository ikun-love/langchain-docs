>[北京人工智能研究院 (BAAI) (维基百科)](https://en.wikipedia.org/wiki/Beijing_Academy_of_Artificial_Intelligence)，
> 亦称为 `Zhiyuan Institute`，是中国一家非营利性人工智能 (AI) 研究实验室。`BAAI` 从事 AI 研究，致力于促进学术界和工业界之间的协作，并培养顶尖人才，重点关注 AI 技术的长期基础研究。作为一个重要的协作中心，BAAI 的创始成员包括领先的 AI 公司、大学和研究机构。

## 嵌入模型 (Embedding Models)

### HuggingFaceBgeEmbeddings

>[HuggingFace 上的 BGE 模型](https://huggingface.co/BAAI/bge-large-en-v1.5) 是 [最好的开源嵌入模型之一](https://huggingface.co/spaces/mteb/leaderboard)。

请参阅 [使用示例](/oss/python/integrations/text_embedding/bge_huggingface)。

```python
from langchain_community.embeddings import HuggingFaceBgeEmbeddings
```

### IpexLLMBgeEmbeddings

>[IPEX-LLM](https://github.com/intel-analytics/ipex-llm) 是一个 PyTorch 库，用于在英特尔 CPU 和 GPU（例如，带有 iGPU 的本地 PC、Arc、Flex 和 Max 等独立 GPU）上以极低延迟运行大型语言模型 (LLM)。

请参阅 [在英特尔 CPU 上运行模型的示例](/oss/python/integrations/text_embedding/ipex_llm)。
请参阅 [在英特尔 GPU 上运行模型的示例](/oss/python/integrations/text_embedding/ipex_llm_gpu)。

```python
from langchain_community.embeddings import IpexLLMBgeEmbeddings
```

### QuantizedBgeEmbeddings

请参阅 [使用示例](/oss/python/integrations/text_embedding/itrex)。

from langchain_community.embeddings import QuantizedBgeEmbeddings
