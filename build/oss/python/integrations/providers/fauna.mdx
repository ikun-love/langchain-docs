> [Fauna](https://fauna.com/) 是一个分布式文档关系型数据库，它结合了文档的灵活性和关系型、**ACID 兼容**数据库[^1]的能力，并且可以跨区域、跨云或在全球范围内进行扩展。

## 安装和设置 (Installation and Setup)

我们需要获取密钥（secret key）。
请参阅详细的 [指南](https://docs.fauna.com/fauna/current/learn/security_model/)。

我们需要安装 `fauna` 包。

<CodeGroup>
```bash pip
pip install -U fauna
```

```bash uv
uv add fauna
```
</CodeGroup>

## 文档加载器 (Document Loader)

请查看 [使用示例](/oss/python/integrations/document_loaders/fauna)。

```python
from langchain_community.document_loaders.fauna import FaunaLoader
```

[^1]: **ACID** 兼容性意味着该数据库支持原子性 (Atomicity)、一致性 (Consistency)、隔离性 (Isolation) 和持久性 (Durability)，这通常是传统关系型数据库的关键特性。
