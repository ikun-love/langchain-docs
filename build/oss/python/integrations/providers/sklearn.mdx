> [scikit-learn](https://scikit-learn.org/stable/) 是一个开源的机器学习算法集合，
> 其中包含了一些 [k 近邻 (k nearest neighbors)](https://scikit-learn.org/stable/modules/generated/sklearn.neighbors.NearestNeighbors.html) 算法的实现。`SKLearnVectorStore` 封装了这些实现，并增加了将向量存储持久化为 json、bson (二进制 json) 或 Apache Parquet 格式的可能性。

## 安装与设置

- 使用 `pip install scikit-learn` 安装 Python 包

## 向量存储 (Vector Store)

`SKLearnVectorStore` 提供了对 scikit-learn 包中最近邻实现的简单封装，允许您将其用作向量存储。

要导入此向量存储：

```python
from langchain_community.vectorstores import SKLearnVectorStore
```

有关 `SKLearnVectorStore` 封装的更详细演练，请参阅 [此 Notebook](/oss/python/integrations/vectorstores/sklearn)。

## 检索器 (Retriever)

`支持向量机 (Support vector machines, SVMs)` 是用于分类、回归和异常值检测的监督学习方法。

请参阅 [使用示例](/oss/python/integrations/retrievers/svm)。

```python
from langchain_community.retrievers import SVMRetriever
```
