> `llama.cpp python` 库是 `@ggerganov` 的 [llama.cpp](https://github.com/ggerganov/llama.cpp) 的一个简单的 Python 绑定。
>
> 这个包提供了以下内容：
>
> - 通过 `ctypes` 接口实现的 C API 的底层访问。
> - 用于文本补全的高级 Python API
>   - 类似 `OpenAI` 的 API
>   - `LangChain` 兼容性
>   - `LlamaIndex` 兼容性
> - 兼容 OpenAI 规范的 Web 服务器
>   - 本地 Copilot 替代方案
>   - 函数调用（Function Calling）支持
>   - 视觉 API（Vision API）支持
>   - 多模型支持

## 安装与设置

- 安装 Python 包
  ```bash
  pip install llama-cpp-python
  ```
- 下载一个 [支持的模型](https://github.com/ggerganov/llama.cpp#description)，并按照 [说明](https://github.com/ggerganov/llama.cpp) 将其转换为 llama.cpp 的格式。


## 聊天模型 (Chat models)

请参阅 [使用示例](/oss/python/integrations/chat/llamacpp)。

```python
from langchain_community.chat_models import ChatLlamaCpp
```
## LLM 模型

```pythonc
from langchain_community.llms import LlamaCpp
```
## 嵌入模型 (Embedding models)

请参阅 [使用示例](/oss/python/integrations/text_embedding/llamacpp)。

from langchain_community.embeddings import LlamaCppEmbeddings
