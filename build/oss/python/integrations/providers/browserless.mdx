> [Browserless](https://www.browserless.io/docs/start) 是一项服务，它允许您在云端运行无头 Chrome 实例。这是一种以可扩展的方式运行基于浏览器的自动化的绝佳方法，无需担心管理自己的基础设施。

## 安装和设置

我们必须在此处 [获取 API 密钥](https://www.browserless.io/pricing/)。
