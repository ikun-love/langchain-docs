>[KoboldAI](https://koboldai.com/) 是一个免费的、开源的项目，它允许用户在自己的计算机上本地运行 AI 模型。
>它是一个基于浏览器的前端界面（front-end），可用于与 AI 一起进行写作或角色扮演。
>[KoboldAI](https://github.com/KoboldAI/KoboldAI-Client) 被描述为“一个用于 AI 辅助写作的基于浏览器的前端界面，支持多个本地和远程的 AI 模型……”。
>它提供了一个公共和本地的 API，这个 API 可以在 LangChain 中使用。

## 安装和设置

请查看 [安装指南](https://github.com/KoboldAI/KoboldAI-Client)。
