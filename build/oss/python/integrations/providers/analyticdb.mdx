> [AnalyticDB for PostgreSQL](https://www.alibabacloud.com/help/en/analyticdb-for-postgresql/latest/product-introduction-overview) 是阿里云提供的一种**大规模并行处理 (MPP)** 数据仓库服务，专门设计用于在线分析海量数据。

>`AnalyticDB for PostgreSQL` 基于开源的 `Greenplum Database` 项目开发，并由 `Alibaba Cloud` 进行了深度增强和扩展。AnalyticDB for PostgreSQL 兼容 ANSI SQL 2003 语法，并支持 PostgreSQL 和 Oracle 数据库生态系统。此外，它同时支持行存 (row store) 和列存 (column store)。AnalyticDB for PostgreSQL 能够以高性能处理 PB 级别的数据，并支持高并发的离线分析。

本文档介绍如何在 LangChain 中使用 AnalyticDB 生态系统。

## 安装与设置 (Installation and Setup)

你需要安装 `sqlalchemy` Python 包。

<CodeGroup>
```bash pip
pip install sqlalchemy
```

```bash uv
uv add sqlalchemy
```
</CodeGroup>
