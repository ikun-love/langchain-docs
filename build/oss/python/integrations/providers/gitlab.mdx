>[GitLab Inc.](https://about.gitlab.com/) 是一家开放核心（open-core）公司，提供名为 `GitLab` 的 DevOps 软件套件，可用于软件的开发、安全保护和运维。`GitLab` 内置了基于 Git 的分布式版本控制系统，同时为每个项目提供了访问控制、Bug 跟踪、软件功能请求、任务管理、Wiki 以及代码片段（snippets）等功能。

## 工具/工具包

### GitLabToolkit

`GitLab` 工具包包含一系列工具，使 LLM 代理能够与 GitLab 仓库进行交互。

该工具包是对 `python-gitlab` 库的封装。

请参阅[使用示例](/oss/python/integrations/tools/gitlab)。

```python
from langchain_community.agent_toolkits.gitlab.toolkit import GitLabToolkit
```

### GitLabAction

用于与 GitLab API 进行交互的工具。

```python
from langchain_community.tools.gitlab.tool import GitLabAction
```
