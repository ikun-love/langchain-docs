> [Figma](https://www.figma.com/) 是一款用于界面设计的协作式 Web 应用程序。

## 安装和设置

Figma API 需要一个 `access token`（访问令牌）、`node_ids`（节点 ID 列表）以及一个 `file key`（文件密钥）。

`file key` 可以从 Figma 的文件 URL 中提取。https://www.figma.com/file/\{filekey\}/sampleFilename

`Node IDs` 同样可以在 URL 中找到。点击文件中的任何元素，然后在 URL 中查找 `?node-id=\{node_id\}` 这个参数。

`Access token` 的获取请参考 [说明](https://help.figma.com/hc/en-us/articles/8085703771159-Manage-personal-access-tokens)。
