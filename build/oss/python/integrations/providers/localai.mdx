>[LocalAI](https://localai.io/) 是一个免费的、开源的 OpenAI 替代方案。
> `LocalAI` 充当一个即插即用的 REST API，它与 OpenAI API 规范兼容，用于本地推理（local inferencing）。它允许您使用普通消费级硬件在本地或本地部署（on-prem）运行大型语言模型（LLMs）、生成图像、音频（以及更多内容），并支持多种模型家族和架构。

<Warning>
**为确保兼容性，请确保您使用的 `openai` SDK 版本是 `0.x`。**
</Warning>

<Info>
`langchain-localai` 是一个用于 LocalAI 的第三方集成包。它提供了一种在 LangChain 中使用 LocalAI 服务的简单方法。
源代码可在 [GitHub](https://github.com/mkhludnev/langchain-localai) 上找到。
</Info>

## 安装和设置

我们需要安装几个 Python 包：

<CodeGroup>
```bash pip
pip install tenacity openai
```

```bash uv
uv add tenacity openai
```
</CodeGroup>


## 嵌入模型 (Embedding models)

请参阅 [使用示例](/oss/python/integrations/text_embedding/localai)。

```python
from langchain_localai import LocalAIEmbeddings
```
