>[Aleph Alpha](https://docs.aleph-alpha.com/) 成立于 2019 年，其使命是研究和构建强人工智能时代的基础技术。该团队由来自不同国家的科学家、工程师和创新者组成，他们研究、开发并部署了如大型语言模型和多模态模型等变革性的 AI 技术，并运营着欧洲最快的商业 AI 集群。

>[Luminous 系列](https://docs.aleph-alpha.com/docs/introduction/luminous/) 是一系列大型语言模型（LLM）。

## 安装和设置

<CodeGroup>
```bash pip
pip install aleph-alpha-client
```

```bash uv
uv add aleph-alpha-client
```
</CodeGroup>

您需要创建一个新的 API 令牌（token）。请参阅[说明](https://docs.aleph-alpha.com/docs/account/#create-a-new-token)。

```python
from getpass import getpass

ALEPH_ALPHA_API_KEY = getpass()
```


## LLM

请参阅[使用示例](/oss/python/integrations/llms/aleph_alpha)。

```python
from langchain_community.llms import AlephAlpha
```
