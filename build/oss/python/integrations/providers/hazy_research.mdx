本页面介绍如何在 LangChain 中使用 Hazy Research 生态系统。
内容分为两个部分：安装与设置，以及特定 Hazy Research 封装器的引用。

## 安装与设置
- 要使用 `manifest` 库，请使用 `pip install manifest-ml` 命令进行安装。

## 封装器 (Wrappers)

### LLM

Hazy Research 的 `manifest` 库提供了一个 LLM 封装器。
`manifest` 是一个 Python 库，它本身是对许多模型提供商的封装，并增加了缓存、历史记录等功能。

要使用此封装器：
```python
from langchain_community.llms.manifest import ManifestWrapper
```
