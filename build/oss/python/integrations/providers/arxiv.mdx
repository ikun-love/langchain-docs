> [arXiv](https://arxiv.org/) 是一个开放获取的电子文献库，其中包含物理学、数学、计算机科学、定量生物学、定量金融、统计学、电气工程与系统科学以及经济学等领域的 200 万篇学术文章。

## 安装与设置

首先，您需要安装 `arxiv` Python 包。

<CodeGroup>
```bash pip
pip install arxiv
```

```bash uv
uv add arxiv
```
</CodeGroup>

其次，您需要安装 `PyMuPDF` Python 包。该包用于将从 `arxiv.org` 网站下载的 PDF 文件转换为文本格式。

<CodeGroup>
```bash pip
pip install pymupdf
```

```bash uv
uv add pymupdf
```
</CodeGroup>

## 文档加载器 (Document Loader)

请参阅 [使用示例](/oss/python/integrations/document_loaders/arxiv)。

```python
from langchain_community.document_loaders import ArxivLoader
```
