>[SemaDB](https://semafind.com/) 是一个简单易用的向量相似性搜索引擎。它提供低成本的云托管版本，帮助您轻松构建 AI 应用。

使用我们的托管版本 SemaDB Cloud，“简单易用”意味着：无需计算 Pod 大小、无需定义 Schema、无需配置分区、无需调整参数、无需调整搜索算法、无需复杂安装、无需复杂 API。它与 [RapidAPI](https://rapidapi.com/semafind-semadb/api/semadb) 集成，提供透明的计费、自动分片和一个交互式的 API 游乐场。

## 安装

无需安装任何内容，可以直接在 [RapidAPI](https://rapidapi.com/semafind-semadb/api/semadb) 上开始使用 SemaDB Cloud。

## 向量存储（Vector Store）

SemaDB 对集合（collections）提供了一个基础封装，允许您将其用作向量存储。

```python
from langchain_community.vectorstores import SemaDB
```

您可以参考 [此 Notebook](/oss/python/integrations/vectorstores/semadb) 中关于如何使用此封装的教程。
