>**GreenNode** 是一家全球性 AI 解决方案提供商，同时也是 **NVIDIA 优选合作伙伴 (Preferred Partner)**。它为美国、中东和北非（MENA）以及亚太地区的企业提供从基础设施到应用程序的全栈 AI 能力。
>
>GreenNode 运营着**世界一流的基础设施**（符合 LEED 金级、TIA‑942、Uptime Tier III 标准），为企业、初创公司和研究人员提供全方位的 AI 服务：
>
>- [强大的 AI 基础设施:](https://greennode.ai/) 作为亚太地区首批超大规模 AI 集群之一，GreenNode 的基础设施由 NVIDIA H100 GPU 驱动，专为高吞吐量的机器学习和深度学习工作负载进行了优化。
>- [GreenNode AI 平台:](https://greennode.ai/product/ai-platform) GreenNode 的自助式 AI 平台专为技术团队设计，能够快速部署 Jupyter notebook 环境，并预先配置了优化的计算实例。通过此门户，开发人员可以以最少的设置时间启动机器学习训练、微调 (fine-tuning)、超参数优化和推理工作流。该平台提供对 100 多个精选开源模型的访问权限，并支持与常用 MLOps 工具和存储框架的集成。
>- [GreenNode Serverless AI:](https://greennode.ai/product/model-as-a-service) GreenNode Serverless AI 包含一个预训练的、可投入生产的模型库，涵盖文本生成、代码生成、文本转语音、语音转文本、嵌入 (embedding) 和重排序 (reranking) 等领域。此服务非常适合希望快速原型设计或部署 AI 解决方案而无需自行管理模型基础设施的团队。
>- [AI 应用:](https://vngcloud.vn/en/solution) 从智能数据管理和文档处理 (IDP) 到智能视频分析——GreenNode 支持大规模的实际 AI 用例。
>无论您是正在构建下一个 LLM 工作流、扩展 AI 研究，还是部署企业级应用程序，**GreenNode** 都为您提供了加速发展所需工具和基础设施。

## 安装和设置

可以通过 pip 安装 GreenNode 集成：

```python
pip install -qU langchain-greennode
```

### API 密钥

要使用 GreenNode Serverless AI，您需要一个 API 密钥，该密钥可以从 [GreenNode Serverless AI](https://aiplatform.console.greennode.ai/api-keys) 获取。API 密钥可以作为初始化参数 `api_key` 传入，或者设置为环境变量 `GREENNODE_API_KEY`。

```python
import getpass
import os

if not os.getenv("GREENNODE_API_KEY"):
    os.environ["GREENNODE_API_KEY"] = getpass.getpass("Enter your GreenNode API key: ")
```

## 聊天模型 (Chat models)

```python
from langchain_greennode import ChatGreenNode

chat = ChatGreenNode(
    model="deepseek-ai/DeepSeek-R1-Distill-Qwen-32B",  # 从可用模型中选择
    temperature=0.6,
    top_p=0.95,
)
```

GreenNode [聊天模型](https://python.langchain.com/docs/integrations/chat/greennode/) 的使用

## 嵌入模型 (Embedding models)

```python
from langchain_greennode import GreenNodeEmbeddings

# 初始化嵌入模型
embeddings = GreenNodeEmbeddings(
    model="BAAI/bge-m3"  # 从可用模型中选择
)
```

GreenNode [嵌入模型](https://python.langchain.com/docs/integrations/text_embedding/greennode) 的使用

## 重排序 (Rerank)

```python
from langchain_greennode import GreenNodeRerank

# 初始化重排序器
rerank = GreenNodeRerank(
    model="BAAI/bge-reranker-v2-m3",  # 从可用模型中选择
    top_n=-1,
)
```

GreenNode [Rerank 模型](https://python.langchain.com/docs/integrations/retrievers/greennode-reranker) 的使用
