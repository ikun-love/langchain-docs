> [MediaWiki XML Dumps](https://www.mediawiki.org/wiki/Manual:Importing_XML_dumps) 包含一个 Wiki 的内容（带有所有修订版本的 Wiki 页面），但不包含与站点相关的数据。XML 转储文件不会创建 Wiki 数据库的完整备份，它不包含用户账户、图片、编辑日志等信息。

## 安装和设置 (Installation and Setup)

我们需要安装几个 Python 包。

`mediawiki-utilities` 支持未合并分支中的 XML 模式 0.11。

<CodeGroup>
```bash pip
pip install -qU git+https://github.com/mediawiki-utilities/python-mwtypes@updates_schema_0.11
```

```bash uv
uv add U git+https://github.com/mediawiki-utilities/python-mwtypes@updates_schema_0.11
```
</CodeGroup>

`mediawiki-utilities mwxml` 中存在一个 bug，修复的拉取请求（PR）正在等待中。

<CodeGroup>
```bash pip
pip install -qU git+https://github.com/gdedrouas/python-mwxml@xml_format_0.11
pip install -qU mwparserfromhell
```

```bash uv
uv add git+https://github.com/gdedrouas/python-mwxml@xml_format_0.11
uv add mwparserfromhell
```
</CodeGroup>
