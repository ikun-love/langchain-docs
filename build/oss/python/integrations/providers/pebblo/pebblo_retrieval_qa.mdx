> `PebbloRetrievalQA` 是一个检索链，它对作用于向量数据库的问答（Question-Answering）功能具有身份和语义强制执行能力。

本教程将介绍如何使用身份和语义强制执行（拒绝主题/实体）来检索文档。有关 Pebblo 及其 `SafeRetriever` 功能的更多详细信息，请访问 [Pebblo 文档](https://daxa-ai.github.io/pebblo/retrieval_chain/)。

### 步骤

1. **加载文档 (Loading Documents):**
我们将把带有授权和语义元数据（metadata）的文档加载到一个内存中的 Qdrant 向量存储中。这个向量存储将作为 `PebbloRetrievalQA` 中的检索器（retriever）。

> **注意:** 建议在数据摄取端（ingestion side）使用 `[PebbloSafeLoader](https://daxa-ai.github.io/pebblo/rag)` 来加载带有身份验证和语义元数据的文档。`PebbloSafeLoader` 确保安全高效地加载文档，同时保持元数据的完整性。

2. **测试强制执行机制 (Testing Enforcement Mechanisms):**
   我们将分别测试身份和语义强制执行。对于每种用例，我们将定义一个具有所需上下文（*auth_context* 和 *semantic_context*）的特定“提问”函数（`ask` function），然后提出我们的问题。

## 设置 (Setup)

```python
pip install -qU langchain langchain_core langchain-community langchain-openai qdrant_client
```

### 身份感知的数据摄取 (Identity-aware Data Ingestion)

在这里我们使用 Qdrant 作为向量数据库；但是，您可以使用任何受支持的向量数据库。

**`PebbloRetrievalQA` 链支持以下向量数据库：**

- Qdrant
- Pinecone
- Postgres (使用 `pgvector` 扩展)

**使用授权和语义信息加载向量数据库到元数据中：**

在此步骤中，我们将源文档的授权和语义信息捕获到向量数据库（VectorDB）条目元数据中的 `authorized_identities`、`pebblo_semantic_topics` 和 `pebblo_semantic_entities` 字段内。

*注意：要使用 `PebbloRetrievalQA` 链，您**必须**始终将授权和语义元数据放置在指定的字段中。这些字段必须包含一个字符串列表 (`list of strings`)。*

```python
from langchain_community.vectorstores.qdrant import Qdrant
from langchain_core.documents import Document
from langchain_openai.embeddings import OpenAIEmbeddings
from langchain_openai.llms import OpenAI

llm = OpenAI()
embeddings = OpenAIEmbeddings()
collection_name = "pebblo-identity-and-semantic-rag"

page_content = """
**ACME Corp 财务报告**

**概述:**
ACME Corp 是并购行业的领先者，呈报截至 2020 年 12 月 31 日的财政年度财务报告。
尽管经济环境充满挑战，ACME Corp 仍展现出强劲的业绩和战略增长。

**财务亮点:**
收入飙升至 5000 万美元，比上一年增长了 15%，这得益于成功的交易完成和向新市场的扩张。
净利润达到 1200 万美元，显示出健康的 24% 利润率。

**关键指标:**
总资产激增至 8000 万美元，同比增长 20%，突显了 ACME Corp 强劲的财务状况和资产基础。
此外，公司维持了保守的 0.5 的债务权益比，确保了可持续的财务稳定。

**未来展望:**
ACME Corp 对未来保持乐观，计划利用全球并购格局中的新兴机会。
公司致力于在保持商业道德实践的同时，为股东创造价值。

**银行账户详情:**
如有查询或交易，请参阅 ACME Corp 的美国银行账户：
账号：123456789012
银行名称：虚构美国银行 (Fictitious Bank of America)
"""

documents = [
    Document(
        **{
            "page_content": page_content,
            "metadata": {
                "pebblo_semantic_topics": ["financial-report"],
                "pebblo_semantic_entities": ["us-bank-account-number"],
                "authorized_identities": ["finance-team", "exec-leadership"],
                "page": 0,
                "source": "https://drive.google.com/file/d/xxxxxxxxxxxxx/view",
                "title": "ACME Corp Financial Report.pdf",
            },
        }
    )
]

vectordb = Qdrant.from_documents(
    documents,
    embeddings,
    location=":memory:",
    collection_name=collection_name,
)

print("Vectordb loaded.")
```

```output
Vectordb loaded.
```

## 检索与身份强制执行 (Retrieval with Identity Enforcement)

`PebbloRetrievalQA` 链使用一个 `SafeRetrieval` 来强制执行，确保用于上下文（in-context）的片段仅从授权给用户的文档中检索出来。
要实现这一点，生成式 AI（Gen-AI）应用程序需要在检索链中提供一个授权上下文。
这个 *auth_context* 应该用访问 Gen-AI 应用程序的用户的身份和授权组来填充。

下面是 `PebbloRetrievalQA` 的示例代码，其中包含用户访问 RAG 应用程序时在 `auth_context` 中传入的 `user_auth`（用户授权列表，可能包括他们的用户 ID 和所属群组）。

```python
from langchain_community.chains import PebbloRetrievalQA
from langchain_community.chains.pebblo_retrieval.models import AuthContext, ChainInput

# 初始化 PebbloRetrievalQA 链
qa_chain = PebbloRetrievalQA.from_chain_type(
    llm=llm,
    retriever=vectordb.as_retriever(),
    app_name="pebblo-identity-rag",
    description="使用 PebbloRetrievalQA 进行身份强制执行的应用",
    owner="ACME Corp",
)


def ask(question: str, auth_context: dict):
    """
    向 PebbloRetrievalQA 链提问
    """
    auth_context_obj = AuthContext(**auth_context) if auth_context else None
    chain_input_obj = ChainInput(query=question, auth_context=auth_context_obj)
    return qa_chain.invoke(chain_input_obj.dict())
```

### 1. 授权用户提出的问题 (Questions by Authorized User)

我们已摄取了授权身份为 `["finance-team", "exec-leadership"]` 的数据，因此具有授权身份/群组 `finance-team` 的用户应收到正确的答案。

```python
auth = {
    "user_id": "finance-user@acme.org",
    "user_auth": [
        "finance-team",
    ],
}

question = "分享一下 ACME Corp 2020 年的财务表现"
resp = ask(question, auth)
print(f"问题: {question}\n\n答案: {resp['result']}")
```

```output
问题: 分享一下 ACME Corp 2020 年的财务表现

答案:
收入：5000 万美元（比上一年增长 15%）
净利润：1200 万美元（24% 利润率）
总资产：8000 万美元（增长 20%）
债务权益比：0.5
```

### 2. 未授权用户提出的问题 (Questions by Unauthorized User)

由于用户的授权身份/群组 `eng-support` 未包含在授权身份 `["finance-team", "exec-leadership"]` 中，因此我们不应收到答案。

```python
auth = {
    "user_id": "eng-user@acme.org",
    "user_auth": [
        "eng-support",
    ],
}

question = "分享一下 ACME Corp 2020 年的财务表现"
resp = ask(question, auth)
print(f"问题: {question}\n\n答案: {resp['result']}")
```

```output
问题: 分享一下 ACME Corp 2020 年的财务表现

答案:  我不知道。
```

### 3. 使用 PromptTemplate 提供额外指令 (Using PromptTemplate to provide additional instructions)

您可以使用 `PromptTemplate` 为 LLM 提供额外指令，以生成自定义响应。

```python
from langchain_core.prompts import PromptTemplate

prompt_template = PromptTemplate.from_template(
    """
使用提供的上下文回答问题。
如果没有提供上下文，只需说 "对不起，该信息不可用，或访问受到限制。" (I'm sorry, but that information is unavailable, or Access to it is restricted.)。

问题: {question}
"""
)

question = "分享一下 ACME Corp 2020 年的财务表现"
prompt = prompt_template.format(question=question)
```

```python

    "user_auth": [

    ],
}
resp = ask(prompt, auth)
print(f"问题: {question}\n\n答案: {resp['result']}")
```

## 语义强制执行 (Retrieval with Semantic Enforcement)

`PebbloRetrievalQA` 链使用 `SafeRetrieval` 来确保上下文（context）中使用的片段仅从符合所提供的语义上下文的文档中检索出来。
要实现这一点，生成式 AI 应用程序必须为此检索链提供一个语义上下文。
这个 `semantic_context` 应包括应被拒绝访问 Gen-AI 应用程序的用户的**主题**（topics）和**实体**（entities）。

下面是 `PebbloRetrievalQA` 的示例代码，其中包含在 `semantic_context` 传递给链输入时使用的 `topics_to_deny` 和 `entities_to_deny`。

```python
from typing import List, Optional

from langchain_community.chains import PebbloRetrievalQA
from langchain_community.chains.pebblo_retrieval.models import (
    ChainInput,
    SemanticContext,
)

# 初始化 PebbloRetrievalQA 链
qa_chain = PebbloRetrievalQA.from_chain_type(
    llm=llm,
    retriever=vectordb.as_retriever(),
    app_name="pebblo-semantic-rag",
    description="使用 PebbloRetrievalQA 进行语义强制执行的应用",
    owner="ACME Corp",
)


def ask(
    question: str,
    topics_to_deny: Optional[List[str]] = None,
    entities_to_deny: Optional[List[str]] = None,
):
    """
    向 PebbloRetrievalQA 链提问
    """
    semantic_context = dict()
    if topics_to_deny:
        semantic_context["pebblo_semantic_topics"] = {"deny": topics_to_deny}
    if entities_to_deny:
        semantic_context["pebblo_semantic_entities"] = {"deny": entities_to_deny}

    semantic_context_obj = (
        SemanticContext(**semantic_context) if semantic_context else None
    )
    chain_input_obj = ChainInput(query=question, semantic_context=semantic_context_obj)
    return qa_chain.invoke(chain_input_obj.dict())
```

### 1. 不进行语义强制执行 (Without semantic enforcement)

由于没有应用语义强制执行，系统应返回答案，而不会因与上下文相关的语义标签而排除任何内容。

```python
topic_to_deny = []
entities_to_deny = []
question = "分享一下 ACME Corp 2020 年的财务表现"
resp = ask(question, topics_to_deny=topic_to_deny, entities_to_deny=entities_to_deny)
print(
    f"要拒绝的主题: {topic_to_deny}\n要拒绝的实体: {entities_to_deny}\n"
    f"问题: {question}\n答案: {resp['result']}"
)
```

```output
要拒绝的主题: []
要拒绝的实体: []
问题: 分享一下 ACME Corp 2020 年的财务表现
答案:
ACME Corp 2020 年的收入增长 15% 至 5000 万美元，净利润为 1200 万美元，资产基础强劲，为 8000 万美元。该公司还维持了保守的 0.5 债务权益比。
```

### 2. 拒绝 `financial-report` 主题 (Deny financial-report topic)

数据已使用主题 `["financial-report"]` 摄取。
因此，拒绝 `financial-report` 主题的应用程序不应收到答案。

```python
topic_to_deny = ["financial-report"]
entities_to_deny = []
question = "分享一下 ACME Corp 2020 年的财务表现"
resp = ask(question, topics_to_deny=topic_to_deny, entities_to_deny=entities_to_deny)
print(
    f"要拒绝的主题: {topic_to_deny}\n要拒绝的实体: {entities_to_deny}\n"
    f"问题: {question}\n答案: {resp['result']}"
)
```

```output
要拒绝的主题: ['financial-report']
要拒绝的实体: []
问题: 分享一下 ACME Corp 2020 年的财务表现
答案:

很抱歉，我无法获取 ACME Corp 2020 年的财务表现信息。
```

### 3. 拒绝 `us-bank-account-number` 实体 (Deny us-bank-account-number entity)

由于实体 `us-bank-account-number` 被拒绝，系统不应返回答案。

```python
topic_to_deny = []
entities_to_deny = ["us-bank-account-number"]
question = "分享一下 ACME Corp 2020 年的财务表现"
resp = ask(question, topics_to_deny=topic_to_deny, entities_to_deny=entities_to_deny)

    f"要拒绝的主题: {topic_to_deny}\n要拒绝的实体: {entities_to_deny}\n"
```
