> [Annoy](https://github.com/spotify/annoy)（全称 `Approximate Nearest Neighbors Oh Yeah`，意为“近似近邻，是的”）是一个 C++ 库，它提供了 Python 绑定，用于在空间中搜索与给定查询点接近的点。它还可以创建大型的、基于文件的、只读的数据结构，并将这些结构映射到内存中，使得多个进程可以共享相同的数据。

## 安装与设置

<CodeGroup>
```bash pip
pip install annoy
```

```bash uv
uv add annoy
```
</CodeGroup>


## 向量存储 (Vectorstore)

请参阅 [使用示例](/oss/python/integrations/vectorstores/annoy)。
