> [LlamaEdge](https://llamaedge.com/docs/intro/) 是在本地或边缘设备上运行定制化和微调的 LLM 的最简单、最快捷的方式。
>
> * 轻量级的推理应用。`LlamaEdge` 的体积单位通常是 MB 而非 GB。
> * 原生且 GPU 加速的性能。
> * 支持多种 GPU 和硬件加速器。
> * 支持许多优化的推理库。
> * 广泛的 AI / LLM 模型选择。

## 安装和设置

请参阅 [安装说明](https://llamaedge.com/docs/user-guide/quick-start-command)。
