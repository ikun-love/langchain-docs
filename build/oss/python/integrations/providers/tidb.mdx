> [TiDB Cloud](https://www.pingcap.com/tidb-serverless) 是一个全面的数据库即服务（DBaaS）解决方案，提供了专用（Dedicated）和无服务器（Serverless）两种部署选项。`TiDB Serverless` 目前正在将内置的向量搜索功能集成到 MySQL 生态中。有了这一增强，您可以无缝地使用 `TiDB Serverless` 开发 AI 应用，而无需引入新的数据库或额外的技术栈。请在 https://pingcap.com/ai 创建一个免费的 TiDB Serverless 集群并开始使用向量搜索功能。
