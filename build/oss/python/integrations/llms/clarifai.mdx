> [Clarifai](https://www.clarifai.com/) 是一个人工智能平台，它提供了完整的人工智能生命周期，涵盖从数据探索、数据标注、模型训练、评估到推理的各个环节。

本示例将介绍如何使用 LangChain 与 `Clarifai` [模型](https://clarifai.com/explore/models)进行交互。

要使用 Clarifai，您必须拥有一个账户和一个个人访问令牌（PAT）密钥。
请在此处 [Check here](https://clarifai.com/settings/security) 获取或创建 PAT。

# 依赖项 (Dependencies)

```python
# 安装所需的依赖项
pip install -qU  clarifai
```

```python
# 将 clarifai pat 令牌声明为环境变量，或者您也可以将其作为参数传递给 clarifai 类。
import os

os.environ["CLARIFAI_PAT"] = "CLARIFAI_PAT_TOKEN"
```

# 导入 (Imports)

在这里，我们将设置个人访问令牌。您可以在 Clarifai 账户的 [settings/security](https://clarifai.com/settings/security) 路径下找到您的 PAT。

```python
# 请登录并从 https://clarifai.com/settings/security 获取您的 API 密钥
from getpass import getpass

CLARIFAI_PAT = getpass()
```

```python
# 导入所需的模块
from langchain.chains import LLMChain
from langchain_community.llms import Clarifai
from langchain_core.prompts import PromptTemplate
```

# 输入 (Input)

创建一个提示模板供 LLM Chain 使用：

```python
template = """问题: {question}

答案: 让我们一步一步思考。"""

prompt = PromptTemplate.from_template(template)
```

# 设置 (Setup)

设置模型所在的 `user id` 和 `app id`。您可以在 [clarifai.com/explore/models](https://clarifai.com/explore/models) 上找到公共模型的列表。

您还必须初始化 `model id`，如果需要，也可以初始化 `model version id`。有些模型有很多版本，您可以根据任务选择合适的版本。

或者，您可以使用 `model_url`（例如：`"[clarifai.com/anthropic/completion/models/claude-v2](https://clarifai.com/anthropic/completion/models/claude-v2)"`）进行初始化。

```python
USER_ID = "openai"
APP_ID = "chat-completion"
MODEL_ID = "GPT-3_5-turbo"

# 您可以通过 model_version_id 参数提供一个特定的模型版本。
# MODEL_VERSION_ID = "MODEL_VERSION_ID"
# 或者

MODEL_URL = "https://clarifai.com/openai/chat-completion/models/GPT-4"
```

```python
# 初始化一个 Clarifai LLM 实例
clarifai_llm = Clarifai(user_id=USER_ID, app_id=APP_ID, model_id=MODEL_ID)
# 或者
# 通过 Model URL 初始化
clarifai_llm = Clarifai(model_url=MODEL_URL)
```

```python
# 创建 LLM 链
llm_chain = LLMChain(prompt=prompt, llm=clarifai_llm)
```

# 运行链 (Run Chain)

```python
question = "贾斯汀·比伯出生的那年，哪支 NFL 球队赢得了超级碗？"

llm_chain.run(question)
```

```output
' 好的，以下是找出答案的步骤：\n\n1. 贾斯汀·比伯出生于 1994 年 3 月 1 日。\n\n2. 发生在他出生那年的超级碗是第二十八届超级碗（Super Bowl XXVIII）。 \n\n3. 第二十八届超级碗于 1994 年 1 月 30 日举行。\n\n4. 参加第二十八届超级碗的两支球队是达拉斯牛仔队（Dallas Cowboys）和布法罗比尔队（Buffalo Bills）。 \n\n5. 达拉斯牛仔队以 30-13 击败布法罗比尔队，赢得了第二十八届超级碗。\n\n因此，在贾斯汀·比伯出生的那年赢得超级碗的 NFL 球队是达拉斯牛仔队。'
```

## 使用推理参数（Inference parameters）对 GPT 模型进行预测

或者，您可以使用带有推理参数（如 `temperature`、`max_tokens` 等）的 GPT 模型进行预测。

```python
# 将参数初始化为字典。
params = dict(temperature=str(0.3), max_tokens=100)
```

```python
clarifai_llm = Clarifai(user_id=USER_ID, app_id=APP_ID, model_id=MODEL_ID)
llm_chain = LLMChain(
    prompt=prompt, llm=clarifai_llm, llm_kwargs={"inference_params": params}
)
```

```python
question = "对于所有三位数的偶数，如果其中一位是 5，则后一位数字必须是 7，请问能组成多少个这样的数？"

llm_chain.run(question)
```

```output
'步骤 1：第一位数字可以是 1 到 9 中任何一个偶数，但不能是 5。因此第一位有 4 种选择。\n\n步骤 2：如果第一位数字不是 5，则第二位数字必须是 7。因此第二位只有 1 种选择。\n\n步骤 3：第三位可以是 0 到 9 中任何一个偶数，但不能是 5 和 7。因此第三位有 '
```
