**Modal 云平台** 提供了便捷的按需访问能力，允许您从本地计算机的 Python 脚本中，通过**无服务器（serverless）**的方式使用云端计算资源。
您可以使用 `modal` 来运行自己定制的 LLM 模型，从而不必完全依赖于现有的 LLM API 服务。

本示例将指导您如何使用 LangChain 与 `modal` 的 HTTPS **Web 端点**（[web endpoint](https://modal.com/docs/guide/webhooks)）进行交互。

[LangChain 与问答（Question-answering with LangChain）](https://modal.com/docs/guide/ex/potus_speech_qanda) 是另一个结合 LangChain 和 `Modal` 使用的示例。在该示例中，Modal 端到端地运行 LangChain 应用程序，并使用 OpenAI 作为其 LLM API。

[`langchain.llms.modal.Modal`](https://github.com/langchain-ai/langchain/blame/master/langchain/llms/modal.py) 集成类要求您部署一个 Modal 应用程序，该应用包含一个符合以下 JSON 接口的 Web 端点：

1. LLM 的提示（Prompt）作为键为 `"prompt"` 的 `str` 值被接收。
2. 返回的 LLM 响应作为键为 `"prompt"` 的 `str` 值返回。

**示例请求 JSON：**

```json
{
    "prompt": "Identify yourself, bot!",
    "extra": "args are allowed",
}
```

**示例响应 JSON：**

```json
{
    "prompt": "This is the LLM speaking",
}
```

满足此接口的“模拟（dummy）” Modal Web 端点函数示例如下：

```python
...
...

class Request(BaseModel):
    prompt: str

@stub.function()
@modal.web_endpoint(method="POST")
def web(request: Request):
    _ = request  # ignore input
    return {"prompt": "hello world"}
```

*   请参阅 Modal 的 [Web 端点](https://modal.com/docs/guide/webhooks#passing-arguments-to-web-endpoints) 指南，了解设置满足此接口的端点的基础知识。
*   请参阅 Modal 的 ['使用 AutoGPTQ 运行 Falcon-40B'](https://modal.com/docs/guide/ex/falcon_gptq) 开源 LLM 示例，作为您定制 LLM 的起点！

一旦您部署了一个 Modal Web 端点，就可以将其 URL 传递给 `langchain.llms.modal.Modal` LLM 类。然后，此类可以作为您链（chain）中的一个构建模块来使用。

```python
from langchain.chains import LLMChain
from langchain_community.llms import Modal
from langchain_core.prompts import PromptTemplate
```

```python
template = """问题: {question}

答案：让我们一步一步思考。"""

prompt = PromptTemplate.from_template(template)
```

```python
endpoint_url = "https://ecorp--custom-llm-endpoint.modal.run"  # 请用您已部署的 Modal Web 端点的 URL 替换此处
llm = Modal(endpoint_url=endpoint_url)
```

```python
llm_chain = LLMChain(prompt=prompt, llm=llm)
```

```python
question = "在贾斯汀·比伯出生的那一年，哪支 NFL 球队赢得了超级碗？"

llm_chain.run(question)
```
