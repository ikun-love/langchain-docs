`Forefront` 平台为您提供了微调（fine-tune）和使用 [开源大型语言模型（LLM）](https://docs.forefront.ai/get-started/models) 的能力。

本 Notebook 将介绍如何将 LangChain 与 [ForefrontAI](https://www.forefront.ai/) 结合使用。

## 导入 (Imports)

```python
import os

from langchain.chains import LLMChain
from langchain_community.llms import ForefrontAI
from langchain_core.prompts import PromptTemplate
```

## 设置环境变量 API 密钥

请确保从 ForefrontAI 获取您的 API 密钥。您将获得一个为期 5 天的免费试用期，用于测试不同的模型。

```python
# 获取新令牌的链接：https://docs.forefront.ai/forefront/api-reference/authentication

from getpass import getpass

FOREFRONTAI_API_KEY = getpass()
```

```python
os.environ["FOREFRONTAI_API_KEY"] = FOREFRONTAI_API_KEY
```

## 创建 ForefrontAI 实例

您可以指定不同的参数，例如模型端点 URL (`endpoint_url`)、长度（`length`）、温度（`temperature`）等。您必须提供一个端点 URL。

```python
llm = ForefrontAI(endpoint_url="YOUR ENDPOINT URL HERE")
```

## 创建 Prompt 模板

我们将为问答（Question and Answer）创建一个提示模板。

```python
template = """Question: {question}

Answer: 让我们一步一步思考（Let's think step by step.）"""

prompt = PromptTemplate.from_template(template)
```

## 初始化 LLMChain

```python
llm_chain = LLMChain(prompt=prompt, llm=llm)
```

## 运行 LLMChain

提供一个问题并运行 LLMChain。

```python
question = "What NFL team won the Super Bowl in the year Justin Beiber was born?"

llm_chain.run(question)
```
