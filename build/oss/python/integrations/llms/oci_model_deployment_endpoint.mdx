## 先决条件

### 模型部署

您可以使用 OCI Data Science 模型部署上的 [AI 快速操作](https://docs.oracle.com/en-us/iaas/data-science/using/ai-quick-actions.htm) 轻松部署、微调和评估基础模型。有关额外的部署示例，请访问 [Oracle GitHub 示例存储库](https://github.com/oracle-samples/oci-data-science-ai-samples/blob/main/ai-quick-actions/llama3-with-smc.md)。

### 策略（Policies）

请确保拥有访问 OCI 数据科学模型部署端点所需的 [策略](https://docs.oracle.com/en-us/iaas/data-science/using/model-dep-policies-auth.htm#model_dep_policies_auth__predict-endpoint)。

## 设置

在部署模型后，您需要设置调用所需的以下参数：

- **`endpoint`**：部署模型的 HTTP 端点，例如 `https://modeldeployment.<region>.oci.customer-oci.com/<md_ocid>/predict`。

### 身份验证

您可以通过 `ads` 库或环境变量设置身份验证。当您在 OCI Data Science 笔记本会话中工作时，可以利用资源主体（resource principal）来访问其他 OCI 资源。请查看 [此处](https://accelerated-data-science.readthedocs.io/en/latest/user_guide/cli/authentication.html) 查看更多选项。

## 示例

```python
import ads
from langchain_community.llms import OCIModelDeploymentLLM

# 通过 ads 设置身份验证
# 如果您在 OCI 服务中操作，并且该服务已配置基于资源主体的身份验证，请使用资源主体
ads.set_auth("resource_principal")

# 创建 OCI 模型部署端点实例
# 替换为您自己的端点 URI 和模型名称
# 使用通用类作为入口点，您将能够在实例化期间通过 model_kwargs 传递模型参数。
llm = OCIModelDeploymentLLM(
    endpoint="https://modeldeployment.<region>.oci.customer-oci.com/<md_ocid>/predict",
    model="odsc-llm",
)

# 运行 LLM
llm.invoke("Who is the first president of United States?")
```

```python
import ads
from langchain_community.llms import OCIModelDeploymentVLLM

# 通过 ads 设置身份验证
# 如果您在 OCI 服务中操作，并且该服务已配置基于资源主体的身份验证，请使用资源主体
ads.set_auth("resource_principal")

# 创建 OCI 模型部署端点实例
# 替换为您自己的端点 URI 和模型名称
# 使用特定于框架的类作为入口点，您可以在构造函数中传递模型参数。
llm = OCIModelDeploymentVLLM(
    endpoint="https://modeldeployment.<region>.oci.customer-oci.com/<md_ocid>/predict",
)

# 运行 LLM
llm.invoke("Who is the first president of United States?")
```

```python
import os

from langchain_community.llms import OCIModelDeploymentTGI

# 通过环境变量设置身份验证
# 当您在本地工作站或不支持资源主体的平台上工作时，请使用 API 密钥设置
os.environ["OCI_IAM_TYPE"] = "api_key"
os.environ["OCI_CONFIG_PROFILE"] = "default"
os.environ["OCI_CONFIG_LOCATION"] = "~/.oci"

# 通过环境变量设置端点
# 替换为您自己的端点 URI
os.environ["OCI_LLM_ENDPOINT"] = (
    "https://modeldeployment.<region>.oci.customer-oci.com/<md_ocid>/predict"
)

# 创建 OCI 模型部署端点实例
# 使用特定于框架的类作为入口点，您可以在构造函数中传递模型参数。
llm = OCIModelDeploymentTGI()

# 运行 LLM
llm.invoke("Who is the first president of United States?")
```

### 异步调用

```python
await llm.ainvoke("Tell me a joke.")
```

### 流式调用

```python
for chunk in llm.stream("Tell me a joke."):
    print(chunk, end="", flush=True)
```
