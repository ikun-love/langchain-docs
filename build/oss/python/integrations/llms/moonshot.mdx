[Moonshot](https://platform.moonshot.cn/) 是一家提供 LLM（大型语言模型）服务的中国初创公司，服务对象包括企业和个人用户。

本示例将介绍如何使用 LangChain 与 Moonshot API 进行交互。

```python
from langchain_community.llms.moonshot import Moonshot
```

```python
import os

# 请从以下链接获取您的 API 密钥：https://platform.moonshot.cn/console/api-keys
os.environ["MOONSHOT_API_KEY"] = "MOONSHOT_API_KEY"
```

```python
llm = Moonshot()
# 或者使用特定的模型
# 可用模型列表：https://platform.moonshot.cn/docs
# llm = Moonshot(model="moonshot-v1-128k")
```

```python
# 向模型发送提示词
llm.invoke("What is the difference between panda and bear?")
```
