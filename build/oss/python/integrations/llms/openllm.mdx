[🦾 OpenLLM](https://github.com/bentoml/OpenLLM) 允许开发者使用**单条命令**将任何**开源大型语言模型 (LLM)** 部署为**兼容 OpenAI 格式的 API** 端点。

- 🔬 专为快速和生产环境使用而设计
- 🚂 支持 Llama 3、Qwen2、Gemma 等模型，以及许多**量化 (quantized)** 版本 [查看完整列表](https://github.com/bentoml/openllm-models)
- ⛓️ 兼容 OpenAI 格式的 API
- 💬 内置类似 ChatGPT 的用户界面 (UI)
- 🔥 利用最先进的推理后端加速 LLM 解码过程
- 🌥️ 准备好进行企业级的云部署（支持 Kubernetes、Docker 和 BentoCloud）

## 安装

通过 [PyPI](https://pypi.org/project/openllm/) 安装 `openllm`

```python
pip install -qU  openllm
```

## 在本地启动 OpenLLM 服务器

要启动一个 LLM 服务器，请使用 `openllm hello` 命令：

```bash
openllm hello
```

## 封装 (Wrapper)

```python
from langchain_community.llms import OpenLLM

server_url = "http://localhost:3000"  # 如果在远程服务器上运行，请替换为远程主机地址
llm = OpenLLM(base_url=server_url, api_key="na")
```

```python
llm("To build a LLM from scratch, the following are the steps:")
```
