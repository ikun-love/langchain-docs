>[Amazon Bedrock](https://aws.amazon.com/bedrock/) 是一项全托管服务，它通过统一的 API 提供了来自 `AI21 Labs`、`Anthropic`、`Cohere`、`Meta`、`Stability AI` 和 `Amazon` 等顶尖 AI 公司的**基础模型 (FMs)** 的选择，并提供了一套广泛的能力，帮助您构建具备安全性、隐私保护和负责任 AI 的生成式 AI 应用程序。通过使用 `Amazon Bedrock`，您可以轻松地针对特定用例试验和评估顶级基础模型，使用微调（fine-tuning）和**检索增强生成 (Retrieval Augmented Generation, RAG)** 等技术使用您自己的数据对其进行私有化定制，并构建能够利用企业系统和数据源执行任务的智能体（Agent）。由于 `Amazon Bedrock` 是无服务器 (serverless) 的，您无需管理任何基础设施，并且可以使用您已经熟悉的 AWS 服务，安全地将生成式 AI 能力集成并部署到您的应用程序中。

from langchain_aws import BedrockLLM

### 自定义模型 (Custom models)

```python
custom_llm = BedrockLLM(
    credentials_profile_name="bedrock-admin",
    provider="cohere",
    model_id="<Custom model ARN>",  # ARN 格式如 'arn:aws:bedrock:...'，通过预置定制模型获得
    model_kwargs={"temperature": 1},
    streaming=True,
)

custom_llm.invoke(input="What is the recipe of mayonnaise?")
```

## Amazon Bedrock 的护栏 (Guardrails for Amazon Bedrock)

[Amazon Bedrock 的护栏](https://aws.amazon.com/bedrock/guardrails/)根据特定用例的策略评估用户的输入和模型的响应，并提供额外的安全保障层，而不受底层模型的影响。护栏可以应用于各种模型，包括 Anthropic Claude、Meta Llama 2、Cohere Command、AI21 Labs Jurassic 和 Amazon Titan Text，以及经过微调的模型。
在本节中，我们将设置一个带有特定护栏并包含**可追溯性/追踪能力 (tracing capabilities)** 的 Bedrock 语言模型。

```python
from typing import Any

from langchain_core.callbacks import AsyncCallbackHandler


class BedrockAsyncCallbackHandler(AsyncCallbackHandler):
    # 可用于处理来自 langchain 的回调的异步回调处理器。

    async def on_llm_error(self, error: BaseException, **kwargs: Any) -> Any:
        reason = kwargs.get("reason")
        if reason == "GUARDRAIL_INTERVENED":
            print(f"Guardrails: {kwargs}")


# 带有追踪功能的 Amazon Bedrock 护栏
llm = BedrockLLM(
    credentials_profile_name="bedrock-admin",
    model_id="<Model_ID>",
    model_kwargs={},
    guardrails={"id": "<Guardrail_ID>", "version": "<Version>", "trace": True},
    callbacks=[BedrockAsyncCallbackHandler()],
)
```
