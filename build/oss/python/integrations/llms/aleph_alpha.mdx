[Luminous 系列](https://docs.aleph-alpha.com/docs/category/luminous/) 是一系列大型语言模型（LLM）。

本示例介绍了如何使用 LangChain 与 Aleph Alpha 模型进行交互。

```python
# 安装使用该集成所需的 langchain 包
pip install -qU langchain-community
```

```python
# 安装该包
pip install -qU  aleph-alpha-client
```

```python
# 创建新令牌的链接：https://docs.aleph-alpha.com/docs/account/#create-a-new-token

from getpass import getpass

# 提示用户输入 API 密钥，输入内容不会被回显
ALEPH_ALPHA_API_KEY = getpass()
```

```output
········
```

```python
from langchain_community.llms import AlephAlpha
from langchain_core.prompts import PromptTemplate
```

```python
template = """问题：{question}

回答："""

prompt = PromptTemplate.from_template(template)
```

```python
llm = AlephAlpha(
    model="luminous-extended",  # 指定使用的模型名称
    maximum_tokens=20,          # 最大生成 token 数
    stop_sequences=["Q:"],      # 停止生成序列
    aleph_alpha_api_key=ALEPH_ALPHA_API_KEY, # 使用上面获取的 API 密钥
)
```

```python
llm_chain = prompt | llm
```

```python
question = "什么是 AI？"

llm_chain.invoke({"question": question})
```

```output
' 人工智能是机器对人类智能过程的模拟。\n\n'
```
