百川智能（Baichuan Inc.，官网：[www.baichuan-ai.com/](https://www.baichuan-ai.com/)）是一家处于通用人工智能（AGI）时代背景下的中国初创公司，致力于解决人类社会的基本需求：效率（Efficiency）、健康（Health）和幸福（Happiness）。

```python
## 安装使用集成所需的 langchain 包
pip install -qU langchain-community
```

## 先决条件 (Prerequisite)

访问百川大模型 API 需要一个 API 密钥。请访问 [platform.baichuan-ai.com/](https://platform.baichuan-ai.com/) 获取您的 API 密钥。

## 使用百川大模型 (Use Baichuan LLM)

```python
import os

os.environ["BAICHUAN_API_KEY"] = "YOUR_API_KEY"
```

```python
from langchain_community.llms import BaichuanLLM

# 加载模型
llm = BaichuanLLM()

res = llm.invoke("你叫什么名字？")
print(res)
```

```python
res = llm.generate(prompts=["你好！"])
res
```

```python
for res in llm.stream("第二次世界大战是谁赢的？"):
    print(res)
```

```python
import asyncio


async def run_aio_stream():
    async for res in llm.astream("写一首关于太阳的诗。"):
        print(res)


asyncio.run(run_aio_stream())
```
