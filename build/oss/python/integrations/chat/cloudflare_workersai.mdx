## 设置 (Setup)

要访问 CloudflareWorkersAI 模型，您需要创建一个 CloudflareWorkersAI 账户，获取一个 API 密钥，并安装 `langchain-cloudflare` 集成包。

### 凭证 (Credentials)

请访问 [www.cloudflare.com/developer-platform/products/workers-ai/](https://www.cloudflare.com/developer-platform/products/workers-ai/) 注册 CloudflareWorkersAI 并生成 API 密钥。完成操作后，设置 `CF_AI_API_KEY` 环境变量和 `CF_ACCOUNT_ID` 环境变量：

```python
import getpass
import os

if not os.getenv("CF_AI_API_KEY"):
    os.environ["CF_AI_API_KEY"] = getpass.getpass(
        "请输入您的 CloudflareWorkersAI API 密钥: "
    )

if not os.getenv("CF_ACCOUNT_ID"):
    os.environ["CF_ACCOUNT_ID"] = getpass.getpass(
        "请输入您的 CloudflareWorkersAI 账户 ID: "
    )
```

如果您希望对模型调用进行自动化的跟踪记录，可以通过取消注释以下代码来设置您的 [LangSmith](https://docs.smith.langchain.com/) API 密钥：

```python
os.environ["LANGSMITH_TRACING"] = "true"
os.environ["LANGSMITH_API_KEY"] = getpass.getpass("请输入您的 LangSmith API 密钥: ")
```

### 安装 (Installation)

LangChain 的 CloudflareWorkersAI 集成位于 `langchain-cloudflare` 包中：

```python
pip install -qU langchain-cloudflare
```

## 实例化 (Instantiation)

现在我们可以实例化模型对象并生成聊天补全（completions）：

- 使用相关参数更新模型实例化。

```python
from langchain_cloudflare.chat_models import ChatCloudflareWorkersAI

llm = ChatCloudflareWorkersAI(
    model="@cf/meta/llama-3.3-70b-instruct-fp8-fast",
    temperature=0,
    max_tokens=1024,
    # 其他参数...
)
```

## 调用 (Invocation)

```python
messages = [
    (
        "system",
        "你是一个乐于助人的助手，将英语翻译成法语。请翻译用户的句子。",
    ),
    ("human", "I love programming."),
]
ai_msg = llm.invoke(messages)
ai_msg
```

```output
AIMessage(content="J'adore la programmation.", additional_kwargs={}, response_metadata={'token_usage': {'prompt_tokens': 37, 'completion_tokens': 9, 'total_tokens': 46}, 'model_name': '@cf/meta/llama-3.3-70b-instruct-fp8-fast'}, id='run-995d1970-b6be-49f3-99ae-af4cdba02304-0', usage_metadata={'input_tokens': 37, 'output_tokens': 9, 'total_tokens': 46})
```

```python
print(ai_msg.content)
```

```output

```

## 结构化输出 (Structured Outputs)

```python
json_schema = {
    "title": "joke",
    "description": "讲给用户的笑话。",
    "type": "object",
    "properties": {
        "setup": {
            "type": "string",
            "description": "笑话的铺垫部分",
        },
        "punchline": {
            "type": "string",
            "description": "笑话的包袱（punchline）",
        },
        "rating": {
            "type": "integer",
            "description": "笑话的搞笑程度，范围从 1 到 10",
            "default": None,
        },
    },
    "required": ["setup", "punchline"],
}
structured_llm = llm.with_structured_output(json_schema)

structured_llm.invoke("给我讲个关于猫的笑话")
```

```output
{'setup': 'Why did the cat join a band?',
 'punchline': 'Because it wanted to be the purr-cussionist',
 'rating': '8'}
```

## 绑定工具 (Bind tools)

```python
from typing import List

from langchain.tools import tool


@tool
def validate_user(user_id: int, addresses: List[str]) -> bool:
    """使用历史地址验证用户。

    Args:
        user_id (int): 用户 ID。
        addresses (List[str]): 历史地址列表。
    """
    return True


llm_with_tools = llm.bind_tools([validate_user])

result = llm_with_tools.invoke(
    "你能验证一下用户 123 吗？他之前住在波士顿马萨诸塞州的 123 Fake St 和休斯顿德克萨斯州的 234 Pretend Boulevard。"
)
result.tool_calls
```

```output
[{'name': 'validate_user',
  'args': {'user_id': '123',
   'addresses': '["123 Fake St in Boston MA", "234 Pretend Boulevard in Houston TX"]'},
  'id': '31ec7d6a-9ce5-471b-be64-8ea0492d1387',
  'type': 'tool_call'}]
```
