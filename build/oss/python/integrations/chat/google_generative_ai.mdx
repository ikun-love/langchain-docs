## 设置

要访问 Google AI 模型，您需要创建一个 Google 帐户，获取一个 Google AI API 密钥，并安装 `langchain-google-genai` 集成包。

### 安装

```python
pip install -U langchain-google-genai
```

### 凭证

前往 [Google AI Studio](https://ai.google.dev/gemini-api/docs/api-key) 生成 Google AI API 密钥。生成后，请在您的环境中设置 `GOOGLE_API_KEY` 环境变量：

```python
import getpass
import os

if "GOOGLE_API_KEY" not in os.environ:
    os.environ["GOOGLE_API_KEY"] = getpass.getpass("输入您的 Google AI API 密钥: ")
```

要启用对模型调用的自动跟踪，请设置您的 [LangSmith](https://docs.smith.langchain.com/) API 密钥：

```python
os.environ["LANGSMITH_API_KEY"] = getpass.getpass("输入您的 LangSmith API 密钥: ")
os.environ["LANGSMITH_TRACING"] = "true"
```

### 文件上传

您可以将文件上传到 Google 的服务器，并通过 URI 引用它们。这对 PDF、图像、视频和音频文件都有效。

```python
import time
from google import genai
from langchain.messages import HumanMessage
from langchain_google_genai import ChatGoogleGenerativeAI

client = genai.Client()
model = ChatGoogleGenerativeAI(model="gemini-3-pro-preview")

# 上传文件到 Google 服务器
myfile = client.files.upload(file="/path/to/your/sample.pdf")
while myfile.state.name == "PROCESSING":
    time.sleep(2)
    myfile = client.files.get(name=myfile.name)

# 通过 URI 引用
message = HumanMessage(
    content=[
        {"type": "text", "text": "文档中有什么内容？"},
        {
            "type": "media",
            "file_uri": myfile.uri,
            "mime_type": "application/pdf",
        },
    ]
)
response = model.invoke([message])
```

### 图像生成

某些模型（如 `gemini-2.5-flash-image`）可以内联生成文本和图像。

有关详细信息，请参阅[Gemini API 文档](https://ai.google.dev/gemini-api/docs/image-generation)。

```python
import base64

from IPython.display import Image, display
from langchain.messages import AIMessage
from langchain_google_genai import ChatGoogleGenerativeAI, Modality

model = ChatGoogleGenerativeAI(model="gemini-2.5-flash-image")

message = {
    "role": "user",
    "content": "生成一只戴着帽子的可爱猫咪的照片级图像。",
}

model = ChatGoogleGenerativeAI(model="gemini-3-pro-preview")

response = model.invoke(
    [message],
    response_modalities=[Modality.TEXT, Modality.IMAGE],
)


def _get_image_base64(response: AIMessage) -> None:
    image_block = next(
        block
        for block in response.content
        if isinstance(block, dict) and block.get("image_url")
    )
    return image_block["image_url"].get("url").split(",")[-1]


image_base64 = _get_image_base64(response)
display(Image(data=base64.b64decode(image_base64), width=300))
```

## 工具调用

您可以为模型配备工具以供调用。

```python
from langchain.tools import tool
from langchain.messages import HumanMessage
from langchain_google_genai import ChatGoogleGenerativeAI


# 定义工具
@tool(description="获取给定地点的当前天气")
def get_weather(location: str) -> str:
    return "It's sunny."


# 初始化并绑定（可能多个）工具到模型
model_with_tools = ChatGoogleGenerativeAI(model="gemini-3-pro-preview").bind_tools([get_weather])

# 步骤 1: 模型生成工具调用
messages = [HumanMessage("波士顿天气如何？")]
ai_msg = model_with_tools.invoke(messages)
messages.append(ai_msg)

# 检查响应中的工具调用
print(ai_msg.tool_calls)

# 步骤 2: 执行工具并收集结果
for tool_call in ai_msg.tool_calls:
    # 使用生成的参数执行工具
    tool_result = get_weather.invoke(tool_call)
    messages.append(tool_result)

# 步骤 3: 将结果传回模型以获得最终响应
final_response = model_with_tools.invoke(messages)
final_response
```

```output
[{'name': 'get_weather', 'args': {'location': 'Boston'}, 'id': '879b4233-901b-4bbb-af56-3771ca8d3a75', 'type': 'tool_call'}]
```


## 结构化输出

强制模型以特定的结构响应。有关更多信息，请参阅[Gemini API 文档](https://ai.google.dev/gemini-api/docs/structured-output)。

```python
from langchain_google_genai import ChatGoogleGenerativeAI
from pydantic import BaseModel
from typing import Literal


class Feedback(BaseModel):
    sentiment: Literal["positive", "neutral", "negative"]
    summary: str


model = ChatGoogleGenerativeAI(model="gemini-3-pro-preview")
structured_model = model.with_structured_output(
    schema=Feedback.model_json_schema(), method="json_schema"
)

response = structured_model.invoke("新的 UI 很棒！")
response["sentiment"]  # "positive"
response["summary"]  # "用户表达了积极的..."
```

对于流式传输结构化输出，请合并字典而不是使用 `+=`：

```python
stream = structured_model.stream("界面直观且美观！")
full = next(stream)
for chunk in stream:
    full.update(chunk)  # 合并字典
print(full)  # 完整的结构化响应
# -> {'sentiment': 'positive', 'summary': '用户赞扬...'}
```

### 结构化输出方法

结构化输出支持两种方法：

- **`method="function_calling"` (默认)**：使用工具调用来提取结构化数据。
- **`method="json_schema"`**：使用 Gemini 的原生结构化输出。

`json_schema` 方法**推荐用于提高可靠性**，因为它直接约束模型的生成过程，而不是依赖事后处理工具调用。

## 思考支持 (Thinking Support)

对于推理模型，您可以选择调整使用的内部思考 Token 数量（`thinking_budget`），或者完全禁用思考。

<Warning>
    并非所有模型都允许禁用思考。有关详细信息，请参阅 [Gemini 模型文档](https://ai.google.dev/gemini-api/docs/models)。
</Warning>

要查看思考模型的“思考过程”，请设置 `include_thoughts=True`，以便将模型的推理摘要包含在响应中。

```python
from langchain_google_genai import ChatGoogleGenerativeAI

llm = ChatGoogleGenerativeAI(
    model="gemini-3-pro-preview",
    thinking_budget=1024, # [!code highlight]
    include_thoughts=True, # [!code highlight]
)

response = llm.invoke("Google 中有多少个 'O'？你是如何验证答案的？")
reasoning_score = response.usage_metadata["output_token_details"]["reasoning"]

print("响应:", response.content)
print("使用的推理 Token:", reasoning_score)
```
```output
响应: [{'type': 'thinking', 'thinking': '**Analyzing and Cou...'}, {'type': 'text', 'text': 'There a...', 'extras': {'signature': 'EroR...'}}]
使用的推理 Token: 672
```

有关思考的更多信息，请参阅[Gemini API 文档](https://ai.google.dev/gemini-api/docs/thinking)。

### 思维签名 (Thought Signatures)

[思维签名](https://ai.google.dev/gemini-api/docs/thinking) 是模型推理过程的加密表示。它们使 Gemini 能够在多轮对话中保持思维上下文，因为 API 是无状态的，将其视为每个请求独立处理。

<Note>
    如果未将思维签名随工具调用响应一起传回，Gemini 3 可能会抛出 4xx 错误。升级到 `langchain-google-genai >= 3.1.0` 以确保正确处理此问题。
</Note>

签名出现在 `AIMessage` 响应的两个位置：
- **文本块**: 存储在内容块内的 `extras.signature` 中
- **工具调用**: 存储在 `additional_kwargs["__gemini_function_call_thought_signatures__"]` 中

```python
from langchain_google_genai import ChatGoogleGenerativeAI

llm = ChatGoogleGenerativeAI(
    model="gemini-3-pro-preview",
    include_thoughts=True,
)

response = llm.invoke("Google 中有多少个 'O'？你是如何验证答案的？")

response.content_blocks[-1]
# -> {"type": "text", "text": "...", "extras": {"signature": "EtgVCt..."}}
```

对于带有工具调用的多轮对话，您必须将完整的 `AIMessage` 传回模型，以便保留签名。当您将 `AIMessage` 追加到消息列表中时，这会自动发生：

```python
from langchain.tools import tool
from langchain.messages import HumanMessage
from langchain_google_genai import ChatGoogleGenerativeAI


@tool
def get_weather(location: str) -> str:
    """获取某地点的当前天气。"""
    return f"Weather in {location}: sunny, 22°C"


model = ChatGoogleGenerativeAI(model="gemini-3-pro-preview").bind_tools([get_weather])
messages = [HumanMessage("东京天气如何？")]

# 步骤 1: 模型返回带有思维签名附加的工具调用
ai_msg = model.invoke(messages)
messages.append(ai_msg)  # 保留思维签名

# 步骤 2: 执行工具并添加结果
for tool_call in ai_msg.tool_calls:
    result = get_weather.invoke(tool_call)
    messages.append(result)

# 步骤 3: 模型接收到签名，继续连贯推理
final_response = model.invoke(messages)
```

<Warning>
    **不要手动重建消息。** 如果您创建了一个新的 `AIMessage` 而不是传递原始对象，签名将会丢失，API 可能会拒绝该请求。
</Warning>

## 安全设置

Gemini 模型具有默认的安全设置，可以被覆盖。如果您的模型收到大量“安全警告” (`'Safety Warnings'`)，您可以尝试调整模型的 `safety_settings` 属性。例如，要关闭对危险内容的安全性屏蔽，可以如下构造您的 LLM：

```python
from langchain_google_genai import (
    ChatGoogleGenerativeAI,
    HarmBlockThreshold,
    HarmCategory,
)

llm = ChatGoogleGenerativeAI(
        model="gemini-3-pro-preview",
        safety_settings={
        HarmCategory.HARM_CATEGORY_DANGEROUS_CONTENT: HarmBlockThreshold.BLOCK_NONE,
    },
)
```

有关可用的类别和阈值的枚举，请参阅 Google 的[安全设置类型](https://ai.google.dev/api/python/google/generativeai/types/SafetySettingDict)。

## 上下文缓存

上下文缓存允许您存储和重用内容（例如 PDF、图像）以加快处理速度。`cached_content` 参数接受一个通过 Google 生成式 AI API 创建的缓存名称。

<Accordion title="单个文件示例">

这会缓存单个文件并对其进行查询。

```python
import time
from google import genai
from google.genai import types
from langchain.messages import HumanMessage
from langchain_google_genai import ChatGoogleGenerativeAI

client = genai.Client()

# 上传文件
file = client.files.upload(file="path/to/your/file")
while file.state.name == "PROCESSING":
    time.sleep(2)
    file = client.files.get(name=file.name)

# 创建缓存
model = "gemini-3-pro-preview"
cache = client.caches.create(
    model=model,
    config=types.CreateCachedContentConfig(
        display_name="Cached Content",
        system_instruction=(
            "你是一位专业的内容分析师，你的工作是根据你所访问的文件回答用户的查询。"
        ),
        contents=[file],
        ttl="300s",
    ),
)

# 使用 LangChain 查询
llm = ChatGoogleGenerativeAI(
    model=model,
    cached_content=cache.name,
)
message = HumanMessage(content="总结内容的主要观点。")
llm.invoke([message])
```

</Accordion>

<Accordion title="多个文件示例">

这个例子使用 `Part` 缓存两个文件并一起查询它们。

```python
import time
from google import genai
from google.genai.types import CreateCachedContentConfig, Content, Part
from langchain.messages import HumanMessage
from langchain_google_genai import ChatGoogleGenerativeAI

client = genai.Client()

# 上传文件
file_1 = client.files.upload(file="./file1")
while file_1.state.name == "PROCESSING":
    time.sleep(2)
    file_1 = client.files.get(name=file_1.name)

file_2 = client.files.upload(file="./file2")
while file_2.state.name == "PROCESSING":
    time.sleep(2)
    file_2 = client.files.get(name=file_2.name)

# 使用多个文件创建缓存
contents = [
    Content(
        role="user",
        parts=[
            Part.from_uri(file_uri=file_1.uri, mime_type=file_1.mime_type),
            Part.from_uri(file_uri=file_2.uri, mime_type=file_2.mime_type),
        ],
    )
]
model = "gemini-3-pro-preview"
cache = client.caches.create(
    model=model,
    config=CreateCachedContentConfig(
        display_name="Cached Contents",
        system_instruction=(
            "你是一位专业的内容分析师，你的工作是根据你所访问的文件回答用户的查询。"
        ),
        contents=contents,
        ttl="300s",
    ),
)

# 使用 LangChain 查询
llm = ChatGoogleGenerativeAI(
    model=model,
    cached_content=cache.name,
)
message = HumanMessage(
    content="提供对两个文件中关键信息的总结。"
)
llm.invoke([message])
```

</Accordion>

有关更多信息，请参阅 Gemini API 文档中的[上下文缓存](https://ai.google.dev/gemini-api/docs/caching?lang=python)。
