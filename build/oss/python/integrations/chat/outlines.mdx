这将帮助您开始使用 Outlines [聊天模型](/oss/python/langchain/models/)。有关所有 ChatOutlines 功能和配置的详细文档，请访问 [API 参考](https://python.langchain.com/api_reference/community/chat_models/langchain_community.chat_models.outlines.ChatOutlines.html)。

[Outlines](https://github.com/outlines-dev/outlines) 是一个用于受约束语言生成的库。它允许您使用各种后端的[大型语言模型 (LLMs)](https://en.wikipedia.org/wiki/Large_language_model) (LLMs)，同时对生成的输出应用约束。

## 设置

要访问 Outlines 模型，您需要有互联网连接以下载模型权重自 huggingface。根据您使用的后端，您需要安装相应的依赖项（请参阅 [Outlines 文档](https://dottxt-ai.github.io/outlines/latest/installation/)）。

### 凭证 (Credentials)

Outlines 没有内置的身份验证机制。

### 安装

LangChain Outlines 集成位于 `langchain-community` 包中，并且需要 `outlines` 库：

```python
pip install -qU langchain-community outlines
```

## 实例化

现在我们可以实例化模型对象并生成对话补全：

```python
from langchain_community.chat_models.outlines import ChatOutlines

# 对于 llamacpp 后端
model = ChatOutlines(model="TheBloke/phi-2-GGUF/phi-2.Q4_K_M.gguf", backend="llamacpp")

# 对于 vllm 后端 (Mac 上不可用)
model = ChatOutlines(model="meta-llama/Llama-3.2-1B", backend="vllm")

# 对于 mlxlm 后端 (仅 Mac 上可用)
model = ChatOutlines(model="mistralai/Ministral-8B-Instruct-2410", backend="mlxlm")

# 对于 huggingface transformers 后端
model = ChatOutlines(model="microsoft/phi-2")  # 默认为 transformers 后端
```

## 调用 (Invocation)

```python
from langchain.messages import HumanMessage

messages = [HumanMessage(content="火星的首都是什么名字?")]
response = model.invoke(messages)

response.content
```

## 流式传输 (Streaming)

ChatOutlines 支持 Token 的流式传输：

```python
messages = [HumanMessage(content="用法文数到 10:")]

for chunk in model.stream(messages):
    print(chunk.content, end="", flush=True)
```

## 链式调用 (Chaining)

```python
from langchain_core.prompts import ChatPromptTemplate

prompt = ChatPromptTemplate.from_messages(
    [
        (
            "system",
            "你是一个乐于助人的助手，负责将 {input_language} 翻译成 {output_language}。",
        ),
        ("human", "{input}"),
    ]
)

chain = prompt | model
chain.invoke(
    {
        "input_language": "English",
        "output_language": "German",
        "input": "I love programming.",
    }
)
```

## 受约束的生成 (Constrained Generation)

ChatOutlines 允许您对生成的输出应用各种约束：

### 正则表达式约束 (Regex Constraint)

```python
model.regex = r"((25[0-5]|2[0-4]\d|[01]?\d\d?)\.){3}(25[0-5]|2[0-4]\d|[01]?\d\d?)"

response = model.invoke("Google DNS 服务器的 IP 地址是什么?")

response.content
```

### 类型约束 (Type Constraints)

```python
model.type_constraints = int
response = model.invoke("生命、宇宙以及一切的答案是什么?")

response.content
```

### Pydantic 和 JSON 模式

```python
from pydantic import BaseModel


class Person(BaseModel):
    name: str


model.json_schema = Person
response = model.invoke("LangChain 的主要贡献者是谁?")
person = Person.model_validate_json(response.content)

person
```

### 上下文无关文法 (Context Free Grammars)

```python
model.grammar = """
?start: expression
?expression: term (("+" | "-") term)*
?term: factor (("*" | "/") factor)*
?factor: NUMBER | "-" factor | "(" expression ")"
%import common.NUMBER
%import common.WS
%ignore WS
"""
response = model.invoke("给出一个复杂算术表达式:")

response.content
```

## LangChain 的结构化输出

您也可以将 LangChain 的结构化输出与 ChatOutlines 结合使用：

```python
from pydantic import BaseModel


class AnswerWithJustification(BaseModel):
    answer: str
    justification: str


_model = model.with_structured_output(AnswerWithJustification)
result = _model.invoke("一磅砖头和一磅羽毛哪个更重?")

result
```
