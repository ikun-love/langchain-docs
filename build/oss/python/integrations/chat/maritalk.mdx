MariTalk 是由巴西公司 [Maritaca AI](https://www.maritaca.ai) 开发的一款助手。
MariTalk 基于专门针对葡萄牙语进行了优化的语言模型。

本 Notebook 通过两个示例演示了如何使用 LangChain 和 MariTalk：

1.  一个简单的示例，展示如何使用 MariTalk 执行任务。
2.  LLM + RAG：第二个示例展示了如何回答一个答案可以在一个很长的文档中找到，但该文档内容超出了 MariTalk 的 Token 限制的问题。为此，我们将使用一个简单的搜索器（BM25）首先从文档中检索最相关的部分，然后将其提供给 MariTalk 进行回答。

### 示例 1 - 宠物名称建议

让我们定义语言模型 `ChatMaritalk`，并用您的 API 密钥对其进行配置。

```python
from langchain_community.chat_models import ChatMaritalk
from langchain_core.output_parsers import StrOutputParser
from langchain_core.prompts.chat import ChatPromptTemplate

llm = ChatMaritalk(
    model="sabia-2-medium",  # 可用模型: sabia-2-small 和 sabia-2-medium
    api_key="",  # 在此处插入您的 API 密钥
    temperature=0.7,
    max_tokens=100,
)

output_parser = StrOutputParser()

chat_prompt = ChatPromptTemplate.from_messages(
    [
        (
            "system",
            "你是一个专门建议宠物名称的助手。给定动物的种类，你必须推荐 4 个名字。",
        ),
        ("human", "我有一只 {animal}"),
    ]
)

chain = chat_prompt | llm | output_parser

response = chain.invoke({"animal": "dog"})
print(response)  # 应该会输出类似 "1. Max\n2. Bella\n3. Charlie\n4. Rocky" 的内容
```

### 流式生成 (Stream Generation)

对于涉及生成长文本的任务，例如创建一篇长文章或翻译一份大文档，当文本生成时，可以分块接收响应，而不是等待整个文本完成。这使得应用程序更具响应性和效率，特别是当生成的文本很长时。我们提供了两种方法来满足此需求：一种是同步方法，另一种是异步方法。

#### 同步 (Synchronous)

```python
from langchain.messages import HumanMessage

messages = [HumanMessage(content="Suggest 3 names for my dog")]

for chunk in llm.stream(messages):
    print(chunk.content, end="", flush=True)
```

#### 异步 (Asynchronous)

```python
from langchain.messages import HumanMessage


async def async_invoke_chain(animal: str):
    messages = [HumanMessage(content=f"Suggest 3 names for my {animal}")]
    async for chunk in llm._astream(messages):
        print(chunk.message.content, end="", flush=True)


await async_invoke_chain("dog")
```

#### 加载数据库

第一步是根据章程信息创建一个数据库。为此，我们将从 COMVEST 网站下载章程，并将提取的文本分割成 500 个字符的窗口。

```python
from langchain_community.document_loaders import OnlinePDFLoader
from langchain_text_splitters import RecursiveCharacterTextSplitter

# 加载 COMVEST 2024 章程
loader = OnlinePDFLoader(
    "https://www.comvest.unicamp.br/wp-content/uploads/2023/10/31-2023-Dispoe-sobre-o-Vestibular-Unicamp-2024_com-retificacao.pdf"
)
data = loader.load()

text_splitter = RecursiveCharacterTextSplitter(
    chunk_size=500, chunk_overlap=100, separators=["\n", " ", ""]
)
texts = text_splitter.split_documents(data)
```

#### 创建搜索器 (Searcher)

现在我们有了数据库，我们需要一个搜索器。在本例中，我们将使用一个简单的 BM25 作为搜索系统，但这可以替换为任何其他搜索器（例如，基于嵌入的搜索）。

```python
from langchain_community.retrievers import BM25Retriever

retriever = BM25Retriever.from_documents(texts)
```

#### 组合搜索系统和 LLM

现在我们有了搜索器，我们只需要实现一个指定任务的提示词 (prompt)，然后调用链 (chain)。

```python
from langchain.chains.question_answering import load_qa_chain

prompt = """Baseado nos seguintes documentos, responda a pergunta abaixo.

{context}

Pergunta: {query}
"""

qa_prompt = ChatPromptTemplate.from_messages([("human", prompt)])

chain = load_qa_chain(llm, chain_type="stuff", verbose=True, prompt=qa_prompt)

query = "Qual o tempo máximo para realização da prova?"

docs = retriever.invoke(query)

chain.invoke(
    {"input_documents": docs, "query": query}
)  # 应该输出类似 "O tempo máximo para realização da prova é de 5 horas." 的内容
```
