本文档将指导您开始使用 AWS Bedrock [聊天模型](/oss/python/langchain/models)。Amazon Bedrock 是一项全托管服务，通过单一 API 提供了来自 AI21 Labs、Anthropic、Cohere、Meta、Stability AI 和 Amazon 等领先 AI 公司的多种高性能基础模型（FMs）的选择，以及构建生成式 AI 应用所需的广泛功能，同时确保安全、隐私和负责任的 AI。借助 Amazon Bedrock，您可以轻松地针对您的用例试验和评估顶级 FM，使用微调（fine-tuning）和检索增强生成（RAG）等技术利用您的数据对其进行私有定制，并构建利用您的企业系统和数据源来执行任务的智能体（agents）。由于 Amazon Bedrock 是无服务器的，您无需管理任何基础设施，并且可以使用您已经熟悉的 AWS 服务安全地将生成式 AI 功能集成并部署到您的应用程序中。

AWS Bedrock 维护着一个 [Converse API](https://docs.aws.amazon.com/bedrock/latest/APIReference/API_runtime_Converse.html)，它为 Bedrock 模型提供了一个统一的会话式接口。此 API **目前**还不支持自定义模型。您可以在 [此处](https://docs.aws.amazon.com/bedrock/latest/userguide/conversation-inference.html)查看所有受支持的 [模型列表](https://docs.aws.amazon.com/bedrock/latest/userguide/conversation-inference.html)。

<Info>
**我们推荐不使用自定义模型的使用者采用 Converse API。它可以通过 [ChatBedrockConverse](https://python.langchain.com/api_reference/aws/chat_models/langchain_aws.chat_models.bedrock_converse.ChatBedrockConverse.html) 访问。**

</Info>

如需了解所有 Bedrock 功能和配置的详细文档，请访问 [API 参考](https://python.langchain.com/api_reference/aws/chat_models/langchain_aws.chat_models.bedrock_converse.ChatBedrockConverse.html)。

## 设置

要访问 Bedrock 模型，您需要创建一个 AWS 账户，设置 Bedrock API 服务，获取访问密钥 ID（access key ID）和密钥（secret key），并安装 `langchain-aws` 集成包。

### 凭证 (Credentials)

请访问 [AWS 文档](https://docs.aws.amazon.com/bedrock/latest/userguide/setting-up.html) 注册 AWS 并设置您的凭证。

或者，`ChatBedrockConverse` 默认会读取以下环境变量：

```python
# os.environ["AWS_ACCESS_KEY_ID"] = "..."
# os.environ["AWS_SECRET_ACCESS_KEY"] = "..."

# 仅在使用临时凭证时需要。
# os.environ["AWS_SESSION_TOKEN"] = "..."
```

您还需要为您的账户开启模型访问权限，可以通过遵循 [这些说明](https://docs.aws.amazon.com/bedrock/latest/userguide/model-access.html) 来完成。

要启用对模型调用的自动追踪，请设置您的 [LangSmith](https://docs.smith.langchain.com/) API 密钥：

```python
os.environ["LANGSMITH_API_KEY"] = getpass.getpass("请输入您的 LangSmith API 密钥: ")
os.environ["LANGSMITH_TRACING"] = "true"
```

### 安装

LangChain 的 Bedrock 集成位于 `langchain-aws` 包中：

```python
pip install -qU langchain-aws
```

## 实例化

现在我们可以实例化模型对象并生成聊天补全：

```python
from langchain_aws import ChatBedrockConverse

llm = ChatBedrockConverse(
    model_id="anthropic.claude-3-5-sonnet-20240620-v1:0",
    # region_name=...,
    # aws_access_key_id=...,
    # aws_secret_access_key=...,
    # aws_session_token=...,
    # temperature=...,
    # max_tokens=...,
    # 其他参数...
)
```

## 扩展思考 (Extended Thinking)

本指南重点介绍了如何使用 LangChain 的 `ChatBedrockConverse` 集成在 AWS Bedrock 上实现扩展思考。

### 支持的模型

扩展思考支持 AWS Bedrock 上的以下 Claude 模型：

| 模型 | 模型 ID |
|-------|----------|
| **Claude Opus 4** | `anthropic.claude-opus-4-20250514-v1:0` |
| **Claude Sonnet 4** | `anthropic.claude-sonnet-4-20250514-v1:0` |
| **Claude 3.7 Sonnet** | `us.anthropic.claude-3-7-sonnet-20250219-v1:0` |

```python
from langchain_aws import ChatBedrockConverse

llm = ChatBedrockConverse(
    model_id="us.anthropic.claude-sonnet-4-20250514-v1:0",
    region_name="us-west-2",
    max_tokens=4096,
    additional_model_request_fields={
        "thinking": {"type": "enabled", "budget_tokens": 1024},
    },
)

ai_msg = llm.invoke(messages)
ai_msg.content_blocks
```

next_messages = messages + [("ai", ai_msg.content), ("human", "I love AI")]

ai_msg = llm.invoke(next_messages)

## 提示缓存 (Prompt Caching)

Bedrock 支持对提示（prompt）的元素进行[缓存](https://docs.aws.amazon.com/bedrock/latest/userguide/prompt-caching.html)，包括消息和工具。这允许您重复使用大型文档、指令、[少样本示例](/langsmith/create-few-shot-evaluators) 和其他数据，以减少延迟和成本。

<Note>
**并非所有模型都支持提示缓存。请在[此处](https://docs.aws.amazon.com/bedrock/latest/userguide/prompt-caching.html#prompt-caching-models)查看支持的模型列表。**

</Note>

要在提示的某个元素上启用缓存，请使用 `cachePoint` 键标记其关联的内容块。请看下面的示例：

```python
import requests
from langchain_aws import ChatBedrockConverse

llm = ChatBedrockConverse(model="us.anthropic.claude-sonnet-4-5-20250929-v1:0")

# 拉取 LangChain README 文件
get_response = requests.get(
    "https://raw.githubusercontent.com/langchain-ai/langchain/master/README.md"
)
readme = get_response.text

messages = [
    {
        "role": "user",
        "content": [
            {
                "type": "text",
                "text": "根据其 README 文件，LangChain 是什么？",
            },
            {
                "type": "text",
                "text": f"{readme}",
            },
            {
                "cachePoint": {"type": "default"},
            },
        ],
    },
]

response_1 = llm.invoke(messages)
response_2 = llm.invoke(messages)

usage_1 = response_1.usage_metadata["input_token_details"]
usage_2 = response_2.usage_metadata["input_token_details"]

print(f"第一次调用:\n{usage_1}")
print(f"\n第二次调用:\n{usage_2}")
```

```output
第一次调用:
{'cache_creation': 1528, 'cache_read': 0}

第二次调用:
{'cache_creation': 0, 'cache_read': 1528}
```

## 引用 (Citations)

如果输入文档启用了引用，则可以生成引用。文档可以采用 Bedrock 的[原生格式](https://docs.aws.amazon.com/bedrock/latest/APIReference/API_runtime_DocumentBlock.html)或 LangChain 的[标准类型](/oss/python/langchain/messages#multimodal)来指定：

<CodeGroup>
```python Bedrock 格式
from langchain_aws import ChatBedrockConverse

llm = ChatBedrockConverse(model="us.anthropic.claude-sonnet-4-20250514-v1:0")

pdf_path = "path/to/your/file.pdf"

with open(pdf_path, "rb") as f:
    pdf_bytes = f.read()

document = {
    "document": {
        "format": "pdf",
        "source": {"bytes": pdf_bytes},
        "name": "my-pdf",
        "citations": {"enabled": True},  # [!code highlight]
    },
}

response = llm.invoke(
    [
        {
            "role": "user",
            "content": [
                {"type": "text", "text": "描述此文档。"},
                document,
            ]
        },
    ]
)
response.content_blocks
```

```python LangChain 标准格式
import base64
from langchain_aws import ChatBedrockConverse

llm = ChatBedrockConverse(model="us.anthropic.claude-sonnet-4-20250514-v1:0")

pdf_path = "path/to/your/file.pdf"

with open(pdf_path, "rb") as f:
    pdf_base64 = base64.b64encode(f.read()).decode("utf-8")

document = {
    "type": "file",
    "mime_type": "application/pdf",
    "base64": pdf_base64,
    "name": "my-pdf",  # Converse 需要文件名
    "citations": {"enabled": True},  # [!code highlight]
}

response = llm.invoke(
    [
        {
            "role": "user",
            "content": [
                {"type": "text", "text": "描述此文档。"},
                document,
            ]
        },
    ]
)
response.content_blocks
```
</CodeGroup>
