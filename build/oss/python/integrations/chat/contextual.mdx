## 设置

要访问 Contextual 模型，您需要创建一个 Contextual AI 账户，获取一个 API 密钥，并安装 `langchain-contextual` 集成包。

### 凭证 (Credentials)

前往 [app.contextual.ai](https://app.contextual.ai) 注册 Contextual 并生成 API 密钥。完成之后，设置 `CONTEXTUAL_AI_API_KEY` 环境变量：

```python
import getpass
import os

if not os.getenv("CONTEXTUAL_AI_API_KEY"):
    os.environ["CONTEXTUAL_AI_API_KEY"] = getpass.getpass(
        "Enter your Contextual API key: "
    )
```

如果您希望对模型调用进行自动化的追踪记录，您可以通过取消注释以下代码来设置您的 [LangSmith](https://docs.smith.langchain.com/) API 密钥：

```python
os.environ["LANGSMITH_TRACING"] = "true"
os.environ["LANGSMITH_API_KEY"] = getpass.getpass("Enter your LangSmith API key: ")
```

### 安装

LangChain Contextual 集成位于 `langchain-contextual` 包中：

```python
pip install -qU langchain-contextual
```

## 实例化 (Instantiation)

现在我们可以实例化我们的模型对象并生成聊天补全（chat completions）。

聊天客户端可以通过以下附加设置进行实例化：

| 参数 (Parameter) | 类型 (Type) | 描述 (Description) | 默认值 (Default) |
| :--- | :--- | :--- | :--- |
| temperature | Optional[float] | 采样温度，它会影响响应中的随机性。请注意，较高的 temperature 值可能会降低基于事实的准确性（groundedness）。 | 0 |
| top_p | Optional[float] | 核心采样（nucleus sampling）的参数，这是 temperature 之外影响响应随机性的另一种方法。请注意，较高的 top_p 值可能会降低基于事实的准确性。 | 0.9 |
| max_new_tokens | Optional[int] | 模型在响应中可以生成的最大 token 数量。最小值为 1，最大值为 2048。 | 1024 |

```python
from langchain_contextual import ChatContextual

llm = ChatContextual(
    model="v1",  # 默认为 `v1`
    api_key="",
    temperature=0,  # 默认为 0
    top_p=0.9,  # 默认为 0.9
    max_new_tokens=1024,  # 默认为 1024
)
```

## 调用 (Invocation)

在调用 `ChatContextual.invoke` 方法时，Contextual 基于事实大语言模型（GLM）接受额外的 `kwargs`（关键字参数）。

这些额外的输入是：

| 参数 (Parameter) | 类型 (Type) | 描述 (Description) |
| :--- | :--- | :--- |
| knowledge | list[str] | 必需：模型在生成响应时可以使用的知识源字符串列表。 |
| system_prompt | Optional[str] | 可选：模型在生成响应时应遵循的指令。请注意，我们不保证模型会完全遵循这些指令。 |
| avoid_commentary | Optional[bool] | 可选（默认为 `False`）：一个标志位，用于指示模型是否应避免在响应中提供额外的评论或解说。评论性质上是对话性的，不包含可验证的主张；因此，评论不严格基于可用的上下文。然而，评论可能会提供有助于提高响应有用性的背景信息。 |

```python
# 包含系统提示（可选）
system_prompt = "You are a helpful assistant that uses all of the provided knowledge to answer the user's query to the best of your ability."

# 在此处提供您知识库中的知识，格式为字符串数组
knowledge = [
    "There are 2 types of dogs in the world: good dogs and best dogs.",
    "There are 2 types of cats in the world: good cats and best cats.",
]

# 创建您的消息
messages = [
    ("human", "What type of cats are there in the world and what are the types?"),
]

# 通过提供知识字符串、可选的系统提示来调用 GLM
# 如果您想关闭 GLM 的评论功能，请向 `avoid_commentary` 参数传递 True
ai_msg = llm.invoke(
    messages, knowledge=knowledge, system_prompt=system_prompt, avoid_commentary=True
)

print(ai_msg.content)
```

## 链式调用 (Chaining)

我们可以将 Contextual 模型与输出解析器（output parsers）链接起来。

```python
from langchain_core.output_parsers import StrOutputParser

chain = llm | StrOutputParser

chain.invoke(
    messages, knowledge=knowledge, systemp_prompt=system_prompt, avoid_commentary=True
)
```
