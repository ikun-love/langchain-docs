## 设置 (Setup)

要访问 Qwen 模型，您需要创建一个阿里云账户，获取一个 API 密钥 (API key)，并安装 `langchain-qwq` 集成包。

### 凭证 (Credentials)

请访问 [阿里云 API 密钥页面](https://account.alibabacloud.com/login/login.htm?oauth_callback=https%3A%2F%2Fbailian.console.alibabacloud.com%2F%3FapiKey%3D1&lang=en#/api-key) 注册阿里云账户并生成 API 密钥。完成此操作后，设置 `DASHSCOPE_API_KEY` 环境变量：

```python
import getpass
import os

if not os.getenv("DASHSCOPE_API_KEY"):
    os.environ["DASHSCOPE_API_KEY"] = getpass.getpass("Enter your Dashscope API key: ")
```

### 安装 (Installation)

LangChain Qwen 集成位于 `langchain-qwq` 包中：

```python
pip install -qU langchain-qwq
```

## 实例化 (Instantiation)

现在我们可以实例化模型对象并生成聊天补全 (chat completions)：

```python
from langchain_qwq import ChatQwen

llm = ChatQwen(
    model="qwen-flash",
    max_tokens=3_000,
    timeout=None,
    max_retries=2,
    # other params...
)
```

## 工具调用 (Tool Calling)

ChatQwen 支持工具调用 API，它允许您描述工具及其参数，并让模型返回一个包含要调用的工具及其输入的 JSON 对象。

### 与 `bind_tools` 一起使用 (Use with `bind_tools`)

```python
from langchain.tools import tool
from langchain_qwq import ChatQwen


@tool
def multiply(first_int: int, second_int: int) -> int:
    """Multiply two integers together."""
    return first_int * second_int


llm = ChatQwen(model="qwen-flash")

llm_with_tools = llm.bind_tools([multiply])

msg = llm_with_tools.invoke("What's 5 times forty two")

print(msg)
```

### 视觉支持 (Vision Support)
#### 图像 (Image)
```python
from langchain.messages import HumanMessage

model = ChatQwen(model="qwen-vl-max-latest")

messages = [
    HumanMessage(content=[
        {
            "type": "image_url",
            "image_url": {
                "url": "https://example.com/image/image.png"
            },
        },
        {"type": "text", "text": "What do you see in this image?"},
    ])
]

response = model.invoke(messages)
print(response)
```
