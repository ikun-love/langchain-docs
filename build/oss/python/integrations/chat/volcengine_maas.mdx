title: VolcEngineMaas 聊天模型
---

本指南将指导您如何开始使用火山引擎（VolcEngine）的 Maas 聊天模型。

```python
# 安装包
pip install -qU  volcengine
```

```python
from langchain_community.chat_models import VolcEngineMaasChat
from langchain.messages import HumanMessage
```

```python
chat = VolcEngineMaasChat(volc_engine_maas_ak="您的 ak", volc_engine_maas_sk="您的 sk")
```

或者，您也可以在环境变量中设置 `access_key` 和 `secret_key`：

```bash
export VOLC_ACCESSKEY=您的AK
export VOLC_SECRETKEY=您的SK
```

```python
chat([HumanMessage(content="给我讲个笑话")])
```

```output
AIMessage(content='好的，这是一个笑话：\n\n为什么鸟儿不会玩电脑游戏？\n\n因为它们没有翅膀！')
```

# 使用流式输出（Stream）进行 VolcEngine Maas 聊天

```python
chat = VolcEngineMaasChat(
    volc_engine_maas_ak="您的 ak",
    volc_engine_maas_sk="您的 sk",
    streaming=True,
)
```

```python
chat([HumanMessage(content="给我讲个笑话")])
```

```output
AIMessage(content='好的，这是一个笑话：\n\n三岁的女儿说她会造句了，妈妈让她用“年轻”造句，女儿说：“妈妈减肥，一年轻了好几斤”。')
```
