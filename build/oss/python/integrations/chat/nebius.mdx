## 设置

要访问 Nebius 模型，你需要创建一个 Nebius 账户，获取一个 API 密钥，并安装 `langchain-nebius` 集成包。

### 安装

可以通过 pip 安装 Nebius 集成：

```python
pip install -U langchain-nebius
```

### 凭证 (Credentials)

Nebius 需要一个 API 密钥，该密钥可以作为初始化参数 `api_key` 传入，或者设置为环境变量 `NEBIUS_API_KEY`。你可以在 [Nebius AI Studio](https://studio.nebius.ai/) 创建账户以获取 API 密钥。

```python
import getpass
import os

# 确保你的 API 密钥已设置为环境变量
if "NEBIUS_API_KEY" not in os.environ:
    os.environ["NEBIUS_API_KEY"] = getpass.getpass("Enter your Nebius API key: ")
```

## 实例化 (Instantiation)

现在我们可以实例化模型对象来生成聊天补全内容：

```python
from langchain_nebius import ChatNebius

# 初始化聊天模型
chat = ChatNebius(
    # api_key="YOUR_API_KEY",  # 你可以直接传入 API 密钥
    model="Qwen/Qwen3-14B",  # 从可用模型中选择
    temperature=0.6,
    top_p=0.95,
)
```

## 调用 (Invocation)

你可以使用 `invoke` 方法从模型获取补全结果：

```python
response = chat.invoke("用简单的术语解释一下量子计算")
print(response.content)
```

```output
量子计算是一种使用**量子力学**原理来处理信息的计算类型，其处理方式是经典计算机无法做到的。以下是一个简单的分解：

### 1. **比特 vs. 量子比特 (Bits vs. Qubits)**
   - **经典计算机**使用*比特*（bits），它们就像只能是**0**（关）或**1**（开）的开关。
   - **量子计算机**使用*量子比特*（qubits），它们就像“旋转的硬币”。在旋转时，量子比特可以是**0**、**1**，或**两者同时存在**（这被称为**叠加态** (superposition)）。只有当你“观察”（测量）量子比特时，它才会稳定到一个确定的状态（0 或 1）。

### 2. **叠加态：同时做很多事情**
   - 想象一枚在空中旋转的硬币。当它旋转时，它既不是“正面”也不是“反面”——它是两者的混合。
   - 利用量子比特，量子计算机可以**同时处理许多可能性**。例如，如果你有 2 个量子比特，它们可以同时表示 4 种状态（00、01、10、11）。有 10 个量子比特，就可以同时表示 **1,024 种状态**！这使得量子计算机能够比经典计算机快得多地解决某些问题。

### 3. **纠缠：量子比特相互“对话”**
   - 当量子比特**纠缠**时，它们的状态是相互关联的。如果你测量其中一个，无论它们相距多远，另一个都会瞬间受到影响。
   - 这种连接使得量子计算机能够更高效地执行复杂的计算，就像解决那些相互关联性很强（深度耦合）的难题一样。

### 4. **为什么它很重要**
   - **速度**：对于特定任务（如破解加密代码或模拟分子），量子计算机可能比经典计算机**快得多**（指数级加速）。
   - **新机遇**：它们有可能彻底改变药物发现、材料科学以及优化问题（例如，为送货卡车寻找最佳路线）。

### 5. **局限性**
   - **脆弱**：量子比特对环境（热量、噪声）非常敏感，因此量子计算机需要极低的冷却温度（接近绝对零度）才能工作。
   - **不能替代**：它们不擅长日常任务，如浏览网页或发送电子邮件。它们是用于**专业化任务**的工具，而这些任务正是经典计算机所不擅长的。

### 简而言之：
量子计算就像拥有一个魔术计算器，可以同时探索许多路径，在几秒钟内解决传统计算机需要数年才能解决的某些问题。但它仍处于早期阶段，需要精心维护才能正确运行！ 🌌
```

### 聊天消息 (Chat Messages)

你可以使用不同的消息类型来构建与模型的对话：

```python
from langchain.messages import AIMessage, HumanMessage, SystemMessage

messages = [
    SystemMessage(content="你是一个乐于助人的 AI 助手，专长于科学领域。"),
    HumanMessage(content="什么是黑洞？"),
    AIMessage(
        content="黑洞是时空区域，那里的引力极其强大，以至于任何东西，包括光，都无法从中逃逸。"
    ),
    HumanMessage(content="它们是如何形成的？"),
]

response = chat.invoke(messages)
print(response.content)
```

```output

黑洞是通过大质量恒星的坍缩或其他极端天体物理过程形成的。以下是主要形成机制的分类：

---

### **1. 恒星级黑洞 (最常见)**
- **起源**：大质量恒星（通常**超过太阳质量的 20-25 倍**）。
- **过程**：
  1. **恒星演化**：这些恒星在数百万年间燃烧其核燃料（氢、氦等）。
  2. **超新星爆发**：当恒星耗尽燃料时，它无法再抵抗引力。核心坍缩，引发**超新星爆发**（巨大的恒星爆炸）。
  3. **核心坍缩**：如果剩余的核心（在超新星爆发后）的质量**超过太阳质量的大约 3 倍**，引力将压倒所有其他力。核心坍缩成一个被称为**奇点**（singularity）的无限密集的点，周围环绕着一个**事件视界**（光和物质的“不归点”）。

### **2. 超大质量黑洞 (位于星系中心)**
- **质量**：太阳质量的数百万到数十亿倍。
- **形成理论**：
  - **吸积 (Accretion)**：它们可能通过数十亿年来逐渐积累物质（气体、尘埃、恒星）而形成。
  - **合并**：较小的黑洞（或致密星团）可能会合并形成超大质量黑洞。
  - **直接坍缩**：一些理论认为，它们可能来自早期宇宙中巨大气体云的直接坍缩，绕过了恒星的生命周期。

---

### **3. 中等质量黑洞**
- **质量**：数百到数千个太阳质量。
- **形成**：了解较少。它们可能通过恒星级黑洞的合并或异常大质量恒星的坍缩形成。

- **起源**：宇宙大爆炸后（最初的几秒内）。
- **形成**：如果早期宇宙中的密度波动足够极端，某些区域可能直接坍缩成黑洞，而无需经历恒星生命周期。
- **状态**：这些仍然是理论上的，尚未被明确观测到。

### **关键概念**
- **事件视界 (Event Horizon)**：黑洞周围的边界，任何东西（包括光）都无法逃脱。
- **奇点 (Singularity)**：黑洞无限致密的内核，我们所知的物理定律在那里失效。
- **引力坍缩 (Gravitational Collapse)**：引力将物质压缩到极小空间的过程，形成了黑洞的极端条件。
```

### 参数 (Parameters)

你可以使用各种参数来自定义聊天模型的行为：

```python
# 使用自定义参数初始化
custom_chat = ChatNebius(
    model="meta-llama/Llama-3.3-70B-Instruct-fast",
    max_tokens=100,  # 限制响应长度
    top_p=0.01,  # 较低的核采样参数，使响应更具确定性
    request_timeout=30,  # 超时时间（秒）
    stop=["###", "\n\n"],  # 自定义停止序列
)

response = custom_chat.invoke("用恰好 3 句话解释一下 DNA 是什么。")
print(response.content)
```

### 异步支持 (Async Support)

ChatNebius 支持异步操作：

```python
import asyncio


async def generate_async():
    response = await chat.ainvoke("法国的首都是哪里？")
    print("Async response:", response.content)

    # 异步流式传输
    print("\nAsync streaming:")
    async for chunk in chat.astream("德国的首都是哪里？"):
        print(chunk.content, end="", flush=True)


await generate_async()
```

## 链接 (Chaining)

你可以在 LangChain 的链（chains）和代理（agents）中使用 `ChatNebius`：

```python
from langchain_core.output_parsers import StrOutputParser
from langchain_core.prompts import ChatPromptTemplate

# 创建一个提示模板
prompt = ChatPromptTemplate.from_messages(
    [
        (
            "system",
            "你是一个乐于助人的助手，以 {character} 的风格回答。",
        ),
        ("human", "{query}"),
    ]
)

# 创建一个链
chain = prompt | chat | StrOutputParser()

# 调用链
response = chain.invoke(
    {"character": "莎士比亚", "query": "解释一下互联网是如何运作的"}
)

print(response)
```
