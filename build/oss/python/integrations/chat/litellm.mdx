[LiteLLM](https://github.com/BerriAI/litellm) 是一个简化调用 Anthropic、Azure、Huggingface、Replicate 等服务的库。

本教程涵盖了如何开始使用 LangChain + LiteLLM I/O 库。

此集成包含两个主要类：

- `ChatLiteLLM`: 用于 LiteLLM 基本用法的 LangChain 包装器（[文档](https://docs.litellm.ai/docs/)）。
- `ChatLiteLLMRouter`: 一个 `ChatLiteLLM` 的包装器，它利用了 LiteLLM 的 Router 功能（[文档](https://docs.litellm.ai/docs/routing)）。

### 设置 (Setup)

要访问 `ChatLiteLLM` 和 `ChatLiteLLMRouter` 模型，您需要安装 `langchain-litellm` 包，并创建 OpenAI、Anthropic、Azure、Replicate、OpenRouter、Hugging Face、Together AI 或 Cohere 账户。然后，您必须获取 API 密钥并将其导出为环境变量。

## 凭证 (Credentials)

您需要选择要使用的 LLM 提供商，注册账户以获取其 API 密钥。

### 示例 - Anthropic

前往 [Claude 控制台](https://console.anthropic.com) 注册并生成 Claude API 密钥。执行此操作后，设置 `ANTHROPIC_API_KEY` 环境变量：

### 示例 - OpenAI

前往 [platform.openai.com/api-keys](https://platform.openai.com/api-keys) 注册 OpenAI 账户并生成 API 密钥。执行此操作后，设置 OPENAI_API_KEY 环境变量。

```python
## 设置环境变量 (Set ENV variables)
import os

os.environ["OPENAI_API_KEY"] = "your-openai-key"
os.environ["ANTHROPIC_API_KEY"] = "your-anthropic-key"
```

### 安装 (Installation)

LangChain LiteLLM 集成在 `langchain-litellm` 包中可用：

```python
pip install -qU langchain-litellm
```

## 实例化 (Instantiation)

### ChatLiteLLM

您可以通过提供一个 LiteLLM [支持的模型名称](https://docs.litellm.ai/docs/providers) 来实例化 `ChatLiteLLM` 模型。

```python
from langchain_litellm import ChatLiteLLM

llm = ChatLiteLLM(model="gpt-4.1-nano", temperature=0.1)
```

### ChatLiteLLMRouter

您还可以通过定义模型列表（如 [此处](https://docs.litellm.ai/docs/routing) 指定）来利用 LiteLLM 的路由功能。

```python
from langchain_litellm import ChatLiteLLMRouter
from litellm import Router

model_list = [
    {
        "model_name": "gpt-4.1",
        "litellm_params": {
            "model": "azure/gpt-4.1",
            "api_key": "<your-api-key>",
            "api_version": "2024-10-21",
            "api_base": "https://<your-endpoint>.openai.azure.com/",
        },
    },
    {
        "model_name": "gpt-4o",
        "litellm_params": {
            "model": "azure/gpt-4o",
            "api_key": "<your-api-key>",
            "api_version": "2024-10-21",
            "api_base": "https://<your-endpoint>.openai.azure.com/",
        },
    },
]
litellm_router = Router(model_list=model_list)
llm = ChatLiteLLMRouter(router=litellm_router, model_name="gpt-4.1", temperature=0.1)
```

## 调用 (Invocation)

无论您实例化的是 `ChatLiteLLM` 还是 `ChatLiteLLMRouter`，现在都可以通过 LangChain 的 API 使用聊天模型。

```python
response = await llm.ainvoke(
    "将文本分类为中性、负面或正面。文本：我觉得食物还行。情感："
)
print(response)
```

## 异步和流式功能 (Async and Streaming Functionality)

`ChatLiteLLM` 和 `ChatLiteLLMRouter` 也支持异步和流式传输功能：

```python
async for token in llm.astream("你好，请解释一下抗生素是如何起作用的"):
    print(token.text(), end="")
```
