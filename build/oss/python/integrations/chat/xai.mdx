## 设置

要访问 xAI 模型，您需要创建一个 xAI 账户，获取一个 API 密钥，并安装 `langchain-xai` 集成包。

### 凭证 (Credentials)

访问 [此页面](https://console.x.ai/) 注册 xAI 并生成一个 API 密钥。完成此操作后，请设置 `XAI_API_KEY` 环境变量：

```python
import getpass
import os

if "XAI_API_KEY" not in os.environ:
    os.environ["XAI_API_KEY"] = getpass.getpass("Enter your xAI API key: ")
```

要启用对您的模型调用的自动追踪，可以设置您的 [LangSmith](https://docs.smith.langchain.com/) API 密钥：

```python
os.environ["LANGSMITH_API_KEY"] = getpass.getpass("Enter your LangSmith API key: ")
os.environ["LANGSMITH_TRACING"] = "true"
```

### 安装

LangChain 的 xAI 集成位于 `langchain-xai` 包中：

```python
pip install -qU langchain-xai
```

## 实例化

现在我们可以实例化模型对象并生成聊天补全：

```python
from langchain_xai import ChatXAI

llm = ChatXAI(
    model="grok-beta",
    temperature=0,
    max_tokens=None,
    timeout=None,
    max_retries=2,
    # other params...
)
```

## 调用 (Invocation)

```python
messages = [
    (
        "system",
        "你是一个乐于助人的助手，负责将英语翻译成法语。请翻译用户输入的句子。",
    ),
    ("human", "I love programming."),
]
ai_msg = llm.invoke(messages)
```


## 工具调用 (Tool calling)

ChatXAI 具有一个 [工具调用](https://docs.x.ai/docs#capabilities) API（在此我们交替使用“工具调用”和“函数调用”），它允许您描述工具及其参数，并让模型返回一个包含要调用的工具和该工具输入的 JSON 对象。工具调用对于构建使用工具的链和代理，以及更普遍地从模型中获取结构化输出来说极其有用。

### ChatXAI.bind_tools()

使用 `ChatXAI.bind_tools`，我们可以轻松地将 Pydantic 类、字典 Schema、LangChain 工具甚至函数作为工具传递给模型。在底层，这些会被转换为 OpenAI 工具 Schema，其结构如下：

```
{
    "name": "...",
    "description": "...",
    "parameters": {...}  # JSONSchema
}
```

并在每次模型调用中传入。

```python
from pydantic import BaseModel, Field


class GetWeather(BaseModel):
    """获取指定地点的当前天气"""

    location: str = Field(..., description="城市和州，例如：San Francisco, CA")


llm_with_tools = llm.bind_tools([GetWeather])
```

```python
ai_msg = llm_with_tools.invoke(
    "what is the weather like in San Francisco",
)
ai_msg
```

```output
AIMessage(content='I am retrieving the current weather for San Francisco.', additional_kwargs={'tool_calls': [{'id': '0', 'function': {'arguments': '{"location":"San Francisco, CA"}', 'name': 'GetWeather'}, 'type': 'function'}], 'refusal': None}, response_metadata={'token_usage': {'completion_tokens': 11, 'prompt_tokens': 151, 'total_tokens': 162, 'completion_tokens_details': None, 'prompt_tokens_details': None}, 'model_name': 'grok-beta', 'system_fingerprint': 'fp_14b89b2dfc', 'finish_reason': 'tool_calls', 'logprobs': None}, id='run-73707da7-afec-4a52-bee1-a176b0ab8585-0', tool_calls=[{'name': 'GetWeather', 'args': {'location': 'San Francisco, CA'}, 'id': '0', 'type': 'tool_call'}], usage_metadata={'input_tokens': 151, 'output_tokens': 11, 'total_tokens': 162, 'input_token_details': {}, 'output_token_details': {}})
```

## 实时搜索 (Live Search)

xAI 支持 [实时搜索 (Live Search)](https://docs.x.ai/docs/guides/live-search) 功能，该功能使 Grok 能够利用网络搜索结果来充实其答案：

```python
from langchain_xai import ChatXAI

llm = ChatXAI(
    model="grok-3-latest",
    search_parameters={
        "mode": "auto",
        # 示例可选参数如下：
        "max_search_results": 3,
        "from_date": "2025-05-26",
        "to_date": "2025-05-27",
    },
)

llm.invoke("Provide me a digest of world news in the last 24 hours.")
```

有关完整的网络搜索选项集，请参阅 [xAI 文档](https://docs.x.ai/docs/guides/live-search)。
