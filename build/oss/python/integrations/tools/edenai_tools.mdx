本 Jupyter Notebook 演示了如何将 Eden AI 工具与 Agent 结合使用。

Eden AI 正在通过整合顶尖的 AI 提供商，彻底改变人工智能格局，使用户能够释放无限潜力并挖掘人工智能的真正能力。借助这个一体化、全面且便捷的平台，用户可以极速将 AI 功能部署到生产环境，并通过单一 API 轻松访问全方位的 AI 能力。（网站：[edenai.co/](https://edenai.co/) ）

通过在提供给 Agent 的工具列表中包含一个 Edenai 工具，您可以赋予 Agent 执行多项任务的能力，例如：

- 语音转文本 (speech to text)
- 文本转语音 (text to speech)
- 文本显性内容检测 (text explicit content detection)
- 图像显性内容检测 (image explicit content detection)
- 物体检测 (object detection)
- OCR 发票解析 (OCR invoice parsing)
- OCR 身份信息解析 (OCR ID parsing)

在这个示例中，我们将介绍利用 Edenai 工具创建能够执行上述部分任务的 Agent 的过程。

---------------------------------------------------------------------------
访问 EDENAI 的 API 需要一个 API 密钥，

您可以通过创建账户 [app.edenai.run/user/register](https://app.edenai.run/user/register) 并转到此处 [app.edenai.run/admin/account/settings](https://app.edenai.run/admin/account/settings) 获取该密钥。

获得密钥后，我们需要将其设置为环境变量 `EDENAI_API_KEY`，或者您可以在初始化 EdenAI 工具时直接通过 `edenai_api_key` 命名的参数传入密钥，例如 `EdenAiTextModerationTool(edenai_api_key="...")`。

```python
from langchain_community.tools.edenai import (
    EdenAiExplicitImageTool,
    EdenAiObjectDetectionTool,
    EdenAiParsingIDTool,
    EdenAiParsingInvoiceTool,
    EdenAiSpeechToTextTool,
    EdenAiTextModerationTool,
    EdenAiTextToSpeechTool,
)
```

```python
from langchain.agents import AgentType, initialize_agent
from langchain_community.llms import EdenAI

llm = EdenAI(
    feature="text", provider="openai", params={"temperature": 0.2, "max_tokens": 250}
)

tools = [
    EdenAiTextModerationTool(providers=["openai"], language="en"),
    EdenAiObjectDetectionTool(providers=["google", "api4ai"]),
    EdenAiTextToSpeechTool(providers=["amazon"], language="en", voice="MALE"),
    EdenAiExplicitImageTool(providers=["amazon", "google"]),
    EdenAiSpeechToTextTool(providers=["amazon"]),
    EdenAiParsingIDTool(providers=["amazon", "klippa"], language="en"),
    EdenAiParsingInvoiceTool(providers=["amazon", "google"], language="en"),
]
agent_chain = initialize_agent(
    tools,
    llm,
    agent=AgentType.ZERO_SHOT_REACT_DESCRIPTION,
    verbose=True,
    return_intermediate_steps=True,
)
```

result = agent_chain(input_)
