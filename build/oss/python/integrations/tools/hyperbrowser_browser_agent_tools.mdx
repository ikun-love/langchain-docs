[Hyperbrowser](https://hyperbrowser.ai) 是一个用于运行、管理浏览器代理（Browser Agents）和扩展无头浏览器（Headless Browsers）的平台。它允许您大规模启动和管理浏览器会话，并为任何网页抓取需求（例如抓取单个页面或爬取整个网站）提供易于使用的解决方案。

主要功能：

- 即时可扩展性 - 在几秒钟内启动数百个浏览器会话，无需处理基础设施的麻烦
- 简单集成 - 与 Puppeteer 和 Playwright 等流行工具无缝协作
- 强大的 API - 易于使用的 API，用于抓取/爬取任何网站，以及更多功能
- 绕过反机器人措施 - 内置隐身模式、广告拦截、自动 CAPTCHA 求解和代理轮换

本指南提供了使用 Hyperbrowser 工具的快速入门概览。

有关 Hyperbrowser 的更多信息，请访问 [Hyperbrowser 网站](https://hyperbrowser.ai)；如果您想查看文档，可以访问 [Hyperbrowser 文档](https://docs.hyperbrowser.ai)。

## 浏览器代理 (Browser Agents)

Hyperbrowser 提供了强大的浏览器代理工具，使 AI 模型能够以编程方式与 Web 浏览器进行交互。这些浏览器代理可以导航网站、填写表单、点击按钮、提取数据并执行复杂的 Web 自动化任务。

浏览器代理在以下场景中特别有用：

- 从复杂网站进行 Web 抓取和数据提取
- 自动化重复性的 Web 任务
- 与需要身份验证的 Web 应用程序进行交互
- 跨多个网站进行研究
- 测试 Web 应用程序

Hyperbrowser 提供了三种类型的浏览器代理工具：

- **Browser Use Tool (浏览器使用工具)**：一个通用的浏览器自动化工具
- **OpenAI CUA Tool (OpenAI CUA 工具)**：与 OpenAI 的计算机使用代理 (Computer Use Agent, CUA) 集成
- **Claude Computer Use Tool (Claude 计算机使用工具)**：与 Anthropic 的 Claude 的计算机使用功能集成

## 设置 (Setup)

要使用 Hyperbrowser 工具，您需要安装 `langchain-hyperbrowser` 集成包，并创建一个 Hyperbrowser 账户并获取 API 密钥。

### 凭证 (Credentials)

前往 [Hyperbrowser](https://app.hyperbrowser.ai/) 注册并生成 API 密钥。完成此操作后，设置 `HYPERBROWSER_API_KEY` 环境变量：

```bash
export HYPERBROWSER_API_KEY=<your-api-key>
```

### 安装 (Installation)

安装 **langchain-hyperbrowser**。

```python
pip install -qU langchain-hyperbrowser
```

## 实例化 (Instantiation)

### Browser Use Tool

`HyperbrowserBrowserUseTool` 是一个工具，用于使用浏览器代理（特别是 Browser-Use 代理）来执行 Web 自动化任务。

```python
from langchain_hyperbrowser import HyperbrowserBrowserUseTool
tool = HyperbrowserBrowserUseTool()
```

### OpenAI CUA Tool

`HyperbrowserOpenAICUATool` 是一个专业工具，它通过 Hyperbrowser 利用 OpenAI 计算机使用代理 (CUA) 的能力。

```python
from langchain_hyperbrowser import HyperbrowserOpenAICUATool
tool = HyperbrowserOpenAICUATool()
```

### Claude Computer Use Tool

`HyperbrowserClaudeComputerUseTool` 是一个专业工具，它通过 Hyperbrowser 利用 Claude 的计算机使用能力。

```python
from langchain_hyperbrowser import HyperbrowserClaudeComputerUseTool
tool = HyperbrowserClaudeComputerUseTool()
```

### 使用自定义会话选项 (With Custom Session Options)

所有工具都支持自定义会话选项：

```python
result = tool.run(
    {
        "task": "Go to npmjs.com, and tell me when react package was last updated.",
        "session_options": {
            "session_options": {"use_proxy": True, "accept_cookies": True}
        },
    }
)
print(result)
```

```output
{'data': 'I have found that the react package was last published 11 hours ago. This is the most recently updated package I could find.', 'error': None}
```

### 异步用法 (Async Usage)

所有工具都支持异步调用：

```python
async def browse_website():
    tool = HyperbrowserBrowserUseTool()
    result = await tool.arun(
        {
            "task": "Go to npmjs.com, click the first visible package, and tell me when it was updated"
        }
    )
    return result


result = await browse_website()
```


## 在代理中使用 (Use within an agent)

以下是如何在代理中使用任何 Hyperbrowser 工具的示例：

```python
from langchain.prompts import ChatPromptTemplate, MessagesPlaceholder
from langchain_hyperbrowser import browser_use_tool
from langchain_openai import ChatOpenAI
from langchain.agents import create_agent


model = ChatOpenAI(temperature=0)

# 您可以在此处使用上述三个工具中的任何一个
browser_use_tool = HyperbrowserBrowserUseTool()
agent = create_agent(model, [browser_use_tool])

user_input = "Go to npmjs.com, and tell me when react package was last updated."
for step in agent.stream(
    {"messages": user_input},
    stream_mode="values",
):
    step["messages"][-1].pretty_print()
```

## 配置选项 (Configuration Options)

Claude Computer Use、OpenAI CUA 和 Browser Use 具有以下可用参数：

- `task`: 使用代理执行的任务
- `max_steps`: 代理完成任务可以采取的最大交互步骤数
- `session_options`: 浏览器会话配置
