## 初始化

### 进行身份验证

1. 创建一个 [ClickUp 应用](https://help.clickup.com/hc/en-us/articles/6303422883095-Create-your-own-app-with-the-ClickUp-API)
2. 按照[这些步骤](https://clickup.com/api/developer-portal/authentication/)获取您的 `client_id` 和 `client_secret`。
    - *建议: 使用 `https://google.com` 作为 `redirect_uri`。这是本工具包默认采用的设置。*
3. 复制/粘贴它们，并运行下一个单元格以获取您的 `code`

```python
# Copilot 沙盒
oauth_client_id = "ABC..."
oauth_client_secret = "123..."
redirect_uri = "https://google.com"

print("点击此链接，选择您的工作区，然后点击 `Connect Workspace`")
print(ClickupAPIWrapper.get_access_code_url(oauth_client_id, redirect_uri))
```

```output
点击此链接，选择您的工作区，然后点击 `Connect Workspace`
https://app.clickup.com/api?client_id=ABC...&redirect_uri=https://google.com
```

该 URL 应该会变为类似以下形式：[www.google.com/?code=THISISMYCODERIGHTHERE](https://www.google.com/?code=THISISMYCODERIGHTHERE)。

接下来，将 URL 中生成的 `CODE` (THISISMYCODERIGHTHERE) 复制/粘贴到下面的单元格中。

```python
code = "THISISMYCODERIGHTHERE"
```

### 获取访问令牌 (Access Token)

然后，使用下面的代码获取您的 `access_token`。

*重要提示*: 每个代码只能使用一次，并在使用后过期。`access_token` 可以使用一段时间。请务必在获取到 `access_token` 后复制粘贴保存！

```python
access_token = ClickupAPIWrapper.get_access_token(
    oauth_client_id, oauth_client_secret, code
)
```

```output
Error: {'err': 'Code already used', 'ECODE': 'OAUTH_014'}
您已经使用过此代码一次。请返回上一步重新生成一个新代码。
我们猜测获取新代码的 URL 是：
https://app.clickup.com/api?client_id=B5D61F8EVO04PR0JX0U73984LLS9GI6P&redirect_uri=https://google.com
```

```python
# 初始化工具包
clickup_api_wrapper = ClickupAPIWrapper(access_token=access_token)
toolkit = ClickupToolkit.from_clickup_api_wrapper(clickup_api_wrapper)
print(
    f"找到 team_id: {clickup_api_wrapper.team_id}.\n大多数请求都需要 team id，因此我们将其存储在工具包中，我们假设列表中的第一个团队是您想要的团队。 \n注意：如果您知道这个 ID 是错误的，您可以在初始化时传入正确的 ID。"
)
```

```output
找到 team_id: 9011010153.
```

### 创建代理 (Agent)

```python
llm = OpenAI(temperature=0, openai_api_key="")

agent = initialize_agent(
    toolkit.get_tools(), llm, agent=AgentType.ZERO_SHOT_REACT_DESCRIPTION, verbose=True
)
```

## 使用代理

```python
# 示例的辅助函数
def print_and_run(command):
    print("\033[94m$ COMMAND\033[0m")
    print(command)
    print("\n\033[94m$ AGENT\033[0m")
    response = agent.run(command)
    print("".join(["-"] * 80))
    return response
```
