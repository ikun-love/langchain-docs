---
title: Golden 查询
---

>[Golden](https://golden.com) 提供了一套自然语言 API，用于利用 Golden 知识图谱进行查询和信息丰富。例如，可以使用类似下面的查询来检索相关的结构化数据：`来自 OpenAI 的产品`、`获得 A 轮融资的生成式 AI 公司`，以及 `进行投资的说唱歌手`。
>
> `golden-query` LangChain 工具是 [Golden 查询 API](https://docs.golden.com/reference/query-api) 的一个封装层，它使得可以对这些结果进行编程访问。
> 有关更多信息，请参阅 [Golden 查询 API 文档](https://docs.golden.com/reference/query-api)。

本 Notebook 将介绍如何使用 `golden-query` 工具。

- 前往 [Golden API 文档](https://docs.golden.com/) 了解 Golden API 的概述。
- 从 [Golden API 设置](https://golden.com/settings/api) 页面获取您的 API 密钥。
- 将您的 API 密钥保存到 `GOLDEN_API_KEY` 环境变量中。

```python
pip install -qU langchain-community
```

```python
import os

os.environ["GOLDEN_API_KEY"] = ""
```

```python
from langchain_community.utilities.golden_query import GoldenQueryAPIWrapper
```

```python
golden_query = GoldenQueryAPIWrapper()
```

```python
import json

json.loads(golden_query.run("nanotech 领域的公司"))
```
