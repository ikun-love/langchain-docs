> [Steam (维基百科)](https://en.wikipedia.org/wiki/Steam_(service)) 是由 `Valve Corporation` 开发的一款电子游戏数字发行服务和商店。它会自动为 Valve 的游戏提供更新，后来扩展到分发第三方游戏。`Steam` 提供各种功能，例如带有 Valve 反作弊措施的游戏服务器匹配、社交网络和游戏串流服务。

>[Steam](https://store.steampowered.com/about/) 是游玩、讨论和创作游戏的终极平台。

Steam 工具包包含两个工具：

- `游戏详情` (`Game Details`)
- `推荐游戏` (`Recommended Games`)

本指南将引导您完成使用 LangChain 调用 Steam API 的过程，以便根据您当前的 Steam 游戏库存获取游戏推荐，或者收集您提供的特定 Steam 游戏的信息。

## 设置 (Setting up)

我们需要安装两个 Python 库。

## 导入 (Imports)

```python
pip install -qU python-steam-api python-decouple steamspypi
```

## 分配环境变量 (Assign Environmental Variables)

要使用此工具包，请准备好您的 OpenAI API 密钥、Steam API 密钥（可从 [此处](https://steamcommunity.com/dev/apikey) 获取）以及您的 SteamID。收到 Steam API 密钥后，您可以将其作为以下环境变量进行输入。
该工具包将读取 "STEAM_KEY" API 密钥作为环境变量来进行身份验证，因此请在此处设置它们。您还需要设置您的 "OPENAI_API_KEY" 和 "STEAM_ID"。

```python
import os

os.environ["STEAM_KEY"] = ""
os.environ["STEAM_ID"] = ""
os.environ["OPENAI_API_KEY"] = ""
```

## 初始化 (Initialization)

初始化 LLM、`SteamWebAPIWrapper`、`SteamToolkit`，以及最重要的是用于处理您查询的 LangChain 智能体 (agent)！

## 示例 (Example)

```python
from langchain_community.agent_toolkits.steam.toolkit import SteamToolkit
from langchain_community.utilities.steam import SteamWebAPIWrapper

steam = SteamWebAPIWrapper()
tools = [steam.run]
```

```python
from langchain.agents import create_agent

agent = create_agent("gpt-4.1-mini", tools)
```

```python
events = agent.stream(
    {"messages": [("user", "can you give the information about the game Terraria?")]},
    stream_mode="values",
)
for event in events:
    event["messages"][-1].pretty_print()
```
