[Bright Data](https://brightdata.com/) 提供了一个功能强大的 Web Scraper API，它允许您从 100 多个热门域名中提取结构化数据，例如亚马逊产品详情、领英个人资料等。这使得它对于需要可靠结构化网络数据源的 AI 智能体特别有用。

## 设置

该集成位于 `langchain-brightdata` 包中。

```python
pip install langchain-brightdata
```

要使用此工具，您需要一个 Bright Data API 密钥。您可以将其设置为环境变量：

```python
import os

os.environ["BRIGHT_DATA_API_KEY"] = "your-api-key"
```

或者在初始化工具时直接传入：

```python
from langchain_brightdata import BrightDataWebScraperAPI

scraper_tool = BrightDataWebScraperAPI(bright_data_api_key="your-api-key")
```

## 实例化

以下展示了如何实例化 `BrightDataWebScraperAPI` 工具。此工具允许您使用 Bright Data 的数据集 API，从包括亚马逊产品详情、领英个人资料等在内的各种网站中提取结构化数据。

该工具支持在实例化时传入多种参数：

- `bright_data_api_key` (必需, str): 您的 Bright Data API 密钥，用于身份验证。
- `dataset_mapping` (可选, Dict[str, str]): 一个字典，用于将数据集类型映射到其对应的 Bright Data 数据集 ID。默认映射包括：
  - "amazon_product": "gd_l7q7dkf244hwjntr0"
  - "amazon_product_reviews": "gd_le8e811kzy4ggddlq"
  - "linkedin_person_profile": "gd_l1viktl72bvl7bjuj0"
  - "linkedin_company_profile": "gd_l1vikfnt1wgvvqz95w"

## 调用

### 基本用法

```python
from langchain_brightdata import BrightDataWebScraperAPI

# 初始化工具
scraper_tool = BrightDataWebScraperAPI(
    bright_data_api_key="your-api-key"  # 如果已设置环境变量则可以省略
)

# 提取亚马逊产品数据
results = scraper_tool.invoke(
    {"url": "https://www.amazon.com/dp/B08L5TNJHG", "dataset_type": "amazon_product"}
)

print(results)
```

### 高级用法与参数传递

```python
from langchain_brightdata import BrightDataWebScraperAPI

# 使用默认参数初始化
scraper_tool = BrightDataWebScraperAPI(bright_data_api_key="your-api-key")

# 提取具有特定地区定价的亚马逊产品数据
results = scraper_tool.invoke(
    {
        "url": "https://www.amazon.com/dp/B08L5TNJHG",
        "dataset_type": "amazon_product",
        "zipcode": "10001",  # 获取纽约市的定价信息
    }
)

print(results)

# 提取领英个人资料数据
linkedin_results = scraper_tool.invoke(
    {
        "url": "https://www.linkedin.com/in/satyanadella/",
        "dataset_type": "linkedin_person_profile",
    }
)

print(linkedin_results)
```

## 定制化选项

`BrightDataWebScraperAPI` 工具接受多个参数以进行定制：

|参数名|类型|描述|
|:--|:--|:--|
|`url`|str|要从中提取数据的 URL|
|`dataset_type`|str|使用的数据集类型（例如："amazon_product"）|
|`zipcode`|str|用于获取特定地区数据的可选邮政编码|

## 可用的数据集类型

该工具支持以下数据集类型用于结构化数据提取：

|数据集类型|描述|
|:--|:--|
|`amazon_product`|提取详细的亚马逊产品数据|
|`amazon_product_reviews`|提取亚马逊产品评论|
|`linkedin_person_profile`|提取领英个人资料数据|
|`linkedin_company_profile`|提取领英公司资料数据|

## 在 Agent 中使用

```python
from langchain_brightdata import BrightDataWebScraperAPI
from langchain_google_genai import ChatGoogleGenerativeAI
from langchain.agents import create_agent


# 初始化 LLM
llm = ChatGoogleGenerativeAI(model="gemini-2.5-flash", google_api_key="your-api-key")

# 初始化 Bright Data Web Scraper API 工具
scraper_tool = BrightDataWebScraperAPI(bright_data_api_key="your-api-key")

# 使用工具创建 Agent
agent = create_agent(llm, [scraper_tool])

# 提供用户查询
user_input = "Scrape Amazon product data for https://www.amazon.com/dp/B0D2Q9397Y?th=1 in New York (zipcode 10001)."

# 流式输出 Agent 的分步结果
for step in agent.stream(
    {"messages": user_input},
    stream_mode="values",
):
    step["messages"][-1].pretty_print()
```
