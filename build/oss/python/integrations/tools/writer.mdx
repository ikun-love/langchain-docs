### 功能特性

`ChatWriter` 支持多种工具类型：`function`（函数），`graph`（知识图谱），`translation`（翻译）和 `web_search`（网络搜索）。

> **重要限制**: 您一次只能使用一个 WRITER 工具（翻译、知识图谱、网络搜索、LLM、图像、视觉）。虽然不能组合多个 WRITER 工具，但您可以将一个 WRITER 工具与多个自定义函数工具一起使用。

#### 函数 (Function)

函数是工具中最常见的一种类型，它允许 LLM 调用外部 API、从数据库中获取数据，以及执行您希望执行的任何外部操作。请访问 WRITER 的 [工具调用文档](https://dev.writer.com/home/tool-calling) 以获取更多信息。

#### 知识图谱 (Graph)

`Graph` 工具使用 WRITER 的知识图谱（Knowledge Graph），这是一个基于图的检索增强生成 (RAG) 系统。当使用此工具时，开发者提供一个图 ID，该 ID 引用其特定的知识图谱。然后，模型使用该图来查找相关信息，并针对提示中的问题生成准确的答案。这使得模型能够在对话中访问和利用自定义知识库。如需了解更多详情，请参阅 WRITER 的 [知识图谱 API 文档](https://dev.writer.com/home/knowledge-graph)。

#### 翻译 (Translation)

翻译工具允许您在与 Palmyra 模型对话期间翻译文本。虽然 Palmyra X 模型可以执行翻译任务，但它们并非为此类任务进行优化，在没有正确提示的情况下性能可能不佳。有关更多信息，请参阅 WRITER 的 [翻译 API 文档](https://dev.writer.com/home/translation-tool#translate-text-in-a-chat)。

#### 网络搜索 (Web Search)

网络搜索工具允许您在与 Palmyra 模型对话期间搜索网页以获取最新信息。虽然 Palmyra 模型拥有广泛的知识，但它们可能无法访问最新的信息或实时数据。网络搜索工具使您的 AI 助手能够从网络上查找最新的信息、新闻和事实。有关更多信息，请参阅 WRITER 的 [网络搜索 API 文档](https://dev.writer.com/home/web-search-tool#web-search-in-a-chat)。

## 设置

注册 [WRITER AI Studio](https://app.writer.com/aistudio/signup?utm_campaign=devrel) 以生成 API 密钥（您可以遵循此 [快速入门指南](https://dev.writer.com/home/quickstart)）。然后，设置 `WRITER_API_KEY` 环境变量：

```python
import getpass
import os

if not os.getenv("WRITER_API_KEY"):
    os.environ["WRITER_API_KEY"] = getpass.getpass("输入您的 WRITER API 密钥: ")
```

## 用法

您可以将知识图谱或函数工具绑定到 `ChatWriter`。

### 知识图谱工具 (Graph Tools)

要绑定知识图谱工具，首先使用您想用作数据源的 `graph_ids` 来创建并初始化 `GraphTool` 实例：

```python
from langchain_writer.chat_models import ChatWriter
from langchain_writer.tools import GraphTool

chat = ChatWriter()

graph_id = getpass.getpass("输入 WRITER 知识图谱 ID: ")
graph_tool = GraphTool(graph_ids=[graph_id])
```

### 翻译工具 (Translation Tools)

翻译工具允许您在与 Palmyra 模型对话期间翻译文本。虽然 Palmyra X 模型可以执行翻译任务，但它们并非为此类任务进行优化，在没有正确提示的情况下性能可能不佳。

要使用翻译工具，请导入并初始化内置的 `TranslationTool`：

```python
from langchain_writer.tools import TranslationTool

# 初始化翻译工具
translation_tool = TranslationTool()
```

### 网络搜索工具 (Web Search Tools)

网络搜索工具允许您在与 Palmyra 模型对话期间搜索网页以获取最新信息。虽然 Palmyra 模型拥有广泛的知识，但它们可能无法访问最新的信息或实时数据。网络搜索工具使您的 AI 助手能够从网络上查找最新的信息、新闻和事实。

要使用网络搜索工具，请导入并初始化内置的 `WebSearchTool`：

```python
from langchain_writer.tools import WebSearchTool

# 使用可选配置初始化网络搜索工具
web_search_tool = WebSearchTool(
    include_domains=["wikipedia.org", "github.com", "techcrunch.com"],
    exclude_domains=["quora.com"]
)
```

## 实例化 (Instantiation)

```python
from langchain.tools import tool
from pydantic import BaseModel, Field


@tool
def get_supercopa_trophies_count(club_name: str) -> int | None:
    """返回有关超级杯奖杯数量的信息。

    Args:
        club_name: 您想要查询超级杯奖杯数量的俱乐部名称

    Returns:
        超级杯奖杯数量，如果找不到所请求俱乐部的相关信息则返回 None
    """

    if club_name == "Barcelona":
        return 15
    elif club_name == "Real Madrid":
        return 13
    elif club_name == "Atletico Madrid":
        return 2
    else:
        return None


class GetWeather(BaseModel):
    """获取指定地点的当前天气"""

    location: str = Field(..., description="城市和州，例如 San Francisco, CA")


get_product_info = {
    "type": "function",
    "function": {
        "name": "get_product_info",
        "description": "通过 ID 获取产品信息",
        "parameters": {
            "type": "object",
            "properties": {
                "product_id": {
                    "type": "number",
                    "description": "要检索信息的产品的唯一标识符",
                }
            },
            "required": ["product_id"],
        },
    },
}
```

### 绑定工具 (Binding tools)

**重要提示**: WRITER 一次只允许绑定一个 WRITER 工具（翻译、知识图谱、网络搜索、LLM、图像、视觉）。您不能同时绑定多个 WRITER 工具。但是，您可以将多个自定义函数工具与一个 WRITER 工具一起绑定。

```python
# ✅ 正确：一个 WRITER 工具 + 多个函数工具
llm_with_tools = chat.bind_tools(
    [graph_tool, get_supercopa_trophies_count, GetWeather, get_product_info]
)

# ✅ 正确：不同的 WRITER 工具 + 函数工具
llm_with_tools = chat.bind_tools(
    [translation_tool, get_supercopa_trophies_count, GetWeather]
)

# ❌ 错误：多个 WRITER 工具（将导致 BadRequestError）
llm_with_tools = chat.bind_tools(
    [graph_tool, translation_tool, web_search_tool]  # 这将失败
)
```

如果您需要使用不同的 WRITER 工具，您可以选择以下几种方案：

**方案 1：为每次对话重新绑定工具**：

```python
# 用于一次对话，使用知识图谱工具
llm_with_tools = chat.bind_tools([graph_tool, get_supercopa_trophies_count])
response1 = llm_with_tools.invoke([HumanMessage("使用知识图谱工具回答...")])

# 切换到翻译工具进行另一次对话
llm_with_tools = chat.bind_tools([translation_tool, get_supercopa_trophies_count])
response2 = llm_with_tools.invoke([HumanMessage("翻译这段文本...")])
```

**方案 2：使用独立的 ChatWriter 实例**：

```python
# 为不同的工具创建独立的 ChatWriter 实例
chat_with_graph = ChatWriter()
llm_with_graph_tool = chat_with_graph.bind_tools([graph_tool])

chat_with_translation = ChatWriter()
llm_with_translation_tool = chat_with_translation.bind_tools([translation_tool])
```

## 调用 (Invocation)

在调用（调用）时，模型将自动选择工具（支持流式/非流式、同步/异步所有模式）。

```python
from langchain.messages import HumanMessage

# 使用知识图谱工具和函数工具的示例
llm_with_tools = chat.bind_tools([graph_tool, get_supercopa_trophies_count])
messages = [
    HumanMessage(
        "使用知识图谱工具来撰写此答案。告诉我知识图谱中存储的文档的第一行是什么。另外，我想知道：巴塞罗那赢得了多少次超级杯奖杯？"
    )
]

response = llm_with_tools.invoke(messages)
messages.append(response)

# 使用翻译工具的示例
llm_with_translation = chat.bind_tools([translation_tool])
translation_messages = [
    HumanMessage("将 'Hello, world!' 翻译成西班牙语")
]

translation_response = llm_with_translation.invoke(translation_messages)
print(translation_response.content)  # 输出: "¡Hola, mundo!"

# 使用网络搜索工具的示例
llm_with_search = chat.bind_tools([web_search_tool])
search_messages = [
    HumanMessage("AI 技术有哪些最新进展？请搜索网络以获取当前信息。")
]

search_response = llm_with_search.invoke(search_messages)
print(search_response.content)  # 输出: 基于网络搜索的当前 AI 进展
```

在函数工具的情况下，您将收到一个包含工具调用请求的助手消息。

```python
print(response.tool_calls)
```

然后您可以手动处理工具调用请求，发送给模型并接收最终响应：

```python
for tool_call in response.tool_calls:
    selected_tool = {
        "get_supercopa_trophies_count": get_supercopa_trophies_count,
    }[tool_call["name"].lower()]
    tool_msg = selected_tool.invoke(tool_call)
    messages.append(tool_msg)

response = llm_with_tools.invoke(messages)
print(response.content)
```

对于 `GraphTool`，模型将远程调用它，并在 `additional_kwargs` 中 `graph_data` 键下返回使用信息：

```python
print(response.additional_kwargs["graph_data"])
```

`content` 属性包含最终响应：

```python
print(response.content)
```

## 链式调用 (Chaining)

WRITER 知识图谱工具与其他工具的工作方式不同；当使用它时，WRITER 服务器会自动处理调用知识图谱并使用 RAG 生成响应。由于这种自动化的服务器端处理，您不能单独调用 `GraphTool` 或将其用作 LangChain 链的一部分。您必须如上例所示，直接将 `GraphTool` 与 `ChatWriter` 实例一起使用。
