> [Lemon Agent](https://github.com/felixbrock/lemon-agent) 帮助您在几分钟内部署强大的 AI 助手，并通过在 `Airtable`, `Hubspot`, `Discord`, `Notion`, `Slack` 和 `GitHub` 等工具中实现准确可靠的读取和写入操作来自动化工作流程。

[查看完整文档](https://github.com/felixbrock/lemonai-py-client)。

目前大多数可用的连接器都专注于只读操作，这限制了 LLM 的潜力。另一方面，由于缺少上下文或指令，Agent 可能会不时出现“幻觉”（即生成不准确或虚构的信息）。

有了 `Lemon AI`，就可以为您的 Agent 提供对定义明确的 API 的访问权限，以实现可靠的读写操作。此外，`Lemon AI` 函数还提供了一种静态定义工作流的方法，当模型不确定时可以依赖这些工作流，从而进一步降低产生幻觉的风险。

## 快速开始

以下快速入门示例演示了如何将 Lemon AI 与 Agent 结合使用，以自动化涉及与内部工具交互的工作流程。

### 1. 安装 Lemon AI

要求 Python 3.8.1 及以上版本。

要在您的 Python 项目中使用 Lemon AI，请运行 `pip install lemonai`

这将安装相应的 Lemon AI 客户端，然后您可以将其导入到您的脚本中。

该工具使用 Python 包 `langchain` 和 `loguru`。如果 Lemon AI 安装失败，请先安装这两个包，然后再安装 Lemon AI 包。

### 2. 启动服务器

您的 Agent 与 Lemon AI 提供的所有工具之间的交互由 [Lemon AI Server](https://github.com/felixbrock/lemonai-server) 处理。要使用 Lemon AI，您需要在本地机器上运行该服务器，以便 Lemon AI Python 客户端可以连接到它。

### 3. 在 LangChain 中使用 Lemon AI

Lemon AI 会自动解决给定的任务，方法是找到相关工具的正确组合，或者使用 Lemon AI 函数作为替代方案。以下示例演示了如何从 Hackernews 中检索用户数据并将其写入 Airtable 中的一个表：

#### (可选) 定义您的 Lemon AI 函数

类似于 [OpenAI functions](https://openai.com/blog/function-calling-and-other-api-updates)，Lemon AI 提供了将工作流程定义为可重用函数。可以在需要尽可能接近确定性行为的用例中定义这些函数。可以在单独的 `lemonai.json` 文件中定义特定的工作流程：

```json
[
  {
    "name": "Hackernews Airtable User Workflow",
    "description": "从 Hackernews 中检索用户数据并将其追加到 Airtable 的一个表中",
    "tools": ["hackernews-get-user", "airtable-append-data"]
  }
]
```

您的模型将可以访问这些函数，并且在解决给定任务时会优先选择它们，而不是自行选择工具。您所要做的就是通过在提示中包含函数名称来告知 Agent 应使用哪个函数。

#### 在 LangChain 项目中包含 Lemon AI

```python
import os

from langchain_openai import OpenAI
from lemonai import execute_workflow
```

#### 加载 API 密钥和访问令牌

要使用需要身份验证的工具，您必须以 `"{tool name}_{authentication string}"` 的格式将相应的访问凭证存储在环境中，其中身份验证字符串是 API 密钥的 ["API_KEY", "SECRET_KEY", "SUBSCRIPTION_KEY", "ACCESS_KEY"] 之一，或者对于身份验证令牌是 ["ACCESS_TOKEN", "SECRET_TOKEN"] 之一。示例如 "OPENAI_API_KEY"、"BING_SUBSCRIPTION_KEY"、"AIRTABLE_ACCESS_TOKEN"。

```python
""" 将所有相关的 API 密钥和访问令牌加载到您的环境变量中 """
os.environ["OPENAI_API_KEY"] = "*INSERT OPENAI API KEY HERE*"
os.environ["AIRTABLE_ACCESS_TOKEN"] = "*INSERT AIRTABLE TOKEN HERE*"
```

```python
hackernews_username = "*INSERT HACKERNEWS USERNAME HERE*"
airtable_base_id = "*INSERT BASE ID HERE*"
airtable_table_id = "*INSERT TABLE ID HERE*"

""" 定义要提供给您的 LLM 的指令 """
prompt = f"""
从 Hackernews 为用户 {hackernews_username} 读取信息，然后将结果写入 Airtable（baseId: {airtable_base_id}, tableId: {airtable_table_id}）。只写入 "username"、"karma" 和 "created_at_i" 字段。请确保 Airtable **不**会自动转换字段类型。
"""

"""
使用 Lemon AI execute_workflow 包装器
将您的 LangChain Agent 与 Lemon AI 结合运行
"""
model = OpenAI(temperature=0)

execute_workflow(llm=model, prompt_string=prompt)
```

### 4. 了解 Agent 决策过程的透明度

要了解 Agent 如何与 Lemon AI 工具进行交互以解决给定任务，所有决策、使用的工具和执行的操作都会写入本地 `lemonai.log` 文件。每当您的 LLM Agent 与 Lemon AI 工具堆栈交互时，都会创建相应的日志条目。

```log
2023-06-26T11:50:27.708785+0100 - b5f91c59-8487-45c2-800a-156eac0c7dae - hackernews-get-user
2023-06-26T11:50:39.624035+0100 - b5f91c59-8487-45c2-800a-156eac0c7dae - airtable-append-data
2023-06-26T11:58:32.925228+0100 - 5efe603c-9898-4143-b99a-55b50007ed9d - hackernews-get-user
2023-06-26T11:58:43.988788+0100 - 5efe603c-9898-4143-b99a-55b50007ed9d - airtable-append-data
```

通过使用 [Lemon AI Analytics](https://github.com/felixbrock/lemon-agent/blob/main/apps/analytics/README.md)，您可以轻松更好地了解工具的使用频率和顺序。因此，您可以识别 Agent 决策能力中的薄弱环节，并通过定义 Lemon AI 函数来转向更具确定性的行为。
