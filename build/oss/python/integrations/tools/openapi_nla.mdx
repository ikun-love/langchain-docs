`自然语言 API` 工具包 (`NLAToolkit`) 允许 LangChain 智能体（Agents）高效地规划和组合对各个端点的调用。

本 Notebook 演示了 `Speak`、`Klarna` 和 `Spoonacular` API 的一个组合示例。

### 首先，导入依赖项并加载 LLM

```python
from langchain.agents import AgentType, initialize_agent
from langchain_community.agent_toolkits import NLAToolkit
from langchain_community.utilities import Requests
from langchain_openai import OpenAI
```

```python
# 选择要使用的 LLM。这里我们使用 gpt-3.5-turbo-instruct
llm = OpenAI(
    temperature=0, max_tokens=700, model_name="gpt-3.5-turbo-instruct"
)  # 您可以在此处切换不同的核心 LLM。
```

### 接下来，加载自然语言 API 工具包

```python
speak_toolkit = NLAToolkit.from_llm_and_url(llm, "https://api.speak.com/openapi.yaml")
klarna_toolkit = NLAToolkit.from_llm_and_url(
    llm, "https://www.klarna.com/us/shopping/public/openai/v0/api-docs/"
)
```

### 创建智能体 (Agent)

```python
# 对默认智能体的指令进行微调
openapi_format_instructions = """使用以下格式：

Question: 您必须回答的输入问题
Thought: 您应该始终思考要做什么
Action: 要执行的操作，应为 [{tool_names}] 中的一项
Action Input: 要指示 AI 操作代表的操作的内容。
Observation: 智能体的响应
... (此 Thought/Action/Action Input/Observation 可以重复 N 次)
Thought: 我现在知道最终答案了。用户看不到我的任何观察结果、API 响应、链接或工具。
Final Answer: 对原始输入问题的最终答案，包含足够详细的信息

当您用 Final Answer 进行回复时，请记住，您回复的人**看不到**您的任何 Thought/Action/Action Input/Observations，因此如果其中有任何相关信息，您需要明确地将其包含在您的回复中。"""
```

```python
natural_language_tools = speak_toolkit.get_tools() + klarna_toolkit.get_tools()
mrkl = initialize_agent(
    natural_language_tools,
    llm,
    agent=AgentType.ZERO_SHOT_REACT_DESCRIPTION,
    verbose=True,
    agent_kwargs={"format_instructions": openapi_format_instructions},
)
```

```python
mrkl.run(
    "I have an end of year party for my Italian class and have to buy some Italian clothes for it"
)
```


### 使用身份验证 (Auth) 并添加更多端点

某些端点可能需要通过访问令牌等方式进行用户身份验证。这里我们展示如何通过 `Requests` 包装器对象传入身份验证信息。

由于每个 NLATool 为其包装的 API 提供简洁的自然语言接口，顶层的对话智能体在整合每个端点以满足用户请求时会更加轻松。

**添加 Spoonacular 端点。**

1. 前往 [Spoonacular API Console](https://spoonacular.com/food-api/console#Profile) 并免费注册一个账户。
2. 点击 `Profile` 并将在下面复制您的 API 密钥。

```python
spoonacular_api_key = ""  # 从 API 控制台复制
```

```python
requests = Requests(headers={"x-api-key": spoonacular_api_key})
spoonacular_toolkit = NLAToolkit.from_llm_and_url(
    llm,
    "https://spoonacular.com/application/frontend/downloads/spoonacular-openapi-3.json",
    requests=requests,
    max_text_length=1800,  # 如果您想截断响应文本
)
```
