title: "工具和工具包"

[工具 (Tools)](/oss/python/langchain/tools) 是设计用于被模型调用的实用程序：它们的输入旨在由模型生成，它们的输出旨在传回给模型。

工具包 (Toolkit) 是一组旨在一起使用的工具的集合。
