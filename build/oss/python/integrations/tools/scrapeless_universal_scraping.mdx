**Scrapeless** 提供灵活且功能丰富的**数据采集服务**，支持广泛的参数自定义和多格式导出。这些功能使得 LangChain 能够更有效地集成和利用外部数据。其核心功能模块包括：

**DeepSerp**

- **Google 搜索**: 支持跨所有结果类型，对 Google SERP（搜索引擎结果页面）数据进行全面提取。
  - 支持选择本地化的 Google 域名（例如：`google.com`, `google.ad`），以检索特定区域的搜索结果。
  - 支持**分页**功能，用于获取第一页之后的更多结果。
  - 支持**搜索结果过滤**开关，用于控制是否排除重复或相似的内容。
- **Google Trends**: 从 Google 检索关键词趋势数据，包括随时间变化的流行度、区域兴趣和相关搜索。
  - 支持**多关键词对比**。
  - 支持多种数据类型：`interest_over_time`（随时间变化的兴趣度）、`interest_by_region`（按区域划分的兴趣度）、`related_queries`（相关查询）和 `related_topics`（相关主题）。
  - 允许按特定的 Google 属性（网页、YouTube、新闻、购物）进行过滤，以进行特定来源的趋势分析。

**通用抓取 (Universal Scraping)**

- 专为现代、大量使用 JavaScript 的网站设计，支持动态内容提取。
  - 全局**高级代理**支持，用于绕过地理限制并提高抓取可靠性。

**爬虫 (Crawler)**

- **爬取 (Crawl)**: 递归地爬取一个网站及其链接的页面，以提取全站内容。
  - 支持**配置爬取深度**和**限定的 URL 目标范围**。
- **抓取 (Scrape)**: 从单个网页中提取内容，具有高精度。
  - 支持“仅提取主要内容”，以排除广告、页脚和其他非必要元素。
  - 支持对多个独立 URL 进行**批量抓取**。

## 实例化

此处展示了如何实例化 `ScrapelessUniversalScrapingTool` 的实例。此工具允许您使用具有 JavaScript 渲染能力的**无头浏览器**来抓取任何网站，并支持自定义的输出类型和地理位置特定的代理。

实例化时，该工具接受以下参数：

- `url` (必填，str): 要抓取的网站的 URL。
- `headless` (可选，bool): 是否使用无头浏览器。默认为 `True`。
- `js_render` (可选，bool): 是否启用 JavaScript 渲染。默认为 `True`。
- `js_wait_until` (可选，str): 定义何时认为 JavaScript 渲染的页面已准备就绪。默认为 `'domcontentloaded'`。选项包括：
  - `load`: 等待页面完全加载。
  - `domcontentloaded`: 等待 DOM 完全加载。
  - `networkidle0`: 等待网络空闲（0个活动连接）。
  - `networkidle2`: 等待网络空闲 2 秒。
- `outputs` (可选，str): 要从页面提取的具体数据类型。选项包括：
  - `phone_numbers` (电话号码)
  - `headings` (标题)
  - `images` (图片)
  - `audios` (音频)
  - `videos` (视频)
  - `links` (链接)
  - `menus` (菜单)
  - `hashtags` (标签)
  - `emails` (电子邮件)
  - `metadata` (元数据)
  - `tables` (表格)
  - `favicon` (网站图标)
- `response_type` (可选，str): 定义响应的格式。默认为 `'html'`。选项包括：
  - `html`: 返回页面的原始 HTML。
  - `plaintext`: 返回纯文本内容。
  - `markdown`: 返回页面的 Markdown 版本。
  - `png`: 返回 PNG 截图。
  - `jpeg`: 返回 JPEG 截图。
- `response_image_full_page` (可选，bool): 使用截图输出（png 或 jpeg）时，是否捕获并返回**全页**图像。默认为 `False`。
- `selector` (可选，str): 用于将抓取范围限定在页面某个部分的**特定 CSS 选择器**。默认为 `None`。
- `proxy_country` (可选，str): 用于地理位置特定代理访问的**两位国家代码**（例如：`'us'`, `'gb'`, `'de'`, `'jp'`）。默认为 `'ANY'`。

from langchain_scrapeless import ScrapelessUniversalScrapingTool

tool = ScrapelessUniversalScrapingTool()

# 基本用法
result = tool.invoke("https://example.com")
print(result)

### 使用参数的高级用法

```python
from langchain_scrapeless import ScrapelessUniversalScrapingTool

tool = ScrapelessUniversalScrapingTool()

result = tool.invoke({"url": "https://exmaple.com", "response_type": "markdown"})
print(result)
```

### 在 Agent 中使用

```python
from langchain_openai import ChatOpenAI
from langchain_scrapeless import ScrapelessUniversalScrapingTool
from langchain.agents import create_agent


model = ChatOpenAI()

tool = ScrapelessUniversalScrapingTool()

# 将工具与 Agent 一起使用
tools = [tool]
agent = create_agent(model, tools)

for chunk in agent.stream(
    {
        "messages": [
            (
                "human",
                "使用 scrapeless 抓取工具获取 https://www.scrapeless.com/en 并提取 h1 标签。",
            )
        ]
    },
    stream_mode="values",
):
    chunk["messages"][-1].pretty_print()
```
