---
title: Azure 认知服务工具包
---

此工具包用于与 `Azure Cognitive Services API` 交互，以实现某些多模态能力。

当前此工具包捆绑了四个工具：

- AzureCogsImageAnalysisTool：用于从图像中提取标题、对象、标签和文本。（注意：由于依赖的 `azure-ai-vision` 包目前仅支持 Windows 和 Linux，因此此工具在 Mac OS 上尚不可用。）
- AzureCogsFormRecognizerTool：用于从文档中提取文本、表格和键值对。
- AzureCogsSpeech2TextTool：用于将语音转录为文本。
- AzureCogsText2SpeechTool：用于将文本合成为语音。
- AzureCogsTextAnalyticsHealthTool：用于提取医疗保健实体。

首先，您需要设置一个 Azure 账户并创建一个认知服务资源。您可以按照 [此处](https://docs.microsoft.com/en-us/azure/cognitive-services/cognitive-services-apis-create-account?tabs=multiservice%2Cwindows) 的说明来创建资源。

然后，您需要获取资源的终结点（endpoint）、密钥（key）和区域（region），并将它们设置为环境变量。您可以在资源页面的“密钥和终结点”部分找到它们。

## 在 Agent 中使用

```python
from langchain.agents import AgentType, initialize_agent
from langchain_openai import OpenAI
```

```python
llm = OpenAI(temperature=0)
agent = initialize_agent(
    tools=toolkit.get_tools(),
    llm=llm,
    agent=AgentType.STRUCTURED_CHAT_ZERO_SHOT_REACT_DESCRIPTION,
    verbose=True,
)
```
