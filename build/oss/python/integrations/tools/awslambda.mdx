> [`Amazon AWS Lambda`](https://aws.amazon.com/pm/lambda/) 是 `Amazon Web Services` (`AWS`) 提供的无服务器计算服务。它帮助开发者构建和运行应用程序及服务，而无需预置或管理服务器。这种无服务器架构使您能够专注于编写和部署代码，而 AWS 会自动处理运行应用程序所需的底层基础设施的扩展、补丁和管理工作。

本指南将介绍如何使用 `AWS Lambda` 工具。

将 `AWS Lambda` 包含在提供给 Agent 的工具列表中后，您的 Agent 就可以调用在 AWS 云中运行的代码，以满足您的任何需求。

当 Agent 使用 `AWS Lambda` 工具时，它会提供一个 **string** 类型的参数，该参数随后会通过 `event` 参数传递给 Lambda 函数。

首先，您需要安装 `boto3` Python 包。

```python
pip install -qU  boto3 > /dev/null
pip install -qU langchain-community
```

为了让 Agent 能够使用该工具，您必须提供与您的 Lambda 函数逻辑的功能相匹配的名称（tool name）和描述（description）。

您还必须提供函数的具体名称（function name）。

请注意，由于此工具实际上是 `boto3` 库的封装，因此在使用此工具之前，您需要运行 `aws configure` 命令来配置您的 AWS 凭证。有关更多详细信息，请参阅[此处](https://docs.aws.amazon.com/cli/index.html)。

```python
from langchain.agents import AgentType, initialize_agent, load_tools
from langchain_openai import OpenAI

llm = OpenAI(temperature=0)

tools = load_tools(
    ["awslambda"],
    awslambda_tool_name="email-sender",
    awslambda_tool_description="sends an email with the specified content to test@testing123.com",
    function_name="testFunction1",
)

agent = initialize_agent(
    tools, llm, agent=AgentType.ZERO_SHOT_REACT_DESCRIPTION, verbose=True
)

agent.run("Send an email to test@testing123.com saying hello world.")
```
