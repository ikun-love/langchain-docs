>[Parallel](https://platform.parallel.ai/) 是一个专为大型语言模型（LLM）和 AI 应用设计的实时网页搜索和内容提取平台。

`ParallelWebSearchTool` 提供了对 Parallel Search API 的访问权限。该 API 将传统的“搜索 → 抓取 → 提取”流程整合为一个单一的 API 调用，返回结构化、经过 LLM 优化的搜索结果。

### 工具特性

- **实时网页搜索**: 访问最新的网络信息。
- **结构化结果**: 返回经过压缩并为 LLM 优化的摘要内容。
- **灵活的输入**: 支持自然语言目标描述或特定的搜索查询。
- **域名过滤**: 允许通过源策略（source policy）包含或排除特定域名。
- **可定制的输出**: 控制结果数量（1-40）和摘要长度（最小 100 个字符）。
- **丰富的元数据**: 可选地提供搜索时间、结果计数和查询信息。
- **异步支持**: 具有适当的执行器处理，支持完整的 `async/await` 操作。
- **错误处理**: 具有详细错误消息的全面错误处理机制。

请访问 [Parallel](https://beta.parallel.ai) 注册并生成 API 密钥。生成密钥后，设置 `PARALLEL_API_KEY` 环境变量：

```python
import getpass
import os

if not os.environ.get("PARALLEL_API_KEY"):
    os.environ["PARALLEL_API_KEY"] = getpass.getpass("Parallel API 密钥:\n")
```

## 实例化

这里展示了如何实例化一个 `ParallelWebSearchTool` 实例。该工具可以配置 API 密钥和基础 URL 参数：

```python
from langchain_parallel import ParallelWebSearchTool

# 基本实例化 - API 密钥来自环境变量
tool = ParallelWebSearchTool()

# 使用显式的 API 密钥和自定义的基础 URL
tool = ParallelWebSearchTool(
    api_key="your-api-key",
    base_url="https://api.parallel.ai",  # 默认值
)
```

## 调用 (Invocation)

### 直接使用参数调用

您可以使用 `objective`（自然语言描述）或 `search_queries`（特定搜索查询）来调用此工具。该工具支持各种配置选项，包括域名过滤和元数据收集：

```python
# 使用带有高级选项的特定搜索查询
result = tool.invoke(
    {
        "search_queries": [
            "2024 年 AI 突破",
            "机器学习进展",
            "生成式 AI 新闻",
        ],
        "max_results": 8,
        "excerpts": {"max_chars_per_result": 2000},
        "mode": "one-shot",  # 使用 'agentic' 以实现更节省 token 的结果
        "source_policy": {
            "include_domains": ["arxiv.org", "nature.com"],
            "exclude_domains": ["reddit.com", "twitter.com"],
        },
        "fetch_policy": {
            "max_age_seconds": 86400,  # 缓存内容 1 天
            "timeout_seconds": 60,
        },
        "include_metadata": True,
        "timeout": 120,  # 自定义超时时间（单位：秒）
    }
)

print(result)
```

```python
# 使用目标（自然语言）和元数据
result = tool.invoke(
```

### 使用 `ToolCall` 调用

我们也可以使用模型生成的 `ToolCall` 来调用该工具，此时会返回一个 `ToolMessage`：

```python
# 这通常由模型生成，但为了演示，我们在此直接创建一个 tool call。
model_generated_tool_call = {
    "args": {
        "objective": "查找关于气候变化倡议的最新消息",
        "max_results": 3,
        "source_policy": {"include_domains": ["ipcc.ch", "unfccc.int", "nature.com"]},
        "include_metadata": True,
    },
    "id": "call_123",
    "name": tool.name,  # "parallel_web_search"
    "type": "tool_call",
}

result = tool.invoke(model_generated_tool_call)
print(result)
print(f"工具名称: {tool.name}")  # parallel_web_search
print(f"工具描述: {tool.description}")
```

### 异步使用

该工具完全支持异步操作，以便在异步应用程序中获得更好的性能：

```python
async def search_async():
    return await tool.ainvoke(
        {
            "objective": "最新的量子计算突破",
            "max_results": 5,
            "include_metadata": True,
        }
    )


# 运行异步搜索
result = await search_async()
print(result)
```

### 参数详情和验证

该工具执行全面的输入验证，并支持以下参数：

#### 必需参数

必须提供以下至少一个：

- `objective`: 自然语言描述（最大 5000 个字符）
- `search_queries`: 搜索查询列表（最多 5 个查询，每个最多 200 个字符）

#### 可选参数:
- `max_results`: 返回的结果数量（1-40，默认值：10）
- `excerpts`: 摘要设置字典（例如：`{"max_chars_per_result": 1500}`）
- `mode`: 搜索模式 - 'one-shot' 用于全面结果，'agentic' 用于节省 token 的结果
- `source_policy`: 带有 `include_domains` 和/或 `exclude_domains` 列表的域名过滤
- `fetch_policy`: 缓存控制字典（例如：`{"max_age_seconds": 86400, "timeout_seconds": 60}`）
- `include_metadata`: 包含搜索时间和统计数据（默认值：True）
- `timeout`: 请求超时时间（单位：秒，可选）

#### 错误处理:
该工具为验证失败和 API 错误提供详细的错误消息。

```python
# 全面参数使用示例
result = tool.invoke(
    {
        "objective": "查找关于欧洲国家可再生能源政策的全面信息",
        "max_results": 15,
        "excerpts": {
            "max_chars_per_result": 2500
        },  # 更长的摘要以获取详细信息
        "mode": "one-shot",  # 全面结果
        "source_policy": {
            "include_domains": ["europa.eu", "iea.org", "irena.org"],
            "exclude_domains": ["wikipedia.org", "reddit.com"],
        },
        "fetch_policy": {
            "max_age_seconds": 86400,  # 1 天缓存
            "timeout_seconds": 90,
        },
        "include_metadata": True,
        "timeout": 180,  # 扩展超时时间以支持全面搜索
    }
)

# 访问结果和元数据
print(f"找到 {len(result['results'])} 个结果")
if "search_metadata" in result:
    metadata = result["search_metadata"]
    print(f"搜索耗时 {metadata['search_duration_seconds']}s")
    print(f"源策略已应用: {metadata.get('source_policy_applied', False)}")
```

## 链式调用 (Chaining)

我们可以通过首先将工具绑定到 [工具调用模型](/oss/python/langchain/tools/)，然后调用它，在链中使用我们的工具：

import ChatModelTabs from '/snippets/chat-model-tabs.mdx';

<ChatModelTabs customVarName="llm" />

```python
# | output: false
# | echo: false

# !pip install -qU langchain langchain-openai
from langchain.chat_models import init_chat_model

llm = init_chat_model(model="gpt-4o", model_provider="openai")
```

```python
from langchain_core.prompts import ChatPromptTemplate
from langchain_core.runnables import RunnableConfig, chain

prompt = ChatPromptTemplate(
    [
        ("system", "你是一个有帮助的助手。"),
        ("human", "{user_input}"),
        ("placeholder", "{messages}"),
    ]
)

# 指定 tool_choice 将强制模型调用此工具。
llm_with_tools = llm.bind_tools([tool], tool_choice=tool.name)

llm_chain = prompt | llm_with_tools


@chain
def tool_chain(user_input: str, config: RunnableConfig):
    input_ = {"user_input": user_input}
    ai_msg = llm_chain.invoke(input_, config=config)
    tool_msgs = tool.batch(ai_msg.tool_calls, config=config)
    return llm_chain.invoke({**input_, "messages": [ai_msg, *tool_msgs]}, config=config)


tool_chain.invoke("最新的量子计算突破有哪些？")
```

## 最佳实践

- **使用具体的明确目标**: 越具体的目标将带来越精确、越有针对性的结果。
- **应用域名过滤**: 使用 `source_policy` 来聚焦权威来源或排除不可靠的域名。
- **包含元数据**: 设置 `include_metadata: True` 用于调试和性能优化。
- **优雅地处理错误**: 该工具为验证失误和 API 故障提供了详细的错误消息。
- **为性能使用异步**: 在异步应用程序中使用 `ainvoke()` 以获得更好的性能。

该工具返回一个具有以下结构的字典：

```python
{
    "search_id": "search_abc123...",  # 唯一的搜索标识符
    "results": [  # 搜索结果列表
        {
            "url": "https://example.com/page",
            "title": "页面标题",
            "excerpts": [  # 相关文本摘要
                "第一个相关摘要...",
                "第二个相关摘要..."
            ]
        }
    ],
    "search_metadata": {  # 可选元数据 (如果 include_metadata=True)
        "search_duration_seconds": 4.123,
        "search_timestamp": "2024-01-15T10:30:00",
        "max_results_requested": 10,
        "actual_results_returned": 8,
        "search_id": "search_abc123...",
        "query_count": 3,  # 使用的查询数量
        "queries_used": ["query1", "query2", "query3"],  # 如果提供了 search_queries
        "source_policy_applied": true,  # 如果使用了 source_policy
        "included_domains": ["nature.com"],  # 被包含的域名列表
        "excluded_domains": ["reddit.com"]   # 被排除的域名列表
    }
}
```
