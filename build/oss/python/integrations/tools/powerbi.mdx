title: PowerBI 工具包

本 Notebook 展示了一个与 `Power BI 数据集`交互的智能体。该智能体不仅能回答关于数据集的一般性问题，还能从错误中恢复。

请注意，由于此智能体仍在积极开发中，所有答案可能并不完全正确。它针对 [executequery 终结点](https://learn.microsoft.com/en-us/rest/api/power-bi/datasets/execute-queries) 运行，该终结点不允许执行删除操作。

### 备注

- 它依赖于 `azure.identity` 包进行身份验证，您可以使用 `pip install azure-identity` 进行安装。或者，您也可以在不提供凭据的情况下，使用令牌作为字符串来创建 PowerBI 数据集。
- 您还可以提供一个用户名以供模仿（impersonate），用于与启用了行级别安全性（RLS）的数据集配合使用。
- 该工具包使用 LLM（大型语言模型）根据用户问题生成查询，而智能体则使用 LLM 来进行整体执行。
- 测试主要使用 `gpt-3.5-turbo-instruct` 模型进行，Codex 模型的效果似乎不太好。

## 初始化 (Initialization)

```python
from azure.identity import DefaultAzureCredential
from langchain_community.agent_toolkits import PowerBIToolkit, create_pbi_agent
from langchain_community.utilities.powerbi import PowerBIDataset
from langchain_openai import ChatOpenAI
```

```python
fast_llm = ChatOpenAI(
    temperature=0.5, max_tokens=1000, model_name="gpt-3.5-turbo", verbose=True
)
smart_llm = ChatOpenAI(temperature=0, max_tokens=100, model_name="gpt-4", verbose=True)

toolkit = PowerBIToolkit(
    powerbi=PowerBIDataset(
        dataset_id="<dataset_id>",
        table_names=["table1", "table2"],
        credential=DefaultAzureCredential(),
    ),
    llm=smart_llm,
)

agent_executor = create_pbi_agent(
    llm=fast_llm,
    toolkit=toolkit,
    verbose=True,
)
```

## 示例：描述一个表 (Example: describing a table)

```python
agent_executor.run("Describe table1")
```

## 示例：在表上执行简单查询 (Example: simple query on a table)

在这个例子中，智能体会设法找出正确的查询语句，以获取表的行数。

```python
agent_executor.run("How many records are in table1?")
```

## 示例：运行查询 (Example: running queries)

```python
agent_executor.run("How many records are there by dimension1 in table2?")
```

```python
agent_executor.run("What unique values are there for dimensions2 in table2")
```

## 示例：添加您自己的少样本提示 (Example: add your own few-shot prompts)

```python
# fictional example
few_shots = """
Question: How many rows are in the table revenue?
DAX: EVALUATE ROW("Number of rows", COUNTROWS(revenue_details))
----
Question: How many rows are in the table revenue where year is not empty?
DAX: EVALUATE ROW("Number of rows", COUNTROWS(FILTER(revenue_details, revenue_details[year] <> "")))
----
Question: What was the average of value in revenue in dollars?
DAX: EVALUATE ROW("Average", AVERAGE(revenue_details[dollar_value]))
----
"""
toolkit = PowerBIToolkit(
    powerbi=PowerBIDataset(
        dataset_id="<dataset_id>",
        table_names=["table1", "table2"],
        credential=DefaultAzureCredential(),
    ),
    llm=smart_llm,
    examples=few_shots,
)
agent_executor = create_pbi_agent(
    llm=fast_llm,
    toolkit=toolkit,
    verbose=True,
)
```

```python
agent_executor.run("What was the maximum of value in revenue in dollars in 2022?")
```
