title: Compass DeFi 工具包
---

与各种 DeFi 协议进行交互。**非托管**。工具返回*未签名的交易*。该工具包基于一个通用 DeFi API（[Compass API](https://api.compasslabs.ai/)）构建，允许代理执行金融操作，例如：

- 在 Uniswap 和 Aerodrome 上**兑换代币**
- 使用 Aave 上的协议**借入**或**借出**资产
- 在 Aerodrome 和 Uniswap 上**提供流动性**
- 在钱包之间**转移资金**。
- 查询余额、投资组合和**监控头寸**。

## 概述

### 集成详情

| 类名 | 包名 | 可序列化 | JS 支持 | 版本 |
|:---|:---|:---:|:---:|:---|
| `LangchainCompassToolkit` | `langchain-compass` | ❌ | ❌ | ![PyPI - Version](https://img.shields.io/pypi/v/langchain-compass?style=flat-square&label=%20) |

### 工具功能

以下是此工具包提供的工具示例（可能每日更改）：

- `aave_supply`: 向 Aave 供应资产以赚取利息。
- `aave_borrow`: 使用抵押品从 Aave 借入资产。
- `uniswap_swap_sell_exactly`: 在 Uniswap 上兑换特定数量的一种代币。
- `generic_portfolio_get`: 以美元和代币余额的形式检索钱包的投资组合。
- `generic_transfer_erc20`: 在地址之间转移 ERC20 代币。

## 设置

在这里，我们将执行以下步骤：

1. 安装 `langchain` 包
2. 导入并实例化工具包
3. 将工具通过 `toolkit.get_tools()` 传递给你的代理

### 安装

此工具包位于 `langchain-compass` 包中：

```python
pip install -qU langchain-compass
```

#### 环境设置

要运行这些示例，请确保 LangChain 可以访问 LLM 服务。例如，如果你使用的是 GPT-4o，请创建一个包含以下内容的 `.env` 文件：

```plaintext
# .env file
OPENAI_API_KEY=<your_openai_api_key_here>
```

### 实例化

现在我们可以实例化工具包：

```python
from langchain_compass.toolkits import LangchainCompassToolkit

toolkit = LangchainCompassToolkit(compass_api_key=None)
```

### 工具

查看 [可用工具](#tool-features)：

```python
tools = toolkit.get_tools()
for tool in tools:
    print(tool.name)
```

## 调用

要以编程方式调用单个工具：

```python
tool_name = "generic_ens_get"
tool = next(tool for tool in tools if tool.name == tool_name)
tool.invoke({"ens_name": "vitalik.eth", "chain": "ethereum:mainnet"})
```

## 在 Agent 中使用

我们需要一个 LLM 或聊天模型：

```python
from dotenv import load_dotenv
from langchain_openai import ChatOpenAI

load_dotenv()

llm = ChatOpenAI(model="gpt-4o")
```

初始化 Agent 并传入工具：

```python
from langchain.agents import create_agent


tools = toolkit.get_tools()
agent_executor = create_agent(llm, tools)
```

使用示例：

```python
example_query = "please set an allowance on Uniswap of 10 WETH for vitalic.eth."  # spelt wrong intentionally

events = agent_executor.stream(
    {"messages": [("user", example_query)]},
    stream_mode="values",
)
for event in events:
    event["messages"][-1].pretty_print()
```
