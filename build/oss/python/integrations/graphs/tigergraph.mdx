> [TigerGraph](https://www.tigergraph.com/tigergraph-db/) 是一个原生分布式的高性能图数据库。
> 数据以顶点（vertices）和边（edges）的图格式存储，这使得数据关系非常丰富，非常适合用于**支撑大型语言模型（LLM）的问答和推理**。

一个关于 `TigerGraph` 和 `LangChain` 集成的重大示例 [请参见此处](https://github.com/tigergraph/graph-ml-notebooks/blob/main/applications/large_language_models/TigerGraph_LangChain_Demo.ipynb)。

## 安装和设置

请遵循 [如何连接到 `TigerGraph` 数据库](https://docs.tigergraph.com/pytigergraph/current/getting-started/connection) 的说明进行操作。

安装 Python SDK：

<CodeGroup>
```bash pip
pip install pyTigerGraph
```

```bash uv
uv add pyTigerGraph
```
</CodeGroup>

## 示例

要利用 `TigerGraph InquiryAI` 的功能，您可以从 `langchain_community.graphs` 中导入 `TigerGraph` 类。

```python
import pyTigerGraph as tg

conn = tg.TigerGraphConnection(host="DATABASE_HOST_HERE", graphname="GRAPH_NAME_HERE", username="USERNAME_HERE", password="PASSWORD_HERE")

### ==== 配置 INQUIRYAI 主机 ====
conn.ai.configureInquiryAIHost("INQUIRYAI_HOST_HERE")

from langchain_community.graphs import TigerGraph

graph = TigerGraph(conn)
result = graph.query("How many servers are there?")
print(result)
```
