---
title: Comet 追踪
---

您可以通过两种方式使用 Comet 来追踪您的 LangChain 执行流程：

1. 将环境变量 `LANGCHAIN_COMET_TRACING` 设置为 `"true"`。这是推荐的做法。
2. 手动导入 `CometTracer` 并明确地将其传递给相关组件。

```python
import os

import comet_llm
from langchain_openai import OpenAI

os.environ["LANGCHAIN_COMET_TRACING"] = "true"

# 如果没有设置 API 密钥，则连接到 Comet
comet_llm.init()

# 关于如何使用环境变量配置 comet 的文档：
# https://www.comet.com/docs/v2/api-and-sdk/llm-sdk/configuration/
# 在这里我们配置 comet 的项目名称
os.environ["COMET_PROJECT_NAME"] = "comet-example-langchain-tracing"

from langchain.agents import AgentType, initialize_agent, load_tools
```

```python
# 开启追踪的 Agent 运行示例。请确保已正确设置 OPENAI_API_KEY 才能运行此示例。

llm = OpenAI(temperature=0)
tools = load_tools(["llm-math"], llm=llm)
```

```python
agent = initialize_agent(
    tools, llm, agent=AgentType.ZERO_SHOT_REACT_DESCRIPTION, verbose=True
)

agent.run("What is 2 raised to .123243 power?")  # 此操作应该被追踪
# 以下内容将打印在您的控制台中，它是一个指向 Comet 中 LLM 链的 URL：
# https://www.comet.com/<workspace>/<project_name>
# 您可以使用此 URL 在 Comet 中查看 LLM 链的执行详情。
```

```python
# 现在，我们取消设置环境变量，并使用上下文管理器的方式。
if "LANGCHAIN_COMET_TRACING" in os.environ:
    del os.environ["LANGCHAIN_COMET_TRACING"]

from langchain_community.callbacks.tracers.comet import CometTracer

tracer = CometTracer()

# 重新创建 LLM、工具和 Agent，并将回调 (callback) 传递给它们
llm = OpenAI(temperature=0)
tools = load_tools(["llm-math"], llm=llm)
agent = initialize_agent(
    tools, llm, agent=AgentType.ZERO_SHOT_REACT_DESCRIPTION, verbose=True
)

agent.run(
    "What is 2 raised to .123243 power?", callbacks=[tracer]
)  # 此操作也应该被追踪
```
