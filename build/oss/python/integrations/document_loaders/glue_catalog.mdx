---
title: Glue Catalog（Glue 数据目录）
---

[AWS Glue Data Catalog](https://docs.aws.amazon.com/en_en/glue/latest/dg/catalog-and-crawler.html) 是一个集中化的元数据存储库，它允许您管理、访问和共享有关存储在 AWS 中的数据元数据。它充当数据资产的元数据存储，使各种 AWS 服务和您的应用程序能够高效地查询和连接到它们所需的数据。

当您在 AWS Glue 中定义数据源（Data Sources）、转换（Transformations）和目标（Targets）时，关于这些元素的元数据会存储在 Data Catalog 中。这包括数据位置、Schema 定义、运行时指标等信息。它支持各种数据存储类型，例如 Amazon S3、Amazon RDS、Amazon Redshift 以及兼容 JDBC 的外部数据库。它还与 Amazon Athena、Amazon Redshift Spectrum 和 Amazon EMR 直接集成，使得这些服务可以直接访问和查询数据。

`LangChain GlueCatalogLoader` 将以与 Pandas dtype 相同的格式获取指定 Glue 数据库中所有表的 Schema 信息。

## 设置

- 按照 [说明设置 AWS 账户](https://docs.aws.amazon.com/athena/latest/ug/setting-up.html)。
- 安装 boto3 库：`pip install boto3`

## 示例

```python
from langchain_community.document_loaders.glue_catalog import GlueCatalogLoader
```

```python
database_name = "my_database"
profile_name = "my_profile"

loader = GlueCatalogLoader(
    database=database_name,
    profile_name=profile_name,
)

schemas = loader.load()
print(schemas)
```

## 带有表过滤的示例

表过滤（Table filtering）允许您有选择性地检索 Glue 数据库中特定子集表的 Schema 信息。您可以使用 `table_filter` 参数来指定您感兴趣的具体表，而不是加载所有表的 Schema。

```python
from langchain_community.document_loaders.glue_catalog import GlueCatalogLoader
```

```python
database_name = "my_database"
profile_name = "my_profile"
table_filter = ["table1", "table2", "table3"]

loader = GlueCatalogLoader(
    database=database_name, profile_name=profile_name, table_filter=table_filter
)

schemas = loader.load()
print(schemas)
```
