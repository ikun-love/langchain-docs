---
title: 飞书 (LarkSuite)
---

>[LarkSuite](https://www.larksuite.com/) 是字节跳动开发的、面向企业的一体化协作平台。

本指南介绍了如何从 `LarkSuite` REST API 加载数据，并将其转换为可被 LangChain 摄取（Ingest）的格式，同时提供了文本摘要任务的示例用法。

LarkSuite API 需要一个访问令牌（`tenant_access_token` 或 `user_access_token`）。有关 API 的详细信息，请参见 [LarkSuite 开放平台文档](https://open.larksuite.com/document)。

```python
from getpass import getpass

from langchain_community.document_loaders.larksuite import (
    LarkSuiteDocLoader,
    LarkSuiteWikiLoader,
)

DOMAIN = input("飞书域名 (larksuite domain)")
ACCESS_TOKEN = getpass("飞书租户访问令牌或用户访问令牌 (larksuite tenant_access_token or user_access_token)")
DOCUMENT_ID = input("飞书文档 ID (larksuite document id)")
```

## 从文档加载 (Load From Document)

```python
from pprint import pprint

larksuite_loader = LarkSuiteDocLoader(DOMAIN, ACCESS_TOKEN, DOCUMENT_ID)
docs = larksuite_loader.load()

pprint(docs)
```

```output
[Document(page_content='Test Doc\nThis is a Test Doc\n\n1\n2\n3\n\n', metadata={'document_id': 'V76kdbd2HoBbYJxdiNNccajunPf', 'revision_id': 11, 'title': 'Test Doc'})]
```

## 从 Wiki 加载 (Load From Wiki)

```python
from pprint import pprint

DOCUMENT_ID = input("飞书 Wiki ID (larksuite wiki id)")
larksuite_loader = LarkSuiteWikiLoader(DOMAIN, ACCESS_TOKEN, DOCUMENT_ID)
docs = larksuite_loader.load()

pprint(docs)
```

```output
[Document(page_content='Test doc\nThis is a test wiki doc.\n', metadata={'document_id': 'TxOKdtMWaoSTDLxYS4ZcdEI7nwc', 'revision_id': 15, 'title': 'Test doc'})]
```

```python
# 更多详情请参见 https://python.langchain.com/docs/use_cases/summarization
from langchain.chains.summarize import load_summarize_chain
from langchain_community.llms.fake import FakeListLLM

llm = FakeListLLM()
chain = load_summarize_chain(llm, chain_type="map_reduce")
chain.run(docs)
```
