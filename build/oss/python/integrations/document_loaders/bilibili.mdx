>[Bilibili](https://www.bilibili.com/) 是中国最受欢迎的长视频网站之一。

此加载器（Loader）利用 [bilibili-api](https://github.com/Nemo2011/bilibili-api) 来从 `Bilibili` 视频中检索文本字幕。要有效使用此加载器，必须提供 `sessdata`、`bili_jct` 和 `buvid3` 这三个 Cookie 参数。这些参数可以通过登录 [Bilibili](https://www.bilibili.com/) 网站，然后从浏览器的开发者工具中提取 `sessdata`、`bili_jct` 和 `buvid3` 的值来获取。

如果您选择将 Cookie 参数留空，加载器仍然可以工作，但**只能**获取用于元数据的视频信息，而无法获取字幕内容。

有关获取这些凭据的详细说明，请参阅[此处](https://nemo2011.github.io/bilibili-api/#/get-credential)的指南。

`BiliBiliLoader` 提供了一个用户友好的界面，使用户可以轻松访问 Bilibili 上所需视频内容的字幕，对于希望分析或利用这些媒体数据的人来说，它是一个非常有价值的工具。
