> [TOML](https://en.wikipedia.org/wiki/TOML) 是一种用于配置文件（configuration files）的文件格式。它的设计目标是易于人类阅读和编写，并且旨在可以被清晰无歧义地映射到字典（dictionary）结构中。其规范是开源的。`TOML` 已经被许多编程语言实现。`TOML` 这个名字是 "Tom's Obvious, Minimal Language"（Tom 的直观、最小化语言）的首字母缩写，用以纪念其创建者 Tom Preston-Werner。

如果您需要加载 `Toml` 文件，请使用 `TomlLoader`。

```python
from langchain_community.document_loaders import TomlLoader
```

```python
loader = TomlLoader("example_data/fake_rule.toml")
```

```python
rule = loader.load()
```
