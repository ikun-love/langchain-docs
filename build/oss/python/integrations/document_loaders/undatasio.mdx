本指南（Notebook）提供了__UnDatasIO 文档加载器__的快速上手概览。UnDatasIO 能够高效地加载和解析各种文档格式，包括 PDF、PNG、JPG、JPEG 和 JFIF。它通过 UnDatasIO 的安全云 API 提供文档的**延迟加载**和**原生异步支持**功能。这些能力使得处理后的数据可以直接用于生成式 AI 工作流，例如 RAG（检索增强生成）。

有关所有功能和配置的详细文档，请参阅官方 API 参考文档。

## 概述

## 设置

### 凭证

UnDatasIO 需要一个 API 令牌（token）。请在 [undatas.io](https://undatas.io) 上生成一个免费令牌，并将其设置在下面的代码单元格中：

```python
import getpass
import os

if "UNDATASIO_TOKEN" not in os.environ:
    os.environ["UNDATASIO_TOKEN"] = getpass.getpass(
        "Enter your UnDatasIO API token: "
    )
```

### 初始化

__UnDatasIOLoader__ 支持通过 UnDatasIO 云 API 进行单文件上传和解析。

```python
from langchain_undatasio import UnDatasIOLoader

loader = UnDatasIOLoader(
    token=os.environ["UNDATASIO_TOKEN"],
    file_path="demo.pdf"
)
```

### 加载 (Load)

```python
docs = loader.load()
docs[0]
```

### 延迟加载 (Lazy Load)

__UnDatasIOLoader__ 支持延迟加载，以实现内存高效的迭代。

```python
pages = []
for doc in loader.lazy_load():
    pages.append(doc)

pages[0]
```
