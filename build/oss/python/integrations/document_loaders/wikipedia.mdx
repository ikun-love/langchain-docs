> [维基百科](https://wikipedia.org/) 是一个多语言的免费在线百科全书，由一群被称为“维基人”的志愿者通过开放协作和使用名为 MediaWiki 的基于 wiki 的编辑系统共同撰写和维护。`Wikipedia` 是历史上规模最大、阅读人数最多的参考资料。

本指南（Notebook）展示了如何从 `wikipedia.org` 加载维基百科页面，并将其转换为我们下游使用的 `Document` 格式。

## 安装

首先，您需要安装 `langchain_community` 和 `wikipedia` 包。

```python
pip install -qU langchain_community wikipedia
```

## 参数

`WikipediaLoader` 具有以下可选参数：

- `query`: 用于在维基百科中查找文档的自由文本查询。
- `lang` (可选): 默认为 `"en"`。用于在维基百科的特定语言板块中进行搜索。
- `load_max_docs` (可选): 默认为 `100`。用于限制已下载文档的数量。下载全部 100 个文档会比较耗时，因此建议在实验时使用较小的数字。目前有一个硬性上限为 300。
- `load_all_available_meta` (可选): 默认为 `False`。默认情况下，只下载最重要的字段：`title`（标题）和 `summary`（摘要）。如果设置为 `True`，则会下载所有可用的字段。
- `doc_content_chars_max` (可选): 默认为 `4000`。文档内容允许拥有的最大字符数。

## 示例

```python
from langchain_community.document_loaders import WikipediaLoader
```

```python
docs = WikipediaLoader(query="HUNTER X HUNTER", load_max_docs=2).load()
len(docs)
```

```output
2
```

```python
docs[0].metadata  # 第一个文档的元数据
```
