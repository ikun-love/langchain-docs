本教程介绍了如何使用 `LLM Sherpa` 来加载多种类型的文件。`LLM Sherpa` 支持的文档格式包括 DOCX、PPTX、HTML、TXT 和 XML。

`LLMSherpaFileLoader` 使用了 `LayoutPDFReader`，它是 LLMSherpa 库的一部分。这个工具旨在解析 PDF 文件，同时保留其布局信息，而布局信息通常在大多数 PDF 文本解析器中会丢失。

以下是 `LayoutPDFReader` 的一些关键特性：

* 它可以识别并提取带有层级信息的章节和小节内容。
* 它可以将多行文本合并成段落。
* 它可以识别章节和段落之间的链接关系。
* 它可以提取表格，并标明表格所在的部分。
* 它可以识别并提取列表和嵌套列表。
* 它可以将跨页的内容连接起来。
* 它可以移除重复的页眉和页脚。
* 它可以移除水印。

请参阅 [llmsherpa](https://llmsherpa.readthedocs.io/en/latest/) 文档。

`INFO: 此库对某些 PDF 文件可能存在解析失败的情况，请谨慎使用。`

## LLMSherpaFileLoader

`LLMSherpaFileLoader` 在底层定义了若干策略（strategist）来加载文件内容：["sections", "chunks", "html", "text"]。您可以设置 [nlm-ingestor](https://github.com/nlmatics/nlm-ingestor) 以获取 `llmsherpa_api_url`，或者使用默认值。

### sections 策略：将文件解析为章节结构返回

```python
from langchain_community.document_loaders.llmsherpa import LLMSherpaFileLoader

loader = LLMSherpaFileLoader(
    file_path="https://arxiv.org/pdf/2402.14207.pdf",
    new_indent_parser=True,
    apply_ocr=True,
    strategy="sections",
    llmsherpa_api_url="http://localhost:5010/api/parseDocument?renderFormat=all",
)
docs = loader.load()
```

```python
docs[1]
```

### chunks 策略：将文件解析为分块（chunks）返回

```python
from langchain_community.document_loaders.llmsherpa import LLMSherpaFileLoader

loader = LLMSherpaFileLoader(
    file_path="https://arxiv.org/pdf/2402.14207.pdf",
    new_indent_parser=True,
    apply_ocr=True,
    strategy="chunks",
    llmsherpa_api_url="http://localhost:5010/api/parseDocument?renderFormat=all",
```
