[Spider](https://spider.cloud/) 是最快、最具成本效益的网络爬虫和抓取工具，能够返回可供 LLM（大型语言模型）使用的数据。

## 安装

```python
pip install spider-client
```

## 用法

要使用 Spider，您需要从 [spider.cloud](https://spider.cloud/) 获取 API 密钥。

```python
from langchain_community.document_loaders import SpiderLoader

loader = SpiderLoader(
    api_key="YOUR_API_KEY",
    url="https://spider.cloud",
    mode="scrape",  # 如果未提供 API 密钥，它会在环境变量中查找 SPIDER_API_KEY
)

data = loader.load()
print(data)
```

## 模式 (Modes)

- `scrape`: 默认模式，抓取单个 URL。
- `crawl`: 抓取所提供的域名下的所有子页面。

## 爬虫选项 (Crawler options)

`params` 参数是一个字典，可以传递给加载器 (loader)。请参阅 [Spider 文档](https://spider.cloud/docs/api) 以查看所有可用的参数。
