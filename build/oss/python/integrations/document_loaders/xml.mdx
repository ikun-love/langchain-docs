本指南提供了关于如何开始使用 `UnstructuredXMLLoader` [文档加载器](https://python.langchain.com/docs/concepts/document_loaders)的快速概览。`UnstructuredXMLLoader` 用于加载 `XML` 文件。该加载器支持 `.xml` 文件。页面内容将是**从 XML 标签中提取的文本**。

## 设置 (Setup)

要使用 `UnstructuredXMLLoader` 文档加载器，您需要安装 `langchain-community` 集成包。

### 凭证 (Credentials)

使用 `UnstructuredXMLLoader` **不需要任何凭证**。

如需启用模型调用的自动化追踪，请设置您的 [LangSmith](https://docs.smith.langchain.com/) API 密钥：

```python
os.environ["LANGSMITH_API_KEY"] = getpass.getpass("输入您的 LangSmith API 密钥: ")
os.environ["LANGSMITH_TRACING"] = "true"
```

### 安装 (Installation)

安装 **langchain_community**。

```python
pip install -qU langchain_community
```

## 初始化 (Initialization)

现在我们可以实例化模型对象并加载文档：

```python
from langchain_community.document_loaders import UnstructuredXMLLoader

loader = UnstructuredXMLLoader(
    "./example_data/factbook.xml",
)
```

## 加载 (Load)

```python
docs = loader.load()
docs[0]
```

```output
Document(metadata={'source': './example_data/factbook.xml'}, page_content='United States\n\nWashington, DC\n\nJoe Biden\n\nBaseball\n\nCanada\n\nOttawa\n\nJustin Trudeau\n\nHockey\n\nFrance\n\nParis\n\nEmmanuel Macron\n\nSoccer\n\nTrinidad & Tobado\n\nPort of Spain\n\nKeith Rowley\n\nTrack & Field')
```

```python
print(docs[0].metadata)
```

```output
{'source': './example_data/factbook.xml'}
```

## 延迟加载 (Lazy Load)

```python
page = []
for doc in loader.lazy_load():
    page.append(doc)
    if len(page) >= 10:
        # 执行一些分页操作，例如：
        # index.upsert(page)

        page = []
```
