本 Notebook 介绍如何使用 `Unstructured` [文档加载器](https://python.langchain.com/docs/concepts/document_loaders) 来加载多种类型的文件。`Unstructured` 当前支持加载文本文件、PowerPoint、HTML、PDF、图像等文件。

有关在本地设置 Unstructured 的更多说明，包括设置必要的系统依赖项，请参阅[本指南](/oss/python/integrations/providers/unstructured)。

## 设置 (Setup)

### 凭证 (Credentials)

默认情况下，`langchain-unstructured` 安装了一个较小的依赖集，它要求将分块/解析逻辑 (partitioning logic) 卸载到 Unstructured API，这就需要一个 API 密钥。如果使用本地安装，则不需要 API 密钥。要获取您的 API 密钥，请访问[此网站](https://unstructured.io)并获取一个 API 密钥，然后在下面的单元格中设置它：

```python
import getpass
import os

if "UNSTRUCTURED_API_KEY" not in os.environ:
    os.environ["UNSTRUCTURED_API_KEY"] = getpass.getpass(
        "Enter your Unstructured API key: "
    )
```

### 安装 (Installation)

#### 常规安装 (Normal Installation)

运行本 Notebook 的其余部分需要安装以下包。

```python
# 安装包，兼容 API 分区
pip install -qU langchain-unstructured unstructured-client unstructured "unstructured[pdf]" python-magic
```

#### 本地安装 (Installation for Local)

如果您希望在本地运行解析逻辑，则需要安装系统依赖项的组合，具体细节请参考 Unstructured [文档](https://docs.unstructured.io/open-source/installation/full-installation)中的说明。

例如，在 Mac 上，您可以使用以下命令安装所需的依赖项：

```bash
# 基础依赖项
brew install libmagic poppler tesseract

# 如果解析 XML / HTML 文档：
brew install libxml2 libxslt
```

您可以使用以下命令安装本地所需的 `pip` 依赖项：

```bash
pip install "langchain-unstructured[local]"
```

## 初始化 (Initialization)

`UnstructuredLoader` 支持从各种不同的文件类型加载内容。要全面了解 `unstructured` 包，请参阅其[文档](https://docs.unstructured.io/open-source/introduction/overview)/。在此示例中，我们展示了如何从文本文件和 PDF 文件加载内容。

```python
from langchain_unstructured import UnstructuredLoader

file_paths = [
    "./example_data/layout-parser-paper.pdf",
    "./example_data/state_of_the_union.txt",
]


loader = UnstructuredLoader(file_paths)
```

## 后处理 (Post Processing)

如果您需要在提取内容后对 `unstructured` 元素进行后处理，可以在实例化 `UnstructuredLoader` 时向 `post_processors` 形参传递一个 `str` -> `str` 函数列表。这也适用于其他的 Unstructured 加载器。下面是一个示例。

```python
from langchain_unstructured import UnstructuredLoader
from unstructured.cleaners.core import clean_extra_whitespace

loader = UnstructuredLoader(
    "./example_data/layout-parser-paper.pdf",
    post_processors=[clean_extra_whitespace],
)

docs = loader.load()

docs[5:10]
```

## Unstructured API

如果您希望使用更小的软件包并获得最新的分区 (partitioning) 功能，可以 `pip install unstructured-client`，然后 `pip install langchain-unstructured`。有关 `UnstructuredLoader` 的更多信息，请参阅[Unstructured 提供商页面](https://python.langchain.com/v0.1/docs/integrations/document_loaders/unstructured_file/)。

当您传入 `api_key` 并设置 `partition_via_api=True` 时，加载器将使用托管的 Unstructured 无服务器 API 来处理您的文档。您可以在[此处](https://unstructured.io/api-key/)生成免费的 Unstructured API 密钥。

如果您想自己托管 Unstructured API 或在本地运行它，请查看[此处](https://github.com/Unstructured-IO/unstructured-api#dizzy-instructions-for-using-the-docker-image)的说明。

```python
from langchain_unstructured import UnstructuredLoader

loader = UnstructuredLoader(
    file_path="example_data/fake.docx",
    api_key=os.getenv("UNSTRUCTURED_API_KEY"),
    partition_via_api=True,
)

docs = loader.load()
docs[0]
```

```output
INFO: Successfully partitioned the document.
```

### Unstructured SDK 客户端 (Unstructured SDK Client)

通过 Unstructured API 进行分块/解析依赖于 [Unstructured SDK 客户端](https://docs.unstructured.io/api-reference/api-services/accessing-unstructured-api)。

如果您想自定义客户端，则必须将 `UnstructuredClient` 实例传递给 `UnstructuredLoader`。下面是一个示例，展示了如何自定义客户端的功能，例如使用您自己的 `requests.Session()`、传递备用的 `server_url` 以及自定义 `RetryConfig` 对象。有关自定义客户端或 SDK 客户端接受哪些其他参数的更多信息，请参阅[Unstructured Python SDK](https://docs.unstructured.io/api-reference/api-services/sdk-python) 文档和[API 参数](https://docs.unstructured.io/api-reference/api-services/api-parameters)文档的客户端部分。请注意，所有 API 参数都应传递给 `UnstructuredLoader`。

<div class="alert alert-block alert-warning"><b>警告:</b> 以下示例可能未使用的 UnstructuredClient 的最新版本，并且未来版本中可能存在破坏性更改。有关最新示例，请参阅 <a href="https://docs.unstructured.io/api-reference/api-services/sdk-python">Unstructured Python SDK</a> 文档。</div>

```python
import requests
from langchain_unstructured import UnstructuredLoader
from unstructured_client import UnstructuredClient
from unstructured_client.utils import BackoffStrategy, RetryConfig

client = UnstructuredClient(
        api_key_auth=os.getenv(
        "UNSTRUCTURED_API_KEY"
    ),  # 注意：客户端的 API 参数是 "api_key_auth"，而不是 "api_key"
        client=requests.Session(),  # 定义您自己的请求会话
        server_url="https://api.unstructuredapp.io/general/v0/general",  # 定义您自己的 API URL
        retry_config=RetryConfig(
                strategy="backoff",
                retry_connection_errors=True,
                backoff=BackoffStrategy(
                        initial_interval=500,
                        max_interval=60000,
                        exponent=1.5,
                        max_elapsed_time=900000,
        ),
    ),  # 定义您自己的重试配置
)

loader = UnstructuredLoader(
    "./example_data/layout-parser-paper.pdf",
        partition_via_api=True,
        client=client,
        split_pdf_page=True,
        split_pdf_page_range=[1, 10],
)

docs = loader.load()

print(docs[0].metadata["filename"], ": ", docs[0].page_content[:100])
```

## 分块 (Chunking)

`UnstructuredLoader` 不支持像旧的加载器 `UnstructuredFileLoader` 等那样使用 `mode` 形参来分组文本。它支持“分块 (chunking)”操作。Unstructured 中的分块与您可能熟悉的基于纯文本特征（如可能指示段落边界或列表项边界的换行符 "\n\n" 或 "\n"）形成块的其他分块机制不同。相反，所有文档都使用针对每种文档格式的特定知识进行分割，将文档划分为**语义单元**（文档元素），我们仅在单个元素超过所需的最大块大小时才需要诉诸文本分割。一般来说，分块会将连续的元素组合起来，形成尽可能大而又不超过最大块大小的块。分块会产生一系列 `CompositeElement`、`Table` 或 `TableChunk` 元素。每个“块”是这三种类型中的一种实例。

有关分块选项的更多详细信息，请参阅此[页面](https://docs.unstructured.io/open-source/core-functionality/chunking)，但要重现 `mode="single"` 的相同行为，您可以设置 `chunking_strategy="basic"`、`max_characters=<一个非常大的数字>` 和 `include_orig_elements=False`。

```python
from langchain_unstructured import UnstructuredLoader

loader = UnstructuredLoader(
    "./example_data/layout-parser-paper.pdf",
    chunking_strategy="basic",
    max_characters=1000000,
    include_orig_elements=False,
)

docs = loader.load()

print("LangChain 文档数量:", len(docs))
print("文档文本长度:", len(docs[0].page_content))
```

```output
LangChain 文档数量: 1
文档文本长度: 42772
```

## 加载网页 (Loading web pages)

当在本地运行时，`UnstructuredLoader` 接受一个 `web_url` 形参，该形参用于填充底层 Unstructured [partition](https://docs.unstructured.io/open-source/core-functionality/partitioning) 方法的 `url` 参数。这使得解析远程托管的文档（如 HTML 网页）成为可能。

使用示例：

```python
from langchain_unstructured import UnstructuredLoader

loader = UnstructuredLoader(web_url="https://www.example.com")
docs = loader.load()

for doc in docs:
    print(f"{doc}\n")
```
