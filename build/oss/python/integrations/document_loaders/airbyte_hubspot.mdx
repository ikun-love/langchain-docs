>[Airbyte](https://github.com/airbytehq/airbyte) 是一个数据集成平台，用于构建从 API、数据库和文件到数据仓库和数据湖的 ELT（提取、加载、转换）管道。它拥有最丰富的 ELT 连接器目录，可连接到各种数据仓库和数据库。

此加载器将 Hubspot 连接器暴露为一个文档加载器，允许您将各种 Hubspot 对象加载为 LangChain 中的 `Document`。

## 安装

首先，您需要安装 `airbyte-source-hubspot` Python 包。

```python
pip install -qU  airbyte-source-hubspot
```

## 示例

请参阅 [Airbyte 文档页面](https://docs.airbyte.com/integrations/sources/hubspot/)，了解有关如何配置读取器的详细信息。
配置对象应遵循的 JSON Schema 可以在 GitHub 上找到：[https://github.com/airbytehq/airbyte/blob/master/airbyte-integrations/connectors/source-hubspot/source_hubspot/spec.yaml](https://github.com/airbytehq/airbyte/blob/master/airbyte-integrations/connectors/source-hubspot/source_hubspot/spec.yaml)。

一般配置结构如下所示：

```python
{
  "start_date": "<从该日期开始检索记录（ISO 格式），例如 2020-10-20T00:00:00Z>",
  "credentials": {
    "credentials_title": "Private App Credentials",
    "access_token": "<您的私有应用的访问令牌>"
  }
}
```

默认情况下，所有字段都作为元数据存储在文档中，并且 `page_content`（文档内容）被设置为一个空字符串。您需要通过转换读取器返回的文档来构造文档的文本内容。

```python
from langchain_community.document_loaders.airbyte import AirbyteHubspotLoader

config = {
    # 您的 hubspot 配置
}

loader = AirbyteHubspotLoader(
    config=config, stream_name="products"
)  # 使用上面链接的文档中提到的所有流列表
```

现在您可以像往常一样加载文档：

```python
docs = loader.load()
```

因为 `load` 方法返回一个列表，它会阻塞直到所有文档加载完毕。为了更好地控制此过程，您也可以使用 `lazy_load` 方法，它返回一个迭代器：

```python
docs_iterator = loader.lazy_load()
```

请记住，默认情况下页面内容是空的，并且元数据对象包含记录中的所有信息。要自定义文档的处理方式，请创建一个继承自基础加载器的类，并自行实现 `_handle_records` 方法：

```python
from langchain_core.documents import Document


def handle_record(record, id):
    # 示例：将记录中的 'title' 字段作为 page_content
    return Document(page_content=record.data["title"], metadata=record.data)


loader = AirbyteHubspotLoader(
    config=config, record_handler=handle_record, stream_name="products"
)
docs = loader.load()
```

## 增量加载 (Incremental Loads)

某些流支持增量加载，这意味着源会跟踪已同步的记录，并且不会再次加载它们。这对于数据量大且更新频繁的源非常有用。

要利用此功能，请存储加载器的 `last_state` 属性，并在重新创建加载器时将其传入。这将确保只加载新记录。

```python
last_state = loader.last_state  # 安全地存储状态

incremental_loader = AirbyteHubspotLoader(
    config=config, stream_name="products", state=last_state
)

new_docs = incremental_loader.load()
```
