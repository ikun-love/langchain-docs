>[SurrealDB](https://surrealdb.com/) 是一款专为现代应用（包括 Web、移动应用、无服务器架构 (serverless)、Jamstack、后端以及传统应用）设计的端到端云原生数据库。使用 SurrealDB，您可以简化数据库和 API 基础设施，缩短开发时间，并快速、经济高效地构建安全、高性能的应用。
>
>**SurrealDB 的关键特性包括：**
>
>* **缩短开发时间：** SurrealDB 通过消除对大多数服务端组件的需求，简化了数据库和 API 堆栈，使您能够更快、更经济地构建安全、高性能的应用。
>* **实时协作 API 后端服务：** SurrealDB 同时充当数据库和 API 后端服务，支持实时协作功能。
>* **支持多种查询语言：** SurrealDB 支持来自客户端设备的 SQL 查询、GraphQL、ACID 事务、WebSocket 连接、结构化和非结构化数据、图查询、全文索引以及地理空间查询。
>* **精细的访问控制：** SurrealDB 提供基于权限的行级访问控制，让您能够精确地管理数据访问权限。
>
>查看 [特性](https://surrealdb.com/features)、最新的 [发布版本](https://surrealdb.com/releases) 和 [文档](https://surrealdb.com/docs)。

本 Notebook 展示了如何使用与 `SurrealDBLoader` 相关的各项功能。

## 概述

SurrealDB 文档加载器（Document Loader）会从 SurrealDB 数据库中返回一个 LangChain `Document` 对象的列表。

该文档加载器接受以下可选参数：

* `dburl`: 连接到 WebSocket 端点的连接字符串。默认为 `ws://localhost:8000/rpc`
* `ns`: 命名空间 (namespace) 的名称。默认为 `langchain`
* `db`: 数据库 (database) 的名称。默认为 `database`
* `table`: 表 (table) 的名称。默认为 `documents`
* `db_user`: 如果需要，SurrealDB 凭据：数据库用户名。
* `db_pass`: 如果需要，SurrealDB 凭据：数据库密码。
* `filter_criteria`: 一个字典，用于构建 `WHERE` 子句，以便从表中过滤结果。

输出的 [`Document`](https://reference.langchain.com/python/langchain_core/documents/#langchain_core.documents.base.Document) 具有以下结构：

```
Document(
    page_content=<包含结果文档的 JSON 编码字符串>,
    metadata={
        'id': <文档 ID>,
        'ns': <命名空间名称>,
        'db': <数据库名称>,
        'table': <表名称>,
        ... <来自文档 metadata 属性的其他字段>
    }
)
```

```python
# 在 Jupyter Notebook 中运行时添加此导入
import nest_asyncio

```

```python
import json

from langchain_community.document_loaders.surrealdb import SurrealDBLoader
```

```python
loader = SurrealDBLoader(
    dburl="ws://localhost:8000/rpc",
    ns="langchain",
    db="database",
    table="documents",
    db_user="root",
    db_pass="root",
    filter_criteria={},
)
docs = loader.load()
len(docs)
```

```output
42
```

```python
doc = docs[-1]
doc.metadata
```

