title: Datadog 日志
---

>[Datadog](https://www.datadoghq.com/) 是一个用于云规模应用的监控和分析平台。

此加载器（Loader）使用 `datadog_api_client` Python 包从您的 Datadog 应用程序中获取日志。您必须使用您的 `Datadog API 密钥` 和 `APP 密钥` 来初始化此加载器，并且需要传入一个查询条件（query）来提取所需的日志。

```python
from langchain_community.document_loaders import DatadogLogsLoader
```

```python
pip install -qU  datadog-api-client
```

```python
DD_API_KEY = "..."
DD_APP_KEY = "..."
```

```python
query = "service:agent status:error"

loader = DatadogLogsLoader(
    query=query,
    api_key=DD_API_KEY,
    app_key=DD_APP_KEY,
    from_time=1688732708951,  # 可选，时间戳（单位：毫秒）
    to_time=1688736308951,    # 可选，时间戳（单位：毫秒）
    limit=100,                # 可选，默认为 100
)
```

```python
documents = loader.load()
documents
```
