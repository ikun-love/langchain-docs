> [WhatsApp](https://www.whatsapp.com/)（也称为 `WhatsApp Messenger`）是一项免费、跨平台、集中式的即时消息（IM）和语音通话（VoIP）服务。它允许用户发送文本和语音消息、拨打语音和视频电话，以及共享图片、文档、用户位置和其他内容。

本指南将介绍如何将 `WhatsApp Chats` 中的数据加载并转换成可被 LangChain 摄取（Ingest）的格式。

```python
from langchain_community.document_loaders import WhatsAppChatLoader
```

```python
loader = WhatsAppChatLoader("example_data/whatsapp_chat.txt")
```

```python
loader.load()
```
