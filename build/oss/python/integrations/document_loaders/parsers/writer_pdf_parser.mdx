本指南将快速概述如何开始使用 WRITER 的 `PDFParser` [文档加载器](/oss/python/integrations/document_loaders/)。

WRITER 的 [PDF 解析器](https://dev.writer.com/api-guides/api-reference/tool-api/pdf-parser#parse-pdf)可以将 PDF 文档转换为其他格式，如文本或 Markdown。当您需要从 PDF 文件中提取和处理文本内容以供进一步分析或集成到您的工作流程中时，这一点尤其有用。在 `langchain-writer` 中，我们提供了 LangChain 文档解析器对 WRITER PDF 解析器的使用方法。

<Warning>
**弃用通知**: `parse` PDF 工具已被弃用，将于 **2025 年 12 月 22 日**移除。

**迁移路径**: 我们计划引入一个用于聊天补全的预构建 PDF 解析工具，它将提供类似的功能。此工具将与其他预构建工具的工作方式类似。一旦该替代方案可用，我们将提供更多相关详细信息。
</Warning>

## 设置

`PDFParser` 可以在 `langchain-writer` 包中使用：

```python
pip install --quiet -U langchain-writer
```

### 凭证

请注册 [WRITER AI Studio](https://app.writer.com/aistudio/signup?utm_campaign=devrel) 以生成 API 密钥（您可以遵循本 [快速入门指南](https://dev.writer.com/api-guides/quickstart)）。然后，设置 `WRITER_API_KEY` 环境变量：

```python
import getpass
import os

if not os.getenv("WRITER_API_KEY"):
    os.environ["WRITER_API_KEY"] = getpass.getpass("Enter your WRITER API key: ")
```

设置 [LangSmith](https://smith.langchain.com/) 对于获得一流的可观察性也很有帮助（但并非必需）。如果您希望这样做，可以设置 `LANGSMITH_TRACING` 和 `LANGSMITH_API_KEY` 环境变量：

```python
os.environ["LANGSMITH_TRACING"] = "true"
# os.environ["LANGSMITH_API_KEY"] = getpass.getpass()
```

### 实例化

接下来，使用所需的输出格式实例化 WRITER PDF 解析器的一个实例：

```python
from langchain_writer.pdf_parser import PDFParser

parser = PDFParser(format="markdown")
```

## 用法

使用 PDF 解析器有两种方式，可以同步或异步调用。在这两种情况下，PDF 解析器都将返回一个 `[`Document`](https://reference.langchain.com/python/langchain_core/documents/#langchain_core.documents.base.Document)` 对象的列表，每个对象包含 PDF 文件中某一页的解析内容。

### 同步用法

要同步调用 PDF 解析器，请向 `parse` 方法传递一个引用了要解析的 PDF 文件的 `Blob` 对象：

```python
from langchain_core.documents.base import Blob

file = Blob.from_path("../example_data/layout-parser-paper.pdf")

parsed_pages = parser.parse(blob=file)
parsed_pages
```

### 异步用法

要异步调用 PDF 解析器，请向 `aparse` 方法传递一个引用了要解析的 PDF 文件的 `Blob` 对象：

```python
parsed_pages_async = await parser.aparse(blob=file)
parsed_pages_async
```
