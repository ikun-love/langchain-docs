>[阿里云 MaxCompute](https://www.alibabacloud.com/product/maxcompute)（前身为 ODPS）是一个通用、完全托管、多租户的大规模数据仓库数据处理平台。MaxCompute 支持多种数据导入方案和分布式计算模型，使用户能够有效地查询海量数据集、降低生产成本并确保数据安全。

`MaxComputeLoader` 允许您执行 MaxCompute SQL 查询，并将结果作为每行一个文档（document）进行加载。

## 基本用法

要实例化加载器（loader），您需要提供一个要执行的 SQL 查询、您的 MaxCompute 终端节点（endpoint）和项目名称（project），以及您的访问 ID（access ID）和密钥（secret access key）。访问 ID 和密钥可以通过 `access_id` 和 `secret_access_key` 参数直接传入，或者设置为环境变量 `MAX_COMPUTE_ACCESS_ID` 和 `MAX_COMPUTE_SECRET_ACCESS_KEY`。

```python
from langchain_community.document_loaders import MaxComputeLoader
```

```python
base_query = """
SELECT *
FROM (
    SELECT 1 AS id, 'content1' AS content, 'meta_info1' AS meta_info
    UNION ALL
    SELECT 2 AS id, 'content2' AS content, 'meta_info2' AS meta_info
    UNION ALL
    SELECT 3 AS id, 'content3' AS content, 'meta_info3' AS meta_info
) mydata;
"""
```

```python
endpoint = "<ENDPOINT>"
project = "<PROJECT>"
ACCESS_ID = "<ACCESS ID>"
SECRET_ACCESS_KEY = "<SECRET ACCESS KEY>"
```

```python
loader = MaxComputeLoader.from_params(
    base_query,
    endpoint,
    project,
    access_id=ACCESS_ID,
    secret_access_key=SECRET_ACCESS_KEY,
)
data = loader.load()
```

```python
print(data)
```

## 指定哪些列作为内容（Content）与元数据（Metadata）

您可以使用 `page_content_columns` 和 `metadata_columns` 参数来配置哪些列子集应该作为 `Document` 的内容（contents），哪些应该作为元数据（metadata）。

```python
loader = MaxComputeLoader.from_params(
    base_query,
    endpoint,
    project,
    page_content_columns=["content"],  # 指定 Document 的页面内容
    metadata_columns=["id", "meta_info"],  # 指定 Document 的元数据
    access_id=ACCESS_ID,
    secret_access_key=SECRET_ACCESS_KEY,
)
data = loader.load()
```

```python
print(data[0].page_content)
```

```output
content: content1
```

```python
print(data[0].metadata)
```

```output
{'id': 1, 'meta_info': 'meta_info1'}
```
