title: AWS S3 目录加载器

>[Amazon Simple Storage Service (Amazon S3)](https://docs.aws.amazon.com/AmazonS3/latest/userguide/using-folders.html) 是一种对象存储服务

>[AWS S3 目录](https://docs.aws.amazon.com/AmazonS3/latest/userguide/using-folders.html)

本文介绍如何从 `AWS S3` 目录（可以看作是 S3 存储桶中的一个“文件夹”）加载文档对象。

```python
pip install -qU  boto3
```

```python
from langchain_community.document_loaders import S3DirectoryLoader
```

要加载 S3 存储桶中的文档，首先需要实例化 `S3DirectoryLoader`，需要传入存储桶的名称：

```python
loader = S3DirectoryLoader("testing-hwc")
```

然后调用 `load()` 方法：

```python
loader.load()
```

## 指定前缀 (Prefix)

您还可以指定一个 `prefix`（前缀），以便对要加载的文件拥有更精细的控制。前缀相当于 S3 存储桶中的一个子路径。

```python
loader = S3DirectoryLoader("testing-hwc", prefix="fake")
```

```python
loader.load()
```

```output
[Document(page_content='Lorem ipsum dolor sit amet.', lookup_str='', metadata={'source': 's3://testing-hwc/fake.docx'}, lookup_index=0)]
```

## 配置 AWS Boto3 客户端

您可以通过在创建 `S3DirectoryLoader` 实例时传递命名参数来配置 AWS [Boto3](https://boto3.amazonaws.com/v1/documentation/api/latest/index.html) 客户端。

当 AWS 凭证无法设置为环境变量时，这种方式非常有用。有关可以配置的参数列表，请参阅 [参数列表](https://boto3.amazonaws.com/v1/documentation/api/latest/reference/core/session.html#boto3.session.Session)。

```python
loader = S3DirectoryLoader(
    "testing-hwc", aws_access_key_id="xxxx", aws_secret_access_key="yyyy"
)
```

```python
loader.load()
```
