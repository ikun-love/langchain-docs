title: Needle 文档加载器
---

[Needle](https://needle-ai.com) 可让您轻松地以最小的工作量创建 RAG（检索增强生成）管道。

有关更多详细信息，请参阅我们的 [API 文档](https://docs.needle-ai.com/docs/api-reference/needle-api)

## 概述

Needle 文档加载器（Needle Document Loader）是一个实用工具，用于将 Needle 集合与 LangChain 集成。它支持在检索增强生成 (RAG) 工作流程中无缝地存储、检索和利用文档。

本示例演示了以下操作：

* 将文档存储到 Needle 集合中。
* 设置检索器（Retriever）来获取文档。
* 构建检索增强生成 (RAG) 管道。

### 设置

在开始之前，请确保您已设置以下环境变量：

* NEEDLE_API_KEY：用于向 Needle 进行身份验证的 API 密钥。
* OPENAI_API_KEY：用于语言模型操作的 OpenAI API 密钥。

```python
import os
```

```python
os.environ["NEEDLE_API_KEY"] = ""
```

```python
os.environ["OPENAI_API_KEY"] = ""
```

## 初始化

要初始化 `NeedleLoader`，您需要以下参数：

* needle\_api\_key：您的 Needle API 密钥（或者将其设置为环境变量）。
* collection\_id：要使用的 Needle 集合的 ID。

## 实例化

```python
from langchain_community.document_loaders.needle import NeedleLoader

collection_id = "clt_01J87M9T6B71DHZTHNXYZQRG5H"

# 初始化 NeedleLoader 以将文档存储到集合中
document_loader = NeedleLoader(
    needle_api_key=os.getenv("NEEDLE_API_KEY"),
    collection_id=collection_id,
)
```

## 加载 (Load)

要将文件添加到 Needle 集合中：

```python
files = {
    "tech-radar-30.pdf": "https://www.thoughtworks.com/content/dam/thoughtworks/documents/radar/2024/04/tr_technology_radar_vol_30_en.pdf"
}

document_loader.add_files(files=files)
```

`lazy_load` 方法允许您迭代地从 Needle 集合中加载文档，在获取到每个文档时立即生成（yield）它：

## 用法

### 在链（Chain）中使用

下面是一个完整的示例，展示了如何在链中使用 Needle 设置 RAG 管道：

```python
import os

from langchain.chains import create_retrieval_chain
from langchain.chains.combine_documents import create_stuff_documents_chain
from langchain_community.retrievers.needle import NeedleRetriever
from langchain_core.prompts import ChatPromptTemplate
from langchain_openai import ChatOpenAI

llm = ChatOpenAI(temperature=0)

# 初始化 Needle 检索器（确保您的 Needle API 密钥已设置为环境变量）
retriever = NeedleRetriever(
    needle_api_key=os.getenv("NEEDLE_API_KEY"),
    collection_id="clt_01J87M9T6B71DHZTHNXYZQRG5H",
)

# 定义助手的系统提示
system_prompt = """
    您是用于问答任务的助手。
    使用以下检索到的上下文片段来回答问题。
    如果您不知道，请简洁地说明。\n\n{context}
    """

prompt = ChatPromptTemplate.from_messages(
    [("system", system_prompt), ("human", "{input}")]
)

# 使用文档链（stuff chain）和检索器定义问答链
question_answer_chain = create_stuff_documents_chain(llm, prompt)

# 通过组合检索器和问答链来创建 RAG（检索增强生成）链
rag_chain = create_retrieval_chain(retriever, question_answer_chain)

# 定义输入查询
query = {"input": "RAG 移动到被接受（accepted）状态了吗？"}

response = rag_chain.invoke(query)

response
```
