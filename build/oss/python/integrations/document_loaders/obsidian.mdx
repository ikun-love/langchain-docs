> [Obsidian](https://obsidian.md/) 是一个功能强大且可扩展的知识库，它基于您本地存储的纯文本文件文件夹来工作。

本指南涵盖了如何从 `Obsidian` 数据库中加载文档。

由于 `Obsidian` 数据的存储形式就是磁盘上的一个 Markdown 文件文件夹，因此加载器（Loader）只需要接收该目录的路径即可。

`Obsidian` 文件有时也会包含[元数据](https://help.obsidian.md/Editing+and+formatting/Metadata)，这些元数据通常是位于文件顶部的 YAML 块（Block）。这些值将被添加为文档的元数据。 (如果需要禁用此行为，可以在 `ObsidianLoader` 构造函数中传入参数 `collect_metadata=False`)。

```python
from langchain_community.document_loaders import ObsidianLoader
```

```python
loader = ObsidianLoader("<path-to-obsidian>")
```

```python
docs = loader.load()
```
