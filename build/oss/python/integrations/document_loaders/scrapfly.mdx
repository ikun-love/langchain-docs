title: ScrapFly
---

[ScrapFly](https://scrapfly.io/) 是一个集成了无头浏览器能力、代理（Proxy）和反爬虫绕过功能的网页抓取 API。它能够将网页数据提取为易于 LLM 处理的 Markdown 或纯文本格式。

#### 安装

使用 pip 安装 ScrapFly Python SDK 以及所需的 LangChain 软件包：

```shell
pip install scrapfly-sdk langchain langchain-community
```

#### 使用方法

```python
from langchain_community.document_loaders import ScrapflyLoader

scrapfly_loader = ScrapflyLoader(
    ["https://web-scraping.dev/products"],
    api_key="Your ScrapFly API key",  # 从 https://www.scrapfly.io/ 获取您的 API 密钥
    continue_on_failure=True,  # 忽略无法处理的网页并记录其异常
)

# 将 URL 中的文档加载为 Markdown 格式
documents = scrapfly_loader.load()
print(documents)
```

`ScrapFlyLoader` 还允许传入 `ScrapeConfig` 对象来定制抓取请求。有关完整的特性详情及其 API 参数，请参阅文档：[scrapfly.io/docs/scrape-api/getting-started](https://scrapfly.io/docs/scrape-api/getting-started)

```python
from langchain_community.document_loaders import ScrapflyLoader

scrapfly_scrape_config = {
    "asp": True,  # 绕过反爬虫和反机器人解决方案，例如 Cloudflare
    "render_js": True,  # 使用云端无头浏览器启用 JavaScript 渲染
    "proxy_pool": "public_residential_pool",  # 选择一个代理池（数据中心或住宅）
    "country": "us",  # 选择一个代理地理位置
    "auto_scroll": True,  # 自动滚动页面
    "js": "",  # 由无头浏览器执行自定义 JavaScript 代码
}

scrapfly_loader = ScrapflyLoader(
    ["https://web-scraping.dev/products"],
    api_key="Your ScrapFly API key",  # 从 https://www.scrapfly.io/ 获取您的 API 密钥
    continue_on_failure=True,  # 忽略无法处理的网页并记录其异常
    scrape_config=scrapfly_scrape_config,  # 传入 scrape_config 对象
    scrape_format="markdown",  # 抓取结果的格式，可以是 `markdown`(默认) 或 `text`
)

# 将 URL 中的文档加载为 Markdown 格式
documents = scrapfly_loader.load()
print(documents)
```
