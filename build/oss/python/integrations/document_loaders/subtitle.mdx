> [SubRip 文件格式](https://en.wikipedia.org/wiki/SubRip#SubRip_file_format) 在 `Matroska` 多媒体容器格式网站上被描述为“可能是所有字幕格式中最基础的一种”。`SubRip (SubRip Text)` 文件以 `.srt` 扩展名命名，它包含按顺序编号（从 1 开始）的格式化纯文本行，每组字幕之间用一个空行隔开。使用的定时码格式是 时:分:秒,毫秒，其中时间单位固定为两位零填充数字，小数部分固定为三位零填充数字（`00:00:00,000`）。由于该程序最初是在法国编写的，因此小数分隔符使用的是逗号。

如何从字幕（`.srt`）文件中加载数据

请下载 [此处的示例 .srt 文件](https://www.opensubtitles.org/en/subtitles/5575150/star-wars-the-clone-wars-crisis-at-the-heart-en) 进行测试。

```python
pip install -qU  pysrt
```

```python
from langchain_community.document_loaders import SRTLoader
```

```python
loader = SRTLoader(
    "example_data/Star_Wars_The_Clone_Wars_S06E07_Crisis_at_the_Heart.srt"
)
```

```python
docs = loader.load()
```

```python
docs[0].page_content[:100]
```

```output
'<i>Corruption discovered\nat the core of the Banking Clan!</i> <i>Reunited, Rush Clovis\nand Senator A'
```
