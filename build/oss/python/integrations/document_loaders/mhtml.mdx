MHTML（有时简称为 MHT）代表 MIME **H**yper**M**ake**L**ang，它是一种用于电子邮件和存档网页的格式。MHTML 是一个单一的文件，其中**包**含了整个网页的内容。当用户将一个网页保存为 MHTML 格式时，这个文件扩展名会包含 HTML 代码、图像、音频文件、Flash 动画等所有相关资源。

```python
from langchain_community.document_loaders import MHTMLLoader
```

```python
# 创建 MHTML 文件的新加载器对象
loader = MHTMLLoader(
    file_path="../../../../../../tests/integration_tests/examples/example.mht"
)

# 从文件中加载文档
documents = loader.load()

# 打印文档以查看结果
for doc in documents:
    print(doc)
```
