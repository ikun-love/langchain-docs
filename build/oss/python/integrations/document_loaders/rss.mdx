本篇内容涵盖了如何从一系列 RSS 源 URL 中加载 HTML 新闻文章，并将它们转换为我们下游可以使用的文档格式。

```python
pip install -qU  feedparser newspaper3k listparser
```

```python
from langchain_community.document_loaders import RSSFeedLoader
```

```python
urls = ["https://news.ycombinator.com/rss"]
```

将 `urls` 传入以下代码以将它们加载到 `Document` 对象中：

```python
loader = RSSFeedLoader(urls=urls)
data = loader.load()
print(len(data))
```

```python
print(data[0].page_content)
```

您可以将参数传递给 `NewsURLLoader`，后者将使用这些参数来加载文章。

```python
loader = RSSFeedLoader(urls=urls, nlp=True)
data = loader.load()
print(len(data))
```

您也可以使用 OPML 文件，例如 Feedly 导出的文件。传入 URL 或 OPML 内容。

```python
with open("example_data/sample_rss_feeds.opml", "r") as f:
        loader = RSSFeedLoader(opml=f.read())
data = loader.load()
print(len(data))
```
