>[Jupyter Notebook](https://en.wikipedia.org/wiki/Project_Jupyter#Applications)（原名 `IPython Notebook`）是一个基于 Web 的交互式计算环境，用于创建 Notebook 文档。

本 Notebook 将介绍如何将来自 `Jupyter notebook (.ipynb)` 的数据加载到 LangChain 可以使用的格式中。

```python
from langchain_community.document_loaders import NotebookLoader
```

```python
loader = NotebookLoader(
    "example_data/notebook.ipynb",
    include_outputs=True,
    max_output_length=20,
    remove_newline=True,
)
```

`NotebookLoader.load()` 会将 `.ipynb` Notebook 文件加载为一个 [`Document`](https://reference.langchain.com/python/langchain_core/documents/#langchain_core.documents.base.Document) 对象。

**参数**:

* `include_outputs` (bool): 是否将单元格的输出包含在最终的文档中（默认为 False）。
* `max_output_length` (int): 从每个单元格输出中包含的最大字符数（默认为 10）。
* `remove_newline` (bool): 是否从单元格的源码和输出中移除换行符（默认为 False）。
* `traceback` (bool): 是否包含完整的追溯信息（默认为 False）。

```python
loader.load()
```
