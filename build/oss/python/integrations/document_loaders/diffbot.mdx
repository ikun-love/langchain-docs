>[Diffbot](https://docs.diffbot.com/docs/getting-started-with-diffbot) 是一套基于机器学习（ML）的产品套件，它使结构化网络数据变得轻而易举。

>Diffbot 的 [Extract API](https://docs.diffbot.com/reference/extract-introduction) 是一项服务，用于对网页数据进行结构化和规范化处理。

>与传统的网页抓取工具不同，`Diffbot Extract` 不需要任何预设的规则就能读取页面上的内容。它使用计算机视觉模型将页面分类为 20 种可能的类型之一，然后将原始的 HTML 标记转换为 JSON 格式。由此产生的结构化 JSON 遵循一套一致的 [基于类型的本体（ontology）](https://docs.diffbot.com/docs/ontology)，这使得能够使用相同的 Schema 从多个不同的网页源中提取数据变得非常容易。

## 概述

本指南介绍了如何使用 [Diffbot Extract API](https://www.diffbot.com/products/extract/) 从一系列 URL 中提取数据，并将其转换为可供后续处理的结构化 JSON 格式。

## 设置

首先安装所需的软件包。

```python
pip install -qU langchain-community
```

Diffbot 的 Extract API 需要一个 API 令牌（Token）。请遵循这些说明 [获取免费的 API 令牌](/oss/python/integrations/providers/diffbot#installation-and-setup)，然后设置一个环境变量。

```python
%env DIFFBOT_API_TOKEN REPLACE_WITH_YOUR_TOKEN
```

## 使用文档加载器（Document Loader）

导入 `DiffbotLoader` 模块，并使用 URL 列表和您的 Diffbot 令牌对其进行实例化。

```python
import os

from langchain_community.document_loaders import DiffbotLoader

urls = [
    "https://python.langchain.com/",
]

loader = DiffbotLoader(urls=urls, api_token=os.environ.get("DIFFBOT_API_TOKEN"))
```

使用 `.load()` 方法，您可以看到加载后的文档内容：

```python
loader.load()
```

## 将提取的文本转换为图文档（Graph Document）

结构化的页面内容可以通过 `DiffbotGraphTransformer` 进一步处理，将实体和关系提取到图中。

```python
pip install -qU langchain-experimental
```

```python
from langchain_experimental.graph_transformers.diffbot import DiffbotGraphTransformer

diffbot_nlp = DiffbotGraphTransformer(
    diffbot_api_key=os.environ.get("DIFFBOT_API_TOKEN")
)
graph_documents = diffbot_nlp.convert_to_graph_documents(loader.load())
```

要继续将数据加载到知识图谱（Knowledge Graph）中，请遵循 [`DiffbotGraphTransformer` 指南](/oss/python/integrations/graphs/diffbot/#loading-the-data-into-a-knowledge-graph)。
```
