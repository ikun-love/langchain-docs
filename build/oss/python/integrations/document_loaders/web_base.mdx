本文介绍如何使用 `WebBaseLoader` 将 `HTML` 网页中的所有文本加载为文档格式，以便后续处理。如需更复杂的网页加载逻辑，请参阅一些子类加载器的示例，例如 `IMSDbLoader`、`AZLyricsLoader` 和 `CollegeConfidentialLoader`。

如果您不想手动处理网站爬取、绕过 JavaScript 屏蔽的站点以及数据清洗等问题，可以考虑使用 `FireCrawlLoader` 或更快速的选项 `SpiderLoader`。

## 设置

### 凭据

`WebBaseLoader` 不需要任何凭据（Credentials）。

### 安装

要使用 `WebBaseLoader`，您首先需要安装 `langchain-community` Python 包。

```python
pip install -qU langchain-community beautifulsoup4
```

## 初始化

现在我们可以实例化模型对象并加载文档：

```python
from langchain_community.document_loaders import WebBaseLoader

loader = WebBaseLoader("https://www.example.com/")
```

为了绕过获取过程中出现的 SSL 验证错误，您可以设置 "verify" 选项：

`loader.requests_kwargs = {'verify':False}`

### 使用多个页面进行初始化

您也可以传入一个页面列表进行加载。

```python
loader_multiple_pages = WebBaseLoader(
    ["https://www.example.com/", "https://google.com"]
)
```

docs = loader.load()

### 并发加载多个 URL

您可以通过并发抓取和解析多个 URL 来加快抓取过程。

并发请求存在合理的限制，默认为每秒 2 个请求。如果您不关心“做个好公民”（即不限制速度），或者您控制了所抓取的服务器且不担心负载，您可以更改 `requests_per_second` 参数以增加最大并发请求数。请注意，虽然这会加快抓取过程，但可能会导致服务器阻止您访问。请谨慎操作！

```python
pip install -qU  nest_asyncio

# 修复 asyncio 和 jupyter 之间的 Bug
import nest_asyncio

nest_asyncio.apply()
```

```python
loader = WebBaseLoader(["https://www.example.com/", "https://google.com"])
loader.requests_per_second = 1
docs = loader.aload()
docs
```

## 惰性加载 (Lazy Load)

您可以使用惰性加载（lazy loading）的方式一次只加载一个页面，以最小化内存占用。

```python
pages = []
for doc in loader.lazy_load():
    pages.append(doc)

print(pages[0].page_content[:100])
print(pages[0].metadata)
```

## 使用代理 (Using proxies)

有时您可能需要使用代理（proxies）来绕过 IP 封锁。您可以将代理字典传递给加载器（以及其底层的 `requests` 库）来使用它们。

```python
loader = WebBaseLoader(
        "https://www.walmart.com/search?q=parrots",
        proxies={
        "http": "http://{username}:{password}:@proxy.service.com:6666/",
        "https": "https://{username}:{password}:@proxy.service.com:6666/",
    },
)
docs = loader.load()
```
