---
title: 复制粘贴
---

本 Notebook 介绍如何从你刚刚复制粘贴的内容中加载一个 `Document` 对象。在这种情况下，你甚至不需要使用 `DocumentLoader`，而是可以直接构造 `Document` 对象。

```python
from langchain_core.documents import Document
```

```python
text = "..... 将你复制粘贴的文本放在这里......"
```

```python
doc = Document(page_content=text)
```

## 元数据 (Metadata)

如果你想为这（段）文本的来源添加元数据，可以通过 `metadata` 键轻松实现。

```python
metadata = {"source": "internet", "date": "Friday"}
```

```python
doc = Document(page_content=text, metadata=metadata)
```
