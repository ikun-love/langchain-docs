>[Yuque](https://www.yuque.com/) 是一个专业的、基于云端的知识库，专为团队协作和文档编写而设计。

本指南涵盖了如何从 `Yuque` 加载文档。

您可以在 [个人设置](https://www.yuque.com/settings/tokens) 页面的个人头像处点击，以获取个人访问令牌（Personal Access Token）。

```python
from langchain_community.document_loaders import YuqueLoader
```

```python
loader = YuqueLoader(access_token="<your_personal_access_token>")
```

```python
docs = loader.load()
```
