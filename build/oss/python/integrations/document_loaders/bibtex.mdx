>[BibTeX](https://www.ctan.org/pkg/bibtex) 是一种文件格式和参考文献管理系统，通常与 `LaTeX` 排版系统配合使用。它提供了一种组织和存储学术及研究文档参考文献信息的方式。

`BibTeX` 文件拥有 `.bib` 扩展名，由纯文本条目组成，代表对各种出版物（如书籍、期刊文章、会议论文、学位论文等）的引用。每个 `BibTeX` 条目遵循特定的结构，并包含作者姓名、出版物标题、期刊或书名、出版年份、页码等不同的文献学详细信息字段。

BibTeX 文件还可以存储文档的路径，例如可以检索到的 `.pdf` 文件路径。

## 安装

首先，你需要安装 `bibtexparser` 和 `PyMuPDF` 库。

```python
pip install -qU  bibtexparser pymupdf
```

## 示例

`BibtexLoader` 具有以下参数：

- `file_path`: `.bib` BibTeX 文件的路径。
- 可选参数 `max_docs`: 默认为 `None`，即不设置限制。用于限制检索到的文档数量。
- 可选参数 `max_content_chars`: 默认为 `4000`。用于限制单个文档中的字符数。
- 可选参数 `load_extra_meta`: 默认为 `False`。默认情况下，它只加载 BibTeX 条目中最重要的字段：`Published`（出版年份）、`Title`（标题）、`Authors`（作者）、`Summary`（摘要/Abstract）、`Journal`（期刊）、`Keywords`（关键词）和 `URL`。如果设置为 `True`，它还将尝试加载并返回 `entry_id` (条目 ID)、`note` (备注)、`doi` (数字对象标识符) 和 `links` (链接) 字段。
- 可选参数 `file_pattern`: 默认为 `r'[^:]+\.pdf'`。用于在 `file` 字段中查找 PDF 文件的正则表达式模式。默认模式支持 `Zotero` 风格的 BibTeX 以及裸文件路径。

```python
from langchain_community.document_loaders import BibtexLoader
```

```python
# 创建一个虚拟的 bibtex 文件并下载一个 pdf。
import urllib.request

urllib.request.urlretrieve(
    "https://www.fourmilab.ch/etexts/einstein/specrel/specrel.pdf", "einstein1905.pdf"
)

bibtex_text = """
    @article{einstein1915,
        title={Die Feldgleichungen der Gravitation},
        abstract={Die Grundgleichungen der Gravitation, die ich hier entwickeln werde, wurden von mir in einer Abhandlung: ,,Die formale Grundlage der allgemeinen Relativit{\"a}tstheorie`` in den Sitzungsberichten der Preu{\ss}ischen Akademie der Wissenschaften 1915 ver{\"o}ffentlicht.},
        author={Einstein, Albert},
        journal={Sitzungsberichte der K{\"o}niglich Preu{\ss}ischen Akademie der Wissenschaften},
        volume={1915},
        number={1},
        pages={844--847},
        year={1915},
        doi={10.1002/andp.19163540702},
        link={https://onlinelibrary.wiley.com/doi/abs/10.1002/andp.19163540702},
        file={einstein1905.pdf}
    }
    """
# 将 bibtex_text 保存到 biblio.bib 文件中
with open("./biblio.bib", "w") as file:
    file.write(bibtex_text)
```

```python
docs = BibtexLoader("./biblio.bib").load()
```
