>[Twitter](https://twitter.com/) 是一个在线社交媒体和社交网络服务。

此加载器使用 `tweepy` Python 包，从一组指定的 `Twitter` 用户的推文中抓取文本。您必须使用您的 `Twitter API` 令牌初始化加载器，并且需要传入目标 Twitter 用户名。

```python
from langchain_community.document_loaders import TwitterTweetLoader
```

```python
pip install -qU  tweepy
```

```python
loader = TwitterTweetLoader.from_bearer_token(
    oauth2_bearer_token="YOUR BEARER TOKEN",
    twitter_users=["elonmusk"],
    number_tweets=50,  # 默认值为 100
)

# 或者从访问令牌和消费者密钥加载
# loader = TwitterTweetLoader.from_secrets(
#     access_token='YOUR ACCESS TOKEN',
#     access_token_secret='YOUR ACCESS TOKEN SECRET',
#     consumer_key='YOUR CONSUMER KEY',
#     consumer_secret='YOUR CONSUMER SECRET',
#     twitter_users=['elonmusk'],
#     number_tweets=50,
# )
```

```python
documents = loader.load()
documents[:5]
```
