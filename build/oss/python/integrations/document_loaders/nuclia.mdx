>[Nuclia](https://nuclia.com) 会自动索引您来自任何内部和外部来源的非结构化数据，从而提供优化的搜索结果和生成式答案。它可以处理视频和音频转录、图像内容提取以及文档解析。

> `Nuclia Understanding API` 支持处理非结构化数据，包括文本、网页、文档以及音视频内容。它会提取所有文本内容（在需要时使用语音转文本或 OCR 技术），同时还会提取元数据、嵌入式文件（如 PDF 中的图片）和网页链接。如果启用了机器学习，它还能识别实体、提供内容摘要并为所有句子生成向量嵌入（embeddings）。

## 设置 (Setup)

要使用 `Nuclia Understanding API`，您需要拥有一个 Nuclia 账户。您可以在 [https://nuclia.cloud](https://nuclia.cloud) 免费创建一个账户，然后 [创建一个 NUA 密钥](https://docs.nuclia.dev/docs/docs/using/understanding/intro)。

```python
pip install -qU  protobuf
pip install -qU  nucliadb-protos
```

```python
import os

os.environ["NUCLIA_ZONE"] = "<YOUR_ZONE>"  # 例如：europe-1
os.environ["NUCLIA_NUA_KEY"] = "<YOUR_API_KEY>"
```

## 示例 (Example)

要使用 Nuclia 文档加载器，您需要实例化一个 `NucliaUnderstandingAPI` 工具：

```python
from langchain_community.tools.nuclia import NucliaUnderstandingAPI

nua = NucliaUnderstandingAPI(enable_ml=False)
```

```python
from langchain_community.document_loaders.nuclia import NucliaLoader

loader = NucliaLoader("./interview.mp4", nua)
```

您现在可以循环调用 `load` 方法，直到获取到文档为止。

```python
import time

pending = True
while pending:
    time.sleep(15)
    docs = loader.load()
    if len(docs) > 0:
        print(docs[0].page_content)
        print(docs[0].metadata)
        pending = False
    else:
        print("waiting...")
```

## 检索到的信息 (Retrieved information)

Nuclia 返回以下信息：

- 文件元数据 (file metadata)
- 提取的文本 (extracted text)
- 嵌套文本（例如嵌入图片中的文本）(nested text (like text in an embedded image))
- 段落和句子划分（由其第一个和最后一个字符的位置定义，对于视频或音频文件还包含开始和结束时间）(paragraphs and sentences splitting (defined by the position of their first and last characters, plus start time and end time for a video or audio file))
- 链接 (links)
- 缩略图 (a thumbnail)
- 嵌入式文件 (embedded files)

注意：

  生成的（如缩略图、提取的嵌入文件等）文件将以 Token 的形式提供。您可以使用 [`/processing/download` 端点](https://docs.nuclia.dev/docs/api#operation/Download_binary_file_processing_download_get) 进行下载。

  此外，在任何层次结构中，如果某个属性的大小超过了设定的限制，它将被放入一个可下载的文件中，并在文档中被替换为一个文件指针。该指针格式为 `{"file": {"uri": "JWT_TOKEN"}}`。规则是：如果消息的总大小大于 1,000,000 个字符，最大的部分将被移至可下载文件。首先，压缩过程将针对向量 (vectors)。如果仍然不够，它将针对大型字段元数据 (large field metadata)，最后才会针对提取的文本 (extracted text)。
