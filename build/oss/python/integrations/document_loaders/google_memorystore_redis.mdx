> [Google Memorystore for Redis](https://cloud.google.com/memorystore/docs/redis/memorystore-for-redis-overview) 是一项全代管式服务，它基于 Redis in-memory data store（内存数据存储），可用于构建提供毫秒级以下数据访问的应用缓存。通过利用 Memorystore for Redis 的 LangChain 集成，您可以扩展数据库应用以构建由 AI 驱动的体验。

本 Notebook 演示了如何使用 [Memorystore for Redis](https://cloud.google.com/memorystore/docs/redis/memorystore-for-redis-overview) 通过 `MemorystoreDocumentLoader` 和 `MemorystoreDocumentSaver` 来[保存、加载和删除 LangChain 文档](/oss/python/integrations/document_loaders)。

了解有关该包的更多信息，请访问 [GitHub](https://github.com/googleapis/langchain-google-memorystore-redis-python/)。

## 基本用法

### 保存文档

使用 `MemorystoreDocumentSaver.add_documents(<documents>)` 保存 LangChain 文档。要初始化 `MemorystoreDocumentSaver` 类，您需要提供两项内容：

1. `client` - 一个 `redis.Redis` 客户端对象。
2. `key_prefix` - 用于在 Redis 中存储文档的键的前缀。

文档将存储到使用指定 `key_prefix` 随机生成的键中。或者，您可以在 `add_documents` 方法中指定 `ids`，从而指定键的后缀。

```python
import redis
from langchain_core.documents import Document
from langchain_google_memorystore_redis import MemorystoreDocumentSaver

test_docs = [
    Document(
        page_content="Apple Granny Smith 150 0.99 1",
        metadata={"fruit_id": 1},
    ),
    Document(
        page_content="Banana Cavendish 200 0.59 0",
        metadata={"fruit_id": 2},
    ),
    Document(
        page_content="Orange Navel 80 1.29 1",
        metadata={"fruit_id": 3},
    ),
]
doc_ids = [f"{i}" for i in range(len(test_docs))]

redis_client = redis.from_url(ENDPOINT)
saver = MemorystoreDocumentSaver(
    client=redis_client,
    key_prefix=KEY_PREFIX,
    content_field="page_content",
)
saver.add_documents(test_docs, ids=doc_ids)
```

### 加载文档

初始化一个加载器，用于加载存储在具有特定前缀的 Memorystore for Redis 实例中的所有文档。

使用 `MemorystoreDocumentLoader.load()` 或 `MemorystoreDocumentLoader.lazy_load()` 加载 LangChain 文档。`lazy_load` 会返回一个生成器，该生成器仅在迭代时才查询数据库。要初始化 `MemorystoreDocumentLoader` 类，您需要提供：

1. `client` - 一个 `redis.Redis` 客户端对象。
2. `key_prefix` - 用于在 Redis 中存储文档的键的前缀。

```python
import redis
from langchain_google_memorystore_redis import MemorystoreDocumentLoader

redis_client = redis.from_url(ENDPOINT)
loader = MemorystoreDocumentLoader(
    client=redis_client,
    key_prefix=KEY_PREFIX,
    content_fields=set(["page_content"]),
)
for doc in loader.lazy_load():
    print("Loaded documents:", doc)
```

### 删除文档

使用 `MemorystoreDocumentSaver.delete()` 删除 Memorystore for Redis 实例中具有指定前缀的所有键。如果您知道键的后缀，也可以指定它们。

```python
docs = loader.load()
print("Documents before delete:", docs)

saver.delete(ids=[0])
print("Documents after delete:", loader.load())

saver.delete()
print("Documents after delete all:", loader.load())
```

## 高级用法

### 自定义文档内容和元数据

当使用多于一个内容字段初始化加载器时，加载的文档的 `page_content` 将包含一个 JSON 编码的字符串，其顶层字段等同于 `content_fields` 中指定的字段。

如果指定了 `metadata_fields`，则加载的文档的 `metadata` 字段将仅包含等同于指定 `metadata_fields` 的顶层字段。如果任何元数据字段的值存储为 JSON 编码的字符串，则在加载到元数据字段之前会对其进行解码。

```python
loader = MemorystoreDocumentLoader(
    client=redis_client,
    key_prefix=KEY_PREFIX,
    content_fields=set(["content_field_1", "content_field_2"]),
    metadata_fields=set(["title", "author"]),
)
```
