[html2text](https://github.com/Alir3z4/html2text/) 是一个 Python 包，可以将一页 `HTML` 内容转换为干净、易于阅读的纯 `ASCII` 文本。

这种 ASCII 文本恰好也是有效的 `Markdown`（一种文本转 HTML 的格式）。

```python
pip install -qU html2text
```

```python
from langchain_community.document_loaders import AsyncHtmlLoader

urls = ["https://www.espn.com", "https://lilianweng.github.io/posts/2023-06-23-agent/"]
loader = AsyncHtmlLoader(urls)
docs = loader.load()
```

```python
from langchain_community.document_transformers import Html2TextTransformer

urls = ["https://www.espn.com", "https://lilianweng.github.io/posts/2023-06-23-agent/"]
html2text = Html2TextTransformer()
docs_transformed = html2text.transform_documents(docs)

print(docs_transformed[0].page_content[1000:2000])

print(docs_transformed[1].page_content[1000:2000])
```
