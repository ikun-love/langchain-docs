LangChain 的 MariaDB 集成（`langchain-mariadb`）为使用 MariaDB 11.7.1 及以上版本提供了向量能力，该集成在 MIT 许可下分发。用户可以按原样使用提供的实现，也可以根据特定需求进行定制。
其主要特性包括：

* 内置的向量相似度搜索
* 支持余弦（cosine）和欧几里得（euclidean）距离度量
* 强大的元数据过滤选项
* 通过连接池（connection pooling）实现性能优化
* 可配置的表和列设置

## 设置 (Setup)

使用以下命令启动一个 MariaDB Docker 容器：

```python
!docker run --name mariadb-container -e MARIADB_ROOT_PASSWORD=langchain -e MARIADB_DATABASE=langchain -p 3306:3306 -d mariadb:11.7
```

### 安装软件包

该软件包使用了 SQLAlchemy，但与 MariaDB 连接器配合使用效果最佳，而 MariaDB 连接器需要 C/C++ 组件：

```python
# Debian, Ubuntu
!sudo apt install libmariadb3 libmariadb-dev

# CentOS, RHEL, Rocky Linux
!sudo yum install MariaDB-shared MariaDB-devel

# 安装 Python 连接器
!pip install -U mariadb
```

然后安装 `langchain-mariadb` 软件包

```python
pip install -U langchain-mariadb

```

VectorStore（向量存储）与 LLM 模型协同工作，这里以 `langchain-openai` 为例：

```python
pip install langchain-openai
export OPENAI_API_KEY=...

```

## 初始化 (Initialization)

```python
from langchain_core.documents import Document
from langchain_mariadb import MariaDBStore
from langchain_openai import OpenAIEmbeddings

# 连接字符串
url = f"mariadb+mariadbconnector://myuser:mypassword@localhost/langchain"

# 初始化向量存储
vectorstore = MariaDBStore(
    embeddings=OpenAIEmbeddings(),
    embedding_length=1536,
    datasource=url,
    collection_name="my_docs",
)
```

## 管理向量存储 (Manage vector store)

### 添加数据 (Adding Data)

您可以添加带有元数据（metadata）的 `Document` 对象：

```python
docs = [
    Document(
        page_content="there are cats in the pond",
        metadata={"id": 1, "location": "pond", "topic": "animals"},
    ),
    Document(
        page_content="ducks are also found in the pond",
        metadata={"id": 2, "location": "pond", "topic": "animals"},
    ),
    # 更多文档...
]
vectorstore.add_documents(docs)
```

或者添加纯文本（plain text）并附带可选的元数据：

```python
texts = [
    "a sculpture exhibit is also at the museum",
    "a new coffee shop opened on Main Street",
]
metadatas = [
    {"id": 6, "location": "museum", "topic": "art"},
    {"id": 7, "location": "Main Street", "topic": "food"},
]

vectorstore.add_texts(texts=texts, metadatas=metadatas)
```

## 查询向量存储 (Query vector store)

```python
# 基本相似度搜索
results = vectorstore.similarity_search("Hello", k=2)

# 带元数据过滤的搜索
results = vectorstore.similarity_search("Hello", filter={"category": "greeting"})
```

### 过滤选项 (Filter Options)

系统支持对元数据执行各种过滤操作：

* 相等性：$eq
* 不等性：$ne
* 比较：$lt, $lte, $gt, $gte
* 列表操作：$in, $nin
* 文本匹配：$like, $nlike
* 逻辑操作：$and, $or, $not

示例：

```python
# 带简单过滤条件的搜索
results = vectorstore.similarity_search(
    "kitty", k=10, filter={"id": {"$in": [1, 5, 2, 9]}}
)

# 带有多重条件 (AND) 的搜索
results = vectorstore.similarity_search(
    "ducks",
    k=10,
    filter={"id": {"$in": [1, 5, 2, 9]}, "location": {"$in": ["pond", "market"]}},
)
```
