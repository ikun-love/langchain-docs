> [SemaDB](https://www.semafind.com/products/semadb) 是来自 [SemaFind](https://www.semafind.com) 的一款**无须繁琐配置**（no fuss）的向量相似度数据库，专为构建 AI 应用而设计。其托管服务 `SemaDB Cloud` 提供了极其便捷的开发者体验，便于快速上手。

API 的完整文档、示例以及交互式演示平台可在 [RapidAPI](https://rapidapi.com/semafind-semadb/api/semadb) 上获取。

本 Notebook 演示了如何使用 `SemaDB Cloud` 向量存储（vector store）。

要使用此集成，你需要安装 `langchain-community`：运行 `pip install -qU langchain-community`。

## 加载文档嵌入（Embeddings）

为了在本地运行，我们使用 [Sentence Transformers](https://www.sbert.net/)，这是一种常用于句子嵌入的模型。当然，你也可以使用 LangChain 提供的任何其他嵌入模型。

```python
pip install -qU  sentence_transformers
```

```python
from langchain_huggingface import HuggingFaceEmbeddings

model_name = "sentence-transformers/all-mpnet-base-v2"
embeddings = HuggingFaceEmbeddings(model_name=model_name)
```

```python
from langchain_community.document_loaders import TextLoader
from langchain_text_splitters import CharacterTextSplitter

# 加载本地文件
loader = TextLoader("../../how_to/state_of_the_union.txt")
documents = loader.load()
# 使用字符分割器，设置 chunk_size 为 400，不设置重叠部分
text_splitter = CharacterTextSplitter(chunk_size=400, chunk_overlap=0)
docs = text_splitter.split_documents(documents)
print(len(docs))
```

```output
114
```

## 连接到 SemaDB

SemaDB Cloud 使用 [RapidAPI 密钥](https://rapidapi.com/semafind-semadb/api/semadb) 进行身份验证。你可以通过创建一个免费的 RapidAPI 账户来获取密钥。

```python
import getpass
import os

# 如果环境变量中未设置 SEMADB_API_KEY，则提示用户输入
if "SEMADB_API_KEY" not in os.environ:
    os.environ["SEMADB_API_KEY"] = getpass.getpass("SemaDB API Key:")
```

```output
SemaDB API Key: ········
```

```python
from langchain_community.vectorstores import SemaDB
from langchain_community.vectorstores.utils import DistanceStrategy
```

传递给 SemaDB 向量存储的参数直接对应于其 API 结构：

- `"mycollection"`: 我们将存储这些向量的集合（collection）名称。
- `768`: 向量的维度。在我们的例子中，Sentence Transformer 嵌入生成的是 768 维的向量。
- `API_KEY`: 你的 RapidAPI 密钥。
- `embeddings`: 对应于文档、文本和查询的嵌入将如何生成。
- `DistanceStrategy`: 使用的距离度量标准。如果使用 `COSINE`（余弦相似度），包装器会自动对向量进行归一化处理。

```python
db = SemaDB("mycollection", 768, embeddings, DistanceStrategy.COSINE)

# 首次运行时创建集合。如果集合已存在，此操作会失败。
db.create_collection()
```

```output
True
```

SemaDB 向量存储包装器会将文档文本作为点的元数据（metadata）添加，以便后续检索。**不建议**存储大块的文本内容。如果需要索引大型文档集合，我们建议存储文档的外部引用 ID，而不是全文。

```python
# 添加文档，并仅显示前两个返回的 ID
db.add_documents(docs)[:2]
```

```output
['813c7ef3-9797-466b-8afa-587115592c6c',
 'fc392f7f-082b-4932-bfcc-06800db5e017']
```

## 相似性搜索（Similarity Search）

我们使用 LangChain 默认的相似性搜索接口来查找最相似的句子。

```python
query = "What did the president say about Ketanji Brown Jackson"
docs = db.similarity_search(query)
print(docs[0].page_content)
```

```output
And I did that 4 days ago, when I nominated Circuit Court of Appeals Judge Ketanji Brown Jackson. One of our nation’s top legal minds, who will continue Justice Breyer’s legacy of excellence.
```

```python
# 执行带分数（score）的相似性搜索
docs = db.similarity_search_with_score(query)
docs[0]
```

```output

One of our nation’s top legal minds, who will continue Justice Breyer’s legacy of excellence.'}),
 0.42369342)
```
