---
title: IBM Db2 向量存储和向量搜索
---

LangChain 的 Db2 集成 (`langchain-db2`) 提供了向量存储（Vector Store）和向量搜索（Vector Search）功能，用于处理 IBM 关系型数据库 Db2 v12.1.2 及更高版本。该集成基于 MIT 许可证发布。用户可以按原样使用提供的实现，也可以根据特定需求进行定制。

关键特性包括：

*   支持带元数据（metadata）的向量存储。
*   支持向量相似性搜索（Vector similarity search）和最大边际相关性搜索（Max marginal relevance search），并带有元数据过滤选项。
*   支持点积（dot production）、余弦（cosine）和欧几里得距离（euclidean distance）度量标准。
*   通过索引创建和近似最近邻搜索（Approximate nearest neighbors search）进行性能优化。（该功能即将增加）

## 设置

### 使用 LangChain 和 Db2 向量存储与搜索的先决条件

安装 `langchain-db2` 包，这是 Db2 LangChain 向量存储和搜索的集成包。

安装此包时，它也应安装其依赖项，如 `langchain-core` 和 `ibm_db`。

```python
# pip install -U langchain-db2
```

### 连接到 Db2 向量存储

下面的示例代码演示了如何连接到 Db2 数据库。除了上述依赖项，您还需要一个正在运行的 Db2 数据库实例（版本 v12.1.2+，该版本支持向量数据类型）。

```python
import ibm_db
import ibm_db_dbi

database = ""
username = ""
password = ""

try:
    connection = ibm_db_dbi.connect(database, username, password)
    print("Connection successful!")
except Exception as e:
    print("Connection failed!")
```

### 使用不同的距离度量创建向量存储

首先，我们将使用三种不同的距离策略（distance strategies）创建三个向量存储。

（您可以手动连接到 Db2 数据库，将看到三个表：`Documents_DOT`、`Documents_COSINE` 和 `Documents_EUCLIDEAN`。）

```python
# 使用不同的距离策略创建 Db2 向量存储

# 当使用我们的 API 调用时，首先使用 from_documents() 初始化向量存储及其部分文档，
# 然后使用 add_texts() 增量添加更多文档。
# 这种方法可以防止系统过载并确保文档处理效率。

model = HuggingFaceEmbeddings(model_name="sentence-transformers/all-mpnet-base-v2")

vector_store_dot = DB2VS.from_documents(
    documents_langchain,
    model,
    client=connection,
    table_name="Documents_DOT",
    distance_strategy=DistanceStrategy.DOT_PRODUCT,
)
vector_store_max = DB2VS.from_documents(
    documents_langchain,
    model,
    client=connection,
    table_name="Documents_COSINE",
    distance_strategy=DistanceStrategy.COSINE,
)
vector_store_euclidean = DB2VS.from_documents(
    documents_langchain,
    model,
    client=connection,
    table_name="Documents_EUCLIDEAN",
    distance_strategy=DistanceStrategy.EUCLIDEAN_DISTANCE,
)
```

## 管理向量存储

### 演示添加和删除文本操作，以及基本的相似性搜索

```python
def manage_texts(vector_stores):
    """
    向每个向量存储添加文本，演示重复添加的错误处理，并执行文本删除操作。
    展示每个向量存储的相似性搜索和索引创建情况。

    Args:
    - vector_stores (list): DB2VS 实例列表。
    """
    texts = ["Rohan", "Shailendra"]
    metadata = [
        {"id": "100", "link": "Document Example Test 1"},
        {"id": "101", "link": "Document Example Test 2"},
    ]

    for i, vs in enumerate(vector_stores, start=1):
        # 添加文本
        try:
            vs.add_texts(texts, metadata)
            print(f"\n\n\n向量存储 {i} 添加文本完成\n\n\n")
        except Exception as ex:
            # 预期在尝试重复添加时会发生错误
            print(f"\n\n\n向量存储 {i} 重复添加的预期错误\n\n\n")

        # 使用 'id' 的值删除文本
        vs.delete([metadata[0]["id"], metadata[1]["id"]])
        print(f"\n\n\n向量存储 {i} 删除文本完成\n\n\n")

        # 相似性搜索
        results = vs.similarity_search("How are LOBS stored in Db2 Database", 2)
        print(f"\n\n\n向量存储 {i} 的相似性搜索结果: {results}\n\n\n")


vector_store_list = [
    vector_store_dot,
    vector_store_max,
    vector_store_euclidean,
]
manage_texts(vector_store_list)
```

## 查询向量存储

### 演示对向量存储的高级搜索，包括带属性过滤和不带过滤的搜索

带过滤的搜索中，我们只选择 document id 为 101 的文档，不选择其他。

```python
# 进行高级搜索
def conduct_advanced_searches(vector_stores):
    query = "How are LOBS stored in Db2 Database"
    # 构建一个用于与文档元数据进行直接比较的过滤条件
    # 此过滤器旨在包含 'id' 恰好是 '101' 的文档
    filter_criteria = {"id": ["101"]}  # 直接比较过滤器

    for i, vs in enumerate(vector_stores, start=1):
        print(f"\n--- 向量存储 {i} 高级搜索 ---")
        # 不带过滤器的相似性搜索
        print("\n不带过滤器的相似性搜索结果:")
        print(vs.similarity_search(query, 2))

        # 带过滤器的相似性搜索
        print("\n带过滤器的相似性搜索结果:")
        print(vs.similarity_search(query, 2, filter=filter_criteria))

        # 带相关性分数的相似性搜索
        print("\n带相关性分数的相似性搜索结果:")
        print(vs.similarity_search_with_score(query, 2))

        # 带相关性分数和过滤器的相似性搜索
        print("\n带相关性分数和过滤器的相似性搜索结果:")
        print(vs.similarity_search_with_score(query, 2, filter=filter_criteria))

        # 最大边际相关性搜索 (Max marginal relevance search)
        print("\n最大边际相关性搜索结果:")
        print(vs.max_marginal_relevance_search(query, 2, fetch_k=20, lambda_mult=0.5))

        # 带过滤器的最大边际相关性搜索
        print("\n带过滤器的最大边际相关性搜索结果:")
        print(
            vs.max_marginal_relevance_search(
                query, 2, fetch_k=20, lambda_mult=0.5, filter=filter_criteria
            )
        )


conduct_advanced_searches(vector_store_list)
```
