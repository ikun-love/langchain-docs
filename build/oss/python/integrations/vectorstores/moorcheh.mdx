# Moorcheh

[Moorcheh](https://www.moorcheh.ai/) 是一个闪电般快速的语义搜索引擎和向量存储。Moorcheh 没有使用 L2 或余弦相似度等简单的距离度量，而是利用最大信息二值化 (Maximally Informative Binarization, MIB) 和信息论分数 (Information-Theoretic Score, ITS) 来检索准确的文档片段。

本教程将指导您如何使用 Moorcheh 和 LangChain 上传和存储文本文档及向量嵌入，并为您的所有查询检索相关的文档片段。

## 设置 (Setup)

首先，安装必要的包：

```bash
pip install langchain-moorcheh
```

## 初始化 (Initialization)

开始使用 Moorcheh：

1.  访问 [Moorcheh 控制台](https://console.moorcheh.ai/) 注册或登录。
2.  进入 "API Keys"（API 密钥）标签页并生成一个 API 密钥。
3.  将该密钥保存为一个名为 `MOORCHEH_API_KEY` 的环境变量（您将在下面使用它）。
4.  要为数据存储创建一个命名空间 (namespace)：
    *   在控制台中，打开 "Namespaces"（命名空间）标签页并点击 "Create namespace"（创建命名空间）；或者
    *   使用下一节中的向量存储代码以编程方式初始化它。
5.  使用您的 API 密钥来创建命名空间、上传文档和检索答案。

有关 Moorcheh SDK 函数的更多信息，请参阅 [GitHub 仓库](https://github.com/moorcheh-ai/moorcheh-python-sdk)。

## 代码设置 (Code Setup)

将您的 Moorcheh API 密钥设置到环境变量中：

```python
MOORCHEH_API_KEY = os.environ['MOORCHEH_API_KEY']
```

设置您的命名空间名称 (`namespace`)、类型 (`namespace_type`) 并创建向量存储：

```python
namespace = "your_namespace_name"
namespace_type = "text" # 也可以是 "vector"
store = MoorchehVectorStore(
            api_key=MOORCHEH_API_KEY,
            namespace=namespace,
            namespace_type=namespace_type
        )
```

## 查询引擎 (Query Engine)

一旦您的命名空间已创建并且您已向其中上传了文档，您就可以直接通过向量存储对文档提出查询。设置您希望用来回答查询的查询语句和 LLM。有关支持的 LLM 的更多信息，请访问我们的 [GitHub 页面](https://github.com/moorcheh-ai/moorcheh-python-sdk)。

```python
query = "Give me a brief summary of the provided documents"
answer = store.generative_answer(query, ai_model = "anthropic.claude-sonnet-4-5-20250929-v1:0")
print(answer)
```
