title: Azure Database for PostgreSQL - 灵活服务器
---

[Azure Database for PostgreSQL - 灵活服务器](https://learn.microsoft.com/en-us/azure/postgresql/flexible-server/service-overview) 是一种基于开源 Postgres 数据库引擎的关系数据库服务。它是一个完全托管的数据库即服务 (Database-as-a-Service)，能够以可预测的性能、安全性和高可用性来处理关键任务工作负载，并提供动态可伸缩性。

本指南将向您展示如何利用此集成的 [向量数据库](https://learn.microsoft.com/en-us/azure/postgresql/flexible-server/how-to-use-pgvector)，以使用余弦距离（Cosine Distance）、L2（欧几里得距离）和 IP（内积）等近似最近邻算法来存储文档集合、创建索引并执行向量搜索查询，从而定位与查询向量最接近的文档。

## 向量支持 (Vector Support)

Azure Database for PostgreSQL - 灵活服务器使您能够在 PostgreSQL 中高效地存储和查询数百万个向量嵌入 (vector embeddings)。它还能帮助您将 AI 用例从概念验证 (POC) 扩展到生产环境：

* 提供熟悉的 SQL 接口，用于查询向量嵌入和关系型数据。
* 利用 [DiskANN 索引算法](https://aka.ms/pg-diskann-docs)，加速并提高跨 1 亿多个向量的相似性搜索的准确性，从而增强 `pgvector` 的性能。
* 通过将关系元数据、向量嵌入和时间序列数据集成到单个数据库中，简化运维操作。
* 利用强大的 PostgreSQL 生态系统和 Azure 云的功能，实现企业级的特性，包括复制和高可用性。

## 身份验证 (Authentication)

Azure Database for PostgreSQL - 灵活服务器支持基于密码的身份验证以及 [Microsoft Entra](https://learn.microsoft.com/en-us/azure/postgresql/flexible-server/concepts-azure-ad-authentication)（前身为 Azure Active Directory）身份验证。

Entra 身份验证允许您使用 Entra 身份来验证到 PostgreSQL 服务器的连接。这消除了为数据库用户管理单独用户名和密码的需要，并允许您利用与其他 Azure 服务相同的安全机制。

本指南设置为使用任一身份验证方法。您稍后可以在 Notebook 中配置是否使用 Entra 身份验证。

## 设置 (Setup)

Azure Database for PostgreSQL 基于开源 Postgres 构建。此集成使用了专用的 [`langchain-azure-postgresql`](https://pypi.org/project/langchain-azure-postgresql/) 包，它提供了优化的支持，包括 DiskANN 索引和 Microsoft Entra 身份验证。

首先下载配套包：

```python
pip install -qU langchain-azure-postgresql langchain-openai azure-identity
```

### 启用 pgvector

请参阅 Azure Database for PostgreSQL 的[启用说明](https://learn.microsoft.com/en-us/azure/postgresql/flexible-server/how-to-use-pgvector)。

### 设置凭据

您需要您的 Azure Database for PostgreSQL [连接详细信息](https://learn.microsoft.com/en-us/azure/postgresql/flexible-server/quickstart-create-server-portal#get-the-connection-information)，并将它们作为环境变量添加到您的环境中，以便运行此 Notebook。

如果希望使用 Microsoft Entra 身份验证，请将 `USE_ENTRA_AUTH` 标志设置为 `True`。如果使用 Entra 身份验证，您只需要提供主机名和数据库名称。如果使用密码身份验证，还需要设置用户名和密码。

```python
import getpass
import os

USE_ENTRA_AUTH = True

# 提供数据库的连接详细信息
os.environ["DBHOST"] = "REPLACE_WITH_SERVER_NAME"
os.environ["DBNAME"] = "REPLACE_WITH_DATABASE_NAME"
os.environ["SSLMODE"] = "require"

if not USE_ENTRA_AUTH:
    # 如果使用用户名和密码，请在此处提供
    os.environ["DBUSER"] = "REPLACE_WITH_USERNAME"
    os.environ["DBPASSWORD"] = getpass.getpass("Database Password:")
```

### 设置 `AzureOpenAIEmbeddings`

```python
os.environ["AZURE_OPENAI_ENDPOINT"] = "REPLACE_WITH_AZURE_OPENAI_ENDPOINT"
os.environ["AZURE_OPENAI_API_KEY"] = getpass.getpass("Azure OpenAI API Key:")
```

```python
AZURE_OPENAI_ENDPOINT = os.environ["AZURE_OPENAI_ENDPOINT"]
AZURE_OPENAI_API_KEY = os.environ["AZURE_OPENAI_API_KEY"]

from langchain_openai import AzureOpenAIEmbeddings

embeddings = AzureOpenAIEmbeddings(
    model="text-embedding-3-small",
    api_key=AZURE_OPENAI_API_KEY,
    azure_endpoint=AZURE_OPENAI_ENDPOINT,
    azure_deployment="text-embedding-3-small",
)
```

## 初始化 (Initialization)

### 使用 Microsoft Entra 身份验证

接下来的部分将演示如何设置 LangChain 以使用 Microsoft Entra 身份验证。LangChain Azure Postgres 包中的 `AzurePGConnectionPool` 类通过使用 `azure.identity` 库中的 `DefaultAzureCredential` 来检索 Azure Database for PostgreSQL 服务的令牌。

可以将连接传递给 LangChain 向量存储 `AzurePGVectorStore` 的 `connection` 参数。

#### 登录 Azure

要登录 Azure，请确保已安装 [Azure CLI](https://learn.microsoft.com/en-us/cli/azure/install-azure-cli)。您需要在终端中运行以下命令：

```bash
az login
```

登录后，下面的代码将能够获取令牌。

```python
from langchain_azure_postgresql.common import (
    BasicAuth,
    AzurePGConnectionPool,
    ConnectionInfo,
)
from langchain_azure_postgresql.langchain import AzurePGVectorStore

entra_connection_pool = AzurePGConnectionPool(
    azure_conn_info=ConnectionInfo(
        host=os.environ["DBHOST"], dbname=os.environ["DBNAME"]
    )
)
```

### 密码身份验证

如果您没有使用 Microsoft Entra 身份验证，`BasicAuth` 类允许使用用户名和密码：

```python
basic_auth_connection_pool = AzurePGConnectionPool(
    azure_conn_info=ConnectionInfo(
        host=os.environ["DBHOST"],
        dbname=os.environ["DBNAME"],
        credentials=BasicAuth(
            username=os.environ["DBUSER"],
            password=os.environ["DBPASSWORD"],
        ),
    )
)
```

### 创建向量存储 (Creating the Vector Store)

```python
from langchain_core.documents import Document
from langchain_azure_postgresql.langchain import AzurePGVectorStore

table_name = "my_docs"

# 连接将使用 Entra ID 或 Basic Auth
connection = entra_connection_pool if USE_ENTRA_AUTH else basic_auth_connection_pool

vector_store = AzurePGVectorStore(
    embedding=embeddings,
    table_name=table_name,
    connection=connection,
)
```

```output
Metadata columns are specified as a string, defaulting to 'jsonb' type.
Embedding type is not specified, defaulting to 'vector'.
Embedding dimension is not specified, defaulting to 1536.
Embedding index is not specified, defaulting to 'DiskANN' with 'vector_cosine_ops' opclass.
```

## 配置向量存储参数 (Configuring Vector Store parameters)

在初始化 `AzurePGVectorStore` 时，您可以覆盖元数据类型、嵌入维度、索引类型等的默认参数。这允许您根据特定的用例和数据来定制向量存储。

**关键配置选项：**

- `metadata_column_type`: 元数据列的类型（默认值: `'jsonb'`）。可设置为 `'jsonb'`、`'text'` 等。
- `embedding_column_type`: 嵌入列的类型（默认值: `'vector'`）。
- `embedding_dimension`: 嵌入向量的维度（默认值: `1536`）。
- `embedding_index_type`: 用于向量搜索的索引类型（默认值: `'DiskANN'`）。其他选项可能包括 `'ivfflat'`、`'hnsw'` 等。
- `embedding_index_opclass`: 索引的操作符类（默认值: `'vector_cosine_ops'`）。

**示例：**

```python
vector_store = AzurePGVectorStore(
    embedding=embeddings,
    table_name=table_name,
    connection=connection,
    metadata_column_type="jsonb",           # 或 "text"
    embedding_column_type="vector",
    embedding_dimension=768,                # 设置以匹配模型的输出
    embedding_index_type="DiskANN",         # 或 "ivfflat", "hnsw" 等
    embedding_index_opclass="vector_cosine_ops",  # 或 "vector_l2_ops" 等
)
```

## 初始化 DiskANN 向量索引以实现更高效的向量搜索

[DiskANN](https://aka.ms/pg-diskann-blog) 是一种可扩展的近似最近邻搜索算法，可实现任何规模下的高效向量搜索。它即使对于包含数十亿个点的超大规模数据集，也能提供高召回率、高每秒查询次数 (QPS) 和低查询延迟。这些特性使其成为处理海量数据的强大工具。

```python
vector_store.create_index()
```

```output
True
```

## 查询向量存储 (Query vector store)

在创建向量存储并添加相关文档后，您可以在链 (chain) 或代理 (agent) 中查询向量存储。

### 筛选 (Filtering)

向量存储支持一组过滤器，这些过滤器可以通过 [LangChain Azure PostgreSQL](https://pypi.org/project/langchain-azure-postgresql/) 包中的 `FilterCondition`、`OrFilter` 和 `AndFilter` 针对文档的元数据字段进行应用：

| 运算符 | 含义/类别 |
| -------- | ------------------------------- |
| `=`      | 等于 (Equality) |
| `!=`      | 不等于 (Inequality) |
| `<`      | 小于 (Less than) |
| `<=`     | 小于等于 (Less than or equal) |
| `>`      | 大于 (Greater than) |
| `>=`     | 大于等于 (Greater than or equal) |
| `in`      | 特殊处理（包含于） |
| `not in`     | 特殊处理（不包含于） |
| `is null`     | 特殊处理（为空） |
| `is not null`     | 特殊处理（不为空） |
| `between` | 特殊处理（在...之间） |
| `not between` | 特殊处理（不在...之间） |
| `like`    | 文本（模糊匹配） |
| `ilike`   | 文本（不区分大小写的模糊匹配） |
| `AND`     | 逻辑（与） |
| `OR`      | 逻辑（或） |

### 直接查询 (Query directly)

执行简单的相似性搜索可以按如下方式完成：

```python
from langchain_azure_postgresql import FilterCondition, AndFilter

results = vector_store.similarity_search(
    "kitty",
    k=10,
    filter=FilterCondition(
        column="(metadata->>'doc_id')::int",
        operator="in",
        value=[1, 5, 2, 9],
    ),
)

for doc in results:
    print("* " + doc.page_content + " [" + str(doc.metadata) + "]")
```

```output
* there are cats in the pond [{'topic': 'animals', 'doc_id': 1, 'location': 'pond'}]
* ducks are also found in the pond [{'topic': 'animals', 'doc_id': 2, 'location': 'pond'}]
* the new art exhibit is fascinating [{'topic': 'art', 'doc_id': 5, 'location': 'museum'}]
* the library hosts a weekly story time for kids [{'topic': 'reading', 'doc_id': 9, 'location': 'library'}]
```

如果您想使用逻辑 `AND` 过滤器，请看以下示例：

```python
results = vector_store.similarity_search(
    "ducks",
    k=10,
    filter=AndFilter(
        AND=[
            FilterCondition(
                column="(metadata->>'doc_id')::int",
                operator="in",
                value=[1, 5, 2, 9],
            ),
            FilterCondition(
                column="metadata->>'location'",
                operator="in",
                value=["pond", "market"],
            ),
        ]
    ),
)

for doc in results:
    print("* " + doc.page_content + " [" + str(doc.metadata) + "]")
```

```output
* ducks are also found in the pond [{'topic': 'animals', 'doc_id': 2, 'location': 'pond'}]
* there are cats in the pond [{'topic': 'animals', 'doc_id': 1, 'location': 'pond'}]
```

如果您想执行相似性搜索并接收相应的分数，可以运行：

```python
results = vector_store.similarity_search_with_score(query="cats", k=1)
for doc, score in results:
    print(f"* [SIM={score:3f}] {doc.page_content} [{doc.metadata}]")
```

```output
* [SIM=0.528167] there are cats in the pond [{'topic': 'animals', 'doc_id': 1, 'location': 'pond'}]
```

### 通过转换为检索器查询 (Query by turning into retriever)

您也可以将向量存储转换为检索器 (retriever)，以便在链中使用它。

```python
retriever = vector_store.as_retriever(search_kwargs={"k": 1})
retriever.invoke("kitty")
```

```output
[Document(id='00e2cfe6-6e58-4733-9ebf-a708fd16488a', metadata={'topic': 'animals', 'doc_id': 1, 'location': 'pond'}, page_content='there are cats in the pond')]
```

如果您想在向量存储上使用最大边际相关性搜索 (MMR) (max marginal relevance search)：

```python
results = vector_store.max_marginal_relevance_search(
    "query about cats",
    k=10,
    lambda_mult=0.5,
    filter=FilterCondition(
        column="(metadata->>'doc_id')::int",
        operator="in",
        value=[1, 2, 5, 9],
    ),
)

for doc in results:
    print("* " + doc.page_content + " [" + str(doc.metadata) + "]")
```

```output
* there are cats in the pond [{'topic': 'animals', 'doc_id': 1, 'location': 'pond'}]
* the new art exhibit is fascinating [{'topic': 'art', 'doc_id': 5, 'location': 'museum'}]
* the library hosts a weekly story time for kids [{'topic': 'reading', 'doc_id': 9, 'location': 'library'}]
* ducks are also found in the pond [{'topic': 'animals', 'doc_id': 2, 'location': 'pond'}]
```
