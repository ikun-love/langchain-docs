我们希望使用 [`OpenAIEmbeddings`](https://reference.langchain.com/python/integrations/langchain_openai/OpenAIEmbeddings)，因此需要获取 OpenAI API 密钥。

```python
import getpass
import os

if "OPENAI_API_KEY" not in os.environ:
    os.environ["OPENAI_API_KEY"] = getpass.getpass("OpenAI API Key:")
```

```python
from langchain_community.vectorstores import DuckDB
from langchain_openai import OpenAIEmbeddings
```

```python
from langchain_community.document_loaders import TextLoader
from langchain_text_splitters import CharacterTextSplitter

# 加载本地文档文件
loader = TextLoader("../../how_to/state_of_the_union.txt")
documents = loader.load()

# 使用 CharacterTextSplitter 对文档进行分块处理
documents = CharacterTextSplitter().split_documents(documents)
# 初始化 OpenAI 嵌入模型
embeddings = OpenAIEmbeddings()
```

```python
# 使用文档和嵌入模型创建 DuckDB 向量存储实例
docsearch = DuckDB.from_documents(documents, embeddings)

query = "What did the president say about Ketanji Brown Jackson"
# 执行相似性搜索
docs = docsearch.similarity_search(query)
```

```python
# 打印最相关的文档内容（第一个结果）
print(docs[0].page_content)
```
