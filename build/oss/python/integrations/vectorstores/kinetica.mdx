[Kinetica](https://www.kinetica.com/) 是一个内置了向量相似性搜索功能的数据库。

它支持：

- 精确近邻搜索和近似近邻搜索
- L2 距离、内积（Inner Product）和余弦距离

本教程（Notebook）展示了如何使用 Kinetica 向量存储（`Kinetica`）。

要使用此功能，你需要一个 Kinetica 实例。可以通过参考[安装指南](https://www.kinetica.com/developer-edition/)轻松设置。

```python
# Kinetica 需要连接到数据库。
# 下面是设置连接的方式。
HOST = os.getenv("KINETICA_HOST", "http://127.0.0.1:9191")
USERNAME = os.getenv("KINETICA_USERNAME", "")
PASSWORD = os.getenv("KINETICA_PASSWORD", "")

def create_config() -> KineticaSettings:
    return KineticaSettings(host=HOST, username=USERNAME, password=PASSWORD)
```

## 使用欧几里得距离进行相似性搜索（默认）

```python
# Kinetica 模块将尝试创建一个与 collection 同名的表。
# 因此，请确保 collection 名称是唯一的，并且用户有权限创建表。

COLLECTION_NAME = "langchain_example"
connection = create_config()

db = Kinetica(
    connection,
    embeddings,
    collection_name=COLLECTION_NAME,
)

db.add_documents(documents=documents, ids=uuids)
```

## 使用向量存储

在上面，我们从头创建了一个向量存储。但是，很多时候我们希望使用一个已存在的向量存储。
要做到这一点，可以直接初始化它。

```python
store = Kinetica(
    collection_name=COLLECTION_NAME,
    config=connection,
    embedding_function=embeddings,
)
```

### 添加文档

我们可以向现有的向量存储中添加文档。

```python
store.add_documents([Document(page_content="foo")])
```

### 覆盖向量存储

如果你有一个现有的 collection，可以通过调用 `from_documents` 并设置 `pre_delete_collection` = True 来覆盖它。

```python
db = Kinetica.from_documents(
    documents=documents,
    embedding=embeddings,
    collection_name=COLLECTION_NAME,
    config=connection,
    pre_delete_collection=True,
)
```

```python
docs_with_score = db.similarity_search_with_score("foo")
```

