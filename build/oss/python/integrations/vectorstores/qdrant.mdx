>[Qdrant](https://qdrant.tech/documentation/)（发音：quadrant）是一个向量相似性搜索引擎。它提供了一个生产就绪的服务，带有一个方便的 API 用于存储、搜索和管理带有附加 Payload（有效载荷）和扩展过滤支持的向量。这使得它对于各种神经网络或基于语义的匹配、分面搜索以及其他应用非常有用。

本文档演示了如何将 Qdrant 与 LangChain 结合用于密集（即基于嵌入）检索、稀疏（即文本搜索）检索和混合检索。`QdrantVectorStore` 类通过 Qdrant 的新 [Query API](https://qdrant.tech/blog/qdrant-1.10.x/) 支持多种检索模式。它要求您运行 Qdrant v1.10.0 或更高版本。

## 设置 (Setup)

运行 `Qdrant` 有多种模式，根据所选模式的不同，会存在一些细微的差别。选项包括：

- 本地模式，无需服务器
- Docker 部署
- Qdrant Cloud

请在此处 [here](https://qdrant.tech/documentation/install/) 查看安装说明。

```python
pip install -qU langchain-qdrant
```

```

## 初始化 (Initialization)

### 本地模式 (Local mode)

Python 客户端提供了在不运行 Qdrant 服务器的情况下以本地模式运行代码的选项。这对于测试、调试或仅存储少量向量非常有用。嵌入可以完全保存在内存中，也可以持久化存储在磁盘上。

#### 内存中 (In-memory)

对于某些测试场景和快速实验，您可能更希望将所有数据仅保留在内存中，这样当客户端销毁时（通常在脚本/Notebook 结束时）数据就会被移除。

<EmbeddingTabs/>

```python
# | output: false
# | echo: false
from langchain_openai import OpenAIEmbeddings

# 使用 OpenAI 的嵌入模型，例如 text-embedding-3-large
embeddings = OpenAIEmbeddings(model="text-embedding-3-large")
```

```python
from langchain_qdrant import QdrantVectorStore
from qdrant_client import QdrantClient
from qdrant_client.http.models import Distance, VectorParams

# 使用内存模式初始化 Qdrant 客户端
client = QdrantClient(":memory:")

# 创建一个集合，向量大小为 3072，使用余弦距离
client.create_collection(
    collection_name="demo_collection",
    vectors_config=VectorParams(size=3072, distance=Distance.COSINE),
)

# 创建 QdrantVectorStore 实例
vector_store = QdrantVectorStore(
    client=client,
    collection_name="demo_collection",
    embedding=embeddings,
)
```

#### 磁盘存储 (On-disk storage)

在不使用 Qdrant 服务器的情况下运行的本地模式也可以将您的向量存储在磁盘上，以便在每次运行之间持久化。

```python
# 指定磁盘路径来存储数据
client = QdrantClient(path="/tmp/langchain_qdrant")

client.create_collection(
    collection_name="demo_collection",
    vectors_config=VectorParams(size=3072, distance=Distance.COSINE),
)

vector_store = QdrantVectorStore(
    client=client,
    collection_name="demo_collection",
    embedding=embeddings,
)
```

### 部署本地服务器 (On-premise server deployment)

无论您选择使用 [Docker 容器](https://qdrant.tech/documentation/install/) 在本地启动 Qdrant，还是选择使用 [官方 Helm chart](https://github.com/qdrant/qdrant-helm) 进行 Kubernetes 部署，连接到该实例的方式将是相同的。您需要提供一个指向服务的 URL。

```python
url = "<---qdrant url here --->"
docs = []  # 在此处放入文档 docs
qdrant = QdrantVectorStore.from_documents(
    docs,
    embeddings,
    url=url,
    prefer_grpc=True,
    collection_name="my_documents",
)
```

### Qdrant Cloud

如果您不想费心管理基础设施，可以选择在 [Qdrant Cloud](https://cloud.qdrant.io/) 上设置一个完全托管的 Qdrant 集群。其中包含一个永久免费的 1GB 集群供您试用。使用托管版本的 Qdrant 的主要区别在于，您需要提供一个 API 密钥来保护您的部署，防止被公开访问。该值也可以在 `QDRANT_API_KEY` 环境变量中设置。

```python
url = "<---qdrant cloud cluster url here --->"
api_key = "<---api key here--->"
qdrant = QdrantVectorStore.from_documents(
    docs,
    embeddings,
    url=url,
    prefer_grpc=True,
    api_key=api_key,
    collection_name="my_documents",
)
```

## 查询向量存储 (Query vector store)

创建向量存储并将相关文档添加进去后，在运行链或代理时很可能会希望对其进行查询。

### 直接查询 (Query directly)

使用 Qdrant 向量存储的最简单场景是执行相似性搜索。在底层，我们的查询将被编码成向量嵌入，并用于在 Qdrant 集合中查找相似的文档。

```python
results = vector_store.similarity_search(
    "LangChain provides abstractions to make working with LLMs easy", k=2
)
for res in results:
    print(f"* {res.page_content} [{res.metadata}]")
```

```output
* Building an exciting new project with LangChain - come check it out! [{'source': 'tweet', '_id': 'd3202666-6f2b-4186-ac43-e35389de8166', '_collection_name': 'demo_collection'}]
* LangGraph is the best framework for building stateful, agentic applications! [{'source': 'tweet', '_id': '91ed6c56-fe53-49e2-8199-c3bb3c33c3eb', '_collection_name': 'demo_collection'}]
```

`QdrantVectorStore` 支持[三种](https://qdrant.tech/blog/qdrant-1.10.x/) 相似性搜索模式。可以使用 `retrieval_mode` 参数进行配置。

- 密集向量搜索 (默认)
- 稀疏向量搜索
- 混合搜索

### 密集向量搜索 (Dense Vector Search)

密集向量搜索涉及通过基于向量的嵌入来计算相似性。要仅使用密集向量进行搜索：

- `retrieval_mode` 参数应设置为 `RetrievalMode.DENSE`。这是默认行为。
- 必须向 `embedding` 参数提供一个 [密集嵌入](https://python.langchain.com/docs/integrations/text_embedding/) 值。

```python
from langchain_qdrant import QdrantVectorStore, RetrievalMode
from qdrant_client import QdrantClient
from qdrant_client.http.models import Distance, VectorParams

# 创建一个用于本地存储的 Qdrant 客户端
client = QdrantClient(path="/tmp/langchain_qdrant")

# 创建一个带有密集向量的集合
client.create_collection(
    collection_name="my_documents",
    vectors_config=VectorParams(size=3072, distance=Distance.COSINE),
)

qdrant = QdrantVectorStore(
    client=client,
    collection_name="my_documents",
    embedding=embeddings,
    retrieval_mode=RetrievalMode.DENSE,
)

qdrant.add_documents(documents=documents, ids=uuids)

query = "How much money did the robbers steal?"
found_docs = qdrant.similarity_search(query)
found_docs
```

### 稀疏向量搜索 (Sparse Vector Search)

要仅使用稀疏向量进行搜索：

- `retrieval_mode` 参数应设置为 `RetrievalMode.SPARSE`。
- 必须向 `sparse_embedding` 参数提供一个实现 [`SparseEmbeddings`](https://github.com/langchain-ai/langchain/blob/master/libs/partners/qdrant/langchain_qdrant/sparse_embeddings.py) 接口的任何稀疏嵌入提供程序的值。

`langchain-qdrant` 包开箱即用提供了一个基于 [FastEmbed](https://github.com/qdrant/fastembed) 的实现。

要使用它，请安装 FastEmbed 包。

```python
pip install -qU fastembed
```

```python
from langchain_qdrant import FastEmbedSparse, QdrantVectorStore, RetrievalMode
from qdrant_client import QdrantClient, models
from qdrant_client.http.models import Distance, SparseVectorParams, VectorParams

# 初始化 FastEmbed 稀疏嵌入器
sparse_embeddings = FastEmbedSparse(model_name="Qdrant/bm25")

# 创建一个用于本地存储的 Qdrant 客户端
client = QdrantClient(path="/tmp/langchain_qdrant")

# 创建一个带有稀疏向量的集合
client.create_collection(
    collection_name="my_documents",
    vectors_config={"dense": VectorParams(size=3072, distance=Distance.COSINE)},
    sparse_vectors_config={
        "sparse": SparseVectorParams(index=models.SparseIndexParams(on_disk=False))
    },
)

qdrant = QdrantVectorStore(
    client=client,
    collection_name="my_documents",
    sparse_embedding=sparse_embeddings,
    retrieval_mode=RetrievalMode.SPARSE,
    sparse_vector_name="sparse",
)

qdrant.add_documents(documents=documents, ids=uuids)

query = "How much money did the robbers steal?"
found_docs = qdrant.similarity_search(query)
found_docs
```

### 混合向量搜索 (Hybrid Vector Search)

要使用密集向量和稀疏向量进行混合搜索并进行分数融合：

- `retrieval_mode` 参数应设置为 `RetrievalMode.HYBRID`。
- 必须向 `embedding` 参数提供一个 [密集嵌入](https://python.langchain.com/docs/integrations/text_embedding/) 值。
- 必须向 `sparse_embedding` 参数提供一个实现 [`SparseEmbeddings`](https://github.com/langchain-ai/langchain/blob/master/libs/partners/qdrant/langchain_qdrant/sparse_embeddings.py) 接口的任何稀疏嵌入提供程序的值。

请注意，如果您使用 `HYBRID` 模式添加了文档，则可以在搜索时切换到任何检索模式，因为密集向量和稀疏向量都存在于集合中。

```python
from langchain_qdrant import FastEmbedSparse, QdrantVectorStore, RetrievalMode
from qdrant_client import QdrantClient, models
from qdrant_client.http.models import Distance, SparseVectorParams, VectorParams

sparse_embeddings = FastEmbedSparse(model_name="Qdrant/bm25")

# 创建一个用于本地存储的 Qdrant 客户端
client = QdrantClient(path="/tmp/langchain_qdrant")

# 创建一个同时包含密集和稀疏向量的集合
client.create_collection(
    collection_name="my_documents",
    vectors_config={"dense": VectorParams(size=3072, distance=Distance.COSINE)},
    sparse_vectors_config={
        "sparse": SparseVectorParams(index=models.SparseIndexParams(on_disk=False))
    },
)

qdrant = QdrantVectorStore(
    client=client,
    collection_name="my_documents",
    embedding=embeddings,
    sparse_embedding=sparse_embeddings,
    retrieval_mode=RetrievalMode.HYBRID,
    vector_name="dense",
    sparse_vector_name="sparse",
)

qdrant.add_documents(documents=documents, ids=uuids)

query = "How much money did the robbers steal?"
found_docs = qdrant.similarity_search(query)
found_docs
```

如果您想执行相似性搜索并接收相应的分数，您可以运行：

```python
results = vector_store.similarity_search_with_score(
    query="Will it be hot tomorrow", k=1
)
for doc, score in results:
    print(f"* [SIM={score:3f}] {doc.page_content} [{doc.metadata}]")
```

```

### 元数据过滤 (Metadata filtering)

Qdrant 具有[广泛的过滤系统](https://qdrant.tech/documentation/concepts/filtering/)，并支持丰富的类型。也可以在 LangChain 中使用过滤器，只需向 `similarity_search_with_score` 和 `similarity_search` 方法传递一个额外的参数即可。

```python
from qdrant_client import models

results = vector_store.similarity_search(
    query="Who are the best soccer players in the world?",
    k=1,
    filter=models.Filter(
        should=[
            models.FieldCondition(
                key="page_content",
                match=models.MatchValue(
                    value="The top 10 soccer players in the world right now."
                ),
            ),
        ]
    ),
)
for doc in results:
    print(f"* {doc.page_content} [{doc.metadata}]")
```

```output
* The top 10 soccer players in the world right now. [{'source': 'website', '_id': 'b0964ab5-5a14-47b4-a983-37fa5c5bd154', '_collection_name': 'demo_collection'}]
```

## 自定义 Qdrant (Customizing Qdrant)

可以选择在 LangChain 应用程序中使用现有的 Qdrant 集合。在这种情况下，您可能需要定义如何将 Qdrant 点映射到 LangChain 的 `Document` 对象。

### 命名向量 (Named vectors)

Qdrant 通过命名向量支持[每个点拥有多个向量](https://qdrant.tech/documentation/concepts/collections/#collection-with-multiple-vectors)。如果您使用的是外部创建的集合，或者希望使用具有不同名称的向量，可以通过提供其名称来配置它。

```python
from langchain_qdrant import RetrievalMode

QdrantVectorStore.from_documents(
    docs,
    embedding=embeddings,
    sparse_embedding=sparse_embeddings,
    location=":memory:",
    collection_name="my_documents_2",
    retrieval_mode=RetrievalMode.HYBRID,
    vector_name="custom_vector",
    sparse_vector_name="custom_sparse_vector",
)
```

### 元数据 (Metadata)

Qdrant 存储您的向量嵌入以及可选的类似 JSON 的 Payload（有效载荷）。Payload 是可选的，但由于 LangChain 假定嵌入是根据文档生成的，因此我们保留上下文数据，以便您可以提取原始文本。

默认情况下，您的文档将以以下 Payload 结构存储：

```json
{
    "page_content": "Lorem ipsum dolor sit amet",
    "metadata": {
        "foo": "bar"
    }
}
```

然而，您可以决定为页面内容和元数据使用不同的键。当您想要重用已有的集合时，这非常有用。

```python
QdrantVectorStore.from_documents(
    docs,
    embeddings,
    location=":memory:",
    collection_name="my_documents_2",
    content_payload_key="my_page_content_key",
    metadata_payload_key="my_meta",
)
```
