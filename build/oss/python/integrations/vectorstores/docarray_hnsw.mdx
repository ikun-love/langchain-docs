>[DocArrayHnswSearch](https://docs.docarray.org/user_guide/storing/index_hnswlib/) 是 [Docarray](https://github.com/docarray/docarray) 提供的一个轻量级的文档索引实现，它可以完全在本地运行，最适合用于小型到中型数据集。它使用 [hnswlib](https://github.com/nmslib/hnswlib) 在磁盘上存储向量，并使用 [SQLite](https://www.sqlite.org/index.html) 存储所有其他数据。

你需要通过运行 `pip install -qU langchain-community` 来安装 `langchain-community` 才能使用此集成。

本 Notebook 展示了如何使用与 `DocArrayHnswSearch` 相关的各项功能。

## 使用 DocArrayHnswSearch

```python
from langchain_community.document_loaders import TextLoader
from langchain_community.vectorstores import DocArrayHnswSearch
from langchain_openai import OpenAIEmbeddings
from langchain_text_splitters import CharacterTextSplitter
```

```python
documents = TextLoader("../../how_to/state_of_the_union.txt").load()
text_splitter = CharacterTextSplitter(chunk_size=1000, chunk_overlap=0)
docs = text_splitter.split_documents(documents)

embeddings = OpenAIEmbeddings()

db = DocArrayHnswSearch.from_documents(
    docs, embeddings, work_dir="hnswlib_store/", n_dim=1536
)
```

### 相似度搜索 (Similarity search)

```python
query = "What did the president say about Ketanji Brown Jackson"
docs = db.similarity_search(query)
```

```python
print(docs[0].page_content)
```

### 相似度搜索并带得分 (Similarity search with score)

返回的距离得分是余弦距离 (cosine distance)。因此，分数越低越好。

```python
docs = db.similarity_search_with_score(query)
```
