>[百度云 VectorSearch](https://cloud.baidu.com/doc/BES/index.html?from=productToDoc) 是一个完全托管的企业级分布式搜索和分析服务，与开源产品 100% 兼容。百度云 VectorSearch 为结构化/非结构化数据提供低成本、高性能、高可靠性的检索与分析平台级产品服务。作为一个向量数据库，它支持多种索引类型和相似性距离计算方法。

>`百度云 ElasticSearch` 提供权限管理机制，允许您自由配置集群权限，以进一步确保数据安全。

本示例 Notebook 展示了如何使用与 `百度云 ElasticSearch VectorStore` 相关的能力。要运行此示例，您需要有一个正在运行的 [百度云 ElasticSearch](https://cloud.baidu.com/product/bes.html) 实例：

请阅读 [帮助文档](https://cloud.baidu.com/doc/BES/s/8llyn0hh4 ) 以快速熟悉并配置百度云 ElasticSearch 实例。

实例启动并运行后，请遵循以下步骤来拆分文档、获取向量嵌入（Embeddings）、连接到百度云 Elasticsearch 实例、索引文档并执行向量检索。

首先，我们需要安装以下 Python 包。

```python
pip install -qU langchain-community elasticsearch == 7.11.0
```

首先，我们希望使用 `QianfanEmbeddings`，因此需要获取千帆的 AK 和 SK。关于千帆的详细信息，请参考 [百度千帆工作坊](https://cloud.baidu.com/product/wenxinworkshop)。

```python
import getpass
import os

if "QIANFAN_AK" not in os.environ:
    os.environ["QIANFAN_AK"] = getpass.getpass("您的千帆 AK:")
if "QIANFAN_SK" not in os.environ:
    os.environ["QIANFAN_SK"] = getpass.getpass("您的千帆 SK:")
```

其次，拆分文档并获取向量嵌入。

```python
from langchain_community.document_loaders import TextLoader
from langchain_text_splitters import CharacterTextSplitter

loader = TextLoader("../../../state_of_the_union.txt")
documents = loader.load()
text_splitter = CharacterTextSplitter(chunk_size=1000, chunk_overlap=0)
docs = text_splitter.split_documents(documents)

from langchain_community.embeddings import QianfanEmbeddingsEndpoint

embeddings = QianfanEmbeddingsEndpoint()
```

然后，创建一个可访问的百度 Elasticsearch 实例。

```python
# 创建一个 BES 实例并索引文档。
from langchain_community.vectorstores import BESVectorStore

bes = BESVectorStore.from_documents(
    documents=docs,
    embedding=embeddings,
    bes_url="您的 bes 集群 url",
    index_name="您的向量索引名",
)
bes.client.indices.refresh(index="您的向量索引名")
```

最后，查询和检索数据。

```python
query = "总统关于 Ketanji Brown Jackson 说了些什么"
docs = bes.similarity_search(query)
print(docs[0].page_content)
```
