> [Clarifai](https://www.clarifai.com/) 是一个 AI 平台，提供完整的 AI 生命周期服务，涵盖数据探索、数据标注、模型训练、评估和推理。上传输入（Inputs）后，Clarifai 应用还可以用作向量数据库。

本教程展示了如何使用与 `Clarifai` 向量数据库相关的各项功能。示例将演示文本语义搜索能力。Clarifai 还支持图像、视频帧的语义搜索，以及局部搜索（参见 [Rank](https://docs.clarifai.com/api-guide/search/rank)）和属性搜索（参见 [Filter](https://docs.clarifai.com/api-guide/search/filter)）。

要使用 Clarifai，您必须拥有一个账户和一个个人访问令牌（PAT）密钥。
请[点击此处](https://clarifai.com/settings/security)获取或创建 PAT。

```python
# 导入所需的模块
from langchain_community.document_loaders import TextLoader
from langchain_community.vectorstores import Clarifai
from langchain_text_splitters import CharacterTextSplitter
```

# 设置

设置将上传文本数据的用户 ID (`USER_ID`) 和应用 ID (`APP_ID`)。注意：在创建该应用时，请选择一个适合的基准工作流（Base Workflow）来索引您的文本文档，例如“语言理解工作流”（Language-Understanding workflow）。

您需要先在 [Clarifai](https://clarifai.com/login) 上创建一个账户，然后创建一个应用。

```python
USER_ID = "USERNAME_ID"
APP_ID = "APPLICATION_ID"
NUMBER_OF_DOCS = 2
```

## 从文本创建

从一系列文本列表中创建 Clarifai 向量存储。此部分会将每个文本及其相应的元数据上传到 Clarifai 应用。然后，该 Clarifai 应用可用于语义搜索，以查找相关的文本。

```python
texts = [
    "I really enjoy spending time with you",
    "I hate spending time with my dog",
    "I want to go for a run",
    "I went to the movies yesterday",
    "I love playing soccer with my friends",
]

metadatas = [
    {"id": i, "text": text, "source": "book 1", "category": ["books", "modern"]}
    for i, text in enumerate(texts)
]
```

或者，您可以选择为输入提供自定义输入 ID。

```python
idlist = ["text1", "text2", "text3", "text4", "text5"]
metadatas = [
    {"id": idlist[i], "text": text, "source": "book 1", "category": ["books", "modern"]}
    for i, text in enumerate(texts)
]
```

```python
# 也可以选择在初始化 clarifai 向量存储时传入 pat 参数！
clarifai_vector_db = Clarifai(
    user_id=USER_ID,
    app_id=APP_ID,
    number_of_docs=NUMBER_OF_DOCS,
)
```

将数据上传到 clarifai 应用。

```python
# 使用元数据和自定义输入 ID 上传。
response = clarifai_vector_db.add_texts(texts=texts, ids=idlist, metadatas=metadatas)

# 不带元数据上传（不推荐）- 因为您将无法根据元数据执行搜索操作。
# 自定义输入 ID（可选）
response = clarifai_vector_db.add_texts(texts=texts)
```

您可以通过以下方式直接创建一个 clarifai 向量 DB 存储并将所有输入摄取（ingest）到您的应用中：

```python
clarifai_vector_db = Clarifai.from_texts(
    user_id=USER_ID,
    app_id=APP_ID,
    texts=texts,
    metadatas=metadatas,
)
```

使用相似性搜索函数搜索相似文本。

```python
docs = clarifai_vector_db.similarity_search("I would like to see you")
docs
```

```output
[Document(page_content='I really enjoy spending time with you', metadata={'text': 'I really enjoy spending time with you', 'id': 'text1', 'source': 'book 1', 'category': ['books', 'modern']})]
```

此外，您还可以通过元数据过滤搜索结果。

```python
# 通过利用元数据过滤器，您可以在应用内执行大量强大的过滤操作。
# 此处限制相似性查询仅针对“source”键值匹配“book 1”的文本
book1_similar_docs = clarifai_vector_db.similarity_search(
    "I would love to see you", filter={"source": "book 1"}
)

# 您也可以在输入的元数据中使用列表，然后选择匹配列表中某个项的内容。
# 这对于如下所示的类别很有用：
book_category_similar_docs = clarifai_vector_db.similarity_search(
    "I would love to see you", filter={"category": ["books"]}
)
```

## 从文档创建

从文档列表中创建 Clarifai 向量存储。此部分会将每个文档及其相应的元数据上传到 Clarifai 应用。然后，该 Clarifai 应用可用于语义搜索，以查找相关的文档。

```python
loader = TextLoader("your_local_file_path.txt")
documents = loader.load()
text_splitter = CharacterTextSplitter(chunk_size=1000, chunk_overlap=0)
docs = text_splitter.split_documents(documents)
```

```python
USER_ID = "USERNAME_ID"
APP_ID = "APPLICATION_ID"
NUMBER_OF_DOCS = 4
```

创建 clarifai 向量 DB 类并将所有文档摄取到 clarifai 应用中。

```python
clarifai_vector_db = Clarifai.from_documents(
    user_id=USER_ID,
    app_id=APP_ID,
    documents=docs,
    number_of_docs=NUMBER_OF_DOCS,
)
```

```python
docs = clarifai_vector_db.similarity_search("Texts related to population")
docs
```

## 从现有应用创建

在 Clarifai 内部，我们有很棒的工具可以通过 API 或 UI 向应用程序（本质上是项目）添加数据。大多数用户在与 LangChain 交互之前就已经完成了这项工作，所以此示例将使用现有应用中的数据来执行搜索。请查看我们的 [API 文档](https://docs.clarifai.com/api-guide/data/create-get-update-delete) 和 [UI 文档](https://docs.clarifai.com/portal-guide/data)。然后，Clarifai 应用可用于语义搜索，以查找相关的文档。

```python
USER_ID = "USERNAME_ID"
APP_ID = "APPLICATION_ID"
NUMBER_OF_DOCS = 4
```

```python
clarifai_vector_db = Clarifai(
    user_id=USER_ID,
    app_id=APP_ID,
    number_of_docs=NUMBER_OF_DOCS,
)
```

```python
docs = clarifai_vector_db.similarity_search(
    "Texts related to ammuniction and president wilson"
)
```
