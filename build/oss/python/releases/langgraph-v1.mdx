**LangGraph v1 是一个专注于稳定性的智能体运行时版本。** 它保持了核心图（Graph）API 和执行模型不变，同时改进了类型安全、文档和开发者的人机工程学（使用体验）。

该版本的发布旨在与 [LangChain v1](/oss/python/releases/langchain-v1) 紧密配合（LangChain 的 `create_agent` 正是基于 LangGraph 构建的），这样您就可以从高层次开始，并在需要时深入到细粒度的控制层面。

<CardGroup cols={1}>
    <Card title="核心 API 稳定" icon="diagram-project">
        图（Graph）的基本结构（状态、节点、边）和执行/运行时模型没有变化，这使得升级过程非常简单直接。
    </Card>
    <Card title="默认可靠性" icon="database">
        持久化执行（通过检查点、持久化、流式传输和人机协作）仍然是首要支持的功能。
    </Card>
    <Card title="与 LangChain v1 无缝集成" icon="link">
        LangChain 的 `create_agent` 运行在 LangGraph 之上。使用 LangChain 可以快速入门；需要自定义编排时，则切换到 LangGraph。
    </Card>
</CardGroup>

要进行升级，请执行以下操作：

<CodeGroup>
```bash pip
pip install -U langgraph
```
```bash uv
uv add langgraph
```
</CodeGroup>

## 弃用 `create_react_agent`

LangGraph 中预构建的 [`create_react_agent`](https://reference.langchain.com/python/langgraph/agents/#langgraph.prebuilt.chat_agent_executor.create_react_agent) 组件已被弃用，取而代之的是 LangChain 的 [`create_agent`](https://reference.langchain.com/python/langchain/agents/#langchain.agents.create_agent)。后者提供了一个更简洁的接口，并且通过引入中间件（middleware）提供了更大的定制潜力。

* 有关新的 [`create_agent`](https://reference.langchain.com/python/langchain/agents/#langchain.agents.create_agent) API 的信息，请参阅 [LangChain v1 发布说明](/oss/python/releases/langchain-v1#create-agent)。
* 有关如何从 [`create_react_agent`](https://reference.langchain.com/python/langgraph/agents/#langgraph.prebuilt.chat_agent_executor.create_react_agent) 迁移到 [`create_agent`](https://reference.langchain.com/python/langchain/agents/#langchain.agents.create_agent) 的信息，请参阅 [LangChain v1 迁移指南](/oss/python/migrate/langchain-v1#create-agent)。
