---
title: Google Vertex AI 匹配引擎
---

<Tip>
**兼容性**

仅在 Node.js 上可用。
</Tip>

Google Vertex AI 匹配引擎“提供了业界领先的高扩展、低延迟的向量数据库。这些向量数据库通常被称为向量相似性匹配或近似最近邻 (ANN) 服务。”

## 设置

<Warning>
**此模块需要预先创建好端点和部署的索引，因为创建过程需要将近一个小时。要了解更多信息，请参阅 LangChain Python 文档中的 [创建索引并将其部署到端点](https://python.langchain.com/docs/integrations/vectorstores/google_vertex_ai_vector_search/#deploy-index-to-the-endpoint)。**
</Warning>

在运行此代码之前，您应该确保 Vertex AI API 已为您在 Google Cloud 控制台中选择的相关项目中启用，并且您已通过以下任一方法向 Google Cloud 进行身份验证：

- 您已登录到允许访问该项目的帐户（使用 `gcloud auth application-default login`）。
- 您正在运行在一个被授权访问该项目的服务账号所在的机器上。
- 您已下载了被授权访问该项目的服务账号的凭据，并将 `GOOGLE_APPLICATION_CREDENTIALS` 环境变量设置为该文件的路径。

使用以下命令安装身份验证库：

```bash npm
npm install @langchain/community @langchain/core google-auth-library
```
匹配引擎不会存储实际的文档内容，只存储嵌入向量 (embeddings)。因此，您需要一个文档存储 (docstore)。下面的示例使用了 Google Cloud Storage，这要求安装以下库：

```bash npm
npm install @google-cloud/storage
```
## 用法

### 初始化引擎

创建 `MatchingEngine` 对象时，您需要一些关于匹配引擎配置的信息。您可以从匹配引擎的 Cloud Console 中获取这些信息：

- 索引的 ID
- 索引端点的 ID

您还需要一个文档存储。虽然对于初始测试，`InMemoryDocstore` 是可以接受的，但您可能希望使用类似 [GoogleCloudStorageDocstore](https://api.js.langchain.com/classes/_langchain_community.stores_doc_gcs.GoogleCloudStorageDocstore.html) 的存储，以便更持久地保存数据。

```typescript
import { MatchingEngine } from "@langchain/community/vectorstores/googlevertexai";
import { Document } from "@langchain/classic/document";
import { SyntheticEmbeddings } from "@langchain/classic/embeddings/fake";
import { GoogleCloudStorageDocstore } from "@langchain/community/stores/doc/gcs";

const embeddings = new SyntheticEmbeddings({
  vectorSize: Number.parseInt(
    process.env.SYNTHETIC_EMBEDDINGS_VECTOR_SIZE ?? "768",
    10
  ),
});

const store = new GoogleCloudStorageDocstore({
  bucket: process.env.GOOGLE_CLOUD_STORAGE_BUCKET!,
});

const config = {
  index: process.env.GOOGLE_VERTEXAI_MATCHINGENGINE_INDEX!,
  indexEndpoint: process.env.GOOGLE_VERTEXAI_MATCHINGENGINE_INDEXENDPOINT!,
  apiVersion: "v1beta1",
  docstore: store,
};

const engine = new MatchingEngine(embeddings, config);
```
### 添加文档

```typescript
const doc = new Document({ pageContent: "this" });
await engine.addDocuments([doc]);
```
文档中的任何元数据 (metadata) 都会被转换为匹配引擎的“允许列表” (allow list) 值，这些值可用于查询时的过滤。

```typescript
const documents = [
  new Document({
    pageContent: "this apple",
    metadata: {
      color: "red",
      category: "edible",
    },
  }),
  new Document({
    pageContent: "this blueberry",
    metadata: {
      color: "blue",
      category: "edible",
    },
  }),
  new Document({
    pageContent: "this firetruck",
    metadata: {
      color: "red",
      category: "machine",
    },
  }),
];

// 添加我们所有的文档
await engine.addDocuments(documents);
```
假定这些文档也包含一个 "id" 参数。如果未设置此参数，则会分配一个 ID 并在返回的 Document 中作为一部分返回。

### 查询文档

使用任何标准方法进行直接的 k-最近邻搜索，该搜索将返回所有结果：

```typescript
const results = await engine.similaritySearch("this");
```
### 带过滤/限制条件的文档查询

我们可以根据文档设置的元数据来限制返回的文档。因此，如果我们只想将结果限制为颜色为“红色”的文档，我们可以这样做：

```typescript
import { Restriction } from `@langchain/community/vectorstores/googlevertexai`;

const redFilter: Restriction[] = [
  {
    namespace: "color",
    allowList: ["red"],
  },
];
const redResults = await engine.similaritySearch("this", 4, redFilter);
```
如果我们想做更复杂的操作，比如查找红色的、但不是可食用的物品：

```typescript
const filter: Restriction[] = [
  {
    namespace: "color",
    allowList: ["red"],
  },
  {
    namespace: "category",
    denyList: ["edible"],
  },
];
const results = await engine.similaritySearch("this", 4, filter);
```
### 删除文档

删除文档是根据 ID 进行的。

```typescript
import { IdDocument } from `@langchain/community/vectorstores/googlevertexai`;

const oldResults: IdDocument[] = await engine.similaritySearch("this", 10);
const oldIds = oldResults.map( doc => doc.id! );
await engine.delete({ids: oldIds});
```
