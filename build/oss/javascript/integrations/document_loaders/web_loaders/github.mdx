此示例介绍如何从 GitHub 仓库加载数据。
您可以设置环境变量 `GITHUB_ACCESS_TOKEN` 为 GitHub 访问令牌，以提高速率限制并访问私有仓库。

## 设置 (Setup)

GitHub 加载器需要 [ignore npm 包](https://www.npmjs.com/package/ignore) 作为对等依赖项（peer dependency）。请按如下方式安装它：

```bash npm
npm install @langchain/community @langchain/core ignore
```

## 用法 (Usage)

```typescript
import { GithubRepoLoader } from "@langchain/community/document_loaders/web/github";

export const run = async () => {
  const loader = new GithubRepoLoader(
    "https://github.com/langchain-ai/langchainjs",
    {
      branch: "main",
      recursive: false,
      unknown: "warn",
      maxConcurrency: 5, // 默认值为 2
    }
  );
  const docs = await loader.load();
  console.log({ docs });
};
```

加载器将忽略二进制文件（如图片）。

### 使用 `.gitignore` 语法

要忽略特定文件，可以在构造函数中传入一个 `ignorePaths` 数组：

```typescript
import { GithubRepoLoader } from "@langchain/community/document_loaders/web/github";

export const run = async () => {
  const loader = new GithubRepoLoader(
    "https://github.com/langchain-ai/langchainjs",
    { branch: "main", recursive: false, unknown: "warn", ignorePaths: ["*.md"] }
  );
  const docs = await loader.load();
  console.log({ docs });
  // 不会包含任何 .md 文件
};
```

### 使用不同的 GitHub 实例

您可能希望目标不是 `github.com`，而是另一个 GitHub 实例，例如您公司内部使用的 GitHub Enterprise 实例。
为此，您需要提供两个额外的参数：

- `baseUrl` - 您的 GitHub 实例的基础 URL，这样 `githubUrl` 就会匹配 `<baseUrl>/<owner>/<repo>/...`
- `apiUrl` - 您的 GitHub 实例的 API 端点 URL

```typescript
import { GithubRepoLoader } from "@langchain/community/document_loaders/web/github";

export const run = async () => {
  const loader = new GithubRepoLoader(
    "https://github.your.company/org/repo-name",
    {
      baseUrl: "https://github.your.company",
      apiUrl: "https://github.your.company/api/v3",
      accessToken: "ghp_A1B2C3D4E5F6a7b8c9d0",
      branch: "main",
      recursive: true,
      unknown: "warn",
    }
  );
  const docs = await loader.load();
  console.log({ docs });
};
```

### 处理子模块 (Submodules)

如果您的仓库包含子模块，您需要决定加载器是否应该跟踪它们。您可以使用布尔参数 `processSubmodules` 来控制此行为。默认情况下，子模块不被处理。
请注意，处理子模块仅在设置 `recursive` 参数为 `true` 时才有效。

```typescript
import { GithubRepoLoader } from "@langchain/community/document_loaders/web/github";

export const run = async () => {
  const loader = new GithubRepoLoader(
    "https://github.com/langchain-ai/langchainjs",
    {
      branch: "main",
      recursive: true,
      processSubmodules: true,
      unknown: "warn",
    }
  );
  const docs = await loader.load();
  console.log({ docs });
};
```

请注意，加载器不会跟踪位于与当前仓库不同 GitHub 实例上的子模块。

### 流式处理大型仓库 (Stream large repository)

在需要以内存高效的方式处理大型仓库的情况下，您可以使用 `loadAsStream` 方法，以异步流的形式从整个 GitHub 仓库中加载文档。

```typescript
import { GithubRepoLoader } from "@langchain/community/document_loaders/web/github";

export const run = async () => {
  const loader = new GithubRepoLoader(
    "https://github.com/langchain-ai/langchainjs",
    {
      branch: "main",
      recursive: false,
      unknown: "warn",
      maxConcurrency: 3, // 默认值为 2
    }
  );

  const docs = [];
  for await (const doc of loader.loadAsStream()) {
    docs.push(doc);
  }

  console.log({ docs });
};
```
