<Tip>

本指南介绍了如何使用 [Sonix](https://sonix.ai/) API 从音频文件中加载文档对象（即转录文本）。

## 设置 (Setup)

要运行此加载器，您需要在 https://sonix.ai/ 注册一个账户，并从 https://my.sonix.ai/api 页面获取一个身份验证密钥 (auth key)。

您还需要安装 `sonix-speech-recognition` 相关的库：

```bash npm
npm install @langchain/community @langchain/core sonix-speech-recognition
```

## 用法 (Usage)

配置好身份验证密钥后，您可以使用这个加载器来创建转录内容，然后将其转换为 `Document` 对象。在 `request` 参数中，您可以通过设置 `audioFilePath` 来指定本地文件路径，或者使用 `audioUrl` 来指定远程文件 URL。您还需要指定音频的语言。支持的语言列表请参见 [此处](https://sonix.ai/docs/api#languages)。

```typescript
import { SonixAudioTranscriptionLoader } from "@langchain/community/document_loaders/web/sonix_audio";

const loader = new SonixAudioTranscriptionLoader({
  sonixAuthKey: "SONIX_AUTH_KEY",
  request: {
    audioFilePath: "LOCAL_AUDIO_FILE_PATH",
    fileName: "FILE_NAME",
    language: "en",
  },
});

const docs = await loader.load();

console.log(docs);
```
