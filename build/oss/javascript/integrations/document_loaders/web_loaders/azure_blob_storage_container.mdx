title: Azure Blob 存储容器
---

<Tip>
**兼容性**

仅在 Node.js 环境下可用。
</Tip>

本指南介绍如何将 Azure Blob 存储中的容器加载到 LangChain 的文档（Documents）中。

## 设置

要运行此加载器，你需要确保 Unstructured 已经设置好，并且可以通过一个可用的 URL 端点访问。它也可以配置为在本地运行。

有关如何进行设置的信息，请参见 [此处](/oss/javascript/integrations/document_loaders/file_loaders/unstructured) 的文档。

你还需要安装官方的 Azure 存储 Blob 客户端库：

```bash npm
npm install @langchain/community @langchain/core @azure/storage-blob
```

## 用法

一旦 Unstructured 配置完成，你就可以使用 Azure Blob 存储容器加载器来加载文件，然后将它们转换为 `Document` 对象。

```typescript
import { AzureBlobStorageContainerLoader } from "@langchain/community/document_loaders/web/azure_blob_storage_container";

const loader = new AzureBlobStorageContainerLoader({
  azureConfig: {
    connectionString: "",
    container: "container_name",
  },
  unstructuredConfig: {
    apiUrl: "http://localhost:8000/general/v0/general",
    apiKey: "", // 此项很快将成为必需项
  },
});

const docs = await loader.load();

console.log(docs);
```
