---
title: ChatGPT 文件
---

本示例将介绍如何从您的 ChatGPT 数据导出文件夹中加载 `conversations.json` 文件。您可以通过以下路径获取数据导出文件：ChatGPT -> (个人资料/Profile) -> 设置 (Settings) -> 导出数据 (Export data) -> 确认导出 (Confirm export) -> 查看电子邮件。

## 用法：提取所有日志

示例代码：

```typescript
import { ChatGPTLoader } from "@langchain/community/document_loaders/fs/chatgpt";

const loader = new ChatGPTLoader("./example_data/example_conversations.json");

const docs = await loader.load();

console.log(docs);
```

## 用法：提取单个日志

示例代码：

```typescript
import { ChatGPTLoader } from "@langchain/community/document_loaders/fs/chatgpt";

const loader = new ChatGPTLoader(
  "./example_data/example_conversations.json",
  1
);

const docs = await loader.load();

console.log(docs);
```
