---
title: Cohere 重排序 (Rerank)
---

对文档进行重排序 (Reranking) 可以极大地改进任何 RAG 应用和文档检索系统。

从宏观角度看，重排序 API 是一个语言模型，它分析文档，并根据文档与给定查询的相关性对它们重新排序。

Cohere 提供了一个用于文档重排序的 API。在这个示例中，我们将向您展示如何使用它。

## 设置 (Setup)

<Tip>
请参阅 [此部分](/oss/javascript/langchain/install) 获取安装 LangChain 包的通用说明。
</Tip>

```bash npm
npm install @langchain/cohere @langchain/core
```

```typescript
import { CohereRerank } from "@langchain/cohere";
import { Document } from "@langchain/core/documents";

const query = "What is the capital of the United States?"; // “美国的（首都在哪里）？”
const docs = [
  new Document({
    pageContent:
      "Carson City is the capital city of the American state of Nevada. At the 2010 United States Census, Carson City had a population of 55,274.", // 卡森城是美国内华达州的首府。根据 2010 年美国人口普查，卡森城的人口为 55,274。
  }),
  new Document({
    pageContent:
      "The Commonwealth of the Northern Mariana Islands is a group of islands in the Pacific Ocean that are a political division controlled by the United States. Its capital is Saipan.", // 北马里亚纳群岛联邦是太平洋中的一群岛屿，是美国控制的政治实体。其首都是塞班岛。
  }),
  new Document({
    pageContent:
      "Charlotte Amalie is the capital and largest city of the United States Virgin Islands. It has about 20,000 people. The city is on the island of Saint Thomas.", // 夏洛特阿马利亚是美属维尔京群岛的首府和最大城市。它大约有 20,000 人。该城市位于圣托马斯岛上。
  }),
  new Document({
    pageContent:
      "Washington, D.C. (also known as simply Washington or D.C., and officially as the District of Columbia) is the capital of the United States. It is a federal district. The President of the USA and many major national government offices are in the territory. This makes it the political center of the United States of America.", // 华盛顿哥伦比亚特区（通常简称为华盛顿或 D.C.，官方名称为哥伦比亚特区）是美国的首都。它是一个联邦直辖区。美国总统和许多主要的国家政府机构都在该地区。这使其成为美利坚合众国的政治中心。
  }),
  new Document({
    pageContent:
      "Capital punishment (the death penalty) has existed in the United States since before the United States was a country. As of 2017, capital punishment is legal in 30 of the 50 states. The federal government (including the United States military) also uses capital punishment.", // 死刑（终身监禁）在美国建国前就已存在。截至 2017 年，死刑在美国 50 个州中的 30 个州是合法的。联邦政府（包括美国军方）也使用死刑。
  }),
];

const cohereRerank = new CohereRerank({
  apiKey: process.env.COHERE_API_KEY, // 默认值
  model: "rerank-english-v2.0",
});

const rerankedDocuments = await cohereRerank.rerank(docs, query, {
  topN: 5,
});

console.log(rerankedDocuments);
/**
[
  { index: 3, relevanceScore: 0.9871293 },
  { index: 1, relevanceScore: 0.29961726 },
  { index: 4, relevanceScore: 0.27542195 },
  { index: 0, relevanceScore: 0.08977329 },
  { index: 2, relevanceScore: 0.041462272 }
]
 */
```

在这里，我们可以看到 `.rerank()` 方法只返回文档的索引（与输入文档的索引相匹配）及其相关性分数。

如果我们希望从该方法本身返回排序后的文档，我们可以使用 `.compressDocuments()` 方法。

console.log(rerankedDocuments);

正如预期的那样，相关性分数最高的文档是引用了华盛顿特区的文档，得分为 `98.7%`！

### 与 `CohereClient` 的用法
