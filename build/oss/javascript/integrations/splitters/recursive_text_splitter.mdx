title: 递归分割
---

这个[文本分割器](/oss/javascript/integrations/splitters/)是通用文本推荐使用的分割器。它通过一个字符列表进行参数化配置。它会按顺序尝试在这些分隔符上进行分割，直到文本块足够小为止。默认的分隔符列表是 `["\n\n", "\n", " ", ""]`。这样做的效果是尽可能长时间地保持段落（然后是句子，然后是单词）的完整性，因为这些通常被认为是语义关联最强的文本片段。

1. 文本如何分割：通过字符列表。
2. 文本块大小如何衡量：通过字符数量。

下面我们展示使用示例。


<CodeGroup>
```bash npm
npm install @langchain/textsplitters
```

```bash pnpm
pnpm install @langchain/textsplitters
```

```bash yarn
yarn add @langchain/textsplitters
```

```bash bun
bun add @langchain/textsplitters
```
</CodeGroup>




要直接获取字符串内容，请使用 `.splitText`。

要创建 LangChain [Document](https://reference.langchain.com/javascript/classes/_langchain_core.documents.Document.html) 对象（例如，用于下游任务），请使用 `.createDocuments`。

```ts
import { RecursiveCharacterTextSplitter } from "@langchain/textsplitters";

const splitter = new RecursiveCharacterTextSplitter({ chunkSize: 100, chunkOverlap: 0 })
const texts = splitter.createDocuments([{ pageContent: "..." }])
```
```output
[
  { pageContent: "...", metadata: {} },
]
```


让我们看一下上面为 `RecursiveCharacterTextSplitter` 设置的参数：



- `chunkSize`: 分块的最大尺寸，尺寸由 `lengthFunction` 决定。
- `chunkOverlap`: 分块之间的目标重叠度。重叠的分块有助于减轻上下文在分块之间分割时丢失信息的风险。


## 分割不具有单词边界的语言的文本

有些书写系统没有[单词边界](https://en.wikipedia.org/wiki/Category:Writing_systems_without_word_boundaries)，例如中文、日文和泰文。使用默认分隔符列表 `["\n\n", "\n", " ", ""]` 分割文本可能会导致单词被分割到不同的分块中。为了保持单词的完整性，您可以重写分隔符列表，加入额外的标点符号：

* 添加 ASCII 句点“`.`”，[Unicode 全角句点](https://en.wikipedia.org/wiki/Halfwidth_and_Fullwidth_Forms_(Unicode_block)) “`．`”（用于中文），以及[表意文字句点](https://en.wikipedia.org/wiki/CJK_Symbols_and_Punctuation) “`。`”（用于日文和中文）
* 添加泰文、缅甸文、高棉文和日文中使用的[零宽度空格](https://en.wikipedia.org/wiki/Zero-width_space)（`\u200b`）。
* 添加 ASCII 逗号“`,`”，[Unicode 全角逗号](https://en.wikipedia.org/wiki/Halfwidth_and_Fullwidth_Forms_(Unicode_block))“`，`”，以及 [Unicode 表意文字逗号](https://en.wikipedia.org/wiki/CJK_Symbols_and_Punctuation) “`、`”


```ts
const splitter = new RecursiveCharacterTextSplitter({
  separators: [
    "\n\n",
    "\n",
    " ",
    ".",
    ",",
    "\u200b",  // Zero-width space (零宽度空格)
    "\uff0c",  // Fullwidth comma (全角逗号)
    "\u3001",  // Ideographic comma (表意文字逗号)
    "\uff0e",  // Fullwidth full stop (全角句点)
    "\u3002",  // Ideographic stop (表意文字句点)
    "",
  ],
});
```
