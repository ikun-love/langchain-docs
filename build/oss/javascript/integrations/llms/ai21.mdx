您可以通过在 [其官网站点](https://www.ai21.com/) 注册 API 密钥，来开始使用 AI21Labs 的 Jurassic 系列模型，并查看可用基础模型的完整列表。

以下是在 LangChain.js 中初始化一个实例的示例：

<Tip>
有关安装 LangChain 包的通用说明，请参阅 [本章节](/oss/javascript/langchain/install)。
</Tip>

```bash npm
npm install @langchain/community @langchain/core
```

```typescript
import { AI21 } from "@langchain/community/llms/ai21";

const model = new AI21({
  ai21ApiKey: "YOUR_AI21_API_KEY", // 或者设置为环境变量 process.env.AI21_API_KEY
});

const res = await model.invoke(`Translate "I love programming" into German.`);

console.log({ res });

/*
  {
    res: "\nIch liebe das Programmieren."
  }
 */
```
