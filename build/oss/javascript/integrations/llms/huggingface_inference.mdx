下面是如何调用 HuggingFaceInference 模型作为大型语言模型（LLM）的示例：

```bash npm
npm install @langchain/community @langchain/core @huggingface/inference@4
```

<Tip>
我们正在统一所有包的模型参数。我们现在建议使用 `model` 替代 `modelName`，并使用 `apiKey` 来表示 API 密钥。
</Tip>

```typescript
import { HuggingFaceInference } from "@langchain/community/llms/hf";

const model = new HuggingFaceInference({
  model: "gpt2",
  apiKey: "YOUR-API-KEY", // 在 Node.js 环境中，默认会读取 process.env.HUGGINGFACEHUB_API_KEY
});
const res = await model.invoke("1 + 1 =");
console.log({ res });
```
