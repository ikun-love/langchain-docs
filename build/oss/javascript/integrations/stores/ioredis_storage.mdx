此示例演示了如何使用 `RedisByteStore` [`BaseStore`](https://reference.langchain.com/javascript/classes/_langchain_langgraph-checkpoint.BaseStore.html) 集成来设置聊天历史记录存储。

## 设置

```bash npm
npm install @langchain/community @langchain/core ioredis
```

## 用法

```typescript
import { Redis } from "ioredis";
import { RedisByteStore } from "@langchain/community/storage/ioredis";
import { AIMessage, HumanMessage } from "@langchain/core/messages";

// 定义客户端和存储
const client = new Redis({});
const store = new RedisByteStore({
  client,
});
// 定义我们的编码器/解码器，用于在字符串和 Uint8Array 之间进行转换
const encoder = new TextEncoder();
const decoder = new TextDecoder();
/**
 * 在这里，您需要定义 LLM 和聊天链，调用 LLM，并最终获得消息列表。
 * 在此示例中，我们假设已经有了一个列表。
 */
const messages = Array.from({ length: 5 }).map((_, index) => {
  if (index % 2 === 0) {
    return new AIMessage("ai stuff...");
  }
  return new HumanMessage("human stuff...");
});
// 将您的消息设置到存储中
// 键将以 `message:id:` 为前缀，并以索引结尾。
await store.mset(
  messages.map((message, index) => [
    `message:id:${index}`,
    encoder.encode(JSON.stringify(message)),
  ])
);
// 现在您可以从存储中获取消息
const retrievedMessages = await store.mget(["message:id:0", "message:id:1"]);
// 确保解码这些值
console.log(retrievedMessages.map((v) => decoder.decode(v)));
/**
[
  '{"id":["langchain","AIMessage"],"kwargs":{"content":"ai stuff..."}}',
  '{"id":["langchain","HumanMessage"],"kwargs":{"content":"human stuff..."}}'
]
 */
// 或者，如果您想获取所有键，可以调用 `yieldKeys` 方法。
// （可选）您可以传递一个键前缀，仅获取与该前缀匹配的键。
const yieldedKeys = [];
for await (const key of store.yieldKeys("message:id:")) {
  yieldedKeys.push(key);
}
// 键是未编码的，因此不需要解码
console.log(yieldedKeys);
/**
[
  'message:id:2',
  'message:id:1',
  'message:id:3',
  'message:id:0',
  'message:id:4'
]
 */
// 最后，让我们从存储中删除这些键，并关闭 Redis 连接。
await store.mdelete(yieldedKeys);
client.disconnect();
```
