## 概述

<Note>
本概述涵盖**基于文本的嵌入模型**。LangChain 目前不支持多模态嵌入。
</Note>

嵌入模型可以将原始文本（如句子、段落或推文）转换成一个固定长度的数字向量，该向量捕获了文本的**语义含义**。这些向量使得机器能够基于含义而非精确的词语进行文本比较和搜索。

在实践中，这意味着想法相似的文本在向量空间中会彼此靠近。例如，嵌入模型不仅能匹配短语 *"machine learning"*，还能在使用了不同措辞的情况下，检索出讨论相关概念的文档。

### 工作原理

1. **向量化 (Vectorization)** — 模型将每个输入字符串编码为一个高维向量。
2. **相似度评分 (Similarity scoring)** — 使用数学指标比较向量，以衡量底层文本的相关程度。

### 相似度度量标准 (Similarity metrics)

比较嵌入时，通常使用以下几种度量标准：

* **余弦相似度 (Cosine similarity)** — 测量两个向量之间的夹角。
* **欧几里得距离 (Euclidean distance)** — 测量两点之间的直线距离。
* **点积 (Dot product)** — 测量一个向量在另一个向量上的投影程度。

## 接口 (Interface)

LangChain 通过 [Embeddings](https://reference.langchain.com/javascript/classes/_langchain_core.embeddings.Embeddings.html) 接口为文本嵌入模型（例如 OpenAI, Cohere, Hugging Face）提供了一个标准的接口。

提供两种主要方法：

* `embedDocuments(documents: string[]) → number[][]`: 对一组文档进行嵌入。
* `embedQuery(text: string) → number[]`: 对单个查询进行嵌入。

<Note>
该接口允许使用不同的策略对查询和文档进行嵌入，尽管在实践中大多数服务提供商处理方式相同。
</Note>

## 缓存 (Caching)

嵌入模型的结果可以存储或临时缓存，以避免重复计算。

可以使用 `CacheBackedEmbeddings` 来缓存嵌入。这个包装器会将嵌入存储在一个键值存储中，其中文本被哈希化，哈希值用作缓存中的键。

初始化 `CacheBackedEmbeddings` 的主要受支持方式是 `fromBytesStore`。它接受以下参数：

- **underlyingEmbeddings**: 用于嵌入的底层嵌入器。
- **documentEmbeddingStore**: 用于缓存文档嵌入的任何 [`BaseStore`](/oss/javascript/integrations/stores/) 实例。
- **options.namespace**: (可选，默认为 `""`) 用于文档缓存的命名空间。有助于避免冲突（例如，可以将其设置为嵌入模型的名称）。

<Important>
- 使用不同的嵌入模型时，务必设置 `namespace` 参数以避免冲突。
- 默认情况下，`CacheBackedEmbeddings` 不会缓存查询嵌入。要启用此功能，请指定 `query_embedding_store`。
</Important>

```typescript
import { CacheBackedEmbeddings } from "@langchain/classic/embeddings/cache_backed";
import { InMemoryStore } from "@langchain/core/stores";

const underlyingEmbeddings = new OpenAIEmbeddings();

const inMemoryStore = new InMemoryStore();

const cacheBackedEmbeddings = CacheBackedEmbeddings.fromBytesStore(
  underlyingEmbeddings,
  inMemoryStore,
  {
    namespace: underlyingEmbeddings.model,
  }
);

// 示例：缓存查询嵌入
const tic = Date.now();
const queryEmbedding = cacheBackedEmbeddings.embedQuery("Hello, world!");
console.log(`第一次调用耗时: ${Date.now() - tic}ms`);

// 示例：缓存文档嵌入
const tic = Date.now();
const documentEmbedding = cacheBackedEmbeddings.embedDocuments(["Hello, world!"]);
console.log(`缓存创建时间: ${Date.now() - tic}ms`);
```

在生产环境中，您通常会使用更健壮的持久化存储，例如数据库或云存储。请参阅 [stores 集成](/oss/javascript/integrations/stores/) 查看可用选项。
