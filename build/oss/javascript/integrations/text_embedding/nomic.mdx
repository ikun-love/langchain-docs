`NomicEmbeddings` 类使用 Nomic AI API 为给定文本生成嵌入（Embeddings）。

## 环境准备 (Setup)

为了使用 Nomic API，您需要一个 API 密钥。
您可以在 [此处](https://atlas.nomic.ai/) 注册一个 Nomic 账户并创建一个 API 密钥。

首先，您需要安装 [`@langchain/nomic`](https://www.npmjs.com/package/@langchain/nomic) 包：

<Tip>
有关安装 LangChain 包的通用说明，请参阅[本节](/oss/javascript/langchain/install)。
</Tip>

```bash npm
npm install @langchain/nomic @langchain/core
```

## 用法 (Usage)

```typescript
import { NomicEmbeddings } from "@langchain/nomic";

/* 嵌入单个查询 */
const nomicEmbeddings = new NomicEmbeddings();
const res = await nomicEmbeddings.embedQuery("Hello world");
console.log(res);
/* 嵌入多个文档 */
const documentRes = await nomicEmbeddings.embedDocuments([
  "Hello world",
  "Bye bye",
]);
console.log(documentRes);
```
