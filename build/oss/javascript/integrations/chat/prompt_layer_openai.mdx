您可以传入可选的 `returnPromptLayerId` 布尔值，以像下面一样获取 `promptLayerRequestId`。以下是获取 PromptLayerChatOpenAI 请求 ID 的示例：

```typescript
import { PromptLayerChatOpenAI } from "@langchain/classic/llms/openai";

const chat = new PromptLayerChatOpenAI({
  returnPromptLayerId: true,
});

const respA = await chat.generate([
  [
    new SystemMessage(
      "You are a helpful assistant that translates English to French." // 这是一个示例字符串，不进行翻译
    ),
  ],
]);

console.log(JSON.stringify(respA, null, 3));
```
