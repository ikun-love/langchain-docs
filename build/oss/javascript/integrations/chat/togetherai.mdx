## 设置 (Setup)

要访问 `ChatTogetherAI` 模型，您需要创建一个 Together 账户，[在此处](https://api.together.xyz/) 获取一个 API 密钥，并安装 `@langchain/community` 集成包。

### 凭证 (Credentials)

前往 [api.together.ai](https://api.together.ai/) 注册 TogetherAI 并生成 API 密钥。完成操作后，设置 `TOGETHER_AI_API_KEY` 环境变量：

```bash
export TOGETHER_AI_API_KEY="your-api-key"
```

如果您希望对模型调用进行自动跟踪（tracing），也可以通过取消注释以下内容来设置您的 [LangSmith](https://docs.smith.langchain.com/) API 密钥：

```bash
# export LANGSMITH_TRACING="true"
# export LANGSMITH_API_KEY="your-api-key"
```

### 安装 (Installation)

LangChain ChatTogetherAI 集成位于 `@langchain/community` 包中：

<CodeGroup>
```bash npm
npm install @langchain/community @langchain/core
```
```bash yarn
yarn add @langchain/community @langchain/core
```
```bash pnpm
pnpm add @langchain/community @langchain/core
```
</CodeGroup>

## 实例化 (Instantiation)

现在我们可以实例化模型对象并生成聊天补全（chat completions）：

```typescript
import { ChatTogetherAI } from "@langchain/community/chat_models/togetherai"

const llm = new ChatTogetherAI({
    model: "mistralai/Mixtral-8x7B-Instruct-v0.1",
    temperature: 0,
    // other params...
})
```

## 调用 (Invocation)

```typescript
const aiMsg = await llm.invoke([
    [
        "system",
        "You are a helpful assistant that translates English to French. Translate the user sentence.",
    ],
    ["human", "I love programming."],
])
aiMsg
```
