---
title: Arcjet 屏蔽
---

[Arcjet](https://arcjet.com) 的屏蔽（Redact）集成功能，允许您在将用户提示（prompts）发送给聊天模型（Chat Model）**之前**，屏蔽掉其中敏感的用户信息。

Arcjet Redact 完全在您自己的机器上运行，**绝不会将数据发送到任何其他地方**，从而确保了顶级隐私保护和高性能。

Arcjet Redact 对象本身并不是一个聊天模型，而是对一个大语言模型（LLM）进行封装。它会屏蔽传入的文本，然后在包装的聊天模型的输出被返回之前，对其进行“解屏蔽”（unredact）处理。

### 安装

安装 Arcjet 屏蔽库：

<CodeGroup>
```bash npm
npm install @arcjet/redact
```
```bash yarn
yarn add @arcjet/redact
```
```bash pnpm
pnpm add @arcjet/redact
```
</CodeGroup>

然后安装 LangChain Community：

<CodeGroup>
```bash npm
npm install @langchain/community @langchain/core
```
```bash yarn
yarn add @langchain/community @langchain/core
```
```bash pnpm
pnpm add @langchain/community @langchain/core
```
</CodeGroup>

现在您就可以开始使用 Arcjet 屏蔽功能来保护您的聊天模型调用了！

## 用法

```typescript
import {
  ArcjetRedact,
  ArcjetSensitiveInfoType,
} from "@langchain/community/chat_models/arcjet";
import { ChatOpenAI } from "@langchain/openai";

// 创建另一个聊天模型的实例，供 Arcjet Redact 封装调用
const openai = new ChatOpenAI({
  temperature: 0.8,
  model: "gpt-3.5-turbo-0125",
});

const arcjetRedactOptions = {
  // 指定一个 LLM，Arcjet Redact 在屏蔽输入内容后将调用它。
  chatModel: openai,

  // 指定需要被屏蔽的实体（敏感信息）类型列表。
  // 如果未指定，则所有支持的实体类型都将被屏蔽。
  entities: ["email", "phone-number", "ip-address", "custom-entity"] as ArcjetSensitiveInfoType[],

  // 您可以提供一个自定义的检测函数，用于检测我们尚未支持的实体。
  // 该函数接收一个 token 列表，并返回一个识别出的类型列表或 undefined。
  // 返回 undefined 的类型如果需要在屏蔽列表中使用，应该被添加到 entities 列表中。
  detect: (tokens: string[]) => {
    return tokens.map((t) => t === "some-sensitive-info" ? "custom-entity" : undefined)
  },

  // 传递给自定义检测函数（detect）的 token 数量。默认值为 1。
  // 这可以用于在检测自定义实体类型时提供额外的上下文信息。
  contextWindowSize: 1,

  // 这允许您在屏蔽时提供自定义的替换值。请确保替换值是唯一的，以便解屏蔽操作能按预期工作。
  replace: (identifiedType: string) => {
    return identifiedType === "email" ? "redacted@example.com" : undefined;
  },
};

const arcjetRedact = new ArcjetRedact(arcjetRedactOptions);

const response = await arcjetRedact.invoke(
  "My email address is test@example.com, here is some-sensitive-info"
);
```
