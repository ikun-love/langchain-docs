title: 聊天模型
---

[聊天模型](/oss/javascript/langchain/models) 是以消息序列作为输入并返回消息作为输出的语言模型 <Tooltip tip="不遵循聊天模型接口的旧模型，它们使用接受字符串作为输入并返回字符串作为输出的接口。这些模型通常在其名称中不包含前缀 'Chat' 或包含后缀 'LLM'。">(与纯文本模型相对应)</Tooltip>。

## 安装和使用

<Tip>
    有关安装 LangChain 包的通用说明，请参阅[本节](/oss/javascript/langchain/install)。
</Tip>

<AccordionGroup>
    <Accordion title="OpenAI">
        安装：

        <CodeGroup>
            ```bash npm
            npm i @langchain/openai
            ```
            ```bash yarn
            yarn add @langchain/openai
            ```
            ```bash pnpm
            pnpm add @langchain/openai
            ```
        </CodeGroup>

        添加环境变量：

        ```bash
        OPENAI_API_KEY=your-api-key
        ```

        实例化模型：

        ```typescript
        import { ChatOpenAI } from "@langchain/openai";

        const model = new ChatOpenAI({ model: "gpt-4o-mini" });
        ```
        ```javascript
        await model.invoke("Hello, world!")
        ```
    </Accordion>

## 聊天补全 (Chat Completions) API

某些模型提供商提供与 OpenAI 的（旧版）[Chat Completions API](https://platform.openai.com/docs/guides/completions) 兼容的端点。在这种情况下，您可以使用 [`ChatOpenAI`](/oss/javascript/integrations/chat/openai) 并设置自定义 `base_url` 来连接到这些端点。请注意，建立在 Chat Completions API 上的功能可能不完全被 `ChatOpenAI` 支持；在这种情况下，请考虑使用特定于提供商的类（如果可用）。

<Accordion title="示例：OpenRouter">
    要使用 OpenRouter，您需要注册一个账户并获取一个 [API 密钥](https://openrouter.ai/docs/api-reference/authentication)。

    ```typescript
    import { ChatOpenAI } from "@langchain/openai";

    const model = new ChatOpenAI({
        model: "...", // 指定 OpenRouter 上可用的模型
        configuration: {
        apiKey: "OPENROUTER_API_KEY",
        baseURL: "https://openrouter.ai/api/v1",
        }
    });
    ```

    有关更多详细信息，请参阅 [OpenRouter 文档](https://openrouter.ai/docs/quickstart)。
</Accordion>
