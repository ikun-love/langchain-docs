## 设置 (Setup)

要访问 Perplexity 模型，您需要创建一个 Perplexity 账户，获取一个 API 密钥，并安装 `@langchain/community` 集成包。

### 凭证 (Credentials)

请访问 [https://perplexity.ai](https://perplexity.ai) 注册 Perplexity 并生成 API 密钥。完成此操作后，设置 `PERPLEXITY_API_KEY` 环境变量：

```bash
export PERPLEXITY_API_KEY="your-api-key"
```

如果您想为模型调用获取自动化的跟踪记录，也可以取消注释以下内容来设置您的 [LangSmith](https://docs.smith.langchain.com/) API 密钥：

```bash
# export LANGSMITH_TRACING="true"
# export LANGSMITH_API_KEY="your-api-key"
```

### 安装 (Installation)

LangChain 的 Perplexity 集成位于 `@langchain/community` 包中：

<CodeGroup>
```bash npm
npm install @langchain/community @langchain/core
```
```bash yarn
yarn add @langchain/community @langchain/core
```
```bash pnpm
pnpm add @langchain/community @langchain/core
```
</CodeGroup>

## 实例化 (Instantiation)

现在，我们可以实例化模型对象并生成聊天补全 (chat completions)：

```typescript
import { ChatPerplexity } from "@langchain/community/chat_models/perplexity"

const llm = new ChatPerplexity({
  model: "sonar",
  temperature: 0,
  maxTokens: undefined,
  timeout: undefined,
  maxRetries: 2,
  // other params... (其他参数...)
})
```

## 调用 (Invocation)

```typescript
const aiMsg = await llm.invoke([

  },
  {
    role: "user",
    content: "I love programming.",
  },
```
