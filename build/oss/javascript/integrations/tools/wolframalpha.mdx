title: WolframAlpha 工具
---

WolframAlpha 工具将您的代理（Agents）和链（Chains）连接到 WolframAlpha 最先进的计算智能引擎。

## 设置 (Setup)

您需要从 [WolframAlpha 门户网站](https://developer.wolframalpha.com/) 创建一个应用，并获取一个 `appid`。

## 用法 (Usage)

```typescript
import { WolframAlphaTool } from "@langchain/community/tools/wolframalpha";

const tool = new WolframAlphaTool({
  appid: "YOUR_APP_ID",
});

const res = await tool.invoke("What is 2 * 2?");

console.log(res);
```
