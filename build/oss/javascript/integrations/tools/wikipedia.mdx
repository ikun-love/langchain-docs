---
title: 维基百科工具
---

`WikipediaQueryRun` 工具将您的代理（Agents）和链（Chains）与维基百科连接起来。

## 用法

```typescript
import { WikipediaQueryRun } from "@langchain/community/tools/wikipedia_query_run";

const tool = new WikipediaQueryRun({
  topKResults: 3, // 限制返回最相关的结果数量
  maxDocContentLength: 4000, // 限制返回的文档内容的最大长度
});

const res = await tool.invoke("LangChain");

console.log(res);
```
