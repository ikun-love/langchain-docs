**LangGraph v1 是一个专注于稳定性的智能体运行时版本。** 它保持了核心的图（Graph）API 和执行模型不变，同时改进了类型安全、文档和开发者的人机工程学（Developer Ergonomics）。

它的设计理念是与 [LangChain v1](/oss/javascript/releases/langchain-v1) 紧密协作（`createAgent` 就是基于 LangGraph 构建的），因此你可以从高级功能快速启动，并在需要时深入到细粒度的控制。

<CardGroup cols={1}>
    <Card title="核心 API 稳定" icon="diagram-project">
        图的原语（状态、节点、边）以及执行/运行时模型保持不变，这使得升级过程非常直接。
    </Card>
    <Card title="默认可靠" icon="database">
        持久化执行（如检查点、持久化、流式传输和人工干预）仍然是一等公民特性。
    </Card>
    <Card title="与 LangChain v1 无缝集成" icon="link">
        LangChain 的 `createAgent` 运行在 LangGraph 之上。使用 LangChain 可以快速上手；需要自定义编排时，则可下沉到 LangGraph。
    </Card>
</CardGroup>

## 弃用 `createReactAgent`

LangGraph 中预构建的 `createReactAgent` 已被弃用，推荐使用 LangChain 的 `createAgent`。后者提供了一个更简洁的接口，并通过引入中间件（middleware）提供了更强的定制潜力。

* 有关新的 `createAgent` API 的信息，请参阅 [LangChain v1 发布说明](/oss/javascript/releases/langchain-v1#createagent)。
* 有关如何从 `createReactAgent` 迁移到 `createAgent` 的信息，请参阅 [LangChain v1 迁移指南](/oss/javascript/migrate/langchain-v1#createagent)。

## 类型化的中断（Typed Interrupts）

`[StateGraph](https://reference.langchain.com/javascript/classes/_langchain_langgraph.index.StateGraph.html)` 现在在构造函数中接受一个中断类型的映射（map），以便更严格地约束可以在图内部使用的中断类型。

```typescript expandable
import { StateGraph, MemorySaver, interrupt } from "@langchain/langgraph";
import * as z from "zod";

const stateSchema = z.object({
  foo: z.string(),
})

const graphConfig = {
  interrupts: {
    // 定义一个简单的中断，它接受一个 reason 并返回 messages
    simple: interrupt<{ reason: string }, { messages: string[] }>, // [!code highlight]
    // 定义一个具有相同签名的复杂中断
    complex: interrupt<{ reason: string }, { messages: string[] }>, // [!code highlight]
  }
}

const checkpointer = new MemorySaver();

const graph = new StateGraph(stateSchema, graphConfig)
  .addNode("node", async (state, runtime) => {
    // 使用一个 reason 触发简单中断
    const response = runtime.interrupt.simple({ reason: "test" });
    // 将中断响应作为新状态返回
    return { foo: response };
  })
  // 使用检查点编译图
  .compile({ checkpointer });

// 使用初始状态调用图
const result = await graph.invoke({ foo: "test" });

// 访问中断数据
if (graph.isInterrupted(result)) {
  console.log(result.__interrupt__.messages);
}
```

有关中断的更多信息，请参阅 [中断](/oss/javascript/langgraph/interrupts) 文档。

## 前端 SDK 增强

LangGraph v1 在从前端与 LangGraph 应用程序交互时带来了一些增强。

### 事件流编码（Event stream encoding）

底层的 `toLangGraphEventStream` 辅助函数已被移除。流式响应现在由 SDK 原生处理，你可以通过向 `graph.stream` 传入 `encoding` 格式来选择底层的数据线缆格式。这使得在不更改 UI 代码的情况下，轻松地在 SSE（Server-Sent Events）和普通 JSON 响应之间切换变得简单。

有关更多信息，请参阅 [迁移指南](/oss/javascript/migrate/langgraph-v1#stream-encoding)。

### `useStream` 中的自定义传输层（Custom transports）

React 的 `useStream` 钩子现在支持可插入的传输层（pluggable transports），因此你可以在不修改 UI 代码的情况下，对网络层拥有更多控制权。

```typescript
const stream = useStream({
  transport: new FetchStreamTransport({
    apiUrl: "http://localhost:2024",
  }),
});
```

了解如何集成和定制此钩子：[将 LangGraph 集成到你的 React 应用程序中](/oss/javascript/langgraph/ui)。
