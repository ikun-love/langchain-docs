```markdown
title: MODEL_NOT_FOUND

<Note>
    目前仅在 `langchainjs` (JavaScript/TypeScript) 中使用。
</Note>

您指定的模型名称未被您的提供商识别到。

## 故障排查 (Troubleshooting)

要解决此错误，请执行以下操作：

1. **验证模型标识符 (Verify the model identifier)**：仔细检查您传入的模型字符串。确保拼写和格式完全正确。
2. **检查代理/包装器配置 (Check proxy/wrapper configurations)**：如果您正在使用代理或其他替代主机以及模型包装器（wrapper），请确认允许的模型名称没有被限制或更改。

此错误通常源于模型名称字符串中存在拼写错误，或者是模型包装器或代理服务在您的代码和提供商 API 之间施加的限制所致。
```
