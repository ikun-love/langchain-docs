当您准备将 LangChain 智能体（Agent）部署到生产环境时，LangSmith 提供了一个专为智能体工作负载设计的托管式（managed）托管平台。传统的托管平台是为无状态、短期运行的 Web 应用而构建的，而 LangGraph 则是**专门为有状态、长期运行的智能体**构建的，这些智能体需要持久化的状态和后台执行能力。LangSmith 负责处理基础设施、扩展（scaling）和运维方面的问题，因此您可以直接从您的代码仓库进行部署。

## 先决条件

在开始之前，请确保您拥有以下资源：

- 一个 [GitHub 账户](https://github.com/)
- 一个 [LangSmith 账户](https://smith.langchain.com/)（可免费注册）

## 部署您的智能体

### 1. 在 GitHub 上创建一个仓库

您的应用程序代码必须位于一个 GitHub 仓库中，才能部署到 LangSmith 上。LangSmith 支持公共和私有仓库。对于本快速入门，请先确保您的应用与 LangGraph 兼容，方法是遵循 [本地服务器设置指南](/oss/javascript/langchain/studio#setup-local-agent-server)。然后，将您的代码推送到该仓库。
