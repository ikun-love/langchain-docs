本指南将向您展示如何**在本地运行 LangGraph 应用程序**。

## 先决条件

在开始之前，请确保您已准备好以下内容：

* 一个 [LangSmith](https://smith.langchain.com/settings) 的 API 密钥（注册是免费的）。

## 1. 安装 LangGraph CLI



```shell
npx @langchain/langgraph-cli
```


## 2. 创建一个 LangGraph 应用



使用 [`new-langgraph-project-js` 模板](https://github.com/langchain-ai/new-langgraphjs-project) 创建一个新应用。此模板演示了一个单节点应用程序，您可以基于此扩展自己的逻辑。

```shell
npm create langgraph
```


## 3. 安装依赖项

在新的 LangGraph 应用的根目录下，以 `edit` 模式安装依赖项，这样服务器才能使用您的本地更改：



```shell
cd path/to/your/app
npm install
```


## 4. 创建一个 `.env` 文件

您将在新的 LangGraph 应用的根目录下找到一个 `.env.example` 文件。请在应用根目录下创建一个名为 `.env` 的文件，并将 `.env.example` 的内容复制到其中，然后填入必要的 API 密钥：

```bash
LANGSMITH_API_KEY=lsv2...
```

## 5. 启动 Agent 服务器

在本地启动 LangGraph API 服务器：



```shell
npx @langchain/langgraph-cli dev
```


示例输出：

```
>    Ready!
>
>    - API: [http://localhost:2024](http://localhost:2024/)
>
>    - Docs: http://localhost:2024/docs
>
>    - LangGraph Studio Web UI: https://smith.langchain.com/studio/?baseUrl=http://127.0.0.1:2024
```

`langgraph dev` 命令以**内存（in-memory）模式**启动 Agent Server。此模式非常适合开发和测试目的。对于生产环境使用，请部署 Agent Server 并确保它连接到持久化存储后端。有关更多信息，请参阅 [平台设置概述](/langsmith/platform-setup) 页面。

## 6. 在 Studio 中测试您的应用

[Studio](/langsmith/studio) 是一个专门的 UI 界面，您可以将其连接到 LangGraph API 服务器，以便在本地可视化、交互和调试您的应用程序。要通过访问 `langgraph dev` 命令输出中提供的 URL 来在 Studio 中测试您的图（Graph），请定位以下行：

```
>    - LangGraph Studio Web UI: https://smith.langchain.com/studio/?baseUrl=http://127.0.0.1:2024
```

如果您在自定义的主机/端口上运行 Agent Server，则需要更新 URL 中的 `baseUrl` 查询参数。例如，如果您的服务器运行在 `http://myhost:3000`：

```
https://smith.langchain.com/studio/?baseUrl=http://myhost:3000
```

<Accordion title="Safari 兼容性">
    由于 Safari 对连接到本地主机服务器存在限制，请使用 `--tunnel` 标志与您的命令一起使用以创建安全隧道：

    ```shell
    langgraph dev --tunnel
    ```
</Accordion>

## 7. 测试 API



<Tabs>
    <Tab title="Javascript SDK">
    1. 安装 LangGraph JS SDK：
        ```shell
        npm install @langchain/langgraph-sdk
        ```
    2. 向助手发送消息（无线程运行/Threadless run）：
      ```js
      const { Client } = await import("@langchain/langgraph-sdk");

      // 仅在调用 langgraph dev 时更改了默认端口时才设置 apiUrl
      const client = new Client({ apiUrl: "http://localhost:2024"});

      const streamResponse = client.runs.stream(
          null, // 无线程运行 (Threadless run)
          "agent", // 助手 ID
          {
              input: {
                  "messages": [
                      { "role": "user", "content": "What is LangGraph?"}
                  ]
              },
              streamMode: "messages-tuple",
          }
      );

      for await (const chunk of streamResponse) {
          console.log(`Receiving new event of type: ${chunk.event}...`);
          console.log(JSON.stringify(chunk.data));
          console.log("\n\n");
      }
      ```
    </Tab>
    <Tab title="Rest API">
    ```bash
    curl -s --request POST \
        --url "http://localhost:2024/runs/stream" \
        --header 'Content-Type: application/json' \
        --data "{
            \"assistant_id\": \"agent\",
            \"input\": {
                \"messages\": [
                    {
                        \"role\": \"human\",
                        \"content\": \"What is LangGraph?\"
                    }
                ]
            },
            \"stream_mode\": \"messages-tuple\"
        }"
    ```
    </Tab>
</Tabs>
