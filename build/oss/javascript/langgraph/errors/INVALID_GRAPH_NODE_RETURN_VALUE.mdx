---
title: INVALID_GRAPH_NODE_RETURN_VALUE
---



LangGraph 的 [`StateGraph`](https://langchain-ai.github.io/langgraph/reference/graphs/#langgraph.graph.state.StateGraph) 从某个节点接收到了非对象（object）类型的返回值。示例如下：

```typescript
import * as z from "zod";
import { StateGraph } from "@langchain/langgraph";

const State = z.object({
  someKey: z.string(),
});

const badNode = (state: z.infer<typeof State>) => {
  // 应该返回一个包含 "someKey" 值的对象，而不是一个数组
  return ["whoops"];
};

const builder = new StateGraph(State).addNode("badNode", badNode);
// ...

const graph = builder.compile();
```

调用上述图（graph）将导致如下错误：

```typescript
await graph.invoke({ someKey: "someval" });
```

```
InvalidUpdateError: Expected object, got ['whoops']
有关故障排除，请访问: https://langchain-ai.github.io/langgraphjs/troubleshooting/errors/INVALID_GRAPH_NODE_RETURN_VALUE
```

图中的节点**必须**返回一个对象，该对象包含你所定义状态中一个或多个键。


## 故障排除 (Troubleshooting)

以下方法可能有助于解决此错误：



* 如果你的节点中包含复杂的逻辑，请确保所有代码路径都返回一个与你定义的 `State` 结构相匹配的对象。
