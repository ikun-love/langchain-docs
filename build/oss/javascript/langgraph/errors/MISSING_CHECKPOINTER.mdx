---
title: 缺少检查点（MISSING_CHECKPOINTER）
---

您正尝试使用内置的 LangGraph 持久化功能，但没有提供检查点（checkpointer）。



当在 [`StateGraph`](https://reference.langchain.com/javascript/classes/_langchain_langgraph.index.StateGraph.html) 或 @[`entrypoint` 的 `compile()` 方法中缺少 `checkpointer` 时，会发生此情况。



## 故障排除

以下方法可能有助于解决此错误：


-   初始化一个检查点，并将其传递给 [`StateGraph`](https://reference.langchain.com/javascript/classes/_langchain_langgraph.index.StateGraph.html) 或 @[`entrypoint` 的 `compile()` 方法。




```typescript
import { InMemorySaver, StateGraph } from "@langchain/langgraph";
const checkpointer = new InMemorySaver();

// Graph API
import { StateGraph } from "@langchain/langgraph";
const graph = new StateGraph(...).compile({ checkpointer });

// Functional API
import { entrypoint } from "@langchain/langgraph";
const workflow = entrypoint(
    { checkpointer, name: "workflow" },
    async (messages: string[]) => {
        // ...
    }
);
```



-   使用 LangGraph API，这样您就不需要手动实现或配置检查点。API 会为您处理所有的持久化基础架构。
