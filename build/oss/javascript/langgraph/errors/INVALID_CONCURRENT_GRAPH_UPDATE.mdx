---
title: INVALID_CONCURRENT_GRAPH_UPDATE
---

LangGraph 的 [`StateGraph`](https://langchain-ai.github.io/langgraph/reference/graphs/#langgraph.graph.state.StateGraph) 接收到了来自多个节点的并发状态更新，但被更新的状态属性（State property）不支持这种并发写入。

这种情况可能发生在你使用了图中的 [fanout](/oss/javascript/langgraph/graph-api#map-reduce-and-the-send-api) 或其他并行执行逻辑，并且你的图结构定义如下：



```typescript
import { StateGraph, Annotation, START } from "@langchain/langgraph";
import * as z from "zod";  // [!code highlight]

const State = z.object({
  someKey: z.string(),
});

const builder = new StateGraph(State)
  .addNode("node", (state) => {
    return { someKey: "some_string_value" };
  })
  .addNode("otherNode", (state) => {
    return { someKey: "some_string_value" };
  })
  .addEdge(START, "node")
  .addEdge(START, "otherNode");

const graph = builder.compile();
```




如果在上述图结构中，某个节点返回 `{ someKey: "some_string_value" }`，这将覆盖 `someKey` 状态值。
然而，如果在同一步骤中（例如在 fanout 中），多个节点都返回了 `someKey` 的值，图将抛出此错误，因为图无法确定如何合并对内部状态的更新。


要解决此问题，你可以定义一个“归并器”（reducer）函数来组合多个值：



```typescript
import { registry } from "@langchain/langgraph/zod";
import * as z from "zod";

const State = z.object({  // [!code highlight]
  someKey: z.array(z.string()).register(registry, {  // [!code highlight]
    reducer: {  // [!code highlight]
      fn: (existing, update) => existing.concat(update),  // [!code highlight]
    },
    default: () => [] as string[],
  }),
});
```


这将允许你定义逻辑来处理在并行执行的多个节点中返回的相同键。

## 故障排除

以下步骤可能有助解决此错误：

* 如果你的图并行执行节点，请确保你为相关的状态键定义了归并器（reducer）。
