调用链（Traces）是应用程序从输入到输出所经历的一系列步骤。这些单独的步骤由一个“运行”（Run）来表示。您可以使用 [LangSmith](https://smith.langchain.com/) 来可视化这些执行步骤。要使用它，请[为您的应用程序启用追踪](/langsmith/trace-with-langgraph)。启用追踪后，您可以进行以下操作：

* [调试本地运行的应用程序](/langsmith/observability-studio#debug-langsmith-traces)。
* [评估应用程序的性能](/oss/javascript/langchain/evals)。
* [监控应用程序](/langsmith/dashboards)。

## 先决条件

在开始之前，请确保您拥有以下内容：

- **一个 LangSmith 账户**：请在 [smith.langchain.com](https://smith.langchain.com) 注册（免费）或登录。
- **一个 LangSmith API 密钥**：请遵循[创建 API 密钥](/langsmith/create-account-api-key#create-an-api-key)指南。

## 启用追踪

要为您的应用程序启用追踪，请设置以下环境变量：

```python
export LANGSMITH_TRACING=true
export LANGSMITH_API_KEY=<your-api-key>
```

默认情况下，追踪记录将被记录到名为 `default` 的项目中。要配置自定义项目名称，请参阅[记录到指定项目](#log-to-a-project)。

更多信息，请参阅[使用 LangGraph 进行追踪](/langsmith/trace-with-langgraph)。

## 使用匿名化器防止敏感数据记录到追踪中

您可能希望屏蔽敏感数据，以防止其记录到 LangSmith 中。您可以通过配置创建[匿名化器](/langsmith/mask-inputs-outputs#rule-based-masking-of-inputs-and-outputs)并将其应用于您的图（graph）。此示例将从发送到 LangSmith 的追踪中屏蔽任何匹配社会安全号码格式 `XXX-XX-XXXX` 的内容。


```typescript TypeScript
import { StateGraph } from "@langchain/langgraph";
import { LangChainTracer } from "@langchain/core/tracers/tracer_langchain";
import { StateAnnotation } from "./state.js";
import { createAnonymizer } from "langsmith/anonymizer"
import { Client } from "langsmith"


const anonymizer = createAnonymizer([
    // 匹配社会安全号码 (SSN)
    { pattern: /\b\d{3}-?\d{2}-?\d{4}\b/, replace: "<ssn>" }
])

const langsmithClient = new Client({ anonymizer })
const tracer = new LangChainTracer({
  client: langsmithClient,
});

export const graph = new StateGraph(StateAnnotation)
  .compile()
  .withConfig({
    callbacks: [tracer],
});
```
