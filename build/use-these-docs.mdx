## 使用我们的 MCP 服务器

我们的文档内置了一个**模型上下文协议 (MCP) 服务器**，它允许 AI 应用程序实时查询最新的文档。

LangChain 文档 MCP 服务器地址如下：

```txt
https://docs.langchain.com/mcp
```

连接后，您可以询问您的 AI 助手有关 LangChain、LangGraph 和 LangSmith 的问题，它将搜索我们的文档以提供准确、最新的答案。

### 连接 Claude Code

如果您正在使用 Claude Code，请在终端中运行以下命令，将服务器添加到您当前的お项目中：

```bash
claude mcp add --transport http docs-langchain https://docs.langchain.com/mcp
```

<Note>
    **项目（本地）范围**

    上述命令仅将 MCP 服务器添加到您当前的**项目/工作目录**中。要全局添加 MCP 服务器并在所有项目中访问它，请通过在命令中添加 `--scope user` 来添加用户范围：

    ```bash
    claude mcp add --transport http docs-langchain --scope user https://docs.langchain.com/mcp
    ```
</Note>

### 连接 Claude Desktop

1. 打开 Claude Desktop
2. 转到 Settings > Connectors（设置 > 连接器）
3. 添加我们的 MCP 服务器 URL：`https://docs.langchain.com/mcp`

### 连接 Codex CLI

如果您正在使用 OpenAI Codex CLI，请在终端中运行以下命令将服务器全局添加：

```sh
codex mcp add langchain-docs --url https://docs.langchain.com/mcp
```

### 连接 Cursor 或 VS Code

将以下内容添加到您的 MCP 设置配置文件中：

```json
{
  "mcpServers": {
    "docs-langchain": {
      "url": "https://docs.langchain.com/mcp"
    }
  }
}
```

### 连接 Antigravity

将以下内容添加到您的 MCP 设置配置文件中：

```json
{
  "mcpServers": {
    "docs-langchain": {
      "serverUrl": "https://docs.langchain.com/mcp"
    }
  }
}
```
