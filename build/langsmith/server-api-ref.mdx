Agent Server API 参考信息可以在每个 [部署](/langsmith/deployments) 的 `/docs` 端点下找到（例如：`http://localhost:8124/docs`）。

您可以在侧边栏的 **Agent Server API** 部分浏览完整的 API 参考，或查看下面的端点组：

- [Assistants](/langsmith/agent-server-api/assistants) - 图（Graph）的已配置实例
- [Threads](/langsmith/agent-server-api/threads) - 一组运行（run）的累积结果
- [Thread Runs](/langsmith/agent-server-api/thread-runs) - 在特定线程上对图/助手进行的调用
- [Stateless Runs](/langsmith/agent-server-api/stateless-runs) - 不保留状态的调用
- [Crons](/langsmith/agent-server-api/crons-plus-tier) - 定期调度的运行
- [Store](/langsmith/agent-server-api/store) - 用于长期记忆的持久化键值存储
- [A2A](/langsmith/agent-server-api/a2a) - 智能体到智能体协议（Agent-to-Agent Protocol）端点
- [MCP](/langsmith/agent-server-api/mcp) - 模型上下文协议（Model Context Protocol）端点
- [System](/langsmith/agent-server-api/system) - 健康检查和服务器信息

## 身份验证 (Authentication)

对于部署到 LangSmith 的服务，需要进行身份验证。请在每次向 Agent Server 发送请求时，在请求头中附带 `X-Api-Key` 字段。该字段的值应设置为部署 Agent Server 的组织中有效的 LangSmith API 密钥。

`curl` 命令示例：

```shell
curl --request POST \
  --url http://localhost:8124/assistants/search \
  --header 'Content-Type: application/json' \
  --header 'X-Api-Key: LANGSMITH_API_KEY' \
  --data '{
  "metadata": {},
  "limit": 10,
  "offset": 0
}'
```
