LangSmith 的 [Playground（提示词工程概念）](/langsmith/prompt-engineering-concepts#prompt-playground) 允许您控制提示词的各种设置。**提示词设置 (Prompt Settings)** 窗口包含以下内容：

- [模型配置](#model-configurations)
- [工具设置](#tool-settings)
- [提示词格式化](#prompt-formatting)

要访问**提示词设置 (Prompt Settings)**：

1. 在左侧边栏导航到 **Playground**。
1. 在 **Prompts** 标题下，选择模型名称旁边的齿轮 <Icon icon="gear" iconType="solid" /> 图标，这将启动 **提示词设置 (Prompt Settings)** 窗口。

## 模型配置 (Model configurations)

模型配置定义了您的提示词运行所依据的参数。在 LangSmith Playground 中，您可以保存和管理这些配置，这使您可以在不同的提示词和会话中重复使用偏好的设置。有关特定设置的详细信息，请参阅您的模型提供商的文档（例如，[Anthropic](https://platform.claude.com/docs/en/api/messages)，[OpenAI](https://platform.openai.com/docs/api-reference/responses/create)）。

### 创建已保存的配置

1. 在 **Model Configurations** 选项卡中，根据需要调整模型配置——您可以选择一个 [已保存的配置进行编辑](#edit-configurations)。
1. 点击顶部栏中的 **Save As** 按钮。
1. 输入配置的名称和可选描述，然后确认。
1. 保存配置后，您组织 [工作区](/langsmith/administration-overview#workspaces) 中的任何成员都可以访问它。所有已保存的配置都可以在 **Model Configuration** 下拉菜单中找到。
1. 创建了已保存的配置后，您可以将其设置为默认值，这样您创建的任何新提示词都将自动使用此配置。要将配置设置为默认，请点击下拉菜单中模型名称旁边的 **Set as default** <Icon icon="thumbtack" iconType="solid" /> 图标。

### 编辑配置

1. 要重命名或更新已保存配置的描述，请选择配置的名称或描述并进行必要的更改。
1. 根据需要更新当前配置的参数，然后点击顶部的 **Save** 按钮。

### 删除配置

1. 选择要删除的配置。
1. 点击垃圾桶 <Icon icon="trash" iconType="solid" /> 图标将其删除。

### 额外参数 (Extra parameters)

**Extra Parameters** 字段允许您传递 LangSmith 界面未直接支持的额外模型参数。这在以下两种情况下特别有用：

1. 当模型提供商发布了新参数但尚未集成到 LangSmith 界面中时。您可以将这些参数以 JSON 格式指定，以便立即使用。例如：

    ```json
    {
        "reasoning_effort": "medium"
    }
    ```

1. 当在 Playground 中针对与参数相关的错误进行故障排除时，例如：

    ```
    TypeError: AsyncCompletions.create() got an unexpected keyword argument 'max_concurrency'
    ```

    如果您收到有关不必要参数的错误（在使用 [LangChain JS](/oss/python/langchain/overview) 进行运行跟踪时更常见），您可以使用此字段来移除多余的参数。

## 工具设置 (Tool settings)

[_工具_](/langsmith/prompt-engineering-concepts#tools) 使您的 LLM 能够执行搜索网络、查找信息等任务。在 **Tools Settings** 选项卡中，您可以管理 LLM 使用和访问您在提示词中定义工具的方式，包括：

- **Parallel Tool Calls（并行工具调用）**: 适当时并行调用多个工具。这允许模型同时从不同来源收集信息。（取决于模型对并行执行的支持情况。）
- **Tool Choice（工具选择）**: 选择模型可以访问的工具。有关详细信息，请参阅 [在提示词中使用工具](/langsmith/use-tools)。

## 提示词格式化 (Prompt formatting)

**Prompt Format** 选项卡允许您指定：

- **Prompt type（提示词类型）**。有关聊天提示词和完成提示词的详细信息，请参阅 [提示词工程概念](/langsmith/prompt-engineering-concepts#chat-vs-completion)。
- **Template format（模板格式）**。有关提示词模板化和使用变量的详细信息，请参阅 [F-string 与 mustache 比较](/langsmith/prompt-engineering-concepts##f-string-vs-mustache)。
