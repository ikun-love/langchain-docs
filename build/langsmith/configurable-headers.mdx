---
title: 使用 HTTP 标头进行运行时配置
sidebarTitle: 可配置的标头
---
LangGraph 允许运行时配置来动态修改 Agent 的行为和权限。在使用 [LangSmith 部署](/langsmith/deployment-quickstart) 时，您可以通过请求体 (`config`) 或特定的请求标头 (`headers`) 传递此配置。这使得配置能够根据用户身份或其他请求信息进行调整。

为了保护隐私，您可以通过 `langgraph.json` 文件中 `http.configurable_headers` 部分来控制哪些标头会被传递给运行时配置。

以下是自定义包含和排除标头的方法：

```json
{
  "http": {
    "configurable_headers": {
      "includes": ["x-user-id", "x-organization-id", "my-prefix-*"],
      "excludes": ["authorization", "x-api-key"]
    }
  }
}
```

`includes` 和 `excludes` 列表接受精确的标头名称或使用 `*` 作为通配符的模式（匹配任意数量的字符）。出于安全考虑，不支持其他正则表达式模式。

## 在 Graph 中使用

您可以在任何节点的 `config` 参数中使用已包含的标头：

```python
def my_node(state, config):
  organization_id = config["configurable"].get("x-organization-id")
  ...
```

或者通过从上下文中获取（在工具或任何其他嵌套函数中很有用）：

```python
from langgraph.config import get_config

def search_everything(query: str):
  organization_id = get_config()["configurable"].get("x-organization-id")
  ...
```

您甚至可以使用此功能来动态编译 (compile) Graph。

```python
# my_graph.py.
import contextlib

@contextlib.asynccontextmanager
async def generate_agent(config):
  organization_id = config["configurable"].get("x-organization-id")
  if organization_id == "org1":
    graph = ...
    yield graph
  else:
    graph = ...
    yield graph

```

```json
{
  "graphs": {"agent": "my_grph.py:generate_agent"}
}
```

### 选择退出可配置标头

如果您想选择退出（opt-out）可配置标头，只需在 `excludes` 列表中设置一个通配符模式即可：

```json
{
  "http": {
    "configurable_headers": {
      "excludes": ["*"]
    }
  }
}
```

这将排除所有标头，防止它们被添加到您的运行配置中。

请注意，排除的设置优先于包含的设置（即排除具有最高优先级）。
