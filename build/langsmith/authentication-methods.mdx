LangSmith 支持多种认证方法，以实现便捷的注册和登录。

## Cloud（云托管版）

### 邮箱/密码

用户可以使用电子邮件地址和密码注册并登录 LangSmith。

### 社交登录提供商

用户也可以选择使用其 GitHub 或 Google 凭证进行登录。

### SAML SSO

企业客户可以配置 [SAML SSO](/langsmith/user-management) 和 [SCIM](/langsmith/user-management)。

## Self-Hosted（自托管版）

自托管客户可以更精细地控制用户登录 LangSmith 的方式。有关更深入的配置选项介绍，请参阅 [自托管文档](/langsmith/self-hosted) 和 [Helm Chart](https://github.com/langchain-ai/helm/tree/main/charts/langsmith)。

### 通过 OAuth 2.0 和 OIDC 进行 SSO

生产环境的安装应当配置 SSO，以便使用外部身份提供商。这使用户能够通过像 Auth0/Okta 这样的身份平台登录。LangSmith 支持几乎所有符合 OIDC 标准的提供商。在 [SSO 配置指南](/langsmith/self-host-sso) 中了解更多关于配置 SSO 的信息。

### 邮箱/密码（即基本身份验证）

此身份验证方法所需的配置非常少，因为它不需要外部身份提供商。它最适合用于自托管的试用阶段。在 [基本身份验证配置指南](/langsmith/self-host-basic-auth) 中了解更多信息。

### 无（None）

<Warning>
此身份验证模式将在基本身份验证（Basic Auth）发布后移除。
</Warning>

如果没有启用任何身份验证方法，自托管安装将不需要任何登录/注册过程。此配置仅应用于在基础设施层面验证安装是否成功，因为此模式支持的功能集有限，仅支持单个组织和工作区。
