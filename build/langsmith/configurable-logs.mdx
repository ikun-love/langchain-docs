---
title: 在服务器日志中包含 HTTP 标头
sidebarTitle: 记录标头
---

默认情况下，[Agent Server](/langsmith/agent-server) 出于隐私考虑，会从服务器日志中省略 HTTP 标头（Headers）。然而，记录请求 ID（request IDs）和关联 ID（correlation IDs）可以帮助您调试问题，并在分布式系统中追踪请求。您可以通过修改 `[`langgraph.json`](/langsmith/application-structure#configuration-file)` 文件中的 `logging_headers` 部分，选择为所有 API 调用记录标头。

```json
{
  "$schema": "https://langgra.ph/schema.json",
  "http": {
    "logging_headers": {
      "includes": ["request-id", "x-purchase-id", "*-trace-*"],
      "excludes": ["authorization", "x-api-key", "x-organization-id", "x-user-id"]
    }
  }
}
```

`includes` 和 `excludes` 列表接受精确的标头名称，或者使用 `*` 作为通配符的 glob 模式（匹配任意数量的字符，不区分大小写）。为了您的安全起见，不支持其他任何模式类型。

请注意，排除项的优先级高于包含项。例如，如果您包含了 `*-id`，但同时排除了 `x-user-id`，那么 `x-user-id` 标头将不会被记录。
