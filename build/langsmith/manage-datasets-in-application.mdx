[_数据集_](/langsmith/evaluation-concepts#datasets) 使您能够随着时间的推移，使用一致的数据执行可重复的评估。数据集由 [_示例_](/langsmith/evaluation-concepts#examples) 组成，示例存储输入、输出，以及可选的参考输出。

本页面概述了在 [LangSmith UI](https://smith.langchain.com) 中[创建](#create-a-dataset-and-add-examples)和[管理](#manage-a-dataset)数据集的各种方法。

## 创建数据集并添加示例

以下部分解释了您可以在 LangSmith 中创建数据集并向其中添加示例的不同方式。根据您的工作流程，您可以手动整理示例、从跟踪（tracing）中自动捕获示例、导入文件，甚至生成合成数据：

- [从跟踪项目中手动创建](#manually-from-a-tracing-project)
- [从跟踪项目中自动创建](#automatically-from-a-tracing-project)
- [从标注队列中的示例创建](#from-examples-in-an-annotation-queue)
- [从 Prompt Playground 创建](#from-the-prompt-playground)
- [从 CSV 或 JSONL 文件导入数据集](#import-a-dataset-from-a-csv-or-jsonl-file)
- [从数据集页面创建新数据集](#create-a-new-dataset-from-the-dataset-page)
- [通过 Datasets UI 添加 LLM 创建的合成示例](#add-synthetic-examples-created-by-an-llm-via-the-datasets-ui)

### 从跟踪项目中手动创建

构造数据集的一种常见模式是将应用程序中值得注意的跟踪（traces）转换为数据集示例。此方法要求您已[将跟踪配置到 LangSmith](/langsmith/observability-concepts#tracing-configuration)。

<Check>
构建数据集的一种技巧是过滤掉最有趣的跟踪，例如标记了较差用户反馈的跟踪，并将它们添加到数据集中。有关如何过滤跟踪的提示，请参阅[过滤跟踪](/langsmith/filter-traces-in-application)指南。
</Check>

有两种方法可以从跟踪项目中手动将数据添加到数据集中。导航到 **Tracing Projects** 并选择一个项目。

1.  多选运行（runs）。在 **Runs** 选项卡中，多选运行。在页面底部，单击 <Icon icon="database" /> **Add to Dataset**。

    ![The Runs table with a run selected and the Add to Dataset button visible at the bottom of the page.](/langsmith/images/multiselect-add-to-dataset.png)

2.  在 **Runs** 选项卡中，从表中选择一个运行。在单个运行详情页面上，在右上角选择 **Add to** -> **Dataset**。

    ![Add to dataset](/langsmith/images/add-to..dataset.png)

    当您从运行详情页面中选择一个数据集时，会弹出一个模态框，告知您是否有任何[转换](/langsmith/dataset-transformations)被应用或模式验证是否失败。例如，下面的屏幕截图显示了一个正在使用转换来优化收集 LLM 运行的数据集。

    ![Confirmation](/langsmith/images/confirmation.png)

    然后，您可以选择在将其添加到数据集之前编辑该运行。

### 从跟踪项目中自动创建

您可以使用[运行规则](/langsmith/rules)根据某些条件自动将跟踪添加到数据集中。例如，您可以添加所有[标记](/langsmith/observability-concepts#tags)有特定用例或具有[低反馈分数](/langsmith/observability-concepts#feedback)的跟踪。

### 从标注队列中的示例创建

<Check>
如果您依赖主题专家来构建有意义的数据集，请使用[标注队列](/langsmith/annotation-queues)为审阅者提供简化的视图。人工审阅者可以选择在将运行添加到数据集之前修改来自跟踪的输入/输出/参考输出。
</Check>

标注队列可以可选地配置默认数据集，尽管您可以通过使用屏幕底部的​​数据集切换器将运行添加到任何数据集。选择正确的数据集后，单击 **Add to Dataset** 或按下热键 `D` 将运行添加到其中。

您在标注队列中对运行所做的任何修改都将转移到数据集中，并且运行关联的所有元数据也将被复制。

![Add to dataset from annotation queue](/langsmith/images/add-to-dataset-from-aq.png)

请注意，您还可以设置规则，使用[自动化规则](/langsmith/rules)将满足特定标准的运行添加到标注队列中。

### 从 Prompt Playground 创建

在 [**Prompt Playground**](/langsmith/observability-concepts#prompt-playground) 页面上，选择 **Set up Evaluation**，如果您要开始一个新的数据集，请单击 **+New**，或者从现有数据集中选择。

<Note>
Playground 中内联创建数据集不支持嵌套键的数据集。为了添加/编辑具有嵌套键的示例，您必须[从数据集页面进行编辑](/langsmith/manage-datasets-in-application#from-the-datasets-page)。
</Note>

要编辑示例：

*   使用 **+Row** 向数据集中添加一个新示例
*   使用表右侧的 **⋮** 下拉菜单删除一个示例
*   如果您正在创建一个不带参考的数据集，请使用列中的 **x** 按钮移除“Reference Output”列。注意：此操作不可逆。

![Create a dataset in the playground](/langsmith/images/playground-dataset.png)

### 从 CSV 或 JSONL 文件导入数据集

在 **Datasets & Experiments** 页面上，单击 **+New Dataset**，然后从 CSV 或 JSONL 文件 **Import**（导入）现有数据集。

### 从 Datasets & Experiments 页面创建新数据集

1.  从左侧菜单导航到 **Datasets & Experiments** 页面。
1.  单击 **+ New Dataset**。
1.  在 **New Dataset** 页面上，选择 **Create from scratch** 选项卡。
1.  为数据集添加名称和描述。
1.  （可选）创建一个[数据集模式（schema）](#create-a-dataset-schema)来验证您的数据集。
1.  单击 **Create**，这将创建一个空数据集。
1.  要在数据集中内联添加示例，请转到数据集的 **Examples** 选项卡。单击 **+ Example**。
1.  以 JSON 格式定义示例并单击 **Submit**。有关数据集分割（splits）的更多详细信息，请参阅[创建和管理数据集分割](#create-and-manage-dataset-splits)。

### 添加 LLM 创建的合成示例

如果您有现有示例并且数据集上定义了[模式（schema）](#create-a-dataset-schema)，当您单击 **+ Example** 时，有一个选项可以 <Icon icon="sparkles"/> **Add AI-Generated Examples**（添加 AI 生成的示例）。这将使用 LLM 创建[合成](/langsmith/evaluation-concepts#synthetic-data)示例。

在 **Generate examples**（生成示例）中，执行以下操作：

1.  单击窗格右上角的 **API Key**，将您的 OpenAI API 密钥设置为[工作区密钥](/langsmith/administration-overview#workspaces)。如果您的工作区已经设置了 OpenAI API 密钥，则可以跳过此步骤。
1.  选择 <Tooltip tip="A few sample input–output pairs that guide the model on how to perform a task.">few-shot examples</Tooltip>（少样本示例）：切换 **Automatic**（自动）或 **Manual**（手动）参考示例。您可以手动从数据集中选择这些示例，或者使用自动选择选项。
1.  输入您想要生成的合成示例的数量。
1.  单击 **Generate**。

## 管理数据集

### 创建数据集模式（Schema）

LangSmith 数据集存储任意 JSON 对象。我们建议（但不强制要求）您为数据集定义一个模式，以确保它们符合特定的 JSON 结构。数据集模式使用标准的 [JSON schema](https://json-schema.org/) 定义，并增加了一些[预构建类型](/langsmith/dataset-json-types)，使为常见原始类型（如消息和工具）添加类型化更简单。

您的模式中的某些字段具有 `+ Transformations`（+ 转换）选项。转换是预处理步骤，如果启用，则在将示例添加到数据集时更新它们。例如，`convert to OpenAI messages`（转换为 OpenAI 消息）转换会将类似消息的对象（如 LangChain 消息）转换为 OpenAI 消息格式。

有关可用转换的完整列表，请参阅[我们的参考](/langsmith/dataset-transformations)。

<Note>
如果您打算从 LangChain [ChatModels](https://python.langchain.com/do/langsmith/observability-concepts/chat_models/) 或使用 [LangSmith OpenAI wrapper](/langsmith/annotate-code#wrap-the-openai-client) 的 OpenAI 调用中收集生产跟踪到您的数据集中，我们提供了一个预构建的 Chat Model 模式，它将消息和工具转换为行业标准的 OpenAI 格式，可供下游的任何模型用于测试。您还可以自定义模板设置以匹配您的用例。

有关更多信息，请参阅[数据集转换参考](/langsmith/dataset-transformations)。
</Note>

### 创建和管理数据集分割（Splits）

数据集分割是数据集的划分，可用于分段您的数据。例如，在机器学习工作流程中，通常将数据集分成训练集、验证集和测试集。这有助于防止**过拟合**——即模型在训练数据上表现良好，但在未见过的数据上表现不佳。在评估工作流程中，当您有一个包含多个类别的具有多个类别的数据集，并且可能希望单独评估它们时，这会很有用；或者如果您正在测试一个新的用例，您可能希望将来包含在您的数据集中，但目前希望将其分开。请注意，可以通过元数据手动实现相同的效果——但我们期望分割被用于对数据集进行**更高级别的组织**，将其分成单独的组进行评估，而元数据将更多地用于存储有关您的示例的信息，例如标签和有关其来源的信息。

在机器学习中，最佳实践是保持分割独立（每个示例仅属于一个分割）。但是，我们允许您为同一示例选择多个分割，因为这可能对某些评估工作流程有意义——例如，如果一个示例落入您可能希望单独评估应用程序的多个类别中。

为了在应用程序中创建和管理分割，您可以选择数据集中的一些示例并单击 "Add to Split"（添加到分割）。在弹出的菜单中，您可以为选定的示例选择和取消选择分割，或者创建一个新分割。

![Add to Split](/langsmith/images/add-to-split2.png)

### 编辑示例元数据

您可以单击示例，然后在弹出窗口的右上方单击 "Edit"（编辑）来向示例添加元数据。在此页面上，您可以更新/删除现有元数据，或添加新元数据。您可以利用此功能来存储有关示例的信息，例如标签或版本信息，然后您可以在分析实验结果时[按其分组](/langsmith/analyze-an-experiment#group-results-by-metadata)，或在您调用 SDK 中的 `list_examples` 时[按其过滤](/langsmith/manage-datasets-programmatically#list-examples-by-metadata)。

![Add Metadata](/langsmith/images/add-metadata.gif)

### 过滤示例

您可以按分割、元数据键/值过滤示例，或对示例执行全文搜索。这些过滤选项位于示例表的左上方。

*   **按分割过滤**：选择 Split > 选择一个要过滤的分割
*   **按元数据过滤**：选择 Filters > 从下拉菜单中选择 "Metadata" > 选择要过滤的元数据键和值
*   **全文搜索**：选择 Filters > 从下拉菜单中选择 "Full Text" > 输入您的搜索条件

您可以添加多个过滤器，只有满足所有过滤条件的示例才会显示在表中。

![Filters Applied to Examples](/langsmith/images/filters-applied.png)
