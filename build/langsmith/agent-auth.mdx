## 安装

从 PyPI 安装 Agent Auth 客户端库：

<CodeGroup>
```bash pip
pip install langchain-auth
```

```bash uv
uv add langchain-auth
```
</CodeGroup>


## 快速开始 (Quickstart)

### 1. 初始化客户端

```python
from langchain_auth import Client

client = Client(api_key="your-langsmith-api-key")
```

### 2. 设置 OAuth 提供商

在代理能够进行身份验证之前，您需要使用以下流程配置一个 OAuth 提供商：

1. 在 LangChain 平台上使用的 OAuth 提供商处，选择一个唯一的标识符（例如："github-local-dev"、"google-workspace-prod"）。

2. 前往您的 OAuth 提供商的开发者控制台，创建一个新的 OAuth 应用程序。

3. 使用以下结构，将 LangChain 的 API 设置为可用的回调 URL：
   ```
   https://api.host.langchain.com/v2/auth/callback/{provider_id}
   ```
   例如，如果您的 `provider_id` 是 "github-local-dev"，则使用：
   ```
   https://api.host.langchain.com/v2/auth/callback/github-local-dev
   ```

4. 使用您的 OAuth 应用中获取的凭据调用 `client.create_oauth_provider()`：

```python
new_provider = await client.create_oauth_provider(
    provider_id="{provider_id}", # 提供任何唯一的 ID。它不与提供商正式绑定。
    name="{provider_display_name}", # 提供任何显示的名称
    client_id="{your_client_id}",
    client_secret="{your_client_secret}",
    auth_url="{auth_url_of_your_provider}",
    token_url="{token_url_of_your_provider}",
)
```

### 3. 从代理进行身份验证

客户端的 `authenticate()` API 用于从预配置的提供商处获取 OAuth 令牌。在第一次调用时，它会引导调用者完成 OAuth 2.0 授权流程。

#### 在 LangGraph 上下文中

默认情况下，令牌的作用域受调用代理的 Assistant ID 参数限制。

```python
auth_result = await client.authenticate(
    provider="{provider_id}",
    scopes=["scopeA"],
    user_id="your_user_id" # 任何唯一的标识符，用于将此令牌限定于人类调用者
)

# 或者，如果您想要一个可供任何代理使用的令牌，请设置 agent_scoped=False
auth_result = await client.authenticate(
    provider="{provider_id}",
    scopes=["scopeA"],
    user_id="your_user_id",
    agent_scoped=False
)
```

在执行过程中，如果需要身份验证，SDK 将抛出一个 [interrupt (中断)](https://langchain-ai.github.io/langgraph/how-tos/human_in_the_loop/add-human-in-the-loop/#pause-using-interrupt) 信号。代理执行会暂停，并向用户展示 OAuth URL：

![Studio interrupt showing OAuth URL](/images/langgraph-auth-interrupt.png)

用户完成 OAuth 身份验证并收到来自提供商的回调后，他们将看到授权成功的页面。

![GitHub OAuth success page](/images/github-auth-success.png)

然后，代理从中断的位置恢复执行，并且获取到的令牌可用于任何 API 调用。我们存储并刷新 OAuth 令牌，以便用户或代理未来再次使用服务时，无需重新执行 OAuth 流程。

```python
token = auth_result.token
```

#### 在 LangGraph 环境之外

对于带外（Out-of-band）OAuth 流程，请向用户提供 `auth_url`。

```python
# 默认：用户范围的令牌（可供该用户下的任何代理使用）
auth_result = await client.authenticate(
    provider="{provider_id}",
    scopes=["scopeA"],
    user_id="your_user_id"
)

if auth_result.needs_auth:
    print(f"请在以下地址完成 OAuth: {auth_result.auth_url}")
    # 等待完成
    completed_auth = await client.wait_for_completion(auth_result.auth_id)
    token = completed_auth.token
else:
    token = auth_result.token
```
