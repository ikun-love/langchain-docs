```markdown
---
title: 在本地运行 LangGraph 应用
sidebarTitle: 本地测试
---

本快速入门指南将向您展示如何设置一个本地 LangGraph 应用程序，以便进行测试和开发。

## 前提条件

在开始之前，请确保您拥有 [LangSmith](https://smith.langchain.com/settings) 的 API 密钥（注册是免费的）。

## 1. 安装 LangGraph CLI

<Tabs>
    <Tab title="Python 服务器">
    ```shell
    # 需要 Python >= 3.11。

    pip install -U "langgraph-cli[inmem]"
    ```
    </Tab>
    <Tab title="Node 服务器">
    ```shell
    npx @langchain/langgraph-cli
    ```
    </Tab>
</Tabs>

## 2. 创建一个 LangGraph 应用

可以从 [`new-langgraph-project-python` 模板](https://github.com/langchain-ai/new-langgraph-project) 或 [`new-langgraph-project-js` 模板](https://github.com/langchain-ai/new-langgraphjs-project) 创建一个新的应用。此模板演示了一个单节点应用程序，您可以基于此扩展您自己的逻辑。

<Tabs>
    <Tab title="Python 服务器">
    ```shell
    langgraph new path/to/your/app --template new-langgraph-project-python
    ```
    </Tab>
    <Tab title="Node 服务器">
    ```shell
    langgraph new path/to/your/app --template new-langgraph-project-js
    ```
    </Tab>
</Tabs>

<Tip>
**其他模板**<br></br>
如果您在运行 [`langgraph new`](/langsmith/cli) 时没有指定模板，系统将为您提供一个交互式菜单，允许您从可用模板列表中进行选择。
</Tip>

## 3. 安装依赖项

在新的 LangGraph 应用的根目录下，使用 `edit` 模式安装依赖项，这样服务器就能使用您的本地更改：

<Tabs>
    <Tab title="Python 服务器">
    ```shell
    cd path/to/your/app
    pip install -e .
    ```
    </Tab>
    <Tab title="Node 服务器">
    ```shell
    cd path/to/your/app
    yarn install
    ```
    </Tab>
</Tabs>

## 4. 创建一个 `.env` 文件

您将在新的 LangGraph 应用的根目录下找到一个 [`.env.example`](/langsmith/application-structure#configuration-file) 文件。请在该应用的根目录中创建一个 `.env` 文件，并将 `.env.example` 文件中的内容复制到其中，然后填入必要的 API 密钥：

```bash
LANGSMITH_API_KEY=lsv2...
```

## 5. 启动 Agent Server

在本地启动 Agent Server：

<Tabs>
    <Tab title="Python 服务器">
    ```shell
    langgraph dev
    ```
    </Tab>
    <Tab title="Node 服务器">
    ```shell
    npx @langchain/langgraph-cli dev
    ```
    </Tab>
</Tabs>

示例输出：

```
>    Ready!
>
>    - API: [http://localhost:2024](http://localhost:2024/)
>
>    - Docs: http://localhost:2024/docs
>
>    - Studio Web UI: https://smith.langchain.com/studio/?baseUrl=http://127.0.0.1:2024
```

[`langgraph dev`](/langsmith/cli) 命令以内存中的模式（in-memory mode）启动 Agent Server。这种模式非常适合开发和测试用途。

<Tip>
对于生产环境，建议使用具有持久化存储后端的 Agent Server 进行部署。有关更多信息，请参阅 LangSmith 的 [平台选项](/langsmith/platform-setup) 文档。
</Tip>

## 6. 测试 API

<Tabs>
    <Tab title="Python SDK (异步)">
    1. 安装 LangGraph Python SDK：
      ```shell
      pip install langgraph-sdk
      ```
    2. 向助手发送消息（无线程运行/threadless run）：
      ```python
      from langgraph_sdk import get_client
      import asyncio

      client = get_client(url="http://localhost:2024")

      async def main():
          async for chunk in client.runs.stream(
              None,  # 无线程运行
              "agent", # 助手的名称。在 langgraph.json 中定义。
              input={
              "messages": [{
                  "role": "human",
                  "content": "What is LangGraph?",
                  }],
              },
          ):
              print(f"正在接收事件类型: {chunk.event}...")
              print(chunk.data)
              print("\n\n")

      asyncio.run(main())
      ```
    </Tab>
    <Tab title="Python SDK (同步)">
    1. 安装 LangGraph Python SDK：
      ```shell
      pip install langgraph-sdk
      ```
    2. 向助手发送消息（无线程运行/threadless run）：
      ```python
      from langgraph_sdk import get_sync_client

      client = get_sync_client(url="http://localhost:2024")

      for chunk in client.runs.stream(
          None,  # 无线程运行
          "agent", # 助手的名称。在 langgraph.json 中定义。
          input={
              "messages": [{
                  "role": "human",
                  "content": "What is LangGraph?",
              }],
          },
          stream_mode="messages-tuple",
      ):
          print(f"正在接收事件类型: {chunk.event}...")
          print(chunk.data)
          print("\n\n")
      ```
    </Tab>
    <Tab title="Javascript SDK">
    1. 安装 LangGraph JS SDK：
      ```shell
      npm install @langchain/langgraph-sdk
      ```
    2. 向助手发送消息（无线程运行/threadless run）：
      ```js
      const { Client } = await import("@langchain/langgraph-sdk");

      // 如果在调用 langgraph dev 时更改了默认端口，请设置 apiUrl
      const client = new Client({ apiUrl: "http://localhost:2024"});

      const streamResponse = client.runs.stream(
          null, // 无线程运行
          "agent", // 助手 ID
          {
              input: {
                  "messages": [
                      { "role": "user", "content": "What is LangGraph?"}
                  ]
              },
              streamMode: "messages-tuple",
          }
      );

      for await (const chunk of streamResponse) {
          console.log(`Receiving new event of type: ${chunk.event}...`);
          console.log(JSON.stringify(chunk.data));
          console.log("\n\n");
      }
      ```
    </Tab>
    <Tab title="Rest API">
    ```bash
    curl -s --request POST \
        --url "http://localhost:2024/runs/stream" \
        --header 'Content-Type: application/json' \
        --data "{
            \"assistant_id\": \"agent\",
            \"input\": {
                \"messages\": [
                    {
                        \"role\": \"human\",
                        \"content\": \"What is LangGraph?\"
                    }
                ]
            },
            \"stream_mode\": \"messages-tuple\"
        }"
    ```
    </Tab>
</Tabs>

## 后续步骤

现在您已经本地运行了一个 LangGraph 应用，接下来就可以准备部署它了：

**为 LangSmith 选择一个托管选项：**
- [**云端 (Cloud)**](/langsmith/cloud)：最快的设置，完全托管（推荐）。
- [**混合 (Hybrid)**](/langsmith/hybrid)：<Tooltip tip="Agent Servers 和代理的运行时执行环境。">数据平面</Tooltip> 位于您的云中，而 <Tooltip tip="用于管理部署的 LangSmith UI 和 API。">控制平面</Tooltip> 由 LangChain 管理。
- [**自托管 (Self-hosted)**](/langsmith/self-hosted)：在您自己的基础设施中完全控制。

有关更多详细信息，请参阅 [平台设置对比](/langsmith/platform-setup) 文档。

**然后部署您的应用：**
- [云端快速入门](/langsmith/deployment-quickstart)：快速设置指南。
- [完整的云端设置指南](/langsmith/deploy-to-cloud)：全面的部署文档。

**探索功能：**
- **[Studio](/langsmith/studio)**：使用 Studio UI 可视化、交互和调试您的应用程序。尝试 [Studio 快速入门](/langsmith/quick-start-studio)。
- **API 参考**：[LangSmith 部署 API](https://langchain-ai.github.io/langgraph/cloud/reference/api/api_ref/)、[Python SDK](/langsmith/langgraph-python-sdk)、[JS/TS SDK](/langsmith/langgraph-js-ts-sdk)
```
