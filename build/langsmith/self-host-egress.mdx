<Info>
此部分仅适用于未在离线模式下运行的客户，并假设您使用的是服务于 **0.9.0** 或更高版本的自托管 LangSmith 实例。早期版本的 LangSmith 不具备此功能。
</Info>

自托管 LangSmith 实例会将所有信息本地存储，并且永远不会将敏感信息发送到您的网络之外。根据您的订单中的授权，我们目前仅出于计费目的跟踪平台使用情况。为了更好地远程支持我们的客户，我们确实需要向 `https://beacon.langchain.com` 开放出口访问权限。

将来，我们将引入支持诊断功能，以帮助我们确保 LangSmith 在您的环境中以最佳状态运行。

<Warning>
**这要求您的网络必须能够访问 `https://beacon.langchain.com`。如果需要静态 IP 地址，请参阅 [允许列表 IP 部分](/langsmith/cloud#allowlisting-ip-addresses)。**
</Warning>

通常，我们发送到 Beacon 的数据可按如下方式分类：

* 订阅指标 (Subscription Metrics)

  * 订阅指标用于确定 LangSmith 的访问级别和利用率。这包括但不限于：

    * 跟踪 (traces) 的数量
    * 根据合同分配的席位数 (Seats)
    * 当前正在使用的席位数

* 操作元数据 (Operational Metadata)
  * 此元数据将包含并收集上述订阅指标，以协助远程支持，使 LangChain 团队能够更有效、更主动地诊断和解决性能问题。

## LangSmith 遥测 (Telemetry)

从 ***0.11*** 版本开始，LangSmith 部署将默认向我们的后端发送遥测数据。所有遥测数据都与组织和部署相关联，但绝不会与单个用户标识。我们***不会***以任何形式收集 PII（个人身份信息）。

### 我们用它来做什么

* 为自托管实例提供更主动的支持和更快的故障排除。
* 协助进行性能调优。
* 了解真实世界的使用情况，以便优先改进。

### 我们收集什么

* **请求元数据**: 匿名化的请求计数、大小和持续时间。
* **数据库指标**: 查询持续时间、错误率和性能计数器。
* **操作性 LangSmith 跟踪**: 包含延迟和错误信息的跟踪记录，用于处理高延迟或失败的请求。这些**不是**客户的跟踪记录，而是关于 LangSmith 实例运行情况的操作性跟踪记录。

<Info>
我们不收集实际的负载内容 (payload contents)、数据库记录或任何可以识别您的最终用户或客户的数据。
</Info>

### 如何禁用

在您的 `langsmith_config.yaml` 文件中设置以下值：

```yaml
config:
  telemetry:
    metrics: false
    traces: false
```

## 示例负载 (Example payloads)

为了最大限度地保持透明度，我们在 [下面] 提供示例负载：

### 许可证验证 (License Verification)

**端点 (Endpoint):**

`POST beacon.langchain.com/v1/beacon/verify`

**请求 (Request):**

```json
{
  "license": "<YOUR_LICENSE_KEY>"
}
```

**响应 (Response):**

```json
{
  "token": "Valid JWT" // 用于避免重复许可证检查的短期 JWT 令牌
}
```

### 用量报告 (Usage Reporting)

**端点 (Endpoint):**

`POST beacon.langchain.com/v1/beacon/ingest-traces`

**请求 (Request):**

```json

    {
      "id": "af28dfea-5358-463d-a2dc-37df1da72498",
```

## 我们的承诺 (Our Commitment)

LangChain 不会在订阅指标或操作元数据中存储任何敏感信息。收集到的任何数据都不会与第三方共享。如果您对发送的数据有任何疑虑，请联系您的客户团队。
