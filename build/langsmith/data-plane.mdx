**数据平面**（_data plane_）由您的 [Agent Servers](/langsmith/agent-server)（部署实例）、其支持的基础设施，以及一个持续轮询 [LangSmith 控制平面](/langsmith/control-plane)以获取更新的“监听器”应用程序组成。

## 服务器基础设施

除了 [Agent Server](/langsmith/agent-server) 本身之外，广义的“数据平面”定义还包括每个服务器的以下基础设施组件：

- **PostgreSQL**: 用户数据、运行数据和内存数据的持久化层。
- **Redis**: 用于工作进程（workers）的通信和易失性元数据。
- **Secrets store**: 用于安全管理环境变量机密信息。
- **Autoscalers**: 根据负载自动伸缩服务器容器。

## “监听器”应用程序

数据平面的“监听器”应用程序会定期调用 [控制平面 API](/langsmith/control-plane#control-plane-api) 来执行以下操作：

* 确定是否应创建新的部署。
* 确定是否应更新现有部署（即新的修订版本）。
* 确定是否应删除现有部署。

换句话说，数据平面的“监听器”会读取控制平面的最新状态（期望状态），并采取行动来协调待处理的部署（当前状态），使其与最新状态保持一致。

## PostgreSQL

PostgreSQL 是 Agent Server 中所有用户数据、运行数据和长期内存数据的持久化层。它存储检查点（有关更多信息请参阅 [此处](/oss/python/langgraph/persistence)）、服务器资源（线程、运行、助手和定时任务 [crons]），以及存储在长期内存存储中的项（有关更多信息请参阅 [此处](/oss/python/langgraph/persistence#memory-store)）。

## Redis

每个 Agent Server 内部都使用 Redis 作为服务器和队列工作进程进行通信的方式，并用于存储易失性元数据。Redis 中不存储任何用户数据或运行数据。

### 通信

Agent Server 中的所有运行都是由每个部署中的后台工作进程池执行的。为了启用某些功能（如取消操作和输出流式传输），我们需要在服务器和处理特定运行的工作进程之间建立一个双向通信通道。我们使用 Redis 来组织这种通信。

1. Redis 的一个 List 数据结构被用作一种机制，在新运行创建后立即唤醒工作进程。只有一条哨兵（sentinel）值存储在此列表中，不存储实际的运行信息。运行信息随后由工作进程从 PostgreSQL 中检索。
2. Redis 的 String 类型和 Redis PubSub 通道组合用于服务器向适当的工作进程传达运行取消请求。
3. 工作进程使用 Redis PubSub 通道来广播一个 Agent 在处理运行期间的流式输出。服务器中任何开放的 `/stream` 请求都会订阅该通道，并在事件到达时将其转发到响应中。任何事件在任何时候都不会存储在 Redis 中。

### 易失性元数据

Agent Server 中的运行可能会因特定故障而重试（目前仅针对运行过程中遇到的瞬态 PostgreSQL 错误）。为了限制重试次数（目前每运行限制为 3 次尝试），当工作进程拾取一个运行任务时，我们会将其尝试次数记录在一个 Redis 字符串中。除了运行 ID 之外，这个字符串不包含任何特定于运行的信息，并且会在短时间延迟后过期。

## 数据平面特性

本节介绍数据平面的各种特性。

### 数据区域

<Info>
**仅限云端**
数据区域仅适用于 [Cloud](/langsmith/cloud) 部署。
</Info>

部署可以在 2 个数据区域中创建：美国 (US) 和 欧盟 (EU)。

部署的数据区域由创建该部署的 LangSmith 组织的数据区域决定。部署及其底层数据库不能在数据区域之间迁移。

### 自动伸缩

[`Production` 类型](/langsmith/control-plane#deployment-types) 的部署会自动扩展到最多 10 个容器。扩展是基于 3 个指标进行的：

1. CPU 利用率
2. 内存利用率
3. 待处理（进行中）[运行](/langsmith/assistants#execution) 的数量

对于 CPU 利用率，自动伸缩器以 75% 的利用率为目标。这意味着自动伸缩器会增加或减少容器数量，以确保 CPU 利用率达到或接近 75%。对于内存利用率，自动伸缩器也以 75% 的利用率为目标。

对于待处理运行数量，自动伸缩器以 10 个待处理运行为目标。例如，如果当前容器数量为 1，但待处理运行数为 20，自动伸缩器会将部署扩展到 2 个容器（20 个待处理运行 / 2 个容器 = 每个容器 10 个待处理运行）。

每个指标都会独立计算，自动伸缩器将根据导致最大容器数量的指标来决定伸缩操作。

缩减操作会延迟 30 分钟才会执行任何操作。换句话说，如果自动伸缩器决定缩减部署规模，它会先等待 30 分钟再进行缩减。30 分钟后，指标会重新计算，如果重新计算的指标导致容器数量低于当前数量，部署将会缩减。否则，部署将保持扩展状态。此“冷却期”可确保部署不会过于频繁地进行扩展和缩减。

### 有效载荷大小 (Payload size)
<Info>
**仅限云端**
有效载荷大小限制仅适用于 [Cloud](/langsmith/cloud) 部署。
</Info>
所有发送到 [Cloud](/langsmith/cloud) 部署的请求的最大有效载荷大小为 25 MB。尝试发送有效载荷大于 25 MB 的请求将导致 `413 Payload Too Large` 错误。

### 自定义 PostgreSQL

<Info>
自定义 PostgreSQL 实例仅适用于 [Hybrid](/langsmith/hybrid) 和 [Self-Hosted](/langsmith/self-hosted) 部署。
</Info>

可以使用自定义 PostgreSQL 实例代替 [控制平面自动创建的实例](/langsmith/control-plane#database-provisioning)。指定环境变量 [`POSTGRES_URI_CUSTOM`](/langsmith/env-var#postgres-uri-custom) 即可使用自定义 PostgreSQL 实例。

多个部署可以共享同一个 PostgreSQL 实例。例如，对于 `Deployment A`，`POSTGRES_URI_CUSTOM` 可以设置为 `postgres://<user>:<password>@/<database_name_1>?host=<hostname_1>`，而对于 `Deployment B`，`POSTGRES_URI_CUSTOM` 可以设置为 `postgres://<user>:<password>@/<database_name_2>?host=<hostname_1>`。`<database_name_1>` 和 `<database_name_2>` 是同一实例内的不同数据库，但 `<hostname_1>` 是共享的。**不能将同一个数据库用于单独的部署**。

### 自定义 Redis

<Info>
自定义 Redis 实例仅适用于 [Hybrid](/langsmith/hybrid) 和 [Self-Hosted](/langsmith/self-hosted) 部署。
</Info>

可以使用自定义 Redis 实例代替控制平面自动创建的实例。指定环境变量 [REDIS_URI_CUSTOM](/langsmith/env-var#redis-uri-custom) 即可使用自定义 Redis 实例。

多个部署可以共享同一个 Redis 实例。例如，对于 `Deployment A`，`REDIS_URI_CUSTOM` 可以设置为 `redis://<hostname_1>:<port>/1`，而对于 `Deployment B`，`REDIS_URI_CUSTOM` 可以设置为 `redis://<hostname_1>:<port>/2`。`1` 和 `2` 是同一实例内的不同数据库编号，但 `<hostname_1>` 是共享的。**不能将同一个数据库编号用于单独的部署**。

|--------------|------------------------|----------------------|
| 必需<br />追踪到 LangSmith SaaS。 | 可选<br />禁用追踪或追踪到 LangSmith SaaS。 | 可选<br />禁用追踪、追踪到 LangSmith SaaS，或追踪到自托管 LangSmith。 |

### 遥测数据 (Telemetry)

Agent Server 已自动配置为报告用于计费目的的遥测元数据。请参阅下表，了解每种部署选项的详细信息。

| 云端 (Cloud) | 混合 (Hybrid) | 自托管 (Self-Hosted) |
|--------------|------------------------|----------------------|
| 遥测数据发送到 LangSmith SaaS。 | 遥测数据发送到 LangSmith SaaS。 | 报告自用情况（审计），用于气隙（air-gapped）许可证密钥。<br />遥测数据发送到 LangSmith SaaS，用于 LangSmith 许可证密钥。 |

### 许可证 (Licensing)

|--------------|------------------------|----------------------|
