在运行 [评估](/langsmith/evaluation-concepts) 时，您可能希望在脚本中以编程方式处理结果，而不是在 [LangSmith UI](https://smith.langchain.com) 中查看它们。这对于以下场景非常有用：

- **CI/CD 管道**：实施质量门，如果评估分数低于某个阈值，则使构建失败。
- **本地调试**：检查和分析结果，而无需进行 API 调用。
- **自定义聚合**：使用您自己的逻辑计算指标和统计数据。
- **集成测试**：使用评估结果来控制合并或部署的流程。

本指南将向您展示如何根据 [`Client.evaluate()`](https://reference.langchain.com/python/langsmith/observability/sdk/client/#langsmith.client.Client.evaluate) 返回的 [`ExperimentResults`](https://reference.langchain.com/python/langsmith/observability/sdk/evaluation/#langsmith.evaluation._runner.ExperimentResults) 对象进行迭代和处理 [实验](/langsmith/evaluation-concepts#experiment) 结果。

<Note>
此页面重点介绍在**仍将结果上传到 LangSmith 的同时**以编程方式处理结果。

如果您想在**不向 LangSmith 记录任何内容**的情况下在本地运行评估（用于快速测试或验证），请参阅 [在本地运行评估](/langsmith/local)，该评估使用 `upload_results=False`。
</Note>

## 迭代评估结果

[`evaluate()`](https://reference.langchain.com/python/langsmith/observability/sdk/client/#langsmith.client.Client.evaluate) 函数返回一个可迭代的 [`ExperimentResults`](https://reference.langchain.com/python/langsmith/observability/sdk/evaluation/#langsmith.evaluation._runner.ExperimentResults) 对象。`blocking` 参数控制结果何时可用：

- `blocking=False`：立即返回一个迭代器，该迭代器在生成结果时会产生结果。这允许您在评估运行时实时处理结果。
- `blocking=True`（默认值）：在所有评估完成之前会阻塞，然后才返回。当您迭代结果时，所有数据都已经可用。

这两种模式都返回相同的 `ExperimentResults` 类型；区别在于函数是否等待完成才返回。使用 `blocking=False` 进行流式传输和实时调试，使用 `blocking=True` 进行批处理，即需要完整数据集时。

以下示例演示了 `blocking=False`。它在结果流式传输时进行迭代，将它们收集到一个列表中，然后在单独的循环中处理它们：

```python
from langsmith import Client
import random

client = Client()

def target(inputs):
    """您的应用程序或 LLM 链"""
    return {"output": "MY OUTPUT"}

def evaluator(run, example):
    """您的评估器函数"""
    return {"key": "randomness", "score": random.randint(0, 1)}

# 运行评估并设置 blocking=False 以获取迭代器
streamed_results = client.evaluate(
    target,
    data="MY_DATASET_NAME",
    evaluators=[evaluator],
    blocking=False
)

# 在流式传输时收集结果
aggregated_results = []
for result in streamed_results:
    aggregated_results.append(result)

# 在单独的循环中处理，以避免与 evaluate() 的日志同时记录
for result in aggregated_results:
    print("Input:", result["run"].inputs)
    print("Output:", result["run"].outputs)
    print("Evaluation Results:", result["evaluation_results"]["results"])
    print("--------------------------------")
```

这会产生如下输出：

```
Input: {'input': 'MY INPUT'}
Output: {'output': 'MY OUTPUT'}
Evaluation Results: [EvaluationResult(key='randomness', score=1, value=None, comment=None, correction=None, evaluator_info={}, feedback_config=None, source_run_id=UUID('7ebb4900-91c0-40b0-bb10-f2f6a451fd3c'), target_run_id=None, extra=None)]
--------------------------------
```

## 理解结果结构

迭代器中的每个结果包含：

- `result["run"]`: 您的目标函数的执行记录。
  - `result["run"].inputs`: 来自您 [数据集](/langsmith/evaluation-concepts#datasets) 示例的输入。
  - `result["run"].outputs`: 您的目标函数产生的输出。
  - `result["run"].id`: 此运行的唯一 ID。

- `result["evaluation_results"]["results"]`: 一个 `EvaluationResult` 对象的列表，每个评估器对应一个。
  - `key`: 指标名称（来自评估器的返回值）。
  - `score`: 数字分数（通常为 0-1 或布尔值）。
  - `comment`: 可选的解释性文本。
  - `source_run_id`: 评估器运行的 ID。

- `result["example"]`: 被评估的数据集示例。
  - `result["example"].inputs`: 输入值。
  - `result["example"].outputs`: 参考输出（如果有）。

## 示例

### 实施质量门

此示例使用评估结果根据质量阈值自动通过或失败 CI/CD 构建。脚本会遍历结果，计算平均准确率分数，如果准确率低于 85%，则以非零状态码退出。这确保了只有满足质量标准的代码更改才能部署。

```python
from langsmith import Client
import sys

client = Client()

def my_application(inputs):
    # 您的应用程序逻辑
    return {"response": "..."}

def accuracy_evaluator(run, example):
    # 您的评估逻辑
    is_correct = run.outputs["response"] == example.outputs["expected"]
    return {"key": "accuracy", "score": 1 if is_correct else 0}

# 运行评估
results = client.evaluate(
    my_application,
    data="my_test_dataset",
    evaluators=[accuracy_evaluator],
    blocking=False
)

# 计算汇总指标
total_score = 0
count = 0

for result in results:
    eval_result = result["evaluation_results"]["results"][0]
    total_score += eval_result.score
    count += 1

average_accuracy = total_score / count

print(f"Average accuracy: {average_accuracy:.2%}")

# 如果准确率过低，则使构建失败
if average_accuracy < 0.85:
    print("❌ 评估失败！准确率低于 85% 阈值。")
    sys.exit(1)

print("✅ 评估通过！")
```

### 使用 blocking=True 进行批处理

当您需要执行需要完整数据集的操作时（例如，计算百分位数、按分数排序或生成摘要报告），请使用 `blocking=True` 在处理前等待所有评估完成：

```python
# 运行评估并等待所有结果
results = client.evaluate(
    target,
    data=dataset,
    evaluators=[evaluator],
    blocking=True  # 等待所有评估完成
)

# 评估完成后处理所有结果
for result in results:
    print("Input:", result["run"].inputs)
    print("Output:", result["run"].outputs)

    # 访问单个评估结果
    for eval_result in result["evaluation_results"]["results"]:
        print(f"  {eval_result.key}: {eval_result.score}")
```

使用 `blocking=True` 时，您的处理代码仅在所有评估完成后运行，避免了评估日志输出与处理输出混杂的情况。

有关不上传结果运行评估的更多信息，请参阅 [在本地运行评估](/langsmith/local)。
