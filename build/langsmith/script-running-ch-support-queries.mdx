此 Helm 仓库包含的查询可用于生成 LangSmith UI 当前尚不支持直接输出的结果（例如，从 ClickHouse 获取查询异常日志）。

此命令需要一个包含嵌入式用户名和密码的 ClickHouse 连接字符串（此信息可以从密钥管理服务调用中传入），并执行来自输入文件的查询。在以下示例中，我们使用了 `support_queries/clickhouse` 目录中的 `ch_get_query_exceptions.sql` 输入文件。

### 先决条件

请确保您已准备好以下工具/项目。

1. kubectl

   * [https://kubernetes.io/docs/tasks/tools/](https://kubernetes.io/docs/tasks/tools/)

2. ClickHouse 数据库凭据

   * 主机 (Host)
   * 端口 (Port)
   * 用户名 (Username)
     * 如果使用捆绑版本，则为 `default`
   * 密码 (Password)
     * 如果使用捆绑版本，则为 `password`
   * 数据库名称 (Database name)
     * 如果使用捆绑版本，则为 `default`

3. 从您将运行迁移脚本的机器到 ClickHouse 数据库的网络连通性。

   * 如果您使用的是捆绑版本，则可能需要对 ClickHouse 服务进行端口转发 (port forward) 到本地机器。
   * 运行 `kubectl port-forward svc/langsmith-clickhouse 8123:8123` 将 ClickHouse 服务端口转发到您的本地机器。

4. 用于运行支持查询的脚本

   * 您可以从 [此处](https://github.com/langchain-ai/helm/blob/main/charts/langsmith/scripts/run_support_query_ch.sh) 下载该脚本

### 运行查询脚本

运行以下命令来执行所需的查询：

```bash
sh run_support_query_ch.sh <clickhouse_url> --input path/to/query.sql
```

例如，如果您使用的是捆绑版本并通过端口转发连接，则命令可能如下所示：

```bash
sh run_support_query_ch.sh "clickhouse://default:password@localhost:8123/default" --input support_queries/clickhouse/ch_get_query_exceptions.sql
```

这将输出 ClickHouse 中过去 7 天内引发了异常的所有查询的日志。要将这些日志提取到文件中，请添加标志 `--output path/to/file.csv`。
