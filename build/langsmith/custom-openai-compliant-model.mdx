LangSmith 的 Playground 允许您使用任何与 OpenAI API 兼容的模型。您可以通过在 Playground 中设置 **Proxy Provider** 来利用您的模型。

## 部署 OpenAI 兼容模型

许多提供商都提供与 OpenAI 兼容的模型或代理服务。一些例子包括：

* [LiteLLM Proxy](https://github.com/BerriAI/litellm?tab=readme-ov-file#quick-start-proxy---cli)
* [Ollama](https://ollama.com/)

您可以使用这些提供商来部署您的模型，并获得一个与 OpenAI API 兼容的 API 终结点。

请查阅完整的[规范](https://platform.openai.com/docs/api-reference/chat)以获取更多信息。

## 在 LangSmith Playground 中使用模型

部署模型服务器后，您就可以在 LangSmith [Playground](/langsmith/prompt-engineering-concepts#prompt-playground) 中使用它了。

要访问 **Prompt Settings**（提示词设置）菜单：

1. 在 **Prompts**（提示词）标题下，选择模型名称旁边的齿轮 <Icon icon="gear" iconType="solid" /> 图标。
1. 在 **Model Configuration**（模型配置）选项卡中，从下拉菜单中选择要编辑的模型。
1. 对于 **Provider**（提供商）下拉菜单，选择 **OpenAI Compatible Endpoint**（OpenAI 兼容终结点）。
1. 将您的 OpenAI 兼容终结点添加到 **Base URL**（基础网址）输入框中。

有关如何存储模型配置的信息，请参阅[配置提示词设置](/langsmith/managing-model-configurations)。
