检索增强生成 (Retrieval Augmented Generation, RAG) 是一种通过为大型语言模型 (LLM) 提供相关的外部知识来增强它们的技术。它已成为构建 LLM 应用最常用的方法之一。

本教程将向您展示如何使用 LangSmith 来评估您的 RAG 应用。您将了解到：

1. 如何创建测试数据集
2. 如何在这些数据集上运行您的 RAG 应用
3. 如何使用不同的评估指标来衡量应用的性能

## 概述

一个典型的 RAG 评估工作流程包含三个主要步骤：

1. 创建一个包含问题及其预期答案的数据集

2. 在这些问题上运行您的 RAG 应用

3. 使用评估器来衡量应用的表现如何，关注以下因素：

   * 答案相关性
   * 答案准确性
   * 检索质量

对于本教程，我们将创建一个针对 Lilian Weng 几篇富有洞察力的博客文章进行问答的机器人，并对其进行评估。[Lilian Weng 的](https://lilianweng.github.io/)

<Info>
虽然本教程使用了 LangChain，但这里展示的评估技术和 LangSmith 功能适用于**任何框架**。欢迎使用您首选的工具和库。

在本节中，我们将构建一个基础的检索增强生成 (RAG) 应用。

我们将坚持一个简单的实现，该实现执行以下操作：

* **索引 (Indexing)**：对 Lilian Weng 的几篇博客文章进行分块 (chunking) 并将其索引到向量存储 (vector store) 中
* **检索 (Retrieval)**：根据用户问题检索相关的块（文档片段）
* **生成 (Generation)**：将问题和检索到的文档传递给 LLM。

#### 索引和检索

首先，我们加载想要构建聊天机器人的博客文章并对其进行索引。

<CodeGroup>

```python Python
from langchain_community.document_loaders import WebBaseLoader
from langchain_core.vectorstores import InMemoryVectorStore
from langchain_openai import OpenAIEmbeddings
from langchain_text_splitters import RecursiveCharacterTextSplitter

# 要加载文档的 URL 列表
urls = [
    "https://lilianweng.github.io/posts/2023-06-23-agent/",
    "https://lilianweng.github.io/posts/2023-03-15-prompt-engineering/",
    "https://lilianweng.github.io/posts/2023-10-25-adv-attack-llm/",
]

# 从 URL 加载文档
docs = [WebBaseLoader(url).load() for url in urls]
docs_list = [item for sublist in docs for item in sublist]

# 使用指定的块大小和重叠度初始化文本分割器
text_splitter = RecursiveCharacterTextSplitter.from_tiktoken_encoder(
    chunk_size=250, chunk_overlap=0
)

# 将文档分割成块
doc_splits = text_splitter.split_documents(docs_list)

# 使用 OpenAIEmbeddings 将文档块添加到“向量存储”中
vectorstore = InMemoryVectorStore.from_documents(
    documents=doc_splits,
    embedding=OpenAIEmbeddings(),
)

# 使用 LangChain，我们可以轻松地将任何向量存储转换为检索组件：
retriever = vectorstore.as_retriever(k=6)
```

```typescript TypeScript
import { OpenAIEmbeddings } from "@langchain/openai";
import { MemoryVectorStore } from "@langchain/classic/vectorstores/memory";
import { BrowserbaseLoader } from "@langchain/community/document_loaders/web/browserbase";
import { RecursiveCharacterTextSplitter } from "@langchain/text_splitters";

// 要加载文档的 URL 列表
const urls = [
    "https://lilianweng.github.io/posts/2023-06-23-agent/",
    "https://lilianweng.github.io/posts/2023-03-15-prompt-engineering/",
    "https://lilianweng.github.io/posts/2023-10-25-adv-attack-llm/",
]

const loader = new BrowserbaseLoader(urls, {
    textContent: true,
});

const docs = await loader.load();

const splitter = new RecursiveCharacterTextSplitter({
    chunkSize: 1000, chunkOverlap: 200
});

const allSplits = await splitter.splitDocuments(docs);

const embeddings = new OpenAIEmbeddings({
    model: "text-embedding-3-large"
});

const vectorStore = new MemoryVectorStore(embeddings);  // 索引分块
await vectorStore.addDocuments(allSplits)
```

#### 生成

我们现在可以定义生成管道。

<CodeGroup>

```python Python
from langchain_openai import ChatOpenAI
from langsmith import traceable

llm = ChatOpenAI(model="gpt-4o", temperature=1)

# 添加装饰器，以便此函数在 LangSmith 中被追踪
@traceable()
def rag_bot(question: str) -> dict:
    # LangChain 检索器将自动被追踪
    docs = retriever.invoke(question)
    docs_string = "".join(doc.page_content for doc in docs)
    instructions = f"""你是一个乐于助人、擅长分析源信息并回答问题的助手。
       请使用以下源文档回答用户的问题。
       如果你不知道答案，请直接说不知道。
       最多使用三句话，并保持答案简洁。

文档:
{docs_string}"""
    # LangChain ChatModel 将自动被追踪
    ai_msg = llm.invoke([
            {"role": "system", "content": instructions},
            {"role": "user", "content": question},
        ],
    )
    return {"answer": ai_msg.content, "documents": docs}
```

```typescript TypeScript

  model: "gpt-4o",
  temperature: 1,

const ragBot = traceable(

        请使用以下源文档回答用户的问题。
        如果你不知道答案，请直接说不知道。
        最多使用三句话，并保持答案简洁。
        文档:
        ${docsContent}`;

        const aiMsg = await llm.invoke([
            {
                role: "system",
                content: instructions
            },
            {
                role: "user",
                content: question
            }
        ])

        return {"answer": aiMsg.content, "documents": retrievedDocs}
    }
)
```

## 评估器

思考不同类型的 RAG 评估器的一种方式是将其视为一个元组：正在评估的内容 X 评估标准：

1. **准确性 (Correctness)**：响应 vs 参考答案

* `目标`: 衡量“RAG 链的答案与基准 (ground-truth) 答案相比，有多相似/正确”
* `模式`: 需要通过数据集中提供的基准 (参考) 答案
* `评估器`: 使用 LLM 作为判官来评估答案的准确性。

2. **相关性 (Relevance)**：响应 vs 输入

* `目标`: 衡量“生成的响应在多大程度上解决了最初的用户输入”
* `模式`: 不需要参考答案，因为它会将答案与输入问题进行比较
* `评估器`: 使用 LLM 作为判官来评估答案的相关性、有用性等。

3. **根据性/事实基础性 (Groundedness)**：响应 vs 检索到的文档

* `目标`: 衡量“生成的响应在多大程度上与检索到的上下文一致”
* `模式`: 不需要参考答案，因为它会将答案与检索到的上下文进行比较
* `评估器`: 使用 LLM 作为判官来评估事实一致性、幻觉 (hallucination) 等。

4. **检索相关性 (Retrieval relevance)**：检索到的文档 vs 输入

* `目标`: 衡量“我的检索结果对于这个查询有多相关”
* `模式`: 不需要参考答案，因为它会将查询与检索到的上下文进行比较
* `评估器`: 使用 LLM 作为判官来评估相关性

### 准确性：响应 vs 参考答案

<CodeGroup>

```python Python
from typing_extensions import Annotated, TypedDict

# 评分输出模式 (Grade output schema)
class CorrectnessGrade(TypedDict):
    # 注意：字段定义的顺序是模型生成它们的顺序。
    # 将解释放在响应之前很有用，因为它会迫使模型在生成最终响应前先思考其推理过程：
    explanation: Annotated[str, ..., "解释您对分数的原因"]
    correct: Annotated[bool, ..., "如果答案正确，则为 True，否则为 False。"]

# 评分提示 (Grade prompt)
correctness_instructions = """你是一名批改小测验的老师。你将收到一个问题 (QUESTION)、基准 (正确) 答案 (GROUND TRUTH ANSWER) 和学生的答案 (STUDENT ANSWER)。请遵循以下评分标准：
(1) 仅根据学生答案相对于基准答案的事实准确性进行评分。(2) 确保学生答案不包含任何冲突的陈述。
(3) 如果学生答案包含比基准答案更多的信息，只要其事实准确性相对于基准答案是正确的，也是可以的。

准确性 (Correctness):
准确性值为 True 表示学生的答案满足所有标准。
准确性值为 False 表示学生的答案不满足所有标准。

请逐步解释您的推理，以确保您的推理和结论正确。避免一开始就简单地陈述正确答案。"""

# 判官 LLM (Grader LLM)
grader_llm = ChatOpenAI(model="gpt-4o", temperature=0).with_structured_output(
    CorrectnessGrade, method="json_schema", strict=True
)

def correctness(inputs: dict, outputs: dict, reference_outputs: dict) -> bool:
    """RAG 答案准确性的评估器"""
    answers = f"""\
问题: {inputs['question']}
基准答案: {reference_outputs['answer']}
学生答案: {outputs['answer']}"""
    # 运行评估器
    grade = grader_llm.invoke([
        {"role": "system", "content": correctness_instructions},
        {"role": "user", "content": answers}
    ])
    return grade["correct"]
```

```typescript TypeScript
import type { EvaluationResult } from "langsmith/evaluation";
import { z } from "zod";

// 评分提示 (Grade prompt)
const correctnessInstructions = `You are a teacher grading a quiz. You will be given a QUESTION, the GROUND TRUTH (correct) ANSWER, and the STUDENT ANSWER. Here is the grade criteria to follow:
(1) Grade the student answers based ONLY on their factual accuracy relative to the ground truth answer. (2) Ensure that the student answer does not contain any conflicting statements.
(3) It is OK if the student answer contains more information than the ground truth answer, as long as it is factually accurate relative to the  ground truth answer.

Correctness:
A correctness value of True means that the student's answer meets all of the criteria.
A correctness value of False means that the student's answer does not meet all of the criteria.

Explain your reasoning in a step-by-step manner to ensure your reasoning and conclusion are correct. Avoid simply stating the correct answer at the outset.`

const graderLLM = new ChatOpenAI({
  model: "gpt-4o",
  temperature: 0,
}).withStructuredOutput(
  z
    .object({
      explanation: z
        .string()
        .describe("Explain your reasoning for the score"),
      correct: z
        .boolean()
        .describe("True if the answer is correct, False otherwise.")
    })
    .describe("Correctness score for reference answer v.s. generated answer.")
);

async function correctness({
  inputs,
  outputs,
  referenceOutputs,
}: {
  inputs: Record<string, any>;
  outputs: Record<string, any>;
  referenceOutputs?: Record<string, any>;
}): Promise<EvaluationResult> => {
  const answer = `QUESTION: ${inputs.question}
    GROUND TRUTH ANSWER: ${referenceOutputs.answer}
    STUDENT ANSWER: ${outputs.answer}`

  // 运行评估器
  const grade = graderLLM.invoke([{role: "system", content: correctnessInstructions}, {role: "user", content: answer}])
  return grade.score;
};
```

### 相关性：响应 vs 输入

流程与上述类似，但我们只查看 `inputs` 和 `outputs`，而不需要 `reference_outputs`。如果没有参考答案，我们就无法评估准确性，但仍然可以评估相关性——即模型是否解决了用户的问题。

<CodeGroup>

```python Python
# 评分输出模式 (Grade output schema)
class RelevanceGrade(TypedDict):
    explanation: Annotated[str, ..., "解释您对分数的原因"]
    relevant: Annotated[
        bool, ..., "提供关于答案是否解决了问题的分数"
    ]

# 评分提示 (Grade prompt)
relevance_instructions = """你是一名批改小测验的老师。你将收到一个问题 (QUESTION) 和一个学生答案 (STUDENT ANSWER)。请遵循以下评分标准：
(1) 确保学生答案简洁并与问题相关
(2) 确保学生答案有助于回答问题

相关性 (Relevance):
相关性值为 True 表示学生的答案满足所有标准。
相关性值为 False 表示学生的答案不满足所有标准。

请逐步解释您的推理，以确保您的推理和结论正确。避免一开始就简单地陈述正确答案。"""

# 判官 LLM (Grader LLM)
relevance_llm = ChatOpenAI(model="gpt-4o", temperature=0).with_structured_output(
    RelevanceGrade, method="json_schema", strict=True
)

# 评估器
def relevance(inputs: dict, outputs: dict) -> bool:

        {"role": "system", "content": relevance_instructions},
        {"role": "user", "content": answer}
    ])
    return grade["relevant"]
```

### 根据性/事实基础性：响应 vs 检索到的文档

评估响应的另一种有用方法是在不需要参考答案的情况下，检查响应是否根据检索到的文档得到“支持”（或“基于事实”）。

<CodeGroup>

```python Python
# 评分输出模式 (Grade output schema)
class GroundedGrade(TypedDict):
    explanation: Annotated[str, ..., "解释您对分数的原因"]
    grounded: Annotated[
        bool, ..., "提供关于答案是否从文档中产生幻觉的分数"
    ]

# 评分提示 (Grade prompt)
grounded_instructions = """你是一名批改小测验的老师。你将收到事实 (FACTS) 和一个学生答案 (STUDENT ANSWER)。请遵循以下评分标准：
(1) 确保学生答案基于事实 (FACTS)。(2) 确保学生答案不包含超出事实范围的“幻觉”信息。

基于事实性 (Grounded):
基于事实性值为 True 表示学生的答案满足所有标准。
基于事实性值为 False 表示学生的答案不满足所有标准。

请逐步解释您的推理，以确保您的推理和结论正确。避免一开始就简单地陈述正确答案。"""

# 判官 LLM (Grader LLM)
grounded_llm = ChatOpenAI(model="gpt-4o", temperature=0).with_structured_output(
    GroundedGrade, method="json_schema", strict=True
)

# 评估器
def groundedness(inputs: dict, outputs: dict) -> bool:
    """RAG 答案基于事实性的简单评估器。"""
    # 在 Python 中，outputs["documents"] 应该是 Document 对象的列表，需要提取 page_content
    doc_string = "\n\n".join(doc.page_content for doc in outputs["documents"])
    answer = f"事实: {doc_string}\n学生答案: {outputs['answer']}"
    grade = grounded_llm.invoke([
        {"role": "system", "content": grounded_instructions},
        {"role": "user", "content": answer}
    ])
    return grade["grounded"]
```
