本文档描述了 LangGraph CLI 和 Agent Server 如何处理数据（包括**内存中的服务器**（`langgraph dev`）和**本地 Docker 服务器**（`langgraph up`））。此外，它还描述了与托管的 Studio 前端交互时会跟踪哪些数据。

## CLI

LangGraph **CLI** 是用于构建和运行 LangGraph 应用的命令行界面；请参阅 [CLI 指南](/langsmith/cli) 了解更多信息。

默认情况下，对大多数 CLI 命令的调用会在执行时记录一个分析事件。这有助于我们更好地确定 CLI 体验改进的优先级。每个遥测事件包含调用进程的操作系统 (OS)、OS 版本、Python 版本、CLI 版本、命令名称（如 `dev`、`up`、`run` 等），以及表示是否向命令传递了某个标志的布尔值。您可以在 [此处](https://github.com/langchain-ai/langgraph/blob/main/libs/cli/langgraph-cli/analytics.py) 查看完整的分析逻辑。

您可以通过设置环境变量 `LANGGRAPH_CLI_NO_ANALYTICS=1` 来禁用所有 CLI 遥测。

## Agent Server (代理服务器)

[Agent Server](/langsmith/agent-server) 提供了一个持久化的执行运行时环境，它依赖于将应用程序状态的检查点、长期记忆、线程元数据、助手和类似资源持久化到本地文件系统或数据库中。除非您明确自定义了存储位置，否则这些信息要么写入本地磁盘（用于 `langgraph dev`），要么写入 PostgreSQL 数据库（用于 `langgraph up` 和所有部署环境）。

### LangSmith 跟踪 (Tracing)

在运行 Agent 服务器时（无论是内存中还是 Docker 中），LangSmith 跟踪功能可能会被启用，以便于快速调试，并在生产环境中提供图状态和 LLM 提示的可观测性。您始终可以通过在服务器的运行时环境中设置 `LANGSMITH_TRACING=false` 来禁用跟踪。

<a id="langgraph-dev"></a>
### 内存开发服务器 (In-memory development server)

`langgraph dev` 作为一个单一的 Python 进程运行一个 [内存中的开发服务器](/langsmith/local-server)，专为快速开发和测试而设计。它将所有检查点和内存数据保存在当前工作目录下的 `.langgraph_api` 目录中。除了 [CLI](#cli) 部分中描述的遥测数据外，除非您启用了跟踪，或者您的图代码明确联系了外部服务，否则**不会有任何数据离开本地机器**。

<a id="langgraph-up"></a>
### 独立服务器 (Standalone Server)

`langgraph up` 将您的本地包构建成 Docker 镜像，并将服务器作为 [数据平面](/langsmith/self-hosted) 运行，该数据平面由三个容器组成：API 服务器、一个 PostgreSQL 容器和一个 Redis 容器。所有持久化数据（检查点、助手等）都存储在 PostgreSQL 数据库中。Redis 用于作为发布/订阅 (pubsub) 连接，以实现事件的实时流式传输。您可以通过设置有效的 `LANGGRAPH_AES_KEY` 环境变量，在数据保存到数据库**之前**加密所有检查点。您还可以通过在 `langgraph.json` 中指定检查点和跨线程内存的 [TTL](/langsmith/configure-ttl)（生存时间）来控制数据的存储时长。所有持久化的线程、内存和其他数据都可以通过相应的 API 端点删除。

此外，还会发出额外的 API 调用，以确认服务器拥有有效的许可证，并跟踪已执行的运行和任务的数量。API 服务器会定期验证提供的许可证密钥（或 API 密钥）。

如果您禁用了 [跟踪](#langsmith-tracing)，则除非您的图代码明确联系外部服务，否则不会将任何用户数据持久化到外部。

## Studio

[Studio](/langsmith/studio) 是一个用于与您的 Agent Server 交互的图形界面。它**不会持久化任何私有数据**（发送到您服务器的数据不会发送到 LangSmith）。尽管 Studio 界面托管在 [smith.langchain.com](https://smith.langchain.com)，但它在您的浏览器中运行，并直接连接到您的本地 Agent Server，因此**无需**将任何数据发送到 LangSmith。

如果您已登录，LangSmith 会收集一些使用遥测数据，以帮助改进调试用户体验。这些数据包括：

* 页面访问量和导航模式
* 用户操作（按钮点击）
* 浏览器类型和版本
* 屏幕分辨率和视口大小

重要的是，**不会**收集任何应用程序数据、代码或其他敏感的配置详情。所有这些数据都存储在您的 Agent Server 的持久化层中。在使用 Studio 进行匿名访问时，无需创建帐户，也不会收集使用遥测数据。

## 快速参考

总而言之，您可以通过关闭 CLI 分析和禁用跟踪来选择退出服务器端的遥测。

| 变量 | 用途 | 默认值 |
| :--- | :--- | :--- |
| `LANGGRAPH_CLI_NO_ANALYTICS=1` | 禁用 CLI 分析 | 分析启用 |
| `LANGSMITH_API_KEY` | 启用 LangSmith 跟踪 | 跟踪禁用 |
| `LANGSMITH_TRACING=false` | 禁用 LangSmith 跟踪 | 取决于环境 |
