本节内容涵盖如何托管和管理 LangSmith 基础设施。您可以为 [可观测性](/langsmith/observability)、[评估](/langsmith/evaluation) 和 [提示工程](/langsmith/prompt-engineering) 设置 LangSmith，或者使用完整的平台体验 [LangSmith 部署](/langsmith/deployments) 来通过 UI 部署和管理您的应用程序。

<Callout icon="building" color="#2563EB" iconType="regular">
**如果您正在设置或维护 LangSmith 基础设施，请从这里开始。**

如果您想部署一个 Agent 应用程序，[部署部分](/langsmith/deployments) 涵盖了应用程序结构和部署配置。
</Callout>

## 选择设置 LangSmith 的方式

您可以通过以下三种模式部署 LangSmith：
- [**云端 (Cloud)**](/langsmith/cloud)：由 LangChain 完全托管
- [**混合 (Hybrid)**](/langsmith/hybrid)：LangChain 管理 <Tooltip tip="用于管理部署的 LangSmith UI 和 API。">控制平面</Tooltip>；您托管 <Tooltip tip="Agent Server 和 Agent 执行的运行时环境。">数据平面</Tooltip>
- [**自托管 (Self-hosted)**](/langsmith/self-hosted)：您在自己的基础设施中管理整个堆栈

### 对比

有关对比信息，请参阅下表：

| 功能 | **云端 (Cloud)** | **混合云 (Hybrid)** | **自托管 (Self-Hosted)** |
|---------|-----------|------------|-----------------|
| **基础设施位置** | LangChain 的云端 | 分离：控制平面在 LangChain 云端，数据平面在您的云端 | 您的云端 |
| **谁管理更新** | LangChain | LangChain (控制平面)，您 (数据平面) | 您 |
| **谁管理应用的 CI/CD** | LangChain | 您 | 您 |
| **可以部署应用程序吗？** | ✅ 是 | ✅ 是 | ✅ 是 (启用了 LangSmith 部署) |
| **可观测性数据位置** | LangChain 云端 | LangChain 云端 | 您的云端 |
| **[价格](https://www.langchain.com/plans)** | Plus 套件 | 企业版 | 企业版 |
| **最适合于** | 快速设置，托管基础设施 | 数据驻留要求 + 托管控制平面 | 完全控制，数据隔离 |

<Tip>

</Tip>
