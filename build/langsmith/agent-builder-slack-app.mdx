LangSmith Agent Builder Slack 应用将您的代理与 Slack 集成，实现在您的 Slack 工作区内进行安全、上下文感知的交流。

安装后，您的代理将能够：

- 发送私信（Direct messages）。
- 发布到频道（Channels）。
- 读取线程消息（Thread messages）。
- 在线程中回复。
- 读取会话历史记录。

## 如何安装

要安装 LangSmith Agent Builder for Slack：

1. 导航至您的 [LangSmith 工作区](https://smith.langchain.com) 中的 Agent Builder 界面。
2. 创建或编辑一个代理。
3. 添加 Slack 作为触发器（trigger）或启用 Slack 工具（tools）。
4. 出现提示时，授权 Slack 连接。
5. 遵循 OAuth 流程，授予您的 Slack 工作区必要的权限。

当您完成授权后，应用将会自动安装，**但是**，您仍然需要将该应用邀请到您希望使用的特定频道中去。

要邀请 Slack 机器人，您可以发送以下消息：
```txt
/invite @LangSmith Agent Builder
```

## 权限

LangSmith Agent Builder 需要您的 Slack 工作区授予以下权限：

- **发送消息 (Send messages)** - 发送私信和发布到频道
- **读取消息 (Read messages)** - 读取频道历史记录和线程消息
- **查看频道 (View channels)** - 访问基础的频道信息
- **查看用户 (View users)** - 查找用户信息以便发送消息

这些权限使代理能够在您的 Slack 工作区内进行有效的通信。

## 隐私政策

LangSmith Agent Builder Slack 应用根据我们的隐私政策收集、管理和存储第三方数据。有关数据处理的完整详细信息，请参阅[我们的隐私政策](https://www.langchain.com/privacy-policy)。

## AI 组件和免责声明

LangSmith Agent Builder 使用大型语言模型（LLMs）来驱动与 Slack 用户互动的 AI 代理。尽管这些模型功能强大，但它们仍有可能生成不准确的响应、摘要或其他输出。

### 您应该了解什么

- **AI 生成的内容**：代理的所有响应均由 AI 生成，可能包含错误或不准确之处。请务必验证重要信息。
- **数据使用**：Slack 数据不会被用于训练 LLM。您的工作区数据将保持私密，仅用于提供代理功能。
- **透明度**：如上文“权限”部分所述，Agent Builder 会明确说明添加后它将采取哪些操作。

### 技术细节

Agent Builder 在使用 AI 方面遵循以下方法：

- **模型 (Model)**：使用 LangSmith 平台提供的 LLMs
- **数据保留 (Data retention)**：用户数据根据 LangSmith 的数据保留政策进行保留
- **数据租约 (Data tenancy)**：数据根据您的 LangSmith 组织设置进行处理
- **数据驻留 (Data residency)**：数据驻留遵循您的 LangSmith 配置

有关 AI 安全性和最佳实践的更多信息，请参阅 [Agent Builder 文档](/langsmith/agent-builder)。

## 定价

LangSmith Agent Builder Slack 应用本身没有直接的定价。但是，代理运行（runs）和跟踪（traces）将根据您组织的计划，通过 [LangSmith 平台](https://smith.langchain.com) 进行计费。

有关当前的定价信息，请参阅 [LangSmith 定价页面](https://www.langchain.com/pricing)。
