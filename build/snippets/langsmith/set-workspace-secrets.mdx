在 [LangSmith UI](https://smith.langchain.com) 中，请确保您的 OpenAI API 密钥已设置为 [工作区密钥（workspace secret）](/langsmith/administration-overview#workspace-secrets)。

1. 导航到 <Icon icon="gear" /> **设置 (Settings)**，然后切换到 **密钥 (Secrets)** 选项卡。
1. 选择 **添加密钥 (Add secret)**，输入 `OPENAI_API_KEY` 作为密钥名称，并将您的 API 密钥作为**值 (Value)** 填入。
1. 选择 **保存密钥 (Save secret)**。

<Note> 在 LangSmith UI 中添加工作区密钥时，请务必确保密钥的名称（Key）与您的模型提供商所期望的环境变量名称完全匹配。</Note>
