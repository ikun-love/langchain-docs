默认情况下，LangSmith 遵循 `uv`/`pip` 的行为，即**不**安装预发布版本（prerelease versions），除非明确允许。如果要使用预发布版本，您有以下几种选择：

- 使用 `pyproject.toml`：在您的 `[tool.uv]` 配置段中添加 `allow-prereleases = true`。
- 使用 `requirements.txt` 或 `setup.py`：您必须明确指定每一个预发布依赖项，包括间接依赖项（transitive ones）。例如，如果您声明了 `a==0.0.1a1`，并且 `a` 依赖于 `b==0.0.1a1`，那么您也必须在依赖项中明确包含 `b==0.0.1a1`。
