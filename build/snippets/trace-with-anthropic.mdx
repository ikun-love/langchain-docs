Python 中的 `wrap_anthropic` 方法允许您将 Anthropic 客户端包装起来，以便**自动记录追踪信息（traces）**——无需使用装饰器或函数包裹！使用该包装器可以确保消息（包括工具调用和多模态内容块）在 LangSmith 中得到美观的渲染。

此包装器可以无缝地与 `@traceable` 装饰器或 `traceable` 函数协同工作，您可以在同一个应用程序中同时使用它们。

<Note>
为了能将追踪信息记录到 LangSmith，**`LANGSMITH_TRACING` 环境变量必须设置为 `'true'`**，即使在使用 `wrap_anthropic` 时也是如此。这样做的好处是，您无需修改代码就能随时开启或关闭追踪功能。

此外，您还需要设置 `LANGSMITH_API_KEY` 环境变量为您的 API 密钥（更多信息请参阅 [Setup](/])）。

如果您的 LangSmith API 密钥关联了多个工作区，请设置 `LANGSMITH_WORKSPACE_ID` 环境变量来指定要使用的工作区。

默认情况下，追踪信息将记录到一个名为 `default` 的项目中。如需将追踪信息记录到其他项目，请参阅 [本节](/langsmith/log-traces-to-project)。
</Note>

```python
import anthropic
from langsmith import traceable
from langsmith.wrappers import wrap_anthropic

client = wrap_anthropic(anthropic.Anthropic())

# 您也可以包装异步客户端
# async_client = wrap_anthropic(anthropic.AsyncAnthropic())

@traceable(run_type="tool", name="Retrieve Context")
def my_tool(question: str) -> str:
    return "During this morning's meeting, we solved all world conflict."

@traceable(name="Chat Pipeline")
def chat_pipeline(question: str):
    context = my_tool(question)
    messages = [
        { "role": "user", "content": f"Question: {question}\nContext: {context}"}
    ]
    messages = client.messages.create(
      model="claude-sonnet-4-5-20250929",
      messages=messages,
      max_tokens=1024,
      system="You are a helpful assistant. Please respond to the user's request only based on the given context."
    )
    return messages

chat_pipeline("Can you summarize this morning's meetings?")
```
