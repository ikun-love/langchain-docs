[Dappier](https://dappier.com) 将任何大型语言模型（LLM）或您的 Agentic AI 连接到来自可信来源的实时、已获授权的专有数据，使您的 AI 能够精通任何主题。我们在专业模型中包括：实时网络搜索、新闻、体育、金融股票市场数据、加密货币数据，以及来自高级出版商的独家内容。欢迎访问我们的市场 [marketplace.dappier.com](https://marketplace.dappier.com) 探索各种数据模型。

[Dappier](https://dappier.com) 提供丰富、即时可用且与上下文相关的、优化过的**数据字符串**，以便与 LangChain 无缝集成。无论您是构建对话式 AI、推荐引擎还是智能搜索，Dappier 的 LLM 无关（LLM-agnostic）的 RAG 模型都能确保您的 AI 访问经过验证的最新数据，而无需处理构建和管理自己的检索管道的复杂性。

# DappierRetriever

这部分内容将帮助您开始使用 Dappier 的 [retriever](https://python.langchain.com/docs/concepts/retrievers/)（检索器）。要查看所有 DappierRetriever 功能和配置的详细文档，请前往 [API reference](https://python.langchain.com/en/latest/retrievers/langchain_dappier.retrievers.Dappier.DappierRetriever.html)。

### Setup (设置)

安装 `langchain-dappier` 并设置环境变量 `DAPPIER_API_KEY`。

```bash
pip install -U langchain-dappier
export DAPPIER_API_KEY="your-api-key"
```

我们还需要设置 Dappier API 凭证，这些凭证可以在 [Dappier 站点](https://platform.dappier.com/profile/api-keys)上生成。

您可以通过访问 [Dappier 市场](https://platform.dappier.com/marketplace) 找到支持的数据模型。

如果您希望从单个查询中获得自动化的追踪（tracing）记录，您还可以取消注释以下代码以设置您的 [LangSmith](https://docs.langchain.com/langsmith/home) API 密钥：

```python
os.environ["LANGSMITH_API_KEY"] = getpass.getpass("Enter your LangSmith API key: ")
os.environ["LANGSMITH_TRACING"] = "true"
```

### Installation (安装)

这个检索器包含在 `langchain-dappier` 包中：

```python
pip install -qU langchain-dappier
```

## Instantiation (实例化)

- data_model_id: str
    数据模型 ID，以 `dm_` 开头。
    您可以在以下位置找到可用的数据模型 ID：
    [Dappier 市场。](https://platform.dappier.com/marketplace)
- k: int
    要返回的文档数量。
- ref: Optional[str]
    显示 AI 推荐的站点域名。
- num_articles_ref: int
    来自指定 `ref` 域名的最小文章数。
    其余文章将来自 RAG 模型中的其他站点。
- search_algorithm: Literal[
    "most_recent",
    "most_recent_semantic",
    "semantic",
    "trending"
]
    用于检索文章的搜索算法。
- api_key: Optional[str]
    用于与 Dappier API 交互的 API 密钥。

```python
from langchain_dappier import DappierRetriever

retriever = DappierRetriever(data_model_id="dm_01jagy9nqaeer9hxx8z1sk1jx6")
```

## Usage (使用)

```python
query = "latest tech news"

retriever.invoke(query)
```
