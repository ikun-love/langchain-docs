本 Notebook 展示了如何从 Arxiv.org 中检索科学文章，并将其转换为下游使用的 [Document](https://python.langchain.com/api_reference/core/documents/langchain_core.documents.base.Document.html) 格式。

如需了解 `ArxivRetriever` 所有功能和配置的详细文档，请参阅 [API 参考](https://python.langchain.com/api_reference/community/retrievers/langchain_community.retrievers.arxiv.ArxivRetriever.html)。

## 实例化 (Instantiation)

`ArxivRetriever` 的参数包括：

- 可选 `load_max_docs`: 默认为 100。用于限制下载的文档数量。下载全部 100 份文档需要时间，因此实验时请使用较小的数字。目前有一个 300 的硬性限制。
- 可选 `load_all_available_meta`: 默认为 False。默认情况下，只下载最重要的字段：`Published`（文档发布/最后更新日期）、`Title`（标题）、`Authors`（作者）、`Summary`（摘要）。如果设置为 True，则会下载其他字段。
- `get_full_documents`: 布尔值，默认为 False。决定是否获取文档的全文内容。

有关更多详细信息，请参阅 [API 参考](https://python.langchain.com/api_reference/community/retrievers/langchain_community.retrievers.arxiv.ArxivRetriever.html)。

```python
from langchain_community.retrievers import ArxivRetriever

retriever = ArxivRetriever(
    load_max_docs=2,
    get_full_documents=True,
)
```

## 用法 (Usage)

`ArxivRetriever` 支持通过文章标识符进行检索：

```python
docs = retriever.invoke("1605.08386")
```

```python
docs[0].metadata  # Document 的元信息
```

```output
{'Entry ID': 'http://arxiv.org/abs/1605.08386v1',
 'Published': datetime.date(2016, 5, 26),

 'Authors': 'Caprice Stanley, Tobias Windisch'}
```

docs[0].page_content[:400]  # Document 的内容
