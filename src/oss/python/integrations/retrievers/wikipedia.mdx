## 实例化

现在我们可以实例化我们的检索器：

`WikipediaRetriever` 参数包括：

- 可选 `lang`：默认为 `"en"`。用于在维基百科的特定语言部分中进行搜索。
- 可选 `load_max_docs`：默认为 `100`。用于限制下载的文档数量。下载全部 100 个文档会耗费时间，因此实验时请使用较小的数字。目前有一个 300 的硬性限制。
- 可选 `load_all_available_meta`：默认为 `False`。默认情况下，只下载最重要的字段：`Published`（文档发布/最后更新日期）、`title`、`Summary`（摘要）。如果设置为 `True`，则也会下载其他字段。

`get_relevant_documents()` 有一个参数 `query`：用于在维基百科中查找文档的自由文本。

```python
from langchain_community.retrievers import WikipediaRetriever

retriever = WikipediaRetriever()
```

## 用法

```python
docs = retriever.invoke("TOKYO GHOUL")
```

```python
print(docs[0].page_content[:400])
```
