## Zep Cloud 的检索器示例

> 回忆、理解并从聊天历史中提取数据。为个性化 AI 体验提供支持。

> [Zep](https://www.getzep.com) 是 AI 助手应用的长期记忆服务。
> 通过 Zep，您可以让 AI 助手具备回忆过去对话的能力，无论这些对话发生多久以前，
> 同时还能减少幻觉、延迟和成本。

> 查看 [Zep Cloud 安装指南](https://help.getzep.com/sdks) 和更多 [Zep Cloud LangChain 示例](https://github.com/getzep/zep-python/tree/main/examples)

## 检索器示例

本 Notebook 演示了如何使用 [Zep 长期记忆存储](https://www.getzep.com/) 搜索历史聊天消息。

我们将演示：

1. 将对话历史添加到 Zep 记忆存储中。
2. 对对话历史进行向量搜索：
    1. 使用对聊天消息的相似性搜索
    2. 使用对聊天消息的**最大边际相关性 (MMR)** 重新排序
    3. 使用元数据过滤器过滤搜索结果
    4. 对聊天消息摘要进行相似性搜索
    5. 使用对摘要搜索的 MMR 重新排序

```python
import getpass
import time
from uuid import uuid4

from langchain_community.memory.zep_cloud_memory import ZepCloudMemory
from langchain_community.retrievers import ZepCloudRetriever
from langchain.messages import AIMessage, HumanMessage

# 提供您的 Zep API 密钥。
zep_api_key = getpass.getpass()
```

### 初始化 Zep 聊天消息历史记录类并将聊天消息历史记录添加到记忆存储中

**注意：** 与其他检索器不同，Zep 检索器返回的内容是特定于会话/用户的。实例化检索器时需要提供 `session_id`。

```python
session_id = str(uuid4())  # 这是用户/会话的唯一标识符

# 初始化 Zep 记忆类
zep_memory = ZepCloudMemory(session_id=session_id, api_key=zep_api_key)
```

### 使用 Zep 检索器对 Zep 记忆进行向量搜索

Zep 为历史对话记忆提供了原生的向量搜索功能。嵌入是自动发生的。

注意：消息的嵌入是异步发生的，因此第一次查询可能不会返回结果。后续查询会随着嵌入的生成而返回结果。

```python
zep_retriever = ZepCloudRetriever(
    api_key=zep_api_key,
    session_id=session_id,  # 确保在实例化检索器时提供 session_id
    top_k=5,
)

await zep_retriever.ainvoke("谁写了《播种者的寓言》？")
```

### 使用 MMR (最大边际相关性) 进行重新排序

Zep 对使用 MMR 重新排序结果提供原生的、经过 SIMD 加速的支持。这有助于消除结果中的冗余。

```python
zep_retriever = ZepCloudRetriever(
    api_key=zep_api_key,
    session_id=session_id,  # 确保在实例化检索器时提供 session_id
    top_k=5,
    search_type="mmr",
    mmr_lambda=0.5,
)

await zep_retriever.ainvoke("谁写了《播种者的寓言》？")
```

### 使用元数据过滤器精炼搜索结果

Zep 支持按元数据过滤结果。这对于按实体类型或其他元数据过滤结果非常有用。

更多信息请参阅：[help.getzep.com/document-collections#searching-a-collection-with-hybrid-vector-search](https://help.getzep.com/document-collections#searching-a-collection-with-hybrid-vector-search)

```python
filter = {"where": {"jsonpath": '$[*] ? (@.baz == "qux")'}}

await zep_retriever.ainvoke(
    "谁写了《播种者的寓言》？", config={"metadata": filter}
)
```

### 对摘要进行搜索并使用 MMR 重新排序

Zep 会自动为聊天消息生成摘要。可以使用 Zep 检索器对这些摘要进行搜索。由于摘要是对对话的提炼，它们更有可能匹配您的搜索查询，并为 LLM 提供丰富、简洁的上下文。

连续的摘要可能包含相似的内容，Zep 的相似性搜索会返回匹配度最高的但多样性较差的结果。
MMR 会重新排序结果，以确保您填充到提示中的摘要既相关，又能为 LLM 提供额外信息。

```python
zep_retriever = ZepCloudRetriever(
    api_key=zep_api_key,
    session_id=session_id,  # 确保在实例化检索器时提供 session_id
    top_k=3,
    search_scope="summary",
    search_type="mmr",
    mmr_lambda=0.5,
)

await zep_retriever.ainvoke("谁写了《播种者的寓言》？")
```
