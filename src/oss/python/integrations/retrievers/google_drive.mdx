本 Notebook 介绍如何从 `Google Drive` 中检索文档。

## 前提条件 (Prerequisites)

1. 创建一个 Google Cloud 项目或使用现有项目
1. 启用 [Google Drive API](https://console.cloud.google.com/flows/enableapi?apiid=drive.googleapis.com)
1. [为桌面应用授权凭据](https://developers.google.com/drive/api/quickstart/python#authorize_credentials_for_a_desktop_application)
1. `pip install -U google-api-python-client google-auth-httplib2 google-auth-oauthlib`

## 检索 Google 文档 (Retrieve the Google Docs)

默认情况下，`GoogleDriveRetriever` 期望 `credentials.json` 文件位于 `~/.credentials/credentials.json`，但这可以通过设置环境变量 `GOOGLE_ACCOUNT_FILE` 进行配置。
`token.json` 文件会使用相同的目录（或者使用参数 `token_path`）。请注意，`token.json` 文件会在您第一次使用检索器时自动创建。

`GoogleDriveRetriever` 可以通过一些请求检索选定的文件。

默认情况下，如果您使用 `folder_id`，则可以检索该文件夹内的所有文件，并将其转换为 `Document` 对象。

您可以从 URL 中获取文件夹 ID 和文档 ID：

* 文件夹 (Folder): [drive.google.com/drive/u/0/folders/1yucgL9WGgWZdM1TOuKkeghlPizuzMYb5](https://drive.google.com/drive/u/0/folders/1yucgL9WGgWZdM1TOuKkeghlPizuzMYb5) -> 文件夹 ID 是 `"1yucgL9WGgWZdM1TOuKkeghlPizuzMYb5"`
* 文档 (Document): [docs.google.com/document/d/1bfaMQ18_i56204VaQDVeAFpqEijJTgvurupdEDiaUQw/edit](https://docs.google.com/document/d/1bfaMQ18_i56204VaQDVeAFpqEijJTgvurupdEDiaUQw/edit) -> 文档 ID 是 `"1bfaMQ18_i56204VaQDVeAFpqEijJTgvurupdEDiaUQw"`

特殊值 `root` 代表您的个人根目录（My Drive）。

```python
from langchain_googledrive.retrievers import GoogleDriveRetriever

folder_id = "root"
# folder_id='1yucgL9WGgWZdM1TOuKkeghlPizuzMYb5'

retriever = GoogleDriveRetriever(
    num_results=2,
)
```

默认情况下，具有以下 MIME 类型的*所有文件*都可以转换为 `Document` 对象。

* `text/text`
* `text/plain`
* `text/html`
* `text/csv`
* `text/markdown`
* `image/png`
* `image/jpeg`
* `application/epub+zip`
* `application/pdf`
* `application/rtf`
* `application/vnd.google-apps.document` (GDoc)
* `application/vnd.google-apps.presentation` (GSlide)
* `application/vnd.google-apps.spreadsheet` (GSheet)
* `application/vnd.google.colaboratory` (Notebook colab)
* `application/vnd.openxmlformats-officedocument.presentationml.presentation` (PPTX)
* `application/vnd.openxmlformats-officedocument.wordprocessingml.document` (DOCX)

可以更新或自定义此列表。请参阅 `GoogleDriveRetriever` 的文档。

但是，必须安装相应的包 (`unstructured`) 才能处理某些文件类型（如 PDF、PPTX 等）。

```python
pip install -qU  unstructured
```

```python
retriever.invoke("machine learning")
```

您可以自定义选择文件的标准。这里提供了一组预定义的筛选模板：

| 模板 (Template)                      | 描述 (Description)                                                           |
| --------------------------------------   | --------------------------------------------------------------------- |
| `gdrive-all-in-folder`                   | 从指定的 `folder_id` 返回所有兼容的文件 |
| `gdrive-query`                           | 在所有驱动器中搜索 `query` |
| `gdrive-by-name`                         | 通过名称 `query` 搜索文件 |
| `gdrive-query-in-folder`                 | 在 `folder_id` 中搜索 `query`（如果设置 `_recursive=true` 则包括子文件夹） |
| `gdrive-mime-type`                       | 搜索特定的 `mime_type` |
| `gdrive-mime-type-in-folder`             | 在 `folder_id` 中搜索特定的 `mime_type` |
| `gdrive-query-with-mime-type`            | 搜索符合 `query` 和特定 `mime_type` 的文件 |
| `gdrive-query-with-mime-type-and-folder` | 在 `folder_id` 中搜索符合 `query` 和特定 `mime_type` 的文件 |

```python
retriever = GoogleDriveRetriever(
    template="gdrive-query",  # 全局搜索
    num_results=2,  # 但只获取前 2 个文档
)
for doc in retriever.invoke("machine learning"):
    print("---")
    print(doc.page_content.strip()[:60] + "...")
```

另外，您可以使用专门的 `PromptTemplate` 来自定义查询提示。

```python
from langchain_core.prompts import PromptTemplate

retriever = GoogleDriveRetriever(
    template=PromptTemplate(
        input_variables=["query"],
        # 参考：https://developers.google.com/drive/api/guides/search-files
        template="(fullText contains '{query}') "
        "and mimeType='application/vnd.google-apps.document' "
        "and modifiedTime > '2000-01-01T00:00:00' "
        "and trashed=false",
    ),
    num_results=2,
    # 参考：https://developers.google.com/drive/api/v3/reference/files/list
    includeItemsFromAllDrives=False,
    supportsAllDrives=False,
)
for doc in retriever.invoke("machine learning"):
    print(f"{doc.metadata['name']}:")
    print("---")
    print(doc.page_content.strip()[:60] + "...")
```

## 使用 Google Drive 的 'description' 元数据

每个 Google Drive 文件元数据中都有一个 `description` 字段（参见*文件详情*）。
使用 `snippets` 模式可以返回所选文件的描述信息。

```python
retriever = GoogleDriveRetriever(
    template="gdrive-mime-type-in-folder",
    folder_id=folder_id,
    mime_type="application/vnd.google-apps.document",  # 仅限 Google Docs
    num_results=2,
    mode="snippets",
    includeItemsFromAllDrives=False,
    supportsAllDrives=False,
)
retriever.invoke("machine learning")
```
