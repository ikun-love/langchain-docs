title: 不透明提示 (OpaquePrompts)
---

[OpaquePrompts](https://opaqueprompts.readthedocs.io/en/latest/) 是一项服务，它使应用程序能够在不损害用户隐私的前提下，利用大型语言模型（LLM）的强大能力。OpaquePrompts 的设计注重可组合性，易于集成到现有应用程序和服务中，可以通过简单的 Python 库或 LangChain 进行使用。更重要的是，OpaquePrompts 利用了 [机密计算 (confidential computing)](https://en.wikipedia.org/wiki/Confidential_computing) 的能力，确保即使是 OpaquePrompts 服务本身也无法访问其所保护的数据。

本教程将介绍如何使用 LangChain 与 `OpaquePrompts` 进行交互。

```python
# 安装 opaqueprompts 和 langchain 软件包
pip install -qU  opaqueprompts langchain
```

访问 OpaquePrompts API 需要一个 API 密钥，您可以在 [OpaquePrompts 网站](https://opaqueprompts.opaque.co/) 上创建账户后获取。获得账户后，您可以在 [API 密钥页面](https:opaqueprompts.opaque.co/api-keys) 找到您的 API 密钥。

```python
import os

# 设置 API 密钥

os.environ["OPAQUEPROMPTS_API_KEY"] = "<OPAQUEPROMPTS_API_KEY>"
os.environ["OPENAI_API_KEY"] = "<OPENAI_API_KEY>"
```

# 使用 OpaquePrompts LLM 包装器

将 OpaquePrompts 应用到您的应用程序可能非常简单，只需使用 `OpaquePrompts` 类包装您的 LLM 即可，将 `llm=OpenAI()` 替换为 `llm=OpaquePrompts(base_llm=OpenAI())`。

```python
from langchain.chains import LLMChain
from langchain.globals import set_debug, set_verbose
from langchain.memory import ConversationBufferWindowMemory
from langchain_community.llms import OpaquePrompts
from langchain_core.callbacks import StdOutCallbackHandler
from langchain_core.prompts import PromptTemplate
from langchain_openai import OpenAI

set_debug(True)
set_verbose(True)

prompt_template = """
作为一名 AI 助手，您将根据提供的上下文来回答问题。

问题中出现的敏感个人信息已被屏蔽以保护隐私。
例如，如果原始内容是 "Giana is good"，它将被更改为 "PERSON_998 is good"。

请按如下方式处理这些更改：
* 请将这些屏蔽后的短语视为占位符，但在回答时仍需以相关方式引用它们。
* 不同的屏蔽术语可能表示相同的意思。请坚持使用给定的术语，不要修改它。
* 所有屏蔽术语都遵循 "TYPE_ID" 模式。
* 请不要编造新的屏蔽术语。例如，如果您看到 "PERSON_998"，除非它已在问题中出现，否则不要凭空创建 "PERSON_997" 或 "PERSON_999"。

对话历史: \`\`\`{history}\`\`\`
上下文 : \`\`\`在 2023 年 2 月 23 日上午 10:30 的最近会议中，John Doe 向我提供了他的个人详细信息。 他的电子邮件是 johndoe@example.com，联系电话是 650-456-7890。他住在纽约市，美国，拥有美国国籍，信仰基督教，倾向于民主党。他提到他最近使用信用卡 4111 1111 1111 1111 进行了一笔交易，并将比特币转账到了钱包地址 1A1zP1eP5QGefi2DMPTfTL5SLmv7DivfNa。在讨论他的欧洲旅行时，他记下了他的 IBAN 号码是 GB29 NWBK 6016 1331 9268 19。此外，他还提供了他的网站地址 https://johndoeportfolio.com。John 还讨论了一些与美国相关的详细信息。他说他的银行账号是 1234567890123456，驾驶证号码是 Y12345678。他的 ITIN 是 987-65-4321，他最近更新了护照，号码是 123456789。他强调不要分享他的 SSN，即 123-45-6789。此外，他还提到他通过 IP 地址 192.168.1.1 远程访问他的工作文件，并拥有医疗执照号码 MED-123456。 \`\`\`
问题: \`\`\`{question}\`\`\`

"""

chain = LLMChain(
    prompt=PromptTemplate.from_template(prompt_template),
    llm=OpaquePrompts(base_llm=OpenAI()),
    memory=ConversationBufferWindowMemory(k=2),
    verbose=True,
)


print(
    chain.run(
        {
            "question": """写一条消息提醒 John 为他的网站重置密码，以确保安全。"""
        },
        callbacks=[StdOutCallbackHandler()],
    )
)
```

从输出中，您可以看到用户输入中的以下上下文包含敏感数据。

```

```

占位符用于 LLM 的响应中。

```

```

# 在 LangChain 表达式中使用 OpaquePrompts

如果即插即用的替换方案不能提供所需的灵活性，也可以使用一些函数配合 LangChain 表达式。

```python
import langchain_community.utilities.opaqueprompts as op
from langchain_core.output_parsers import StrOutputParser
from langchain_core.runnables import RunnablePassthrough

prompt = (PromptTemplate.from_template(prompt_template),)
llm = OpenAI()
pg_chain = (
    op.sanitize
    | RunnablePassthrough.assign(
        response=(lambda x: x["sanitized_input"]) | prompt | llm | StrOutputParser(),
    )
    | (lambda x: op.desanitize(x["response"], x["secure_context"]))
)

pg_chain.invoke(
    {
        "question": "写一条短信提醒 John 通过他的电子邮件为他的网站重置密码以保持安全。",
        "history": "",
    }
)
```
