百度智能云千帆平台是面向企业开发者的**一站式大模型开发与服务运营平台**。千帆不仅提供了包括文心一言（ERNIE-Bot）及第三方开源模型在内的多种模型，还提供了各种 AI 开发工具和**全套开发环境**，从而方便客户轻松地使用和开发大模型应用。

从根本上说，这些模型被拆分成了以下类型：

- 嵌入（Embedding）
- 聊天（Chat）
- 补全（Completion）

在本 Notebook 中，我们将介绍如何将 LangChain 与 [千帆](https://cloud.baidu.com/doc/WENXINWORKSHOP/index.html) 结合使用，主要关注与 LangChain 的 `langchain/llms` 包相对应的 `Completion`（补全）功能：

## API 初始化

要使用基于百度千帆的 LLM（大语言模型）服务，您需要初始化以下参数：

您可以选择在环境变量中初始化 AK 和 SK，或者直接在代码中初始化参数：

```base
export QIANFAN_AK=XXX
export QIANFAN_SK=XXX
```

## 当前支持的模型

- ERNIE-Bot-turbo（默认模型）
- ERNIE-Bot
- BLOOMZ-7B
- Llama-2-7b-chat
- Llama-2-13b-chat
- Llama-2-70b-chat
- Qianfan-BLOOMZ-7B-compressed
- Qianfan-Chinese-Llama-2-7B
- ChatGLM2-6B-32K
- AquilaChat-7B

```python
"""基础初始化和调用"""
import os

from langchain_community.llms import QianfanLLMEndpoint

os.environ["QIANFAN_AK"] = "your_ak"
os.environ["QIANFAN_SK"] = "your_sk"

llm = QianfanLLMEndpoint(streaming=True)
res = llm.invoke("hi")
print(res)
```

## 在千帆中使用不同的模型

如果您想部署基于 EB 或多个开源模型的自定义模型，可以按照以下步骤操作：

- 1.（可选，如果模型包含在默认模型中，则跳过此步骤）在千帆控制台部署您的模型，获取您自己的定制化部署端点（deploy endpoint）。
- 2. 在初始化时设置 `endpoint` 字段：

```python
llm = QianfanLLMEndpoint(
    streaming=True,
    model="ERNIE-Bot-turbo",
    endpoint="eb-instant",
)
res = llm.invoke("hi")
```

```output
[INFO] [09-15 20:23:36] logging.py:55 [t:140708023539520]: 请求 llm api 端点: /chat/eb-instant
```

## 模型参数（Model Params）

目前，只有 `ERNIE-Bot` 和 `ERNIE-Bot-turbo` 支持以下模型参数，未来我们可能会支持更多模型。

- temperature（温度）
- top_p
- penalty_score（惩罚分数）

```python
res = llm.generate(
    prompts=["hi"],
    streaming=True,
    **{"top_p": 0.4, "temperature": 0.1, "penalty_score": 1},
)

for r in res:
    print(r)
```
