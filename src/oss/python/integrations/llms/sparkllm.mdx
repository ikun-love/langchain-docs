[SparkLLM](https://xinghuo.xfyun.cn/spark) 是科大讯飞独立研发的大规模认知模型。
它通过学习海量的文本、代码和图像内容，具备了跨领域的知识和语言理解能力。
它可以理解自然对话并根据对话内容执行任务。

## 先决条件 (Prerequisite)

- 从 [科大讯飞星火大模型 API 控制台](https://console.xfyun.cn/services/bm3) 获取 SparkLLM 的 `app_id`、`api_key` 和 `api_secret`（更多信息请参阅 [科大讯飞星火大模型介绍](https://xinghuo.xfyun.cn/sparkapi) ），然后设置环境变量 `IFLYTEK_SPARK_APP_ID`、`IFLYTEK_SPARK_API_KEY` 和 `IFLYTEK_SPARK_API_SECRET`；或者，如上一个示例所示，在创建 `ChatSparkLLM` 实例时直接传入这些参数。

## 使用 SparkLLM

```python
import os

os.environ["IFLYTEK_SPARK_APP_ID"] = "app_id"
os.environ["IFLYTEK_SPARK_API_KEY"] = "api_key"
os.environ["IFLYTEK_SPARK_API_SECRET"] = "api_secret"
```

```python
from langchain_community.llms import SparkLLM

# 加载模型
llm = SparkLLM()

res = llm.invoke("What's your name?")
print(res)
```
