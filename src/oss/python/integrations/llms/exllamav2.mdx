[ExLlamav2](https://github.com/turboderp/exllamav2) 是一个快速的推理库，用于在现代消费级 GPU 上本地运行大型语言模型（LLM）。

它支持 GPTQ 和 EXL2 量化模型的推理，这些模型可以在 [Hugging Face](https://huggingface.co/TheBloke) 上找到。

本 Colab 笔记本将介绍如何在 LangChain 内部运行 `exllamav2`。

附加信息：
[ExLlamav2 示例](https://github.com/turboderp/exllamav2/tree/master/examples)

## 安装 (Installation)

请参考官方 [文档](https://github.com/turboderp/exllamav2)。
对于本笔记本，需要的依赖项如下：

- python 3.11
- langchain 0.1.7
- CUDA: 12.1.0 (见下文)
- torch==2.1.1+cu121
- exllamav2 (0.0.12+cu121)

如果你想要安装相同版本的 exllamav2：

```shell
pip install https://github.com/turboderp/exllamav2/releases/download/v0.0.12/exllamav2-0.0.12+cu121-cp311-cp311-linux_x86_64.whl
```

如果你使用 conda，依赖项如下：

```
  - conda-forge::ninja
  - nvidia/label/cuda-12.1.0::cuda
  - conda-forge::ffmpeg
  - conda-forge::gxx=11.4
```

## 使用方法 (Usage)

由于你将在本地运行 LLM，因此不需要 `API_TOKEN`。

了解哪些模型适用于你选择的机器是非常有价值的。

[TheBloke](https://huggingface.co/TheBloke) 在 Hugging Face 上的模型有一个 `Provided files`（提供的文件）部分，这里会展示运行不同量化大小和方法的模型所需的 RAM（例如：[Mistral-7B-Instruct-v0.2-GPTQ](https://huggingface.co/TheBloke/Mistral-7B-Instruct-v0.2-GPTQ)）。

```python
import os

from huggingface_hub import snapshot_download
from langchain_community.llms.exllamav2 import ExLlamaV2
from langchain_core.callbacks import StreamingStdOutCallbackHandler
from langchain_core.prompts import PromptTemplate

from libs.langchain.langchain.chains.llm import LLMChain
```

```python
# 函数用于从 hugging face 仓库下载 gptq 模型
def download_GPTQ_model(model_name: str, models_dir: str = "./models/") -> str:
    """下载指定模型名称的 GPTQ 模型。

    参数 (Params):
    model_name: str: 要下载的模型名称（仓库名称）。示例："TheBloke/CapybaraHermes-2.5-Mistral-7B-GPTQ"
    """
    # 分割模型名称并创建目录名称。示例："TheBloke/CapybaraHermes-2.5-Mistral-7B-GPTQ" -> "TheBloke_CapybaraHermes-2.5-Mistral-7B-GPTQ"

    if not os.path.exists(models_dir):
        os.makedirs(models_dir)

    _model_name = model_name.split("/")
    _model_name = "_".join(_model_name)
    model_path = os.path.join(models_dir, _model_name)
    if _model_name not in os.listdir(models_dir):
        # 下载模型
        snapshot_download(
            repo_id=model_name, local_dir=model_path, local_dir_use_symlinks=False
        )
    else:
        print(f"{model_name} already exists in the models directory")

    return model_path
```

```python
from exllamav2.generator import (
    ExLlamaV2Sampler,
)

settings = ExLlamaV2Sampler.Settings()
settings.temperature = 0.85
settings.top_k = 50
settings.top_p = 0.8
settings.token_repetition_penalty = 1.05

# 下载 GPTQ 模型
model_path = download_GPTQ_model("TheBloke/Mistral-7B-Instruct-v0.2-GPTQ")

callbacks = [StreamingStdOutCallbackHandler()]

# 定义提示模板
template = """问题 (Question): {question}

回答 (Answer): 让我们一步一步思考 (Let's think step by step)."""

prompt = PromptTemplate(template=template, input_variables=["question"])

# verbose 必须设置为 True 才能传递给回调管理器
llm = ExLlamaV2(
    model_path=model_path,
    callbacks=callbacks,
    verbose=True,
    settings=settings,
    streaming=True,
    max_new_tokens=150,
)
llm_chain = LLMChain(prompt=prompt, llm=llm)

question = "在 iPhone 6s 发布的那一年，哪支足球队赢得了欧洲冠军联赛 (UEFA Champions League)？"

output = llm_chain.invoke({"question": question})
print(output)
```
