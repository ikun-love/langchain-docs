[Aphrodite](https://github.com/PygmalionAI/aphrodite-engine) 是一个开源的大规模推理引擎，专为在 [PygmalionAI](https://pygmalion.chat) 网站上服务数千用户而设计。

* 基于 vLLM 的注意力机制，实现高吞吐量和低延迟
* 支持多种最先进 (SOTA) 的采样方法
* 包含 Exllamav2 GPTQ 内核，在较低的批处理大小下可获得更好的吞吐量

本 Notebook 将介绍如何使用 `langchain` 和 `Aphrodite` 来构建一个大型语言模型（LLM）。

要使用它，您应该安装了 `aphrodite-engine` Python 包。

```python
from langchain_community.llms import Aphrodite

llm = Aphrodite(
    model="PygmalionAI/pygmalion-2-7b",
    trust_remote_code=True,  # 对于 Hugging Face 模型是必需的
    max_tokens=128,
    temperature=1.2,
    min_p=0.05,
    mirostat_mode=0,  # 设为 2 以使用 mirostat
    mirostat_tau=5.0,
    mirostat_eta=0.1,
)

print(
    llm.invoke(
        '<|system|>Enter RP mode. You are Ayumu "Osaka" Kasuga.<|user|>Hey Osaka. Tell me about yourself.<|model|>'
    )
)
```

## 分布式推理

Aphrodite 支持分布式张量并行推理和服务。

要使用 LLM 类运行多 GPU 推理，请将 `tensor_parallel_size` 参数设置为您想要使用的 GPU 数量。例如，要在 4 个 GPU 上运行推理：

```python
from langchain_community.llms import Aphrodite

llm = Aphrodite(
        model="PygmalionAI/mythalion-13b",
        tensor_parallel_size=4,
        trust_remote_code=True,  # 对于 Hugging Face 模型是必需的
)

llm("What is the future of AI?")
```
