## 概述

`InMemoryByteStore` 是 `ByteStore` 的一个**非持久化**实现，它将所有数据存储在 Python 字典中。它主要适用于演示场景，或者在 Python 进程生命周期内不需要数据持久化的场景。

### 安装

LangChain 的 `InMemoryByteStore` 集成位于 `langchain-core` 包中：

```python
pip install -qU langchain-core
```

## 实例化

现在您可以实例化您的字节存储：

```python
from langchain_core.stores import InMemoryByteStore

kv_store = InMemoryByteStore()
```

## 用法

您可以使用 `mset` 方法在键下设置数据，如下所示：

```python
kv_store.mset(
    [
        ["key1", b"value1"],
        ["key2", b"value2"],
    ]
)

kv_store.mget(
    [
        "key1",
        "key2",
    ]
)
```

```output
[b'value1', b'value2']
```

您还可以使用 `mdelete` 方法删除数据：

```python
kv_store.mdelete(
    [
        "key1",
        "key2",
    ]
)

kv_store.mget(
    [
        "key1",
        "key2",
    ]
)
```

```output
[None, None]
```
