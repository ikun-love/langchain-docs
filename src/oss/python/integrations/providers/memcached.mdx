> [Memcached](https://www.memcached.org/) 是一个免费且开源的高性能、分布式内存对象缓存系统，它本质上是通用的，但旨在通过减轻数据库负载来加速动态 Web 应用程序。

本页面介绍如何将 Memcached 与 LangChain 结合使用，使用 [pymemcache](https://github.com/pinterest/pymemcache) 客户端连接到已在运行的 Memcached 实例。

## 安装和设置

<CodeGroup>
```bash pip
pip install pymemcache
```

```bash uv
uv add pymemcache
```
</CodeGroup>

## LLM 缓存

要在应用程序中集成 Memcached 缓存：
```python3
from langchain.globals import set_llm_cache
from langchain_openai import OpenAI

from langchain_community.cache import MemcachedCache
from pymemcache.client.base import Client

llm = OpenAI(model="gpt-3.5-turbo-instruct", n=2, best_of=2)
set_llm_cache(MemcachedCache(Client('localhost')))

# 第一次调用时，结果不在缓存中，因此耗时会稍长
llm.invoke("Which city is the most crowded city in the USA?")

# 第二次调用时，结果已在缓存中，因此速度会更快
llm.invoke("Which city is the most crowded city in the USA?")
```
