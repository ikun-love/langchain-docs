>[Zilliz Cloud](https://zilliz.com/doc/quick_start) 是一个完全托管的云服务，用于部署 `LF AI Milvus®`。

## 安装和设置 (Installation and Setup)

安装 Python SDK：
<CodeGroup>
```bash pip
pip install pymilvus
```

```bash uv
uv add pymilvus
```
</CodeGroup>

## 向量存储 (Vectorstore)

一个围绕 Zilliz 索引的封装器，允许您将其用作向量存储（vectorstore），无论用于语义搜索还是示例选择。

```python
from langchain_community.vectorstores import Milvus
```

有关 Milvus 封装器的更详细演练，请参阅[此笔记本](/oss/integrations/vectorstores/zilliz)。
