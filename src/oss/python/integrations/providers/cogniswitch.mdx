>[CogniSwitch](https://www.cogniswitch.ai/aboutus) 是一个基于 API 的数据平台。它通过提取实体（entities）、概念（concepts）及其关系（relationships）来增强企业数据，进而将这些数据转换为多维格式，并存储在能够容纳这些增强信息的数据库中。在我们的场景中，数据是存储在知识图谱（knowledge graph）中的。这样增强后的数据就可以被 LLM 和其他 GenAI 应用消费，确保数据是可用的，并且上下文信息可以得到维护，从而消除“幻觉”（hallucinations），保证输出的准确性。

## 工具包 (Toolkit)

参见 [安装说明和使用示例](/oss/integrations/tools/cogniswitch)。

```python
from langchain_community.agent_toolkits import CogniswitchToolkit
```
