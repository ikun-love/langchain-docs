>[Chaindesk](https://chaindesk.ai) 是一个[开源](https://github.com/gmpetrov/databerry)文档检索平台，它能帮助您将个人数据与大型语言模型（LLM）连接起来。

## 安装与设置

您需要注册 Chaindesk 账户，创建一个数据存储（datastore），添加相关数据，并获取您的数据存储 API 端点 URL。
您还需要 [API 密钥](https://docs.chaindesk.ai/api-reference/authentication)。

## 检索器 (Retriever)

请参阅[使用示例](/oss/integrations/retrievers/chaindesk)。

```python
from langchain_classic.retrievers import ChaindeskRetriever
```
