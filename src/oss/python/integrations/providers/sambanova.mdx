客户正在转向 [SambaNova](https://sambanova.ai/) 来快速部署最先进的人工智能能力，从而获得竞争优势。我们专为企业级规模构建的 AI 平台是下一代 AI 计算的技术支柱。我们赋能基础模型，从而释放数据中蕴藏的宝贵业务洞察。

SambaNova RDU（计算单元）专为 AI 设计，采用了革命性的数据流（dataflow）架构。与 GPU 相比，这种设计使得 RDU 在处理这些工作负载时效率更高，因为它消除了对内存的冗余调用——而内存调用是 GPU 运行机制中固有的局限性。这种内置的效率是 RDU 能够在更小尺寸（footprint）内实现比 GPU 高得多的性能的关键特性之一。

在我们架构的基础上，我们开发了一些平台，使公司和开发人员能够充分利用 RDU 处理器和开源模型的能力。

## API 密钥

将其 API 密钥设置为环境变量：

如果您是 SambaCloud 用户，请申请一个 [API 密钥](http://cloud.sambanova.ai/apis?utm_source=langchain&utm_medium=external&utm_campaign=cloud_signup)，并将其设置为环境变量：

```bash
export SAMBANOVA_API_KEY="your-sambacloud-api-key-here"
```

如果您是 SambaStack 用户，请设置您的基础 URL 和 API 密钥作为环境变量：

```bash
export SAMBANOVA_API_BASE="your-sambastack-envirronment-base-url-here"
export SAMBANOVA_API_KEY="your-sambastack-api-key-here"
```
