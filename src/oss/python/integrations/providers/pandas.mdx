>[pandas](https://pandas.pydata.org) 是一个快速、强大、灵活且易于使用的开源数据分析和处理工具，它构建在 `Python` 编程语言之上。

## 安装和设置

使用 `pip` 安装 `pandas` 包：

<CodeGroup>
```bash pip
pip install pandas
```

```bash uv
uv add pandas
```
</CodeGroup>
