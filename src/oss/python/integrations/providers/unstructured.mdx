> `unstructured` 包来自 [Unstructured.IO](https://www.unstructured.io/)，它可以从原始源文档（如 PDF 和 Word 文档）中提取干净的文本。
本文档介绍如何在 LangChain 中使用 [`unstructured`](https://github.com/Unstructured-IO/unstructured) 生态系统。

## 安装与设置

如果您正在使用在本地运行的加载器（Loader），请按照以下步骤设置 `unstructured` 及其依赖项。

- 为了获得最小的安装占位符，并利用开源 `unstructured` 包中不提供的功能，请使用 `pip install unstructured-client` 安装 Python SDK，同时安装 `pip install langchain-unstructured` 以使用 `UnstructuredLoader` 对 Unstructured API 进行远程分区（partitioning）。这个加载器位于 LangChain 的合作伙伴仓库中，而不是 `langchain-community` 仓库中，您需要一个 `api_key`，您可以在 [此处](https://unstructured.io/api-key/) 免费生成密钥。
    - Unstructured 的 SDK 文档可在此处找到：
      https://docs.unstructured.io/api-reference/api-services/sdk

- 要在本地运行所有功能，请使用 `pip install unstructured` 安装开源 Python 包，同时安装 `pip install langchain-community`，并使用上面提到的相同的 `UnstructuredLoader`。
    - 您可以使用 extras 安装特定文档的依赖项，例如 `pip install "unstructured[docx]"`。有关 extras 的更多信息，请参阅 [此处](https://docs.unstructured.io/open-source/installation/full-installation)。
    - 要安装所有文档类型的依赖项，请使用 `pip install "unstructured[all-docs]"`。
- 如果您的系统尚未安装以下系统依赖项（例如在 Mac 上使用 `brew install`），请安装它们。
  根据您解析的文档类型，您可能不需要所有这些依赖项。
    - `libmagic-dev` (文件类型检测)
    - `poppler-utils` (图像和 PDF)
    - `tesseract-ocr` (图像和 PDF)
    - `qpdf` (PDF)
    - `libreoffice` (MS Office 文档)
    - `pandoc` (EPUBs)
- 在本地运行时，Unstructured 也推荐通过 [遵循此指南](https://docs.unstructured.io/open-source/installation/docker-installation) 使用 Docker，以确保所有系统依赖项都已正确安装。

Unstructured API 需要 API 密钥才能发起请求。
您可以 [此处](https://unstructured.io/api-key-hosted) 申请 API 密钥，并立即开始使用！
查看 [此处](https://github.com/Unstructured-IO/unstructured-api) 的 README 以开始发起 API 调用。
我们非常欢迎您的反馈，请在我们的 [社区 Slack](https://join.slack.com/t/unstructuredw-kbe4326/shared_invite/zt-1x7cgo0pg-PTptXWylzPQF9xZolzCnwQ) 频道中告诉我们您的使用体验。
请继续关注质量和性能的改进！
如果您想自托管 Unstructured API 或在本地运行它，请查看 [此处](https://github.com/Unstructured-IO/unstructured-api#dizzy-instructions-for-using-the-docker-image) 的说明。


## 数据加载器 (Data Loaders)

`Unstructured` 的主要用途是在数据加载器中。

### UnstructuredLoader

请参阅 [使用示例](/oss/integrations/document_loaders/unstructured_file)，了解如何将此加载器用于本地分区和使用无服务器 Unstructured API 进行远程分区。

```python
from langchain_unstructured import UnstructuredLoader
```

### UnstructuredCHMLoader

`CHM` 代表 `Microsoft Compiled HTML Help`（微软编译的 HTML 帮助文件）。

```python
from langchain_community.document_loaders import UnstructuredCHMLoader
```

### UnstructuredCSVLoader

`逗号分隔值` (`CSV`) 文件是一种定界文本文件，它使用逗号来分隔值。文件的每一行都是一条数据记录。
每条记录由一个或多个字段组成，字段之间用逗号分隔。

请参阅 [使用示例](/oss/integrations/document_loaders/csv#unstructuredcsvloader)。

```python
from langchain_community.document_loaders import UnstructuredCSVLoader
```

### UnstructuredEmailLoader

### UnstructuredEPubLoader

请参阅 [使用示例](/oss/integrations/document_loaders/epub)。
