> [CnosDB](https://github.com/cnosdb/cnosdb) 是一个开源的分布式时序数据库，它具有高性能、高压缩率和高易用性。

## 安装和设置

```python
pip install cnos-connector
```

## 连接到 CnosDB
您可以使用 `SQLDatabase.from_cnosdb()` 方法连接到 CnosDB。
### 语法
```python
def SQLDatabase.from_cnosdb(url: str = "127.0.0.1:8902",
                              user: str = "root",
                              password: str = "",
                              tenant: str = "cnosdb",
                              database: str = "public")
```
参数 (Args):
1. url (str): CnosDB 服务的 HTTP 连接主机名和端口号。**不包含** "http://" 或 "https://" 前缀。默认值为 `"127.0.0.1:8902"`。
2. user (str): 用于连接到 CnosDB 服务的用户名。默认值为 `"root"`。
3. password (str): 连接到 CnosDB 服务的用户密码。默认值为 `""`。
4. tenant (str): 用于连接到 CnosDB 服务的租户 (tenant) 名称。默认值为 `"cnosdb"`。
5. database (str): CnosDB 租户中的数据库名称。
## 示例
```python
# 使用 SQLDatabase 包装器连接到 CnosDB
from langchain_community.utilities import SQLDatabase

db = SQLDatabase.from_cnosdb()
```
```python
# 创建一个 OpenAI Chat LLM 包装器
from langchain_openai import ChatOpenAI

llm = ChatOpenAI(temperature=0, model_name="gpt-3.5-turbo")
```

### SQL 数据库链 (SQL Database Chain)
此示例演示如何使用 SQL Chain 对 CnosDB 上的数据回答问题。
```python
from langchain_community.utilities import SQLDatabaseChain

db_chain = SQLDatabaseChain.from_llm(llm, db, verbose=True)

db_chain.run(
    "What is the average temperature of air at station XiaoMaiDao between October 19, 2022 and Occtober 20, 2022?"
)
```

### SQL 数据库代理 (SQL Database Agent)
此示例演示如何使用 SQL Database Agent 对 CnosDB 上的数据回答问题。
```python
from langchain.agents import create_sql_agent
from langchain_community.agent_toolkits import SQLDatabaseToolkit

toolkit = SQLDatabaseToolkit(db=db, llm=llm)
agent = create_sql_agent(llm=llm, toolkit=toolkit, verbose=True)
```
```python
agent.run(
    "What is the average temperature of air at station XiaoMaiDao between October 19, 2022 and Occtober 20, 2022?"
```
