> 什么是 `Timbr`？

>- Timbr 是一个**语义 SQL 知识图谱平台**（semantic SQL knowledge graph platform），专注于通过本体驱动的语义层来连接数据。
>- Timbr 允许您使用对业务友好的语言来表示和查询数据，使其非常适合处理复杂的数据关系和业务逻辑。
>- Timbr 提供**自然语言转 SQL**（natural language to SQL）功能，使您能够轻松地使用纯英文查询与数据进行交互。
>- 使用 Timbr，您可以实现高性能的**语义数据查询**（semantic data querying），适用于生产级别的分析和商业智能（BI）。

> 开始使用 Timbr，请访问[其官方网站](https://docs.timbr.ai/doc/docs/getting-started/intro-timbr/)。

## 安装和设置 (Installation and Setup)

- 使用 `pip install langchain-timbr` 安装 Python SDK

### 可选：安装并指定 LLM 提供商

选择以下之一：openai, anthropic, google, azure\_openai, snowflake, databricks, vertex\_ai（或 'all'）

```bash
pip install 'langchain-timbr[<您选择的提供商，用逗号分隔，无空格>]'
```

## 语义 SQL 查询 (Semantic SQL Queries)

Timbr 提供了对其语义层的封装，该层可以根据自然语言输入生成 SQL 语句，并从您的知识图谱中检索相关信息。

```python
from langchain_timbr import create_timbr_sql_agent, ExecuteTimbrQueryChain, GenerateTimbrSqlChain
```

请参阅[使用示例](/oss/integrations/graphs/timbr)
