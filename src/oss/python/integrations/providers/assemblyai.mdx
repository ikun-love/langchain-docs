>[AssemblyAI](https://www.assemblyai.com/) 构建用于语音转文本、说话人分离、语音摘要等任务的 `Speech AI`（语音人工智能）模型。
> `AssemblyAI` 的语音 AI 模型包括针对语音数据（如通话、虚拟会议和播客）的高精度语音转文本、说话人检测、情感分析、章节检测以及个人身份信息（PII）的移除/屏蔽能力。

## 安装与设置

获取您的 [API Key](https://www.assemblyai.com/dashboard/signup)。

安装 `assemblyai` 包。

<CodeGroup>
```bash pip
pip install -U assemblyai
```

```bash uv
uv add assemblyai
```
</CodeGroup>

## 文档加载器（Document Loader）

### AssemblyAI 音频转录 (AssemblyAI Audio Transcript)

`AssemblyAIAudioTranscriptLoader` 使用 **AssemblyAI API** 对音频文件进行转录，并将转录后的文本加载到文档中。

参阅 [使用示例](/oss/integrations/document_loaders/assemblyai)。

```python
from langchain_community.document_loaders import AssemblyAIAudioTranscriptLoader
```

### AssemblyAI 基于 ID 的音频加载器 (AssemblyAI Audio Loader By Id)

`AssemblyAIAudioLoaderById` 使用 AssemblyAI API 获取**已存在的**转录结果，并根据指定的格式，将转录后的文本加载到一个或多个 `Document` 对象中。

```python
from langchain_community.document_loaders import AssemblyAIAudioLoaderById
```
