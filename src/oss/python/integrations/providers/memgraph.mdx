>Memgraph 是一个高性能的、内存中的图数据库，它针对实时查询和分析进行了优化。
>要开始使用 Memgraph，请访问 [其官网](https://memgraph.com/)。

## 安装和设置

- 使用 `pip install langchain-memgraph` 安装 Python SDK

## MemgraphQAChain

这里有一个围绕 Memgraph 图数据库的包装器，它允许你根据用户输入生成 Cypher 语句，并使用这些语句从数据库中检索相关信息。

```python
from langchain_memgraph.chains.graph_qa import MemgraphQAChain
from langchain_memgraph.graphs.memgraph import MemgraphLangChain
```

查看 [使用示例](/oss/integrations/graphs/memgraph)

## 从非结构化数据构建知识图谱

你可以使用此集成从非结构化数据构建知识图谱。

```python
from langchain_memgraph.graphs.memgraph import MemgraphLangChain
from langchain_experimental.graph_transformers import LLMGraphTransformer
```

查看 [使用示例](/oss/integrations/graphs/memgraph)

## Memgraph 工具和工具包 (Toolkit)

Memgraph 还提供了一个工具包，允许你与 Memgraph 数据库进行交互。
查看 [使用示例](/oss/integrations/tools/memgraph)。

```python
from langchain_memgraph import MemgraphToolkit
```
