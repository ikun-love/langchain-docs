[Dappier](https://dappier.com) 将任何 LLM 或您的 Agentic AI 连接到来自受信任来源的实时、已获授权、专有数据，使您的 AI 成为任何领域的专家。我们专门的模型包括实时网络搜索、新闻、体育、金融股票市场数据、加密货币数据以及来自高级出版商的独家内容。请访问 [marketplace.dappier.com](https://marketplace.dappier.com) 探索我们市场中广泛的数据模型。

[Dappier](https://dappier.com) 提供丰富、即时可用的、与上下文相关的（contextually relevant）数据字符串，这些数据经过优化，可与 LangChain 无缝集成。无论您是构建对话式 AI、推荐引擎还是智能搜索，Dappier 与 LLM 无关（LLM-agnostic）的 RAG 模型都能确保您的 AI 能够访问经过验证的最新数据——而无需处理构建和管理自己的检索管道的复杂性。

## 安装和设置

安装 `langchain-dappier` 并设置环境变量 `DAPPIER_API_KEY`。

<CodeGroup>
```bash pip
pip install -U langchain-dappier
export DAPPIER_API_KEY="your-api-key"
```

```bash uv
uv add langchain-dappier
export DAPPIER_API_KEY="your-api-key"
```
</CodeGroup>

我们还需要设置 Dappier API 凭据，这些凭据可以在 [Dappier 网站](https://platform.dappier.com/profile/api-keys)上生成。

通过访问 [Dappier 市场](https://platform.dappier.com/marketplace)，我们可以找到受支持的数据模型。
