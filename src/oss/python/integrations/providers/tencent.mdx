## 文档加载器 (Document Loaders)

### 腾讯 COS

>[腾讯云对象存储 (COS)](https://www.tencentcloud.com/products/cos) 是一种分布式存储服务，允许用户通过 HTTP/HTTPS 协议存储任意数量、任意地点的海量数据。`COS` 对数据结构或格式没有限制，并且没有存储桶大小限制和分区管理限制，因此适用于几乎所有用例，例如数据分发、数据处理和数据湖。COS 提供了基于 Web 的控制台、多语言 SDK 和 API、命令行工具以及图形工具。它与 Amazon S3 API 兼容，使用户能够快速访问社区工具和插件。

安装 Python SDK：

<CodeGroup>
```bash pip
pip install cos-python-sdk-v5
```

```bash uv
uv add cos-python-sdk-v5
```
</CodeGroup>

## 向量存储 (Vector Store)

### 腾讯 VectorDB

>[腾讯云 VectorDB](https://www.tencentcloud.com/products/vdb) 是一种全托管的自研企业级分布式数据库服务，专门用于存储、检索和分析多维向量数据。该数据库支持多种索引类型和相似度计算方法，单个索引支持 10 亿级向量、百万级 QPS 和毫秒级的查询延迟。`Tencent Cloud Vector Database` 不仅可以为大模型提供外部知识库以提高回答的准确性，还可广泛应用于推荐系统、自然语言处理 (NLP) 服务、计算机视觉和智能客服等人工智能领域。

安装 Python SDK：

<CodeGroup>
```bash pip
pip install tcvectordb
```

```bash uv
uv add tcvectordb
```
</CodeGroup>

更多信息请参阅 [此 Notebook](/oss/integrations/vectorstores/tencentvectordb)
