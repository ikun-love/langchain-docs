> [AwaDB](https://github.com/awa-ai/awadb) 是一个原生 AI 数据库，用于存储和检索由 LLM（大语言模型）应用程序使用的嵌入向量。

## 安装与设置

```bash
pip install awadb
```

## 向量存储 (Vector Store)

```python
from langchain_community.vectorstores import AwaDB
```

请参阅[使用示例](/oss/integrations/vectorstores/awadb)。

## 嵌入模型 (Embedding Models)

```python
from langchain_community.embeddings import AwaEmbeddings
```

请参阅[使用示例](/oss/integrations/text_embedding/awadb)。
```
