> [Beautiful Soup](https://www.crummy.com/software/BeautifulSoup/) 是一个 Python 包，用于解析 HTML 和 XML 文档（包括处理格式不规范的标记，即标签不闭合的情况，因此得名“标签汤”）。它会为解析后的页面创建一个解析树，可用于从 HTML 中提取数据，[3] 这对于网络抓取（web scraping）非常有用。

## 安装与设置

<CodeGroup>
```bash pip
pip install beautifulsoup4
```

```bash uv
uv add beautifulsoup4
```
</CodeGroup>
