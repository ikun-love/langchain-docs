本文档介绍如何使用 [Yeager.ai](https://yeager.ai) 来生成 LangChain 的工具（Tools）和智能体（Agents）。

## 什么是 Yeager.ai？
Yeager.ai 是一个旨在简化创建 AI 智能体和工具流程的生态系统。

它包含 yAgents，一个**无需代码**的 LangChain 智能体构建器。这使用户能够轻松地构建、测试和部署 AI 解决方案。通过利用 LangChain 框架，yAgents 实现了与各种语言模型和资源的无缝集成，使其适用于不同应用场景下的开发者、研究人员和 AI 爱好者。

## yAgents
一个低代码（Low code）的生成式智能体，旨在帮助您轻松构建、原型设计和部署 LangChain 工具。

### 如何使用？

pip install yeagerai-agent
yeagerai-agent

yeagerai-agent

这将安装必要的依赖项并在您的系统上设置好 yAgents。首次运行后，yAgents 会创建一个 `.env` 文件，您可以在其中输入您的 OpenAI API 密钥。您也可以直接在 Gradio 界面的 "Settings" 选项卡中进行相同的操作。

`OPENAI_API_KEY=<your_openai_api_key_here>`

我们推荐使用 GPT-4，但如果问题被充分分解，该工具也可以与 GPT-3 配合工作。

### 使用 yAgents 创建和执行工具
yAgents 使创建和执行 AI 驱动的工具变得非常简单。以下是该过程的简要概述：
1. **创建工具 (Create a tool)**：要创建工具，请向 yAgents 提供一个自然语言提示（Prompt）。该提示应清晰描述工具的目的和功能。例如：
`create a tool that returns the n-th prime number` （创建一个返回第 n 个素数的工具）

2. **将工具加载到工具集中 (Load the tool into the toolkit)**：要将工具加载到 yAgents 中，只需向 yAgents 发出明确的指令即可。例如：
`load the tool that you just created it into your toolkit` （将您刚刚创建的工具加载到您的工具集中）

3. **执行工具 (Execute the tool)**：要运行工具或智能体，只需向 yAgents 提供一条包含工具名称和任何必需参数的命令即可。例如：
`generate the 50th prime number` （生成第 50 个素数）

您可以在 [此处](https://www.youtube.com/watch?v=KA5hCM3RaWE) 观看演示 yAgents 工作原理的视频。

随着您对 yAgents 越来越熟悉，您可以创建更高级的工具和智能体，以实现工作自动化并提高您的生产力。
