> [Forefront AI](https://forefront.ai/) 是一个平台，使您能够对开源文本生成模型进行微调（fine-tune）和推理（inference）。

## 安装与设置

您需要通过访问 [此页面](https://accounts.forefront.ai/sign-in?redirect_url=https%3A%2F%2Fforefront.ai%2Fapp%2Fapi-keys) 获取 `ForefrontAI` API 密钥，并将其设置为环境变量（`FOREFRONTAI_API_KEY`）。

## 大型语言模型 (LLM)

请参阅 [使用示例](/oss/integrations/llms/forefrontai)。

```python
from langchain_community.llms import ForefrontAI
```
