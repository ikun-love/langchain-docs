>[Dedoc](https://dedoc.readthedocs.io) 是一个 [开源](https://github.com/ispras/dedoc) 库/服务，它可以从各种格式的文件中提取文本、表格、附件以及文档结构（例如标题、列表项等）。

`Dedoc` 支持 `DOCX`、`XLSX`、`PPTX`、`EML`、`HTML`、`PDF`、图像文件等多种格式。完整的支持格式列表可以在[这里](https://dedoc.readthedocs.io/en/latest/#id1)找到。

## 安装和设置

### Dedoc 库

您可以使用 `pip` 来安装 `Dedoc`。
在这种情况下，您需要安装依赖项，请访问[此处](https://dedoc.readthedocs.io/en/latest/getting_started/installation.html)以获取更多信息。

<CodeGroup>
```bash pip
pip install dedoc
```

```bash uv
uv add dedoc
```
</CodeGroup>

### Dedoc API

如果您打算使用 `Dedoc` API，则无需安装 `dedoc` 库。
在这种情况下，您应该运行 `Dedoc` 服务，例如使用 `Docker` 容器（请参阅[文档](https://dedoc.readthedocs.io/en/latest/getting_started/installation.html#install-and-run-dedoc-using-docker)以获取更多详细信息）：

```bash
docker pull dedocproject/dedoc
docker run -p 1231:1231
```

## 文档加载器 (Document Loader)

* 要处理 `Dedoc` 支持的任何格式的文件，您可以使用 `DedocFileLoader`：

    ```python
    from langchain_community.document_loaders import DedocFileLoader
    ```

* 要处理（带或不带文本层的）PDF 文件，您可以使用 `DedocPDFLoader`：

    ```python
    from langchain_community.document_loaders import DedocPDFLoader
    ```

* 要在不安装库的情况下处理任何格式的文件，您可以使用带有 `DedocAPIFileLoader` 的 `Dedoc API`：

    ```python
    from langchain_community.document_loaders import DedocAPIFileLoader
    ```

请参阅[使用示例](/oss/integrations/document_loaders/dedoc)以获取更多详细信息。
