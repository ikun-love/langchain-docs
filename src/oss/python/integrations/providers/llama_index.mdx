>[LlamaIndex](https://www.llamaindex.ai/) 是用于构建 LLM 应用的领先数据框架。

## 安装和设置 (Installation and Setup)

你需要安装 `llama-index` Python 包。

<CodeGroup>
```bash pip
pip install llama-index
```

```bash uv
uv add llama-index
```
</CodeGroup>

请参阅 [安装指南](https://docs.llamaindex.ai/en/stable/getting_started/installation/) 了解更多详情。

## 检索器 (Retrievers)

### LlamaIndexRetriever

>它用于在 LlamaIndex 数据结构上进行带源引用的问答。

```python
from langchain_community.retrievers.llama_index import LlamaIndexRetriever
```

### LlamaIndexGraphRetriever

>它用于在 LlamaIndex 图（Graph）数据结构上进行带源引用的问答。

```python
from langchain_community.retrievers.llama_index import LlamaIndexGraphRetriever
```
