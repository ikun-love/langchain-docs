> [Qdrant](https://qdrant.tech/documentation/)（读作 quadrant，象限）是一个向量相似性搜索引擎。
> 它提供了一个生产就绪的服务，带有便捷的 API，用于存储、搜索和管理（包含附加 Payload 的）点（即向量）。`Qdrant` 专为扩展的过滤支持而定制。

## 安装和设置

安装 Python 客户端包：

<CodeGroup>
```bash pip
pip install langchain-qdrant
```

```bash uv
uv add langchain-qdrant
```
</CodeGroup>

## 嵌入模型 (Embedding Models)

### FastEmbedSparse

```python
from langchain_qdrant import FastEmbedSparse
```

### SparseEmbeddings

```python
from langchain_qdrant import SparseEmbeddings
```

## 向量存储 (Vector Store)

`Qdrant` 索引周围存在一个封装层，允许您将其用作向量存储（vectorstore），无论是用于语义搜索还是示例选择。

导入此向量存储：
```python
from langchain_qdrant import QdrantVectorStore
```

有关 Qdrant 封装层的更详细演练（Walkthrough），请参阅[此笔记本](/oss/integrations/vectorstores/qdrant)。
