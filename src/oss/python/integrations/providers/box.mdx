*   促进协作

# langchain-box

此软件包包含 LangChain 与 Box 的集成。有关 Box 的更多信息，请查阅我们的 [开发者文档](https://developer.box.com)。

## 先决条件

为了与 Box 集成，您需要准备以下几项：

*   一个 Box 实例 — 如果您还不是 Box 客户，请注册一个 [免费开发者账户](https://account.box.com/signup/n/developer#ty9l3)。
*   一个 Box 应用 — 更多关于如何 [创建应用](https://developer.box.com/guides/getting-started/first-application/) 的信息。
*   您的应用在您的 Box 实例中获得批准 — 这由您的管理员完成。好消息是，如果您使用的是免费开发者账户，那么您就是管理员。请[批准您的应用](https://developer.box.com/guides/authorization/custom-app-approval/#manual-approval)。

## 身份验证

`box-langchain` 包在身份验证方面提供了一定的灵活性。最基本的身份验证方法是使用开发人员令牌（developer token）。此令牌可以在 [Box 开发者控制台](https://account.box.com/developers/console) 的配置屏幕上找到。此令牌故意设计为短期有效（1 小时），仅供开发使用。使用此令牌，您可以将其作为 `BOX_DEVELOPER_TOKEN` 添加到您的环境中，可以直接将其传递给加载器，也可以使用 `BoxAuth` 身份验证辅助类。

我们将在下面的部分中介绍如何直接将令牌传递给加载器。

### BoxAuth 辅助类

`BoxAuth` 支持以下身份验证方法：

*   `Token` — 开发者令牌或通过 Box SDK 生成的任何令牌
*   使用服务账户的 JWT
*   使用指定用户的 JWT
*   使用服务账户的 CCG
*   使用指定用户的 CCG

<Note>
**如果使用 JWT 身份验证，您需要在生成公钥/私钥对后从 Box**

开发者控制台下载配置文件。将此文件放在应用程序目录结构中的某个位置。在使用 `BoxAuth` 辅助类时，您将使用此文件的路径。
</Note>

有关更多信息，请学习如何[设置 Box 应用程序](https://developer.box.com/guides/getting-started/first-application/)，并查看[Box 身份验证指南](https://developer.box.com/guides/authentication/select/)，了解有关我们不同身份验证选项的更多信息。

示例：

**令牌 (Token)**

```python
from langchain_box.document_loaders import BoxLoader
from langchain_box.utilities import BoxAuth, BoxAuthType

auth = BoxAuth(
    auth_type=BoxAuthType.TOKEN,
    box_developer_token=box_developer_token
)

loader = BoxLoader(
    box_auth=auth,
    ...
)
```

**使用服务账户的 JWT**

```python
from langchain_box.document_loaders import BoxLoader
from langchain_box.utilities import BoxAuth, BoxAuthType

auth = BoxAuth(
    auth_type=BoxAuthType.JWT,
    box_jwt_path=box_jwt_path
)

loader = BoxLoader(
    box_auth=auth,
    ...
```

**使用指定用户的 JWT**

```python
from langchain_box.document_loaders import BoxLoader
from langchain_box.utilities import BoxAuth, BoxAuthType

auth = BoxAuth(
    auth_type=BoxAuthType.JWT,
    box_jwt_path=box_jwt_path,
    box_user_id=box_user_id
)

loader = BoxLoader(
    box_auth=auth,
    ...
```

**使用服务账户的 CCG**

```python
from langchain_box.document_loaders import BoxLoader
from langchain_box.utilities import BoxAuth, BoxAuthType

auth = BoxAuth(
    auth_type=BoxAuthType.CCG,
    box_client_id=box_client_id,
    box_client_secret=box_client_secret,
    box_enterprise_id=box_enterprise_id
)

loader = BoxLoader(
    box_auth=auth,
    ...
```

**使用指定用户的 CCG**

```python
from langchain_box.document_loaders import BoxLoader
from langchain_box.utilities import BoxAuth, BoxAuthType

auth = BoxAuth(
    auth_type=BoxAuthType.CCG,
    box_client_id=box_client_id,
    box_client_secret=box_client_secret,
    box_user_id=box_user_id
)

loader = BoxLoader(
    box_auth=auth,
    ...
```

如果您希望使用 OAuth2 配合 `authorization_code` 流程，请使用 `BoxAuthType.TOKEN` 并提供您已获取的令牌。
