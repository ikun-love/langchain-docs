本页面介绍了所有 LangChain 与 [Parallel](https://platform.parallel.ai/) 的集成。

## 安装与设置

`Parallel` 集成存在于其独立的[合作伙伴包](https://pypi.org/project/langchain-parallel/)中。您可以使用以下命令安装它：

<CodeGroup>
    ```bash pip
    pip install -qU langchain-parallel
    ```
    ```bash uv
    uv add langchain-parallel
    ```
</CodeGroup>

为了使用该包，您还需要将环境变量 `PARALLEL_API_KEY` 设置为您在 Parallel 获取的 API 密钥。您可以通过[在 Parallel 注册](https://platform.parallel.ai)来获取 API 密钥。
