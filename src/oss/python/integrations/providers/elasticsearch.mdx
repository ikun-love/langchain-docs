> [Elasticsearch](https://www.elastic.co/elasticsearch/) 是一个分布式、RESTful 的搜索和分析引擎。
> 它提供了一个分布式的、支持多租户的全文本搜索引擎，带有一个 HTTP Web 接口和无模式（schema-free）的 JSON 文档。

## 安装与设置 (Installation and Setup)

### 设置 Elasticsearch (Setup Elasticsearch)

启动 Elasticsearch 有两种方式：

#### 通过 Docker 在本地机器上安装 Elasticsearch

示例：通过运行一个禁用了安全特性的单节点 Elasticsearch 实例。
**注意：不推荐在生产环境中使用此配置。**

```bash
    docker run -p 9200:9200 -e "discovery.type=single-node" -e "xpack.security.enabled=false" -e "xpack.security.http.ssl.enabled=false" docker.elastic.co/elasticsearch/elasticsearch:8.9.0
```

#### 在 Elastic Cloud 上部署 Elasticsearch

`Elastic Cloud` 是一个托管式（managed）的 Elasticsearch 服务。请注册 [免费试用](https://cloud.elastic.co/registration?utm_source=langchain&utm_content=documentation)。

### 安装客户端 (Install Client)

<CodeGroup>
```bash pip
pip install elasticsearch
pip install langchain-elasticsearch
```

```bash uv
uv add elasticsearch
uv add langchain-elasticsearch
```
</CodeGroup>
