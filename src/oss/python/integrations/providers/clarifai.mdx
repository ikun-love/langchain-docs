>[Clarifai](https://clarifai.com) 是最早的深度学习平台之一，成立于 2013 年。Clarifai 提供了一个涵盖完整 AI 生命周期（包括数据探索、数据标注、模型训练、评估和推理）的人工智能平台，支持图像、视频、文本和音频数据。在 LangChain 生态系统中，据我们所知，Clarifai 是唯一一个在一个生产级平台上同时支持 LLM、嵌入模型（embeddings）和向量存储（vector store）的提供商，这使其成为部署您的 LangChain 实现的绝佳选择。

`Clarifai` 为许多不同的用例提供了数千个 AI 模型。您可以 [在此处](https://clarifai.com/explore) 浏览它们，以找到最适合您用例的模型。这些模型包括其他提供商（如 OpenAI、Anthropic、Cohere、AI21 等）创建的模型，以及来自开源社区的最先进模型（如 Falcon、InstructorXL 等），以便您可以将最佳的 AI 技术集成到您的产品中。您会发现这些模型按创建者的 `user_id` 组织起来，并放入我们称为“应用程序”（application）的项目中，由其 `app_id` 标识。因此，在找到最适合您用例的模型后，除了 `model_id` 和可选的 `version_id` 之外，还需要记下所有这些 ID！

另外请注意，由于存在许多用于图像、视频、文本和音频理解的模型，您可以构建一些有趣的 AI 代理，利用这些多样的 AI 模型作为专家来理解这些数据类型。

## 安装与设置

- 安装 Python SDK：
<CodeGroup>
```bash pip
pip install clarifai
```

```bash uv
uv add clarifai
```
</CodeGroup>
请 [注册](https://clarifai.com/signup) Clarifai 账户，然后获取个人访问令牌（PAT）以便从您的 [安全设置](https://clarifai.com/settings/security) 访问 Clarifai API，并将其设置为环境变量 (`CLARIFAI_PAT`)。

## LLMs

要在 Clarifai 平台上找到 LLM（大型语言模型）的选择，您可以 [点击此处](https://clarifai.com/explore/models?filterData=%5B%7B%22field%22%3A%22model_type_id%22%2C%22value%22%3A%5B%22text-to-text%22%5D%7D%5D&page=1&perPage=24) 选择“文本到文本”（text-to-text）模型类型。

```python
from langchain_community.llms import Clarifai
llm = Clarifai(pat=CLARIFAI_PAT, user_id=USER_ID, app_id=APP_ID, model_id=MODEL_ID)
```

有关更多详细信息，Clarifai LLM 包装器的文档提供了 [详细的演练指南](/oss/integrations/llms/clarifai)。

## 嵌入模型（Embedding Models）

要在 Clarifai 平台上查找嵌入模型的选择，您可以 [点击此处](https://clarifai.com/explore/models?page=1&perPage=24&filterData=%5B%7B%22field%22%3A%22model_type_id%22%2C%22value%22%3A%5B%22text-embedder%22%5D%7D%5D) 选择“文本嵌入器”（text-embedder）模型类型。

LangChain 中有一个 Clarifai 嵌入模型，您可以使用以下方式访问它：
```python
from langchain_community.embeddings import ClarifaiEmbeddings
embeddings = ClarifaiEmbeddings(pat=CLARIFAI_PAT, user_id=USER_ID, app_id=APP_ID, model_id=MODEL_ID)
```

请参阅 [使用示例](/oss/integrations/document_loaders/couchbase)。

## 向量存储（Vectorstore）

Clarifai 的向量数据库（vector DB）于 2016 年推出，并已针对支持实时搜索查询进行了优化。通过 Clarifai 平台中的工作流程，您的数据会自动被一个嵌入模型以及可选的其他模型所索引，以便将该信息存储到数据库中以供搜索。您不仅可以通过向量查询数据库，还可以通过元数据匹配、其他 AI 预测的概念，甚至地理坐标搜索进行过滤。只需创建一个应用程序，选择适合您的数据类型的相应基础工作流程，然后上传数据（通过 [此处记录的 API](https://docs.clarifai.com/api-guide/data/create-get-update-delete) 或 Clarifai.com 上的 UI）。

您也可以直接从 LangChain 添加数据，自动索引将为您完成。您会发现这与其他向量存储略有不同，在那些存储中，您需要在构造函数中提供一个嵌入模型，并让 LangChain 协调从文本获取嵌入并将这些写入索引的过程。使用 Clarifai 的分布式云在后台完成所有索引工作，这不仅更方便，而且更具可扩展性。

```python
from langchain_community.vectorstores import Clarifai
clarifai_vector_db = Clarifai.from_texts(user_id=USER_ID, app_id=APP_ID, texts=texts, pat=CLARIFAI_PAT, number_of_docs=NUMBER_OF_DOCS, metadatas = metadatas)
```
有关更多详细信息，Clarifai 向量存储的文档提供了 [详细的演练指南](/oss/integrations/vectorstores/clarifai)。
