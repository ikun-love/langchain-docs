> [Banana](https://www.banana.dev/) 提供了用于 AI 模型的无服务器 GPU 推理服务，一个 CI/CD 构建流水线，以及一个简单的 Python 框架（`Potassium`）用于部署您的模型。

本文档介绍了如何在 LangChain 中使用 [Banana](https://www.banana.dev) 生态系统。

## 安装和设置 (Installation and Setup)

- 安装 Python 包 `banana-dev`：

<CodeGroup>
```bash pip
pip install banana-dev
```

```bash uv
uv add banana-dev
```
</CodeGroup>

- 从 [Banana.dev 仪表板](https://app.banana.dev) 获取 Banana API 密钥，并将其设置为环境变量 (`BANANA_API_KEY`)。
- 从模型的详情页面获取您模型的密钥和 URL Slug。

## 定义您的 Banana 模板 (Define your Banana Template)

您需要为您的 Banana 应用设置一个 GitHub 仓库。您可以使用[本指南](https://docs.banana.dev/banana-docs/)在 5 分钟内开始。

或者，对于一个即开即用的 LLM 示例，您可以查看 Banana 的 [CodeLlama-7B-Instruct-GPTQ](https://github.com/bananaml/demo-codellama-7b-instruct-gptq) GitHub 仓库。只需 Fork 它并在 Banana 中进行部署即可。

其他入门示例仓库可以在[这里](https://github.com/orgs/bananaml/repositories?q=demo-&type=all&language=&sort=)找到。

## 构建 Banana 应用 (Build the Banana app)

要在 LangChain 中使用 Banana 应用，您必须在返回的 JSON 中包含 `outputs` 键，并且其值必须是一个字符串。

```python
# 将结果作为字典返回
result = {'outputs': result}
```

一个推理函数的示例是：

```python
@app.handler("/")
def handler(context: dict, request: Request) -> Response:
    """处理生成代码的请求。"""
    model = context.get("model")
    tokenizer = context.get("tokenizer")
    max_new_tokens = request.json.get("max_new_tokens", 512)
    temperature = request.json.get("temperature", 0.7)
    prompt = request.json.get("prompt")
    prompt_template=f'''[INST] 编写代码来解决以下编码问题，该代码必须遵守约束并能通过示例测试用例。请使用 ``` 将您的代码答案包装起来：
    {prompt}
    [/INST]
    '''
    input_ids = tokenizer(prompt_template, return_tensors='pt').input_ids.cuda()
    output = model.generate(inputs=input_ids, temperature=temperature, max_new_tokens=max_new_tokens)
    result = tokenizer.decode(output[0])
    return Response(json={"outputs": result}, status=200)
```

此示例来自 [CodeLlama-7B-Instruct-GPTQ](https://github.com/bananaml/demo-codellama-7b-instruct-gptq) 中的 `app.py` 文件。
