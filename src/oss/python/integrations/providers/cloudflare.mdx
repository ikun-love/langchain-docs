> [Cloudflare, Inc. (维基百科)](https://en.wikipedia.org/wiki/Cloudflare) 是一家美国公司，提供内容分发网络服务、云端网络安全、DDoS 缓解服务以及 ICANN（互联网名称与数字地址分配机构）认可的域名注册服务。

> [Cloudflare Workers AI](https://developers.cloudflare.com/workers-ai/) 允许您通过 REST API，在 `Cloudflare` 网络上从您的代码中运行机器学习模型。

## ChatModels

请参阅[安装说明和用法示例](/oss/integrations/chat/cloudflare_workersai)。

