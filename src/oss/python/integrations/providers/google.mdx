本页面涵盖了 LangChain 与 [Google Gemini](https://ai.google.dev/gemini-api/docs)、[Google Cloud](https://cloud.google.com/) 以及其他 Google 产品（如 Google Maps、YouTube 等 [更多](#other-google-products)）的所有集成。

<Note>
    **统一的 SDK 和包整合**

    从 `langchain-google-genai` 4.0.0 版本开始，该包使用了整合后的 [`google-genai`](https://googleapis.github.io/python-genai/) SDK，现已同时支持 **Gemini 开发者 API 和 Vertex AI** 后端。

    `langchain-google-vertexai` 包仍然受支持，用于支持特定于 Vertex AI 平台的特性（如模型库 Model Garden、向量搜索 Vector Search、评估服务等）。

    请阅读[完整的公告和迁移指南](https://github.com/langchain-ai/langchain-google/discussions/1422)。
</Note>

不确定应该使用哪个包？

<AccordionGroup>
    <Accordion title="Google 生成式 AI（Gemini API 和 Vertex AI）">
        通过 **[Gemini 开发者 API](https://ai.google.dev/)** 或 **[Vertex AI](https://cloud.google.com/vertex-ai)** 访问 Google Gemini 模型。后端会根据您的配置自动选择。

        - **Gemini 开发者 API**: 使用 API 密钥快速设置，非常适合个人开发者和快速原型设计。
        - **Vertex AI**: 具有 Google Cloud 集成的企业级特性（需要 GCP 项目）。

        使用 `langchain-google-genai` 包来处理聊天模型、LLM 和嵌入（Embeddings）。

        [查看集成。](#google-generative-ai)
    </Accordion>
    <Accordion title="Google Cloud（Vertex AI 平台服务）">
        访问除 Gemini 模型之外的 Vertex AI 平台特定服务：模型库 (Model Garden - Llama, Mistral, Anthropic)、评估服务和专业视觉模型。

        使用 `langchain-google-vertexai` 包来处理平台服务，并使用其他云服务（如数据库和存储）的特定包（例如 `langchain-google-community`, `langchain-google-cloud-sql-pg`）。

        [查看集成。](#google-cloud)
    </Accordion>
</AccordionGroup>

有关 Gemini API 与 Vertex AI 之间差异的更多详细信息，请参阅 Google 关于[从 Gemini API 迁移到 Vertex AI](https://ai.google.dev/gemini-api/docs/migrate-to-cloud) 的指南。

<Note>
    Gemini 模型和 Vertex AI 平台的集成包维护在 [`langchain-google`](https://github.com/langchain-ai/langchain-google) 仓库中。

    您可以在本页面列出的 `langchain-google-community` 包以及 [`googleapis`](https://github.com/orgs/googleapis/repositories?q=langchain) GitHub 组织中找到 LangChain 与其他 Google API 和服务的集成。
</Note>

    请阅读[完整的公告和迁移指南](https://github.com/langchain-ai/langchain-google/discussions/1422)。
</Note>
