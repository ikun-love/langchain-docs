本文档涵盖了所有 LangChain 与 [Google Gemini](https://ai.google.dev/gemini-api/docs)、[Google Cloud](https://cloud.google.com/) 以及其他 Google 产品（如 Google Maps、YouTube 等 [更多](#other-google-products)）的集成。

不确定该使用哪一个？

<AccordionGroup>
    <Accordion title="Google 生成式 AI (Gemini API & AI Studio)">
        通过 [Gemini 开发者 API](https://ai.google.dev/) 直接访问 Google Gemini 模型。这通常是个人开发人员的最佳起点。

        [查看集成。](#google-generative-ai)
    </Accordion>
    <Accordion title="Google Cloud (Vertex AI 及其他服务)">
        通过 [Google Cloud Platform](https://cloud.google.com/) 访问 Gemini 模型、Vertex AI Model Garden 以及各种云服务（数据库、存储、文档 AI 等）。对于 Vertex AI 模型，请使用 `langchain-google-vertexai` 包；对于其他云服务，请使用特定的包（例如 `langchain-google-community`, `langchain-google-cloud-sql-pg`）。这非常适合已经在使用 Google Cloud 或需要企业级功能（如 MLOps、特定模型微调或企业支持）的开发人员。

        [查看集成。](#google-cloud)
    </Accordion>
</AccordionGroup>

有关 Gemini API 和 Vertex AI 之间差异的更多详细信息，请参阅 Google 关于 [从 Gemini API 迁移到 Vertex AI](https://ai.google.dev/gemini-api/docs/migrate-to-cloud) 的指南。

<Note>
    Gemini 模型和 Vertex AI 平台的集成包维护在 [`langchain-google`](https://github.com/langchain-ai/langchain-google) 仓库中。

    您可以在本页列出的 `langchain-google-community` 包以及 [`googleapis`](https://github.com/orgs/googleapis/repositories?q=langchain) GitHub 组织中找到 LangChain 与其他 Google API 和服务的集成。
</Note>
