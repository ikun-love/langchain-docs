> [MariTalk](https://www.maritaca.ai/en) 是一个基于 LLM（大语言模型）的聊天机器人，旨在满足巴西地区的需求。

## 安装和设置 (Installation and Setup)

您需要获取 MariTalk API 密钥。

您还需要安装 `httpx` Python 包。

<CodeGroup>
```bash pip
pip install httpx
```

```bash uv
uv add httpx
```
</CodeGroup>

## 聊天模型 (Chat models)

请参阅[使用示例](/oss/integrations/maritalk/chat)。

```python
from langchain_community.chat_models import ChatMaritalk
```
