>[USearch](https://unum-cloud.github.io/usearch/) 是一个更小、更快的单文件向量搜索引擎。

>`USearch` 的核心功能与 `FAISS` 相同，如果您曾经研究过近似最近邻搜索（Approximate Nearest Neighbors search），那么它的接口看起来应该会很熟悉。
> `USearch` 和 `FAISS` 都使用了 `HNSW` 算法，但在设计理念上存在显著差异。`USearch` 的设计追求紧凑性，并且在不牺牲性能的前提下与 FAISS 保持了广泛的兼容性，其主要关注点在于用户自定义的度量标准（metrics）和更少的依赖项。
>
## 安装与设置

我们需要安装 `usearch` Python 包。

<CodeGroup>
```bash pip
pip install usearch
```

```bash uv
uv add usearch
```
</CodeGroup>
