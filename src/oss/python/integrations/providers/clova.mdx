> [CLOVA Studio](https://api.ncloud-docs.com/docs/ai-naver-clovastudio-summary) 是 [Naver Cloud Platform](https://www.ncloud.com/) 的一项服务，它使用 `HyperCLOVA` 语言模型（一种超大规模 AI 技术），根据用户的输入来生成由 AI 技术处理后的文本短语。

## 嵌入模型 (Embedding models)

请参阅[安装说明和使用示例](/oss/integrations/text_embedding/clova)。

```python
from langchain_community.embeddings import ClovaEmbeddings
```
