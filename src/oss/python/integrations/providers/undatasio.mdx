> `undatasio` 包来自 [UnDatasIO](https://undatas.io)，用于从原始源文档（如 PDF）中提取干净的文本内容。
> 本页将介绍如何在 LangChain 中使用 `undatasio` 生态系统。

## 安装和设置 (Installation and Setup)

- 使用以下命令安装 Python SDK：
  `pip install undatasio`
  同时安装
  `pip install langchain-undatasio`
  以便使用 `UnDatasIOLoader` 并针对 UnDatasIO API 进行远程分区处理（partitioning）。
  您需要一个 API 密钥，可以免费在 [undatas.io](https://undatas.io) 上生成。

- 无需本地系统依赖项；所有处理都在云端运行。

## 数据加载器 (Data Loaders)

`UnDatasIO` 的主要用途是通过**文档加载器 (document loader)** 来实现的。

### UnDatasIOLoader

请参阅[使用示例](/oss/integrations/document_loaders/undatasio)，了解单文件解析和延迟加载（lazy loading）的方法。
