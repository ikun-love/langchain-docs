>[YouTube](https://www.youtube.com/) 是 Google 旗下的一个在线视频分享和社交媒体平台。
> 我们会下载 `YouTube` 的字幕（transcript）和视频信息。

## 安装和设置 (Installation and Setup)

<CodeGroup>
```bash pip
pip install youtube-transcript-api
pip install pytube
```

```bash uv
uv add youtube-transcript-api
uv add pytube
```
</CodeGroup>
查看一个 [使用示例](/oss/integrations/document_loaders/youtube_transcript)。
