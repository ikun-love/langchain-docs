本页介绍如何在 LangChain 中使用 [Runhouse](https://github.com/run-house/runhouse) 生态系统。
内容分为三个部分：安装与设置、LLM（大语言模型）以及 Embeddings（嵌入模型）。

## 安装与设置
- 使用 `pip install runhouse` 安装 Python SDK
- 如果您想使用按需集群（on-demand cluster），请使用 `sky check` 检查您的云凭证

## 自托管 LLM
对于基础的自托管 LLM，您可以使用 `SelfHostedHuggingFaceLLM` 类。对于更复杂的定制化 LLM，您可以使用其父类 `SelfHostedPipeline`。

```python
from langchain_community.llms import SelfHostedPipeline, SelfHostedHuggingFaceLLM
```

有关自托管 LLM 的更详细演练，请参阅[此 Notebook](/oss/integrations/llms/runhouse)

## 自托管 Embeddings
您可以通过 Runhouse 在 LangChain 中使用自托管 Embeddings 有几种方法。

对于来自 Hugging Face Transformers 模型的**基础**自托管嵌入，您可以使用 `SelfHostedEmbedding` 类。
```python
from langchain_community.llms import SelfHostedPipeline, SelfHostedHuggingFaceLLM
```

有关自托管 Embeddings 的更详细演练，请参阅[此 Notebook](/oss/integrations/text_embedding/self-hosted)
