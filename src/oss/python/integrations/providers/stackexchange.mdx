> [Stack Exchange](https://en.wikipedia.org/wiki/Stack_Exchange) 是一个问答（Q&A）网站网络，涵盖了各种领域的不同主题，每个网站专注于特定主题，其中问题、答案和用户都会经历声誉奖励机制。

本页面介绍如何在 LangChain 中使用 `Stack Exchange API`。

## 安装与设置
- 使用以下命令安装所需依赖：
<CodeGroup>
```bash pip
pip install stackapi
```

```bash uv
uv add stackapi
```
</CodeGroup>

## 封装器（Wrappers）

### 实用工具（Utility）

存在一个 `StackExchangeAPIWrapper` 实用工具来封装这个 API。要导入此实用工具：

```python
from langchain_community.utilities import StackExchangeAPIWrapper
```

有关此封装器的详细演练，请参阅[此笔记本](/oss/integrations/tools/stackexchange)。

### 工具（Tool）

您也可以轻松地将此封装器加载为工具（以便与代理 Agent 一起使用）。
您可以通过以下方式实现：
```python
from langchain_community.agent_toolkits.load_tools import load_tools
tools = load_tools(["stackexchange"])
```

有关工具的更多信息，请参阅[此页面](/oss/integrations/tools)。
