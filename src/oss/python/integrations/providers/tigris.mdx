> [Tigris](https://tigrisdata.com) 是一个开源的**无服务器（Serverless）NoSQL 数据库和搜索平台**，旨在简化高性能向量搜索应用的构建。
> `Tigris` 消除了管理、操作和同步多种工具的基础设施复杂性，让您可以专注于构建出色的应用程序。

## 安装和设置 (Installation and Setup)


<CodeGroup>
```bash pip
pip install tigrisdb openapi-schema-pydantic
```

```bash uv
uv add tigrisdb openapi-schema-pydantic
```
</CodeGroup>
