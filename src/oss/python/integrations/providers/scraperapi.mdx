---
title: ScraperAPI
---

[ScraperAPI](https://www.scraperapi.com/) 提供了网络抓取 API，使您能够从任何公共网站收集数据，而无需担心代理（proxies）、浏览器或验证码（CAPTCHA）处理问题。[langchain-scraperapi](https://github.com/scraperapi/langchain-scraperapi) 是对这项服务的封装，让 AI 智能体可以轻松地浏览网页并抓取数据。

## 安装与设置 (Installation and Setup)

<CodeGroup>
```bash pip
pip install langchain-scraperapi
```

```bash uv
uv add langchain-scraperapi
```
</CodeGroup>

从 [ScraperAPI](https://www.scraperapi.com/) 获取一个 API 密钥，并将其设置为环境变量：

```python
import os

os.environ["SCRAPERAPI_API_KEY"] = "your-api-key"
```

## 工具 (Tools)

该包提供了 3 个工具，分别用于抓取任何网站、获取结构化的 Google 搜索结果以及获取结构化的 Amazon 搜索结果。

查看每个工具的详细文档：
- [ScraperAPITool](/oss/integrations/tools/scraperapi) - 浏览和抓取任何网站
- ScraperAPIGoogleSearchTool - 获取结构化的 Google 搜索结果页面 (SERP) 数据
- ScraperAPIAmazonSearchTool - 获取结构化的 Amazon 产品搜索数据

如需更详细的指南，请参阅[官方仓库](https://github.com/scraperapi/langchain-scraperapi)。
