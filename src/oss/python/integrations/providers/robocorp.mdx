>[Robocorp](https://robocorp.com/) 帮助构建和运行可以在任何规模下无缝运行的 Python 工作进程。

## 安装和设置

你需要安装 `langchain-robocorp` Python 包：

<CodeGroup>
```bash pip
pip install langchain-robocorp
```

```bash uv
uv add langchain-robocorp
```
</CodeGroup>

你需要一个正在运行的 `Action Server` 实例，以便你的 Agent 应用程序能够与之通信。
请参阅 [Robocorp 快速入门](https://github.com/robocorp/robocorp#quickstart) 以了解如何设置 Action Server 和创建你的 Actions。

你可以使用 Action Server 的 `new` 命令来引导（或初始化）一个新项目。

```bash
action-server new
cd ./your-project-name
action-server start
```
