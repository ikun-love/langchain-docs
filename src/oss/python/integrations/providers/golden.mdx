>[Golden](https://golden.com) 提供了一套自然语言 API，用于使用 Golden 知识图谱进行查询和数据丰富。例如，您可以使用诸如 `Products from OpenAI`（来自 OpenAI 的产品）、`Generative ai companies with series a funding`（获得 A 轮融资的生成式 AI 公司）以及 `rappers who invest`（进行投资的说唱歌手）等查询来检索有关相关实体的结构化数据。

`golden-query` LangChain 工具是对 [Golden Query API](https://docs.golden.com/reference/query-api) 的封装，它支持对这些查询结果的程序化访问。
有关更多信息，请参阅 [Golden Query API 文档](https://docs.golden.com/referen ce/query-api)。

## 安装与设置
- 前往 [Golden API 文档](https://docs.golden.com/) 了解 Golden API 的概览。
- 从 [Golden API 设置](https://golden.com/settings/api) 页面获取您的 API 密钥。
- 将API 密钥保存到 `GOLDEN_API_KEY` 环境变量中。

## 封装器 (Wrappers)

### 实用程序 (Utility)

存在一个 `GoldenQueryAPIWrapper` 实用程序，用于封装此 API。导入该实用程序的方式如下：

```python
from langchain_community.utilities.golden_query import GoldenQueryAPIWrapper
```

有关此封装器的更详细的演示过程，请参阅[此 Notebook](/oss/integrations/tools/golden_query)。

### 工具 (Tool)

您也可以轻松地将此封装器加载为工具（供 Agent 使用）。
您可以通过以下方式实现：
```python
from langchain_community.agent_toolkits.load_tools import load_tools
tools = load_tools(["golden-query"])
```

有关工具的更多信息，请参阅[此页面](/oss/integrations/tools)。
