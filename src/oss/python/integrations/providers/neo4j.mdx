>- Neo4j 是一个专注于图数据库技术的 `开源数据库管理系统`。
>- Neo4j 允许您使用节点（Nodes）和边（Edges）来表示和存储数据，非常适合处理相互关联的数据和关系。
>- Neo4j 提供了一种 `Cypher 查询语言`，使得与图数据进行交互和查询变得非常容易。
>- 使用 Neo4j，您可以实现高性能的 `图遍历和查询`，适用于生产级别的系统。

>通过访问 [其官方网站](https://neo4j.com/) 开始使用 Neo4j。

## 安装和设置

- 使用 `pip install neo4j langchain-neo4j` 安装 Python SDK。


## 向量存储 (VectorStore)

Neo4j 向量索引被用作向量存储（vectorstore），可用于语义搜索或示例选择。

```python
from langchain_neo4j import Neo4jVector
```

查看 [使用示例](/oss/integrations/vectorstores/neo4jvector)

## GraphCypherQAChain

这是一个围绕 Neo4j 图数据库实现的包装器，它允许您根据用户输入生成 Cypher 语句，并使用这些语句从数据库中检索相关信息。

```python
from langchain_neo4j import GraphCypherQAChain, Neo4jGraph
```

查看 [使用示例](/oss/integrations/graphs/neo4j_cypher)

## 从文本构建知识图谱

文本数据通常包含丰富的关系和见解，这对各种分析、推荐引擎或知识管理应用程序非常有用。Diffbot 的 NLP API 允许从非结构化文本数据中提取实体、关系和语义信息。将 Diffbot 的 NLP API 与图数据库 Neo4j 相结合，您可以基于从文本中提取的信息创建强大、动态的图结构。这些图结构是完全可查询的，并且可以集成到各种应用程序中。

```python
from langchain_neo4j import Neo4jGraph
from langchain_experimental.graph_transformers.diffbot import DiffbotGraphTransformer
```

查看 [使用示例](/oss/integrations/graphs/diffbot)
