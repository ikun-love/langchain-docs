> [GitHub](https://github.com/) 是一个开发者平台，它允许开发者创建、存储、管理和分享他们的代码。它使用了 `Git` 软件，提供了 Git 的分布式版本控制，并为每个项目提供访问控制、缺陷跟踪、软件功能请求、任务管理、持续集成和 Wiki 功能。

## 安装和设置

要访问 GitHub API，你需要一个[个人访问令牌](https://github.com/settings/tokens)（Personal Access Token）。

## 文档加载器 (Document Loader)

GitHub 提供了两种可用的文档加载器。

请参阅[使用示例](/oss/integrations/document_loaders/github)。

```python
from langchain_community.document_loaders import GitHubIssuesLoader, GithubFileLoader
```

## 工具/工具包 (Tools/Toolkit)

### GitHubToolkit

`GitHub` 工具包包含允许 LLM 智能体与 GitHub 仓库进行交互的工具。

该工具包是 `PyGitHub` 库的封装。

```python
from langchain_community.agent_toolkits.github.toolkit import GitHubToolkit
```

在[示例 notebook](/oss/integrations/tools/github)中了解更多信息。

### GitHubAction

用于与 GitHub API 交互的工具。

```python
from langchain_community.tools.github.tool import GitHubAction
```
