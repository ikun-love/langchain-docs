[Jenkins](https://www.jenkins.io/) 是一个开源自动化平台，它使软件团队能够简化其开发工作流程。它在 DevOps 社区中被广泛用作通过 CI/CD 流水线（Pipeline）自动化应用程序的构建、测试和部署的工具。

## 安装与设置

<CodeGroup>
```bash pip
pip install langchain-jenkins
```

```bash uv
uv add langchain-jenkins
```
</CodeGroup>
