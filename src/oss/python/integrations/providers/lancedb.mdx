本文档介绍如何在 LangChain 中使用 [LanceDB](https://github.com/lancedb/lancedb)。
内容分为两个部分：安装和设置，以及特定 LanceDB 封装器的引用说明。

## 安装和设置

- 使用 `pip install lancedb` 安装 Python SDK

## 封装器 (Wrappers)

### 向量存储 (VectorStore)

LangChain 提供了一个围绕 LanceDB 数据库的封装器，允许您将其用作向量存储 (vectorstore)，
无论是用于语义搜索还是示例选择。

要导入此向量存储：

```python
from langchain_community.vectorstores import LanceDB
```

有关 LanceDB 封装器的更详细的逐步指南，请参阅[本笔记]( /oss/integrations/vectorstores/lancedb)（notebook）。
