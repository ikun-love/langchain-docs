> [ArcGIS](https://www.esri.com/en-us/arcgis/about-arcgis/overview) 是由 [Esri](https://www.esri.com/) 开发和维护的一系列客户端、服务器和在线地理信息系统（GIS）软件。
> `ArcGISLoader` 使用 `arcgis` 包。
> `arcgis` 是一个 Python 库，用于进行矢量和栅格分析、地理编码、地图制作、路径规划和方向规划。它负责管理、组织和维护您的 GIS 中的用户、群组和信息项。它支持访问来自 `Esri` 和其他权威来源的即用型地图和精选地理数据，同时也兼容您自己的数据。

## 安装与配置 (Installation and Setup)

我们需要安装 `arcgis` 包。

<CodeGroup>
```bash pip
pip install -U arcgis
```

```bash uv
uv add arcgis
```
</CodeGroup>
