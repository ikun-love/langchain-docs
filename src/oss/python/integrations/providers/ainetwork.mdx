>[AI Network](https://www.ainetwork.ai/build-on-ain) 是一个第一层（Layer 1）区块链，旨在容纳大规模人工智能（AI）模型，它利用一个由 [$AIN token](https://www.ainetwork.ai/token) 驱动的去中心化 GPU 网络，用于增强由 AI 驱动的 `NFTs`（即 `AINFTs`）。

## 安装和设置

您需要安装 `ain-py` Python 包。

<CodeGroup>
```bash pip
pip install ain-py
```

```bash uv
uv add ain-py
```
</CodeGroup>
您需要将 `AIN_BLOCKCHAIN_ACCOUNT_PRIVATE_KEY` 环境变量设置为您的 AIN 区块链账户私钥。
