本页面介绍如何在 LangChain 中使用 `GPT4All` 封装器。本教程分为两个部分：安装与设置，以及使用示例。

## 安装和设置

- 使用 `pip install gpt4all` 安装 Python 包
- 下载一个 [GPT4All 模型](https://gpt4all.io/index.html) 并将其放置在您指定的目录中

在这个示例中，我们使用的是 `mistral-7b-openorca.Q4_0.gguf`：

```bash
mkdir models
wget https://gpt4all.io/models/gguf/mistral-7b-openorca.Q4_0.gguf -O models/mistral-7b-openorca.Q4_0.gguf
```

## 使用方法

### GPT4All

要使用 GPT4All 封装器，您需要提供预训练模型文件的路径和模型的配置信息。

```python
from langchain_community.llms import GPT4All

# 实例化模型。Callbacks 支持逐 Token 流式输出
model = GPT4All(model="./models/mistral-7b-openorca.Q4_0.gguf", n_threads=8)

# 生成文本
response = model.invoke("Once upon a time, ")
```

您还可以自定义生成参数，例如 `n_predict`（预测 Token 数量）、`temp`（温度）、`top_p`、`top_k` 等。

要以流式（Streaming）方式输出模型的预测结果，请添加一个 `CallbackManager`。

```python
from langchain_community.llms import GPT4All
from langchain.callbacks.streaming_stdout import StreamingStdOutCallbackHandler

# 支持许多 CallbackHandlers，例如：
# from langchain.callbacks.streamlit import StreamlitCallbackHandler

callbacks = [StreamingStdOutCallbackHandler()]
model = GPT4All(model="./models/mistral-7b-openorca.Q4_0.gguf", n_threads=8)

# 生成文本。Token 会通过回调管理器进行流式传输。
model.invoke("Once upon a time, ", callbacks=callbacks)
```
