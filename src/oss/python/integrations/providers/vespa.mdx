> [Vespa](https://vespa.ai/) 是一个功能齐全的搜索引擎和向量数据库。
> 它可以支持在**同一次查询中**同时进行向量搜索 (ANN)、词法搜索和结构化数据搜索。

## 安装和设置 (Installation and Setup)


<CodeGroup>
```bash pip
pip install pyvespa
```

```bash uv
uv add pyvespa
```
</CodeGroup>
