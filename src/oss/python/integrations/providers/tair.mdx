> [阿里云 Tair](https://www.alibabacloud.com/help/en/tair/latest/what-is-tair) 是阿里云自主研发的一款云原生内存数据库服务。它提供了丰富的数据模型和企业级能力，以支持您的实时在线场景，同时完全兼容开源的 `Redis`。`Tair` 还引入了基于新型非易失性内存（NVM）存储介质的持久化内存优化实例。

---

## 安装与设置

安装 Tair Python SDK：

<CodeGroup>
```bash pip
pip install tair
```

```bash uv
uv add tair
```
</CodeGroup>
