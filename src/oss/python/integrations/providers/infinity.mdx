>[Infinity](https://github.com/michaelfeil/infinity) 允许创建文本嵌入（text embeddings）。

## 文本嵌入模型

存在一个 Infinity 嵌入模型（Embedding model），您可以通过以下方式访问它：
```python
from langchain_community.embeddings import InfinityEmbeddings
```
有关此模型的更详细操作指南，请参阅[此示例笔记本](/oss/integrations/text_embedding/infinity)。
