> [LiteLLM](https://github.com/BerriAI/litellm) 是一个库，旨在简化对 Anthropic、Azure、Huggingface、Replicate 等模型的调用。

## 安装与设置

<CodeGroup>
```bash pip
pip install langchain-litellm
```

```bash uv
uv add langchain-litellm
```
</CodeGroup>

## 聊天模型

```python
from langchain_litellm import ChatLiteLLM
```
```python
from langchain_litellm import ChatLiteLLMRouter
```
更多详细信息请参见[此处](/oss/integrations/chat/litellm)的指南。
