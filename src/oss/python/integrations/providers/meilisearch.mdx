> [Meilisearch](https://meilisearch.com) 是一个开源的、闪电般快速、高度相关的搜索引擎。
> 它提供了出色的默认配置，可以帮助开发者构建响应迅速的搜索体验。
>
> 您可以 [自托管 Meilisearch](https://www.meilisearch.com/docs/learn/getting_started/installation#local-installation)，
> 或在 [Meilisearch Cloud](https://www.meilisearch.com/pricing) 上运行。
>
>`Meilisearch v1.3` 支持向量搜索 (vector search)。

## 安装和设置

有关详细的配置说明，请参阅 [使用示例](/oss/integrations/vectorstores/meilisearch)。

我们需要安装 `meilisearch` Python 包。

<CodeGroup>
```bash pip
pip install meilisearch
```

```bash uv
uv add meilisearch
```
</CodeGroup>
