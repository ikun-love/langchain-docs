>[Ascend](https://https://www.hiascend.com/) 是华为提供的自然过程单元（Natural Process Unit, NPU）。

本文档介绍如何将 LangChain 与 Ascend NPU 配合使用。

### 安装

请使用以下命令安装 `torch-npu`：

<CodeGroup>
```bash pip
pip install torch-npu
```

```bash uv
uv add torch-npu
```
</CodeGroup>

请按照以下说明进行安装：
* 按照[此处](https://www.hiascend.com/document/detail/zh/canncommercial/700/quickstart/quickstart/quickstart_18_0002.html)的说明安装 CANN（Compute Architecture for Neural Networks）。

### 嵌入模型（Embedding Models）

请参阅[使用示例](/oss/integrations/text_embedding/ascend)。

```python
from langchain_community.embeddings import AscendEmbeddings
```
