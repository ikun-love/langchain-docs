> [Xata](https://xata.io) 是一个基于 `PostgreSQL` 的无服务器数据平台。
> 它提供了一个 Python SDK 用于与您的数据库进行交互，并提供了一个 UI
> 用于管理您的数据。
> `Xata` 具有原生的向量（vector）数据类型，可以添加到任何表中，并支持相似性搜索。LangChain 将向量直接插入到 `Xata` 中，并查询给定向量的最近邻（nearest neighbors），这样您就可以将所有 LangChain Embeddings 集成与 `Xata` 一起使用了。

## 安装和设置

我们需要安装 `xata` Python 包。

<CodeGroup>
```bash pip
pip install xata==1.0.0a7
```

```bash uv
uv add "xata==1.0.0a7"
```
</CodeGroup>
