本页面介绍了如何在 LangChain 中使用 [vlite](https://github.com/sdan/vlite)。vlite 是一个简单且速度极快的向量数据库，用于存储和检索嵌入向量（embeddings）。

## 安装和设置

要安装 vlite，请运行以下命令：

<CodeGroup>
```bash pip
pip install vlite
```

```bash uv
uv add vlite
```
</CodeGroup>

如需支持 PDF OCR（光学字符识别），请安装 `vlite[ocr]` 额外依赖项：

<CodeGroup>
```bash pip
pip install vlite[ocr]
```

```bash uv
uv add vlite[ocr]
```
</CodeGroup>

## VectorStore

vlite 提供了一个对其底层向量数据库的封装（wrapper），允许您将其用作向量存储（vectorstore），以实现语义搜索和示例选择功能。

要导入 vlite 向量存储类：

```python
from langchain_community.vectorstores import vlite
```
