> [Git](https://en.wikipedia.org/wiki/Git) 是一个分布式版本控制系统，用于跟踪计算机文件中任何一组更改，通常用于在软件开发过程中协调程序员对源代码的协同开发工作。

## 安装与设置

首先，你需要安装 `GitPython` Python 包。

<CodeGroup>
```bash pip
pip install GitPython
```

```bash uv
uv add GitPython
```
</CodeGroup>
