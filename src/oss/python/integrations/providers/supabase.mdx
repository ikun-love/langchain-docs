title: Supabase (Postgres)
---

> [Supabase](https://supabase.com/docs) 是一个开源的 `Firebase` 替代方案。
> `Supabase` 构建在 `PostgreSQL` 之上，这提供了强大的 `SQL` 查询能力，并能与现有的工具和框架轻松集成。

> [PostgreSQL](https://en.wikipedia.org/wiki/PostgreSQL)，也称为 `Postgres`，是一个免费且开源的关系型数据库管理系统 (RDBMS)，它强调可扩展性和对 `SQL` 的兼容性。

## 安装和设置 (Installation and Setup)

我们需要安装 `supabase` Python 包。

<CodeGroup>
```bash pip
pip install supabase
```

```bash uv
uv add supabase
```
</CodeGroup>
