title: Shale 协议
---

[Shale Protocol](https://shaleprotocol.com) 为开源大型语言模型（LLM）提供可投入生产的推理（Inference）API。它是一个即插即用（Plug & Play）的 API，因为它托管在高度可扩展的 GPU 云基础设施之上。

我们的免费套餐（free tier）为每个密钥（key）提供每日高达 1K 的请求额度，旨在消除任何人使用 LLM 构建生成式 AI（genAI）应用的障碍。

借助 Shale Protocol，开发人员/研究人员可以免费创建应用程序并探索开源 LLM 的能力。

本页面介绍如何将 Shale-Serve API 与 LangChain 集成。

截至 2023 年 6 月，API 默认支持 Vicuna-13B 模型。我们计划在未来的版本中支持更多 LLM，例如 Falcon-40B。

## 如何操作

### 1. 在 https://shaleprotocol.com 上找到我们 Discord 频道的链接。通过 Discord 上的“Shale Bot”生成 API 密钥。无需信用卡，也无免费试用期。这是一个永久免费套餐，每个 API 密钥每日限制为 1K 请求。

### 2. 使用 https://shale.live/v1 作为 OpenAI API 的即插即用替代品（Drop-in Replacement）

例如：

```python
from langchain_openai import OpenAI
from langchain_core.prompts import PromptTemplate
from langchain_core.output_parsers import StrOutputParser

import os
os.environ['OPENAI_API_BASE'] = "https://shale.live/v1"
os.environ['OPENAI_API_KEY'] = "ENTER YOUR API KEY"

llm = OpenAI()

template = """Question: {question}

# Answer: Let's think step by step."""

prompt = PromptTemplate.from_template(template)


llm_chain = prompt | llm | StrOutputParser()

question = "What NFL team won the Super Bowl in the year Justin Beiber was born?"

llm_chain.invoke(question)

```
