>[AI/ML API](https://aimlapi.com/app/?utm_source=langchain&utm_medium=github&utm_campaign=integration) 提供了一个统一的 API 接口，用于访问 300 多个托管的基础模型（如 DeepSeek、Gemini、GPT 等），同时保证企业级的正常运行时间和吞吐量。

## 安装和设置

- 安装 AI/ML API 集成包。

  ```bash
  pip install langchain-aimlapi
  ```

- 在 [aimlapi.com](https://aimlapi.com/app/?utm_source=langchain&utm_medium=github&utm_campaign=integration) 创建一个账户并生成一个 API 密钥。
- 通过设置环境变量 `AIMLAPI_API_KEY` 进行身份验证（认证）。

```python
import os

os.environ["AIMLAPI_API_KEY"] = "aimlapi_..."
```
