>[Discord](https://discord.com/) 是一个基于互联网的语音、视频和即时消息社交平台。用户可以在私聊中或在称为“服务器”（Servers）的社区中，通过语音通话、视频通话、文本消息、媒体和文件进行交流。服务器是持久化的聊天室和语音频道的集合，可以通过邀请链接访问。

## 安装与设置

<CodeGroup>
```bash pip
pip install pandas
```

```bash uv
uv add pandas
```
</CodeGroup>

请按照以下步骤下载您的 `Discord` 数据：

1. 前往您的 **用户设置** (User Settings)
2. 然后前往 **隐私与安全** (Privacy and Safety)
3. 找到 **请求我的所有数据** (Request all of my Data)，然后点击 **请求数据** (Request Data) 按钮

您可能需要等待 30 天才能收到您的数据。您会收到一封电子邮件，发送到您在 Discord 注册的邮箱地址。该邮件中将包含一个下载按钮，您可以使用它来下载您的个人 Discord 数据。
