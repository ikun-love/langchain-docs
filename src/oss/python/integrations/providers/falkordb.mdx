>什么是 `FalkorDB`？

>- FalkorDB 是一个**开源数据库管理系统** (open-source database management system)，专注于**图数据库**技术。
>- FalkorDB 允许您以**节点 (nodes)** 和**边 (edges)** 的形式表示和存储数据，这使其非常适合处理相互关联的数据和复杂关系。
>- FalkorDB 支持 OpenCypher 查询语言，并提供专有的扩展，使得与图数据交互和查询变得非常容易。
>- 使用 FalkorDB，您可以实现高性能的**图遍历和查询** (graph traversals and queries)，适用于生产级别的系统。

>要开始使用 FalkorDB，请访问 [其官方网站](https://docs.falkordb.com/)。

## 安装和设置

- 使用 `pip install falkordb langchain-falkordb` 安装 Python SDK。

## VectorStore（向量存储）

FalkorDB 的向量索引被用作向量存储 (vectorstore)，可用于语义搜索或示例选择。

```python
from langchain_community.vectorstores.falkordb_vector import FalkorDBVector
```

或者

```python
from langchain_falkordb.vectorstore import FalkorDBVector
```

查看 [使用示例](/oss/integrations/vectorstores/falkordbvector.ipynb)
