> [Trubrics](https://trubrics.com) 是一个 LLM（大语言模型）用户分析平台，它允许您收集、分析和管理用户对 AI 模型的提示（prompts）和反馈。
>
> 更多关于 `Trubrics` 的信息，请查看 [Trubrics 仓库](https://github.com/trubrics/trubrics-sdk)。

## 安装和设置 (Installation and Setup)

我们需要安装 `trubrics` Python 包：

<CodeGroup>
```bash pip
pip install trubrics
```

```bash uv
uv add trubrics
```
</CodeGroup>


## 回调 (Callbacks)

请参阅 [使用示例](/oss/integrations/callbacks/trubrics)。

```python
from langchain.callbacks import TrubricsCallbackHandler
```
