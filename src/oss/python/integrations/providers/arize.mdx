title: Arize
---

[Arize](https://arize.com) 是一个 AI 可观测性和 LLM 评估平台，它为 LangChain 应用程序提供支持，可以提供关于输入、嵌入 (embeddings)、检索 (retrieval)、函数 (functions) 和输出消息的详细追踪信息。

## 安装和设置

首先，您需要安装 `arize` Python 包。

<CodeGroup>
```bash pip
pip install arize
```

```bash uv
uv add arize
```
</CodeGroup>

其次，您需要设置您的 [Arize 账户](https://app.arize.com/auth/join) 并获取您的 `API_KEY` 或 `SPACE_KEY`。

## 回调处理器 (Callback handler)

```python
from langchain_community.callbacks import ArizeCallbackHandler
```
