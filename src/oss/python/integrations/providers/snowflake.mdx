> [Snowflake](https://www.snowflake.com/) 是一个基于云的数据仓库平台，它允许您存储和查询大量的（或海量）数据。

本页面将介绍如何在 `LangChain` 中使用 `Snowflake` 生态系统。

## 嵌入模型 (Embedding Models)

Snowflake 提供了其开源的 `arctic` 系列嵌入模型，这些模型可以在 [Hugging Face](https://huggingface.co/Snowflake/snowflake-arctic-embed-m-v1.5) 上免费获取。最新的模型 `snowflake-arctic-embed-m-v1.5` 具备 [matryoshka embedding](https://arxiv.org/abs/2205.13147) 特性，这使得向量截断更加有效。您可以通过以下 [HuggingFaceEmbeddings](/oss/integrations/text_embedding/huggingfacehub) 连接器来使用这些模型：

<CodeGroup>
```bash pip
pip install langchain-community sentence-transformers
```

```bash uv
uv add langchain-community sentence-transformers
```
</CodeGroup>

```python
from langchain_huggingface import HuggingFaceEmbeddings

model = HuggingFaceEmbeddings(model_name="snowflake/arctic-embed-m-v1.5")
```

## 文档加载器 (Document Loader)

您可以使用 [`SnowflakeLoader`](/oss/integrations/document_loaders/snowflake) 从 Snowflake 中加载数据：

```python
from langchain_community.document_loaders import SnowflakeLoader
```
