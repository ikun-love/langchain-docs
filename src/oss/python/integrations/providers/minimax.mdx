> [Minimax](https://api.minimax.chat) 是一家提供自然语言处理模型的中国初创公司，服务于企业和个人用户。

## 安装与设置

1.  获取一个 [Minimax API 密钥](https://api.minimax.chat/user-center/basic-information/interface-key)，并将其设置为环境变量 `MINIMAX_API_KEY`。
2.  获取一个 [Minimax Group ID](https://api.minimax.chat/user-center/basic-information)，并将其设置为环境变量 `MINIMAX_GROUP_ID`。

## 大语言模型 (LLM)

存在一个 Minimax LLM 的封装类，您可以通过以下方式访问它：
查看 [使用示例](/oss/integrations/llms/minimax)。

```python
from langchain_community.llms import Minimax
```

## 聊天模型 (Chat Models)

查看 [使用示例](/oss/integrations/chat/minimax)

```python
from langchain_community.chat_models import MiniMaxChat
```

## 文本嵌入模型 (Text Embedding Model)

存在一个 Minimax 嵌入模型，您可以通过以下方式访问它：
```python
from langchain_community.embeddings import MiniMaxEmbeddings
```
