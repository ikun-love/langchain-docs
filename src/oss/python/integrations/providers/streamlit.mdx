> [Streamlit](https://streamlit.io/) 是一种更快速地构建和分享数据应用的工具。
> `Streamlit` 可以在几分钟内将数据脚本转换为可分享的 Web 应用。所有过程都使用纯 Python 完成，**无需前端开发经验**。
> 访问 [streamlit.io/generative-ai](https://streamlit.io/generative-ai) 查看更多示例。

## 安装和设置

我们需要安装 `streamlit` Python 包：

<CodeGroup>
```bash pip
pip install streamlit
```

```bash uv
uv add streamlit
```
</CodeGroup>
