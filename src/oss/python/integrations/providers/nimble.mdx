[Nimble](https://www.linkedin.com/company/nimbledata) 是第一个商业外部数据平台，它利用我们获奖的、由 AI 驱动的数据结构化技术，使数据决策比以往任何时候都更容易。Nimble 将业务用户与公共网络知识连接起来。

我们为企业提供任务关键型、实时的外部数据，以解锁高级商业智能（Business Intelligence）、价格比较以及其他面向销售和营销的公共数据。我们将数据转化为即时的商业价值。

如果您想了解更多关于 Nimble 的信息，请访问 [nimbleway.com](https://www.nimbleway.com/)。

## 检索器 (Retrievers)

### NimbleSearchRetriever

使开发人员能够构建 RAG 应用程序和 AI Agent，这些应用和 Agent 可以从 Web 上的任意位置搜索、访问和检索在线信息。

我们需要安装 `langchain-nimble` Python 包。

```python
pip install -U langchain-nimble
```

请参阅 [使用示例](/oss/integrations/retrievers/nimble/)。

```python
from langchain_nimble import NimbeSearchRetriever
```

请注意，需要进行身份验证，请参阅[文档中的设置部分](/oss/integrations/retrievers/nimble/#setup)。
