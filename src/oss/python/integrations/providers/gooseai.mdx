> [GooseAI](https://goose.ai) 使部署自然语言处理 (NLP) 服务更简单、更易于访问。
> `GooseAI` 是一个通过 API 提供的完全托管的推理服务。
> `GooseAI` 提供了与其他知名 API 具有功能对等性的解决方案，它通过在代码中更改 2 行配置，即可提供即插即用的服务，用于以行业最佳的经济效益来部署开源语言模型。

## 安装和设置

- 使用 `pip install openai` 安装 Python SDK。
- 从此链接 [here](https://goose.ai/) 获取您的 GooseAI API 密钥。
- 设置环境变量（`GOOSEAI_API_KEY`）。

```python
import os
os.environ["GOOSEAI_API_KEY"] = "YOUR_API_KEY"
```


## 大型语言模型 (LLMs)

请参阅 [使用示例](/oss/integrations/llms/gooseai)。
