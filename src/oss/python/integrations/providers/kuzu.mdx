> [Kùzu](https://kuzudb.com/) 是一个可嵌入、可扩展、速度极快的图数据库。
> 它采用宽松的 MIT 许可协议，您可以在此处 [here](https://github.com/kuzudb/kuzu) 查看其源代码。

> Kùzu 的主要特点：
>- 性能和可扩展性：实现了现代的、最先进的图连接（Join）算法。
>- 易用性：由于没有服务器（采用嵌入式架构），因此非常容易设置和上手使用。
>- 互操作性：可以方便地从外部列式格式（如 CSV、JSON）以及关系型数据库中扫描和复制数据。
>- 结构化属性图模型：实现了属性图模型，并增加了结构化特性。
>- Cypher 支持：允许使用声明式查询语言 Cypher 方便地查询图数据。

> 要开始使用 Kùzu，请访问其 [文档](https://docs.kuzudb.com/)。


## 安装与设置 (Installation and Setup)

使用以下命令安装 Python SDK：

<CodeGroup>
```bash pip
pip install -U langchain-kuzu
```

```bash uv
uv add langchain-kuzu
```
</CodeGroup>
