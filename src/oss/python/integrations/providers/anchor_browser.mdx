[Anchor](https://anchorbrowser.io?utm=langchain) 是一个专为 AI Agent 浏览器自动化设计的平台。它解决了那些**缺乏 API 或 API 覆盖范围有限**的 Web 应用程序的自动化工作流难题。该平台简化了基于浏览器的自动化的创建、部署和管理过程，将复杂的网页交互转化为简单的 API 端点调用。

`langchain-anchorbrowser` 提供了 3 种主要工具：
- `AnchorContentTool` - 用于以 Markdown 或 HTML 格式提取网页内容。
- `AnchorScreenshotTool` - 用于截取网页截图。
- `AnchorWebTaskTools` - 用于执行网页任务。

## 快速开始

### 安装

安装该软件包：

<CodeGroup>
```bash pip
pip install langchain-anchorbrowser
```

```bash uv
uv add langchain-anchorbrowser
```
</CodeGroup>

### 使用方法

导入并使用你需要的工具。有关 Anchor Browser 可用工具的完整列表，请参阅 [Anchor Browser 工具页面](/oss/integrations/tools/anchor_browser) 中的 **工具特性 (Tool Features)** 表格。

```python
from langchain_anchorbrowser import AnchorContentTool

# 获取 https://www.anchorbrowser.io 的 Markdown 内容
AnchorContentTool().invoke(
    {"url": "https://www.anchorbrowser.io", "format": "markdown"}
)
```
