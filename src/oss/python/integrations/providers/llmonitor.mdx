>[LLMonitor](https://llmonitor.com?utm_source=langchain&utm_medium=py&utm_campaign=docs) 是一个开源的可观测性平台，它提供成本和使用情况分析、用户跟踪、追踪（tracing）和评估工具。

## 安装和设置

请先在 [llmonitor.com](https://llmonitor.com?utm_source=langchain&utm_medium=py&utm_campaign=docs) 上创建一个账户，然后复制您新应用的 `tracking id`（跟踪 ID）。

获取 ID 后，通过运行以下命令将其设置为环境变量：

```bash
export LLMONITOR_APP_ID="..."
```


## 回调（Callbacks）

请参阅 [用法示例](/oss/integrations/callbacks/llmonitor) 了解如何使用。

```python
from langchain.callbacks import LLMonitorCallbackHandler
```
