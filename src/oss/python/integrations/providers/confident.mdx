> [Confident AI](https://confident-ai.com) 是 `DeepEval` 的创建者。
> [DeepEval](https://github.com/confident-ai/deepeval) 是一个用于单元测试 LLM（大型语言模型）的软件包。
> 使用 `DeepEval`，每个人都可以通过更快的迭代来构建健壮的语言模型，方法是利用单元测试和集成测试。`DeepEval` 为从合成数据创建到测试的迭代的每一步都提供了支持。

## 安装与设置

您需要获取 [DeepEval API 凭证](https://app.confident-ai.com)。

您需要安装 `DeepEval` Python 包：

<CodeGroup>
```bash pip
pip install deepeval
```

```bash uv
uv add deepeval
```
</CodeGroup>

## 回调 (Callbacks)
