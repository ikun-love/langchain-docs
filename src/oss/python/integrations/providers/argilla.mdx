>[Argilla](https://argilla.io/) 是一个用于大型语言模型（LLMs）的开源数据策展平台。
> 通过使用 `Argilla`，任何人都可以通过结合人类反馈和机器反馈进行更快的数据策展，从而构建健壮的语言模型。`Argilla` 支持 MLOps 周期中的每一步，
> 从数据标注到模型监控。

## 安装与设置

获取您的 [API 密钥](https://platform.openai.com/account/api-keys)。

安装 Python 包：

<CodeGroup>
```bash pip
pip install argilla
```

```bash uv
uv add argilla
```
</CodeGroup>

## 回调（Callbacks）

```python
from langchain.callbacks import ArgillaCallbackHandler
```

请参阅 [示例](/oss/integrations/callbacks/argilla)。
