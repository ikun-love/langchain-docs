> [VDMS](https://github.com/IntelLabs/vdms/blob/master/README.md) 是一个为高效访问大型“视觉”数据而设计的存储解决方案。它通过一个图（graph）来存储视觉元数据，从而实现云规模的搜索，并允许对视觉数据进行机器友好型的增强，以加快访问速度。

## 安装与设置

### 安装客户端

<CodeGroup>
```bash pip
pip install langchain-vdms
```

```bash uv
uv add langchain-vdms
```
</CodeGroup>

### 安装数据库

您可以通过以下两种方式开始使用 VDMS：

1. 通过 Docker 在本地机器上安装 VDMS
    ```bash
        docker run -d -p 55555:55555 intellabs/vdms:latest
    ```

2. 直接在本地机器上安装 VDMS。请参阅[安装说明](https://github.com/IntelLabs/vdms/blob/master/INSTALL.md)。

## VectorStore（向量存储）

要导入此向量存储：

```python
from langchain_vdms import VDMS
from langchain_vdms.vectorstores import VDMS
```
要导入 VDMS 客户端连接器：

```python
from langchain_vdms.vectorstores import VDMS_Client
```

有关 VDMS 封装器的更详细指南，请参阅[本指南](/oss/integrations/vectorstores/vdms)。
