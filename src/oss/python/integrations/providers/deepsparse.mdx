本页面介绍了如何在 LangChain 中使用 [DeepSparse](https://github.com/neuralmagic/deepsparse) 推理运行时（Inference Runtime）。内容分为两个部分：安装和设置，以及 DeepSparse 的使用示例。

## 安装和设置

- 使用 `pip install deepsparse` 安装 Python 包
- 选择一个 [SparseZoo 模型](https://sparsezoo.neuralmagic.com/?useCase=text_generation)，或者使用 Optimum 将支持的模型导出为 ONNX 格式 [参考此教程](https://github.com/neuralmagic/notebooks/blob/main/notebooks/opt-text-generation-deepsparse-quickstart/OPT_Text_Generation_DeepSparse_Quickstart.ipynb)

## LLM（大型语言模型）

DeepSparse 提供了一个 LLM 包装器（Wrapper），您可以通过以下方式访问它：

```python
from langchain_community.llms import DeepSparse
```

它为所有模型提供了一个统一的接口：

```python
llm = DeepSparse(model='zoo:nlg/text_generation/codegen_mono-350m/pytorch/huggingface/bigpython_bigquery_thepile/base-none')

print(llm.invoke('def fib():'))
```

可以使用 `config` 参数传递额外的配置项：

```python
config = {'max_generated_tokens': 256}

llm = DeepSparse(model='zoo:nlg/text_generation/codegen_mono-350m/pytorch/huggingface/bigpython_bigquery_thepile/base-none', config=config)
```
