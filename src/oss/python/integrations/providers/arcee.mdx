> **Arcee** (请参考 [Arcee 官网](https://www.arcee.ai/about/about-us) 的介绍) 致力于支持我们所定义的 SLM（即小型化、专业化、安全性高且可扩展的语言模型）的开发和推进。通过提供 SLM 适配系统和无缝、安全的集成方式，`Arcee` 赋能企业充分利用特定领域适配的语言模型的全部潜力，从而驱动运营方面的变革性创新。

## 安装与设置

获取您的 `Arcee API` 密钥。

## LLM（大型语言模型）

参见 [使用示例](/oss/integrations/llms/arcee)。

```python
from langchain_community.llms import Arcee
```

## 检索器 (Retrievers)

参见 [使用示例](/oss/integrations/retrievers/arcee)。

```python
from langchain_community.retrievers import ArceeRetriever
```
