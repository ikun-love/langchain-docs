>[Chroma](https://docs.trychroma.com/getting-started) 是一个用于构建基于嵌入（embeddings）的 AI 应用的数据库。

## 安装与设置

<CodeGroup>
```bash pip
pip install langchain-chroma
```

```bash uv
uv add langchain-chroma
```
</CodeGroup>


## 向量存储 (VectorStore)

`langchain-chroma` 提供了一个围绕 Chroma 向量数据库的封装（wrapper），允许您将其用作向量存储，无论是在进行语义搜索还是示例选择的场景中。

```python
from langchain_chroma import Chroma
```

有关 Chroma 封装的更详细演练，请参阅[此 Notebook](/oss/integrations/vectorstores/chroma)
