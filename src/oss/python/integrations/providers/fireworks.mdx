> [Fireworks AI](https://fireworks.ai) 是一个生成式 AI 推理平台，提供行业领先的速度和生产级就绪能力，用于运行和定制模型。

## 安装与设置

- 安装 Fireworks 集成包。

  ```bash
  pip install langchain-fireworks
  ```

- 访问 [fireworks.ai](https://fireworks.ai) 注册以获取 Fireworks API 密钥。
- 通过设置 `FIREWORKS_API_KEY` 环境变量进行身份验证。

### 身份验证 (Authentication)

可以使用 Fireworks API 密钥进行身份验证，方式有两种：

1.  设置 `FIREWORKS_API_KEY` 环境变量。

    ```python
    os.environ["FIREWORKS_API_KEY"] = "<KEY>"
    ```

2.  在 Fireworks LLM 模块中设置 `api_key` 字段。

    ```python
    llm = Fireworks(api_key="<KEY>")
    ```
