> [DeepInfra](https://deepinfra.com/docs) 让我们能够轻松运行[最新的机器学习模型](https://deepinfra.com/models)。DeepInfra 负责处理运行、扩展和监控模型的各项繁重工作。用户可以专注于自己的应用程序，并通过简单的 REST API 调用来集成这些模型。

> DeepInfra 提供了与 LangChain 集成的[示例](https://deepinfra.com/docs/advanced/langchain)。

本页面介绍了如何在 `LangChain` 中使用 `DeepInfra` 生态系统。内容分为两个部分：安装和设置，以及特定 DeepInfra 封装器的参考。

## 安装和设置

- 请从[此处](https://deepinfra.com/)获取您的 DeepInfra API 密钥。
- 获取 DeepInfra API 密钥，并将其设置为环境变量（`DEEPINFRA_API_TOKEN`）。

## 可用模型

DeepInfra 提供了一系列可供部署的开源 LLM（大型语言模型）。

您可以查看[文本生成](https://deepinfra.com/models?type=text-generation)和[嵌入](https://deepinfra.com/models?type=embeddings)模型支持列表。

您可以查看[请求和响应参数列表](https://deepinfra.com/meta-llama/Llama-2-70b-chat-hf/api)。

聊天模型[遵循 OpenAI API 规范](https://deepinfra.com/meta-llama/Llama-2-70b-chat-hf/api?example=openai-http)。

## LLM

查看[使用示例](/oss/integrations/llms/deepinfra)。

```python
from langchain_community.llms import DeepInfra
```

## Embeddings (嵌入)

查看[使用示例](/oss/integrations/text_embedding/deepinfra)。

```python
from langchain_community.embeddings import DeepInfraEmbeddings
```

## Chat Models (聊天模型)

查看[使用示例](/oss/integrations/chat/deepinfra)。

```python
from langchain_community.chat_models import ChatDeepInfra
```
