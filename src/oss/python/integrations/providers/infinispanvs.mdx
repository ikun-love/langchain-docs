> [Infinispan](https://infinispan.org) Infinispan 是一个开源的**内存数据网格（In-Memory Data Grid）**，它提供了一个**键值数据存储**，能够存储所有类型的数据，从 Java 对象到纯文本。从 15 版本开始，Infinispan 支持对缓存进行向量搜索。

## 安装和设置 (Installation and Setup)
请参阅 [Get Started](https://infinispan.org/get-started/) 来运行 Infinispan 服务器。您可能需要禁用身份验证（目前不支持此功能）。

## 向量存储 (Vector Store)

from langchain_community.vectorstores import InfinispanVS
