>[spaCy](https://spacy.io/) 是一个开源软件库，用于高级自然语言处理（NLP），它使用 Python 和 Cython 编程语言编写。

## 安装与设置

<CodeGroup>
```bash pip
pip install spacy
```

```bash uv
uv add spacy
```
</CodeGroup>



## 文本分割器（Text Splitter）

```python
from langchain_text_splitters import SpacyTextSplitter
```

## 文本嵌入模型（Text Embedding Models）

请参阅 [使用示例](/oss/integrations/text_embedding/spacy_embedding)

```python
from langchain_community.embeddings.spacy_embeddings import SpacyEmbeddings
```
