>[Apache Doris](https://doris.apache.org/) 是一款专为实时分析而设计的现代化数据仓库。
它能够对大规模的实时数据提供闪电般快速的分析性能。

> 通常情况下，`Apache Doris` 被归类为 OLAP（在线分析处理）数据库，并且在
> [ClickBench — 分析型 DBMS 基准测试](https://benchmark.clickhouse.com/) 中展示了卓越的性能。
> 由于它拥有一个超快速的向量化执行引擎，因此它也可以被用作一个快速的向量数据库（VectorDB）。

## 安装与设置

<CodeGroup>
```bash pip
pip install pymysql
```

```bash uv
uv add pymysql
```
</CodeGroup>
