> [E2B](https://e2b.dev/) 提供用于 AI 生成的代码执行的开源安全沙箱。更多信息请参阅 [此处](https://github.com/e2b-dev)。

## 安装和设置

您需要安装一个 Python 包：

<CodeGroup>
```bash pip
pip install e2b_code_interpreter
```

```bash uv
uv add e2b_code_interpreter
```
</CodeGroup>
