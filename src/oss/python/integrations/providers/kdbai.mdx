> [KDB.AI](https://kdb.ai) 是一个强大的知识型向量数据库和搜索引擎，它支持使用实时数据来构建可扩展、可靠的 AI 应用，并提供先进的搜索、推荐和个性化功能。

## 安装与设置

安装 Python SDK：

<CodeGroup>
```bash pip
pip install kdbai-client
```

```bash uv
uv add kdbai-client
```
</CodeGroup>


## 向量存储 (Vector Store)

KDB.AI 索引提供了一个封装层（wrapper），允许您将其用作向量存储（vectorstore），无论是用于语义搜索还是示例选择。

```python
from langchain_community.vectorstores import KDBAI
```
