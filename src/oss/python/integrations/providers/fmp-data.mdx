> [FMP-Data](https://pypi.org/project/fmp-data/) 是一个用于连接 **Financial Data Prep API** 的 Python 包。它简化了您访问生产级高质量数据的方式。

## 安装与设置

您可以通过访问 [此页面](https://site.financialmodelingprep.com/pricing-plans?couponCode=mehdi) 获取一个 `FMP Data` API 密钥，并将其设置为环境变量（`FMP_API_KEY`）。

然后，安装 [langchain-fmp-data](https://pypi.org/project/langchain-fmp-data/)。

## 工具

请参阅 [一个示例](https://github.com/MehdiZare/langchain-fmp-data/tree/main/docs)。

```python
from langchain_fmp_data import FMPDataTool, FMPDataToolkit
```
