[Pebblo](https://www.daxa.ai/pebblo) 旨在帮助开发者安全地加载和检索数据，从而在无需担心组织合规性和安全要求的情况下，将他们的生成式 AI（Gen AI）应用推广到部署阶段。Pebblo SafeLoader 会识别加载数据中存在的语义主题和实体，而 Pebblo SafeRetriever 则会对检索到的上下文强制执行身份和语义控制。这些结果会汇总显示在 UI 界面或 PDF 报告中。

## Pebblo 概述

`Pebblo` 为生成式 AI 应用程序提供了一种安全的数据加载和检索方式。它主要包含以下组件：

1. **身份感知安全加载器 (Identity-aware Safe Loader)**：用于加载数据并识别语义主题和实体。
2. **安全检索器 (SafeRetrieval)**：用于对检索到的上下文强制执行身份和语义控制。
3. **用户数据报告 (User Data Report)**：用于汇总已加载和已检索的数据。
