title: SWI-Prolog
---

SWI-Prolog 提供了一个全面的免费 Prolog 环境。

## 安装和设置

安装 SWI-Prolog 后，使用 `pip` 安装 `langchain-prolog`：

<CodeGroup>
```bash pip
pip install langchain-prolog
```

```bash uv
uv add langchain-prolog
```
</CodeGroup>

## 工具 (Tools)

`PrologTool` 类支持生成使用 Prolog 规则来产生答案的 LangChain 工具。

```python
from langchain_prolog import PrologConfig, PrologTool
```

请参阅 [使用示例](/oss/integrations/tools/prolog_tool) 了解相关用法。

另请参阅同一指南，了解 `PrologRunnable` 的用法示例。`PrologRunnable` 允许生成使用 Prolog 规则来产生答案的 LangChain 可运行对象 (runnables)。
