> [Apple Inc. (维基百科)](https://en.wikipedia.org/wiki/Apple_Inc.) 是一家美国跨国公司和科技企业。
>
> [iMessage (维基百科)](https://en.wikipedia.org/wiki/IMessage) 是由苹果公司开发并于 2011 年推出的即时通讯服务。`iMessage` 仅在苹果平台上运行。

## 安装与设置

请参阅 [设置说明](/oss/integrations/chat_loaders/imessage)。

## 聊天记录加载器 (Chat loader)

它会从 `iMessage` 的 `chat.db` `SQLite` 文件中加载聊天会话记录。

查看 [使用示例](/oss/integrations/chat_loaders/imessage)。

```python
from langchain_community.chat_loaders.imessage import IMessageChatLoader
```
