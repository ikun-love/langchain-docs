> [Airbyte](https://github.com/airbytehq/airbyte) 是一个数据集成平台，用于构建 ELT（提取、加载、转换）管道，数据源包括 API、数据库和文件，目标目的地是数据仓库和数据湖。它拥有最大的 ELT 连接器目录，支持各种数据仓库和数据库。

## 安装与设置

<CodeGroup>
```bash pip
pip install -U langchain-airbyte
```

```bash uv
uv add langchain-airbyte
```
</CodeGroup>

<Note>
**当前，`langchain-airbyte` 库** **不支持 Pydantic v2。**

请降级到 Pydantic v1 版本以使用此包。

此外，此包目前要求 Python 版本为 3.10 或更高版本。

</Note>

集成包本身不需要设置任何全局环境变量，但某些特定的集成（例如 `source-github`）可能需要在连接时传入凭证信息。
