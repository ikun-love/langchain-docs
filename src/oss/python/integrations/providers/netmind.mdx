[Netmind AI](https://www.netmind.ai/) 构建更快速、更智能、更经济的 AI。
使用我们的全球 GPU 网络进行训练、微调、运行推理和扩展——您的一体化 AI 引擎。

此示例将介绍如何使用 LangChain 与 Netmind AI 模型进行交互。

## 安装与设置

```bash
pip install langchain-netmind
```

获取一个 Netmind API 密钥，并将其设置为环境变量（`NETMIND_API_KEY`）。
请访问 [www.netmind.ai/](https://www.netmind.ai/) 注册 Netmind 并生成 API 密钥。
