>[EverNote](https://evernote.com/) 设计用于存档和创建笔记，这些笔记中可以嵌入照片、音频和保存的网页内容。笔记存储在虚拟的“笔记本”（notebooks）中，可以进行标记、注释、编辑、搜索和导出。

## 安装与设置

首先，你需要安装 `lxml` 和 `html2text` 这两个 Python 包。

<CodeGroup>
```bash pip
pip install lxml
pip install html2text
```

```bash uv
uv add lxml
uv add html2text
```
</CodeGroup>
