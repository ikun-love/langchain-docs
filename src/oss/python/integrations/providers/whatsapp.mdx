>[WhatsApp](https://www.whatsapp.com/)（也被称为 `WhatsApp Messenger`）是一项免费的、跨平台的、集中式的即时消息（IM）和网络电话（VoIP）服务。它允许用户发送文本和语音消息、进行语音和视频通话，以及共享图片、文档、用户位置和其他内容。

## 安装和设置

对于此服务，不需要任何特殊的设置。

## 文档加载器

请参阅 [使用示例](/oss/integrations/document_loaders/whatsapp_chat)。

```python
from langchain_community.document_loaders import WhatsAppChatLoader
```
