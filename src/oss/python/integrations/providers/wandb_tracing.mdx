---
title: Weights & Biases 追踪
---

我们推荐使用以下两种方式来追踪你的 LangChain 流程：

1.  将 `LANGCHAIN_WANDB_TRACING` 环境变量设置为 `"true"`。
1.  使用 `tracing_enabled()` 上下文管理器来追踪特定的代码块。

**注意**：如果设置了环境变量，无论代码是否在上下文管理器内，所有代码都将被追踪。

```python
import os

from langchain_community.callbacks import wandb_tracing_enabled

os.environ["LANGCHAIN_WANDB_TRACING"] = "true"

# wandb (Weights & Biases) 文档，关于如何使用环境变量进行配置：
# https://docs.wandb.ai/guides/track/advanced/environment-variables
# 在这里我们配置 wandb 的项目名称
os.environ["WANDB_PROJECT"] = "langchain-tracing"

from langchain.agents import AgentType, initialize_agent, load_tools
from langchain_openai import OpenAI
```

```python
# 启用追踪的 Agent 运行示例。请确保已正确设置 OPENAI_API_KEY 才能运行此示例。

llm = OpenAI(temperature=0)
tools = load_tools(["llm-math"], llm=llm)
```

```python
agent = initialize_agent(
    tools, llm, agent=AgentType.ZERO_SHOT_REACT_DESCRIPTION, verbose=True
)

agent.run("What is 2 raised to .123243 power?")  # 这应该被追踪
# 在你的控制台中应该会打印类似于以下格式的追踪会话 URL：
# https://wandb.ai/<wandb_entity>/<wandb_project>/runs/<run_id>
# 该 URL 可用于在 wandb 中查看追踪会话。
```

```python
# 现在，我们取消设置环境变量并使用上下文管理器。
if "LANGCHAIN_WANDB_TRACING" in os.environ:
    del os.environ["LANGCHAIN_WANDB_TRACING"]

# 使用上下文管理器启用追踪
with wandb_tracing_enabled():
    agent.run("What is 5 raised to .123243 power?")  # 这应该被追踪

agent.run("What is 2 raised to .123243 power?")  # 这不应该被追踪
```
