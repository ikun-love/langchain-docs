OpenLLM 允许开发者使用**单个命令**将任何**开源 LLM** 作为**与 OpenAI 兼容的 API** 端点来运行。

- 🔬 专为快速和生产环境使用而构建
- 🚂 支持 Llama 3、Qwen 2、Gemma 等模型，以及许多**量化 (quantized)** 版本 [完整列表](https://github.com/bentoml/openllm-models)
- ⛓️ 与 OpenAI 兼容的 API
- 💬 内置类似 ChatGPT 的用户界面 (UI)
- 🔥 利用最先进的推理后端加速 LLM 解码
- 🌥️ 随时可用于企业级云部署（Kubernetes、Docker 和 BentoCloud）

## 安装与设置

通过 PyPI 安装 OpenLLM 包：

<CodeGroup>
```bash pip
pip install openllm
```

```bash uv
uv add openllm
```
</CodeGroup>

## LLM 模型

OpenLLM 支持广泛的开源 LLM，也支持为用户自己的微调 (fine-tuned) LLM 提供服务。使用 `openllm model` 命令可以查看所有已针对 OpenLLM 进行预优化的可用模型。

## 包装器 (Wrappers)

OpenLLM 提供了一个包装器，支持与正在运行的 OpenLLM 服务器进行交互：

```python
from langchain_community.llms import OpenLLM
```

### OpenLLM 服务器的包装器

此包装器支持与 OpenLLM 的 OpenAI 兼容端点进行交互。

要运行一个模型，请执行以下操作：

```bash
openllm hello
```

包装器使用方法：

```python
from langchain_community.llms import OpenLLM

llm = OpenLLM(base_url="http://localhost:3000/v1", api_key="na")

llm("鸭子和鹅有什么区别？为什么加拿大有这么多鹅？")
```
