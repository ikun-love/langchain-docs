> [Baseten](https://baseten.co) 提供部署和提供机器学习模型所需的所有基础设施，以实现高性能、高可靠性和高可扩展性。

> 作为一个模型推理平台，`Baseten` 是 LangChain 生态系统中的一个 `Provider`（提供商）。当前的 `Baseten` 集成实现了 `Chat Models`（聊天模型）和 `Embeddings`（嵌入）组件。

> `Baseten` 允许您通过指定 `model` [slug](https://docs.baseten.co/development/model-apis/overview#supported-models) 来访问 Kimi K2 或 GPT OSS 等开源模型，或者通过指定 `model_url` 在专用的 GPU 部署上运行专有模型或微调模型。

## 安装和设置

要在 LangChain 中使用 Baseten 模型，您需要两样东西：

* 一个 [Baseten 账户](https://baseten.co)
* 一个 [API 密钥](https://docs.baseten.co/observability/api-keys)

将您的 API 密钥导出为名为 `BASETEN_API_KEY` 的环境变量。

```sh
export BASETEN_API_KEY="paste_your_api_key_here"
```

## 聊天模型（Model APIs 和 Dedicated Deployments）

请参阅 [使用示例](/oss/integrations/chat/baseten)。

```python
from langchain_baseten import ChatBaseten
```

## 嵌入（仅限 Dedicated Deployments）

请参阅 [使用示例](/oss/integrations/text_embedding/baseten)。

from langchain_baseten import BasetenEmbeddings
