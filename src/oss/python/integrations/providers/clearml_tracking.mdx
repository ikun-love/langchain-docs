> [ClearML](https://github.com/allegroai/clearml) 是一个 ML/DL 开发和生产套件，它包含 5 个主要模块：

> - `Experiment Manager` - 自动化的实验跟踪、环境和结果管理
> - `MLOps` - 面向 ML/DL 作业的编排、自动化和管道解决方案（K8s / 云 / 裸金属）
> - `Data-Management` - 基于对象存储（S3 / GS / Azure / NAS）的完全可微分的数据管理和版本控制解决方案
> - `Model-Serving` - 云端就绪的可扩展模型服务解决方案！
    在 5 分钟内部署新的模型端点
    包括由 Nvidia-Triton 驱动的优化 GPU 服务支持
    具备开箱即用的模型监控功能
> - `Fire Reports` - 创建和分享支持嵌入式在线内容的丰富的 MarkDown 文档

为了正确跟踪您的 langchain 实验及其结果，您可以启用 `ClearML` 集成。我们使用 `ClearML Experiment Manager` 来整齐地跟踪和组织所有实验运行。

## 回调 (Callbacks)

```python
from langchain_community.callbacks import ClearMLCallbackHandler
```

```python
from langchain_core.callbacks import StdOutCallbackHandler
from langchain_openai import OpenAI

# 设置并使用 ClearML Callback
clearml_callback = ClearMLCallbackHandler(
    task_type="inference",
    project_name="langchain_callback_demo",
    task_name="llm",
    tags=["test"],
    # 根据您希望跟踪的详细信息量更改以下参数
    visualize=True,
    complexity_metrics=True,
    stream_logs=True,
)
callbacks = [StdOutCallbackHandler(), clearml_callback]
# 准备 OpenAI 模型
llm = OpenAI(temperature=0, callbacks=callbacks)
```

```output

```
