[Browserbase](https://browserbase.com) 是一个开发者平台，用于可靠地运行、管理和监控无头浏览器（headless browsers）。

利用以下功能为您的 AI 数据检索提供强大支持：
- [Serverless Infrastructure](https://docs.browserbase.com/under-the-hood)（无服务器基础设施）：提供可靠的浏览器，用于从复杂的 UI 中提取数据
- [Stealth Mode](https://docs.browserbase.com/features/stealth-mode)（隐身模式）：内置指纹识别策略和自动验证码（captcha）解决功能
- [Session Debugger](https://docs.browserbase.com/features/sessions)（会话调试器）：使用网络时间线和日志检查您的浏览器会话
- [Live Debug](https://docs.browserbase.com/guides/session-debug-connection/browser-remote-control)（实时调试）：快速调试您的自动化流程

## 安装与设置

- 从 [browserbase.com](https://browserbase.com) 获取 API 密钥（API key）和项目 ID（Project ID），并将其设置为环境变量（`BROWSERBASE_API_KEY`, `BROWSERBASE_PROJECT_ID`）。
- 安装 [Browserbase SDK](http://github.com/browserbase/python-sdk)：

```python
pip install browserbase
```
