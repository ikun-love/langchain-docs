本页面介绍如何在 LangChain 中使用 Postgres [PGVector](https://github.com/pgvector/pgvector) 生态系统。
内容分为两个部分：安装与设置，以及特定 PGVector 封装器的使用参考。

## 安装 (Installation)
通过运行以下命令安装 Python 包：
```bash
pip install pgvector
```

## 设置 (Setup)
1. 第一步是创建一个已安装 `pgvector` 扩展的数据库。

    请参阅 [PGVector 安装步骤](https://github.com/pgvector/pgvector#installation) 中的步骤来安装数据库及扩展。使用 Docker 镜像启动是最简单的方式。

## 封装器 (Wrappers)

### 向量存储 (VectorStore)

PGVector 提供了对 Postgres 向量数据库的封装，允许你将其用作向量存储（VectorStore），无论是用于语义搜索还是示例选择。

要导入此向量存储：
```python
from langchain_community.vectorstores.pgvector import PGVector
```

### 用法 (Usage)

有关 PGVector 封装器的更详细的逐步指南，请参阅[此教程（notebook）](/oss/integrations/vectorstores/pgvector)。
