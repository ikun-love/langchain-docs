>[PromptLayer](https://docs.promptlayer.com/introduction) 是一个用于提示工程（Prompt Engineering）的平台。
> 它还提供大语言模型（LLM）的可观测性（Observability）功能，可以可视化请求、版本控制提示词以及跟踪使用情况。
>
>虽然 `PromptLayer` 确实提供与 LangChain 直接集成的 LLM（例如 [`PromptLayerOpenAI`](https://docs.promptlayer.com/languages/langchain）），
> 但推荐使用回调（Callback）机制来将 `PromptLayer` 与 LangChain 集成。

## 安装与设置 (Installation and Setup)

要使用 `PromptLayer`，我们需要：
- 创建一个 `PromptLayer` 账户
- 创建一个 API 令牌（token），并将其设置为环境变量 (`PROMPTLAYER_API_KEY`)

安装 Python 包：

<CodeGroup>
```bash pip
pip install promptlayer
```

```bash uv
uv add promptlayer
```
</CodeGroup>


## 回调 (Callback)

请参阅[使用示例](/oss/integrations/callbacks/promptlayer)。

```python
import promptlayer  # 不要忘记导入这个！
from langchain.callbacks import PromptLayerCallbackHandler
```
