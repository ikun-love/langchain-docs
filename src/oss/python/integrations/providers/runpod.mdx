[RunPod](https://www.runpod.io/) 提供了 GPU 云基础设施，包括专为部署和扩展 AI 模型而优化的 Serverless 端点。

本指南将介绍如何使用 `langchain-runpod` 集成包，将 LangChain 应用程序连接到托管在 [RunPod Serverless](https://www.runpod.io/serverless-gpu) 上的模型。

此集成包为标准的语言模型（LLMs）和聊天模型（Chat Models）都提供了接口。

## 安装 (Installation)

安装专用的合作伙伴包：

```python
pip install -qU langchain-runpod
```

## 设置 (Setup)

### 1. 在 RunPod 上部署一个端点 (Endpoint)

- 导航到您的 [RunPod Serverless 控制台](https://www.runpod.io/console/serverless/user/endpoints)。
- 创建一个“新建端点 (New Endpoint)”，选择一个与您的模型以及预期的输入/输出格式兼容的合适 GPU 和模板（例如：vLLM, TGI, text-generation-webui）（请参阅组件指南或包 [README](https://github.com/runpod/langchain-runpod)）。
- 配置设置并部署。
- **关键步骤：在部署完成后，复制端点 ID (Endpoint ID)**。

### 2. 设置 API 凭证

该集成需要您的 RunPod API 密钥和端点 ID。为了安全访问，请将它们设置为环境变量：

```python
import getpass
import os

os.environ["RUNPOD_API_KEY"] = getpass.getpass("输入您的 RunPod API 密钥: ")
os.environ["RUNPOD_ENDPOINT_ID"] = input("输入您的 RunPod 端点 ID: ")
```

（可选）如果您为 LLM 和聊天模型使用不同的端点，您可能需要设置 `RUNPOD_CHAT_ENDPOINT_ID` 或在初始化时直接传入 ID。

## 组件 (Components)

此包提供了两个主要组件：

### 1. LLM

用于与标准的文本补全模型进行交互。

有关详细用法，请参阅 [RunPod LLM 集成指南](/oss/integrations/llms/runpod)。

```python
from langchain_runpod import RunPod

# 示例初始化（使用环境变量）
llm = RunPod(model_kwargs={"max_new_tokens": 100})  # 在此处添加生成参数

# 示例调用
try:
    response = llm.invoke("写一首关于云的短诗。")
    print(response)
except Exception as e:
    print(
        f"调用 LLM 时出错: {e}。请确保端点 ID 和 API 密钥正确且端点处于活动状态。"
    )
```

### 2. 聊天模型 (Chat Model)

用于与对话模型进行交互。

有关详细用法和功能支持，请参阅 [RunPod 聊天模型集成指南](/oss/integrations/chat/runpod)。

```python
from langchain.messages import HumanMessage
from langchain_runpod import ChatRunPod

# 示例初始化（使用环境变量）
chat = ChatRunPod(model_kwargs={"temperature": 0.8})  # 在此处添加生成参数

# 示例调用
try:
    response = chat.invoke(
        [HumanMessage(content="用一句话解释 RunPod Serverless。")]
    )
    print(response.content)
except Exception as e:
    print(
        f"调用聊天模型时出错: {e}。请确保端点 ID 和 API 密钥正确且端点处于活动状态。"
    )
```
