> [Bagel](https://www.bagel.net/)（一个**开源向量数据库**，专为 AI 设计）就像是 AI 数据的 GitHub。
它是一个协作平台，用户可以在其中创建、
共享和管理向量数据集。它可以支持独立开发人员的私有项目、
企业内部的协作，以及数据 DAO 的公共贡献。

## 安装与设置

<CodeGroup>
```bash pip
pip install bagelML
```

```bash uv
uv add bagelML
```
</CodeGroup>
