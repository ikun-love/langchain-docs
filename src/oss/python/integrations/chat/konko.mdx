> [Konko](https://www.konko.ai/) API 是一项全托管的 Web API 服务，旨在帮助应用程序开发者实现以下目标：

1. **选择**适合其应用的开源或专有 LLM（大型语言模型）。
2. 通过与领先的应用框架集成以及全托管的 API，**更快地构建**应用程序。
3. **微调**较小的开源 LLM，以极低的成本实现行业领先的性能。
4. **部署**满足安全、隐私、吞吐量和延迟 SLA（服务等级协议）的生产级 API，而无需进行基础设施设置或管理，这一切都依托于 Konko AI 经过 SOC 2 合规认证的多云基础设施。

本示例将介绍如何使用 LangChain 与 `Konko` ChatCompletion [模型](https://docs.konko.ai/docs/list-of-models#konko-hosted-models-for-chatcompletion)进行交互。

要运行此 Jupyter Notebook，您需要 Konko API 密钥。请登录我们的 Web 应用程序以[创建 API 密钥](https://platform.konko.ai/settings/api-keys)来访问模型。

```python
from langchain_community.chat_models import ChatKonko
from langchain.messages import HumanMessage, SystemMessage
```

#### 设置环境变量

1. 您可以设置以下环境变量：
   1. `KONKO_API_KEY`（必需）
   2. `OPENAI_API_KEY`（可选）
2. 在您当前的 Shell 会话中，使用 `export` 命令：

```shell
export KONKO_API_KEY={your_KONKO_API_KEY_here}
export OPENAI_API_KEY={your_OPENAI_API_KEY_here} # Optional
```

## 调用模型

您可以在 [Konko 概览页面](https://docs.konko.ai/docs/list-of-models)上找到模型。

查找在 Konko 实例上运行的模型列表的另一种方法是通过此 [API 端点](https://docs.konko.ai/reference/get-models)。

从这里，我们可以初始化我们的模型：

```python
chat = ChatKonko(max_tokens=400, model="meta-llama/llama-2-13b-chat")
```

```python
messages = [
    SystemMessage(content="You are a helpful assistant."),
    HumanMessage(content="Explain Big Bang Theory briefly"),
]
chat(messages)
```
