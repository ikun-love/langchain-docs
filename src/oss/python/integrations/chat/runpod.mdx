开始使用 RunPod 聊天模型。

## 概述

本指南介绍如何使用 LangChain 的 `ChatRunPod` 类来与托管在 [RunPod Serverless](https://www.runpod.io/serverless-gpu) 上的聊天模型进行交互。

## 设置

1. **安装包：**

    ```bash
    pip install -qU langchain-runpod
    ```

2. **部署聊天模型端点：** 按照 [RunPod Provider Guide](/oss/integrations/providers/runpod#setup) 中的设置步骤，在 RunPod Serverless 上部署一个兼容的聊天模型端点，并获取其端点 ID（Endpoint ID）。
3. **设置环境变量：** 确保设置了 `RUNPOD_API_KEY` 和 `RUNPOD_ENDPOINT_ID`（或者特定的 `RUNPOD_CHAT_ENDPOINT_ID`）。

```python
import getpass
import os

# 确保环境变量已设置（或者直接传递给 ChatRunPod）
if "RUNPOD_API_KEY" not in os.environ:
    os.environ["RUNPOD_API_KEY"] = getpass.getpass("输入您的 RunPod API 密钥: ")

if "RUNPOD_ENDPOINT_ID" not in os.environ:
    os.environ["RUNPOD_ENDPOINT_ID"] = input(
        "输入您的 RunPod 端点 ID (如果未设置 RUNPOD_CHAT_ENDPOINT_ID 则使用): "
    )

# 可选：使用专门用于聊天模型的不同端点 ID
# if "RUNPOD_CHAT_ENDPOINT_ID" not in os.environ:
#     os.environ["RUNPOD_CHAT_ENDPOINT_ID"] = input("输入您的 RunPod 聊天端点 ID (可选): ")

chat_endpoint_id = os.environ.get(
    "RUNPOD_CHAT_ENDPOINT_ID", os.environ.get("RUNPOD_ENDPOINT_ID")
)
if not chat_endpoint_id:
    raise ValueError(
        "未找到 RunPod 端点 ID。请设置 RUNPOD_ENDPOINT_ID 或 RUNPOD_CHAT_ENDPOINT_ID。"
    )
```

## 实例化

初始化 `ChatRunPod` 类。您可以通过 `model_kwargs` 传递特定于模型的参数，并配置轮询行为。

```python
from langchain_runpod import ChatRunPod

chat = ChatRunPod(
    runpod_endpoint_id=chat_endpoint_id,  # 指定正确的端点 ID
    model_kwargs={
        "max_new_tokens": 512,
        "temperature": 0.7,
        "top_p": 0.9,
        # 添加您的端点处理程序支持的其他参数
    },
    # 可选：调整轮询设置
    # poll_interval=0.2,
    # max_polling_attempts=150
)
```

## 调用

使用标准的 LangChain `.invoke()` 和 `.ainvoke()` 方法来调用模型。也支持通过 `.stream()` 和 `.astream()` 进行流式传输（通过轮询 RunPod `/stream` 端点来模拟）。

```python
from langchain.messages import HumanMessage, SystemMessage

messages = [
    SystemMessage(content="你是一个有帮助的人工智能助手。"),
    HumanMessage(content="RunPod Serverless 的 API 流程是怎样的？"),
]

# 调用 (同步)
try:
    response = chat.invoke(messages)
    print("--- 同步调用响应 ---")
    print(response.content)
except Exception as e:
    print(
        f"调用聊天模型时出错: {e}。请确保端点 ID/API 密钥正确，且端点处于活动/兼容状态。"
    )

# 流式传输 (同步，通过轮询 /stream 模拟)
print("\n--- 同步流式传输响应 ---")
try:
    for chunk in chat.stream(messages):
        print(chunk.content, end="", flush=True)
    print()  # 换行
except Exception as e:
    print(
        f"\n流式传输聊天模型时出错: {e}。请确保端点处理程序支持流式输出格式。"
    )

### 异步用法

# 调用 (异步)
try:
    async_response = await chat.ainvoke(messages)
    print("--- 异步调用响应 ---")
    print(async_response.content)
except Exception as e:
    print(f"异步调用聊天模型时出错: {e}。")

# 流式传输 (异步)
print("\n--- 异步流式传输响应 ---")
try:
    async for chunk in chat.astream(messages):
        print(chunk.content, end="", flush=True)
    print()  # 换行
except Exception as e:
    print(
        f"\n异步流式传输聊天模型时出错: {e}。请确保端点处理程序支持流式输出格式。\n"
    )
```

## 链接 (Chaining)

聊天模型可以无缝集成到 LangChain 表达式语言 (LCEL) 链中。

```python
from langchain_core.output_parsers import StrOutputParser
from langchain_core.prompts import ChatPromptTemplate

prompt = ChatPromptTemplate.from_messages(
    [
        ("system", "你是一个有帮助的助手。"),
        ("human", "{input}"),
    ]
)

parser = StrOutputParser()

chain = prompt | chat | parser

try:
    chain_response = chain.invoke(
        {"input": "请用简单的术语解释一下无服务器计算（serverless computing）的概念。"}
    )
    print("--- 链式调用响应 ---")
    print(chain_response)
except Exception as e:
    print(f"运行链时出错: {e}")


# 异步链
try:
    async_chain_response = await chain.ainvoke(
        {"input": "使用 RunPod 进行 AI/ML 工作负载有哪些好处？"}
    )
    print("--- 异步链式调用响应 ---")
    print(async_chain_response)
except Exception as e:
    print(f"运行异步链时出错: {e}")
```

## 模型特性 (取决于端点)

高级功能的可用性**很大程度上**取决于您的 RunPod 端点处理程序的具体实现。`ChatRunPod` 集成提供了基本框架，但处理程序必须支持底层功能。

| 特性 | 集成支持 | 端点决定? | 备注 |
| :--- | :---: | :---: | :--- |
| [工具调用](/oss/langchain/tools) | ❌ | ✅ | 需要处理程序来处理工具定义并返回工具调用（例如 OpenAI 格式）。集成需要解析逻辑。 |
| [结构化输出](/oss/langchain/structured-output) | ❌ | ✅ | 需要处理程序支持强制结构化输出（JSON 模式、函数调用）。集成需要解析逻辑。 |
| JSON 模式 | ❌ | ✅ | 需要处理程序接受 `json_mode` 参数（或类似参数）并保证 JSON 输出。 |
| [图像输入](/oss/langchain/messages#multimodal) | ❌ | ✅ | 需要接受图像数据（例如 base64）的多模态处理程序。集成不支持多模态消息。 |
| 音频输入 | ❌ | ✅ | 需要处理程序接受音频数据。集成不支持音频消息。 |
| 视频输入 | ❌ | ✅ | 需要处理程序接受视频数据。集成不支持视频消息。 |
| [Token 级流式传输](/oss/langchain/streaming) | ✅ (模拟) | ✅ | 轮询 `/stream`。需要处理程序在状态响应中填充 `stream` 列表（例如 `[{"output": "token"}]`）。内置的真正低延迟流式传输并非标配。 |
| 原生异步 | ✅ | ✅ | 实现了核心的 `ainvoke`/`astream`。依赖于端点处理程序的性能。 |
| [Token 使用量](/oss/langchain/models#token-usage) | ❌ | ✅ | 需要处理程序在最终响应中返回 `prompt_tokens`、`completion_tokens`。当前集成不解析此内容。 |
| [Logprobs](/oss/langchain/models#log-probabilities) | ❌ | ✅ | 需要处理程序返回对数概率。当前集成不解析此内容。 |

**核心要点：** 如果端点遵循基本的 RunPod API 约定，标准的聊天调用和模拟的流式传输就可以工作。高级功能需要特定的处理程序实现，并可能需要扩展或定制此集成包。
