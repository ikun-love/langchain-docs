## 设置

要访问 Baseten 模型，您需要创建一个 Baseten 账户，获取一个 API 密钥，并安装 `langchain-baseten` 集成包。

请访问 [此页面](https://app.baseten.co) 创建 Baseten 账户并生成 API 密钥。完成此操作后，设置 `BASETEN_API_KEY` 环境变量：

### 凭证

```python Set API key icon="key"
import getpass
import os

if "BASETEN_API_KEY" not in os.environ:
    os.environ["BASETEN_API_KEY"] = getpass.getpass("Enter your Baseten API key: ")
```

要启用模型调用的自动 <Tooltip tip="记录模型执行的每一步，以便调试和改进">跟踪</Tooltip>，请设置您的 [LangSmith](https://docs.smith.langchain.com/) API 密钥：

```python Enable tracing icon="flask"
os.environ["LANGSMITH_API_KEY"] = getpass.getpass("Enter your LangSmith API key: ")
os.environ["LANGSMITH_TRACING"] = "true"
```

### 安装

LangChain Baseten 集成位于 `langchain-baseten` 包中：

<CodeGroup>
    ```python pip
    pip install -U langchain-baseten
    ```
    ```python uv
    uv add langchain-baseten
    ```
</CodeGroup>

## 实例化

Baseten 提供两种访问聊天模型的方式：

1. **模型 API (Model APIs)**：用于访问最新、最受欢迎的开源模型。
2. **专用 URL (Dedicated URLs)**：使用具有专用资源的特定模型部署。

两种方法都受支持，并能实现自动化的端点规范化。


```python Initialize with model slug icon="robot"
from langchain_baseten import ChatBaseten

# 选项 1：使用带有模型 slug 的模型 API
model = ChatBaseten(
    model="moonshotai/Kimi-K2-Instruct-0905",  # 可选模型 slug 列表：https://docs.baseten.co/development/model-apis/overview#supported-models
    api_key="your-api-key",  # 或者设置 BASETEN_API_KEY 环境变量
)
```

```python Initialize with model URL icon="link"
from langchain_baseten import ChatBaseten

# 选项 2：使用带有模型 URL 的专用部署
model = ChatBaseten(
    model_url="https://model-<id>.api.baseten.co/environments/production/predict",
    api_key="your-api-key",  # 或者设置 BASETEN_API_KEY 环境变量
)
```

## 调用

```python Basic invocation icon="play"
# 使用聊天模型
response = model.invoke("Hello, how are you?")
print(response.content)
```


您也可以使用消息对象（message objects）进行更复杂的对话：

<CodeGroup>
    ```python Dictionary format icon="book"
    messages = [
        {"role": "system", "content": "You are a poetry expert"},
        {"role": "user", "content": "Write a haiku about spring"},
    ]
    response = model.invoke(messages)
    print(response)
    ```
