> [Azure Machine Learning](https://azure.microsoft.com/en-us/products/machine-learning/) 是一个用于构建、训练和部署机器学习模型的平台。用户可以在“模型目录”（Model Catalog）中探索可部署的模型类型，该目录提供了来自不同提供商的基础模型和通用模型。
>
> 通常情况下，您需要部署模型才能消费其预测结果（推理）。在 `Azure Machine Learning` 中，[在线终结点](https://learn.microsoft.com/en-us/azure/machine-learning/concept-endpoints)（Online Endpoints）用于实时服务部署这些模型。它们基于 `终结点`（Endpoints）和 `部署`（Deployments）的概念，使您能够将生产工作负载的接口与其服务的底层实现解耦。

本笔记本将介绍如何使用托管在 `Azure Machine Learning 终结点` 上的聊天模型。

```python
from langchain_community.chat_models.azureml_endpoint import AzureMLChatOnlineEndpoint
```

## 设置

您必须在 Azure ML 上[部署模型](https://learn.microsoft.com/en-us/azure/machine-learning/how-to-use-foundation-models?view=azureml-api-2#deploying-foundation-models-to-endpoints-for-inferencing)或[部署到 Azure AI Foundry（原 Azure AI Studio）](https://learn.microsoft.com/en-us/azure/ai-studio/how-to/deploy-models-open)并获取以下参数：

* `endpoint_url`: 终结点提供的 REST 终结点 URL。
* `endpoint_api_type`: 当部署模型到**专用终结点**（Dedicated endpoints，即托管的（managed）基础设施）时，使用 `endpoint_type='dedicated'`。当使用**按使用付费**（Pay-as-you-go）方案（模型即服务）部署模型时，使用 `endpoint_type='serverless'`。
* `endpoint_api_key`: 终结点提供的 API 密钥。

## 内容格式化器 (Content Formatter)

`content_formatter` 参数是一个处理程序类，用于转换 AzureML 终结点的请求和响应，以匹配所需的模式（schema）。由于模型目录中存在各种各样的模型，每种模型的**数据处理方式可能不同**，因此提供了一个 `ContentFormatterBase` 类，允许用户根据需要转换数据。提供了以下内容格式化器：

* `CustomOpenAIChatContentFormatter`: 格式化请求和响应数据，以适用于遵循 OpenAI API 规范进行请求和响应的模型，例如 LLaMa2-chat。

*注意：`langchain.chat_models.azureml_endpoint.LlamaChatContentFormatter` 正在被弃用，并由 `langchain.chat_models.azureml_endpoint.CustomOpenAIChatContentFormatter` 取代。*

您可以从 `langchain_community.llms.azureml_endpoint.ContentFormatterBase` 类继承，以实现特定于您模型的**自定义内容格式化器**。

## 示例

以下部分包含有关如何使用此类别的示例：

### 示例：使用实时终结点进行聊天补全

```python
from langchain_community.chat_models.azureml_endpoint import (
    AzureMLEndpointApiType,
    CustomOpenAIChatContentFormatter,
)
from langchain.messages import HumanMessage

chat = AzureMLChatOnlineEndpoint(
    endpoint_url="https://<your-endpoint>.<your_region>.inference.ml.azure.com/score",
    endpoint_api_type=AzureMLEndpointApiType.dedicated,
    endpoint_api_key="my-api-key",
    content_formatter=CustomOpenAIChatContentFormatter(),
)
response = chat.invoke(
    [HumanMessage(content="Will the Collatz conjecture ever be solved?")]
)
response
```

### 示例：使用按使用付费部署（模型即服务）进行聊天补全

```python
chat = AzureMLChatOnlineEndpoint(
    endpoint_url="https://<your-endpoint>.<your_region>.inference.ml.azure.com/v1/chat/completions",
    endpoint_api_type=AzureMLEndpointApiType.serverless,
    endpoint_api_key="my-api-key",
    content_formatter=CustomOpenAIChatContentFormatter,
)
response = chat.invoke(
    [HumanMessage(content="Will the Collatz conjecture ever be solved?")]
)
response
```

如果您需要向模型传递额外的参数，请使用 `model_kwargs` 参数：

```python
chat = AzureMLChatOnlineEndpoint(
    endpoint_url="https://<your-endpoint>.<your_region>.inference.ml.azure.com/v1/chat/completions",
    endpoint_api_type=AzureMLEndpointApiType.serverless,
    endpoint_api_key="my-api-key",
    content_formatter=CustomOpenAIChatContentFormatter,
    model_kwargs={"temperature": 0.8},
)
```

参数也可以在调用时传递：

```python
response = chat.invoke(
    [HumanMessage(content="Will the Collatz conjecture ever be solved?")],
    max_tokens=512,
)
response
```
