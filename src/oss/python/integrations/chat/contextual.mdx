## 设置

要访问 Contextual 模型，您需要创建一个 Contextual AI 帐户，获取一个 API 密钥，并安装 `langchain-contextual` 集成包。

### 凭证 (Credentials)

访问 [app.contextual.ai](https://app.contextual.ai) 注册 Contextual 并生成 API 密钥。完成此操作后，请设置 `CONTEXTUAL_AI_API_KEY` 环境变量：

```python
import getpass
import os

if not os.getenv("CONTEXTUAL_AI_API_KEY"):
    os.environ["CONTEXTUAL_AI_API_KEY"] = getpass.getpass(
        "Enter your Contextual API key: "
    )
```

如果您希望对模型调用进行自动化的追踪，也可以取消注释以下内容来设置您的 [LangSmith](https://docs.langchain.com/langsmith/home) API 密钥：

```python
os.environ["LANGSMITH_TRACING"] = "true"
os.environ["LANGSMITH_API_KEY"] = getpass.getpass("Enter your LangSmith API key: ")
```

### 安装

LangChain Contextual 集成位于 `langchain-contextual` 包中：

```python
pip install -qU langchain-contextual
```

## 实例化

现在我们可以实例化模型对象并生成聊天补全（chat completions）。

聊天客户端可以使用以下附加设置进行实例化：

| 参数 (Parameter) | 类型 (Type) | 描述 (Description) | 默认值 (Default) |
|-----------|------|-------------|---------|
| temperature | Optional[float] | 采样温度，它会影响响应中的随机性。请注意，较高的 temperature 值可能会降低“基于事实性”（groundedness）。 | 0 |
| top_p | Optional[float] | 核采样（nucleus sampling）的参数，是 temperature 的替代方案，也会影响响应的随机性。请注意，较高的 top_p 值可能会降低“基于事实性”。 | 0.9 |
| max_new_tokens | Optional[int] | 模型在响应中可以生成的最大 Token 数量。最小值为 1，最大值为 2048。 | 1024 |

```python
from langchain_contextual import ChatContextual

llm = ChatContextual(
    model="v1",  # 默认为 `v1`
    api_key="",
    temperature=0,  # 默认为 0
    top_p=0.9,  # 默认为 0.9
    max_new_tokens=1024,  # 默认为 1024
)
```

## 调用 (Invocation)

在调用 `ChatContextual.invoke` 方法时，Contextual “基于事实”语言模型接受额外的 `kwargs`。

这些额外输入包括：

| 参数 (Parameter) | 类型 (Type) | 描述 (Description) |
|-----------|------|-------------|
| knowledge | list[str] | 必需：一个字符串列表，包含模型在生成响应时可以使用的知识来源。 |
| system_prompt | Optional[str] | 可选：模型在生成响应时应遵循的指令。请注意，我们不保证模型会完全遵循这些指令。 |
| avoid_commentary | Optional[bool] | 可选（默认为 `False`）：一个标志，用于指示模型是否应避免在响应中提供额外评论。评论本质上是对话性的，不包含可验证的声明；因此，评论并不严格基于可用上下文。然而，评论可能会提供有用的背景信息，从而提高响应的有用性。 |

```python
# 包含一个 system prompt（可选）
system_prompt = "You are a helpful assistant that uses all of the provided knowledge to answer the user's query to the best of your ability."

# 在此处以字符串数组的形式提供您知识库中的知识
knowledge = [
    "There are 2 types of dogs in the world: good dogs and best dogs.",
    "There are 2 types of cats in the world: good cats and best cats.",
]

# 创建您的消息
messages = [
    ("human", "What type of cats are there in the world and what are the types?"),
]

# 通过提供知识字符串、可选的 system prompt 来调用 GLM
# 如果您想关闭 GLM 的评论功能，请向 `avoid_commentary` 参数传递 True
ai_msg = llm.invoke(
    messages, knowledge=knowledge, system_prompt=system_prompt, avoid_commentary=True
)

print(ai_msg.content)
```

## 链式调用 (Chaining)

我们可以将 Contextual 模型与输出解析器进行链式调用。

```python
from langchain_core.output_parsers import StrOutputParser

chain = llm | StrOutputParser

chain.invoke(
    messages, knowledge=knowledge, systemp_prompt=system_prompt, avoid_commentary=True
)
```
