## 聊天补全 API (Chat Completions API)

某些模型提供商提供与 OpenAI 的（旧版）[Chat Completions API](https://platform.openai.com/docs/guides/completions) 兼容的端点。在这种情况下，您可以使用带有自定义 `base_url` 的 [`ChatOpenAI`](/oss/integrations/chat/openai) 来连接这些端点。请注意，构建在 Chat Completions API 之上的功能可能不会被 `ChatOpenAI` 完全支持；在这种情况下，请考虑使用特定于供应商的类（例如 [LiteLLM](https://litellm.ai/) 的 [`ChatLiteLLM`](https://github.com/Akshay-Dongare/langchain-litellm/)（社区维护））。

<Accordion title="示例：OpenRouter">
    要使用 OpenRouter，您需要注册一个账户并获取 [API 密钥](https://openrouter.ai/docs/api-reference/authentication)。

    ```python
    from langchain_openai import ChatOpenAI

    model = ChatOpenAI(
        model="...",  # 在 OpenRouter 上指定一个可用模型
        api_key="OPENROUTER_API_KEY",
        base_url="https://openrouter.ai/api/v1",
    )
    ```

    有关更多详细信息，请参阅 [OpenRouter 文档](https://openrouter.ai/docs/quickstart)。

    <Note>
        要捕获 [推理令牌](https://openrouter.ai/docs/use-cases/reasoning-tokens)，

        1. 将导入从 `langchain_openai` 更改为 `langchain_deepseek`
        2. 使用 `ChatDeepSeek` 而不是 `ChatOpenAI`。您需要将参数 `base_url` 更改为 `api_base`。
        3. 根据需要在 `extra_body` 下调整推理参数，例如：

        ```python
        model = ChatDeepSeek(
            model="...",
            api_key="...",
            api_base="https://openrouter.ai/api/v1",
            extra_body={"reasoning": {"enabled": True}},
        )
        ```

        这是 `ChatOpenAI` 的一个已知限制，将在未来的版本中解决。
    </Note>
</Accordion>
