<Info>
    **Azure OpenAI 与 OpenAI 对比**

    Azure OpenAI 指的是托管在 [Microsoft Azure 平台](https://azure.microsoft.com/en-us/products/ai-services/openai-service) 上的 OpenAI 模型。OpenAI 也提供自己的模型 API。如需直接访问 OpenAI 服务，请使用 [`ChatOpenAI` 集成](/oss/integrations/chat/openai/)。
</Info>

<Info>
    **Azure OpenAI v1 API**

    Azure OpenAI 的 [v1 API](https://learn.microsoft.com/en-us/azure/ai-foundry/openai/api-version-lifecycle?tabs=python#next-generation-api-1)（将于 2025 年 8 月正式可用）允许您直接将 `ChatOpenAI` 与 Azure 端点配合使用。这提供了一个统一的接口，并原生支持 Microsoft Entra ID 身份验证以及自动令牌刷新。

    有关使用 `ChatOpenAI` 配合 Azure 的 v1 API 的详细信息，请参阅 [ChatOpenAI Azure 部分](/oss/integrations/chat/openai#using-with-azure-openai)。

    `AzureChatOpenAI` 目前仍支持传统的 Azure OpenAI API 版本和需要 Azure 特定配置的场景，但我们建议未来使用 [LangChain Azure AI](https://docs.langchain.com/oss/python/integrations/providers/azure_ai) 中的 `ChatOpenAI` 或 `AzureAIChatCompletionsModel`。
</Info>

<Note>
    @[`AzureChatOpenAI`] 共享与 @[`ChatOpenAI`] 相同的底层基础实现，
    后者直接与 OpenAI 服务交互。

    本页面是关于如何将您的 Azure OpenAI 服务进行身份验证并连接到 LangChain 聊天模型的快速入门指南。

    访问 [`ChatOpenAI` 文档](/oss/integrations/chat/openai/) 了解可用功能的详细信息，或前往 @[`AzureChatOpenAI`] API 参考。
</Note>

## 设置

要访问 @[`AzureChatOpenAI`] 模型，您需要创建一个 Azure 帐户，创建一个 Azure OpenAI 模型的部署，获取部署的名称和终结点，获取一个 Azure OpenAI API 密钥，并安装 `langchain-openai` 集成包。

### 安装

<CodeGroup>
    ```bash pip
    pip install -U langchain-openai
    ```
    ```bash uv
    uv add langchain-openai
    ```
</CodeGroup>

### 凭证

请参阅 [Azure 文档](https://learn.microsoft.com/en-us/azure/ai-services/openai/chatgpt-quickstart?tabs=command-line%2Cpython-new&pivots=programming-language-python) 来创建您的部署并生成 API 密钥。完成此操作后，设置 `AZURE_OPENAI_API_KEY` 和 `AZURE_OPENAI_ENDPOINT` 环境变量：

```python
import getpass
import os

if "AZURE_OPENAI_API_KEY" not in os.environ:
    os.environ["AZURE_OPENAI_API_KEY"] = getpass.getpass(
        "输入您的 AzureOpenAI API 密钥: "
    )
os.environ["AZURE_OPENAI_ENDPOINT"] = "https://YOUR-ENDPOINT.openai.azure.com/"
```

要启用模型调用的自动化跟踪，请设置您的 [LangSmith](https://docs.smith.langchain.com/) API 密钥：

```python
os.environ["LANGSMITH_API_KEY"] = getpass.getpass("输入您的 LangSmith API 密钥: ")
os.environ["LANGSMITH_TRACING"] = "true"
```

## 实例化

现在我们可以实例化模型对象并生成聊天补全。

- 将 `azure_deployment` 替换为您的部署名称，
- 您可以在此处找到最新支持的 `api_version`：[learn.microsoft.com/en-us/azure/ai-services/openai/reference](https://learn.microsoft.com/en-us/azure/ai-services/openai/reference)。

```python
from langchain_openai import AzureChatOpenAI

llm = AzureChatOpenAI(
    azure_deployment="gpt-35-turbo",  # 或您的部署名称
    api_version="2023-06-01-preview",  # 或您的 API 版本
    temperature=0,
    max_tokens=None,
    timeout=None,
    max_retries=2,
    # 其他参数...
)
```

## 流式传输使用情况元数据

OpenAI 的聊天补全 API 默认不流式传输 Token 使用情况统计信息（请参阅 [API 参考](https://platform.openai.com/docs/api-reference/completions/create#completions-create-stream_options)）。

要在使用 @[`ChatOpenAI`] 或 `AzureChatOpenAI` 进行流式传输时恢复 Token 计数，请在实例化参数或调用时设置 `stream_usage=True`：

```python
from langchain_openai import AzureChatOpenAI

llm = AzureChatOpenAI(model="gpt-4.1-mini", stream_usage=True)  # [!code highlight]
```

## 指定模型版本

Azure OpenAI 的响应包含 `model_name` 响应元数据属性，即用于生成响应的模型名称。但是，与原生的 OpenAI 响应不同，它不包含模型的具体版本，该版本是在 Azure 的部署中设置的。例如，它无法区分 `gpt-35-turbo-0125` 和 `gpt-35-turbo-0301`。这使得很难知道是哪个版本的模型生成了响应，这可能导致例如使用 `OpenAICallbackHandler` 时计算的总成本错误。

为了解决这个问题，您可以向 @[`AzureChatOpenAI`] 类传递 `model_version` 参数，该参数将添加到 LLM 输出的模型名称中。这样您就可以轻松区分不同版本的模型。

```python
pip install -qU langchain-community
```

```python
from langchain_community.callbacks import get_openai_callback

with get_openai_callback() as cb:
    llm.invoke(messages)
    print(
        f"总成本 (USD): ${format(cb.total_cost, '.6f')}"
    )  # 在不指定模型版本的情况下，为每 1k 输入和输出 Token 使用固定费率 0.002 USD
```

```output
总成本 (USD): $0.000063
```

```python
llm_0301 = AzureChatOpenAI(
    azure_deployment="gpt-35-turbo",  # 或您的部署名称
    api_version="2023-06-01-preview",  # 或您的 API 版本
    model_version="0301",
)
with get_openai_callback() as cb:
    llm_0301.invoke(messages)
    print(f"总成本 (USD): ${format(cb.total_cost, '.6f')}")
```

```output
总成本 (USD): $0.000074
```
