## 设置 (Setup)

`langchain-gradient` 使用 DigitalOcean Gradient 平台。

请在 DigitalOcean 上创建一个账户，从 Gradient 平台获取一个 `DIGITALOCEAN_INFERENCE_KEY` API 密钥，并安装 `langchain-gradient` 集成包。

### 凭证 (Credentials)

前往 [DigitalOcean 登录](https://cloud.digitalocean.com/login)

1. 注册/登录 DigitalOcean 云控制台
2. 进入 Gradient 平台，导航到 Serverless Inference（无服务器推理）。
3. 点击创建模型访问密钥 (Create model access key)，输入一个名称，然后创建密钥。

完成此操作后，设置 `DIGITALOCEAN_INFERENCE_KEY` 环境变量：

```python
import getpass
import os

if not os.getenv("DIGITALOCEAN_INFERENCE_KEY"):
    os.environ["DIGITALOCEAN_INFERENCE_KEY"] = getpass.getpass(
        "Enter your DIGITALOCEAN_INFERENCE_KEY API key: "
    )
```

如果您希望对模型调用进行自动化的追踪（tracing），可以通过取消注释以下代码来设置您的 [LangSmith](https://docs.langchain.com/langsmith/home) API 密钥：

```python
os.environ["LANGSMITH_TRACING"] = "true"
os.environ["LANGSMITH_API_KEY"] = getpass.getpass("Enter your LangSmith API key: ")
```

### 安装 (Installation)

DigitalOcean Gradient 集成位于 `langchain-gradient` 包中：

```python
pip install -qU langchain-gradient
```

## 实例化 (Instantiation)

现在我们可以实例化模型对象并生成聊天补全：

```python
from langchain_gradient import ChatGradient

llm = ChatGradient(
    model="llama3.3-70b-instruct",
    # other params...
)
```

## 链式调用 (Chaining)

我们可以像下面这样将模型与提示模板 (Prompt Template) 链接起来：

```python
from langchain_core.prompts import ChatPromptTemplate

prompt = ChatPromptTemplate(
    [
        (
            "system",
            '你是一位知识渊博的助手。请仔细阅读提供的上下文并回答用户的问题。如果答案存在于上下文中，请引用相关的句子。如果不存在，请回复 "Not found in context"。',
        ),
        ("human", "上下文: {context}\n问题: {question}"),
    ]
)

chain = prompt | llm
chain.invoke(
    {
        "context": (
            "埃菲尔铁塔位于巴黎，于 1889 年竣工。它由古斯塔夫·埃菲尔的工程公司设计。该塔是世界上最知名的建筑之一。自由女神像是法国送给美国的礼物。"
        ),
        "question": "谁设计了埃菲尔铁塔，它是什么时候竣工的？",
    }
)
```
