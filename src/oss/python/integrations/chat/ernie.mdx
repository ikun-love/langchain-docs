[ERNIE-Bot](https://cloud.baidu.com/doc/WENXINWORKSHOP/s/jlil56u11) 是百度开发的一个大型语言模型，涵盖了海量的中文数据。
本指南介绍了如何开始使用文心一言（ErnieBot）的聊天模型。

**弃用警告 (Deprecated Warning)**

我们建议用户从 `langchain_community.chat_models.ErnieBotChat` 迁移到 `langchain_community.chat_models.QianfanChatEndpoint`。

`QianfanChatEndpoint` 的文档可以在 [这里](/oss/integrations/chat/baidu_qianfan_endpoint/) 查看。

我们推荐用户使用 `QianfanChatEndpoint` 的 4 个主要原因：

1. `QianfanChatEndpoint` 支持千帆平台上的更多大语言模型（LLMs）。
2. `QianfanChatEndpoint` 支持流式（streaming）模式。
3. `QianfanChatEndpoint` 支持函数调用（function calling）功能。
4. `ErnieBotChat` 已不再维护，因此已被弃用。

迁移建议：

- 将 `ernie_client_id` 更改为 `qianfan_ak`，同时将 `ernie_client_secret` 更改为 `qianfan_sk`。
- 安装 `qianfan` 包。例如：`pip install qianfan`
- 将代码中的 `ErnieBotChat` 替换为 `QianfanChatEndpoint`。

```python
from langchain_community.chat_models.baidu_qianfan_endpoint import QianfanChatEndpoint

chat = QianfanChatEndpoint(
    qianfan_ak="your qianfan ak",
    qianfan_sk="your qianfan sk",
)
```

## 使用方法 (Usage)

```python
from langchain_community.chat_models import ErnieBotChat
from langchain.messages import HumanMessage

chat = ErnieBotChat(
    ernie_client_id="YOUR_CLIENT_ID", ernie_client_secret="YOUR_CLIENT_SECRET"
)
```

或者，您可以在环境变量中设置 `client_id` 和 `client_secret`：

```bash
export ERNIE_CLIENT_ID=YOUR_CLIENT_ID
export ERNIE_CLIENT_SECRET=YOUR_CLIENT_SECRET
```

```python
chat([HumanMessage(content="hello there, who are you?")])
```
