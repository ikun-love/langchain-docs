[Composio](https://composio.dev) 是一个集成平台，通过统一 API 接口，为 AI 智能体提供对 GitHub、Slack、Notion 等流行应用中 500 多个工具的访问权限。它负责处理身份验证、权限管理和事件驱动的工作流，使用户体能够与外部服务进行交互。

## 概览 (Overview)

### 集成详情 (Integration details)

### 工具特性 (Tool features)

- **超过 500 个工具访问权限**: 为 GitHub、Slack、Gmail、Jira、Notion 等应用提供预构建的集成。
- **身份验证管理**: 自动处理 OAuth 流程、API 密钥和身份验证状态。
- **事件驱动工作流**: 能够基于外部事件（如新的 Slack 消息、GitHub Issue 等）来触发智能体的操作。
- **细粒度权限控制**: 可以按用户控制工具访问权限和数据暴露程度。
- **自定义工具支持**: 允许添加私有 API 和内部工具。

## 实例化 (Instantiation)

使用 LangChain 提供商初始化 Composio，并从特定的工具包 (toolkits) 中获取工具。每个工具包代表一项服务（例如 GitHub），其中包含多个工具（可以执行的操作）。

```python 初始化 Composio icon="robot"
from composio import Composio
from composio_langchain import LangchainProvider

# 使用 LangChain 提供商初始化 Composio
composio = Composio(provider=LangchainProvider())

# 从特定的工具包中获取工具
# 您可以指定一个或多个工具包
tools = composio.tools.get(
    user_id="default",
    toolkits=["GITHUB"]
)

print(f"从 GitHub 工具包加载了 {len(tools)} 个工具")
```

tools = composio.tools.get(

您可以不加载整个工具包，而是加载特定的工具：

## 在智能体中使用 (Use within an agent)

这是一个完整的示例，展示了如何将 Composio 工具与 LangChain 智能体结合使用，以与 GitHub 进行交互：

<ChatModelTabs customVarName="llm" />

```python
import os
import getpass

if not os.environ.get("OPENAI_API_KEY"):
    os.environ["OPENAI_API_KEY"] = getpass.getpass("输入您的 OpenAI API 密钥: ")
```

```python
# | output: false
# | echo: false

from langchain.chat_models import init_chat_model

llm = init_chat_model(model="gpt-5", model_provider="openai")
```

```python 使用 Composio 工具的智能体 icon="robot"
from composio import Composio
from composio_langchain import LangchainProvider
from langchain import hub
from langchain.agents import AgentExecutor, create_openai_functions_agent

# 拉取提示模板
prompt = hub.pull("hwchase17/openai-functions-agent")

# 初始化 Composio
composio = Composio(provider=LangchainProvider())

# 获取 GitHub 工具
tools = composio.tools.get(user_id="default", toolkits=["GITHUB"])

# 定义任务
task = "在 GitHub 上 Star 仓库 composiohq/composio"

# 创建智能体
agent = create_openai_functions_agent(llm, tools, prompt)
agent_executor = AgentExecutor(agent=agent, tools=tools, verbose=True)

# 使用 agent_executor 执行
agent_executor.invoke({"input": task})
```

### 事件驱动工作流 (Event-driven workflows)

Composio 支持基于外部事件触发智能体。当连接的应用（如新的 GitHub 提交或 Slack 消息）中发生事件时，触发器会自动将结构化的数据（payload）发送到您的应用程序。

#### 创建触发器 (Creating a trigger)

首先为要监控的事件创建触发器：

```python
from composio import Composio

composio = Composio(api_key="your_api_key")
user_id = "user_123"

# 查看创建触发器所需的具体配置
trigger_type = composio.triggers.get_type("GITHUB_COMMIT_EVENT")
print(trigger_type.config)

# 使用所需的配置创建触发器
trigger = composio.triggers.create(
    slug="GITHUB_COMMIT_EVENT",
    user_id=user_id,
    trigger_config={
        "owner": "composiohq",
        "repo": "composio"
    }
)

print(f"触发器创建成功: {trigger.trigger_id}")
```

#### 订阅触发器（开发阶段） (Subscribing to triggers (Development))

对于本地开发和原型设计，您可以直接订阅触发器：

```python
from composio import Composio

composio = Composio(api_key="your_api_key")

# 订阅触发器事件
subscription = composio.triggers.subscribe()

# 定义事件处理器
@subscription.handle(trigger_id="your_trigger_id")
def handle_github_commit(data):
    print(f"检测到新提交: {data}")
    # 使用您的智能体处理事件
    # ... 使用 commit_data 调用您的智能体

# 注意：生产环境请使用 Webhooks
```

#### Webhooks（生产环境） (Webhooks (Production))

在生产环境中，请在 [Composio 控制面板](https://platform.composio.dev/settings/events) 中配置 Webhooks：

```python
from fastapi import FastAPI, Request
import json

app = FastAPI()

@app.post("/webhook")
async def webhook_handler(request: Request):
    # 获取 Webhook 数据载荷 (payload)
    payload = await request.json()

    print("接收到触发事件:")
    print(json.dumps(payload, indent=2))

    # 使用事件数据处理（调用智能体）
    if payload.get("triggerSlug") == "GITHUB_COMMIT_EVENT":
        commit_data = payload.get("payload")
        # ... 使用 commit_data 调用您的智能体

    return {"status": "success"}
```

更多详细信息，请参阅 [Composio 触发器文档](https://docs.composio.dev/docs/using-triggers)

## 身份验证设置 (Authentication setup)

在使用需要身份验证的工具之前，用户需要连接他们的账户：

```python
from composio import Composio

composio = Composio()

# 获取用户的身份验证 URL
auth_connection = composio.integrations.create(
    user_id="user_123",
    integration="github"
)

print(f"请在以下地址进行身份验证: {auth_connection.redirect_url}")

# 身份验证完成后，用户的已连接账户即可用于工具调用
```

## 高级特性 (Advanced features)

### 自定义工具 (Custom tools)

Composio 允许您创建自定义工具，以便与内置工具一起使用。有两种类型：

#### 独立工具 (Standalone tools)

不需要身份验证的简单工具：

```python
from pydantic import BaseModel, Field
from composio import Composio

composio = Composio()

class AddTwoNumbersInput(BaseModel):
    a: int = Field(..., description="要相加的第一个数字")
    b: int = Field(..., description="要相加的第二个数字")

# 函数名将用作工具的 slug
@composio.tools.custom_tool
def add_two_numbers(request: AddTwoNumbersInput) -> int:
    """将两个数字相加。"""
    return request.a + request.b

# 与您的智能体一起使用
tools = composio.tools.get(user_id="default", toolkits=["GITHUB"])
tools.append(add_two_numbers)
```

#### 基于工具包的工具 (Toolkit-based tools)

需要身份验证并可以使用工具包凭证的工具：

```python
from composio.types import ExecuteRequestFn

class GetIssueInfoInput(BaseModel):
    issue_number: int = Field(
        ..., description="要查询信息的 Issue 的编号"
    )

@composio.tools.custom_tool(toolkit="github")
def get_issue_info(
    request: GetIssueInfoInput,
    execute_request: ExecuteRequestFn,
    auth_credentials: dict,
) -> dict:
    """获取 GitHub Issue 的信息。"""
    response = execute_request(
        endpoint=f"/repos/composiohq/composio/issues/{request.issue_number}",
        method="GET",
        parameters=[
            {
                "name": "Accept",
                "value": "application/vnd.github.v3+json",
                "type": "header",
            },
            {
                "name": "Authorization",
                "value": f"Bearer {auth_credentials['access_token']}",
                "type": "header",
            },
        ],
    )
    return {"data": response.data}
```

执行自定义工具：

```python
response = composio.tools.execute(
    user_id="default",
    slug="get_issue_info",  # 使用函数名作为 slug
    arguments={"issue_number": 1},
)
```

更多详细信息，请参阅 [Composio 自定义工具文档](https://docs.composio.dev/docs/custom-tools)

### 细粒度权限 (Fine-grained permissions)

控制工具可以执行哪些操作：

```python
# 获取具有特定权限的工具
tools = composio.tools.get(
    user_id="default",
    toolkits=["GITHUB"],
    # 限制为只读操作
    permissions=["read"]
)
```
