[Composio](https://composio.dev) 是一个集成平台，通过统一 API 为 AI 智能体提供对 GitHub、Slack、Notion 等流行应用中 500 多个工具的访问权限，负责处理身份验证、权限和事件驱动的工作流。

## 概述 (Overview)

### 集成详情 (Integration details)

| 类型 (Class) | 包 (Package) | 可序列化 (Serializable) | [JS 支持](https://js.langchain.com/docs/integrations/tools/composio) | 版本 (Version) |
|:---|:---|:---:|:---:|:---:|
| Composio | [composio-langchain](https://pypi.org/project/composio-langchain/) | ❌ | ✅ | ![PyPI - Version](https://img.shields.io/pypi/v/composio-langchain?style=flat-square&label=%20) |

### 工具功能 (Tool features)

- **500+ 工具访问**: 为 GitHub、Slack、Gmail、Jira、Notion 等提供预构建的集成。
- **身份验证管理**: 处理 OAuth 流程、API 密钥和身份验证状态。
- **事件驱动工作流**: 根据外部事件（如新的 Slack 消息、GitHub Issue 等）触发智能体执行操作。
- **细粒度权限**: 按用户控制工具访问和数据暴露。
- **自定义工具支持**: 添加专有 API 和内部工具。

## 实例化 (Instantiation)

使用 LangChain Provider 初始化 Composio，并从特定的工具包中获取工具。每个工具包代表一个服务（例如 GitHub），其中包含多个工具（您可以执行的操作）。

```python Initialize Composio icon="robot"
from composio import Composio
from composio_langchain import LangchainProvider

# 使用 LangChain Provider 初始化 Composio
composio = Composio(provider=LangchainProvider())

# 从特定的工具包中获取工具
# 您可以指定一个或多个工具包
tools = composio.tools.get(
    user_id="default",
    toolkits=["GITHUB"]
)

print(f"从 GitHub 工具包加载了 {len(tools)} 个工具")
```

### 从多个工具包获取工具

您可以一次性加载来自多个服务的工具：

```python

tools = composio.tools.get(
```

您可以加载特定的工具而不是整个工具包：

```python
# 按名称获取特定工具
tools = composio.tools.get(
```

Composio 支持多用户场景，具有特定于用户的身份验证：

### 事件驱动工作流 (Event-driven workflows)

Composio 支持根据外部事件触发智能体。当连接的应用中发生事件（例如新的 GitHub 提交或 Slack 消息）时，触发器会自动将结构化有效负载发送到您的应用程序。

#### 创建触发器 (Creating a trigger)

首先，为您想要监控的事件创建触发器：

```python
from composio import Composio

composio = Composio(api_key="your_api_key")
user_id = "user_123"

# 检查触发器所需的配置
trigger_type = composio.triggers.get_type("GITHUB_COMMIT_EVENT")
print(trigger_type.config)

# 使用所需配置创建触发器
trigger = composio.triggers.create(
    slug="GITHUB_COMMIT_EVENT",
    user_id=user_id,
    trigger_config={
        "owner": "composiohq",
        "repo": "composio"
    }
)

print(f"触发器创建成功: {trigger.trigger_id}")
```

#### 订阅触发器（开发）(Subscribing to triggers (Development))

对于本地开发和原型设计，您可以直接订阅触发器：

```python
from composio import Composio

composio = Composio(api_key="your_api_key")

# 订阅触发器事件
subscription = composio.triggers.subscribe()

# 定义事件处理程序
@subscription.handle(trigger_id="your_trigger_id")
def handle_github_commit(data):
    print(f"检测到新提交: {data}")
    # 使用您的智能体处理事件
    # ... 使用 task 调用您的智能体

# 注意：生产环境请使用 Webhook
```

#### Webhook（生产环境）(Webhooks (Production))

对于生产环境，请在 [Composio 仪表板](https://platform.composio.dev/settings/events) 中配置 Webhook：

```python
from fastapi import FastAPI, Request
import json

app = FastAPI()

@app.post("/webhook")
async def webhook_handler(request: Request):
    # 获取 Webhook 有效载荷 (payload)
    payload = await request.json()

    print("收到触发事件:")
    print(json.dumps(payload, indent=2))

    # 使用您的智能体处理事件
    if payload.get("triggerSlug") == "GITHUB_COMMIT_EVENT":
        commit_data = payload.get("payload")
        # ... 使用 commit_data 调用您的智能体

    return {"status": "success"}
```

有关更多详细信息，请参阅 [Composio 触发器文档](https://docs.composio.dev/docs/using-triggers)

## 身份验证设置 (Authentication setup)

在使用需要身份验证的工具之前，用户需要连接他们的账户：

```python
from composio import Composio

composio = Composio()

# 获取用户的身份验证 URL
auth_connection = composio.integrations.create(
    user_id="user_123",
    integration="github"
)

print(f"请在以下地址进行身份验证: {auth_connection.redirect_url}")

# 身份验证后，用户的连接账户将可用，工具将使用其凭据正常工作
```

## 高级功能 (Advanced features)

### 自定义工具 (Custom tools)

Composio 允许您创建可与内置工具一起使用的自定义工具。有两种类型：

#### 独立工具 (Standalone tools)

不需要身份验证的简单工具：

```python
from pydantic import BaseModel, Field
from composio import Composio

composio = Composio()

class AddTwoNumbersInput(BaseModel):
    a: int = Field(..., description="要相加的第一个数字")
    b: int = Field(..., description="要相加的第二个数字")

# 函数名将用作工具 slug
@composio.tools.custom_tool
def add_two_numbers(request: AddTwoNumbersInput) -> int:
    """将两个数字相加。"""
    return request.a + request.b

# 与您的智能体一起使用
tools = composio.tools.get(user_id="default", toolkits=["GITHUB"])
tools.append(add_two_numbers)
```

#### 基于工具包的工具 (Toolkit-based tools)

需要身份验证并可以使用工具包凭据的工具：

```python
from composio.types import ExecuteRequestFn

class GetIssueInfoInput(BaseModel):
    issue_number: int = Field(
        ..., description="要获取信息的 Issue 编号"
    )

@composio.tools.custom_tool(toolkit="github")
def get_issue_info(
    request: GetIssueInfoInput,
    execute_request: ExecuteRequestFn,
    auth_credentials: dict,
) -> dict:
    """获取有关 GitHub Issue 的信息。"""
    response = execute_request(
        endpoint=f"/repos/composiohq/composio/issues/{request.issue_number}",
        method="GET",
        parameters=[
            {
                "name": "Accept",
                "value": "application/vnd.github.v3+json",
                "type": "header",
            },
            {
                "name": "Authorization",
                "value": f"Bearer {auth_credentials['access_token']}",
                "type": "header",
            },
        ],
    )
    return {"data": response.data}
```

执行自定义工具：

```python
response = composio.tools.execute(
    user_id="default",
    slug="get_issue_info",  # 使用函数名作为 slug
    arguments={"issue_number": 1},
)
```

有关更多详细信息，请参阅 [Composio 自定义工具文档](https://docs.composio.dev/docs/custom-tools)

### 细粒度权限 (Fine-grained permissions)

控制工具可以执行的操作：

```python
# 获取具有特定权限的工具
tools = composio.tools.get(
    user_id="default",
    toolkits=["GITHUB"],
    # 限制为只读操作
    permissions=["read"]
)
```
