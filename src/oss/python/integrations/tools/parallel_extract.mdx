>[Parallel](https://platform.parallel.ai/) 是一个专为 LLM 和 AI 应用设计的实时网页搜索与内容提取平台。

`ParallelExtractTool` 提供了对 Parallel 的 Extract API 的访问权限，该 API 可以从网页中提取干净、结构化的内容。

### 工具功能

- **内容提取干净**: 从网页中提取主要内容，去除广告、导航和样板代码（boilerplate）
- **Markdown 格式化**: 以干净的 Markdown 格式返回内容
- **批量处理**: 在单次 API 调用中从多个 URL 中提取内容
- **元数据提取**: 包括标题、发布日期和其他元数据
- **内容长度控制**: 配置每次提取的最大字符数
- **错误处理**: 使用详细的错误信息优雅地处理提取失败的情况
- **异步支持**: 全面的 async/await 支持，以提升性能

## 设置

该集成位于 `langchain-parallel` 包中。

```python
pip install -qU langchain-parallel
```
### 凭证

请访问 [Parallel](https://platform.parallel.ai) 注册并生成一个 API 密钥。生成密钥后，设置 `PARALLEL_API_KEY` 环境变量：

```python
import getpass
import os

if not os.environ.get("PARALLEL_API_KEY"):
    os.environ["PARALLEL_API_KEY"] = getpass.getpass("Parallel API key:\n")
```

## 实例化

此处展示了如何实例化 `ParallelExtractTool` 的一个实例。可以使用 API 密钥和内容长度参数来配置该工具：

```python
from langchain_parallel import ParallelExtractTool

# 基本实例化 - API 密钥从环境变量读取
tool = ParallelExtractTool()

# 使用显式 API 密钥和自定义设置
tool = ParallelExtractTool(
    api_key="your-api-key",
    base_url="https://api.parallel.ai",  # 默认值
    max_chars_per_extract=5000,  # 限制内容长度
)
```

## 调用

### 直接使用参数调用

你可以传入一个 URL 列表来调用该工具以提取内容：

```python
# 从单个 URL 中提取内容
result = tool.invoke(
    {"urls": ["https://en.wikipedia.org/wiki/Artificial_intelligence"]}
)

print(f"提取了 {len(result)} 个结果")
print(f"标题: {result[0]['title']}")
print(f"URL: {result[0]['url']}")
print(f"内容长度: {len(result[0]['content'])} 个字符")
print(f"内容预览: {result[0]['content'][:200]}...")
```

```python
# 从多个 URL 中提取内容
result = tool.invoke(
    {
        "urls": [
            "https://en.wikipedia.org/wiki/Machine_learning",
            "https://en.wikipedia.org/wiki/Deep_learning",
            "https://en.wikipedia.org/wiki/Natural_language_processing",
        ]
    }
)

print(f"提取了 {len(result)} 个结果")
for i, item in enumerate(result, 1):
    print(f"\n{i}. {item['title']}")
    print(f"   URL: {item['url']}")
    print(f"   内容长度: {len(item['content'])} 个字符")

# 示例响应结构:
# [
#     {
#         "url": "https://example.com/article",
#         "title": "文章标题",
#         "content": "# 文章标题\n\n主要内容为 markdown 格式...",
#         "publish_date": "2024-01-15"  # 可选
#     }
# ]
```

### 使用 `ToolCall` 调用

我们也可以使用模型生成的 `ToolCall` 来调用该工具，在这种情况下将返回一个 `ToolMessage`：

```python
# 这通常由模型生成，但我们在此处直接创建工具调用以作演示。
model_generated_tool_call = {
    "args": {
        "urls": [
            "https://en.wikipedia.org/wiki/Climate_change",
            "https://en.wikipedia.org/wiki/Renewable_energy",
        ]
    },
    "id": "call_123",
    "name": tool.name,  # "parallel_extract"
    "type": "tool_call",
}

result = tool.invoke(model_generated_tool_call)
print(result)
print(f"工具名称: {tool.name}")  # parallel_extract
print(f"工具描述: {tool.description}")
```

### 异步使用

该工具支持完整的 async/await 操作，以便在异步应用程序中获得更好的性能：

```python
async def extract_async():
    return await tool.ainvoke(
        {
            "urls": [
                "https://en.wikipedia.org/wiki/Python_(programming_language)",
                "https://en.wikipedia.org/wiki/JavaScript",
            ]
        }
    )


# 运行异步提取
result = await extract_async()
print(f"异步提取了 {len(result)} 个结果")
```

### 高级功能

提取工具支持使用搜索目标/查询、获取策略（fetch policies）以及对摘录（excerpts）和完整内容进行精细控制的聚焦提取：

```python
# 使用搜索目标提取聚焦摘要
result = tool.invoke(
    {
        "urls": ["https://en.wikipedia.org/wiki/Artificial_intelligence"],
        "search_objective": "AI 的主要应用和伦理关注点是什么？",
        "excerpts": {"max_chars_per_result": 2000},
        "full_content": False,
    }
)

print(f"提取到的聚焦摘要数量: {len(result[0].get('excerpts', []))} 个摘要")
print(f"内容预览: {result[0]['content'][:200]}...")

# 使用获取策略提取内容，以获取最新内容
result = tool.invoke(
    {
        "urls": ["https://en.wikipedia.org/wiki/Quantum_computing"],
        "fetch_policy": {
            "max_age_seconds": 86400,  # 1 天的缓存
            "timeout_seconds": 60,
            "disable_cache_fallback": False,
        },
        "full_content": {"max_chars_per_result": 5000},
    }
)

print(f"内容长度: {len(result[0]['content'])} 个字符")
```

### 错误处理

该工具能够优雅地处理提取失败的 URL，并将它们包含在结果中并带有错误信息：

```python
# 有效和无效 URL 的混合
result = tool.invoke(
    {
        "urls": [
            "https://en.wikipedia.org/wiki/Artificial_intelligence",
            "https://this-domain-does-not-exist-12345.com/",
        ]
    }
)

for item in result:
    if "error_type" in item:
        print(f"失败: {item['url']}")
        print(f"错误: {item['content']}")
    else:
        print(f"成功: {item['url']}")
        print(f"提取了 {len(item['content'])} 个字符")
```

## 最佳实践

- **批量处理 URL**: 在单次调用中提取多个 URL 以获得更好的性能
- **设置内容限制**: 使用 `max_chars_per_extract` 来控制响应大小和 Token 使用量
- **处理错误**: 检查结果中是否存在 `error_type` 以识别提取失败的情况
- **异步使用性能**: 在异步应用程序中使用 `ainvoke()` 以获得更好的性能
- **元数据字段**: 在可用时使用 `publish_date` 和其他元数据以提供上下文

## 响应格式

该工具返回一个字典列表，格式如下：

```python
[
    {
        "url": "https://example.com/article",

        "content": "# 文章标题\n\n主要内容格式化为 markdown...",
        "publish_date": "2024-01-15"  # 如果可用，则为可选
    },
    # 对于提取失败的情况:
    {
        "url": "https://failed-site.com",
        "title": None,
        "content": "Error: 404 Not Found",
        "error_type": "http_error"
    }
]
```
