>[Apify Actors](https://docs.apify.com/platform/actors) 是专为各种网页抓取、爬虫和数据提取任务设计的云端程序。这些 Actor 促进了网络数据的自动化收集，使用户能够高效地提取、处理和存储信息。Actor 可用于执行各种任务，例如抓取电子商务网站的产品详情、监控价格变化或收集搜索引擎结果。它们与 [Apify Datasets](https://docs.apify.com/platform/storage/dataset) 无缝集成，允许将 Actor 收集的结构化数据以 JSON、CSV 或 Excel 等格式存储、管理和导出，以供进一步分析或使用。

## 概述

本 Notebook 将引导您了解如何使用 [Apify Actors](https://docs.apify.com/platform/actors) 结合 LangChain 来自动化网页抓取和数据提取。`langchain-apify` 包将 Apify 的云端工具与 LangChain Agent 相集成，从而为 AI 应用实现高效的数据收集和处理。

## 实例化

在这里，我们实例化 `ApifyActorsTool`，以便调用 [RAG Web Browser](https://apify.com/apify/rag-web-browser) Apify Actor。此 Actor 为 AI 和 LLM 应用提供了网页浏览功能，类似于 ChatGPT 中的网页浏览功能。可以这样使用 [Apify Store](https://apify.com/store) 中的任何 Actor。

```python
from langchain_apify import ApifyActorsTool

tool = ApifyActorsTool("apify/rag-web-browser")
```

## 调用 (Invocation)

`ApifyActorsTool` 接受一个参数，即 `run_input`——一个作为运行输入传递给 Actor 的字典。运行输入的 Schema 文档可以在 Actor 详情页面的输入部分找到。请参阅 [RAG Web Browser 输入 Schema](https://apify.com/apify/rag-web-browser/input-schema)。

```python
tool.invoke({"run_input": {"query": "what is apify?", "maxResults": 2}})
```

## 链式调用 (Chaining)

我们可以将创建的工具提供给一个 [Agent](https://python.langchain.com/docs/tutorials/agents/)。当要求搜索信息时，Agent 将调用 Apify Actor，Actor 将搜索网络，然后检索搜索结果。

```python
pip install langgraph langchain-openai
```

```python
from langchain.messages import ToolMessage
from langchain_openai import ChatOpenAI
from langchain.agents import create_agent


model = ChatOpenAI(model="gpt-4o")
tools = [tool]
graph = create_agent(model, tools=tools)
```

```python
inputs = {"messages": [("user", "search for what is Apify")]}
for s in graph.stream(inputs, stream_mode="values"):
    message = s["messages"][-1]
    # 跳过工具消息
    if isinstance(message, ToolMessage):
        continue
    message.pretty_print()
```
