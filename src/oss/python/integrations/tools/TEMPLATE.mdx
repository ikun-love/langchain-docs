## 调用

### 直接调用

待办：描述工具的参数，并填充它们。

```python 调用工具 icon="rocket"
tool.invoke({...})
```

### 作为 ToolCall 调用

我们也可以使用模型生成的 `ToolCall` 来调用工具，在这种情况下会返回一个 @[`ToolMessage`]：

```python ToolCall icon="toolbox"
# 这通常由模型生成，但我们在此处直接为演示目的创建一个工具调用。
model_generated_tool_call = {
    "args": {...},  # TODO: 填写内容
    "id": "1",
    "name": tool.name,
    "type": "tool_call",
}
tool.invoke(model_generated_tool_call)
```

### 在 Agent 中调用

我们可以在 Agent 中使用我们的工具。为此，我们需要一个具有工具调用功能的模型。

```python 带有工具的 Agent icon="robot"
# pip install -qU "langchain[anthropic]" 来调用模型
from langchain.agents import create_agent

tools = [tool]
agent = create_agent(
    model="claude-sonnet-4-5-20250929",
    tools=tools,
)

# 运行 Agent
agent.invoke(
    {"messages": [{"role": "user", "content": "INSERT QUERY"}]}
)
```
