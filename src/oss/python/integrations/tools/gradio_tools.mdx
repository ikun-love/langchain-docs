在 `Hugging Face Spaces` 上有数千个 `Gradio` 应用。这个库让它们触手可及，就像在 LLM 的指尖一样 🦾

具体来说，`gradio-tools` 是一个 Python 库，用于将 `Gradio` 应用转换为工具，以便基于大型语言模型 (LLM) 的智能体能够利用这些工具来完成任务。例如，LLM 可以使用一个 `Gradio` 工具来转录它在网上找到的语音录音，然后为您总结内容。或者，它可以使用另一个 `Gradio` 工具对您 Google Drive 上的文档执行 OCR（光学字符识别），然后回答有关该文档的问题。

如果您想使用预构建工具以外的 Space，创建自己的工具也非常简单。请参阅 `gradio-tools` 文档的这一部分，了解如何执行此操作。我们欢迎所有贡献！

```python
pip install -qU  gradio_tools langchain-community
```

## 在智能体中使用

```python
from gradio_tools.tools import (
    ImageCaptioningTool,
    StableDiffusionPromptGeneratorTool,
    StableDiffusionTool,
    TextToVideoTool,
)
from langchain.agents import initialize_agent
from langchain.memory import ConversationBufferMemory
from langchain_openai import OpenAI

llm = OpenAI(temperature=0)
memory = ConversationBufferMemory(memory_key="chat_history")
tools = [
    StableDiffusionTool().langchain,
    ImageCaptioningTool().langchain,
    StableDiffusionPromptGeneratorTool().langchain,
    TextToVideoTool().langchain,
]


agent = initialize_agent(
    tools, llm, memory=memory, agent="conversational-react-description", verbose=True
)
output = agent.run(
    input=(
        "请创建一张狗骑滑板的照片，但在使用图像生成器之前请改进我的提示词。"
        "请为生成的图像添加说明，并使用改进后的提示词为其创建视频。"
    )
)
```
