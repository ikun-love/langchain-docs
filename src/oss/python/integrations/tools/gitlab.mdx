---
title: GitLab 工具包
---

`GitLab` 工具包包含使 LLM 代理能够与 gitlab 存储库交互的工具。
该工具是 [python-gitlab](https://github.com/python-gitlab/python-gitlab) 库的包装器（wrapper）。

## 快速开始

1. 安装 `python-gitlab` 库
2. 创建一个 GitLab 个人访问令牌（Personal Access Token）
3. 设置你的环境变量
4. 使用 `toolkit.get_tools()` 将工具传递给你的代理

下面将详细解释每一步骤。

1. **获取 Issue (Get Issues)** - 从仓库中获取问题列表。

2. **获取单个 Issue (Get Issue)** - 获取特定问题的详细信息。

3. **评论 Issue (Comment on Issue)** - 对特定问题发表评论。

4. **创建合并请求 (Create Merge Request)** - 从机器人的工作分支向基础分支（base branch）创建一个合并请求。

5. **创建文件 (Create File)** - 在仓库中创建一个新文件。

6. **读取文件 (Read File)** - 从仓库中读取一个文件。

7. **更新文件 (Update File)** - 更新仓库中的一个文件。

8. **删除文件 (Delete File)** - 删除仓库中的一个文件。

## 设置

### 1. 安装 `python-gitlab` 库

```python
pip install -qU  python-gitlab langchain-community
```

### 2. 创建一个 GitLab 个人访问令牌

请 [点击此处](https://docs.gitlab.com/ee/user/profile/personal_access_tokens.html) 按照说明创建一个 GitLab 个人访问令牌。请确保你的应用具有以下**仓库权限**：

* `read_api`
* `read_repository`
* `write_repository`

### 3. 设置环境变量

在初始化代理之前，需要设置以下环境变量：

* **GITLAB_URL** - 托管 GitLab 的 URL。默认为 "[gitlab.com](https://gitlab.com)"。
* **GITLAB_PERSONAL_ACCESS_TOKEN** - 你在上一步中创建的个人访问令牌。
* **GITLAB_REPOSITORY** - 你希望机器人操作的 GitLab 仓库名称。格式必须是 `\{username\}/\{repo-name\}`。
* **GITLAB_BRANCH** - 机器人将进行提交的分支。默认为 `'main'`。
* **GITLAB_BASE_BRANCH** - 仓库的基础分支，通常是 'main' 或 'master'。合并请求将基于此分支创建。默认为 `'main'`。

## 示例：简单代理

```python
import os

from langchain.agents import AgentType, initialize_agent
from langchain_community.agent_toolkits.gitlab.toolkit import GitLabToolkit
from langchain_community.utilities.gitlab import GitLabAPIWrapper
from langchain_openai import OpenAI
```

```python
# 使用 os.environ 设置你的环境变量
os.environ["GITLAB_URL"] = "https://gitlab.example.org"
os.environ["GITLAB_PERSONAL_ACCESS_TOKEN"] = ""
os.environ["GITLAB_REPOSITORY"] = "username/repo-name"
os.environ["GITLAB_BRANCH"] = "bot-branch-name"
os.environ["GITLAB_BASE_BRANCH"] = "main"

# 此示例还需要一个 OpenAI API 密钥
os.environ["OPENAI_API_KEY"] = ""
```

```python
llm = OpenAI(temperature=0)
gitlab = GitLabAPIWrapper()
toolkit = GitLabToolkit.from_gitlab_api_wrapper(gitlab)
agent = initialize_agent(
    toolkit.get_tools(), llm, agent=AgentType.ZERO_SHOT_REACT_DESCRIPTION, verbose=True
)
```

```python
agent.run(
    "你拥有 Google 首席工程师的软件工程能力。你的任务是完成一个 gitlab 仓库上的 issue。请查看所有开放的 issue，并通过创建合并请求来解决它们。"
)
```
