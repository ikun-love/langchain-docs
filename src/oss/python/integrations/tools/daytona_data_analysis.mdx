## 设置

要使用 `DaytonaDataAnalysisTool`，您需要创建一个 Daytona [账户](https://app.daytona.io/)，获取 [API 密钥](https://app.daytona.io/dashboard/keys)，并安装 `langchain-daytona-data-analysis` 集成包。

### 凭证 (Credentials)

您必须为 Daytona 配置凭证。您可以通过以下三种方式之一完成操作：

**1. 设置 `DAYTONA_API_KEY` 环境变量：**

```bash Set API key icon="key"
export DAYTONA_API_KEY="your-daytona-api-key"
```

**2. 在项目根目录的 `.env` 文件中添加：**

```env Set API key icon="key"
DAYTONA_API_KEY=your-daytona-api-key
```

**3. 在实例化 `DaytonaDataAnalysisTool` 时直接传入 API 密钥：**

```python Set API key icon="key"
tool = DaytonaDataAnalysisTool(daytona_api_key="your-daytona-api-key")
```

设置 LangSmith 环境也有帮助（但不是必需的），以便获得一流的可观察性/<Tooltip tip="将模型执行的每一步记录下来，便于调试和改进">追踪</Tooltip> 您的工具调用。要启用自动追踪，请设置您的 [LangSmith](https://docs.langchain.com/langsmith/home) API 密钥：

```python Enable tracing icon="flask"
os.environ["LANGSMITH_API_KEY"] = getpass.getpass("Enter your LangSmith API key: ")
os.environ["LANGSMITH_TRACING"] = "true"
```

## 实例化

导入并实例化该工具：

```python Initialize tool instance icon="robot"
from langchain_daytona_data_analysis import DaytonaDataAnalysisTool
from daytona import ExecutionArtifacts

# 可选地，您可以传递一个 on_result 回调函数。
# 这个回调函数允许您对数据分析结果应用自定义逻辑。
# 例如，您可以保存输出、显示图表或触发其他操作。
def process_data_analysis_result(result: ExecutionArtifacts):
    print(result)

tool = DaytonaDataAnalysisTool(
    daytona_api_key="your-daytona-api-key", # 如果未设置为 DAYTONA_API_KEY 环境变量，则需要传入
    on_result=process_data_analysis_result
)
```

## 调用 (Invocation)

### 直接调用

```python Call tool icon="rocket"
tool.invoke({'data_analysis_python_code': "print('Hello World')"})
```

### 作为 `ToolCall` 调用

```python ToolCall icon="toolbox"
model_generated_tool_call = {
    "args": {'data_analysis_python_code': "print('Hello World')"},
    "id": "1",
    "name": tool.name,
    "type": "tool_call",
}

tool.invoke(model_generated_tool_call)
```

### 在代理 (Agent) 中使用

```python Agent with tool icon="robot"
from langchain.agents import create_agent
from langchain_anthropic import ChatAnthropic

model = ChatAnthropic(
    model_name="claude-haiku-4-5-20251001",
    temperature=0,
    max_tokens_to_sample=1024,
    timeout=None,
    max_retries=2,
    stop=None
)

agent = create_agent(model, tools=[tool])
```

## 附加功能

`DaytonaDataAnalysisTool` 提供了一些管理文件和沙箱环境的方法：

### 文件管理

**上传文件到沙箱：**

```python
with open("sales_data.csv", "rb") as f:
    uploaded = tool.upload_file(
        f,
        "CSV 文件，包含销售数据，列名包括：id, date, product, revenue"
    )
```

**从沙箱下载文件：**

```python
file_bytes = tool.download_file("/home/daytona/results.csv")
```

**移除已上传的文件：**

```python
tool.remove_uploaded_file(uploaded)
```

### 包管理

**在沙箱中安装 Python 包：**

```python
# 单个包
tool.install_python_packages("pandas")

# 多个包
tool.install_python_packages(["numpy", "matplotlib", "seaborn"])
```

<Note>
有关预安装包的列表，请参阅 [Daytona 默认快照文档](https://www.daytona.io/docs/en/snapshots/#default-snapshot)。
</Note>

### 沙箱管理

**访问沙箱实例：**

```python
sandbox = tool.get_sandbox()
```

**完成后关闭沙箱：**

```python
tool.close()  # 清理资源并删除沙箱
```

<Warning>
当您完成所有数据分析任务后，请调用 `tool.close()` 以正确清理资源并避免不必要的资源占用。
</Warning>
