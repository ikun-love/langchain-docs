> [AskNews](https://asknews.app) 可以使用单个自然语言查询，为任何大型语言模型（LLM）注入最新的全球新闻（或历史新闻）。具体来说，AskNews 每天通过翻译、总结、提取实体并将它们索引到热库和冷向量数据库中，来丰富超过 30 万篇文章的数据。AskNews 将这些向量数据库置于一个低延迟的端点供您使用。当您查询 AskNews 时，您会收到一个经过提示优化的字符串，其中包含所有最相关的丰富信息（例如，实体、分类、翻译、摘要）。这意味着您不需要管理自己的新闻 RAG（检索增强生成），也不需要担心如何以简洁的方式将新闻信息有效地传达给您的 LLM。
> AskNews 也致力于透明度，这就是为什么我们的报道涵盖并分散在数百个国家、13 种语言和五万个信源中。如果您想跟踪我们的信源覆盖情况，可以访问我们的 [透明度仪表板](https://asknews.app/en/transparency)。

## 设置 (Setup)

集成位于 `langchain-community` 包中。我们还需要安装 `asknews` 包本身。

```bash
pip install -U langchain-community asknews
```

我们还需要设置我们的 AskNews API 凭证，这些凭证可以在 [AskNews 控制台](https://my.asknews.app) 获取。

```python
import getpass
import os

os.environ["ASKNEWS_CLIENT_ID"] = getpass.getpass()
os.environ["ASKNEWS_CLIENT_SECRET"] = getpass.getpass()
```

在这里，我们展示如何单独使用该工具。

```python

tool.invoke({"query": "Effect of fed policy on tech sector"})
```

## 链式调用 (Chaining)

我们在此展示如何将其作为智能体的一部分使用。我们使用 OpenAI Functions Agent，因此需要设置并安装其所需的依赖项。我们还将使用 [LangSmith Hub](https://smith.langchain.com/hub) 来获取提示，因此需要安装该依赖项。

```bash
pip install -U langchain-openai langchainhub
```

```python
import getpass
import os

os.environ["OPENAI_API_KEY"] = getpass.getpass()
```

```python
from langchain_classic import hub
from langchain.agents import AgentExecutor, create_openai_functions_agent
from langchain_community.tools.asknews import AskNewsSearch
from langchain_openai import ChatOpenAI

prompt = hub.pull("hwchase17/openai-functions-agent")
llm = ChatOpenAI(temperature=0)
asknews_tool = AskNewsSearch()
tools = [asknews_tool]
agent = create_openai_functions_agent(llm, tools, prompt)
agent_executor = AgentExecutor(agent=agent, tools=tools)
agent_executor.invoke({"input": "How is the tech sector being affected by fed policy?"})
```
