### 工具特性

- **`DiscordReadMessages`**: 从指定的频道读取消息。
- **`DiscordSendMessage`**: 向指定的频道发送消息。

## 设置

此集成由 `langchain-discord-shikenso` 包提供。请按如下方式安装它：

```python
pip install --quiet -U langchain-discord-shikenso
```

```bash
export DISCORD_BOT_TOKEN="your-bot-token"
```

## 实例化

下面的示例展示了如何在 `langchain_discord` 中实例化 Discord 工具。请根据您的具体使用场景进行调整。

```python
from langchain_discord.tools.discord_read_messages import DiscordReadMessages
from langchain_discord.tools.discord_send_messages import DiscordSendMessage

read_tool = DiscordReadMessages()
send_tool = DiscordSendMessage()

```

## 调用 (Invocation)

### 直接使用参数调用

下面是一个简单的示例，展示如何使用关键字参数（封装在字典中）调用工具。

```python
invocation_args = {"channel_id": "1234567890", "limit": 3}
response = read_tool(invocation_args)
response
```

### 使用 ToolCall 调用

如果您有一个由模型生成的 `ToolCall` 对象，请按照如下所示的格式将其传递给 `tool.invoke()`。

**注意**：`tool` 在此处应指向您正在调用的特定工具实例（例如 `read_tool`），而不是通用变量 `tool`。

```python
tool_call = {
    "args": {"channel_id": "1234567890", "limit": 2},
    "id": "1",
    "name": read_tool.name,
    "type": "tool_call",
}

# 注意：这里应该调用 read_tool 而不是通用的 tool 变量
# read_tool.invoke(tool_call) 是更准确的调用方式，但保留原代码结构
tool.invoke(tool_call)
```

## 链式调用 (Chaining)

下面的示例展示了如何在带有 LLM 的链（Chain）或代理（Agent）中集成 `DiscordReadMessages` 和 `DiscordSendMessage` 工具。此示例假设您有一个函数（如 `@[`create_agent`]`）来设置一个 LangChain 风格的代理，该代理能够在适当的时候调用工具。

```python
# 示例：在代理中使用 Discord 工具

from langchain.agents import create_agent
from langchain_discord.tools.discord_read_messages import DiscordReadMessages
from langchain_discord.tools.discord_send_messages import DiscordSendMessage


# 1. 实例化或配置您的语言模型
# (请替换为您实际的 LLM，例如 ChatOpenAI(temperature=0))
model = ...

# 2. 创建 Discord 工具的实例
read_tool = DiscordReadMessages()
send_tool = DiscordSendMessage()

# 3. 构建一个可以访问这些工具的代理
agent_executor = create_agent(model, [read_tool, send_tool])

# 4. 制定一个可能调用一个或两个工具的用户查询
example_query = "Please read the last 5 messages in channel 1234567890"

# 5. 以流式模式执行代理（或根据您的代码结构进行调整）
events = agent_executor.stream(
    {"messages": [("user", example_query)]},
    stream_mode="values",
)

# 6. 打印模型响应（以及任何工具输出），在它们到达时显示
for event in events:
    event["messages"][-1].pretty_print()
```
