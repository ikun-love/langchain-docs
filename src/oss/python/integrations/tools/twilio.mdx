本 Notebook 介绍如何使用 [Twilio](https://www.twilio.com) API 包装器通过短信（SMS）或 [Twilio 消息渠道 (Twilio Messaging Channels)](https://www.twilio.com/docs/messaging/channels) 发送消息。

Twilio 消息渠道促进了与第三方消息应用的集成，并允许您通过 WhatsApp Business Platform（GA 版）、Facebook Messenger（公共 Beta 版）和 Google Business Messages（私有 Beta 版）发送消息。

## 设置 (Setup)

要使用此工具，您需要安装 Python Twilio 包 `twilio`。

```python
pip install -qU  twilio
```

您还需要设置一个 Twilio 账户并获取您的凭证。您需要您的**账户 SID (Account String Identifier)** 和**身份验证令牌 (Auth Token)**。此外，您还需要一个用于发送消息的号码。

您可以将这些凭证作为命名参数 `account_sid`、`auth_token`、`from_number` 传递给 `TwilioAPIWrapper`，或者设置环境变量 `TWILIO_ACCOUNT_SID`、`TWILIO_AUTH_TOKEN`、`TWILIO_FROM_NUMBER`。

## 发送短信 (Sending an SMS)

```python
from langchain_community.utilities.twilio import TwilioAPIWrapper
```

```python
twilio = TwilioAPIWrapper(
    #     account_sid="foo",
    #     auth_token="bar",
    #     from_number="baz,"
)
```

```python
twilio.run("hello world", "+16162904619")
```

## 发送 WhatsApp 消息 (Sending a WhatsApp Message)

您需要将您的 WhatsApp Business 账户与 Twilio 关联起来。此外，您还必须确保用于发送消息的号码已在 Twilio 上配置为“WhatsApp 启用发送方 (WhatsApp Enabled Sender)”，并已在 WhatsApp 注册。

```python
from langchain_community.utilities.twilio import TwilioAPIWrapper
```

```python
twilio = TwilioAPIWrapper(
    #     account_sid="foo",
    #     auth_token="bar",
    #     from_number="whatsapp: baz,"
)
```

```python
twilio.run("hello world", "whatsapp: +16162904619")
```
