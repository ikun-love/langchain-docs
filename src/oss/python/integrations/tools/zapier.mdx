**已弃用** 此 API 将于 2023-11-17 停止服务：[nla.zapier.com/start/](https://nla.zapier.com/start/)

>[Zapier 自然语言操作 (Natural Language Actions)](https://nla.zapier.com/start/) 通过自然语言 API 接口，让您能够访问 Zapier 平台上超过 5000 种应用和 20000 多种操作。
>
>NLA 支持的应用包括 `Gmail`, `Salesforce`, `Trello`, `Slack`, `Asana`, `HubSpot`, `Google Sheets`, `Microsoft Teams` 以及数千种其他应用：[zapier.com/apps](https://zapier.com/apps)
>`Zapier NLA` 负责处理**所有**底层的 API 认证，以及自然语言到底层 API 调用的转换，并返回精简后的输出供大型语言模型 (LLM) 使用。核心思想是：您或您的用户通过一个类似 OAuth 的设置窗口，暴露一组操作 (actions)，然后您可以通过 REST API 对这些操作进行查询和执行。

NLA 提供了 API 密钥 (API Key) 和 OAuth 两种方式来签署 NLA API 请求。

1. 服务器端（API 密钥）：适用于快速入门、测试，以及 LangChain 只会使用开发者 Zapier 账户中暴露的操作（并使用开发者在 Zapier.com 上连接的账户）的生产场景。

2. 面向用户端（OAuth）：适用于您正在部署面向最终用户的应用程序的生产场景，此时 LangChain 需要访问终端用户在 Zapier.com 上暴露的操作和连接的账户。

本快速入门为求简洁，主要关注服务器端用例。请跳转至 [Example Using OAuth Access Token](#oauth) 查看如何为面向用户的场景设置 Zapier 的简短示例。请查阅 [完整文档](https://nla.zapier.com/start/) 以获取面向用户的 OAuth 开发支持的完整信息。

此示例将演示如何将 Zapier 集成与 `SimpleSequentialChain` 结合使用，然后是与 `Agent` 结合使用。
在代码中，如下所示：

```python
import os

# 从 https://platform.openai.com/ 获取
os.environ["OPENAI_API_KEY"] = os.environ.get("OPENAI_API_KEY", "")

# 从 https://nla.zapier.com/docs/authentication/ (登录后获取):
os.environ["ZAPIER_NLA_API_KEY"] = os.environ.get("ZAPIER_NLA_API_KEY", "")
```

## Agent 示例

Zapier 工具可以与 Agent 结合使用。请参见下面的示例。

```python
from langchain.agents import AgentType, initialize_agent
from langchain_community.agent_toolkits import ZapierToolkit
from langchain_community.utilities.zapier import ZapierNLAWrapper
from langchain_openai import OpenAI
```

```python
## 步骤 0. 暴露 Gmail 的“查找邮件”和 Slack 的“发送频道消息”操作

# 首先访问此链接并登录，暴露（启用）这两个操作：https://nla.zapier.com/demo/start -- 对于此示例，可以将所有字段保留为 "Have AI guess"（让 AI 猜测）
# 在 OAuth 场景中，您将获得自己的 <provider> ID（而不是 'demo'），您会先引导用户通过此 ID
```

```python
llm = OpenAI(temperature=0)
zapier = ZapierNLAWrapper()
toolkit = ZapierToolkit.from_zapier_nla_wrapper(zapier)
agent = initialize_agent(
    toolkit.get_tools(), llm, agent=AgentType.ZERO_SHOT_REACT_DESCRIPTION, verbose=True
)
```

```python
agent.run(
    "总结我收到的关于硅谷银行 (Silicon Valley Bank) 的最新邮件。将总结发送到 slack 中的 #test-zapier 频道。"
)
```

## SimpleSequentialChain 示例

如果您需要更明确的控制，可以使用链，如下所示。

```python
from langchain.chains import LLMChain, SimpleSequentialChain, TransformChain
from langchain_community.tools.zapier.tool import ZapierNLARunAction
from langchain_community.utilities.zapier import ZapierNLAWrapper
from langchain_core.prompts import PromptTemplate
from langchain_openai import OpenAI
```

```python
## 步骤 0. 暴露 Gmail 的“查找邮件”和 Slack 的“发送私信”操作

# 首先访问此链接并登录，暴露（启用）这两个操作：https://nla.zapier.com/demo/start -- 对于此示例，可以将所有字段保留为 "Have AI guess"（让 AI 猜测）
# 在 OAuth 场景中，您将获得自己的 <provider> ID（而不是 'demo'），您会先引导用户通过此 ID

actions = ZapierNLAWrapper().list()
```

```python
## 步骤 1. Gmail 查找邮件

GMAIL_SEARCH_INSTRUCTIONS = "获取来自硅谷银行的最新邮件"


def nla_gmail(inputs):
    action = next(
        (a for a in actions if a["description"].startswith("Gmail: Find Email")), None
    )
    return {
        "email_data": ZapierNLARunAction(
            action_id=action["id"],
            zapier_description=action["description"],
            params_schema=action["params"],
        ).run(inputs["instructions"])
    }


gmail_chain = TransformChain(
    input_variables=["instructions"],
    output_variables=["email_data"],
    transform=nla_gmail,
)
```

```python
## 步骤 2. 生成草稿回复

template = """你是一个起草回复进入邮件的助手。以纯文本（非 JSON）形式输出草稿回复。

收到的邮件：
{email_data}

草稿邮件回复："""

prompt_template = PromptTemplate(input_variables=["email_data"], template=template)
reply_chain = LLMChain(llm=OpenAI(temperature=0.7), prompt=prompt_template)
```

```python
## 步骤 3. 通过 Slack 私信发送草稿回复

SLACK_HANDLE = "@Ankush Gola"


def nla_slack(inputs):
    action = next(
        (
            a
            for a in actions
            if a["description"].startswith("Slack: Send Direct Message")
        ),
        None,
    )
    instructions = f"向 Slack 中的 {SLACK_HANDLE} 发送此内容: {inputs['draft_reply']}"
    return {
        "slack_data": ZapierNLARunAction(
            action_id=action["id"],
            zapier_description=action["description"],
            params_schema=action["params"],
        ).run(instructions)
    }


slack_chain = TransformChain(
    input_variables=["draft_reply"],
    output_variables=["slack_data"],
    transform=nla_slack,
)
```

```python
## 最后，执行

overall_chain = SimpleSequentialChain(
    chains=[gmail_chain, reply_chain, slack_chain], verbose=True
)
overall_chain.run(GMAIL_SEARCH_INSTRUCTIONS)
```

## 使用 OAuth 访问令牌的示例

下面的代码片段展示了如何使用已获得的 OAuth 访问令牌来初始化包装器。请注意此处传递的参数与设置环境变量的方式不同。请查阅[身份验证文档](https://nla.zapier.com/docs/authentication/#oauth-credentials)以获取面向用户的 OAuth 开发支持的完整信息。

开发者有责任处理 OAuth 握手过程，以获取和刷新访问令牌。

```python
llm = OpenAI(temperature=0)
zapier = ZapierNLAWrapper(zapier_nla_oauth_access_token="<在此处填入访问令牌>")
toolkit = ZapierToolkit.from_zapier_nla_wrapper(zapier)
agent = initialize_agent(
    toolkit.get_tools(), llm, agent=AgentType.ZERO_SHOT_REACT_DESCRIPTION, verbose=True
)

agent.run(
    "总结我收到的关于硅谷银行 (Silicon Valley Bank) 的最新邮件。将总结发送到 slack 中的 #test-zapier 频道。"
)
```
