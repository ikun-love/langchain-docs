## 设置 (Setup)

要使用此工具包，您需要按照 [Slack API 文档](https://api.slack.com/tutorials/tracks/getting-a-token) 中的说明获取一个令牌。在您收到 `SLACK_USER_TOKEN` 后，可以在下面的环境变量中输入它。

```python
import getpass
import os

if not os.getenv("SLACK_USER_TOKEN"):
    os.environ["SLACK_USER_TOKEN"] = getpass.getpass("输入您的 Slack 用户令牌 (Enter your Slack user token): ")
```

要启用对单个工具的自动化追踪，请设置您的 [LangSmith](https://docs.smith.langchain.com/) API 密钥：

```python
os.environ["LANGSMITH_API_KEY"] = getpass.getpass("输入您的 LangSmith API 密钥 (Enter your LangSmith API key): ")
os.environ["LANGSMITH_TRACING"] = "true"
```

### 安装 (Installation)

此工具包位于 `langchain-community` 包中。我们还需要 Slack SDK：

```python
pip install -qU langchain-community slack_sdk
```

可选地，我们可以安装 `beautifulsoup4` 以帮助解析 HTML 消息：

```python
pip install -qU beautifulsoup4 # 这是可选的，但对解析 HTML 消息很有用
```

## 实例化 (Instantiation)

现在我们可以实例化我们的工具包：

```python
from langchain_community.agent_toolkits import SlackToolkit

toolkit = SlackToolkit()
```

## 工具 (Tools)

查看可用的工具：

```python
tools = toolkit.get_tools()

```

## 在 Agent 中使用

让我们为 Agent 配备 Slack 工具包，并查询有关某个频道的 (channel) 信息。

```python
from langchain_openai import ChatOpenAI
from langchain.agents import create_agent


model = ChatOpenAI(model="gpt-4o-mini")

agent_executor = create_agent(model, tools)
```

```python
example_query = "创建 #general 频道是在什么时候？"

events = agent_executor.stream(
    {"messages": [("user", example_query)]},
    stream_mode="values",
)
for event in events:
    message = event["messages"][-1]
    if message.type != "tool":  # 屏蔽敏感信息
        event["messages"][-1].pretty_print()
```
