我们可以使用 Requests [工具包](/oss/langchain/tools#toolkits) 来构建生成 HTTP 请求的智能体 (agents)。

有关所有 API 工具包的详细文档和配置，请转到 [RequestsToolkit](https://python.langchain.com/api_reference/community/agent_toolkits/langchain_community.agent_toolkits.openapi.toolkit.RequestsToolkit.html) 的 API 参考文档。

## ⚠️ 安全说明 ⚠️

赋予模型自由裁量权去执行实际操作存在固有的风险。请采取预防措施来减轻这些风险：

- 确保与工具关联的权限是**范围受限的**（例如，针对数据库操作或 API 请求）；
- 在需要时，采用“人在回路”(human-in-the-loop) 的工作流程。

## 设置 (Setup)

### 安装 (Installation)

此工具包位于 `langchain-community` 包中：

```python
pip install -qU langchain-community
```

## 实例化 (Instantiation)

首先，我们将演示一个最小示例。

**注意**: 赋予模型自由裁量权去执行实际操作存在固有的风险。我们必须通过设置 `allow_dangerous_request=True` 来“选择加入”这些风险，以便使用这些工具。
**这对调用不受欢迎的请求可能是危险的**。请确保您的自定义 OpenAPI 规范 (yaml) 是安全的，并且与工具关联的权限是范围受限的。

```python
ALLOW_DANGEROUS_REQUEST = True
```

我们可以使用 [JSONPlaceholder](https://jsonplaceholder.typicode.com) API 作为测试用例。

让我们创建（它是）API 规范的一个子集：

```python
from typing import Any, Dict, Union

import requests
import yaml


def _get_schema(response_json: Union[dict, list]) -> dict:
    if isinstance(response_json, list):
        response_json = response_json[0] if response_json else {}
    return {key: type(value).__name__ for key, value in response_json.items()}


def _get_api_spec() -> str:
    base_url = "https://jsonplaceholder.typicode.com"
    endpoints = [
        "/posts",
        "/comments",
    ]
    common_query_parameters = [
        {
            "name": "_limit",
            "in": "query",
            "required": False,
            "schema": {"type": "integer", "example": 2},
            "description": "限制结果的数量",
        }
    ]
    openapi_spec: Dict[str, Any] = {
        "openapi": "3.0.0",
        "info": {"title": "JSONPlaceholder API", "version": "1.0.0"},
        "servers": [{"url": base_url}],
        "paths": {},
    }
    # 遍历端点以构建路径 (paths)
    for endpoint in endpoints:
        response = requests.get(base_url + endpoint)
        if response.status_code == 200:
            schema = _get_schema(response.json())
            openapi_spec["paths"][endpoint] = {
                "get": {
                    "summary": f"获取 {endpoint[1:]}",
                    "parameters": common_query_parameters,
                    "responses": {
                        "200": {
                            "description": "成功的响应",
                            "content": {
                                "application/json": {
                                    "schema": {"type": "object", "properties": schema}
                                }
                            },
                        }
                    },
                }
            }
    return yaml.dump(openapi_spec, sort_keys=False)


api_spec = _get_api_spec()
```

接下来我们可以实例化工具包。对于这个 API，我们不需要任何授权或其他头部信息：

```python
from langchain_community.agent_toolkits.openapi.toolkit import RequestsToolkit
from langchain_community.utilities.requests import TextRequestsWrapper

toolkit = RequestsToolkit(
    requests_wrapper=TextRequestsWrapper(headers={}),
    allow_dangerous_requests=ALLOW_DANGEROUS_REQUEST,
)
```

## 在智能体中使用 (Use within an agent)

```python
from langchain_openai import ChatOpenAI
from langchain.agents import create_agent


model = ChatOpenAI(model="gpt-4o-mini")

system_message = """
您有一个 API 可用于帮助回答用户查询。
API 文档如下：
{api_spec}
""".format(api_spec=api_spec)

agent = create_agent(model, tools, system_prompt=system_message)
```

```python
example_query = "获取前两个帖子。它们的标题是什么？"

events = agent.stream(
    {"messages": [("user", example_query)]},
    stream_mode="values",
)
for event in events:
    event["messages"][-1].pretty_print()
```
