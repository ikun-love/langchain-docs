> [Google Calendar](https://workspace.google.com/intl/en-419/products/calendar/) 是 Google Workspace 的一款产品，它允许用户整理他们的日程和事件。它是一个基于云端的日历，用户可以在其中创建、编辑和删除事件。它还允许用户与其他用户共享他们的日历。

## 概述

本教程将帮助您快速上手 Google Calendar 工具包。此工具包与 Google Calendar API 交互，对日历执行各种操作。它允许您：

- 创建事件。
- 搜索事件。
- 更新事件。
- 将事件在不同的日历之间移动。
- 删除事件。
- 列出事件。

## 设置

要使用此工具包，您需要：

1. 拥有一个可以访问 Google Calendar 的 Google 帐户。
2. 按照 [Google Calendar API 文档](https://developers.google.com/calendar/api/quickstart/python#authorize_credentials_for_a_desktop_application) 中的说明设置您的凭据。下载 `credentials.json` 文件后，您就可以开始使用 Google Calendar API 了。

要启用对单个工具的自动化追踪，请设置您的 [LangSmith](https://docs.langchain.com/langsmith/home) API 密钥：

```python
os.environ["LANGSMITH_TRACING"] = "true"
os.environ["LANGSMITH_API_KEY"] = getpass.getpass("输入您的 LangSmith API 密钥: ")
```

### 安装

此工具包位于 [langchain-google](https://github.com/langchain-ai/langchain-google) 仓库的 `langchain-google-community` 包中。我们需要 `calendar` 额外依赖项：

```python
pip install -qU langchain-google-community\[calendar\]
```

## 实例化

默认情况下，工具包会读取本地的 `credentials.json` 文件。您也可以手动提供一个 `Credentials` 对象。

```python
from langchain_google_community import CalendarToolkit

toolkit = CalendarToolkit()
```

### 自定义身份验证

在底层，`googleapi` 资源是使用以下方法创建的。您可以手动构建一个 `googleapi` 资源以获得更精细的授权控制。

```python
from langchain_google_community import CalendarToolkit
from langchain_google_community.calendar.utils import (
    build_resource_service,
    get_google_credentials,
)

# 可以在此处查看权限范围 (scopes): https://developers.google.com/calendar/api/auth
# 例如，只读权限范围是 https://www.googleapis.com/auth/calendar.readonly
credentials = get_google_credentials(
    token_file="token.json",
    scopes=["https://www.googleapis.com/auth/calendar"],
    client_secrets_file="credentials.json",
)

api_resource = build_resource_service(credentials=credentials)
toolkit = CalendarToolkit(api_resource=api_resource)
```

## 调用

### [直接使用参数调用](/oss/langchain/tools#use-the-tool-directly)

您可以通过传递字典格式的必需参数来直接调用工具。下面是使用 `CalendarCreateEvent` 工具创建新事件的示例。

```python
from langchain_google_community.calendar.create_event import CalendarCreateEvent

tool = CalendarCreateEvent()
tool.invoke(
    {
        "summary": "微积分考试",
        "start_datetime": "2025-07-11 11:00:00",
        "end_datetime": "2025-07-11 13:00:00",
        "timezone": "America/Mexico_City",
        "location": "UAM Cuajimalpa",
        "description": "通过 LangChain 工具包创建的事件",
        "reminders": [{"method": "popup", "minutes": 60}],
        "conference_data": True,
        "color_id": "5",
    }
)
```


## 在代理中使用

下面展示了如何将工具包集成到 [代理 (agent)](/oss/langchain/agents) 中。

我们需要一个 LLM 或聊天模型：

<ChatModelTabs customVarName="llm" />

```python
# | output: false
# | echo: false

from langchain_openai import ChatOpenAI

llm = ChatOpenAI(model="gpt-4o-mini", temperature=0)
```

```python
from langchain.agents import create_agent


agent_executor = create_agent(llm, tools)
```

```python
example_query = "为今天下午创建一个绿色事件，用于跑步 30 分钟。"

events = agent_executor.stream(
    {"messages": [("user", example_query)]},
    stream_mode="values",
)
for event in events:
    event["messages"][-1].pretty_print()
```
