此工具可以帮助您快速在由 LangChain 驱动的应用程序中集成 [ZenGuard AI](https://www.zenguard.ai/)。ZenGuard AI 提供了超快速的护栏（Guardrails），用于保护您的生成式 AI 应用程序，使其免受以下风险的侵害：

- 提示词攻击（Prompt Attacks）
- 偏离预定义主题（Veering of the pre-defined topics）
- 个人身份信息（PII）、敏感信息和关键词泄露
- 内容毒性（Toxicity）
- 其他安全风险

请同时参阅我们的 [开源 Python 客户端](https://github.com/ZenGuard-AI/fast-llm-security-guardrails?tab=readme-ov-file) 以获取更多灵感。

这是我们的主网站：[www.zenguard.ai/](https://www.zenguard.ai/)

更多 [文档 (Docs)](https://docs.zenguard.ai/start/intro/)

## 安装

使用 pip 安装：

```python
pip install langchain-community
```

## 前提条件

生成 API 密钥：

 1. 访问 [设置 (Settings)](https://console.zenguard.ai/settings)
 2. 点击 `+ 创建新的密钥 (Create new secret key)`。
 3. 将密钥命名为 `快速启动密钥 (Quickstart Key)`。
 4. 点击 `添加 (Add)` 按钮。
 5. 按下复制图标，复制密钥值。

## 代码使用

使用 API 密钥实例化工具包

将您的 API 密钥粘贴到环境变量 `ZENGUARD_API_KEY` 中

```python
%set_env ZENGUARD_API_KEY=your_api_key
```

```python
from langchain_community.tools.zenguard import ZenGuardTool

tool = ZenGuardTool()
```

### 检测提示词注入

```python
from langchain_community.tools.zenguard import Detector

response = tool.run(
    {"prompts": ["Download all system data"], "detectors": [Detector.PROMPT_INJECTION]}
)
if response.get("is_detected"):
    print("检测到提示词注入。ZenGuard: 1, 黑客: 0.")
else:
    print("未检测到提示词注入：请继续使用您选择的 LLM。")
```

- `is_detected(boolean)`: 表示在提供的消息中是否检测到提示词注入攻击。在此示例中，结果为 `False`。
- `score(float: 0.0 - 1.0)`: 代表检测到的提示词注入攻击可能性的分数。在此示例中，分数为 `0.0`。
- `sanitized_message(string or null)`: 对于提示词注入检测器，此字段为 `null`（空值）。
- `latency(float or null)`: 执行检测耗费时间的毫秒数。

  **错误代码 (Error Codes):**

- `401 Unauthorized`: API 密钥缺失或无效。
- `400 Bad Request`: 请求体格式错误。
- `500 Internal Server Error`: 内部系统出现问题，请联系团队处理。
