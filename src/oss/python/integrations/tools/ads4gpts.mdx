## 概述

本 Notebook 概述了如何在 LangChain 中直接使用 ADS4GPTs 的工具（Tools）和工具包（Toolkit）。然而，在您的 LangGraph 应用程序中，您很可能会使用我们预先构建好的 LangGraph Agent。

## 实例化

导入必要的库，包括 ADS4GPTs 的工具和工具包。

初始化 ADS4GPTs 工具，例如 `Ads4gptsInlineSponsoredResponseTool`。我们将以一个工具为例进行操作，因为对于我们提供的其他所有工具，操作流程都是相同的。

```python
# 导入所需库

import os
from getpass import getpass

from ads4gpts_langchain import Ads4gptsInlineSponsoredResponseTool, Ads4gptsToolkit
```

```python
# 初始化 ADS4GPTs 工具
# 初始化 Ads4gptsInlineSponsoredResponseTool
inline_sponsored_response_tool = Ads4gptsInlineSponsoredResponseTool(
    ads4gpts_api_key=os.environ["ADS4GPTS_API_KEY"],
)
```

### 工具包实例化

使用所需的参数初始化 `Ads4gptsToolkit`。

```python
# 工具包初始化
# 使用所需的参数初始化 Ads4gptsToolkit
toolkit = Ads4gptsToolkit(
    ads4gpts_api_key=os.environ["ADS4GPTS_API_KEY"],
)

# 从工具包中检索工具
tools = toolkit.get_tools()

# 打印已初始化的工具
for tool in tools:
    print(f"已初始化的工具: {tool.__class__.__name__}")
```

```output
已初始化的工具: Ads4gptsInlineSponsoredResponseTool
已初始化的工具: Ads4gptsSuggestedPromptTool
```

## 调用

使用示例输入运行 ADS4GPTs 工具并显示结果。

```python
# 运行 ADS4GPTs 工具
# 工具的示例输入数据
sample_input = {
    "id": "test_id",
    "user_gender": "female",
    "user_age": "25-34",
    "user_persona": "test_persona",
    "ad_recommendation": "test_recommendation",
    "undesired_ads": "test_undesired_ads",
    "context": "test_context",
    "num_ads": 1,
    "style": "neutral",
}

# 运行 Ads4gptsInlineSponsoredResponseTool
inline_sponsored_response_result = inline_sponsored_response_tool._run(
    **sample_input, ad_format="INLINE_SPONSORED_RESPONSE"
)
print("内联赞助回复结果:", inline_sponsored_response_result)
```

```output
内联赞助回复结果: {'ad_text': '<- Promoted Content ->\n\nLearn the sartorial ways and get your handmade tailored suit by the masters themselves with Bespoke Tailors. [Subscribe now](https://youtube.com/@bespoketailorsdubai?si=9iH587ujoWKkueFa)\n\n<->'}
```

### 异步运行 ADS4GPTs 工具

使用示例输入异步运行 ADS4GPTs 工具并显示结果。

```python
import asyncio


# 定义一个异步函数来异步运行工具
async def run_ads4gpts_tools_async():
    # 异步运行 Ads4gptsInlineSponsoredResponseTool
    inline_sponsored_response_result = await inline_sponsored_response_tool._arun(
        **sample_input, ad_format="INLINE_SPONSORED_RESPONSE"
    )
    print("异步内联赞助回复结果:", inline_sponsored_response_result)
```

```output
异步内联赞助回复结果: {'ad_text': '<- Promoted Content ->\n\nGet the best tailoring content from Jonathan Farley. Learn to tie 100 knots and more! [Subscribe now](https://www.youtube.com/channel/UCx5hk4LN3p02jcUt3j_cexQ)\n\n<->'}
```

### 工具包调用

使用 `Ads4gptsToolkit` 来获取和运行工具。

```python
# 工具的示例输入数据
sample_input = {
    "id": "test_id",
    "user_gender": "female",
    "user_age": "25-34",
    "user_persona": "test_persona",
    "ad_recommendation": "test_recommendation",
    "undesired_ads": "test_undesired_ads",
    "context": "test_context",
    "num_ads": 1,
    "style": "neutral",
}

# 运行一个工具并打印结果
tool = tools[0]
result = tool._run(**sample_input)
print(f"{tool.__class__.__name__} 的结果:", result)


# 定义一个异步函数来异步运行工具
async def run_toolkit_tools_async():
    result = await tool._arun(**sample_input)
    print(f"异步的 {tool.__class__.__name__} 结果:", result)


# 执行异步函数
await run_toolkit_tools_async()
```

```output
异步的 Ads4gptsInlineSponsoredResponseTool 结果: {'ad_text': '<- Promoted Content ->\n\nGet the best tailoring content from Jonathan Farley. Learn to tie 100 knots and more! [Subscribe now](https://www.youtube.com/channel/UCx5hk4LN3p02jcUt3j_cexQ)\n\n<->'}
```

## 链式调用 (Chaining)

```python
    os.environ["OPENAI_API_KEY"] = getpass("输入您的 OPENAI_API_KEY API 密钥: ")
```

```python
import os

from langchain_openai import ChatOpenAI

openai_model = ChatOpenAI(model="gpt-4o", openai_api_key=os.environ["OPENAI_API_KEY"])
model = openai_model.bind_tools(tools)
model_response = model.invoke(
    "为我获取一个关于服装的广告。我是一个想和朋友出去的年轻男性。"

print("工具调用:", model_response)
```
