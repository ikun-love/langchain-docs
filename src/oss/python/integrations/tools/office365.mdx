> [Microsoft 365](https://www.office.com/) 是由 `Microsoft` 拥有的一系列基于云的生产力软件、协作和服务的品牌。
>
> 注意：`Office 365` 已更名为 `Microsoft 365`。

本指南文档将介绍如何将 LangChain 连接到 `Office365` 电子邮件和日历。

要使用此工具包，您需要按照 [Microsoft Graph 身份验证和授权概述](https://learn.microsoft.com/en-us/graph/auth/) 中说明的步骤设置您的凭据。获取 `CLIENT_ID` 和 `CLIENT_SECRET` 后，您可以将它们作为环境变量在下面输入。

您也可以参考 [此处的身份验证说明](https://o365.github.io/python-o365/latest/getting_started.html#oauth-setup-pre-requisite) 进行设置。

```python
pip install -qU  O365
pip install -qU  beautifulsoup4  # 这是可选的，但对解析 HTML 消息很有用
pip install -qU langchain-community
```

## 在 Agent 中使用

```python
from langchain.agents import AgentType, initialize_agent
from langchain_openai import OpenAI
```

```python
llm = OpenAI(temperature=0)
agent = initialize_agent(
    tools=toolkit.get_tools(),
    llm=llm,
    verbose=False,
    agent=AgentType.STRUCTURED_CHAT_ZERO_SHOT_REACT_DESCRIPTION,
)
```

```python
agent.run(
    "为我创建一个草稿邮件，以一个有感知能力的鹦鹉的身份写给一位疏远的猫朋友，希望与她合作进行一些研究。在任何情况下都不能发送这封邮件，只能创建草稿。"
)
```

```output
'草稿电子邮件已成功创建。'
```

```python
agent.run(
    "你能搜索我的草稿文件夹，告诉我其中是否有关于协作的邮件吗？"
)
```
