title: NASA 工具包
---

本 Notebook 演示了如何使用 Agent 来与 NASA 工具包进行交互。该工具包提供了对 NASA 图像和视频库 API 的访问权限，并且在未来的迭代中可能会扩展以包含其他可访问的 NASA API。

**注意：如果未指定期望的媒体结果数量，NASA 图像和视频库的搜索查询可能会返回非常大的响应。在将 Agent 与 LLM token 额度一起使用之前，请考虑这一点。**

## 使用示例

---

### 初始化 Agent

```python
pip install -qU langchain-community
```

```python
from langchain.agents import AgentType, initialize_agent
from langchain_community.agent_toolkits.nasa.toolkit import NasaToolkit
from langchain_community.utilities.nasa import NasaAPIWrapper
from langchain_openai import OpenAI

llm = OpenAI(temperature=0, openai_api_key="")
nasa = NasaAPIWrapper()
toolkit = NasaToolkit.from_nasa_api_wrapper(nasa)
agent = initialize_agent(
    toolkit.get_tools(), llm, agent=AgentType.ZERO_SHOT_REACT_DESCRIPTION, verbose=True
)
```

### 查询媒体资产

```python
agent.run(
    "你能找到三张在 2014 年到 2020 年间发布的月球图片吗？"
)
```

### 查询媒体资产的详细信息

```python
output = agent.run(
    "我刚刚查询了一个 NASA ID 为 NHQ_2019_0311_Go Forward to the Moon 的月球图像。"
    " 我在哪里可以找到该资产的元数据清单（metadata manifest）？"
)
```
