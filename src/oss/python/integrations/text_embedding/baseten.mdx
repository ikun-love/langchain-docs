## 概述 (Overview)

Baseten 提供专为生产应用设计的推理服务。这些 API 基于 Baseten 推理栈构建，为领先的开源模型或自定义模型提供企业级的性能和可靠性：https://www.baseten.co/library/。

## 设置 (Setup)

要访问 Baseten 嵌入模型，您需要创建一个 Baseten 账户、获取一个 API 密钥，并安装 `langchain-baseten` 集成包。

**Baseten 嵌入模型仅作为专用模型提供。** 在使用此集成之前，您必须从 [Baseten 模型库](https://www.baseten.co/library/tag/embedding) 部署一个嵌入模型。

嵌入功能使用 Baseten 的 [性能客户端 (Performance Client)](https://www.baseten.co/blog/introducing-baseten-embeddings-inference-bei/) 以优化性能，该客户端会自动作为依赖项包含进来。

### 凭证 (Credentials)

前往 [https://app.baseten.co](https://app.baseten.co) 注册 Baseten 并生成 API 密钥。生成后，设置 `BASETEN_API_KEY` 环境变量：

```python
import getpass
import os

if not os.getenv("BASETEN_API_KEY"):
    os.environ["BASETEN_API_KEY"] = getpass.getpass("Enter your Baseten API key: ")
```

要启用对模型调用的自动追踪，请设置您的 [LangSmith](https://docs.langchain.com/langsmith/home) API 密钥：

```python
os.environ["LANGSMITH_TRACING"] = "true"
os.environ["LANGSMITH_API_KEY"] = getpass.getpass("Enter your LangSmith API key: ")
```

### 安装 (Installation)

LangChain 的 Baseten 集成位于 `langchain-baseten` 包中：

```python
pip install -qU langchain-baseten
```

## 实例化 (Instantiation)

现在，我们可以使用部署模型的 URL 来实例化 `embeddings` 对象：

```python
from langchain_baseten import BasetenEmbeddings

embeddings = BasetenEmbeddings(
    model_url="https://model-<id>.api.baseten.co/environments/production/sync",  # 您的模型 URL
    api_key="your-api-key",  # 或者设置 BASETEN_API_KEY 环境变量
)
```

## 索引和检索 (Indexing and Retrieval)

嵌入模型通常用于检索增强生成 (RAG) 流程中，既可以用于数据索引阶段，也可以用于后续的检索阶段。有关更详细的说明，请参阅我们的 [RAG 教程](/oss/langchain/rag)。

下面展示了如何使用上面初始化的 `embeddings` 对象来索引和检索数据。在这个示例中，我们将使用 `InMemoryVectorStore` 对一个示例文档进行索引和检索。

```python
# 使用示例文本创建向量存储
from langchain_core.vectorstores import InMemoryVectorStore

text = "LangChain is the framework for building context-aware reasoning applications"

vectorstore = InMemoryVectorStore.from_texts(
    [text],
    embedding=embeddings,
)

# 使用向量存储作为检索器
retriever = vectorstore.as_retriever()

# 检索最相似的文本
retrieved_documents = retriever.invoke("What is LangChain?")

# 显示检索到的文档内容
retrieved_documents[0].page_content
```

```output
'LangChain is the framework for building context-aware reasoning applications'
```

## 直接使用 (Direct Usage)

在底层，向量存储和检索器的实现分别调用 `embeddings.embed_documents(...)` 和 `embeddings.embed_query(...)` 来为 `from_texts` 和检索 `invoke` 操作中使用的文本创建嵌入向量。

您可以直接调用这些方法来获取满足您自身用例的嵌入向量。

### 嵌入单个文本 (Embed single texts)

您可以使用 `embed_query` 来嵌入单个文本或文档：

```python
single_vector = embeddings.embed_query(text)
print(str(single_vector)[:100])  # 显示向量的前 100 个字符
```

```output
[0.013201533816754818, 0.02222288027405739, -0.036066457629203796, 0.027374643832445145, -0.01692997
```

### 嵌入多个文本 (Embed multiple texts)

您可以使用 `embed_documents` 来嵌入多个文本：

```python
text2 = (
    "LangGraph is a library for building stateful, multi-actor applications with LLMs"
)
two_vectors = embeddings.embed_documents([text, text2])
for vector in two_vectors:
    print(str(vector)[:100])  # 显示向量的前 100 个字符
```

```output
[0.013201533816754818, 0.02222288027405739, -0.036066457629203796, 0.027374643832445145, -0.01692997
[0.018247194588184357, 0.007369577884674072, -0.005529594141989946, 0.022589316591620445, -0.0699259
```
