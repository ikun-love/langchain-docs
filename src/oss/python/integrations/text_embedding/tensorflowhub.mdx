> [TensorFlow Hub](https://www.tensorflow.org/hub) 是一个预训练机器学习模型的仓库，这些模型可以随时针对您的特定任务进行微调（fine-tuning）并在任何地方部署。您只需几行代码即可复用像 `BERT` 和 `Faster R-CNN` 这样的已训练模型。
>
>
我们来加载 TensorflowHub 嵌入（Embedding）类。

```python
from langchain_community.embeddings import TensorflowHubEmbeddings
```

```python
embeddings = TensorflowHubEmbeddings()
```
