## 设置

要访问 GreenNode 嵌入模型，您需要创建一个 GreenNode 账户，获取一个 API 密钥，并安装 `langchain-greennode` 集成包。

### 凭证

GreenNode 要求提供 API 密钥进行身份验证。该密钥可以在初始化时作为 `api_key` 参数提供，也可以设置为环境变量 `GREENNODE_API_KEY`。您可以通过在 [GreenNode Serverless AI](https://aiplatform.console.greennode.ai/playground) 上注册一个账户来获取 API 密钥。

```python
import getpass
import os

if not os.getenv("GREENNODE_API_KEY"):
    os.environ["GREENNODE_API_KEY"] = getpass.getpass("请输入您的 GreenNode API 密钥: ")
```

如果您希望对模型调用进行自动化跟踪，您可以取消注释以下代码行来设置您的 [LangSmith](https://docs.smith.langchain.com/) API 密钥：

```python
os.environ["LANGSMITH_TRACING"] = "true"
os.environ["LANGSMITH_API_KEY"] = getpass.getpass("请输入您的 LangSmith API 密钥: ")
```

### 安装

LangChain GreenNode 集成位于 `langchain-greennode` 包中：

```python
pip install -qU langchain-greennode
```

## 实例化

`GreenNodeEmbeddings` 类可以使用可选的 API 密钥和模型名称参数进行实例化：

```python
from langchain_greennode import GreenNodeEmbeddings

# 初始化嵌入模型
embeddings = GreenNodeEmbeddings(
    # api_key="YOUR_API_KEY",  # 您可以直接传入 API 密钥
    model="BAAI/bge-m3"  # 默认的嵌入模型
)
```

## 索引和检索

嵌入模型在检索增强生成 (RAG) 工作流中起着关键作用，它支持内容的索引和高效检索。
下面展示了如何使用我们上面初始化的 `embeddings` 对象来索引和检索数据。在此示例中，我们将使用 `InMemoryVectorStore` 来索引和检索一个示例文档。

```python
# 使用示例文本创建一个向量存储
from langchain_core.vectorstores import InMemoryVectorStore

text = "LangChain 是用于构建上下文感知推理应用的框架"

vectorstore = InMemoryVectorStore.from_texts(
    [text],
    embedding=embeddings,
)

# 使用向量存储作为检索器
retriever = vectorstore.as_retriever()

# 检索最相似的文本
retrieved_documents = retriever.invoke("LangChain 是什么？")

# 显示检索到的文档内容
retrieved_documents[0].page_content
```

```output
'LangChain 是用于构建上下文感知推理应用的框架'
```

## 直接使用

`GreenNodeEmbeddings` 类可以独立使用，用于生成文本嵌入，而无需依赖向量存储。这对于相似度评分、聚类或自定义处理管道等任务非常有用。

### 嵌入单个文本

您可以使用 `embed_query` 嵌入单个文本或文档：

```python
single_vector = embeddings.embed_query(text)
print(str(single_vector)[:100])  # 显示向量的前 100 个字符
```

```output
[-0.01104736328125, -0.0281982421875, 0.0035858154296875, -0.0311279296875, -0.0106201171875, -0.039
```

### 嵌入多个文本

您可以使用 `embed_documents` 嵌入多个文本：

```python
text2 = (
    "LangGraph 是一个用于使用 LLM 构建有状态、多参与者应用的库"
)
two_vectors = embeddings.embed_documents([text, text2])
for vector in two_vectors:
    print(str(vector)[:100])  # 显示向量的前 100 个字符
```

```output
[-0.01104736328125, -0.0281982421875, 0.0035858154296875, -0.0311279296875, -0.0106201171875, -0.039
[-0.07177734375, -0.00017452239990234375, -0.002044677734375, -0.0299072265625, -0.0184326171875, -0
```

### 异步支持

GreenNodeEmbeddings 支持异步操作：

```python
import asyncio


async def generate_embeddings_async():
    # 嵌入单个查询
    query_result = await embeddings.aembed_query("法国的首都是哪里？")
    print(f"异步查询嵌入维度: {len(query_result)}")

    # 嵌入多个文档
    docs = [
        "巴黎是法国的首都",
        "柏林是德国的首都",
        "罗马是意大利的首都",
    ]
    docs_result = await embeddings.aembed_documents(docs)
    print(f"异步文档嵌入数量: {len(docs_result)}")


await generate_embeddings_async()
```

```output
Async query embedding dimension: 1024
Async document embeddings count: 3
```

### 文档相似度示例

```python
import numpy as np
from scipy.spatial.distance import cosine

# 创建一些文档
documents = [
    "机器学习算法根据样本数据构建数学模型",
    "深度学习使用具有多层的神经网络",
    "气候变化是一个主要的全球环境挑战",
    "神经网络的灵感来源于人脑的结构",
]

# 嵌入文档
embeddings_list = embeddings.embed_documents(documents)


# 计算相似度函数
def calculate_similarity(embedding1, embedding2):
    return 1 - cosine(embedding1, embedding2)


# 打印相似度矩阵
print("文档相似度矩阵:")
for i, emb_i in enumerate(embeddings_list):
    similarities = []
    for j, emb_j in enumerate(embeddings_list):
        similarity = calculate_similarity(emb_i, emb_j)
        similarities.append(f"{similarity:.4f}")
    print(f"文档 {i + 1}: {similarities}")
```

```output
Document Similarity Matrix:
Document 1: ['1.0000', '0.6005', '0.3542', '0.5788']
Document 2: ['0.6005', '1.0000', '0.4154', '0.6170']
Document 3: ['0.3542', '0.4154', '1.0000', '0.3528']
Document 4: ['0.5788', '0.6170', '0.3528', '1.0000']
```
