## 概述

<Note>
本概述涵盖**基于文本的嵌入模型**。LangChain 目前不支持多模态嵌入。

参见[顶级嵌入模型](#top-integrations)。
</Note>

嵌入模型可以将原始文本（例如句子、段落或推文）转换成一个固定长度的数字向量，该向量捕获了文本的**语义含义**。这些向量使得机器能够基于含义而非精确的词汇进行文本比较和搜索。

在实践中，这意味着语义相似的文本在向量空间中会彼此靠近。例如，嵌入模型不仅能匹配短语“机器学习”，还能在使用了不同措辞的情况下，找出讨论相关概念的文档。

### 工作原理

1. **向量化 (Vectorization)** — 模型将每个输入的字符串编码成一个高维向量。
2. **相似度评分 (Similarity scoring)** — 使用数学度量标准来比较向量，以衡量底层文本之间的相关程度。

### 相似度度量标准 (Similarity metrics)

几种常用的度量标准用于比较嵌入向量：

* **余弦相似度 (Cosine similarity)** — 测量两个向量之间的夹角。
* **欧几里得距离 (Euclidean distance)** — 测量两点之间的直线距离。
* **点积 (Dot product)** — 测量一个向量在另一个向量上的投影程度。

以下是计算两个向量之间余弦相似度的示例：

```python
import numpy as np

def cosine_similarity(vec1, vec2):
    dot = np.dot(vec1, vec2)
    return dot / (np.linalg.norm(vec1) * np.linalg.norm(vec2))

similarity = cosine_similarity(query_embedding, document_embedding)
print("Cosine Similarity:", similarity)
```

## 接口

LangChain 通过 @[Embeddings] 接口（例如 OpenAI、Cohere、Hugging Face）为文本嵌入模型提供了一个标准的接口。

提供了两个主要方法：

* `embed_documents(texts: List[str]) → List[List[float]]`: 对一批文档进行嵌入。
* `embed_query(text: str) → List[float]`: 对单个查询进行嵌入。

<Note>
该接口允许使用不同的策略对查询和文档进行嵌入，尽管在实践中，大多数提供商的处理方式是相同的。
</Note>

## 缓存 (Caching)

嵌入结果可以被存储或临时缓存，以避免重复计算。

嵌入缓存可以通过 `CacheBackedEmbeddings` 实现。这个包装器将嵌入结果存储在键值存储中，其中文本被哈希化，哈希值用作缓存中的键。

初始化 `CacheBackedEmbeddings` 的主要支持方式是 `from_bytes_store`。它接受以下参数：

- **`underlying_embedder`**: 用于嵌入的底层嵌入器。
- **`document_embedding_cache`**: 用于缓存文档嵌入的任何 [`ByteStore`](/oss/integrations/stores/) 实例。
- **`batch_size`**:（可选，默认为 `None`）在更新存储之前需要嵌入的文档数量。
- **`namespace`**:（可选，默认为 `""`）用于文档缓存的命名空间。有助于避免冲突（例如，可以设置为嵌入模型名称）。
- **`query_embedding_cache`**:（可选，默认为 `None`）用于缓存查询嵌入的 [`ByteStore`](/oss/integrations/stores/) 实例，或者设置为 `True` 以复用 `document_embedding_cache` 的存储。

<Important>
- 使用不同的嵌入模型时，请务必设置 `namespace` 参数以避免冲突。
- `CacheBackedEmbeddings` 默认不缓存查询嵌入。要启用此功能，请指定 `query_embedding_cache`。
</Important>

```python
import time
from langchain_classic.embeddings import CacheBackedEmbeddings  # [!code highlight]
from langchain_classic.storage import LocalFileStore # [!code highlight]
from langchain_core.vectorstores import InMemoryVectorStore

# 创建你的底层嵌入模型
underlying_embeddings = ... # 例如：OpenAIEmbeddings(), HuggingFaceEmbeddings() 等

# Store 用于将嵌入结果持久化到本地文件系统
# 这不适用于生产环境，但对本地开发很有用
store = LocalFileStore("./cache/") # [!code highlight]

cached_embedder = CacheBackedEmbeddings.from_bytes_store(
    underlying_embeddings,
    store,
    namespace=underlying_embeddings.model
)

# 示例：缓存查询嵌入
tic = time.time()
print(cached_embedder.embed_query("Hello, world!"))
print(f"第一次调用耗时: {time.time() - tic:.2f} 秒")

# 后续调用将使用缓存
tic = time.time()
print(cached_embedder.embed_query("Hello, world!"))
print(f"第二次调用耗时: {time.time() - tic:.2f} 秒")
```

在生产环境中，您通常会使用更健壮的持久化存储，例如数据库或云存储。请参阅[存储集成](/oss/integrations/stores/)以了解更多选项。
