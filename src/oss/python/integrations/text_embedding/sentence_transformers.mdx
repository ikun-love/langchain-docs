title: Hugging Face 上的 Sentence Transformers
---

>[Hugging Face sentence-transformers](https://huggingface.co/sentence-transformers) 是一个用于实现最先进的句子、文本和图像嵌入（embeddings）的 Python 框架。
>你可以使用 `HuggingFaceEmbeddings` 类来调用这些嵌入模型。

<Warning>
**在本地运行 `sentence-transformers` 可能会受到操作系统和其他全局因素的影响。我们仅推荐有经验的用户使用。**

</Warning>

## 安装 (Setup)

你需要安装作为依赖项的 `langchain_huggingface` 包：

```python
pip install -qU langchain-huggingface
```

## 用法 (Usage)

```python
from langchain_huggingface import HuggingFaceEmbeddings

embeddings = HuggingFaceEmbeddings(model_name="all-MiniLM-L6-v2")

text = "This is a test document."
query_result = embeddings.embed_query(text)

# 只显示字符串化向量的前 100 个字符
print(str(query_result)[:100] + "...")
```

```output
[-0.038338568061590195, 0.12346471101045609, -0.028642969205975533, 0.05365273356437683, 0.008845377...
```

```python
doc_result = embeddings.embed_documents([text, "This is not a test document."])
print(str(doc_result)[:100] + "...")
```

```output
[[-0.038338497281074524, 0.12346471846103668, -0.028642890974879265, 0.05365274101495743, 0.00884535...
```
