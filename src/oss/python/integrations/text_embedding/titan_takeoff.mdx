## 示例用法

以下是一些帮助您开始使用 Titan Takeoff 服务器的有用示例。在运行这些命令之前，您需要确保 Takeoff 服务器已在后台启动。有关更多信息，请参阅 [Takeoff 启动文档](https://docs.titanml.co/docs/Docs/launching/) 页面。

```python
import time

from langchain_community.embeddings import TitanTakeoffEmbed
```

### 示例 1

基本用法，假设 Takeoff 正在使用其默认端口（例如 `localhost:3000`）在您的机器上运行。

```python
embed = TitanTakeoffEmbed()
output = embed.embed_query(
    "What is the weather in London in August?", consumer_group="embed"
)
print(output)
```

### 示例 2

使用 TitanTakeoffEmbed Python 封装器启动读取器（readers）。如果您在首次启动 Takeoff 时没有创建任何读取器，或者想要添加另一个读取器，可以在初始化 `TitanTakeoffEmbed` 对象时执行此操作。只需将您想启动的模型列表作为 `models` 参数传入即可。

您可以使用 `embed.query_documents` 一次嵌入多个文档。预期的输入是一个**字符串列表**，而不是像 `embed_query` 方法那样只期望单个字符串。

```python
# 嵌入模型的模型配置，您可以在其中指定以下参数：
#   model_name (str): 要使用的模型名称
#   device: (str): 用于推理的设备，可以是 "cuda" 或 "cpu"
#   consumer_group (str): 要将读取器放入的消费者组
embedding_model = {
    "model_name": "BAAI/bge-large-en-v1.5",
    "device": "cpu",
    "consumer_group": "embed",
}
embed = TitanTakeoffEmbed(models=[embedding_model])

# 模型需要时间启动，所需时间取决于模型的大小和您的网络连接速度
time.sleep(60)

prompt = "What is the capital of France?"
# 我们指定了 "embed" 消费者组，因此需要向同一消费者组发送请求，以确保它击中我们的嵌入模型而不是其他模型
output = embed.embed_query(prompt, consumer_group="embed")
print(output)
```
