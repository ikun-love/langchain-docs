title: YandexGPT
---

本指南介绍了如何将 LangChain 与 [YandexGPT](https://cloud.yandex.com/en/services/yandexgpt) 嵌入模型一起使用。

要开始使用，您需要安装 `yandexcloud` Python 包。

```python
pip install -qU  yandexcloud
```

首先，您应该[创建一个服务账户](https://cloud.yandex.com/en/docs/iam/operations/sa/create)，并为其分配 `ai.languageModels.user` 角色。

接下来，您有两种认证（身份验证）方式可供选择：

- [IAM 令牌](https://cloud.yandex.com/en/docs/iam/operations/iam-token/create-for-sa)。
    您可以在构造函数参数 `iam_token` 中指定令牌，或将其设置为环境变量 `YC_IAM_TOKEN`。
- [API 密钥](https://cloud.yandex.com/en/docs/iam/operations/api-key/create)
    您可以在构造函数参数 `api_key` 中指定密钥，或将其设置为环境变量 `YC_API_KEY`。

要指定使用的模型，您可以使用 `model_uri` 参数；有关更多详细信息，请参阅[相关文档](https://cloud.yandex.com/en/docs/yandexgpt/concepts/models#yandexgpt-embeddings)。

默认情况下，将使用指定在 `folder_id` 参数或环境变量 `YC_FOLDER_ID` 中指定的文件夹中的最新版本的 `text-search-query` 模型。

```python
from langchain_community.embeddings.yandex import YandexGPTEmbeddings
```

```python
embeddings = YandexGPTEmbeddings()
```

```python
text = "This is a test document."
```

```python
query_result = embeddings.embed_query(text)
```

```python
doc_result = embeddings.embed_documents([text])
```

```python
query_result[:5]
```

```output
[-0.021392822265625,
 0.096435546875,
 -0.046966552734375,
 -0.0183258056640625,

```

```python
doc_result[0][:5]
```
