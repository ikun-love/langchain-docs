我们来加载 `SageMaker Endpoints Embeddings` 类。如果你在 SageMaker 上部署（例如）自己的 Hugging Face 模型，就可以使用这个类。

关于如何部署模型的说明，请参阅 [这里](https://www.philschmid.de/custom-inference-huggingface-sagemaker)。

**注意**：为了处理批量请求（batched requests），你需要修改自定义 `inference.py` 脚本中 `predict_fn()` 函数的返回语句：

从

`return {"vectors": sentence_embeddings[0].tolist()}`

修改为：

`return {"vectors": sentence_embeddings.tolist()}`.

```python
import json
from typing import Dict, List

from langchain_community.embeddings import SagemakerEndpointEmbeddings
from langchain_community.embeddings.sagemaker_endpoint import EmbeddingsContentHandler


class ContentHandler(EmbeddingsContentHandler):
    content_type = "application/json"
    accepts = "application/json"

    def transform_input(self, inputs: list[str], model_kwargs: Dict) -> bytes:
        """
        将输入转换为 SageMaker 端点可以消费的 bytes 格式。
        Args:
            inputs: 输入字符串列表。
            model_kwargs: 要传递给端点的额外关键字参数。
        Returns:
            转换后的 bytes 输入。
        """
        # 示例：inference.py 期望一个包含 "inputs" 键的 JSON 字符串：
        input_str = json.dumps({"inputs": inputs, **model_kwargs})
        return input_str.encode("utf-8")

    def transform_output(self, output: bytes) -> List[List[float]]:
        """
        将端点返回的 bytes 输出转换为嵌入向量列表。
        Args:
            output: 来自 SageMaker 端点的 bytes 输出。
        Returns:
            转换后的输出 - 嵌入向量列表
        注意:
            外部列表的长度是输入字符串的数量。
            内部列表的长度是嵌入维度。
        """
        # 示例：inference.py 返回一个 JSON 字符串，其中 "vectors" 键包含嵌入向量列表：
        response_json = json.loads(output.read().decode("utf-8"))
        return response_json["vectors"]


content_handler = ContentHandler()


embeddings = SagemakerEndpointEmbeddings(
    # credentials_profile_name="credentials-profile-name",
    endpoint_name="huggingface-pytorch-inference-2023-03-21-16-14-03-834",
    region_name="us-east-1",
    content_handler=content_handler,
)
```
