>[RDFLib](https://rdflib.readthedocs.io/) 是一个纯 Python 包，用于处理 [RDF](https://en.wikipedia.org/wiki/Resource_Description_Framework) 数据。`RDFLib` 包含了处理 `RDF` 所需的大部分功能，包括：
>
>- RDF/XML, N3, NTriples, N-Quads, Turtle, TriX, Trig 和 JSON-LD 的解析器和序列化器
>- 一个可以由多种 Store 实现后端的 Graph 接口
>- 用于内存、持久化到磁盘（Berkeley DB）和远程 SPARQL 端点的存储实现
>- 一个 SPARQL 1.1 实现，支持 SPARQL 1.1 查询和更新语句
>- SPARQL 函数扩展机制

图数据库是基于网络化模型构建应用的绝佳选择。为了统一此类图的语法和语义，W3C 推荐使用 `Semantic Web Technologies`（语义网技术），参见 [Semantic Web](https://www.w3.org/standards/semanticweb/)。

[SPARQL](https://www.w3.org/TR/sparql11-query/) 充当了这些图的查询语言，类似于 `SQL` 或 `Cypher`。本教程演示了如何应用大型语言模型（LLMs）作为图数据库的自然语言接口，通过生成 `SPARQL` 查询来实现。

**免责声明：** 截至目前，通过 LLM 生成 `SPARQL` 查询的功能仍然有些不稳定。对于会修改图数据的 `UPDATE` 查询，请务必格外小心。

我们需要安装一个 Python 库：

您可以针对多种数据源运行查询，包括 Web 上的文件、本地文件、SPARQL 端点（例如 [Wikidata](https://www.wikidata.org/wiki/Wikidata:Main_Page)）以及 [三元组存储库](https://www.w3.org/wiki/LargeTripleStores)（triple stores）。

```python
from langchain.chains import GraphSparqlQAChain
from langchain_community.graphs import RdfGraph
from langchain_openai import ChatOpenAI
```

```python
graph = RdfGraph(
    source_file="http://www.w3.org/People/Berners-Lee/card",
    standard="rdf",
    local_copy="test.ttl",
)
```

请注意，如果源是只读的，提供 `local_file` 对于将更改本地存储是必需的。

## 查询图数据

现在，您可以使用图 SPARQL QA 链来提问关于图数据的问题。

```python
chain = GraphSparqlQAChain.from_llm(
    ChatOpenAI(temperature=0), graph=graph, verbose=True
)
```

```python
chain.run("What is Tim Berners-Lee's work homepage?")
```

```output
> Entering new GraphSparqlQAChain chain...
Identified intent:
SELECT
Generated SPARQL:
PREFIX foaf: [xmlns.com/foaf/0.1/](http://xmlns.com/foaf/0.1/)
SELECT ?homepage
WHERE {
    ?person foaf:name "Tim Berners-Lee" .
    ?person foaf:workplaceHomepage ?homepage .
}
Full Context:
[]

> Finished chain.
```

```output
"Tim Berners-Lee's work homepage is http://www.w3.org/People/Berners-Lee/."
```

## 更新图数据

同样地，您可以使用自然语言来更新图数据，即插入三元组。

```python
chain.run(
    "Save that the person with the name 'Timothy Berners-Lee' has a work homepage at 'http://www.w3.org/foo/bar/'"
)
```

```output
> Entering new GraphSparqlQAChain chain...
Identified intent:
UPDATE
Generated SPARQL:
PREFIX foaf: [xmlns.com/foaf/0.1/](http://xmlns.com/foaf/0.1/)
INSERT {
    ?person foaf:workplaceHomepage [www.w3.org/foo/bar/](http://www.w3.org/foo/bar/) .
}
WHERE {
    ?person foaf:name "Timothy Berners-Lee" .
}

> Finished chain.
```

```output
'Successfully inserted triples into the graph.'
```

让我们验证一下结果：

```python
query = (
    """PREFIX foaf: [xmlns.com/foaf/0.1/](http://xmlns.com/foaf/0.1/)\n"""
    """SELECT ?hp\n"""
    """WHERE {\n"""
    """    ?person foaf:name "Timothy Berners-Lee" . \n"""
    """    ?person foaf:workplaceHomepage ?hp .\n"""
    """}"""
)
graph.query(query)
```

```output
[(rdflib.term.URIRef('https://www.w3.org/'),),
 (rdflib.term.URIRef('http://www.w3.org/foo/bar/'),)]
```

## 返回 SPARQL 查询

您可以使用 `return_sparql_query` 参数从 Sparql QA Chain 返回 SPARQL 查询步骤。

```python
chain = GraphSparqlQAChain.from_llm(
    ChatOpenAI(temperature=0), graph=graph, verbose=True, return_sparql_query=True
)
```

```python
result = chain("What is Tim Berners-Lee's work homepage?")
print(f"SPARQL query: {result['sparql_query']}")
print(f"Final answer: {result['result']}")
```
