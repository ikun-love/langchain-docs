>[ArangoDB](https://github.com/arangodb/arangodb) 是一个可扩展的图数据库系统，用于更快地从互联数据中挖掘价值。它通过单一的查询语言实现了原生图、集成搜索引擎和 JSON 支持。`ArangoDB` 可以在本地（on-prem）或云端运行。

本 Notebook 展示了如何使用大型语言模型（LLM）来为 [ArangoDB](https://github.com/arangodb/arangodb#readme) 数据库提供自然语言界面。

## 设置 (Setting up)

您可以通过 [ArangoDB Docker 镜像](https://hub.docker.com/_/arangodb) 来运行本地的 `ArangoDB` 实例：

```
docker run -p 8529:8529 -e ARANGO_ROOT_PASSWORD= arangodb/arangodb
```

另一种方法是使用 [ArangoDB Cloud Connector 包](https://github.com/arangodb/adb-cloud-connector#readme) 来快速启动一个临时的云实例：

```shell
pip install -qU  python-arango # ArangoDB Python 驱动
pip install -qU  adb-cloud-connector # ArangoDB 云实例配置器
pip install -qU  langchain-openai
pip install -qU  langchain
```

```python
# 实例化 ArangoDB 数据库
import json

from adb_cloud_connector import get_temp_credentials
from arango import ArangoClient

con = get_temp_credentials()

db = ArangoClient(hosts=con["url"]).db(
    con["dbName"], con["username"], con["password"], verify=True
)

print(json.dumps(con, indent=2))
```

我们将使用 `Python Driver` 将我们的 [GameOfThrones](https://github.com/arangodb/example-datasets/tree/master/GameOfThrones) 数据导入到数据库中。

if db.has_graph("GameOfThrones"):
    db.delete_graph("GameOfThrones", drop_collections=True)

## 查询 ArangoDB 数据库 (Querying the ArangoDB database)

我们现在可以使用 `ArangoDB Graph` QA Chain 来查询我们的数据。

```python
import os

os.environ["OPENAI_API_KEY"] = "your-key-here"
```

```python
from langchain.chains import ArangoGraphQAChain
from langchain_openai import ChatOpenAI

chain = ArangoGraphQAChain.from_llm(
    ChatOpenAI(temperature=0), graph=graph, verbose=True
)
```

```python
chain.run("Is Ned Stark alive?")
```

> Finished chain.

## Chain 修改器 (Chain modifiers)

您可以更改以下 `ArangoDBGraphQAChain` 类的变量值，以修改 Chain 的行为和结果：

```python
# 指定要返回的 AQL 查询结果的最大数量
chain.top_k = 10

# 指定是否在输出字典中返回 AQL 查询语句
chain.return_aql_query = True

# 指定是否在输出字典中返回 AQL JSON 结果
chain.return_aql_result = True

# 指定应进行的最大 AQL 生成尝试次数
chain.max_aql_generation_attempts = 5

# 指定一组 AQL 查询示例，它们将被传递给 AQL 生成提示模板以促进少样本学习（few-shot-learning）。
# 默认为空字符串。
chain.aql_examples = """
# Is Ned Stark alive?
RETURN DOCUMENT('Characters/NedStark').alive

# Is Arya Stark the child of Ned Stark?
FOR e IN ChildOf
    FILTER e._from == "Characters/AryaStark" AND e._to == "Characters/NedStark"
    RETURN e
"""
```

```python
chain.run("Is Ned Stark alive?")

# chain("Is Ned Stark alive?") # 返回包含 AQL 查询和 AQL 结果的字典
```

```output
> Entering new ArangoGraphQAChain chain...
AQL Query (1):
RETURN DOCUMENT('Characters/NedStark').alive

AQL Result:
[True]

> Finished chain.
```

```output
'Yes, according to the information in the database, Ned Stark is alive.'
```

```python
chain.run("Is Bran Stark the child of Ned Stark?")
```

```output
> Entering new ArangoGraphQAChain chain...

```
