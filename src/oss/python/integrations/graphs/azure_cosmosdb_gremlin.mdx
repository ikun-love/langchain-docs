>[Azure Cosmos DB for Apache Gremlin](https://learn.microsoft.com/en-us/azure/cosmos-db/gremlin/introduction) 是一种图数据库服务，可用于存储包含数十亿个顶点和边的超大规模图。您可以使用毫秒级的延迟查询这些图，并轻松演进图结构。
>
>[Gremlin](https://en.wikipedia.org/wiki/Gremlin_(query_language)) 是由 `Apache Software Foundation` 旗下的 `Apache TinkerPop` 开发的图遍历语言和虚拟机。

本 Notebook 演示了如何使用大型语言模型（LLM）为图数据库提供自然语言接口，该数据库可以使用 `Gremlin` 查询语言进行查询。

## 填充数据库 (Seeding the database)

假设您的数据库是空的，您可以使用 `GraphDocuments` 来填充它。

对于 Gremlin，始终为每个顶点（Node）添加一个名为 'label' 的属性。
如果没有设置 `label`，则使用 `Node.type` 作为标签。
对于 CosmosDB，使用自然 ID（natural id's）是合理的，因为它们在图资源管理器中是可见的。

```python
source_doc = Document(
    page_content="Matrix is a movie where Keanu Reeves, Laurence Fishburne and Carrie-Anne Moss acted."
)
movie = Node(id="The Matrix", properties={"label": "movie", "title": "The Matrix"})
actor1 = Node(id="Keanu Reeves", properties={"label": "actor", "name": "Keanu Reeves"})
actor2 = Node(
    id="Laurence Fishburne", properties={"label": "actor", "name": "Laurence Fishburne"}
)
actor3 = Node(
    id="Carrie-Anne Moss", properties={"label": "actor", "name": "Carrie-Anne Moss"}
)
rel1 = Relationship(
    id=5, type="ActedIn", source=actor1, target=movie, properties={"label": "ActedIn"}
)
rel2 = Relationship(
    id=6, type="ActedIn", source=actor2, target=movie, properties={"label": "ActedIn"}
)
rel3 = Relationship(
    id=7, type="ActedIn", source=actor3, target=movie, properties={"label": "ActedIn"}
)
rel4 = Relationship(
    id=8,
    type="Starring",
    source=movie,
    target=actor1,
    properties={"label": "Strarring"},
)
rel5 = Relationship(
    id=9,
    type="Starring",
    source=movie,
    target=actor2,
    properties={"label": "Strarring"},
)
rel6 = Relationship(
    id=10,
    type="Straring",
    source=movie,
    target=actor3,
    properties={"label": "Strarring"},
)
graph_doc = GraphDocument(
    nodes=[movie, actor1, actor2, actor3],
    relationships=[rel1, rel2, rel3, rel4, rel5, rel6],
    source=source_doc,
)
```

```python
# 底层的 python-gremlin 库在 Notebook 中运行时存在问题
# 下面的代码行是修复该问题的临时解决方案
nest_asyncio.apply()

# 将文档添加到 CosmosDB 图中。
graph.add_graph_documents([graph_doc])
```

## 查询图 (Querying the graph)

我们现在可以使用 Gremlin QA 链向图提出问题。

```python
chain = GremlinQAChain.from_llm(
    AzureChatOpenAI(
        temperature=0,
        azure_deployment="gpt-4-turbo",
    ),
    graph=graph,
    verbose=True,
)
```

```python
chain.invoke("Who played in The Matrix?")
```

```python
chain.run("How many people played in The Matrix?")
```
