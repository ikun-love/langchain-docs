**LangChain** 是一个用于开发由语言模型驱动的应用程序的框架。它支持的应用程序具有以下特点：

- **上下文感知性（Context-aware）**：将语言模型与上下文来源（如提示指令、少样本示例、用于回答的 grounding 内容等）连接起来。
- **推理能力（Reason）**：依赖语言模型根据提供的上下文、需要采取的操作等来进行推理。

该框架包含几个部分。

- **LangChain 库 (LangChain Libraries)**：Python 和 JavaScript 库。包含大量组件的接口和集成、用于将这些组件组合成链（chains）和代理（agents）的基本运行时，以及现成的链和代理实现。
- **[LangChain 模板](/docs/templates)**：一套可轻松部署的、用于各种任务的参考架构。
- **[LangServe](/docs/langserve)**：一个用于将 LangChain 链部署为 REST API 的库。
- **[LangSmith](https://docs.smith.langchain.com)**：一个开发者平台，允许您调试、测试、评估和监控基于任何 LLM 框架构建的链，并与 LangChain 无缝集成。

![概述 LangChain 框架分层结构的图表，展示了跨多个层互连的部分。](https://python.langchain.com/assets/images/langchain_stack-f21828069f74484521f38199910007c1.svg)

这些产品共同简化了整个应用程序的生命周期：

- **开发 (Develop)**：使用 LangChain/LangChain.js 编写应用程序。通过使用模板快速入门。
- **生产化 (Productionize)**：使用 LangSmith 来检查、测试和监控您的链，以便您可以不断改进并充满信心地部署。
- **部署 (Deploy)**：使用 LangServe 将任何链转换为 API。

## LangChain 库 [​](\#langchain-libraries "LangChain 库的直接链接")

LangChain 包的主要价值主张是：

1. **组件 (Components)**：用于处理语言模型的组合式工具和集成。组件是模块化的，易于使用，无论您是否使用 LangChain 框架的其余部分。
2. **现成的链 (Off-the-shelf chains)**：内置的组件组合，用于完成更高级别的任务。

现成的链使入门变得容易。组件使自定义现有链和构建新链变得容易。

LangChain 库本身由几个不同的包组成。

- **`langchain-core`**：基础抽象和 LangChain 表达式语言 (LCEL)。
- **`langchain-community`**：第三方集成。
- **`langchain`**：构成应用程序认知架构的链、代理和检索策略。
