>[Trello](https://www.atlassian.com/software/trello) 是一个基于 Web 的项目管理和协作工具，它允许个人和团队组织和跟踪他们的任务与项目。它提供了一个可视化的界面，称为“看板”（board），用户可以在其中创建列表（lists）和卡片（cards）来代表他们的任务和活动。

`TrelloLoader` 允许您从 Trello 看板加载卡片，它基于 [py-trello](https://pypi.org/project/py-trello/) 实现。

目前仅支持使用 `api_key/token` 认证方式。

1. 凭证生成：[trello.com/power-ups/admin/](https://trello.com/power-ups/admin/)

2. 点击手动生成令牌链接以获取令牌。

要指定 API 密钥和令牌，您可以设置环境变量 `TRELLO_API_KEY` 和 `TRELLO_TOKEN`，或者直接将 `api_key` 和 `token` 传递给 `from_credentials` 辅助构造方法。

此加载器允许您提供看板名称（board name），以便将相应的卡片拉取到 Document 对象中。

请注意，看板的 “name”（名称）在 Trello 的官方文档中也被称为 “title”（标题）：

[support.atlassian.com/trello/docs/changing-a-boards-title-and-description/](https://support.atlassian.com/trello/docs/changing-a-boards-title-and-description/)

您还可以指定多个加载参数，以包含/移除来自文档 `page_content` 属性和元数据中的不同字段。

## 特性 (Features)

- 从 Trello 看板加载卡片。
- 根据卡片的状态（打开或关闭）进行筛选。
- 将卡片名称、评论和检查项包含在加载的文档中。
- 自定义要包含在文档中的附加元数据字段。

默认情况下，所有卡片字段都会被包含在完整的 `page_content` 文本和相应的元数据中。

```python
# 如果您已经使用环境变量设置了 API 密钥和令牌，
# 则可以跳过此单元格，并在下面的初始化步骤中注释掉 `api_key` 和 `token` 命名参数。
from getpass import getpass

API_KEY = getpass()
TOKEN = getpass()
```

```python
from langchain_community.document_loaders import TrelloLoader

# 从 "Awesome Board" 获取打开的卡片
loader = TrelloLoader.from_credentials(
    "Awesome Board",
    api_key=API_KEY,
    token=TOKEN,
    card_filter="open",
)
documents = loader.load()

print(documents[0].page_content)
print(documents[0].metadata)
```

```python
# 从 "Awesome Board" 获取所有卡片，但仅将
# 卡片所属的列表（列）作为额外元数据包含在内。
loader = TrelloLoader.from_credentials(
    "Awesome Board",
    api_key=API_KEY,
    token=TOKEN,
    extra_metadata=("list"),
)
documents = loader.load()

print(documents[0].page_content)
print(documents[0].metadata)
```

# 从 "Another Board" 获取卡片，但排除卡片名称、
