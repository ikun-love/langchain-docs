> [腾讯云对象存储 (COS)](https://www.tencentcloud.com/products/cos) 是一项分布式存储服务，使您能够通过 HTTP/HTTPS 协议从任意位置存储任意量的数据。`COS` 对数据结构或格式没有限制，也没有存储桶大小和分区管理的限制，因此适用于几乎任何使用场景，例如数据分发、数据处理和数据湖。`COS` 提供基于 Web 的控制台、多语言 SDK 和 API、命令行工具以及图形工具。它与 Amazon S3 API 兼容良好，使您能够快速访问社区工具和插件。

本文涵盖了如何从 `Tencent COS File`（腾讯 COS 文件）加载文档对象。

```python
pip install -qU  cos-python-sdk-v5
```

```python
from langchain_community.document_loaders import TencentCOSFileLoader
from qcloud_cos import CosConfig
```

```python
conf = CosConfig(
    Region="您的 cos 区域",
    SecretId="您的 cos secret_id",
    SecretKey="您的 cos secret_key",
)
loader = TencentCOSFileLoader(conf=conf, bucket="您的_cos_存储桶", key="fake.docx")
```

```python
loader.load()
```
