`SitemapLoader` 继承自 `WebBaseLoader`，它从给定的 URL 加载一个站点地图（sitemap），然后抓取并加载站点地图中的所有页面，将每个页面作为 [`Document`](https://api.python.langchain.com/en/stable/documents/Source.html#langchain.schema.document.Document) 返回。

抓取过程是并发执行的。并发请求的速度受到合理的限制，默认设置为每秒 2 次请求。如果你不担心做“好公民”的责任（即不给服务器造成过大负载），或者你控制被抓取的服务器，你可以提高这个限制。注意：虽然提高限制会加快抓取速度，但**可能会导致服务器阻止你的访问**。请务必谨慎操作！

你可以更改 `requests_per_second` 参数来提高并发请求的最大数量，并使用 `requests_kwargs` 在发送请求时传入额外的关键字参数（kwargs）。

```python
sitemap_loader.requests_per_second = 2
# 可选：避免出现 `[SSL: CERTIFICATE_VERIFY_FAILED]` 错误
sitemap_loader.requests_kwargs = {"verify": False}
```

## 延迟加载 (Lazy Load)

你也可以**延迟加载**页面，以最小化内存占用。

```python
page = []
for doc in sitemap_loader.lazy_load():
    page.append(doc)
    if len(page) >= 10:
        # 执行一些分批操作，例如：
        # index.upsert(page)

        page = []
```

## 过滤站点地图 URL

站点地图文件可能非常庞大，包含数千个 URL。通常你不需要其中的每一个。你可以通过向 `filter_urls` 参数传递一个字符串列表或正则表达式模式来过滤 URL。只有匹配其中一个模式的 URL 才会被加载。

```python
loader = SitemapLoader(
    web_path="https://api.python.langchain.com/sitemap.xml",
    filter_urls=["https://api.python.langchain.com/en/latest"],
)
documents = loader.load()
```

## 添加自定义抓取规则

`SitemapLoader` 使用 `beautifulsoup4` 进行抓取过程，并且默认情况下会抓取页面上的**所有**元素。`SitemapLoader` 的构造函数接受一个自定义的抓取函数。这个功能对根据你的特定需求定制抓取过程很有帮助；例如，你可能希望避免抓取页头或导航元素。

下面的示例展示了如何开发和使用一个自定义函数来避免导航和页头元素。

导入 `beautifulsoup4` 库并定义自定义函数。

```python
pip install beautifulsoup4
```

```python
from bs4 import BeautifulSoup


def remove_nav_and_header_elements(content: BeautifulSoup) -> str:
    # 在 BeautifulSoup 对象中查找所有 'nav' 和 'header' 元素
    nav_elements = content.find_all("nav")
    header_elements = content.find_all("header")

    # 从 BeautifulSoup 对象中移除每个 'nav' 和 'header' 元素
    for element in nav_elements + header_elements:
        element.decompose()

    return str(content.get_text())
```

将你的自定义函数添加到 `SitemapLoader` 对象中。

```python
loader = SitemapLoader(
    "https://api.python.langchain.com/sitemap.xml",
    filter_urls=["https://api.python.langchain.com/en/latest/"],
    parsing_function=remove_nav_and_header_elements,
)
```
