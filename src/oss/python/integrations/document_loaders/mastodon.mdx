>[Mastodon](https://joinmastodon.org/) 是一个联邦式的社交媒体和社交网络服务。

这个加载器使用 `Mastodon.py` Python 包，从一系列 `Mastodon` 账户的“toots”（帖子）中获取文本内容。

默认情况下，可以查询公开账户而无需任何身份验证。如果需要查询非公开账户或实例，您必须为您的账户注册一个应用程序，该应用会为您提供一个访问令牌（access token），然后您需要设置该令牌以及您账户的 API 基础 URL。

然后，您需要以 `@account@instance` 的格式传入想要提取的 Mastodon 账户名称。

```python
from langchain_community.document_loaders import MastodonTootsLoader
```

```python
pip install -qU  Mastodon.py
```

```python
loader = MastodonTootsLoader(
    mastodon_accounts=["@Gargron@mastodon.social"],
    number_toots=50,  # 默认值是 100
)

# 或者，设置访问信息以使用 Mastodon 应用。
# 注意：访问令牌可以传入构造函数，或者您可以设置环境变量 "MASTODON_ACCESS_TOKEN"。
# loader = MastodonTootsLoader(
#     access_token="<ACCESS TOKEN OF MASTODON APP>",

#     mastodon_accounts=["@Gargron@mastodon.social"],

```

```python
documents = loader.load()
for doc in documents[:3]:
    print(doc.page_content)
    print("=" * 80)
```

```output
================================================================================

================================================================================
```

默认情况下，toot 文本（即文档的 `page_content`）是 Mastodon API 返回的 HTML 格式。
