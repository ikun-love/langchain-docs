>[Google Cloud Storage](https://en.wikipedia.org/wiki/Google_Cloud_Storage) 是一项用于存储非结构化数据的托管服务。

本文将介绍如何从 `Google Cloud Storage (GCS) 目录（存储桶/Bucket）` 中加载文档对象。

```python
pip install -qU  langchain-google-community[gcs]
```

```python
from langchain_google_community import GCSDirectoryLoader
```

```python
loader = GCSDirectoryLoader(project_name="aist", bucket="testing-hwc")
```

```python
loader.load()
```

## 指定前缀 (Prefix)

您也可以指定一个 `prefix`（前缀）以实现对要加载文件的更精细控制——这包括加载特定文件夹中的所有文件。

```python
loader = GCSDirectoryLoader(project_name="aist", bucket="testing-hwc", prefix="fake")
```

```python
loader.load()
```

## 遇到单个文件加载失败时继续执行

GCS 存储桶中的某些文件在处理过程中可能会导致错误。启用 `continue_on_failure=True` 参数可以允许静默失败。这意味着单个文件的处理失败不会中断整个函数，而会记录一个警告信息。

```python
loader = GCSDirectoryLoader(
    project_name="aist", bucket="testing-hwc", continue_on_failure=True
)
```

```python
loader.load()
```
