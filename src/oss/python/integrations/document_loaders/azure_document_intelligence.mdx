>[Azure AI Document Intelligence](https://aka.ms/doc-intelligence)（以前称为 `Azure Form Recognizer`）是一项基于机器学习的服务。它能够从数字或扫描的 PDF、图像、Office 文件和 HTML 文件中提取文本（包括手写体）、表格、文档结构（例如标题、章节标题等）以及键值对。
>
>Document Intelligence 支持 `PDF`, `JPEG/JPG`, `PNG`, `BMP`, `TIFF`, `HEIF`, `DOCX`, `XLSX`, `PPTX` 和 `HTML` 格式。

当前使用 `Document Intelligence` 的加载器实现可以将内容按页嵌入，并将其转换为 LangChain 的文档（documents）。默认的输出格式是 Markdown，这可以轻松地与 `MarkdownHeaderTextSplitter` 结合使用，实现语义化的文档分块。您也可以使用 `mode="single"` 或 `mode="page"` 模式返回纯文本，返回形式可以是合并成单个文档的文本，或者按页分割的文本。

## 先决条件 (Prerequisite)

您需要在以下 3 个预览区域之一拥有一个 Azure AI Document Intelligence 资源：**East US**、**West US2**、**West Europe**。如果您还没有资源，请参考[此文档](https://learn.microsoft.com/azure/ai-services/document-intelligence/create-document-intelligence-resource?view=doc-intel-4.0.0)进行创建。您需要将 `<endpoint>` 和 `<key>` 作为参数传递给加载器。

```python
pip install -qU  langchain langchain-community azure-ai-documentintelligence
```

## 示例 1

第一个示例使用本地文件，该文件将被发送到 Azure AI Document Intelligence 进行处理。

有了初始化好的文档分析客户端后，我们就可以继续创建 `DocumentIntelligenceLoader` 的实例了：

```python
from langchain_community.document_loaders import AzureAIDocumentIntelligenceLoader

file_path = "<filepath>"
endpoint = "<endpoint>"
key = "<key>"
loader = AzureAIDocumentIntelligenceLoader(
    api_endpoint=endpoint, api_key=key, file_path=file_path, api_model="prebuilt-layout"
)

documents = loader.load()
```

默认输出包含一个 LangChain 文档，其内容是 Markdown 格式：

```python
documents
```

## 示例 3

您也可以指定 `mode="page"` 来按页加载文档。

```python
from langchain_community.document_loaders import AzureAIDocumentIntelligenceLoader

file_path = "<filepath>"
endpoint = "<endpoint>"
key = "<key>"
loader = AzureAIDocumentIntelligenceLoader(
    api_endpoint=endpoint,
    api_key=key,
    file_path=file_path,
    api_model="prebuilt-layout",
    mode="page",
)

documents = loader.load()
```

输出中，列表里的每一页内容都会被存储为一个单独的文档：

```python
for document in documents:
    print(f"Page Content: {document.page_content}")
    print(f"Metadata: {document.metadata}")
```

## 示例 4

您也可以指定 `analysis_feature=["ocrHighResolution"]` 来启用附加功能（add-on capabilities）。更多信息请参阅：[aka.ms/azsdk/python/documentintelligence/analysisfeature](https://aka.ms/azsdk/python/documentintelligence/analysisfeature)。

```python
from langchain_community.document_loaders import AzureAIDocumentIntelligenceLoader

file_path = "<filepath>"
endpoint = "<endpoint>"
key = "<key>"
analysis_features = ["ocrHighResolution"]
loader = AzureAIDocumentIntelligenceLoader(
    api_endpoint=endpoint,
    api_key=key,
    file_path=file_path,
    api_model="prebuilt-layout",
    analysis_features=analysis_features,
)

documents = loader.load()
```

输出包含使用高分辨率附加功能识别出的 LangChain 文档：

```python
documents
```
