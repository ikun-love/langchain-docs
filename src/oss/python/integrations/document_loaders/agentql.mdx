[AgentQL](https://www.agentql.com/) 的文档加载器（document loader）能够使用 [AgentQL 查询](https://docs.agentql.com/agentql-query) 从任何网页中结构化地提取数据。AgentQL 可以在多种语言和网页上使用，并且不易受网页结构随时间变化而失效的影响。

## 概述

`AgentQLLoader` 需要以下两个参数：

- `url`: 要从中提取数据的网页的 URL。
- `query`: 要执行的 AgentQL 查询。您可以前往文档了解[如何编写 AgentQL 查询](https://docs.agentql.com/agentql-query)，或在 [AgentQL Playground](https://dev.agentql.com/playground) 中测试查询。

以下参数是可选的：

- `api_key`: 您在 [dev.agentql.com](https://dev.agentql.com) 获得的 AgentQL API 密钥。**`可选`**。
- `timeout`: 请求超时前等待的秒数。**默认为 `900`。**
- `is_stealth_mode_enabled`: 是否启用实验性的反机器人规避策略。此功能可能无法随时在所有网站上工作。启用此模式可能会导致数据提取耗时更长。**默认为 `False`。**
- `wait_for`: 在提取数据前等待页面加载的秒数。**默认为 `0`。**
- `is_scroll_to_bottom_enabled`: 在提取数据前是否滚动到页面底部。**默认为 `False`。**
- `mode`: `"standard"` 使用深度数据分析，而 `"fast"` 则以牺牲部分分析深度来换取速度，适用于大多数用例。[在此指南中了解有关模式的更多信息。](https://docs.agentql.com/accuracy/standard-mode) **默认为 `"fast"`。**
- `is_screenshot_enabled`: 在提取数据前是否截取屏幕快照。结果将作为 Base64 字符串返回在 'metadata' 中。**默认为 `False`。**

AgentQLLoader 是基于 AgentQL 的 [REST API](https://docs.agentql.com/rest-api/api-reference) 实现的。

## 设置

要使用 AgentQL 文档加载器，您需要配置 `AGENTQL_API_KEY` 环境变量，或使用 `api_key` 参数。您可以在我们的 [开发人员门户 (Dev Portal)](https://dev.agentql.com) 获取 API 密钥。

### 安装

安装 **langchain-agentql**。

```python
pip install -qU langchain-agentql
```

### 设置凭证

```python
import os

os.environ["AGENTQL_API_KEY"] = "YOUR_AGENTQL_API_KEY"
```

## 初始化

接下来实例化您的模型对象：

```python
from langchain_agentql.document_loaders import AgentQLLoader

loader = AgentQLLoader(
    url="https://www.agentql.com/blog",
    query="""
    {
        posts[] {
            title
            url
            date
            author
        }
    }
    """,
    is_scroll_to_bottom_enabled=True,
)
```

## 加载

```python
docs = loader.load()
docs[0]
```

## 延迟加载 (Lazy Load)

`AgentQLLoader` 当前一次只加载一个 @[`Document`]。因此，`load()` 和 `lazy_load()` 的行为是相同的：

```python
pages = [doc for doc in loader.lazy_load()]
pages
```
