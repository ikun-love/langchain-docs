[Cassandra](https://cassandra.apache.org/) 是一个 NoSQL、面向行、高可扩展性和高可用的数据库。从 5.0 版本开始，该数据库内置了 [向量搜索功能](https://cassandra.apache.org/doc/trunk/cassandra/vector-search/overview.html)。

## 概述

`Cassandra Document Loader` 从 Cassandra 数据库返回一个 LangChain `Document` 列表。

您必须提供一个 CQL 查询或一张表名来检索文档。
该加载器接受以下参数：

*   `table`: (可选) 要从中加载数据的表。
*   `session`: (可选) Cassandra 驱动程序会话。如果未提供，将使用 cassio 解析出的会话。
*   `keyspace`: (可选) 表的键空间（keyspace）。如果未提供，将使用 cassio 解析出的键空间。
*   `query`: (可选) 用于加载数据的查询语句。
*   `page_content_mapper`: (可选) 一个函数，用于将一行数据转换为字符串形式的页面内容（`page_content`）。默认会将该行数据转换为 JSON 格式。
*   `metadata_mapper`: (可选) 一个函数，用于将一行数据转换为元数据字典（`metadata` dict）。
*   `query_parameters`: (可选) 在调用 `session.execute` 时使用的查询参数。
*   `query_timeout`: (可选) 在调用 `session.execute` 时使用的查询超时时间。
*   `query_custom_payload`: (可选) 在调用 `session.execute` 时使用的查询自定义负载（`custom_payload`）。
*   `query_execution_profile`: (可选) 在调用 `session.execute` 时使用的查询执行配置文件（`execution_profile`）。
*   `query_host`: (可选) 在调用 `session.execute` 时使用的查询主机。
*   `query_execute_as`: (可选) 在调用 `session.execute` 时使用的执行身份（`execute_as`）。

## 使用 Document Loader 加载文档

```python
from langchain_community.document_loaders import CassandraLoader
```

### 从 cassandra driver Session 初始化

您需要创建一个 `cassandra.cluster.Session` 对象，具体方法如 [Cassandra 驱动文档](https://docs.datastax.com/en/developer/python-driver/latest/api/cassandra/cluster/#module-cassandra.cluster) 中所述。具体细节（例如网络设置和身份验证）会有所不同，但初始化过程可能如下所示：

```python
from cassandra.cluster import Cluster

cluster = Cluster()
session = cluster.connect()
```

您需要提供 Cassandra 实例上一个现有键空间的名称：

```python
CASSANDRA_KEYSPACE = input("CASSANDRA_KEYSPACE = ")
```

创建文档加载器：

```python
loader = CassandraLoader(
    table="movie_reviews",
    session=session,
    keyspace=CASSANDRA_KEYSPACE,
)
```

```python
docs = loader.load()
```

```python
docs[0]
```

```output
Document(page_content='Row(_id=\'659bdffa16cbc4586b11a423\', title=\'Dangerous Men\', reviewtext=\'"Dangerous Men,"  the picture\\\'s production notes inform, took 26 years to reach the big screen. After having seen it, I wonder: What was the rush?\')', metadata={'table': 'movie_reviews', 'keyspace': 'default_keyspace'})
```

### 从 cassio 初始化

也可以使用 `cassio` 来配置会话（session）和键空间（keyspace）。

```python
import cassio

cassio.init(contact_points="127.0.0.1", keyspace=CASSANDRA_KEYSPACE)

loader = CassandraLoader(
    table="movie_reviews",
)

docs = loader.load()
```
