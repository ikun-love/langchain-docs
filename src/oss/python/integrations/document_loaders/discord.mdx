>[Discord](https://discord.com/) 是一个**在线语音和即时消息**的社交平台。用户可以在私聊中或在称为“服务器”（servers）的社区中，通过语音通话、视频通话、文本消息、媒体和文件进行交流。服务器是持久性聊天室和语音频道的集合，可以通过邀请链接访问。

请按照以下步骤下载你的 `Discord` 数据：

1. 前往你的 **用户设置 (User Settings)**
2. 然后进入 **隐私与安全 (Privacy and Safety)**
3. 找到 **请求我的所有数据 (Request all of my Data)**，然后点击 **请求数据 (Request Data)** 按钮

你可能需要 **30 天** 才能收到你的数据。Discord 会向你注册的电子邮件地址发送一封邮件。该邮件中将包含一个**下载按钮**，通过点击该按钮即可下载你的个人 Discord 数据。

```python
import os

import pandas as pd
```

```python
path = input('请输入 Discord "messages" 文件夹内容的路径: ')
li = []
for f in os.listdir(path):
    expected_csv_path = os.path.join(path, f, "messages.csv")
    csv_exists = os.path.isfile(expected_csv_path)
    if csv_exists:
        df = pd.read_csv(expected_csv_path, index_col=None, header=0)
        li.append(df)

df = pd.concat(li, axis=0, ignore_index=True, sort=False)
```

```python
from langchain_community.document_loaders.discord import DiscordChatLoader
```
