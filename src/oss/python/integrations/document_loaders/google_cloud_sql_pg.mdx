## 基本用法

### 设置 Cloud SQL 数据库值

在 [Cloud SQL 实例页面](https://console.cloud.google.com/sql/instances) 中查找您的数据库变量。

```python
# @title 在此处设置您的值 { display-mode: "form" }
REGION = "us-central1"  # @param {type: "string"}
INSTANCE = "my-primary"  # @param {type: "string"}
DATABASE = "my-database"  # @param {type: "string"}
TABLE_NAME = "vector_store"  # @param {type: "string"}
```

### Cloud SQL 引擎

将 PostgreSQL 设置为文档加载器所需的先决条件和参数之一是 `PostgresEngine` 对象。`PostgresEngine` 配置了到您的 Cloud SQL for PostgreSQL 数据库的连接池，从而确保您的应用程序能够成功连接并遵循行业最佳实践。

要使用 `PostgresEngine.from_instance()` 创建 `PostgresEngine`，您只需要提供 4 样信息：

1. `project_id`：Cloud SQL 实例所在的 Google Cloud 项目的 ID。
1. `region`：Cloud SQL 实例所在的区域（Region）。
1. `instance`：Cloud SQL 实例的名称。
1. `database`：要连接到 Cloud SQL 实例上的数据库的名称。

默认情况下，将使用 [IAM 数据库身份验证](https://cloud.google.com/sql/docs/postgres/iam-authentication) 作为数据库身份验证方法。此库使用从环境中获取的 [应用程序默认凭据 (ADC)](https://cloud.google.com/docs/authentication/application-default-credentials) 所属的 IAM Principal。

或者，也可以使用使用用户名和密码访问 Cloud SQL 数据库的[内置数据库身份验证](https://cloud.google.com/sql/docs/postgres/users)。只需向 `PostgresEngine.from_instance()` 提供可选的 `user` 和 `password` 参数即可：

* `user`：用于内置数据库身份验证和登录的数据库用户。
* `password`：用于内置数据库身份验证和登录的数据库密码。

**注意**：本教程演示的是异步接口。所有异步方法都有相应的同步方法。

```python
from langchain_google_cloud_sql_pg import PostgresEngine

engine = await PostgresEngine.afrom_instance(
    project_id=PROJECT_ID,
    region=REGION,
    instance=INSTANCE,
    database=DATABASE,
)
```

### 创建 PostgresLoader

```python
from langchain_google_cloud_sql_pg import PostgresLoader

# 创建一个基础的 PostgreSQL 对象
loader = await PostgresLoader.create(engine, table_name=TABLE_NAME)
```

### 通过默认表加载文档

加载器返回一个 Documents 列表，其中使用第一个列作为 page_content，所有其他列作为 metadata。默认情况下，表的第一个字段作为 page_content，第二个字段作为 metadata（JSON 格式）。每一行都将成为一个 Document。请注意，如果希望您的文档具有 ID，则需要在表中添加 ID 字段。

```python
from langchain_google_cloud_sql_pg import PostgresLoader

# 创建一个基础的 PostgresLoader 对象
loader = await PostgresLoader.create(engine, table_name=TABLE_NAME)

docs = await loader.aload()
print(docs)
```

### 通过自定义表/metadata 或自定义 page content 列加载文档

```python
loader = await PostgresLoader.create(
    engine,
    table_name=TABLE_NAME,
    content_columns=["product_name"],  # 可选
    metadata_columns=["id"],  # 可选
)
docs = await loader.aload()
print(docs)
```

### 设置 page content 格式

加载器返回一个 Documents 列表，每行对应一个 Document，其 page content 采用指定的字符串格式，例如：文本（空格分隔的拼接）、JSON、YAML、CSV 等。JSON 和 YAML 格式包含字段名（headers），而文本和 CSV 格式不包含字段名。

```python
loader = await PostgresLoader.create(
    engine,
    table_name="products",
    content_columns=["product_name", "description"],
    format="YAML",
)
docs = await loader.aload()
print(docs)
```
