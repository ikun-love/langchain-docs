> [腾讯云对象存储 (COS)](https://www.tencentcloud.com/products/cos) 是一项分布式存储服务，它允许您通过 HTTP/HTTPS 协议随时随地存储任意数量的数据。`COS` 对数据结构或格式没有任何限制，也没有存储桶大小限制和分区管理，因此适用于几乎所有场景，例如数据分发、数据处理和构建数据湖。`COS` 提供了基于 Web 的控制台、多语言 SDK 和 API、命令行工具以及图形化工具。它与 Amazon S3 API 兼容良好，使您能够快速使用社区工具和插件。

本文档将介绍如何从 `Tencent COS Directory`（腾讯云 COS 目录）中加载文档对象。

```python
pip install -qU  cos-python-sdk-v5
```

```python
from langchain_community.document_loaders import TencentCOSDirectoryLoader
from qcloud_cos import CosConfig
```

```python
conf = CosConfig(
    Region="您的 cos 区域",
    SecretId="您的 cos secret_id",
    SecretKey="您的 cos secret_key",
)
loader = TencentCOSDirectoryLoader(conf=conf, bucket="您的cos存储桶名称")
```

```python
loader.load()
```

## 指定前缀 (Prefix)

您也可以指定一个前缀（prefix），以便更精细地控制要加载哪些文件。

```python
loader = TencentCOSDirectoryLoader(conf=conf, bucket="您的cos存储桶名称", prefix="fake")
```

```python
loader.load()
```
