>[Telegram Messenger](https://web.telegram.org/a/) 是一款全球可访问的、免费增值（freemium）、跨平台、加密、基于云端且中心化的即时通讯服务。该应用还提供可选的端到端加密聊天、视频通话、VoIP、文件共享以及其他多项功能。

本指南介绍如何将 `Telegram` 中的数据加载到可被 LangChain 摄取（ingest）的格式中。

```python
from langchain_community.document_loaders import (
    TelegramChatApiLoader,
    TelegramChatFileLoader,
)
```

```python
loader = TelegramChatFileLoader("example_data/telegram.json")
```

```python
loader.load()
```

`TelegramChatApiLoader` 直接从指定的 Telegram 聊天中加载数据。为了导出数据，您需要对您的 Telegram 账户进行身份验证。

您可以在 [my.telegram.org/auth?to=apps](https://my.telegram.org/auth?to=apps) 获取 `API_HASH` 和 `API_ID`。

`chat_entity` – 推荐使用频道的 [实体 (entity)](https://docs.telethon.dev/en/stable/concepts/entities.html?highlight=Entity#what-is-an-entity)。

```python
loader = TelegramChatApiLoader(
    chat_entity="<CHAT_URL>",  # 推荐使用 Entity
    api_hash="<API HASH >",
    api_id="<API_ID>",
    username="",  # 仅在缓存会话时需要。
)
```

```python
loader.load()
```
