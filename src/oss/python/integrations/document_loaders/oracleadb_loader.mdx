Oracle 自动驾驶数据库（Autonomous Database）是一种云数据库，它利用机器学习来自动化数据库调优、安全、备份、更新以及传统上由数据库管理员（DBA）执行的其他例行管理任务。

本指南探讨了如何从 Oracle 自动驾驶数据库中加载文档数据。

## 前提条件

需要一个 `python-oracledb` 的默认 `'Thin'` 模式可以连接的数据库。Oracle 自动驾驶数据库满足此要求，请参阅 `python-oracledb` 架构文档：[`python-oracledb` Architecture](https://python-oracledb.readthedocs.io/en/latest/user_guide/introduction.html#architecture)。

你需要安装 `langchain-oracledb` 才能使用此集成。

`python-oracledb` 驱动程序会自动作为 `langchain-oracledb` 的依赖项安装。

```python
# python -m pip install -U langchain-oracledb
```

## 说明

```python
from langchain_oracledb.document_loaders import OracleAutonomousDatabaseLoader
from settings import s
```

在使用双向 TLS 身份验证（mTLS）时，需要 `wallet_location` 和 `wallet_password` 参数来创建连接。请参阅 python-oracledb 文档中的[连接到 Oracle 云自动驾驶数据库](https://python-oracledb.readthedocs.io/en/latest/user_guide/connection_handling.html#connecting-to-oracle-cloud-autonomous-databases)。

```python
SQL_QUERY = "select prod_id, time_id from sh.costs fetch first 5 rows only"

doc_loader_1 = OracleAutonomousDatabaseLoader(
    query=SQL_QUERY,
    user=s.USERNAME,
    password=s.PASSWORD,
    schema=s.SCHEMA,
    config_dir=s.CONFIG_DIR,
    wallet_location=s.WALLET_LOCATION,
    wallet_password=s.PASSWORD,
    dsn=s.DSN,
)
doc_1 = doc_loader_1.load()

doc_loader_2 = OracleAutonomousDatabaseLoader(
    query=SQL_QUERY,
    user=s.USERNAME,
    password=s.PASSWORD,
    schema=s.SCHEMA,
    dsn=s.DSN,
    wallet_location=s.WALLET_LOCATION,
    wallet_password=s.PASSWORD,
)
doc_2 = doc_loader_2.load()
```

对于单向 TLS 身份验证（1-way TLS），只需提供数据库凭据和连接字符串即可建立连接。以下示例还展示了如何使用 `parameters` 参数传递绑定变量的值。

```python
SQL_QUERY = "select channel_id, channel_desc from sh.channels where channel_desc = :1 fetch first 5 rows only"

doc_loader_3 = OracleAutonomousDatabaseLoader(
    query=SQL_QUERY,
    user=s.USERNAME,
    password=s.PASSWORD,
    schema=s.SCHEMA,
    config_dir=s.CONFIG_DIR,
    dsn=s.DSN,
    parameters=["Direct Sales"],
)
doc_3 = doc_loader_3.load()

doc_loader_4 = OracleAutonomousDatabaseLoader(
    query=SQL_QUERY,
    user=s.USERNAME,
    password=s.PASSWORD,
    schema=s.SCHEMA,
    dsn=s.DSN,
    parameters=["Direct Sales"],
)
doc_4 = doc_loader_4.load()
```
