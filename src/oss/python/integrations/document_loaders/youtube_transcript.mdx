### 添加语言偏好 (Add language preferences)

`language` 参数：这是一个语言代码列表，按**降序优先级**排列，默认为 `en`（英语）。

`translation` 参数：这是一个翻译偏好设置，你可以将可用的字幕翻译成你首选的语言。

```python
loader = YoutubeLoader.from_youtube_url(
    "https://www.youtube.com/watch?v=QsYGlZkevEg",
    add_video_info=True,
    language=["en", "id"],
    translation="en",
)
loader.load()
```

### 将字幕获取为带时间戳的块 (Get transcripts as timestamped chunks)

获取一个或多个 @[`Document`] 对象，每个对象包含视频字幕的一个**片段 (chunk)**。可以指定每个片段代表视频的秒数长度。每个片段的元数据中包含一个 YouTube 视频的 URL，该 URL 将会从特定片段的开始位置播放视频。

`transcript_format` 参数：`langchain_community.document_loaders.youtube.TranscriptFormat` 类型中的一个值。在此例中为 `TranscriptFormat.CHUNKS`。

`chunk_size_seconds` 参数：每个字幕数据块所代表的视频秒数。默认为 120 秒。

```python
from langchain_community.document_loaders.youtube import TranscriptFormat

loader = YoutubeLoader.from_youtube_url(
    "https://www.youtube.com/watch?v=TKCMw0utiak",
    add_video_info=True,
    transcript_format=TranscriptFormat.CHUNKS,
    chunk_size_seconds=30,
)
print("\n\n".join(map(repr, loader.load())))
```

## 经由 Google Cloud 的 YouTube 加载器 (YouTube loader from Google Cloud)

### 前提条件 (Prerequisites)

1. 创建一个 Google Cloud 项目或使用现有项目
1. 启用 [Youtube Api](https://console.cloud.google.com/apis/enableflow?apiid=youtube.googleapis.com&project=sixth-grammar-344520)
1. [为桌面应用授权凭据](https://developers.google.com/drive/api/quickstart/python#authorize_credentials_for_a_desktop_application)
1. `pip install -U google-api-python-client google-auth-httplib2 google-auth-oauthlib youtube-transcript-api`

### 🧑 摄取 Google Docs 数据的说明 (Instructions for ingesting your Google Docs data)

默认情况下，`GoogleDriveLoader` 期望 `credentials.json` 文件位于 `~/.credentials/credentials.json`，但这可以通过 `credentials_file` 关键字参数进行配置。`token.json` 也是如此。请注意，首次使用加载器时会自动创建 `token.json` 文件。

`GoogleApiYoutubeLoader` 可以从一组 Google Docs 文档 ID 或一个文件夹 ID 加载数据。你可以从 URL 中获取你的文件夹和文档 ID：
注意，根据你的设置，可能需要配置 `service_account_path`。有关更多详细信息，请参阅 [此处](https://developers.google.com/drive/api/v3/quickstart/python)。

```python
# 初始化 GoogleApiClient
from pathlib import Path

from langchain_community.document_loaders import GoogleApiClient, GoogleApiYoutubeLoader

google_api_client = GoogleApiClient(credentials_path=Path("your_path_creds.json"))


# 使用频道 (Use a Channel)
youtube_loader_channel = GoogleApiYoutubeLoader(
    google_api_client=google_api_client,
    channel_name="Reducible",
    captions_language="en",
)

# 使用 Youtube Id

youtube_loader_ids = GoogleApiYoutubeLoader(
    google_api_client=google_api_client, video_ids=["TrdevFK_am4"], add_video_info=True
)

# 返回一组 Documents
youtube_loader_channel.load()
```
