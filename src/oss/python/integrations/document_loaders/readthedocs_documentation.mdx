[Read the Docs](https://readthedocs.org/) 是一个开源的免费软件文档托管平台。它负责生成使用 `Sphinx` 文档生成器编写的文档。

本指南（Notebook）介绍了如何加载在 `Read-The-Docs` 构建过程中作为 HTML 生成的内容。

在实际项目中的应用示例，请参阅 [此处](https://github.com/langchain-ai/chat-langchain)。

本文假设您已经将 HTML 内容抓取（Scrape）并存入了一个文件夹中。这可以通过取消注释并运行以下命令来完成：

```python
pip install -qU  beautifulsoup4
```
