本 Notebook 介绍如何开始使用 openGauss VectorStore（向量存储）。[openGauss](https://opengauss.org/en/) 是一个高性能的关系型数据库，内置了向量存储和检索能力。通过这种集成，可以在 LangChain 应用程序中实现兼容 ACID 的向量操作，将传统的 SQL 功能与现代的、由 AI 驱动的相似性搜索相结合。vector store 的一个重要特性。

## 设置 (Setup)

### 启动 openGauss 容器

```bash
docker run --name opengauss \
  -d \
  -e GS_PASSWORD='MyStrongPass@123' \
  -p 8888:5432 \
  opengauss/opengauss-server:latest
```

### 安装 langchain-opengauss

```bash
pip install langchain-opengauss
```

**系统要求 (System Requirements)**:

- openGauss 版本 ≥ 7.0.0
- Python 版本 ≥ 3.8
- psycopg2-binary

### 凭证 (Credentials)

使用您的 openGauss 凭证。

## 管理向量存储 (Manage vector store)

### 向向量存储添加条目 (Add items to vector store)

```python
from langchain_core.documents import Document

document_1 = Document(page_content="foo", metadata={"source": "https://example.com"})

document_2 = Document(page_content="bar", metadata={"source": "https://example.com"})

document_3 = Document(page_content="baz", metadata={"source": "https://example.com"})

documents = [document_1, document_2, document_3]

vector_store.add_documents(documents=documents, ids=["1", "2", "3"])
```

### 更新向量存储中的条目 (Update items in vector store)

```python
updated_document = Document(
    page_content="qux", metadata={"source": "https://another-example.com"}
)

# 如果 ID 已经存在，则会更新该文档
vector_store.add_documents(document_id="1", document=updated_document)
```

### 从向量存储中删除条目 (Delete items from vector store)

```python
vector_store.delete(ids=["3"])
```

在创建了向量存储并将相关文档添加进去之后，您很可能希望在链或代理的运行过程中对其进行查询。

### 直接查询 (Query directly)

```python
results = vector_store.similarity_search(

)

```

如果您想执行相似性搜索并接收相应的分数，可以运行：

```python

    query="thud", k=1, filter={"source": "https://example.com"}
)
for doc, score in results:
    print(f"* [SIM={score:3f}] {doc.page_content} [{doc.metadata}]")
```

## 配置 (Configuration)

### 连接设置 (Connection Settings)

| 参数 (Parameter) | 默认值 (Default) | 描述 (Description) |
|---------------------|-------------------------|--------------------------------------------------------|
| `host`              | localhost               | 数据库服务器地址 |
| `port`              | 8888                    | 数据库连接端口 |
| `user`              | gaussdb                 | 数据库用户名 |
| `password`          | -                       | 复杂密码字符串 |
| `database`          | postgres                | 默认数据库名称 |
| `min_connections`   | 1                       | 连接池最小大小 |
| `max_connections`   | 5                       | 连接池最大大小 |
| `table_name`        | langchain_docs          | 用于存储向量数据和元数据的表名称 |
| `index_type`        | IndexType.HNSW          | 向量索引算法类型。选项包括：HNSW 或 IVFFLAT。默认值为 HNSW。|
| `vector_type`       | VectorType.vector       | 要使用的向量表示类型。默认为 Vector。|
| `distance_strategy` | DistanceStrategy.COSINE | 用于检索的向量相似性度量标准。选项包括：euclidean（L2 距离）、cosine（余弦距离，文本嵌入的理想选择）、manhattan（稀疏数据的 L1 距离）、negative_inner_product（归一化向量的点积）。默认值为 cosine。|
|`embedding_dimension`| 1536                    | 向量嵌入的维度。|

### 支持的组合 (Supported Combinations)

| 向量类型 (Vector Type) | 维度 (Dimensions) | 索引类型 (Index Types) | 支持的距离策略 (Supported Distance Strategies) |
|-------------|------------|--------------|---------------------------------------|
| vector      | ≤2000      | HNSW/IVFFLAT | COSINE/EUCLIDEAN/MANHATTAN/INNER_PROD |

## 性能优化 (Performance Optimization)

### 索引调优指南 (Index Tuning Guidelines)

**HNSW 参数**:

- `m`: 16-100 (在召回率和内存之间取得平衡)
- `ef_construction`: 64-1000 (必须大于 2\*m)

**IVFFLAT 建议**:

```python
import math

lists = min(
    int(math.sqrt(total_rows)) if total_rows > 1e6 else int(total_rows / 1000),
    2000,  # openGauss 最大值
)
```

### 连接池 (Connection Pooling)

```python
OpenGaussSettings(min_connections=3, max_connections=20)
```

## 限制 (Limitations)

- `bit` 和 `sparsevec` 向量类型目前正在开发中
- `vector` 类型的最大向量维度：2000
