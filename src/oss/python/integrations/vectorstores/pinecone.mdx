> [Pinecone](https://docs.pinecone.io/docs/overview) 是一个功能丰富的向量数据库。

本指南展示了如何使用与 `Pinecone` 向量数据库相关的功能。

## 设置 (Setup)

要使用 `PineconeVectorStore`，您首先需要安装配套包以及本指南中使用的其他包。

```python
pip install -qU langchain langchain-pinecone langchain-openai
```

迁移注意事项：如果您是从 `langchain_community.vectorstores` 中实现的 Pinecone 迁移，则可能需要先移除您的 `pinecone-client` v2 依赖，然后再安装 `langchain-pinecone`（它依赖于 `pinecone-client` v6）。

### 凭证 (Credentials)

创建一个新的 Pinecone 账户，或登录到您现有的账户，并创建一个 API 密钥以供本指南使用。

```python
import getpass
import os

from pinecone import Pinecone

if not os.getenv("PINECONE_API_KEY"):
    os.environ["PINECONE_API_KEY"] = getpass.getpass("输入您的 Pinecone API 密钥: ")

pinecone_api_key = os.environ.get("PINECONE_API_KEY")

pc = Pinecone(api_key=pinecone_api_key)
```

如果您希望对模型调用进行自动跟踪，可以通过取消注释以下代码行来设置您的 [LangSmith](https://docs.smith.langchain.com/) API 密钥：

```python
os.environ["LANGSMITH_API_KEY"] = getpass.getpass("输入您的 LangSmith API 密钥: ")
os.environ["LANGSMITH_TRACING"] = "true"
```

## 初始化 (Initialization)

在初始化向量存储之前，我们先连接到 Pinecone 索引。如果名为 `index_name` 的索引不存在，它将被创建。

```python
from pinecone import ServerlessSpec

index_name = "langchain-test-index"  # 如果需要，请更改名称

if not pc.has_index(index_name):
    pc.create_index(
        name=index_name,
        dimension=1536,
        metric="cosine",
        spec=ServerlessSpec(cloud="aws", region="us-east-1"),
    )

index = pc.Index(index_name)
```

```python
from langchain_openai import OpenAIEmbeddings

embeddings = OpenAIEmbeddings(model="text-embedding-3-small")
```

```python
from langchain_pinecone import PineconeVectorStore

vector_store = PineconeVectorStore(index=index, embedding=embeddings)
```

## 管理向量存储 (Manage vector store)

创建向量存储后，我们可以通过添加和删除不同的项与其进行交互。

### 向向量存储添加项 (Add items to vector store)

我们可以使用 `add_documents` 函数向向量存储中添加项。

```python
from uuid import uuid4

from langchain_core.documents import Document

document_1 = Document(
    page_content="I had chocolate chip pancakes and scrambled eggs for breakfast this morning.",
    metadata={"source": "tweet"},
)

document_2 = Document(
    page_content="The weather forecast for tomorrow is cloudy and overcast, with a high of 62 degrees.",
    metadata={"source": "news"},
)

document_3 = Document(
    page_content="Building an exciting new project with LangChain - come check it out!",
    metadata={"source": "tweet"},
)

document_4 = Document(
    page_content="Robbers broke into the city bank and stole $1 million in cash.",
    metadata={"source": "news"},
)

document_5 = Document(
    page_content="Wow! That was an amazing movie. I can't wait to see it again.",
    metadata={"source": "tweet"},
)

document_6 = Document(
    page_content="Is the new iPhone worth the price? Read this review to find out.",
    metadata={"source": "website"},
)

document_7 = Document(
    page_content="The top 10 soccer players in the world right now.",
    metadata={"source": "website"},
)

document_8 = Document(
    page_content="LangGraph is the best framework for building stateful, agentic applications!",
    metadata={"source": "tweet"},
)

document_9 = Document(
    page_content="The stock market is down 500 points today due to fears of a recession.",
    metadata={"source": "news"},
)

document_10 = Document(
    page_content="I have a bad feeling I am going to get deleted :(",
    metadata={"source": "tweet"},
)

documents = [
    document_1,
    document_2,
    document_3,
    document_4,
    document_5,
    document_6,
    document_7,
    document_8,
    document_9,
    document_10,
]
uuids = [str(uuid4()) for _ in range(len(documents))]
vector_store.add_documents(documents=documents, ids=uuids)
```

### 从向量存储中删除项 (Delete items from vector store)

```python
vector_store.delete(ids=[uuids[-1]])
```

## 查询向量存储 (Query vector store)

一旦创建了向量存储并将相关文档添加进去，您很可能希望在运行链或代理时对其进行查询。

### 直接查询 (Query directly)

可以按如下方式执行简单的相似性搜索：

```python
results = vector_store.similarity_search(
    "LangChain provides abstractions to make working with LLMs easy",
    k=2,
    filter={"source": "tweet"},
)
for res in results:
    print(f"* {res.page_content} [{res.metadata}]")
```

#### 带分数的相似性搜索 (Similarity search with score)

您也可以带分数进行搜索：

```python
results = vector_store.similarity_search_with_score(
    "Will it be hot tomorrow?", k=1, filter={"source": "news"}
)
for res, score in results:
    print(f"* [SIM={score:3f}] {res.page_content} [{res.metadata}]")
```

#### 其他搜索方法 (Other search methods)

本指南中未列出更多搜索方法（例如 MMR），要查找所有方法，请务必阅读 [API 参考文档](https://python.langchain.com/api_reference/pinecone/vectorstores/langchain_pinecone.vectorstores.PineconeVectorStore.html)。

### 通过转换为检索器进行查询 (Query by turning into retriever)

您还可以将向量存储转换为检索器 (retriever)，以便在链中使用更加方便。

```python
retriever = vector_store.as_retriever(
    search_type="similarity_score_threshold",
    search_kwargs={"k": 1, "score_threshold": 0.4},
)
retriever.invoke("Stealing from the bank is a crime", filter={"source": "news"})
```
