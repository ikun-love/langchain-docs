本教程介绍如何开始使用 `Chroma` 向量存储。

>[Chroma](https://docs.trychroma.com/getting-started) 是一个面向开发者友好和高效的 AI 原生开源向量数据库。Chroma 采用 Apache 2.0 许可。完整的 `Chroma` 文档请参见[此页面](https://docs.trychroma.com/reference/py-collection)，LangChain 集成相关的 API 参考请参见[此页面](https://python.langchain.com/api_reference/chroma/vectorstores/langchain_chroma.vectorstores.Chroma.html)。

<Info>
**Chroma Cloud (Chroma 云服务)**

Chroma Cloud 提供无服务器的向量搜索和全文搜索功能。它速度极快、性价比高、可扩展且使用方便。使用 5 美元的免费额度，您可以在 30 秒内创建一个数据库并开始体验。

[开始使用 Chroma Cloud](https://trychroma.com/signup)
</Info>

## 安装 (Setup)

要使用 `Chroma` 向量存储，您需要安装 `langchain-chroma` 集成包。

```bash
pip install -qU "langchain-chroma>=0.1.2"
```

### 凭证 (Credentials)

您无需任何凭证即可使用 `Chroma` 向量存储，仅安装上述包即可！

如果您是 [Chroma Cloud](https://trychroma.com/signup) 用户，请设置您的 `CHROMA_TENANT`、`CHROMA_DATABASE` 和 `CHROMA_API_KEY` 环境变量。

安装 `chromadb` 包后，您也可以使用 Chroma CLI 来设置这些环境变量。首先，通过 CLI [登录](https://docs.trychroma.com/docs/cli/login)，然后使用 [`connect` 命令](https://docs.trychroma.com/docs/cli/db)：

```bash
chroma db connect [db_name] --env-file
```

如果您希望对模型调用实现一流的自动化追踪，还可以设置您的 [LangSmith](https://docs.smith.langchain.com/) API 密钥（取消下面的注释即可）：

```python
os.environ["LANGSMITH_API_KEY"] = getpass.getpass("Enter your LangSmith API key: ")
os.environ["LANGSMITH_TRACING"] = "true"
```

## 初始化 (Initialization)

### 基础初始化

以下是一个基础初始化示例，它演示了如何使用一个目录来在本地持久化存储数据。

<EmbeddingTabs/>

```python
# | output: false
# | echo: false
from langchain_openai import OpenAIEmbeddings

embeddings = OpenAIEmbeddings(model="text-embedding-3-large")
```

#### 本地运行（内存中 - In-Memory）

您可以通过简单地实例化一个 `Chroma` 实例，并传入一个集合名称和您的嵌入模型提供者，从而在内存中启动一个 Chroma 服务器：

```python
from langchain_chroma import Chroma

vector_store = Chroma(
    collection_name="example_collection",
    embedding_function=embeddings,
)
```

如果您不需要数据持久化，这是在使用 LangChain 构建 AI 应用程序时进行实验的绝佳选择。

#### 本地运行（带数据持久化）

您可以提供 `persist_directory` 参数，以便在多次运行程序时保存数据：

```python
from langchain_chroma import Chroma

vector_store = Chroma(
    collection_name="example_collection",
    embedding_function=embeddings,
    persist_directory="./chroma_langchain_db",
)
```

#### 连接到 Chroma 服务器

如果您有一个在本地运行的 Chroma 服务器，或者您自己[部署](https://docs.trychroma.com/guides/deploy/client-server-mode)了一个，您可以通过提供 `host` 参数来连接它。

例如，您可以使用 `chroma run` 在本地启动一个 Chroma 服务器，然后使用 `host='localhost'` 进行连接：

```python
from langchain_chroma import Chroma

vector_store = Chroma(
    collection_name="example_collection",
    embedding_function=embeddings,
    host="localhost",
)
```

对于其他部署方式，您可以使用 `port`、`ssl` 和 `headers` 参数来自定义连接。

#### Chroma Cloud

Chroma Cloud 用户也可以使用 LangChain 进行构建。只需向 `Chroma` 实例提供您的 Chroma Cloud API 密钥、租户 (tenant) 和数据库名称 (DB name)：

```python
from langchain_chroma import Chroma

vector_store = Chroma(
    collection_name="example_collection",
    embedding_function=embeddings,
    chroma_cloud_api_key=os.getenv("CHROMA_API_KEY"),
    tenant=os.getenv("CHROMA_TENANT"),
    database=os.getenv("CHROMA_DATABASE"),
)
```

### 从客户端初始化 (Initialization from client)

您也可以从 `Chroma` 客户端进行初始化，这在您希望更方便地访问底层数据库时特别有用。

#### 本地运行（内存中）

```python
import chromadb

client = chromadb.Client()
```

#### 本地运行（带数据持久化）

```python
import chromadb

client = chromadb.PersistentClient(path="./chroma_langchain_db")
```

#### 连接到 Chroma 服务器

例如，如果您正在本地运行一个 Chroma 服务器（使用 `chroma run`）：

```python
import chromadb

client = chromadb.HttpClient(host="localhost", port=8000, ssl=False)
```

#### Chroma Cloud

设置完 `CHROMA_API_KEY`、`CHROMA_TENANT` 和 `CHROMA_DATABASE` 后，您可以直接实例化：

```python
import chromadb

client = chromadb.CloudClient()
```

#### 访问您的 Chroma 数据库

```python
collection = client.get_or_create_collection("collection_name")
collection.add(ids=["1", "2", "3"], documents=["a", "b", "c"])
```

#### 创建 Chroma 向量存储

```python
vector_store_from_client = Chroma(
    client=client,
    collection_name="collection_name",
    embedding_function=embeddings,
)
```

## 管理向量存储 (Manage vector store)

创建向量存储并添加了相关文档后，我们可以通过添加和删除不同的项与之进行交互。

### 向向量存储添加项 (Add items to vector store)

我们可以使用 `add_documents` 函数向向量存储中添加项。

```python
from uuid import uuid4

from langchain_core.documents import Document

document_1 = Document(
    page_content="I had chocolate chip pancakes and scrambled eggs for breakfast this morning.",
    metadata={"source": "tweet"},
    id=1,
)

document_2 = Document(
    page_content="The weather forecast for tomorrow is cloudy and overcast, with a high of 62 degrees.",
    metadata={"source": "news"},
    id=2,
)

document_3 = Document(
    page_content="Building an exciting new project with LangChain - come check it out!",
    metadata={"source": "tweet"},
    id=3,
)

document_4 = Document(
    page_content="Robbers broke into the city bank and stole $1 million in cash.",
    metadata={"source": "news"},
    id=4,
)

document_5 = Document(
    page_content="Wow! That was an amazing movie. I can't wait to see it again.",
    metadata={"source": "tweet"},
    id=5,
)

document_6 = Document(
    page_content="Is the new iPhone worth the price? Read this review to find out.",
    metadata={"source": "website"},
    id=6,
)

document_7 = Document(
    page_content="The top 10 soccer players in the world right now.",
    metadata={"source": "website"},
    id=7,
)

document_8 = Document(
    page_content="LangGraph is the best framework for building stateful, agentic applications!",
    metadata={"source": "tweet"},
    id=8,
)

document_9 = Document(
    page_content="The stock market is down 500 points today due to fears of a recession.",
    metadata={"source": "news"},
    id=9,
)

document_10 = Document(
    page_content="I have a bad feeling I am going to get deleted :(",
    metadata={"source": "tweet"},
    id=10,
)

documents = [
    document_1,
    document_2,
    document_3,
    document_4,
    document_5,
    document_6,
    document_7,
    document_8,
    document_9,
    document_10,
]
uuids = [str(uuid4()) for _ in range(len(documents))]

vector_store.add_documents(documents=documents, ids=uuids)
```

### 更新向量存储中的项 (Update items in vector store)

现在我们已经将文档添加到向量存储中，我们可以使用 `update_documents` 函数来更新现有文档：

```python
updated_document_1 = Document(
    page_content="I had chocolate chip pancakes and fried eggs for breakfast this morning.",
    metadata={"source": "tweet"},
    id=1,
)

updated_document_2 = Document(
    page_content="The weather forecast for tomorrow is sunny and warm, with a high of 82 degrees.",
    metadata={"source": "news"},
    id=2,
)

vector_store.update_document(document_id=uuids[0], document=updated_document_1)
# 您也可以一次更新多个文档
vector_store.update_documents(
    ids=uuids[:2], documents=[updated_document_1, updated_document_2]
)
```

### 从向量存储中删除项 (Delete items from vector store)

我们也可以按如下方式从向量存储中删除项：

```python
vector_store.delete(ids=uuids[-1])
```

## 查询向量存储 (Query vector store)

在创建向量存储并将相关文档添加进去后，您很可能希望在链或代理运行时查询它。

### 直接查询 (Query directly)

#### 相似性搜索 (Similarity search)

执行简单的相似性搜索可以按如下方式完成：

```python
results = vector_store.similarity_search(
    "LangChain provides abstractions to make working with LLMs easy",
    k=2,
    filter={"source": "tweet"},
)
for res in results:
    print(f"* {res.page_content} [{res.metadata}]")
```

#### 相似性搜索并带分数 (Similarity search with score)

如果您想执行相似性搜索并获取相应的得分，可以运行：

```python
results = vector_store.similarity_search_with_score(
    "Will it be hot tomorrow?", k=1, filter={"source": "news"}
)
for res, score in results:
    print(f"* [SIM={score:3f}] {res.page_content} [{res.metadata}]")
```

#### 按向量搜索 (Search by vector)

您也可以按向量进行搜索：

```python
results = vector_store.similarity_search_by_vector(
    embedding=embeddings.embed_query("I love green eggs and ham!"), k=1
)
for doc in results:
    print(f"* {doc.page_content} [{doc.metadata}]")
```

#### 其他搜索方法 (Other search methods)

本教程中未涵盖各种其他搜索方法，例如 MMR 搜索。有关 `AstraDBVectorStore` 可用的搜索功能的完整列表，请查看 [API 参考](https://python.langchain.com/api_reference/astradb/vectorstores/langchain_astradb.vectorstores.AstraDBVectorStore.html)。

### 通过转换为检索器进行查询 (Query by turning into retriever)

您还可以将向量存储转换为检索器 (retriever)，以便在链中使用更方便。有关可传递的不同搜索类型和 kwargs 的更多信息，请访问 [此处](https://python.langchain.com/api_reference/chroma/vectorstores/langchain_chroma.vectorstores.Chroma.html#langchain_chroma.vectorstores.Chroma.as_retriever)的 API 参考。

```python
retriever = vector_store.as_retriever(
    search_type="mmr", search_kwargs={"k": 1, "fetch_k": 5}
)
retriever.invoke("Stealing from the bank is a crime", filter={"source": "news"})
```
