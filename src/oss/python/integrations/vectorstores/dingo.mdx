>[DingoDB](https://dingodb.readthedocs.io/en/latest/) 是一个分布式的多模态向量数据库，它结合了数据湖和向量数据库的特性，可以存储任何类型和大小的数据（如 Key-Value、PDF、音频、视频等）。它具备实时低延迟的处理能力，以实现快速洞察和响应，并能高效地对多模态数据进行即时分析和处理。

你需要使用 `pip install -qU langchain-community` 来安装 `langchain-community` 才能使用此集成。

本教程演示了如何使用与 DingoDB 向量数据库相关的各项功能。

要运行此示例，你需要确保 [DingoDB 实例已启动并正在运行](https://github.com/dingodb/dingo-deploy/blob/main/README.md)。

```python

from langchain_openai import OpenAIEmbeddings

```

```python
from langchain_community.document_loaders import TextLoader

loader = TextLoader("../../how_to/state_of_the_union.txt")
documents = loader.load()
text_splitter = CharacterTextSplitter(chunk_size=1000, chunk_overlap=0)
docs = text_splitter.split_documents(documents)

embeddings = OpenAIEmbeddings()
```

```python
from dingodb import DingoDB

index_name = "langchain_demo"

dingo_client = DingoDB(user="", password="", host=["127.0.0.1:13000"])
# 首先，检查我们的索引是否已经存在。如果不存在，则创建它
if (
    index_name not in dingo_client.get_index()
    and index_name.upper() not in dingo_client.get_index()
):
    # 创建一个新索引，请根据您的需要修改参数
    dingo_client.create_index(
        index_name=index_name, dimension=1536, metric_type="cosine", auto_id=False
    )

# OpenAI 的嵌入模型 `text-embedding-ada-002 使用 1536 维`
docsearch = Dingo.from_documents(
    docs, embeddings, client=dingo_client, index_name=index_name
)
```

### 向现有索引添加更多文本

可以使用 `add_texts` 函数将更多文本嵌入并上载（upsert）到现有的 Dingo 索引中。

```python
vectorstore = Dingo(embeddings, "text", client=dingo_client, index_name=index_name)

vectorstore.add_texts(["More text!"])
```

### 最大边际相关性（MMR）搜索

除了在检索器对象中使用相似性搜索外，您还可以使用 `mmr` 作为检索器。

```python
retriever = docsearch.as_retriever(search_type="mmr")
matched_docs = retriever.invoke(query)
for i, d in enumerate(matched_docs):
    print(f"\n## Document {i}\n")
    print(d.page_content)
```

或者直接使用 `max_marginal_relevance_search`：

```python
found_docs = docsearch.max_marginal_relevance_search(query, k=2, fetch_k=10)
for i, doc in enumerate(found_docs):
    print(f"{i + 1}.", doc.page_content, "\n")
```
