本指南介绍如何使用 `langchain-mongodb` 包在 LangChain 中使用 MongoDB Atlas 向量搜索（Vector Search）。

>[MongoDB Atlas](https://www.mongodb.com/docs/atlas/) 是一个完全托管的云数据库，可在 AWS、Azure 和 GCP 上使用。它支持在 MongoDB 文档数据上进行原生的 **向量搜索 (Vector Search)**、**全文搜索 (BM25)** 以及**混合搜索 (Hybrid Search)**。

>[MongoDB Atlas 向量搜索](https://www.mongodb.com/products/platform/atlas-vector-search) 允许您将嵌入向量存储在 MongoDB 文档中，创建向量搜索索引，并使用近似最近邻算法（`Hierarchical Navigable Small Worlds`，即 HNSW）执行 KNN 搜索。它依赖于 [$vectorSearch MQL 阶段](https://www.mongodb.com/docs/atlas/atlas-vector-search/vector-search-overview/)。

## 设置 (Setup)

>*需要一个运行 MongoDB 版本 6.0.11、7.0.2 或更高版本（包括 RC 版本）的 Atlas 集群。

要使用 MongoDB Atlas，您必须首先部署一个集群。我们为您在所选云服务商上提供了永久免费（Forever-Free）的集群层级。要开始使用，请访问 Atlas 快速入门：[quick start](https://www.mongodb.com/docs/atlas/getting-started/)。

您需要安装 `langchain-mongodb` 和 `pymongo` 才能使用此集成。

```python
pip install -qU langchain-mongodb pymongo
```

### 凭证 (Credentials)

对于本教程，您需要找到您的 MongoDB 集群连接 URI。

有关查找集群 URI 的信息，请阅读[本指南](https://www.mongodb.com/docs/manual/reference/connection-string/)。

```python
import getpass

MONGODB_ATLAS_CLUSTER_URI = getpass.getpass("MongoDB Atlas Cluster URI:")
```

如果您希望获得一流的模型调用自动化跟踪体验，可以取消注释以下代码行来设置您的 [LangSmith](https://docs.langchain.com/langsmith/home) API 密钥：

```python
os.environ["LANGSMITH_API_KEY"] = getpass.getpass("Enter your LangSmith API key: ")
os.environ["LANGSMITH_TRACING"] = "true"
```

## 初始化 (Initialization)

<EmbeddingTabs/>

```python
# | output: false
# | echo: false
from langchain_openai import OpenAIEmbeddings

embeddings = OpenAIEmbeddings()
```

```python
from langchain_mongodb import MongoDBAtlasVectorSearch
from pymongo import MongoClient

# 初始化 MongoDB Python 客户端
client = MongoClient(MONGODB_ATLAS_CLUSTER_URI)

DB_NAME = "langchain_test_db"
COLLECTION_NAME = "langchain_test_vectorstores"
ATLAS_VECTOR_SEARCH_INDEX_NAME = "langchain-test-index-vectorstores"

MONGODB_COLLECTION = client[DB_NAME][COLLECTION_NAME]

vector_store = MongoDBAtlasVectorSearch(
    collection=MONGODB_COLLECTION,
    embedding=embeddings,
    index_name=ATLAS_VECTOR_SEARCH_INDEX_NAME,
    relevance_score_fn="cosine",
)

# 在集合上创建向量搜索索引
# 由于我们使用默认的 OpenAI embedding 模型 (ada-v2)，我们需要将维度指定为 1536
vector_store.create_vector_search_index(dimensions=1536)
```

[可选] 与上述 `vector_store.create_vector_search_index` 命令的替代方案是，您也可以使用 Atlas UI 创建向量搜索索引，使用以下索引定义：

```json
{
  "fields":[
    {
      "type": "vector",
      "path": "embedding",
      "numDimensions": 1536,
      "similarity": "cosine"
    }
  ]
}
```

## 查询向量存储 (Query vector store)

一旦创建了向量存储并添加了相关文档，您很有可能希望在链或代理运行时查询它。

### 直接查询

#### 相似性搜索

可以按如下方式执行简单的相似性搜索：

```python
results = vector_store.similarity_search(
    "LangChain provides abstractions to make working with LLMs easy", k=2
)
for res in results:
    print(f"* {res.page_content} [{res.metadata}]")
```

```output
* Building an exciting new project with LangChain - come check it out! [{'_id': 'e7d95150-67f6-499f-b611-84367c50fa60', 'source': 'tweet'}]
* LangGraph is the best framework for building stateful, agentic applications! [{'_id': '7614bb54-4eb5-4b3b-990c-00e35cb31f99', 'source': 'tweet'}]
```

#### 带分数的相似性搜索

您还可以按分数搜索：

```python
results = vector_store.similarity_search_with_score("Will it be hot tomorrow?", k=1)
for res, score in results:
    print(f"* [SIM={score:3f}] {res.page_content} [{res.metadata}]")
```

```output
* [SIM=0.784560] The weather forecast for tomorrow is cloudy and overcast, with a high of 62 degrees. [{'_id': '8396a68d-f4a3-4176-a581-a1a8c303eea4', 'source': 'news'}]
```

### 使用相似性搜索进行预过滤 (Pre-filtering)

Atlas 向量搜索支持使用 MQL 操作符进行预过滤。下面是一个针对相同数据（如上加载）的索引和查询示例，它允许您根据 "page" 字段进行元数据过滤。您可以更新现有索引以包含定义的过滤器，并通过向量搜索进行预过滤。

要启用预过滤，您需要更新索引定义以包含一个 `filter` 字段。在本例中，我们将使用 `source` 字段作为过滤字段。

可以使用 `MongoDBAtlasVectorSearch.create_vector_search_index` 方法以编程方式完成此操作。

```python
vectorstore.create_vector_search_index(
  dimensions=1536,
  filters=[{"type":"filter", "path":"source"}],
  update=True
)
```

或者，您也可以使用 Atlas UI 更新索引，使用以下索引定义：

```json
{
  "fields":[
    {
      "type": "vector",
      "path": "embedding",
      "numDimensions": 1536,
      "similarity": "cosine"
    },
    {
      "type": "filter",
      "path": "source"
    }
  ]
}
```

然后，您可以按如下方式使用过滤器运行查询：

```python
results = vector_store.similarity_search(query="foo", k=1, pre_filter={"source": {"$eq": "https://example.com"}})
for doc in results:
    print(f"* {doc.page_content} [{doc.metadata}]")
```

### 通过转换为检索器 (Retriever) 进行查询

您还可以将向量存储转换为检索器，以便在链中使用更为方便。

以下是如何将向量存储转换为检索器，然后使用简单的查询和过滤器调用该检索器的方法：

```python
retriever = vector_store.as_retriever(
    search_type="similarity_score_threshold",
    search_kwargs={"k": 1, "score_threshold": 0.2},
)
retriever.invoke("Stealing from the bank is a crime")
```

```output
[Document(metadata={'_id': '8c31b84e-2636-48b6-8b99-9fccb47f7051', 'source': 'news'}, page_content='Robbers broke into the city bank and stole $1 million in cash.')]
```
