>[Apache Doris](https://doris.apache.org/) 是一款用于实时分析的现代化数据仓库。
它能在大规模数据集上对实时数据提供极快的分析速度。

>通常来说，`Apache Doris` 被归类为 OLAP（在线分析处理），并且在 [ClickBench — 面向分析型 DBMS 的基准测试](https://benchmark.clickhouse.com/) 中展现了出色的性能。由于它拥有一个超快的向量化执行引擎，因此也可以被用作快速的向量数据库（vectordb）。

您需要安装 `langchain-community` 才能使用此集成。执行命令：`pip install -qU langchain-community`

下面我们将展示如何使用 Apache Doris 向量存储（Vector Store）。

## 加载文档并将其分割成 Token

加载 `docs` 目录下的所有 markdown 文件。

对于 Apache Doris 的文档，您可以从 [github.com/apache/doris](https://github.com/apache/doris) 克隆仓库，其中包含一个 `docs` 目录。

```python
loader = DirectoryLoader(
    "./docs", glob="**/*.md", loader_cls=UnstructuredMarkdownLoader
)
documents = loader.load()
```

将文档分割成 Token，并将 `update_vectordb` 设置为 `True`，因为存在新的文档/Token 需要处理。

```python
# 加载文本分割器并将文档分割成文本片段
text_splitter = TokenTextSplitter(chunk_size=400, chunk_overlap=50)
split_docs = text_splitter.split_documents(documents)

# 通知向量数据库（vectordb）更新文本嵌入
update_vectordb = True
```

## 创建向量数据库实例

### 将 Apache Doris 作为向量数据库

```python
def gen_apache_doris(update_vectordb, embeddings, settings):
    if update_vectordb:
        docsearch = ApacheDoris.from_documents(split_docs, embeddings, config=settings)
    else:
        docsearch = ApacheDoris(embeddings, settings)
    return docsearch
```

## 将 Token 转换为嵌入 (Embeddings) 并存入向量数据库

这里我们使用 Apache Doris 作为向量数据库。您可以通过 `ApacheDorisSettings` 配置 Apache Doris 实例。

配置 Apache Doris 实例的操作与配置 MySQL 实例非常相似。您需要指定以下内容：

1. host/port
2. username (默认值: `'root'`)
3. password (默认值: `''`)
4. database (默认值: `'default'`)
5. table (默认值: `'langchain'`)

```python
import os
from getpass import getpass

if "OPENAI_API_KEY" not in os.environ:
    os.environ["OPENAI_API_KEY"] = getpass()
```

```python
update_vectordb = True

embeddings = OpenAIEmbeddings()

# 配置 Apache Doris 设置 (host/port/user/pw/db)
settings = ApacheDorisSettings()
settings.port = 9030
settings.host = "172.30.34.130"
settings.username = "root"
settings.password = ""
settings.database = "langchain"
docsearch = gen_apache_doris(update_vectordb, embeddings, settings)

print(docsearch)

update_vectordb = False
```

## 构建 QA 链并向其提问

```python
llm = OpenAI()
qa = RetrievalQA.from_chain_type(
```
