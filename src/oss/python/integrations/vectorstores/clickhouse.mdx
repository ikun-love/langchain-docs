## 管理向量存储 (Manage vector store)

创建向量存储后，我们可以通过添加和删除不同的项目与它进行交互。

### 向向量存储添加项目 (Add items to vector store)

我们可以使用 `add_documents` 函数向向量存储中添加项目。

```python
from uuid import uuid4

from langchain_core.documents import Document

document_1 = Document(
    page_content="I had chocolate chip pancakes and scrambled eggs for breakfast this morning.",
    metadata={"source": "tweet"},
)

document_2 = Document(
    page_content="The weather forecast for tomorrow is cloudy and overcast, with a high of 62 degrees.",
    metadata={"source": "news"},
)

document_3 = Document(
    page_content="Building an exciting new project with LangChain - come check it out!",
    metadata={"source": "tweet"},
)

document_4 = Document(
    page_content="Robbers broke into the city bank and stole $1 million in cash.",
    metadata={"source": "news"},
)

document_5 = Document(
    page_content="Wow! That was an amazing movie. I can't wait to see it again.",
    metadata={"source": "tweet"},
)

document_6 = Document(
    page_content="Is the new iPhone worth the price? Read this review to find out.",
    metadata={"source": "website"},
)

document_7 = Document(
    page_content="The top 10 soccer players in the world right now.",
    metadata={"source": "website"},
)

document_8 = Document(
    page_content="LangGraph is the best framework for building stateful, agentic applications!",
    metadata={"source": "tweet"},
)

document_9 = Document(
    page_content="The stock market is down 500 points today due to fears of a recession.",
    metadata={"source": "news"},
)

document_10 = Document(
    page_content="I have a bad feeling I am going to get deleted :(",
    metadata={"source": "tweet"},
)

documents = [
    document_1,
    document_2,
    document_3,
    document_4,
    document_5,
    document_6,
    document_7,
    document_8,
    document_9,
    document_10,
]
# 为每个文档生成一个 UUID
uuids = [str(uuid4()) for _ in range(len(documents))]

vector_store.add_documents(documents=documents, ids=uuids)
```

### 从向量存储中删除项目 (Delete items from vector store)

我们可以使用 `delete` 函数通过 ID 从向量存储中删除项目。

```python
# 删除最后一个文档
vector_store.delete(ids=uuids[-1])
```

## 查询向量存储 (Query vector store)

一旦创建了向量存储并将相关文档添加进去，在链或代理运行时，您很可能希望对其进行查询。

### 直接查询 (Query directly)

#### 相似度搜索 (Similarity search)

执行简单的相似度搜索方法如下：

```python
results = vector_store.similarity_search(
    "LangChain provides abstractions to make working with LLMs easy", k=2
)
for res in results:
    page_content, metadata = res
    print(f"* {page_content} [{metadata}]")
```

#### 带分数的相似度搜索 (Similarity search with score)

您也可以带分数进行搜索：

```python
results = vector_store.similarity_search_with_score("Will it be hot tomorrow?", k=1)
for res, score in results:
    print(f"* [SIM={score:3f}] {res.page_content} [{res.metadata}]")
```

## 过滤 (Filtering)

您可以直接访问 ClickHouse 的 SQL，其中包含 `WHERE` 语句。您可以按照标准的 SQL 格式编写 `WHERE` 子句。

**注意**: 请注意 SQL 注入风险，此接口不应直接被终端用户调用。

如果您在设置中自定义了 `column_map`，则可以像这样使用过滤器进行搜索：

```python
meta = vector_store.metadata_column
results = vector_store.similarity_search_with_relevance_scores(
    "What did I eat for breakfast?",
    k=4,
    # 仅搜索来源为 'tweet' 的文档
    where_str=f"{meta}.source = 'tweet'",
)
for res in results:
    print(f"* {res.page_content} [{res.metadata}]")
```

#### 其他搜索方法 (Other search methods)

本 Notebook 中未涵盖许多其他搜索方法，例如 MMR 搜索或按向量搜索。要查看 `Clickhouse` 向量存储可用的搜索功能的完整列表，请参阅 [API 参考](https://python.langchain.com/api_reference/community/vectorstores/langchain_community.vectorstores.clickhouse.Clickhouse.html)。

### 通过转换为检索器进行查询 (Query by turning into retriever)

您还可以将向量存储转换为检索器 (Retriever)，以便在链中使用更方便。

下面是如何将向量存储转换为检索器，然后使用简单的查询和过滤器调用该检索器：

```python
retriever = vector_store.as_retriever(
    search_type="similarity_score_threshold",
    search_kwargs={"k": 1, "score_threshold": 0.5},
)
# 检索与 "Stealing from the bank is a crime" 相关的且 source 为 "news"，同时分数高于 0.5 的文档
retriever.invoke("Stealing from the bank is a crime", filter={"source": "news"})
```
