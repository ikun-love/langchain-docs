## 基本用法 (Basic Usage)

### 初始化向量索引 (Initialize a Vector Index)

```python
import redis
from langchain_google_memorystore_redis import (
    DistanceStrategy,
    HNSWConfig,
    RedisVectorStore,
)

# 连接到 Memorystore for Redis 实例
redis_client = redis.from_url("redis://127.0.0.1:6379")

# 使用描述性的参数配置 HNSW 索引
index_config = HNSWConfig(
    name="my_vector_index", distance_strategy=DistanceStrategy.COSINE, vector_size=128
)

# 初始化/创建向量存储索引
RedisVectorStore.init_index(client=redis_client, index_config=index_config)
```

### 准备文档 (Prepare Documents)

文本在与向量存储交互之前需要经过处理和数字表示。这包括：

* 加载文本：`TextLoader` 从文件中（例如 "state\_of\_the\_union.txt"）获取文本数据。
* 文本分割：`CharacterTextSplitter` 将文本分解成更小的块，以便嵌入模型使用。

```python
from langchain_community.document_loaders import TextLoader
from langchain_text_splitters import CharacterTextSplitter

loader = TextLoader("./state_of_the_union.txt")
documents = loader.load()
text_splitter = CharacterTextSplitter(chunk_size=1000, chunk_overlap=0)
docs = text_splitter.split_documents(documents)
```

### 将文档添加到向量存储 (Add Documents to the Vector Store)

在文本准备和嵌入生成之后，以下方法将它们插入到 Redis 向量存储中。

#### 方法 1：用于直接插入的类方法 (Classmethod for Direct Insertion)

这种方法使用 `from_documents` 类方法将嵌入创建和插入合并为一个步骤：

```python
from langchain_community.embeddings.fake import FakeEmbeddings

embeddings = FakeEmbeddings(size=128)
redis_client = redis.from_url("redis://127.0.0.1:6379")
rvs = RedisVectorStore.from_documents(
    docs, embedding=embeddings, client=redis_client, index_name="my_vector_index"
)
```

#### 方法 2：基于实例的插入 (Instance-Based Insertion)

这种方法在处理新旧 `RedisVectorStore` 时提供了灵活性：

* [可选] 创建 RedisVectorStore 实例：实例化一个 `RedisVectorStore` 对象以进行自定义。如果您已有实例，请跳到下一步。
* 添加带元数据的文本：向实例提供原始文本和元数据。嵌入生成和向量存储中的插入会自动处理。

```python
rvs = RedisVectorStore(
    client=redis_client, index_name="my_vector_index", embeddings=embeddings
)
ids = rvs.add_texts(
    texts=[d.page_content for d in docs], metadatas=[d.metadata for d in docs]
)
```

### 执行相似性搜索 (KNN) (Perform a Similarity Search (KNN))

向量存储填充后，可以搜索与查询在语义上相似的文本。以下是使用默认设置的 KNN（K 近邻）方法：

* 构建查询：自然语言问题表达了搜索意图（例如：“总统关于 Ketanji Brown Jackson 说了些什么”）。
* 检索相似结果：`similarity_search` 方法会查找向量存储中与查询含义最接近的项目。

```python
import pprint

query = "What did the president say about Ketanji Brown Jackson"
knn_results = rvs.similarity_search(query=query)
pprint.pprint(knn_results)
```

### 执行基于范围的相似性搜索 (Perform a Range-Based Similarity Search)

范围查询通过指定所需的相似性阈值以及查询文本来提供更强的控制：

* 构建查询：自然语言问题定义了搜索意图。
* 设置相似性阈值：`distance_threshold` 参数决定了匹配项必须有多接近才被认为是相关的。
* 检索结果：`similarity_search_with_score` 方法会查找向量存储中落在指定相似性阈值内的项目。

```python
rq_results = rvs.similarity_search_with_score(query=query, distance_threshold=0.8)
pprint.pprint(rq_results)
```

### 执行最大边际相关性 (MMR) 搜索 (Perform a Maximal Marginal Relevance (MMR) Search)

MMR 查询旨在找到既与查询相关又彼此多样化的结果，从而减少搜索结果中的冗余。

* 构建查询：自然语言问题定义了搜索意图。
* 平衡相关性和多样性：`lambda_mult` 参数控制严格相关性和促进结果多样性之间的权衡。
* 检索 MMR 结果：`max_marginal_relevance_search` 方法会根据 `lambda` 设置，返回优化相关性和多样性组合的项目。

```python
mmr_results = rvs.max_marginal_relevance_search(query=query, lambda_mult=0.90)
pprint.pprint(mmr_results)
```

## 将向量存储用作检索器 (Use the Vector Store as a Retriever)

为了与其他 LangChain 组件无缝集成，可以将向量存储转换为检索器（Retriever）。这有几个优点：

* LangChain 兼容性：许多 LangChain 工具和方法被设计为直接与检索器交互。
* 使用简便性：`as_retriever()` 方法将向量存储转换为一种简化查询的格式。

```python
retriever = rvs.as_retriever()
results = retriever.invoke(query)
pprint.pprint(results)
```

## 清理 (Clean up)

### 从向量存储中删除文档 (Delete Documents from the Vector Store)

有时需要从向量存储中删除文档（及其关联的向量）。`delete` 方法提供了此功能。

```python
rvs.delete(ids)
```

### 删除向量索引 (Delete a Vector Index)

在某些情况下，有必要删除现有的向量索引。常见原因包括：

* 索引配置更改：如果需要修改索引参数，通常需要删除并重新创建索引。
* 存储管理：删除未使用的索引有助于释放 Redis 实例中的空间。

注意：向量索引的删除是不可逆的操作。在继续之前，请确保不再需要存储的向量和搜索功能。

```python
# 删除向量索引
RedisVectorStore.drop_index(client=redis_client, index_name="my_vector_index")
```
