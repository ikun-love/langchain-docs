在本指南中，我们将介绍如何使用 `UpstashRatelimitHandler` 来添加基于请求数量或令牌数量的速率限制。此处理程序使用了 [Upstash 的 ratelimit 库](https://github.com/upstash/ratelimit-py/)，该库利用 [Upstash Redis](https://upstash.com/docs/redis/overall/getstarted)。

Upstash Ratelimit 的工作原理是：每当调用 `limit` 方法时，都会向 Upstash Redis 发送一个 HTTP 请求。系统会检查并更新用户的剩余令牌/请求。根据可用的剩余令牌，我们可以停止执行昂贵的操作，例如调用 LLM 或查询向量存储：

```py
response = ratelimit.limit()
if response.allowed:
    execute_costly_operation()
```

`UpstashRatelimitHandler` 允许您在几分钟内将速率限制逻辑集成到您的链（chain）中。

首先，您需要访问 [Upstash 控制台](https://console.upstash.com/login) 并创建一个 Redis 数据库（[请参阅我们的文档](https://upstash.com/docs/redis/overall/getstarted)）。创建数据库后，您需要设置以下环境变量：

```
UPSTASH_REDIS_REST_URL="****"
UPSTASH_REDIS_REST_TOKEN="****"
```

接下来，您需要使用以下命令安装 Upstash Ratelimit 和 Redis 库：

```
pip install upstash-ratelimit upstash-redis
```

您现在已准备好将速率限制添加到您的链中了！

## 按请求进行速率限制

假设我们想允许用户每分钟调用我们的链 10 次。实现这一点非常简单：

```python
# 设置环境变量
import os

os.environ["UPSTASH_REDIS_REST_URL"] = "****"
os.environ["UPSTASH_REDIS_REST_TOKEN"] = "****"

from langchain_community.callbacks import UpstashRatelimitError, UpstashRatelimitHandler
from langchain_core.runnables import RunnableLambda
from upstash_ratelimit import FixedWindow, Ratelimit
from upstash_redis import Redis

# 创建速率限制器
ratelimit = Ratelimit(
    redis=Redis.from_env(),
    # 窗口大小为 60 秒内，最多 10 个请求：
    limiter=FixedWindow(max_requests=10, window=60),
)

# 创建处理器
user_id = "user_id"  # 应该是一个获取用户 ID 的方法
handler = UpstashRatelimitHandler(identifier=user_id, request_ratelimit=ratelimit)

# 创建模拟链
chain = RunnableLambda(str)

# 使用处理器调用链：
try:
    result = chain.invoke("Hello world!", config={"callbacks": [handler]})
except UpstashRatelimitError:
    print("Handling ratelimit.", UpstashRatelimitError)
```

```output
Error in UpstashRatelimitHandler.on_chain_start callback: UpstashRatelimitError('Request limit reached!')
```
```output
Handling ratelimit. <class 'langchain_community.callbacks.upstash_ratelimit_callback.UpstashRatelimitError'>
```

请注意，我们将处理器传递给了 `invoke` 方法，而不是在定义链时传递它。

对于 `FixedWindow` 以外的速率限制算法，请参阅 [upstash-ratelimit 文档](https://github.com/upstash/ratelimit-py?tab=readme-ov-file#ratelimiting-algorithms)。

在执行我们管道中的任何步骤之前，速率限制器会检查该用户是否已超出请求限制。如果超出，则会引发 `UpstashRatelimitError` 错误。

## 按令牌进行速率限制

另一种选择是根据以下情况对链调用进行速率限制：

1. 提示（prompt）中的令牌数量
2. 提示中的令牌数量和 LLM 的返回内容（completion）中的令牌数量

只有当您的链中包含 LLM 时，此方法才有效。另一个要求是您使用的 LLM 在其 `LLMOutput` 中返回令牌使用情况信息。

### 工作原理

在调用 LLM 之前，处理器将获取剩余的令牌数量。如果剩余令牌数大于 0，则会调用 LLM。否则，将引发 `UpstashRatelimitError` 错误。

LLM 调用完成后，令牌使用情况信息将用于从用户的剩余令牌中进行扣减。在此阶段的链中不会引发错误。

### 配置

对于第一种配置，只需像这样初始化处理器即可：

```python
ratelimit = Ratelimit(
        redis=Redis.from_env(),
    # 窗口大小为 60 秒内，最多 1000 个令牌：
        limiter=FixedWindow(max_requests=1000, window=60),
)

handler = UpstashRatelimitHandler(identifier=user_id, token_ratelimit=ratelimit)
```

对于第二种配置，初始化处理器的方法如下：

```python
ratelimit = Ratelimit(
        redis=Redis.from_env(),
    # 窗口大小为 60 秒内，最多 1000 个令牌：
        limiter=FixedWindow(max_requests=1000, window=60),
)

handler = UpstashRatelimitHandler(
        identifier=user_id,
        token_ratelimit=ratelimit,
        include_output_tokens=True,  # 设置为 True
)
```

您也可以同时使用基于请求和基于令牌的速率限制，只需同时传递 `request_ratelimit` 和 `token_ratelimit` 参数即可。

下面是一个使用 LLM 的链的示例：

```python
# 设置环境变量
import os

os.environ["UPSTASH_REDIS_REST_URL"] = "****"
os.environ["UPSTASH_REDIS_REST_TOKEN"] = "****"
os.environ["OPENAI_API_KEY"] = "****"

from langchain_community.callbacks import UpstashRatelimitError, UpstashRatelimitHandler
from langchain_core.runnables import RunnableLambda
from langchain_openai import ChatOpenAI
from upstash_ratelimit import FixedWindow, Ratelimit
from upstash_redis import Redis

# 创建速率限制器
ratelimit = Ratelimit(
        redis=Redis.from_env(),
    # 窗口大小为 60 秒内，最多 500 个令牌：
        limiter=FixedWindow(max_requests=500, window=60),
)

# 创建处理器
user_id = "user_id"  # 应该是一个获取用户 ID 的方法
handler = UpstashRatelimitHandler(identifier=user_id, token_ratelimit=ratelimit)

# 创建模拟链
as_str = RunnableLambda(str)
model = ChatOpenAI()

chain = as_str | model

# 使用处理器调用链：
try:
        result = chain.invoke("Hello world!", config={"callbacks": [handler]})
except UpstashRatelimitError:
    print("Handling ratelimit.", UpstashRatelimitError)
```

```output
Error in UpstashRatelimitHandler.on_llm_start callback: UpstashRatelimitError('Token limit reached!')
```
```output
Handling ratelimit. <class 'langchain_community.callbacks.upstash_ratelimit_callback.UpstashRatelimitError'>
```
