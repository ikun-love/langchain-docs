title: Google Cloud Document AI
---

Document AI 是 Google Cloud 提供的文档智能处理平台，旨在将文档中的**非结构化数据**转换为**结构化数据**，从而更轻松地理解、分析和使用这些信息。

了解更多：

- [Document AI 概览](https://cloud.google.com/document-ai/docs/overview)
- [Document AI 视频和实验](https://cloud.google.com/document-ai/docs/videos)
- [立即试用！](https://cloud.google.com/document-ai/docs/drag-and-drop)

此模块包含一个基于 Google Cloud DocAI 的 `PDF` 解析器。

要使用此解析器，您需要安装两个库：

```python
pip install -qU  langchain-google-community[docai]
```

首先，您需要设置一个 Google Cloud Storage (GCS) 存储桶，并按照这里的说明（[cloud.google.com/document-ai/docs/create-processor](https://cloud.google.com/document-ai/docs/create-processor)）创建一个您自己的**光学字符识别 (OCR)** 处理器。

`GCS_OUTPUT_PATH` 应该指向 GCS 上的一个文件夹路径（以 `gs://` 开头），而 `PROCESSOR_NAME` 的格式应类似于 `projects/PROJECT_NUMBER/locations/LOCATION/processors/PROCESSOR_ID` 或 `projects/PROJECT_NUMBER/locations/LOCATION/processors/PROCESSOR_ID/processorVersions/PROCESSOR_VERSION_ID`。 您可以以编程方式获取它，或者从 Google Cloud Console 中“处理器详情 (Processor details)”标签页的“预测端点 (Prediction endpoint)”部分复制该值。

```python
GCS_OUTPUT_PATH = "gs://BUCKET_NAME/FOLDER_PATH"
PROCESSOR_NAME = "projects/PROJECT_NUMBER/locations/LOCATION/processors/PROCESSOR_ID"
```

```python
from langchain_core.document_loaders.blob_loaders import Blob
from langchain_google_community import DocAIParser
```

现在，创建一个 `DocAIParser` 实例。

```python
parser = DocAIParser(
    location="us", processor_name=PROCESSOR_NAME, gcs_output_path=GCS_OUTPUT_PATH
)
```

对于此示例，您可以使用上传到公共 GCS 存储桶的 Alphabet 收益报告文件。

[2022Q1_alphabet_earnings_release.pdf](https://storage.googleapis.com/cloud-samples-data/gen-app-builder/search/alphabet-investor-pdfs/2022Q1_alphabet_earnings_release.pdf)

将文档传递给 `lazy_parse()` 方法以进行处理：

```python
blob = Blob(
    path="gs://cloud-samples-data/gen-app-builder/search/alphabet-investor-pdfs/2022Q1_alphabet_earnings_release.pdf"
)
```

我们将为每页获得一个文档，共 11 个：

```python
docs = list(parser.lazy_parse(blob))
print(len(docs))
```

```output
11
```

您可以对 Blob 进行逐个的端到端解析。如果文档很多，将它们批量处理可能是一个更好的方法，甚至可能将解析与处理解析结果的操作分离。

```python
operations = parser.docai_parse([blob])
print([op.operation.name for op in operations])
```

```output
['projects/543079149601/locations/us/operations/16447136779727347991']
```

您可以检查操作是否已完成：

```python
parser.is_running(operations)
```

```output
True
```

操作完成后，您可以解析结果：

```python
parser.is_running(operations)
```

```output
False
```

```python
results = parser.get_results(operations)
print(results[0])
```

```output
DocAIParsingResults(source_path='gs://vertex-pgt/examples/goog-exhibit-99-1-q1-2023-19.pdf', parsed_path='gs://vertex-pgt/test/run1/16447136779727347991/0')
```

现在我们可以从解析结果生成 Document 对象：

```python
docs = list(parser.parse_from_results(results))
```

```python
print(len(docs))
```

```output
11
```
