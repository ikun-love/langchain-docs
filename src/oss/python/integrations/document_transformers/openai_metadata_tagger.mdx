---
title: OpenAI 元数据标签器
---

在摄取文档时，通常需要用结构化的元数据（例如文档的标题、语气或长度）对其进行标记，以便后续进行更有针对性的相似性搜索。然而，对于大量的文档来说，手动完成标记过程可能会非常繁琐。

`OpenAIMetadataTagger` 文档转换器通过根据提供的 Schema 从每个文档中提取元数据来自动执行此过程。它在底层使用可配置的 `OpenAI Functions` 驱动的链，因此如果您传入一个自定义的 LLM 实例，它必须是一个支持函数调用的 OpenAI 模型。

**注意：** 此文档转换器最适用于完整的文档，因此最好先用完整文档运行它，然后再进行任何其他分割或处理！

例如，假设您想要索引一组电影评论。您可以像下面这样，使用一个有效的 `JSON Schema` 对象来初始化文档转换器：

```python
from langchain_community.document_transformers.openai_functions import (
    create_metadata_tagger,
)
from langchain_core.documents import Document
from langchain_openai import ChatOpenAI
```

```python
schema = {
    "properties": {
        "movie_title": {"type": "string"},
        "critic": {"type": "string"},
        "tone": {"type": "string", "enum": ["positive", "negative"]},
        "rating": {
            "type": "integer",
            "description": "影评人给电影打的星级数",
        },
    },
    "required": ["movie_title", "critic", "tone"],
}

# 必须是支持函数调用的 OpenAI 模型
llm = ChatOpenAI(temperature=0, model="gpt-3.5-turbo-0613")

document_transformer = create_metadata_tagger(metadata_schema=schema, llm=llm)
```

然后，您可以简单地将文档列表传递给文档转换器，它就会从内容中提取元数据：

```python
original_documents = [
    Document(
        page_content="Review of The Bee Movie\nBy Roger Ebert\n\nThis is the greatest movie ever made. 4 out of 5 stars."
    ),
    Document(
        page_content="Review of The Godfather\nBy Anonymous\n\nThis movie was super boring. 1 out of 5 stars.",
        metadata={"reliable": False},
    ),
]

enhanced_documents = document_transformer.transform_documents(original_documents)
```

```python
import json

print(
    *[d.page_content + "\n\n" + json.dumps(d.metadata) for d in enhanced_documents],
    sep="\n\n---------------\n\n",
)
```

```output
Review of The Bee Movie
By Roger Ebert

This is the greatest movie ever made. 4 out of 5 stars.

{"movie_title": "The Bee Movie", "critic": "Roger Ebert", "tone": "positive", "rating": 4}

---------------

Review of The Godfather
By Anonymous

This movie was super boring. 1 out of 5 stars.

{"movie_title": "The Godfather", "critic": "Anonymous", "tone": "negative", "rating": 1, "reliable": false}
```

新的文档随后可以由文本分割器进一步处理，然后再加载到向量存储中。提取的字段不会覆盖现有的元数据。

您也可以使用 Pydantic Schema 来初始化文档转换器：

```python
from typing import Literal

from pydantic import BaseModel, Field


class Properties(BaseModel):
    movie_title: str
    critic: str
    tone: Literal["positive", "negative"]
    rating: int = Field(description="5 星制评分")


document_transformer = create_metadata_tagger(Properties, llm)
enhanced_documents = document_transformer.transform_documents(original_documents)

print(
    *[d.page_content + "\n\n" + json.dumps(d.metadata) for d in enhanced_documents],
    sep="\n\n---------------\n\n",
)
```

```output
Review of The Bee Movie
By Roger Ebert

This is the greatest movie ever made. 4 out of 5 stars.

{"movie_title": "The Bee Movie", "critic": "Roger Ebert", "tone": "positive", "rating": 4}

---------------

Review of The Godfather
By Anonymous

This movie was super boring. 1 out of 5 stars.

{"movie_title": "The Godfather", "critic": "Anonymous", "tone": "negative", "rating": 1, "reliable": false}
```

## 定制化 (Customization)

您可以将标准的 LLMChain 参数传递给文档转换器构造函数中的底层标记链。例如，如果您想让 LLM 关注输入文档中的特定细节，或者以某种特定风格提取元数据，您可以传入一个自定义提示词：

```python
from langchain_core.prompts import ChatPromptTemplate

prompt = ChatPromptTemplate.from_template(
    """请从以下文本中提取相关信息。
匿名影评人实际上是 Roger Ebert。

{input}
"""
)

document_transformer = create_metadata_tagger(schema, llm, prompt=prompt)
enhanced_documents = document_transformer.transform_documents(original_documents)

print(
    *[d.page_content + "\n\n" + json.dumps(d.metadata) for d in enhanced_documents],
    sep="\n\n---------------\n\n",
)
```

```output
Review of The Bee Movie
By Roger Ebert

This is the greatest movie ever made. 4 out of 5 stars.

{"movie_title": "The Bee Movie", "critic": "Roger Ebert", "tone": "positive", "rating": 4}

---------------

Review of The Godfather
By Anonymous

This movie was super boring. 1 out of 5 stars.

{"movie_title": "The Godfather", "critic": "Roger Ebert", "tone": "negative", "rating": 1, "reliable": false}
```
