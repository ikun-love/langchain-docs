语言模型存在 Token 限制。您不应超过此 Token 限制。因此，当您将文本[拆分成块](/oss/integrations/splitters/)时，最好计算一下 Token 的数量。有很多分词器（Tokenizers）。在计算文本中的 Token 时，您应该使用与语言模型中相同的分词器。

:::python
## tiktoken

<Note>
**[tiktoken](https://github.com/openai/tiktoken) 是 `OpenAI` 创建的一个快速 `BPE` 分词器。**
</Note>


我们可以使用 `tiktoken` 来估算使用的 Token 数。这对于 OpenAI 的模型来说可能更准确。

1. 文本的分割方式：按传入的字符进行分割。
2. 分块大小的度量方式：使用 `tiktoken` 分词器度量。

@[CharacterTextSplitter]、@[RecursiveCharacterTextSplitter] 和 @[TokenTextSplitter] 可以直接与 `tiktoken` 一起使用。

```python
pip install --upgrade --quiet langchain-text-splitters tiktoken
```

```python
from langchain_text_splitters import CharacterTextSplitter

# 这是我们可以分割的长文档。
with open("state_of_the_union.txt") as f:
    state_of_the_union = f.read()
```

要使用 @[CharacterTextSplitter] 进行分割，然后使用 `tiktoken` 合并分块，请使用其 `.from_tiktoken_encoder()` 方法。请注意，此方法产生的分割结果在按 `tiktoken` 分词器度量时，其大小可能大于指定的 `chunk_size`。

`.from_tiktoken_encoder()` 方法接受 `encoding_name`（例如 `cl100k_base`）或 `model_name`（例如 `gpt-4`）作为参数。所有其他参数，如 `chunk_size`、`chunk_overlap` 和 `separators`，都用于实例化 `CharacterTextSplitter`：

```python
text_splitter = CharacterTextSplitter.from_tiktoken_encoder(
    encoding_name="cl100k_base", chunk_size=100, chunk_overlap=0
)
texts = text_splitter.split_text(state_of_the_union)
```

```python
print(texts[0])
```
```output
Madam Speaker, Madam Vice President, our First Lady and Second Gentleman. Members of Congress and the Cabinet. Justices of the Supreme Court. My fellow Americans.

Last year COVID-19 kept us apart. This year we are finally together again.

Tonight, we meet as Democrats Republicans and Independents. But most importantly as Americans.

With a duty to one another to the American people to the Constitution.
```
要对分块大小实施硬性限制，我们可以使用 `RecursiveCharacterTextSplitter.from_tiktoken_encoder`，如果每个分割结果的大小超过限制，它将递归地继续分割：

```python
from langchain_text_splitters import RecursiveCharacterTextSplitter

text_splitter = RecursiveCharacterTextSplitter.from_tiktoken_encoder(
    model_name="gpt-4",
    chunk_size=100,
    chunk_overlap=0,
)
```

我们也可以加载一个 `TokenTextSplitter` 分割器，它直接与 `tiktoken` 配合工作，并将确保每个分割结果都小于指定的大小（`chunk_size`）。

```python
from langchain_text_splitters import TokenTextSplitter

text_splitter = TokenTextSplitter(chunk_size=10, chunk_overlap=0)

texts = text_splitter.split_text(state_of_the_union)
print(texts[0])
```
```output
Madam Speaker, Madam Vice President, our
```
一些书面语言（例如中文和日文）的字符会编码成两个或更多的 Token。直接使用 `TokenTextSplitter` 可能会在两个分块之间分割字符的 Token，从而导致 Unicode 字符损坏。请使用 `RecursiveCharacterTextSplitter.from_tiktoken_encoder` 或 `CharacterTextSplitter.from_tiktoken_encoder` 来确保分块包含有效的 Unicode 字符串。

```ts
import { TokenTextSplitter } from "@langchain/textsplitters";
import { readFileSync } from "fs";

const stateOfTheUnion = readFileSync("state_of_the_union.txt", "utf8");
```

要使用 @[TokenTextSplitter] 进行分割，然后使用 `tiktoken` 合并分块，请在初始化 @[TokenTextSplitter] 时传入一个 `encodingName`（例如 cl100k_base）。请注意，此方法产生的分割结果在按 `tiktoken` 分词器度量时，其大小可能大于指定的 `chunk_size`。

```ts

// 示例：使用 cl100k_base 编码
const splitter = new TokenTextSplitter({ encodingName: "cl100k_base", chunkSize: 10, chunkOverlap: 0 });

const texts = splitter.splitText(stateOfTheUnion);
console.log(texts[0]);
```

## SentenceTransformers

[SentenceTransformersTokenTextSplitter](https://python.langchain.com/api_reference/text_splitters/sentence_transformers/langchain_text_splitters.sentence_transformers.SentenceTransformersTokenTextSplitter.html) 是一种专用于 sentence-transformer 模型的文本分割器。默认行为是将文本分割成适合您想要使用的 sentence-transformer 模型 Token 窗口大小的分块。

要根据 sentence-transformers 分词器来分割文本并限制 Token 数量，请实例化一个 `SentenceTransformersTokenTextSplitter`。您可以选择性地指定：

- `chunk_overlap`: Token 重叠的数量；
- `model_name`: sentence-transformer 模型名称，默认为 `"sentence-transformers/all-mpnet-base-v2"`；
- `tokens_per_chunk`: 每个分块期望的 Token 数量。

```python
from langchain_text_splitters import SentenceTransformersTokenTextSplitter

splitter = SentenceTransformersTokenTextSplitter(chunk_overlap=0)
text = "Lorem "

count_start_and_stop_tokens = 2
text_token_count = splitter.count_tokens(text=text) - count_start_and_stop_tokens
print(text_token_count)
```
```output
2
```

```python
token_multiplier = splitter.maximum_tokens_per_chunk // text_token_count + 1

# `text_to_split` 不适合单个分块
text_to_split = text * token_multiplier

print(f"tokens in text to split: {splitter.count_tokens(text=text_to_split)}")
```
```output
tokens in text to split: 514
```

```python
text_chunks = splitter.split_text(text=text_to_split)

print(text_chunks[1])
```
```output
lorem
```

## KoNLPY

<Note>
[KoNLPy: Korean NLP in Python](https://konlpy.org/en/latest/) 是一个用于处理韩语自然语言处理（NLP）的 Python 包。
</Note>

Token 分割涉及将文本分割成更小、更容易管理的单元，这些单元称为 Token。这些 Token 通常是单词、短语、符号或其他有意义的元素，对于后续的处理和分析至关重要。在英语等语言中，Token 分割通常涉及用空格和标点符号分隔单词。Token 分割的有效性在很大程度上取决于分词器对语言结构的理解，以确保生成有意义的 Token。由于专为英语设计的`分词器`无法理解韩语等其他语言独特的语义结构，因此不能有效地用于韩语自然语言处理。

### 使用 KoNLPy 的 Kkma 分析器进行韩语 Token 分割
对于韩语文本，KoNLPY 包含一个称为 `Kkma`（韩国知识形态素分析器）的形态学分析器。`Kkma` 提供对韩语文本的详细形态学分析。它将句子分解成单词，将单词分解成各自的形态素，并识别每个 Token 的词性。它可以将文本块分割成单独的句子，这对于处理长文本特别有用。

### 使用注意事项
虽然 `Kkma` 以其详细的分析而闻名，但重要的是要注意，这种精度可能会影响处理速度。因此，`Kkma` 最适合于优先考虑分析深度而非快速文本处理的应用。

```python
# pip install konlpy
```

```python
# 这是我们想要分割成其组成句子的长韩语文档。
with open("./your_korean_doc.txt") as f:
    korean_document = f.read()
```

```python
from langchain_text_splitters import KonlpyTextSplitter

text_splitter = KonlpyTextSplitter()
```

```python
texts = text_splitter.split_text(korean_document)
# 句子是使用 "\n\n" 字符分割的。
print(texts[0])
```

## Hugging Face 分词器

[Hugging Face](https://huggingface.co/docs/tokenizers/index) 提供了许多分词器。

我们使用 Hugging Face 的分词器，即 [GPT2TokenizerFast](https://huggingface.co/Ransaka/gpt2-tokenizer-fast) 来计算文本的 Token 长度。

1. 文本的分割方式：按传入的字符进行分割。
2. 分块大小的度量方式：由 `Hugging Face` 分词器计算出的 Token 数量。

```python
from transformers import GPT2TokenizerFast

tokenizer = GPT2TokenizerFast.from_pretrained("gpt2")
```

```python
# 这是我们可以分割的长文档。
with open("state_of_the_union.txt") as f:
    state_of_the_union = f.read()
from langchain_text_splitters import CharacterTextSplitter
```

```python
text_splitter = CharacterTextSplitter.from_huggingface_tokenizer(
    tokenizer, chunk_size=100, chunk_overlap=0
)
texts = text_splitter.split_text(state_of_the_union)
```

```python
print(texts[0])
```
```output
Madam Speaker, Madam Vice President, our First Lady and Second Gentleman. Members of Congress and the Cabinet. Justices of the Supreme Court. My fellow Americans.

Last year COVID-19 kept us apart. This year we are finally together again.

Tonight, we meet as Democrats Republicans and Independents. But most importantly as Americans.

With a duty to one another to the American people to the Constitution.
```
