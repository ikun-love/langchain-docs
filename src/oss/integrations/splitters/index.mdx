**文本分块器**（Text splitters）用于将大型文档分解成更小的块（chunks），这些块可以被单独检索，并且能适应模型的上下文窗口限制。

有几种不同的文档分割策略，每种都有其独特的优势。

<Tip>
    对于大多数用例，请从 [`RecursiveCharacterTextSplitter`](/oss/integrations/splitters/recursive_text_splitter) 开始使用。它在保持上下文完整性和管理块大小时提供了很好的平衡。这个默认策略开箱即用效果良好，只有当您需要针对特定应用微调性能时，才需要考虑调整它。
</Tip>

## 基于文本结构

文本自然地组织成层级单元，例如段落、句子和单词。我们可以利用这种固有的结构来指导我们的分割策略，创建的块能够保持自然的语言流程、内部语义连贯性，并适应不同粒度的文本。LangChain 的 `RecursiveCharacterTextSplitter` 就实现了这一概念：

- [`RecursiveCharacterTextSplitter`](/oss/integrations/splitters/recursive_text_splitter) 尝试保持较大的单元（例如段落）的完整性。
- 如果一个单元超出了设定的块大小（chunk size），它会降到下一个级别（例如句子）。
- 如果有必要，这个过程会一直持续到单词级别。

示例用法：

:::python
```python
from langchain_text_splitters import RecursiveCharacterTextSplitter

text_splitter = RecursiveCharacterTextSplitter(chunk_size=100, chunk_overlap=0)
texts = text_splitter.split_text(document)
```
:::
:::js
```ts
import { RecursiveCharacterTextSplitter } from "@langchain/textsplitters";

const splitter = new RecursiveCharacterTextSplitter({ chunkSize: 100, chunkOverlap: 0 })
const texts = splitter.splitText(document)
```
:::

## 基于长度

一个直观的策略是根据文档的长度进行分割。这种简单而有效的方法确保了每个块都不会超过指定的尺寸限制。基于长度分割的关键优势包括：

- 实现简单
- 分块大小一致
- 易于适应不同模型的输入要求

基于长度的分割类型包括：

- **Token-based (基于 Token)**: 根据 Token 的数量分割文本，这在处理语言模型时特别有用。
- **Character-based (基于字符)**: 根据字符数分割文本，这对不同类型的文本来说通常更为一致。

使用 LangChain 的 `CharacterTextSplitter` 进行基于 Token 的分割的示例实现：

:::python
```python
from langchain_text_splitters import CharacterTextSplitter

text_splitter = CharacterTextSplitter.from_tiktoken_encoder(
    encoding_name="cl100k_base", chunk_size=100, chunk_overlap=0
)
texts = text_splitter.split_text(document)
```
:::
:::js
```ts
import { TokenTextSplitter } from "@langchain/textsplitters";

const splitter = new TokenTextSplitter({ encodingName: "cl100k_base", chunkSize: 100, chunkOverlap: 0 })
const texts = splitter.splitText(document)
```
:::

## 基于文档结构

有些文档具有固有的结构，如 HTML、Markdown 或 JSON 文件。在这种情况下，根据文档的结构进行分割是很有益的，因为结构通常会自然地将语义相关的文本分组在一起。基于结构分割的关键优势包括：

- 保持文档的逻辑组织结构
- 维护每个块的上下文
- 对于下游任务（如检索或摘要）可能更有效

:::python
结构化分割的示例：

- Markdown: 基于标题（例如 `#`, `##`, `###`）进行分割
- HTML: 使用 HTML 标签进行分割
- JSON: 按对象或数组元素进行分割
- 代码: 按函数、类或逻辑块进行分割
