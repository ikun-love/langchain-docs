sidebarTitle: 安装

要安装基础的 LangGraph 包：

:::python
<CodeGroup>
```bash pip
pip install -U langgraph
```

```bash uv
uv add langgraph
```
</CodeGroup>
:::

:::js
<CodeGroup>
```bash npm
npm install @langchain/langgraph @langchain/core
```

```bash pnpm
pnpm add @langchain/langgraph @langchain/core
```

```bash yarn
yarn add @langchain/langgraph @langchain/core
```

```bash bun
bun add @langchain/langgraph @langchain/core
```
</CodeGroup>
:::

要使用 LangGraph，通常还需要访问大型语言模型（LLM）并定义工具（Tools）。
您可以根据自己的需求来处理这些操作。

一种（我们在文档中将采用的）方法是使用 [LangChain](/oss/langchain/overview)。

使用以下命令安装 LangChain：

:::python
<CodeGroup>
```bash pip
pip install -U langchain
# 需要 Python 3.10 或更高版本
```

```bash uv
uv add langchain
# 需要 Python 3.10 或更高版本
```
</CodeGroup>
:::

:::js
<CodeGroup>
```bash npm
npm install langchain
```

```bash pnpm
pnpm add langchain
```

```bash yarn
yarn add langchain
```

```bash bun
bun add langchain
```
</CodeGroup>
:::

要使用特定的 LLM 提供商包，您需要单独安装它们。

有关特定提供商的安装说明，请参阅 [集成](/oss/integrations/providers/overview) 页面。
