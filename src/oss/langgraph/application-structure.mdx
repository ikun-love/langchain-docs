title: 应用程序结构

一个 LangGraph 应用程序由一个或多个图（graphs）、一个配置文件（`langgraph.json`）、一个指定依赖项的文件，以及一个可选的用于指定环境变量的 `.env` 文件组成。

本指南将展示一个典型的应用程序结构，并说明如何提供所需的配置以使用 [LangSmith 部署](/langsmith/deployments) 来部署应用程序。

<Info>
LangSmith 部署是一个托管服务平台，用于部署和扩展 LangGraph 代理。它负责处理基础设施、扩展和操作问题，因此您可以直接从代码仓库部署有状态、长期运行的代理。请在 [部署文档](/langsmith/deployments) 中了解更多信息。
</Info>

## 关键概念

要使用 LangSmith 进行部署，应提供以下信息：

1. 一个 [LangGraph 配置文件](#configuration-file-concepts)（`langgraph.json`），用于指定应用程序所依赖的依赖项、图以及要使用的环境变量。
2. 实现应用程序逻辑的 [图（graphs）](#graphs)。
3. 一个指定运行应用程序所需 [依赖项](#dependencies) 的文件。
4. 应用程序运行所需的 [环境变量](#environment-variables)。

以下是应用程序目录结构的示例：

    ```plaintext
    ├── requirements.txt # 包依赖项
    └── langgraph.json # LangGraph 配置文件
    ```
    </Tab>

    ```plaintext
    ├── my_agent # 所有项目代码位于此处

    │   │   ├── __init__.py

    │   ├── __init__.py
    ```

:::js

## 配置文件

`langgraph.json` 文件是一个 JSON 文件，用于指定部署 LangGraph 应用程序所需的依赖项、图、环境变量和其他设置。

有关 JSON 文件中所有受支持键的详细信息，请参阅 [LangGraph 配置文件参考](/langsmith/cli#configuration-file)。

<Tip>
[LangGraph CLI](/langsmith/cli) 默认使用当前目录中的配置文件 `langgraph.json`。
</Tip>

### 示例

:::python
* 依赖项涉及一个自定义的本地包和 `langchain_openai` 包。
* 将从文件 `./your_package/your_file.py` 中加载一个图，变量名为 `variable`。
* 环境变量将从 `.env` 文件中加载。

```json
{
  "dependencies": ["langchain_openai", "./your_package"],
  "graphs": {
    "my_agent": "./your_package/your_file.py:agent"
  },
  "env": "./.env"
}
```
:::

:::js
* 依赖项将从本地目录中的依赖文件加载（例如 `package.json`）。
* 将从文件 `./your_package/your_file.js` 中加载一个图，函数名为 `agent`。
* 环境变量 `OPENAI_API_KEY` 在此内联设置。

```json
{
  "dependencies": ["."],
  "graphs": {
    "my_agent": "./your_package/your_file.js:agent"
  },
  "env": {
    "OPENAI_API_KEY": "secret-key"
  }
}
```
:::

## 依赖项 (Dependencies)

:::python
LangGraph 应用程序可能依赖于其他 Python 包。
:::

:::js
LangGraph 应用程序可能依赖于其他 TypeScript/JavaScript 库。
:::

您通常需要为依赖项的正确设置指定以下信息：

:::python
1. 目录中用于指定依赖项的文件（例如 `requirements.txt`、`pyproject.toml` 或 `package.json`）。
:::

:::js
1. 目录中用于指定依赖项的文件（例如 `package.json`）。
:::

1. [LangGraph 配置文件](#configuration-file-concepts) 中用于指定运行 LangGraph 应用程序所需依赖项的 `dependencies` 键。
2. 可以使用 [LangGraph 配置文件](#configuration-file-concepts) 中的 `dockerfile_lines` 键来指定任何额外的二进制文件或系统库。

## 图 (Graphs)

使用 [LangGraph 配置文件](#configuration-file-concepts) 中的 `graphs` 键来指定将哪些图提供给已部署的 LangGraph 应用程序。

您可以在配置文件中指定一个或多个图。每个图由一个唯一的名称（用于标识）和一个路径来指定，该路径指向 (1) 编译后的图或 (2) 定义图的函数。

## 环境变量 (Environment variables)

如果您正在本地使用已部署的 LangGraph 应用程序，您可以在 [LangGraph 配置文件](#configuration-file-concepts) 的 `env` 键中配置环境变量。

对于生产部署，您通常希望在部署环境中配置环境变量。
