当您准备将代理（Agent）部署到生产环境时，LangSmith 提供了一个专为代理工作负载设计的托管平台。传统的托管平台是为无状态、短暂的 Web 应用而构建的，而 LangGraph 是**专门为需要持久化状态和后台执行的有状态、长期运行的代理**而设计的。LangSmith 会处理基础设施、扩展和运维方面的顾虑，因此您可以直接从您的代码仓库进行部署。

## 前提条件

在开始之前，请确保您拥有以下条件：

* 一个 [GitHub 账户](https://github.com/)
* 一个 [LangSmith 账户](https://smith.langchain.com/)（可免费注册）

## 部署您的代理

### 1. 在 GitHub 上创建一个仓库

您的应用程序代码必须存放在一个 GitHub 仓库中，才能部署到 LangSmith。LangSmith 支持公共和私有仓库。对于本快速入门指南，请首先参考[本地服务器设置指南](/oss/langgraph/studio#setup-local-agent-server)确保您的应用与 LangGraph 兼容。然后，将您的代码推送到该仓库。
