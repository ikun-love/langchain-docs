LangGraph 受到 Klarna、Replit、Elastic 等塑造未来的公司的信任。它是一个**低级编排框架和运行时环境**，用于构建、管理和部署长期运行的、有状态的智能体（Agent）。

LangGraph 的级别非常低，完全专注于智能体的**编排（orchestration）**。在开始使用 LangGraph 之前，我们建议您先熟悉一些用于构建智能体的核心组件，例如 [模型 (models)](/oss/langchain/models) 和 [工具 (tools)](/oss/langchain/tools)。

在整个文档中，我们将频繁使用 [LangChain](/oss/langchain/overview) 组件来集成模型和工具，但您**不一定**需要使用 LangChain 才能使用 LangGraph。如果您刚开始接触智能体，或者需要一个更高层次的抽象，我们推荐使用 LangChain 的 [Agents](/oss/langchain/agents)，它们为常见的 LLM 和工具调用循环提供了预构建的架构。

LangGraph 专注于智能体编排所需的基础能力：持久化执行（durable execution）、流式传输（streaming）、人机协作（human-in-the-loop）等等。

然后，创建一个简单的 hello world 示例：

:::python
```python
from langgraph.graph import StateGraph, MessagesState, START, END

def mock_llm(state: MessagesState):
    return {"messages": [{"role": "ai", "content": "hello world"}]}

graph = StateGraph(MessagesState)
graph.add_node(mock_llm)
graph.add_edge(START, "mock_llm")
graph.add_edge("mock_llm", END)
graph = graph.compile()

graph.invoke({"messages": [{"role": "user", "content": "hi!"}]})
```
:::

:::js
```typescript
import { MessagesAnnotation, StateGraph, START, END } from "@langchain/langgraph";

const mockLlm = (state: typeof MessagesAnnotation.State) => {
  return { messages: [{ role: "ai", content: "hello world" }] };
};

const graph = new StateGraph(MessagesAnnotation)
  .addNode("mock_llm", mockLlm)
  .addEdge(START, "mock_llm")
  .addEdge("mock_llm", END)
  .compile();

await graph.invoke({ messages: [{ role: "user", content: "hi!" }] });
```
:::

## 核心优势

LangGraph 为**任何**长期运行、有状态的工作流或智能体提供了低级别的支持性基础架构。LangGraph 不会对提示词（prompts）或架构进行抽象化，而是提供以下核心优势：

* [持久化执行 (Durable execution)](/oss/langgraph/durable-execution)：构建能够抵御故障并可长时间运行的智能体，使其可以从中断的位置恢复执行。
* [人机协作 (Human-in-the-loop)](/oss/langgraph/interrupts)：通过在任何时间点检查和修改智能体的状态，纳入人工监督。
* [全面的内存管理 (Comprehensive memory)](/oss/concepts/memory)：创建有状态的智能体，同时拥有用于持续推理的短期工作记忆和跨会话的长期记忆。
* [使用 LangSmith 进行调试 (Debugging with LangSmith)](/langsmith/home)：通过可视化工具深入了解复杂的智能体行为，这些工具可以跟踪执行路径、捕获状态转换并提供详细的运行时指标。
* [面向生产的部署 (Production-ready deployment)](/langsmith/deployments)：利用专为处理有状态、长期运行的工作流的独特挑战而设计的可扩展基础设施，自信地部署复杂的智能体系统。
