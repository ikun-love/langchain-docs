<Update label="Nov 25, 2025" tags={["langchain"]}>
    ## v1.1.0

    * [模型配置项](/oss/langchain/models#model-profiles)：聊天模型现在通过 `.profile` getter 暴露其支持的功能和能力。这些数据源自 [models.dev](https://models.dev)，这是一个提供模型能力数据的开源项目。
    * [模型重试中间件](/oss/langchain/middleware/built-in#model-retry)：新增中间件，用于自动重试失败的模型调用，并支持可配置的指数退避策略，以提高代理（Agent）的可靠性。
    * [内容适宜性（内容审核）中间件](/oss/langchain/middleware/built-in#content-moderation)：用于检测和处理代理交互中不安全内容的 OpenAI 内容审核中间件。它支持检查用户输入、模型的输出以及工具的调用结果。
    * [摘要中间件](/oss/langchain/middleware/built-in#summarization)：已更新，支持使用模型配置项来灵活设定触发点，以实现上下文感知的摘要功能。
    * [结构化输出](/oss/langchain/structured-output)：现在可以从模型配置项中推断出 `ProviderStrategy` 支持（即原生的结构化输出能力）。
    * [`createAgent` 的 `SystemMessage`](/oss/langchain/middleware/custom#working-with-system-messages)：支持将 `SystemMessage` 实例直接传递给 `createAgent` 的 `systemPrompt` 参数，并新增了一个 `concat` 方法用于扩展系统消息。这使得启用缓存控制和结构化内容块等高级功能成为可能。
    * [动态系统提示中间件](/oss/langchain/agents#dynamic-system-prompt)：`dynamicSystemPromptMiddleware` 的返回值现在是纯粹可累加的。当返回一个 @[`SystemMessage`] 或 `string` 时，它将与现有的系统消息合并，而不是替换它们，从而更容易组合修改提示的多个中间件。
    * **兼容性改进**：修复了结构化输出和工具模式中 Zod v4 验证错误的处理逻辑，确保详细的错误信息能够被正确显示。
</Update>
