`PremEmbeddings` 类使用 Prem AI API 为给定的文本生成嵌入（embeddings）。

## 设置 (Setup)

为了使用 Prem API，你需要一个 API 密钥。你可以 [在此处](https://studio.premai.io/sign-up) 注册一个 Prem 账户并创建一个 API 密钥。

你首先需要安装 [`@langchain/community`](https://www.npmjs.com/package/@langchain/community) 包：

<Tip>
有关安装 LangChain 包的一般说明，请参阅[此部分](/oss/langchain/install)。
</Tip>

```bash npm
npm install @langchain/community @langchain/core
```

## 用法 (Usage)

```typescript
import { PremEmbeddings } from "@langchain/community/embeddings/premai";

const embeddings = new PremEmbeddings({
  // 在 Node.js 环境中，默认使用 process.env.PREM_API_KEY
  apiKey: "YOUR-API-KEY",
  // 在 Node.js 环境中，默认使用 process.env.PREM_PROJECT_ID
  project_id: "YOUR-PROJECT_ID",
  model: "@cf/baai/bge-small-en-v1.5", // 用于生成嵌入的模型
});

const res = await embeddings.embedQuery(
  "What would be a good company name a company that makes colorful socks?"
);
console.log({ res });
```
