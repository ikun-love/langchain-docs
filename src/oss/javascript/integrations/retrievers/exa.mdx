## 概述

[Exa](https://exa.ai/) 是一个搜索引擎，它能根据输入的查询检索相关的网页内容。

本指南将帮助您开始使用 Exa [检索器](/oss/langchain/retrieval)。有关 `ExaRetriever` 所有特性和配置的详细文档，请访问 [API 参考](https://api.js.langchain.com/classes/langchain_exa.ExaRetriever.html)。

### 集成详情

| 检索器 | 来源 | 包 |
| :--- | :--- | :---: |
[ExaRetriever](https://api.js.langchain.com/classes/langchain_exa.ExaRetriever.html) | 网页上的信息。 | [`@langchain/exa`](https://www.npmjs.com/package/@langchain/exa) |

## 设置

您需要将 API 密钥设置为环境变量。

`Exa` 类在查找 API 密钥时，默认使用 `EXASEARCH_API_KEY`。

```typescript
process.env.EXASEARCH_API_KEY="<YOUR API KEY>";
```

如果您希望从单个查询中获得自动化的跟踪（tracing）记录，可以取消注释以下内容来设置您的 [LangSmith](https://docs.langchain.com/langsmith/home) API 密钥：

```typescript
// process.env.LANGSMITH_API_KEY = "<YOUR API KEY HERE>";
// process.env.LANGSMITH_TRACING = "true";
```

### 安装

此检索器位于 `@langchain/exa` 包中：

<CodeGroup>
```bash npm
npm install @langchain/exa @langchain/core
```
```bash yarn
yarn add @langchain/exa @langchain/core
```
```bash pnpm
pnpm add @langchain/exa @langchain/core
```
</CodeGroup>

## 实例化

现在我们可以实例化我们的检索器：

```typescript
import { ExaRetriever } from "@langchain/exa";
import Exa from "exa-js";

const retriever = new ExaRetriever({
  // @lc-ts-ignore
  client: new Exa(
    process.env.EXASEARCH_API_KEY // 默认 API 密钥
  ),
  searchArgs: {
    numResults: 2,
  }
});
```

## 使用方法

```typescript
const query = "What did the speaker say about Justice Breyer in the 2022 State of the Union?";

await retriever.invoke(query);
```
