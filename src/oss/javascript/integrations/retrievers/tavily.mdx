[Tavily 的搜索 API](https://tavily.com) 是专为 AI 智能体（LLMs）构建的搜索引擎，能够快速、准确地提供实时的、基于事实的搜索结果。

## 概述

本文将指导您入门 Tavily 搜索 API [检索器（retriever）](/oss/langchain/retrieval) 的使用。如需了解 `TavilySearchAPIRetriever` 所有功能和配置的详细文档，请参阅[API 参考](https://api.js.langchain.com/classes/langchain_community_retrievers_tavily_search_api.TavilySearchAPIRetriever.html)。

### 集成详情

| 检索器 | 来源 | 包 |
| :--- | :--- | :---: |
[`TavilySearchAPIRetriever`](https://api.js.langchain.com/classes/langchain_community_retrievers_tavily_search_api.TavilySearchAPIRetriever.html) | 互联网信息 | [`@langchain/community`](https://npmjs.com/@langchain/community/) |

## 设置

您需要将 `TAVILY_API_KEY` 环境变量设置为您的 Tavily API 密钥，或者将其作为 `apiKey` 参数传递给构造函数。您可以在[其官方网站](https://tavily.com/)注册以获取密钥。

如果您想为单独的查询获取自动化的追踪记录，可以取消注释以下代码来设置您的 [LangSmith](https://docs.smith.langchain.com/) API 密钥：

```typescript
// process.env.LANGSMITH_API_KEY = "<YOUR API KEY HERE>";
// process.env.LANGSMITH_TRACING = "true";
```

### 安装

该检索器位于 `@langchain/community` 包中：

<CodeGroup>
```bash npm
npm install @langchain/community @langchain/core
```
```bash yarn
yarn add @langchain/community @langchain/core
```
```bash pnpm
pnpm add @langchain/community @langchain/core
```
</CodeGroup>

## 实例化

现在我们可以实例化检索器：

```typescript
import { TavilySearchAPIRetriever } from "@langchain/community/retrievers/tavily_search_api";

const retriever = new TavilySearchAPIRetriever({
  k: 3,
});
```

有关允许参数的完整列表，请参阅[官方文档](https://docs.tavily.com/docs/tavily-api/rest_api#parameters)。您可以通过 `kwargs` 对象将任何参数传递给 SDK。

## 用法

```typescript
const query = "what is the current weather in SF?";

await retriever.invoke(query);
```
