## 设置

1. 在 Prem AI 上创建一个账户 [此处](https://studio.premai.io/sign-up) 并获取您的 API 密钥。
2. 导出或设置您的 API 密钥。`ChatPrem` 类默认使用 `process.env.PREM_API_KEY`。

```bash
export PREM_API_KEY=your-api-key
```

您可以像下面这样使用 Prem AI 提供的模型：

<Tip>
有关安装 LangChain 包的常规说明，请参阅 [此部分](/oss/langchain/install)。
</Tip>

```bash npm
npm install @langchain/community @langchain/core
```

```typescript
import { ChatPrem } from "@langchain/community/chat_models/premai";
import { HumanMessage } from "@langchain/core/messages";

const model = new ChatPrem({
  // 在 Node.js 环境中，默认读取 process.env.PREM_API_KEY
  apiKey: "YOUR-API-KEY",
  // 在 Node.js 环境中，默认读取 process.env.PREM_PROJECT_ID
  project_id: "YOUR-PROJECT_ID",
});

console.log(await model.invoke([new HumanMessage("Hello there!")]));
```
