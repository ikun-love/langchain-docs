## 设置

要访问 Mistral AI 模型，您需要创建一个 Mistral AI 账户、获取一个 API 密钥，并安装 `@langchain/mistralai` 集成包。

### 凭证 (Credentials)

请[此处](https://console.mistral.ai/) 注册 Mistral AI 账户并生成 API 密钥。完成此操作后，设置 `MISTRAL_API_KEY` 环境变量：

```bash
export MISTRAL_API_KEY="your-api-key"
```

如果您希望对模型调用进行自动跟踪（tracing），可以取消注释以下行来设置您的 [LangSmith](https://docs.smith.langchain.com/) API 密钥：

```bash
# export LANGSMITH_TRACING="true"
# export LANGSMITH_API_KEY="your-api-key"
```

### 安装 (Installation)

LangChain ChatMistralAI 集成位于 `@langchain/mistralai` 包中：

<CodeGroup>
```bash npm
npm install @langchain/mistralai @langchain/core
```
```bash yarn
yarn add @langchain/mistralai @langchain/core
```
```bash pnpm
pnpm add @langchain/mistralai @langchain/core
```
</CodeGroup>

## 实例化

现在我们可以实例化模型对象并生成聊天补全（chat completions）：

```typescript
import { ChatMistralAI } from "@langchain/mistralai"

const llm = new ChatMistralAI({
    model: "mistral-large-latest",
    temperature: 0,
    maxRetries: 2,
    // 其他参数...
})
```

## 调用 (Invocation)

向 Mistral 发送聊天消息时，需要遵循以下几点要求：

- 第一条消息**不能**是 `assistant` (ai) 消息。
- 消息**必须**在 `user` 和 `assistant` (ai) 消息之间交替出现。
- 消息**不能**以 `assistant` (ai) 或 `system` 消息结尾。

```typescript
const aiMsg = await llm.invoke([
    [
        "system",
        "You are a helpful assistant that translates English to French. Translate the user sentence.",
    ],
    ["human", "I love programming."],
])
aiMsg
```

## 工具调用 (Tool calling)

Mistral 的 API 支持对其中一部分模型进行 [工具调用](/oss/langchain/tools)。您可以在 [此页面](https://docs.mistral.ai/capabilities/function_calling/) 查看支持工具调用的模型。

以下示例演示了如何使用它：

```typescript
import { ChatMistralAI } from "@langchain/mistralai";
import { ChatPromptTemplate } from "@langchain/core/prompts";
import * as z from "zod";
import { tool } from "@langchain/core/tools";

const calculatorSchema = z.object({
  operation: z
    .enum(["add", "subtract", "multiply", "divide"])
    .describe("要执行的操作类型。"),
  number1: z.number().describe("要操作的第一个数字。"),
  number2: z.number().describe("要操作的第二个数字。"),
});

const calculatorTool = tool((input) => {
  return JSON.stringify(input);
}, {
  name: "calculator",
  description: "一个简单的计算器工具",
  schema: calculatorSchema,
});

// 将工具绑定到模型
const modelWithTool = new ChatMistralAI({
  model: "mistral-large-latest",
}).bindTools([calculatorTool]);


const calcToolPrompt = ChatPromptTemplate.fromMessages([
  [
    "system",
    "You are a helpful assistant who always needs to use a calculator.",
  ],
  ["human", "{input}"],
]);

// 将提示模板 (prompt)、模型和输出解析器链接在一起
const chainWithCalcTool = calcToolPrompt.pipe(modelWithTool);

const calcToolRes = await chainWithCalcTool.invoke({
  input: "What is 2 + 2?",
});
console.log(calcToolRes.tool_calls);
```

```output
[
  {
    name: 'calculator',
    args: { operation: 'add', number1: 2, number2: 2 },
    type: 'tool_call',
    id: 'DD9diCL1W'
  }
]
```

## 钩子 (Hooks)

Mistral AI 支持针对三个事件的自定义钩子：`beforeRequest` (请求前)、`requestError` (请求错误) 和 `response` (响应)。下面可以看到每种钩子类型的函数签名示例：

```typescript
const beforeRequestHook = (req: Request): Request | void | Promise<Request | void> => {
    // 在 Mistral 处理请求之前运行的代码
};

const requestErrorHook = (err: unknown, req: Request): void | Promise<void> => {
    // 在 Mistral 处理请求过程中发生错误时运行的代码
};

const responseHook = (res: Response, req: Request): void | Promise<void> => {
    // 在 Mistral 发送成功响应之前运行的代码
};
```

要将这些钩子添加到聊天模型中，可以作为参数传递，它们会自动添加：

```typescript
import { ChatMistralAI } from "@langchain/mistralai"

const modelWithHooks = new ChatMistralAI({
    model: "mistral-large-latest",
    temperature: 0,
    maxRetries: 2,
    beforeRequestHooks: [ beforeRequestHook ],
    requestErrorHooks: [ requestErrorHook ],
    responseHooks: [ responseHook ],
    // 其他参数...
});
```

或者在实例化后手动赋值并添加：

```typescript
import { ChatMistralAI } from "@langchain/mistralai"

const model = new ChatMistralAI({
    model: "mistral-large-latest",
    temperature: 0,
    maxRetries: 2,
    // 其他参数...
});

model.beforeRequestHooks = [ ...model.beforeRequestHooks, beforeRequestHook ];
model.requestErrorHooks = [ ...model.requestErrorHooks, requestErrorHook ];
model.responseHooks = [ ...model.responseHooks, responseHook ];

model.addAllHooksToHttpClient();
```

`addAllHooksToHttpClient` 方法会清除所有当前已添加的钩子，然后将整个更新后的钩子列表分配过去，以避免钩子重复。

钩子可以逐个移除，也可以一次性清除模型中的所有钩子。

```typescript
model.removeHookFromHttpClient(beforeRequestHook);

model.removeAllHooksFromHttpClient();
```
