## 设置

[Azure OpenAI](https://azure.microsoft.com/products/ai-services/openai-service/) 是一项云服务，可帮助您使用来自 OpenAI、Meta 等的各种预构建和精选模型，快速开发生成式 AI 体验。

LangChain.js 使用 [OpenAI SDK](https://github.com/openai/openai-node) 中的新 Azure 集成来支持与 [Azure OpenAI](https://azure.microsoft.com/products/ai-services/openai-service/) 的集成。

您可以在[此页面](https://learn.microsoft.com/azure/ai-services/openai/overview)上了解有关 Azure OpenAI 及其与 OpenAI API 差异的更多信息。

### 凭证 (Credentials)

如果您还没有 Azure 帐户，可以[创建一个免费帐户](https://azure.microsoft.com/free/)开始使用。

您还需要部署一个 Azure OpenAI 实例。您可以通过遵循[此指南](https://learn.microsoft.com/azure/ai-services/openai/how-to/create-resource?pivots=web-portal)在 Azure Portal 上部署一个版本。

实例运行后，请确保您拥有实例的名称和密钥。您可以在 Azure Portal 中，在实例的“密钥和终结点”(Keys and Endpoint) 部分找到该密钥。然后，如果您使用的是 Node.js，可以将凭证设置为环境变量：

```bash
AZURE_OPENAI_API_INSTANCE_NAME=<YOUR_INSTANCE_NAME>
AZURE_OPENAI_API_DEPLOYMENT_NAME=<YOUR_DEPLOYMENT_NAME>
AZURE_OPENAI_API_KEY=<YOUR_KEY>
AZURE_OPENAI_API_VERSION="2024-02-01"
```

如果您希望对模型调用进行自动化跟踪，您也可以通过取消注释以下内容来设置您的 [LangSmith](https://docs.smith.langchain.com/) API 密钥：

```bash
# export LANGSMITH_TRACING="true"
# export LANGSMITH_API_KEY="your-api-key"
```

## 实例化

现在我们可以实例化模型对象并生成聊天补全：

```typescript
import { AzureChatOpenAI } from "@langchain/openai"

const llm = new AzureChatOpenAI({
    model: "gpt-4o",
    temperature: 0,
    maxTokens: undefined,
    maxRetries: 2,
    azureOpenAIApiKey: process.env.AZURE_OPENAI_API_KEY, // 在 Node.js 中，默认为 process.env.AZURE_OPENAI_API_KEY
    azureOpenAIApiInstanceName: process.env.AZURE_OPENAI_API_INSTANCE_NAME, // 在 Node.js 中，默认为 process.env.AZURE_OPENAI_API_INSTANCE_NAME
    azureOpenAIApiDeploymentName: process.env.AZURE_OPENAI_API_DEPLOYMENT_NAME, // 在 Node.js 中，默认为 process.env.AZURE_OPENAI_API_DEPLOYMENT_NAME
    azureOpenAIApiVersion: process.env.AZURE_OPENAI_API_VERSION, // 在 Node.js 中，默认为 process.env.AZURE_OPENAI_API_VERSION
})
```

## 使用 Azure 托管标识 (Azure Managed Identity)

如果您正在使用 Azure 托管标识，可以按如下方式配置凭证：

```typescript
import {
  DefaultAzureCredential,
  getBearerTokenProvider,
} from "@azure/identity";
import { AzureChatOpenAI } from "@langchain/openai";

const credentials = new DefaultAzureCredential();
const azureADTokenProvider = getBearerTokenProvider(
  credentials,
  "https://cognitiveservices.azure.com/.default"
);

const llmWithManagedIdentity = new AzureChatOpenAI({
  azureADTokenProvider,
  azureOpenAIApiInstanceName: "<your_instance_name>",
  azureOpenAIApiDeploymentName: "<your_deployment_name>",
  azureOpenAIApiVersion: "<api_version>",
});
```

## 使用不同的域名 (Domain)

如果您的实例托管在不同于默认值 `openai.azure.com` 的域下，您需要使用备用环境变量 `AZURE_OPENAI_BASE_PATH`。
例如，以下是如何连接到域名 `https://westeurope.api.microsoft.com/openai/deployments/{DEPLOYMENT_NAME}`：

```typescript
import { AzureChatOpenAI } from "@langchain/openai";

const llmWithDifferentDomain = new AzureChatOpenAI({
  temperature: 0.9,
  azureOpenAIApiKey: "<your_key>", // 在 Node.js 中，默认为 process.env.AZURE_OPENAI_API_KEY
  azureOpenAIApiDeploymentName: "<your_deployment_name>", // 在 Node.js 中，默认为 process.env.AZURE_OPENAI_API_DEPLOYMENT_NAME
  azureOpenAIApiVersion: "<api_version>", // 在 Node.js 中，默认为 process.env.AZURE_OPENAI_API_VERSION
  azureOpenAIBasePath:
    "https://westeurope.api.microsoft.com/openai/deployments", // 在 Node.js 中，默认为 process.env.AZURE_OPENAI_BASE_PATH
});

```

## 自定义标头 (Custom headers)

您可以通过传入一个 `configuration` 字段来指定自定义标头：

```typescript
import { AzureChatOpenAI } from "@langchain/openai";

const llmWithCustomHeaders = new AzureChatOpenAI({
  azureOpenAIApiKey: process.env.AZURE_OPENAI_API_KEY, // 在 Node.js 中，默认为 process.env.AZURE_OPENAI_API_KEY
  azureOpenAIApiInstanceName: process.env.AZURE_OPENAI_API_INSTANCE_NAME, // 在 Node.js 中，默认为 process.env.AZURE_OPENAI_API_INSTANCE_NAME
  azureOpenAIApiDeploymentName: process.env.AZURE_OPENAI_API_DEPLOYMENT_NAME, // 在 Node.js 中，默认为 process.env.AZURE_OPENAI_API_DEPLOYMENT_NAME
  azureOpenAIApiVersion: process.env.AZURE_OPENAI_API_VERSION, // 在 Node.js 中，默认为 process.env.AZURE_OPENAI_API_VERSION
  configuration: {
    defaultHeaders: {
      "x-custom-header": `SOME_VALUE`,
    },
  },
});

await llmWithCustomHeaders.invoke("Hi there!");
```

`configuration` 字段还接受官方 SDK 所接受的其他 `ClientOptions` 参数。

**注意：** 具体的 `api-key` 标头目前无法以这种方式覆盖，它将传递 `azureOpenAIApiKey` 中的值。

## 从 Azure OpenAI SDK 迁移

如果您正在使用已弃用的 Azure OpenAI SDK 及其 `@langchain/azure-openai` 包，可以按照以下步骤将代码更新为使用新的 Azure 集成：

1. 安装新的 `@langchain/openai` 包并移除旧的 `@langchain/azure-openai` 包：

<CodeGroup>
```bash npm
npm install @langchain/openai
```
```bash yarn
yarn add @langchain/openai
```
```bash pnpm
pnpm add @langchain/openai
```
</CodeGroup>

```bash
npm uninstall @langchain/azure-openai
```

2. 将您的导入更新为使用 `@langchain/openai` 包中的新 `@[`AzureChatOpenAI`]` 类：

   ```typescript
   import { AzureChatOpenAI } from "@langchain/openai";
   ```

3. 更新您的代码以使用新的 `@[`AzureChatOpenAI`]` 类并传递所需的参数：

   ```typescript
   const model = new AzureChatOpenAI({
     azureOpenAIApiKey: "<your_key>",
     azureOpenAIApiInstanceName: "<your_instance_name>",
     azureOpenAIApiDeploymentName: "<your_deployment_name>",
     azureOpenAIApiVersion: "<api_version>",
   });
   ```

   请注意，构造函数现在需要 `azureOpenAIApiInstanceName` 参数，而不是 `azureOpenAIEndpoint` 参数，并且添加了 `azureOpenAIApiVersion` 参数来指定 API 版本。

   - 如果您过去使用的是 Azure 托管标识，现在您需要向构造函数使用 `azureADTokenProvider` 参数，而不是 `credentials` 参数。有关更多详细信息，请参阅[Azure 托管标识](#using-azure-managed-identity)部分。

   - 如果您过去使用的是环境变量，现在您需要设置 `AZURE_OPENAI_API_INSTANCE_NAME` 环境变量而不是 `AZURE_OPENAI_API_ENDPOINT`，并添加 `AZURE_OPENAI_API_VERSION` 环境变量来指定 API 版本。
