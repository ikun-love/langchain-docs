</Warning>

LangChain 提供了一个实验性的封装器，用于通过 [Ollama](https://github.com/jmorganca/ollama) 在本地运行的开源模型，使其拥有与 OpenAI Functions 相同的 API。

请注意，功能更强大、能力更强的模型在处理复杂的 Schema 和/或多个函数时表现会更好。以下示例使用了 [Mistral](https://ollama.ai/library/mistral)。

<Warning>
**这是一个实验性的封装器，它试图为那些不原生支持函数调用的模型添加工具调用支持。请谨慎使用。**


</Warning>

## 设置

请遵循 [这些说明](https://github.com/jmorganca/ollama) 来设置并运行本地 Ollama 实例。

## 初始化模型

您可以通过与初始化标准 `ChatOllama` 实例相同的方式来初始化此封装器：

```typescript
import { OllamaFunctions } from "@langchain/community/experimental/chat_models/ollama_functions";

const model = new OllamaFunctions({
  temperature: 0.1,
  model: "mistral",
});
```

## 传入函数

您现在可以像使用 OpenAI 一样传入函数了：

```typescript
import { ChatOllama } from "@langchain/ollama";
import { HumanMessage } from "@langchain/core/messages";

const model = new ChatOllama({
  temperature: 0.1,
  model: "mistral",
})
  .bindTools([
    {
      name: "get_current_weather",
      description: "获取指定地点的当前天气",
      parameters: {
        type: "object",
        properties: {
          location: {
            type: "string",
            description: "城市和州，例如 San Francisco, CA",
          },
          unit: { type: "string", enum: ["celsius", "fahrenheit"] },
        },
        required: ["location"],
      },
    },
  ])
  .withConfig({
    // 您可以设置 `tool_choice` 参数来强制模型使用某个函数
    tool_choice: "get_current_weather",
  });

const response = await model.invoke([
  new HumanMessage({
    content: "Boston 的天气怎么样？",
  }),
]);

console.log(response);

/*
  AIMessage {
    content: '',
    additional_kwargs: {
      function_call: {
        name: 'get_current_weather',
        arguments: '{"location":"Boston, MA","unit":"fahrenheit"}'
      }
    }
  }
*/
```

## 用于提取

```typescript
import * as z from "zod";

import { ChatOllama } from "@langchain/ollama";
import { PromptTemplate } from "@langchain/core/prompts";
import { JsonOutputFunctionsParser } from "@langchain/core/output_parsers/openai_functions";

const EXTRACTION_TEMPLATE = `从以下段落中提取并保存相关的实体及其属性。

段落:
{input}
`;

const prompt = PromptTemplate.fromTemplate(EXTRACTION_TEMPLATE);

// 使用 Zod 更容易声明 Schema
const schema = z.object({
  people: z.array(
    z.object({
      name: z.string().describe("人的名字"),
      height: z.number().describe("人的身高"),
      hairColor: z.optional(z.string()).describe("人的发色"),
    })
  ),
});

const model = new ChatOllama({
  temperature: 0.1,
  model: "mistral",
})
  .bindTools([
    {
      name: "information_extraction",
      description: "从段落中提取相关信息。",
      schema,
    },
  ])
  .withConfig({
    tool_choice: "information_extraction",
  });

// 使用 JsonOutputFunctionsParser 直接获取解析后的 JSON 响应。
const chain = prompt.pipe(model).pipe(new JsonOutputFunctionsParser());

const response = await chain.invoke({
  input:
    "Alex 身高 5 英尺。Claudia 比 Alex 高 1 英尺，跳得比他高。Claudia 是橙色头发，Alex 是金色头发。",
});

console.log(JSON.stringify(response, null, 2));

/*
{
  "people": [
    {
      "name": "Alex",
      "height": 5,
      "hairColor": "blonde"
    },
    {
      "name": "Claudia",
      "height": {
        "$num": 1,
        "add": [
          {
            "name": "Alex",
            "prop": "height"
          }
        ]
      },
      "hairColor": "orange"
    }
  ]
}
*/
```

## 自定义

在底层，这使用 Ollama 的 JSON 模式来限制输出为 JSON，然后将工具 Schema 作为 JSON Schema 传递到提示 (prompt) 中。

由于不同的模型有不同的优势，传入自定义的系统提示可能会很有帮助。这是一个示例：

```typescript
import { ChatOllama } from "@langchain/ollama";
import { HumanMessage, SystemMessage } from "@langchain/core/messages";

// 用于格式化工具的自定义系统提示。您必须鼓励模型
// 使用包含 "tool" 和 "tool_input" 属性的 JSON 对象来包装输出。
const toolSystemPromptTemplate = `您可以使用以下工具:

{tools}

要使用工具，请以以下结构的 JSON 对象进行响应:
{{
  "tool": <调用的工具名称>,
  "tool_input": <与上述 JSON Schema 匹配的工具参数>
}}`;

const model = new ChatOllama({
  temperature: 0.1,
  model: "mistral",
})
  .bindTools([
    {
      name: "get_current_weather",
      description: "获取指定地点的当前天气",
      parameters: {
        type: "object",
        properties: {
          location: {
            type: "string",
            description: "城市和州，例如 San Francisco, CA",
          },
          unit: { type: "string", enum: ["celsius", "fahrenheit"] },
        },
        required: ["location"],
      },
    },
  ])
  .withConfig({
    // 您可以设置 `tool_choice` 参数来强制模型使用某个函数
    tool_choice: "get_current_weather",
  });

const response = await model.invoke([
  new SystemMessage(toolSystemPromptTemplate),
  new HumanMessage({
    content: "Boston 的天气怎么样？",
  }),
]);

console.log(response);

/*
  AIMessage {
    content: '',
    additional_kwargs: {
      function_call: {
        name: 'get_current_weather',
        arguments: '{"location":"Boston, MA","unit":"fahrenheit"}'
      }
    }
  }
*/
```
