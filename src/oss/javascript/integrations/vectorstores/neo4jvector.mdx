title: Neo4j 向量索引
---

Neo4j 是一个开源的图数据库，集成了对向量相似性搜索的支持。
它支持：

- 近似最近邻搜索（approximate nearest neighbor search）
- 欧几里得相似度和余弦相似度（Euclidean similarity and cosine similarity）
- 结合向量和关键词搜索的混合搜索（Hybrid search）

## 设置 (Setup)

要使用 Neo4j 向量索引（Neo4j Vector Index），你需要安装 `neo4j-driver` 包：

```bash npm
npm install neo4j-driver
```
<Tip>
有关安装 LangChain 包的通用说明，请参阅[本节](/oss/langchain/install)。
</Tip>

```bash npm
npm install @langchain/openai @langchain/community @langchain/core
```

### 使用 `docker-compose` 设置自托管 `Neo4j` 实例

`Neo4j` 提供了一个预构建的 Docker 镜像，可用于快速设置自托管的 Neo4j 数据库实例。
创建一个名为 `docker-compose.yml` 的文件如下：

```yml docker-compose.yml
services:
  database:
    image: neo4j
    ports:
      - 7687:7687
      - 7474:7474
    environment:
      - NEO4J_AUTH=neo4j/pleaseletmein
```

然后在同一目录下，运行 `docker compose up` 来启动容器。

你可以在其 [网站](https://neo4j.com/docs/operations-manual/current/installation/) 上找到更多关于如何设置 `Neo4j` 的信息。

## 用法 (Usage)

```typescript
import { OpenAIEmbeddings } from "@langchain/openai";
import { Neo4jVectorStore } from "@langchain/community/vectorstores/neo4j_vector";

// Neo4j 连接和其他相关设置的配置对象
const config = {
  url: "bolt://localhost:7687", // Neo4j 实例的 URL
  username: "neo4j", // 用于 Neo4j 认证的用户名
  password: "pleaseletmein", // 用于 Neo4j 认证的密码
  indexName: "vector", // 向量索引的名称
  keywordIndexName: "keyword", // 如果使用混合搜索，关键词索引的名称
  searchType: "vector" as const, // 搜索类型（例如：vector, hybrid）
  nodeLabel: "Chunk", // 图中节点的标签
  textNodeProperty: "text", // 包含文本的节点属性
  embeddingNodeProperty: "embedding", // 包含嵌入向量的节点属性
};

const documents = [
  { pageContent: "what's this", metadata: { a: 2 } },
  { pageContent: "Cat drinks milk", metadata: { a: 1 } },
];

const neo4jVectorIndex = await Neo4jVectorStore.fromDocuments(
  documents,
  new OpenAIEmbeddings(),
  config
);

const results = await neo4jVectorIndex.similaritySearch("water", 1);

console.log(results);

/*
  [ Document { pageContent: 'Cat drinks milk', metadata: { a: 1 } } ]
*/

await neo4jVectorIndex.close();
```

### 使用 `retrievalQuery` 参数自定义响应

```typescript
import { OpenAIEmbeddings } from "@langchain/openai";
import { Neo4jVectorStore } from "@langchain/community/vectorstores/neo4j_vector";

/*
 * retrievalQuery 是一个可自定义的 Cypher 查询片段，用于在 Neo4jVectorStore 类中定义如何从 Neo4j 数据库中检索和呈现搜索结果。它允许开发人员指定相似性搜索后返回数据的格式和结构。
 * retrievalQuery 的必需列：
 *
 * 1. text:
 *    - 描述：表示节点的文本内容。
 *    - 类型：String
 *
 * 2. score:
 *    - 描述：表示节点相对于搜索查询的相似性得分。得分越高，匹配度越接近。
 *    - 类型：Float（范围在 0 到 1 之间，1 表示完全匹配）
 *
 * 3. metadata:
 *    - 描述：包含有关节点的附加属性和信息。它可以包括节点可能相关的任何其他属性。
 *    - 类型：Object（键值对）
 *    - 示例：{ "id": "12345", "category": "Books", "author": "John Doe" }
 *
 * 注意：虽然你可以自定义 `retrievalQuery` 以获取额外的列或执行转换，但绝对不要遗漏必需的列。这些列名（`text`、`score` 和 `metadata`）应保持一致。重命名它们可能会导致错误或意外行为。
 */

// Neo4j 连接和其他相关设置的配置对象
const config = {
  url: "bolt://localhost:7687", // Neo4j 实例的 URL
  username: "neo4j", // 用于 Neo4j 认证的用户名
  password: "pleaseletmein", // 用于 Neo4j 认证的密码
  retrievalQuery: `
    RETURN node.text AS text, score, {a: node.a * 2} AS metadata
  `,
};

const documents = [
  { pageContent: "what's this", metadata: { a: 2 } },
  { pageContent: "Cat drinks milk", metadata: { a: 1 } },
];

const neo4jVectorIndex = await Neo4jVectorStore.fromDocuments(
  documents,
  new OpenAIEmbeddings(),
  config
);

const results = await neo4jVectorIndex.similaritySearch("water", 1);

console.log(results);

/*
  [ Document { pageContent: 'Cat drinks milk', metadata: { a: 2 } } ]
*/

await neo4jVectorIndex.close();
```

### 从现有图实例化 Neo4jVectorStore

```typescript
import { OpenAIEmbeddings } from "@langchain/openai";
import { Neo4jVectorStore } from "@langchain/community/vectorstores/neo4j_vector";

/**
 * `fromExistingGraph` 方法：
 *
 * 描述：
 * 此方法使用 Neo4j 数据库中已存在的图来初始化 `Neo4jVectorStore` 实例。
 * 它旨在与已经具有文本属性但可能缺少嵌入向量的节点一起工作。该方法将为缺少嵌入的节点计算并存储嵌入向量。
 *
 * 注意：
 * 当你有一个包含文本数据的预先存在的图，并希望通过向量嵌入来增强它以进行相似性搜索，同时又不更改原始数据结构时，此方法特别有用。
 */

// Neo4j 连接和其他相关设置的配置对象
const config = {
  url: "bolt://localhost:7687", // Neo4j 实例的 URL
  username: "neo4j", // 用于 Neo4j 认证的用户名
  password: "pleaseletmein", // 用于 Neo4j 认证的密码
  indexName: "wikipedia",
  nodeLabel: "Wikipedia",
  textNodeProperties: ["title", "description"],
  embeddingNodeProperty: "embedding",
  searchType: "hybrid" as const,
};

// 你应该有一个已填充数据的 Neo4j 数据库才能使用此方法
const neo4jVectorIndex = await Neo4jVectorStore.fromExistingGraph(
  new OpenAIEmbeddings(),
  config
);

await neo4jVectorIndex.close();
```

### 元数据过滤 (Metadata filtering)

```typescript
import { OpenAIEmbeddings } from "@langchain/openai";
import { Neo4jVectorStore } from "@langchain/community/vectorstores/neo4j_vector";

/**
 * `similaritySearch` 方法与元数据过滤：
 *
 * 描述：
 * 此方法便于在 Neo4j 向量索引中进行高级相似性搜索，它利用文本嵌入和元数据属性。
 * 第三个参数 `filter` 允许指定基于元数据的条件，以便在执行相似性搜索之前预先过滤节点。
 * 这种方法通过允许用户在进行相似性搜索的同时，根据复杂的元数据条件进行查询，从而提高了搜索的精度。
 * 元数据过滤还支持以下运算符：
 *
 *  $eq: 等于 (Equal)
 *  $ne: 不等于 (Not Equal)
 *  $lt: 小于 (Less than)
 *  $lte: 小于或等于 (Less than or equal)
 *  $gt: 大于 (Greater than)
 *  $gte: 大于或等于 (Greater than or equal)
 *  $in: 包含在值列表中 (In a list of values)
 *  $nin: 不在值列表中 (Not in a list of values)
 *  $between: 介于两个值之间 (Between two values)
 *  $like: 文本包含指定值 (Text contains value)
 *  $ilike: 小写文本包含指定值 (lowered text contains value)
 *
 * 过滤器支持一系列查询操作，例如相等性检查、范围查询和复合条件（使用逻辑运算符如 $and, $or）。
 * 这使得它高度适应需要基于内容和上下文信息进行详细和特定检索的各种用例。
 *
 * 注意：
 * 有效使用此方法需要结构良好的 Neo4j 数据库，其中节点应同时包含文本和元数据属性。
 * 当文本分析与详细的元数据查询相结合至关重要时，此方法特别有用，例如在内容推荐系统、详细的档案搜索或任何需要上下文相关性的应用程序中。
 */

// Neo4j 连接和其他相关设置的配置对象
const config = {
  url: "bolt://localhost:7687", // Neo4j 实例的 URL
  username: "neo4j", // 用于 Neo4j 认证的用户名
  password: "pleaseletmein", // 用于 Neo4j 认证的密码
  indexName: "vector", // 向量索引的名称
  keywordIndexName: "keyword", // 如果使用混合搜索，关键词索引的名称
  searchType: "vector" as const, // 搜索类型（例如：vector, hybrid）
  nodeLabel: "Chunk", // 图中节点的标签
  textNodeProperty: "text", // 包含文本的节点属性
  embeddingNodeProperty: "embedding", // 包含嵌入向量的节点属性
};

const documents = [
  { pageContent: "what's this", metadata: { a: 2 } },
  { pageContent: "Cat drinks milk", metadata: { a: 1 } },
];

const neo4jVectorIndex = await Neo4jVectorStore.fromDocuments(
  documents,
  new OpenAIEmbeddings(),
  config
);

const filter = { a: { $eq: 1 } };
const results = await neo4jVectorIndex.similaritySearch("water", 1, { filter });

console.log(results);

/*
  [ Document { pageContent: 'Cat drinks milk', metadata: { a: 1 } } ]
*/

await neo4jVectorIndex.close();
```
