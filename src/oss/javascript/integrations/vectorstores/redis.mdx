[Redis](https://redis.io/) 是一款快速的开源内存数据存储。作为 [Redis Stack](https://redis.io/docs/latest/operate/oss_and_stack/install/install-stack/) 的一部分，[RediSearch](https://redis.io/docs/latest/develop/interact/search-and-query/) 是实现向量相似性语义搜索以及其他多种搜索类型的模块。

本指南快速概述了如何入门 Redis [向量存储](/oss/integrations/vectorstores)。如需了解 `RedisVectorStore` 所有特性和配置的详细文档，请访问 [API 参考](https://api.js.langchain.com/classes/langchain_redis.RedisVectorStore.html)。

## 设置

要使用 Redis 向量存储，您需要设置一个 Redis 实例并安装 `@langchain/redis` 集成包。您也可以安装 [`node-redis`](https://github.com/redis/node-redis) 包，以便使用特定的客户端实例来初始化向量存储。

本指南还将使用 [OpenAI 嵌入模型](/oss/integrations/text_embedding/openai)，这要求您安装 `@langchain/openai` 集成包。如果您愿意，也可以使用 [其他受支持的嵌入模型](/oss/integrations/text_embedding)。

<CodeGroup>
```bash npm
npm install @langchain/redis @langchain/core redis @langchain/openai
```
```bash yarn
yarn add @langchain/redis @langchain/core redis @langchain/openai
```
```bash pnpm
pnpm add @langchain/redis @langchain/core redis @langchain/openai
```
</CodeGroup>

您可以通过遵循 [这些说明](https://redis.io/docs/latest/operate/oss_and_stack/install/install-stack/docker/#redisredis-stack) 使用 Docker 在本地设置 Redis 实例。

### 凭证

设置实例后，请设置 `REDIS_URL` 环境变量：

```typescript
process.env.REDIS_URL = "your-redis-url";
```

如果本指南中使用 OpenAI 嵌入模型，您还需要设置您的 OpenAI 密钥：

```typescript
process.env.OPENAI_API_KEY = "YOUR_API_KEY";
```

如果您希望对模型的调用进行自动跟踪，您还可以通过取消注释以下内容来设置您的 [LangSmith](https://docs.langchain.com/langsmith/home) API 密钥：

```typescript
// process.env.LANGSMITH_TRACING="true"
// process.env.LANGSMITH_API_KEY="your-api-key"
```

## 实例化

```typescript
import { RedisVectorStore } from "@langchain/redis";
import { OpenAIEmbeddings } from "@langchain/openai";

import { createClient } from "redis";

const embeddings = new OpenAIEmbeddings({
  model: "text-embedding-3-small",
});

const client = createClient({
  url: process.env.REDIS_URL ?? "redis://localhost:6379",
});
await client.connect();

const vectorStore = new RedisVectorStore(embeddings, {
  redisClient: client,
  indexName: "langchainjs-testing",
});
```

## 管理向量存储

### 向向量存储添加条目

```typescript
import type { Document } from "@langchain/core/documents";

const document1: Document = {
  pageContent: "The powerhouse of the cell is the mitochondria",
  metadata: { type: "example" },
};

const document2: Document = {
  pageContent: "Buildings are made out of brick",
  metadata: { type: "example" },
};

const document3: Document = {
  pageContent: "Mitochondria are made out of lipids",
  metadata: { type: "example" },
};

const document4: Document = {
  pageContent: "The 2024 Olympics are in Paris",
  metadata: { type: "example" },
};

const documents = [document1, document2, document3, document4];

await vectorStore.addDocuments(documents);
```

目前不支持顶级文档 ID，但您可以通过直接向向量存储提供 ID 来删除文档。

## 查询向量存储

一旦创建了向量存储并将相关文档添加进去，您很有可能希望在链或代理运行时查询它。

### 直接查询

可以通过以下方式执行简单的相似性搜索：

```typescript
const similaritySearchResults = await vectorStore.similaritySearch(
  "biology",
  2
);

for (const doc of similaritySearchResults) {
  console.log(`* ${doc.pageContent} [${JSON.stringify(doc.metadata, null)}]`);
}
```

过滤目前会查找包含所提供字符串的任何元数据键。

如果您想执行相似性搜索并接收相应的分数，可以运行：

```typescript
const similaritySearchWithScoreResults =
  await vectorStore.similaritySearchWithScore("biology", 2);

for (const [doc, score] of similaritySearchWithScoreResults) {
  console.log(
    `* [SIM=${score.toFixed(3)}] ${doc.pageContent} [${JSON.stringify(
      doc.metadata
    )}]`
  );
}
```

```output
* [SIM=0.835] The powerhouse of the cell is the mitochondria [{"type":"example"}]
* [SIM=0.852] Mitochondria are made out of lipids [{"type":"example"}]
```

### 通过转换为检索器查询

您也可以将向量存储转换为 [检索器](/oss/langchain/retrieval)，以便在链中使用更方便。

```typescript
const retriever = vectorStore.asRetriever({
  k: 2,
});
await retriever.invoke("biology");
```

```output
[
  Document {
    pageContent: 'The powerhouse of the cell is the mitochondria',
    metadata: { type: 'example' },
    id: undefined
  },
  Document {
    pageContent: 'Mitochondria are made out of lipids',
    metadata: { type: 'example' },
    id: undefined
  }
]
```

## 删除文档

您可以通过两种方式从向量存储中删除文档：

### 删除所有文档

您可以使用以下命令删除整个索引及其所有文档：

```typescript
await vectorStore.delete({ deleteAll: true });
```

### 按 ID 删除特定文档

您也可以通过提供其 ID 来删除特定文档。请注意，配置的键前缀会自动添加到您提供的 ID 上：

```typescript
// 键前缀将自动添加到每个 ID 上
await vectorStore.delete({ ids: ["doc1", "doc2", "doc3"] });
```

## 关闭连接

完成工作后，请务必关闭客户端连接，以避免资源过度消耗：

```typescript
await client.disconnect();
```

## 高级功能

### 自定义 Schema 和元数据过滤

Redis 向量存储支持元数据字段的自定义 Schema 定义，从而实现更高效的过滤和搜索。此功能允许您为元数据定义特定的字段类型和验证规则。

#### 定义自定义 Schema

在创建向量存储时，您可以定义一个自定义 Schema，以指定字段类型、验证规则和索引选项：

```typescript
import { RedisVectorStore } from "@langchain/redis";
import { OpenAIEmbeddings } from "@langchain/openai";
import { SchemaFieldTypes } from "redis";
import { createClient } from "redis";

const embeddings = new OpenAIEmbeddings({
  model: "text-embedding-3-small",
});

const client = createClient({
  url: process.env.REDIS_URL ?? "redis://localhost:6379",
});
await client.connect();

// 为元数据字段定义自定义 Schema
const customSchema:RedisVectorStoreConfig["customSchema"] = {
  userId: {
    type: SchemaFieldTypes.TEXT,
    required: true,
    SORTABLE: true,
  },
  category: {
    type: SchemaFieldTypes.TAG,
    SORTABLE: true,
    SEPARATOR: ",",
  },
  score: {
    type: SchemaFieldTypes.NUMERIC,
    SORTABLE: true,
  },
  tags: {
    type: SchemaFieldTypes.TAG,
    SEPARATOR: ",",
    CASESENSITIVE: true,
  },
  description: {
    type: SchemaFieldTypes.TEXT,
    NOSTEM: true,
    WEIGHT: 2.0,
  },
};

const vectorStoreWithSchema = new RedisVectorStore(embeddings, {
  redisClient: client,
  indexName: "langchainjs-custom-schema",
  customSchema,
});
```

#### Schema 字段类型

自定义 Schema 支持三种主要字段类型：

- **TEXT**: 支持全文搜索的字段，可选配词干提取、加权和排序功能
- **TAG**: 用于精确匹配的分类字段，支持多值和自定义分隔符
- **NUMERIC**: 支持范围查询和排序的数值字段

#### 字段配置选项

每个字段都可以配置各种选项：

- `required`: 字段是否必须存在于元数据中（默认：false）
- `SORTABLE`: 是否启用该字段的排序功能（默认：undefined）
- `SEPARATOR`: 对于 TAG 字段，指定多个值的分隔符（默认：","）
- `CASESENSITIVE`: 对于 TAG 字段，启用区分大小写的匹配（Redis 要求 `true`，而不是布尔值）
- `NOSTEM`: 对于 TEXT 字段，禁用词干提取（Redis 要求 `true`，而不是布尔值）
- `WEIGHT`: 对于 TEXT 字段，指定搜索权重（默认：1.0）

#### 使用 Schema 验证添加文档

使用自定义 Schema 时，文档会根据定义的 Schema 进行自动验证：

```typescript
import type { Document } from "@langchain/core/documents";

const documentsWithMetadata: Document[] = [
  {
    pageContent: "Advanced JavaScript techniques for modern web development",
    metadata: {
      userId: "user123",
      category: "programming",
      score: 95,
      tags: ["javascript", "web-development", "frontend"],
      description: "Comprehensive guide to JavaScript best practices",
    },
  },
  {
    pageContent: "Machine learning fundamentals and applications",
    metadata: {
      userId: "user456",
      category: "ai",
      score: 88,
      tags: ["machine-learning", "python", "data-science"],
      description: "Introduction to ML concepts and practical applications",
    },
  },
  {
    pageContent: "Database optimization strategies for high performance",
    metadata: {
      userId: "user789",
      category: "database",
      score: 92,
      tags: ["database", "optimization", "performance"],
      description: "Advanced techniques for database performance tuning",
    },
  },
];

// 这将根据自定义 Schema 验证每个文档的元数据
await vectorStoreWithSchema.addDocuments(documentsWithMetadata);
```

#### 使用元数据过滤的高级相似性搜索

自定义 Schema 使得使用 `similaritySearchVectorWithScoreAndMetadata` 方法进行强大的元数据过滤成为可能：

```typescript
// 使用 TAG 过滤进行搜索
const tagFilterResults =
  await vectorStoreWithSchema.similaritySearchVectorWithScoreAndMetadata(
    await embeddings.embedQuery("programming tutorial"),
    3,
    {
      category: "programming", // 精确的标签匹配
      tags: ["javascript", "frontend"], // 多个标签的 OR 搜索
    }
  );

console.log("Tag filter results:");
for (const [doc, score] of tagFilterResults) {
  console.log(`* [SIM=${score.toFixed(3)}] ${doc.pageContent}`);
  console.log(`  Metadata: ${JSON.stringify(doc.metadata)}`);
}
```

```typescript
// 使用 NUMERIC 范围过滤进行搜索
const numericFilterResults =
  await vectorStoreWithSchema.similaritySearchVectorWithScoreAndMetadata(
    await embeddings.embedQuery("high quality content"),
    5,
    {
      score: { min: 90, max: 100 }, // 分数在 90 到 100 之间
      category: ["programming", "ai"], // 多个类别
    }
  );

console.log("Numeric filter results:");
for (const [doc, score] of numericFilterResults) {
  console.log(`* [SIM=${score.toFixed(3)}] ${doc.pageContent}`);
  console.log(
    `  Score: ${doc.metadata.score}, Category: ${doc.metadata.category}`
  );
}
```

```typescript
// 使用 TEXT 字段过滤进行搜索
const textFilterResults =
  await vectorStoreWithSchema.similaritySearchVectorWithScoreAndMetadata(
    await embeddings.embedQuery("development guide"),
    3,
    {
      description: "comprehensive guide", // 在 description 字段中搜索文本
      score: { min: 85 }, // 最低分数为 85
    }
  );

console.log("Text filter results:");
for (const [doc, score] of textFilterResults) {
  console.log(`* [SIM=${score.toFixed(3)}] ${doc.pageContent}`);
  console.log(`  Description: ${doc.metadata.description}`);
}
```

#### 数值范围查询选项

对于数值字段，您可以指定各种范围查询：

```typescript
// 精确值匹配
{ score: 95 }

// 带有最小值和最大值的范围
{ score: { min: 80, max: 100 } }

// 仅最小值
{ score: { min: 90 } }

// 仅最大值
{ score: { max: 95 } }
```

#### 错误处理和验证

自定义 Schema 提供了带有帮助性错误消息的自动验证：

```typescript
try {
  // 这将因验证失败而失败 - 缺少必需的 userId 字段
  const invalidDoc: Document = {
    pageContent: "Some content without required metadata",
    metadata: {
      category: "test",
      // 缺少必需的 userId 字段
    },
  };

  await vectorStoreWithSchema.addDocuments([invalidDoc]);
} catch (error) {
  console.log("Validation error:", error.message);
  // 输出: "Required metadata field 'userId' is missing"
}

try {
  // 这将因验证失败而失败 - score 字段类型错误
  const wrongTypeDoc: Document = {
    pageContent: "Content with wrong metadata type",
    metadata: {
      userId: "user123",
      score: "not-a-number", // 应该是数字，而不是字符串
    },
  };

  await vectorStoreWithSchema.addDocuments([wrongTypeDoc]);
} catch (error) {
  console.log("Type validation error:", error.message);
  // 输出: "Metadata field 'score' must be a number, got string"
}
```

#### 性能优势

使用自定义 Schema 可带来多项性能优势：

1. **单独索引的元数据字段**: 单独索引各个元数据字段，从而实现快速过滤
2. **类型优化查询**: 数值和标签字段使用优化的查询结构
3. **减少数据传输**: 搜索结果中只返回相关的字段
4. **更好的查询规划**: Redis 可根据字段类型和索引优化查询

#### 向后兼容性

自定义 Schema 功能完全向后兼容。没有自定义 Schema 的现有 Redis 向量存储将继续像以前一样工作。您可以逐步迁移到自定义 Schema 以用于新索引或重建现有索引时使用。
