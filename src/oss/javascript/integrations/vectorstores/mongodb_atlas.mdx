## 设置

要使用 MongoDB Atlas 矢量存储，你需要配置一个 MongoDB Atlas 集群，并安装 `@langchain/mongodb` 集成包。

### 初始集群配置

要创建一个 MongoDB Atlas 集群，请导航到 [MongoDB Atlas 网站](https://www.mongodb.com/products/platform/atlas-database)，如果还没有账户则创建一个。

在提示时创建并命名一个集群，然后在 `Database` (数据库)下找到它。选择 `Browse Collections` (浏览集合)，并创建一个空白集合或使用提供的示例数据中的一个。

**注意**: 创建的集群必须是 MongoDB 7.0 或更高版本。

### 创建索引

配置集群后，你需要在希望进行搜索的集合字段上创建一个索引。

切换到 `Atlas Search` 标签页，并点击 `Create Search Index` (创建搜索索引)。进入后，请确保选择 `Atlas Vector Search - JSON Editor` (Atlas 矢量搜索 - JSON 编辑器)，然后选择适当的数据库和集合，并将以下内容粘贴到文本框中：

```json
{
  "fields": [
    {
      "numDimensions": 1536,
      "path": "embedding",
      "similarity": "euclidean",
      "type": "vector"
    }
  ]
}
```

请注意，`numDimensions` 属性应与你使用的嵌入的维度数相匹配。例如，Cohere 嵌入有 1024 维，而默认的 OpenAI 嵌入有 1536 维：

注意：默认情况下，矢量存储期望的索引名称是 `default`，索引的集合字段名称是 `embedding`，原始文本字段名称是 `text`。你应该使用与你的索引集合模式匹配的字段名称来初始化矢量存储，如下所示。

最后，继续构建索引。

### 嵌入 (Embeddings)

本指南还将使用 [OpenAI 嵌入](/oss/integrations/text_embedding/openai)，这要求你安装 `@langchain/openai` 集成包。如果你愿意，也可以使用 [其他支持的嵌入模型](/oss/integrations/text_embedding)。

### 凭证

完成上述操作后，请从 Mongo 控制台的 `Connect` (连接) 按钮获取 `MONGODB_ATLAS_URI` 环境变量。你还需要你的数据库名称和集合名称：

```typescript
process.env.MONGODB_ATLAS_URI = "your-atlas-url";
process.env.MONGODB_ATLAS_COLLECTION_NAME = "your-atlas-db-name";
process.env.MONGODB_ATLAS_DB_NAME = "your-atlas-db-name";
```

如果你在本指南中使用 OpenAI 嵌入，你也需要设置你的 OpenAI 密钥：

```typescript
process.env.OPENAI_API_KEY = "YOUR_API_KEY";
```

如果你想获得模型调用的自动追踪，你还可以通过取消注释以下行来设置你的 [LangSmith](https://docs.smith.langchain.com/) API 密钥：

```typescript
// process.env.LANGSMITH_TRACING="true"
// process.env.LANGSMITH_API_KEY="your-api-key"
```

## 实例化

如上所示设置了集群后，你可以按如下方式初始化你的矢量存储：

```typescript
import { MongoDBAtlasVectorSearch } from "@langchain/mongodb";
import { OpenAIEmbeddings } from "@langchain/openai";
import { MongoClient } from "mongodb";

const client = new MongoClient(process.env.MONGODB_ATLAS_URI || "");
const collection = client.db(process.env.MONGODB_ATLAS_DB_NAME)
  .collection(process.env.MONGODB_ATLAS_COLLECTION_NAME);

const embeddings = new OpenAIEmbeddings({
  model: "text-embedding-3-small",
});

const vectorStore = new MongoDBAtlasVectorSearch(embeddings, {
  collection: collection,
  indexName: "vector_index", // Atlas 搜索索引的名称。默认为 "default"
  textKey: "text", // 包含原始内容的集合字段的名称。默认为 "text"
  embeddingKey: "embedding", // 包含嵌入文本的集合字段的名称。默认为 "embedding"
});
```

## 管理矢量存储

### 向矢量存储添加条目

你现在可以将文档添加到矢量存储中：

```typescript
import type { Document } from "@langchain/core/documents";

const document1: Document = {
  pageContent: "The powerhouse of the cell is the mitochondria",
  metadata: { source: "https://example.com" }
};

const document2: Document = {
  pageContent: "Buildings are made out of brick",
  metadata: { source: "https://example.com" }
};

const document3: Document = {
  pageContent: "Mitochondria are made out of lipids",
  metadata: { source: "https://example.com" }
};

const document4: Document = {
  pageContent: "The 2024 Olympics are in Paris",
  metadata: { source: "https://example.com" }
}

const documents = [document1, document2, document3, document4];

await vectorStore.addDocuments(documents, { ids: ["1", "2", "3", "4"] });
```

```output
[ '1', '2', '3', '4' ]
```

**注意**: 添加文档后，需要稍等片刻它们才能被查询。

使用与现有文档相同 `id` 添加文档将更新现有文档。

### 从矢量存储删除条目

```typescript
await vectorStore.delete({ ids: ["4"] });
```

## 查询矢量存储

一旦创建了矢量存储并将相关文档添加进去，你最有可能在链或代理运行时对其进行查询。

### 直接查询

可以直接执行简单的相似性搜索：

```typescript
const similaritySearchResults = await vectorStore.similaritySearch("biology", 2);

for (const doc of similaritySearchResults) {
  console.log(`* ${doc.pageContent} [${JSON.stringify(doc.metadata, null)}]`);
}
```

```output
* The powerhouse of the cell is the mitochondria [{"_id":"1","source":"https://example.com"}]
* Mitochondria are made out of lipids [{"_id":"3","source":"https://example.com"}]
```

### 过滤

MongoDB Atlas 支持对其他字段进行结果的预先过滤。它们要求你通过更新最初创建的索引来定义计划过滤的元数据字段。这是一个示例：

```json
{
  "fields": [
    {
      "numDimensions": 1024,
      "path": "embedding",
      "similarity": "euclidean",
      "type": "vector"
    },
    {
      "path": "source",
      "type": "filter"
    }
  ]
}
```

在上面，`fields` 中的第一项是矢量索引，第二项是你希望过滤的元数据属性。属性的名称是 `path` 键的值。因此，上面的索引将允许我们根据名为 `source` 的元数据字段进行搜索。

然后在代码中，你可以使用 [MQL 查询操作符](https://www.mongodb.com/docs/manual/reference/operator/query/) 进行过滤。

下面的示例说明了这一点：

```typescript
const filter = {
  preFilter: {
    source: {
      $eq: "https://example.com",
    },
  },
}

const filteredResults = await vectorStore.similaritySearch("biology", 2, filter);

for (const doc of filteredResults) {
  console.log(`* ${doc.pageContent} [${JSON.stringify(doc.metadata, null)}]`);
}
```

```output
* The powerhouse of the cell is the mitochondria [{"_id":"1","source":"https://example.com"}]
* Mitochondria are made out of lipids [{"_id":"3","source":"https://example.com"}]
```

### 返回分数

如果你想执行相似性搜索并接收相应的分数，可以运行：

```typescript
const similaritySearchWithScoreResults = await vectorStore.similaritySearchWithScore("biology", 2, filter)

for (const [doc, score] of similaritySearchWithScoreResults) {
  console.log(`* [SIM=${score.toFixed(3)}] ${doc.pageContent} [${JSON.stringify(doc.metadata)}]`);
}
```

```output
* [SIM=0.374] The powerhouse of the cell is the mitochondria [{"_id":"1","source":"https://example.com"}]
* [SIM=0.370] Mitochondria are made out of lipids [{"_id":"3","source":"https://example.com"}]
```

### 通过转换为检索器 (Retriever) 进行查询

你也可以将矢量存储转换为 [检索器](/oss/langchain/retrieval) 以便在链中使用：

```typescript
const retriever = vectorStore.asRetriever({
  // 可选的过滤器
  filter: filter,
  k: 2,
});
await retriever.invoke("biology");
```

```output
[
  Document {
    pageContent: 'The powerhouse of the cell is the mitochondria',
    metadata: { _id: '1', source: 'https://example.com' },
    id: undefined
  },
  Document {
    pageContent: 'Mitochondria are made out of lipids',
    metadata: { _id: '3', source: 'https://example.com' },
    id: undefined
  }
]
```
