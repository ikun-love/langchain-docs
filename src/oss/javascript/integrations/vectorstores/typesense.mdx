利用 Typesense 搜索引擎的向量存储。

### 基本用法

<Tip>
请参阅[本节](/oss/langchain/install)获取有关安装 LangChain 包的一般说明。
</Tip>

```bash npm
npm install @langchain/openai @langchain/community @langchain/core
```
```typescript
import {
  Typesense,
  TypesenseConfig,
} from "@lanchain/community/vectorstores/typesense";
import { OpenAIEmbeddings } from "@langchain/openai";
import { Client } from "typesense";
import { Document } from "@langchain/core/documents";

const vectorTypesenseClient = new Client({
  nodes: [
    {
      // 理想情况下应来自您的 .env 文件
      host: "...",
      port: 123,
      protocol: "https",
    },
  ],
  // 理想情况下应来自您的 .env 文件
  apiKey: "...",
  numRetries: 3,
  connectionTimeoutSeconds: 60,
});

const typesenseVectorStoreConfig = {
  // Typesense 客户端
  typesenseClient: vectorTypesenseClient,
  // 用于存储向量的集合（Collection）的名称
  schemaName: "your_schema_name",
  // 可选的、将在 Typesense 中使用的列名称
  columnNames: {
    // "vec" 是 Typesense 中向量列的默认名称，但您可以将其更改为您想要的任何名称
    vector: "vec",
    // "text" 是 Typesense 中文本列的默认名称，但您可以将其更改为您想要的任何名称
    pageContent: "text",
    // 您将保存到 Typesense 模式（Schema）中并在搜索时需要作为元数据检索的列的名称
    metadataColumnNames: ["foo", "bar", "baz"],
  },
  // 可选的搜索参数，在搜索时传递给 Typesense
  searchParams: {
    q: "*",
    filter_by: "foo:[fooo]",
    query_by: "",
  },
  // 如果您想做一些更复杂的事情，可以覆盖默认的 Typesense 导入函数
  // 默认导入函数：
  // async importToTypesense<
  //   T extends Record<string, unknown> = Record<string, unknown>
  // >(data: T[], collectionName: string) {
  //   const chunkSize = 2000;
  //   for (let i = 0; i < data.length; i += chunkSize) {
  //     const chunk = data.slice(i, i + chunkSize);

  //     await this.caller.call(async () => {
  //       await this.client
  //         .collections<T>(collectionName)
  //         .documents()
  //         .import(chunk, { action: "emplace", dirty_values: "drop" });
  //     });
  //   }
  // }
  import: async (data, collectionName) => {
    await vectorTypesenseClient
      .collections(collectionName)
      .documents()
      .import(data, { action: "emplace", dirty_values: "drop" });
  },
} satisfies TypesenseConfig;

/**
 * 根据文档列表创建 Typesense 向量存储。
 * 如果存在具有相同 ID 的文档，文档将被更新（使用默认导入函数时）。
 * @param documents 用于创建向量存储的文档列表
 * @returns Typesense 向量存储实例
 */
const createVectorStoreWithTypesense = async (documents: Document[] = []) =>
  Typesense.fromDocuments(
    documents,
    new OpenAIEmbeddings(),
    typesenseVectorStoreConfig
  );

/**
 * 从现有索引返回一个 Typesense 向量存储实例。
 * @returns Typesense 向量存储实例
 */
const getVectorStoreWithTypesense = async () =>
  new Typesense(new OpenAIEmbeddings(), typesenseVectorStoreConfig);

// 执行相似性搜索
const vectorStore = await getVectorStoreWithTypesense();
const documents = await vectorStore.similaritySearch("hello world");

// 基于元数据和 Typesense 的搜索参数添加过滤器
// 将排除作者为 'JK Rowling' 的文档，因此如果存在 'Joe Rowling' 和 'JK Rowling'，则只会返回 'Joe Rowling'
vectorStore.similaritySearch("Rowling", undefined, {
  filter_by: "author:!=JK Rowling",
});

// 删除文档
vectorStore.deleteDocuments(["document_id_1", "document_id_2"]);
```

### 构造函数 (Constructor)

在开始之前，请在 Typesense 中创建一个模式（Schema），其中包含一个 `id` 字段、一个用于向量的字段以及一个用于文本的字段。根据需要添加任意多的其他字段作为元数据。

- `constructor(embeddings: Embeddings, config: TypesenseConfig)`: 构造 `Typesense` 类的新实例。
  - `embeddings`: 用于嵌入（embedding）文档的 @[`Embeddings`] 类实例。
  - `config`: Typesense 向量存储的配置对象。
    - `typesenseClient`: Typesense 客户端实例。
    - `schemaName`: 用于存储和搜索文档的 Typesense 模式（Schema）的名称。
    - `searchParams` (可选): Typesense 搜索参数。默认值为 `{ q: '*', per_page: 5, query_by: '' }`。
    - `columnNames` (可选): 列名称配置。
      - `vector` (可选): 向量列的名称。默认值为 `'vec'`。
      - `pageContent` (可选): 页面内容列的名称。默认值为 `'text'`。
      - `metadataColumnNames` (可选): 元数据列的名称。默认值为空数组 `[]`。
    - `import` (可选): 替换用于将数据导入 Typesense 的默认导入函数。这可能会影响文档更新的功能。

### 方法 (Methods)

- `async addDocuments(documents: Document[]): Promise<void>`: 将文档添加到向量存储中。如果 ID 相同，文档将被更新。
- `static async fromDocuments(docs: Document[], embeddings: Embeddings, config: TypesenseConfig): Promise<Typesense>`: 根据文档列表创建 Typesense 向量存储实例。在构造过程中，文档会被添加到向量存储中。
- `static async fromTexts(texts: string[], metadatas: object[], embeddings: Embeddings, config: TypesenseConfig): Promise<Typesense>`: 根据文本列表和相关的元数据创建 Typesense 向量存储实例。在构造过程中，文本会被转换为文档并添加到向量存储中。
- `async similaritySearch(query: string, k?: number, filter?: Record<string, unknown>): Promise<Document[]>`: 根据查询搜索相似文档。返回相似文档的数组。
- `async deleteDocuments(documentIds: string[]): Promise<void>`: 根据文档 ID 从向量存储中删除文档。
