[FireCrawl](https://firecrawl.dev) 用于爬取和转换任何网站数据，使其成为 LLM 就绪的数据。它会爬取所有可访问的子页面，并为每个页面提供干净的 Markdown 和元数据，无需提供站点地图 (sitemap)。

FireCrawl 负责处理复杂的任务，例如反向代理、缓存、速率限制以及由 JavaScript 阻止的内容。由 [mendable.ai](https://mendable.ai) 团队构建。

本指南将展示如何使用 LangChain 中的 `FireCrawlLoader` 来抓取和爬取整个网站并加载它们。

## 设置 (Setup)

要访问 `FireCrawlLoader` 文档加载器，您需要安装 `@langchain/community` 集成，以及 `@mendable/firecrawl-js@0.0.36` 包。然后，创建一个 **[FireCrawl](https://firecrawl.dev)** 账户并获取一个 API 密钥。

### 凭证 (Credentials)

注册并获取您的免费 [FireCrawl API 密钥](https://firecrawl.dev) 以开始使用。FireCrawl 提供 300 个免费额度供您入门，如果您想自行托管，它是 [开源的](https://github.com/mendableai/firecrawl)。

完成此操作后，设置 `FIRECRAWL_API_KEY` 环境变量：

```bash
export FIRECRAWL_API_KEY="your-api-key"
```

如果您想对模型的调用进行自动跟踪，您也可以取消注释以下内容来设置您的 [LangSmith](https://docs.smith.langchain.com/) API 密钥：

```bash
# export LANGSMITH_TRACING="true"
# export LANGSMITH_API_KEY="your-api-key"
```

## 实例化 (Instantiation)

下面是如何使用 `FireCrawlLoader` 来加载网页搜索结果的示例：

Firecrawl 提供 3 种模式：`scrape`（抓取）、`crawl`（爬取）和 `map`（映射）。在 `scrape` 模式下，Firecrawl 只会抓取您提供的页面。在 `crawl` 模式下，Firecrawl 将爬取整个网站。在 `map` 模式下，Firecrawl 将返回与网站相关的语义链接。

`formats` 参数（对于 `crawl` 模式为 `scrapeOptions.formats`）允许从 `"markdown"`、`"html"` 或 `"rawHtml"` 中进行选择。但是，加载后的文档将只以一种格式返回内容，优先级如下：`markdown`（首选），其次是 `html`，最后是 `rawHtml`。

现在我们可以实例化我们的模型对象并加载文档了：

```typescript
import "@mendable/firecrawl-js";
import { FireCrawlLoader } from "@langchain/community/document_loaders/web/firecrawl"

const loader = new FireCrawlLoader({
  url: "https://firecrawl.dev", // 要抓取的 URL
  apiKey: "...", // 可选，默认为环境变量中的 `FIRECRAWL_API_KEY`
  mode: "scrape", // 运行爬虫的模式。可以是 "scrape" 用于单个 URL，或 "crawl" 用于所有可访问的子页面
  params: {
    // 基于 Firecrawl API 文档的可选参数
    // 有关 API 文档，请访问 https://docs.firecrawl.dev
  },
})
```
