## 描述

[Browserbase](https://browserbase.com) 是一个开发者平台，用于可靠地运行、管理和监控无头浏览器。

通过以下功能为您的 AI 数据检索提供动力：

- [无服务器基础架构](https://docs.browserbase.com/under-the-hood)：提供可靠的浏览器，用于从复杂的 UI 中提取数据
- [隐秘模式 (Stealth Mode)](https://docs.browserbase.com/features/stealth-mode)：包含指纹采集策略和自动验证码（Captcha）解算功能
- [会话调试器 (Session Debugger)](https://docs.browserbase.com/features/sessions)：通过网络时间线和日志检查您的浏览器会话
- [实时调试 (Live Debug)](https://docs.browserbase.com/guides/session-debug-connection/browser-remote-control)：快速调试您的自动化脚本

## 安装

- 从 [browserbase.com](https://browserbase.com) 获取 API 密钥和项目 ID (Project ID)，并将其设置为环境变量（`BROWSERBASE_API_KEY`, `BROWSERBASE_PROJECT_ID`）。
- 安装 [Browserbase SDK](http://github.com/browserbase/js-sdk)：

```bash npm
npm i @langchain/community @langchain/core @browserbasehq/sdk
```

## 示例

如下所示使用 `BrowserbaseLoader`，以允许您的智能体（Agent）加载网站：

```typescript
import { BrowserbaseLoader } from "@langchain/community/document_loaders/web/browserbase";

const loader = new BrowserbaseLoader(["https://example.com"], {
  textContent: true,
});
const docs = await loader.load();
```

## 参数 (Arguments)

- `urls`: 必需项。需要加载的 URL 列表。

## 选项 (Options)

- `textContent`: 仅检索文本内容。默认为 `false`。
- `sessionId`: 可选项。提供一个已存在的会话 ID。
- `proxy`: 可选项。启用/禁用代理 (Proxy)。
