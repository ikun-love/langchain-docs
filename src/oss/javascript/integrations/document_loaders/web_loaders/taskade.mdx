[Taskade](https://www.taskade.com) 是一个终极工具，集成了 AI 驱动的写作、项目管理和任务自动化功能。Taskade 被设计为您的“第二大脑”，它能简化项目执行过程，并从头到尾增强团队协作。

## 概述

使用 [Taskade](https://www.taskade.com)，您可以构建、训练和部署自己的 AI 代理团队，以实现任务自动化和工作流程的精简。Taskade 无缝融合了创意构思、协作和执行工具——从结构化的列表到现代化的表格和思维导图，所有元素都可以根据您的独特工作流程进行自定义和调整。

```typescript
import { TaskadeProjectLoader } from "@langchain/community/document_loaders/web/taskade";

const loader = new TaskadeProjectLoader({
  personalAccessToken: "TASKADE_PERSONAL_ACCESS_TOKEN", // 或者从 process.env.TASKADE_PERSONAL_ACCESS_TOKEN 加载
  projectId: "projectId",
});
const docs = await loader.load();

console.log({ docs });
```

您可以通过在浏览器中打开项目并从 URL 中提取，找到您的 Taskade 项目 ID：

```
https://www.taskade.com/d/<YOUR PROJECT ID HERE>
```
