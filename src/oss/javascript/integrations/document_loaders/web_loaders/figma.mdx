title: Figma
---

此示例将介绍如何从 Figma 文件加载数据。
要开始使用，您需要一个 Figma 访问令牌（access token）。

```typescript
import { FigmaFileLoader } from "@langchain/community/document_loaders/web/figma";

const loader = new FigmaFileLoader({
  accessToken: "FIGMA_ACCESS_TOKEN", // 或者从 process.env.FIGMA_ACCESS_TOKEN 加载
  nodeIds: ["id1", "id2", "id3"],
  fileKey: "key",
});
const docs = await loader.load();

console.log({ docs });
```

您可以通过在浏览器中打开 Figma 文件并从 URL 中提取信息来找到您的 Figma 文件的 key 和 node ids：

```
https://www.figma.com/file/<YOUR FILE KEY HERE>/LangChainJS-Test?type=whiteboard&node-id=<YOUR NODE ID HERE>&t=e6lqWkKecuYQRyRg-0
```
