## 设置 (Setup)

要访问 Cohere 模型，您需要创建一个 Cohere 账户，获取一个 API 密钥，并安装 `@langchain/cohere` 集成包。

### 凭证 (Credentials)

请访问 [cohere.com](https://cohere.com) 注册 Cohere 并生成 API 密钥。完成此操作后，设置 `COHERE_API_KEY` 环境变量：

```bash
export COHERE_API_KEY="your-api-key"
```

如果您希望对您的模型调用进行自动追踪，您也可以取消注释下方代码以设置您的 [LangSmith](https://docs.smith.langchain.com/) API 密钥：

```bash
# export LANGSMITH_TRACING="true"
# export LANGSMITH_API_KEY="your-api-key"
```

### 安装 (Installation)

LangChain Cohere 集成位于 `@langchain/cohere` 包中：

<CodeGroup>
```bash npm
npm install @langchain/cohere @langchain/core
```
```bash yarn
yarn add @langchain/cohere @langchain/core
```
```bash pnpm
pnpm add @langchain/cohere @langchain/core
```
</CodeGroup>

## 实例化 (Instantiation)

现在我们可以实例化模型对象并生成聊天补全（chat completions）：

```typescript
import { Cohere } from "@langchain/cohere"

const llm = new Cohere({
  model: "command",
  temperature: 0,
  maxTokens: undefined,
  maxRetries: 2,
  // other params...
})
```

### 针对 Azure 上的 Cohere、AWS Bedrock 上的 Cohere 和独立 Cohere 实例的自定义客户端

我们可以实例化一个自定义的 `CohereClient` 并将其传递给 ChatCohere 构造函数。

**注意：** 如果提供了自定义客户端，构造函数参数中的 `apiKey` 和 `COHERE_API_KEY` 环境变量都将被忽略。

```typescript
import { Cohere } from "@langchain/cohere";
import { CohereClient } from "cohere-ai";

const client = new CohereClient({
  token: "<your-api-key>",
  environment: "<your-cohere-deployment-url>", // 可选 (optional)
  // other params
});

const llmWithCustomClient = new Cohere({
  client,
  // other params...
});
```

## 调用 (Invocation)

```typescript
const inputText = "Cohere 是一家 AI 公司，它 "

const completion = await llm.invoke(inputText)
completion
```

```output
Cohere is a company that provides natural language processing models that help companies improve human-machine interactions. Cohere was founded in 2019 by Aidan Gomez, Ivan Zhang, and Nick Frosst.
```
