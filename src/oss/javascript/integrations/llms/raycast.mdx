title: RaycastAI
---

> **注意：** 这是一个社区构建的集成，并未获得 Raycast 的官方支持。

您可以在 [Raycast 环境](https://developers.raycast.com/api-reference/ai) 中利用 LangChain 的 `RaycastAI` 类，从而增强您的 Raycast 扩展，使其具备 LangChain 的能力。

- 截至 2023 年 8 月，`RaycastAI` 类仅在 Raycast 环境中可用，并且仅对 [Raycast Pro](https://www.raycast.com/pro) 用户开放。您可以[点击此处](https://developers.raycast.com/)查看如何为 Raycast 创建扩展。

- 每位 Raycast Pro 用户的请求速率限制约为每分钟 10 次请求。如果超过此限制，您将收到一个错误。如示例所示，您可以通过向 `RaycastAI` 构造函数传递 `rateLimitPerMinute` 参数来设置您期望的每分钟请求限制 (rpm)，因为此速率限制在未来可能会发生变化。

<Tip>
有关安装 LangChain 包的一般说明，请参阅[本节](/oss/langchain/install)。
</Tip>

```bash npm
npm install @langchain/community @langchain/core
```
```ts
import { RaycastAI } from "@langchain/community/llms/raycast";

import { Tool } from "@langchain/core/tools";

const model = new RaycastAI({
  rateLimitPerMinute: 10, // 默认为 10，因此您可以省略此行
  model: "<model_name>",
  creativity: 0, // `creativity` 是 Raycast 使用的术语，等同于某些其他 LLM 中的 `temperature`（温度）
});
```
