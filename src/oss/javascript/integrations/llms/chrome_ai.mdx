ChromeAI 利用 Gemini Nano 技术，直接在浏览器或 [Worker](https://developer.mozilla.org/en-US/docs/Web/API/Worker) 中运行大型语言模型 (LLMs)，完全无需连接互联网。这使得模型运行更快、更私密，因为用户的数据**永远不会离开用户的设备**。

## 开始使用

一旦您获得了该程序的访问权限，请遵循 Google 提供的说明来下载模型。

模型下载完成后，您可以在浏览器中使用 `ChromeAI` 的方法如下：

```typescript
import { ChromeAI } from "@langchain/community/experimental/llms/chrome_ai";

const model = new ChromeAI({
  temperature: 0.5, // 可选，默认为 0.5
  topK: 40, // 可选，默认为 40
});

const response = await model.invoke("Write me a short poem please");

/*
```

### 流式传输 (Streaming)

`ChromeAI` 也支持流式输出：

```typescript
import { ChromeAI } from "@langchain/community/experimental/llms/chrome_ai";

const model = new ChromeAI({
  temperature: 0.5, // 可选，默认为 0.5
  topK: 40, // 可选，默认为 40
});

for await (const chunk of await model.stream("How are you?")) {
  console.log(chunk);
}
```
