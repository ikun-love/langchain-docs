---
title: Web 浏览器工具
---

Web 浏览器工具赋予智能体访问网站并提取信息的能力。它向智能体描述为：

```
在你需要查找网页上的内容或总结网页内容时很有用。输入应为用逗号分隔的列表，格式为 "包含协议的有效 URL","你想在页面上查找的内容或用于总结的空字符串"。
```

它提供两种操作模式：

- 当智能体仅使用 URL 调用它时，它会生成对该网站内容的总结。
- 当智能体使用 URL 和要查找内容的描述来调用它时，它将使用内存中的 Vector Store (向量存储) 来查找最相关的片段并对这些片段进行总结。

## 设置

要使用 Web 浏览器工具，你需要安装依赖项：

```bash npm
npm install cheerio axios
```
## 用法：独立模式

```typescript
import { WebBrowser } from "@langchain/classic/tools/webbrowser";
import { ChatOpenAI, OpenAIEmbeddings } from "@langchain/openai";

export async function run() {
  const model = new ChatOpenAI({ model: "gpt-4o-mini", temperature: 0 });
  const embeddings = new OpenAIEmbeddings();

  const browser = new WebBrowser({ model, embeddings });

  const result = await browser.invoke(
    `"https://www.themarginalian.org/2015/04/09/find-your-bliss-joseph-campbell-power-of-myth","who is joseph campbell"`
  );

  console.log(result);
  /*
  Joseph Campbell 是一位神话学家和作家，他讨论了灵性、心理原型、文化神话和自我神话。他与 Bill Moyers 在加州乔治·卢卡斯的天行者牧场（Skywalker Ranch）进行了长时间的对话，该对话在第二年继续在美国自然历史博物馆进行。由此产生的 24 小时的原始素材被剪辑成六个一小时的剧集，并于 1988 年在 PBS 播出，这正值 Campbell 去世后不久，成为了公共电视历史上最受欢迎的节目之一。

  相关链接：
  - [The Holstee Manifesto](http://holstee.com/manifesto-bp)
  - [The Silent Music of the Mind: Remembering Oliver Sacks](https://www.themarginalian.org/2015/08/31/remembering-oliver-sacks)
  - [Joseph Campbell series](http://billmoyers.com/spotlight/download-joseph-campbell-and-the-power-of-myth-audio/)
  - [Bill Moyers](https://www.themarginalian.org/tag/bill-moyers/)
  - [books](https://www.themarginalian.org/tag/books/)
  */
}
```
