title: Tavily 搜索
---

[Tavily](https://tavily.com/) 是一个专为 AI 代理（LLMs）构建的搜索引擎，能够快速、实时、准确地提供事实性搜索结果。Tavily 提供了两个核心的 API 端点，其中之一便是 Search（搜索），它能为 LLM 和 RAG（检索增强生成）提供定制化的搜索结果。

本指南将快速概述如何开始使用 Tavily 的**工具（Tool）** [工具](/oss/integrations/tools/)。如需了解 Tavily 工具的完整细节，请参阅 [API 参考文档](https://v03.api.js.langchain.com/modules/_langchain_tavily.html)。

## 设置

此集成位于 `@langchain/tavily` 包中，您可以通过以下方式安装：

<CodeGroup>
```bash npm
npm install @langchain/tavily @langchain/core
```
```bash yarn
yarn add @langchain/tavily @langchain/core
```
```bash pnpm
pnpm add @langchain/tavily @langchain/core
```
</CodeGroup>

### 凭证 (Credentials)

请在 [此处](https://app.tavily.com) 设置您的 API 密钥，并将其设置为名为 `TAVILY_API_KEY` 的环境变量。

```typescript
process.env.TAVILY_API_KEY = "YOUR_API_KEY"
```

为了获得最佳的可观测性（Observability），设置 [LangSmith](https://smith.langchain.com/) 也是很有帮助的（但不是必需的）：

```typescript
process.env.LANGSMITH_TRACING="true"
process.env.LANGSMITH_API_KEY="your-api-key"
```

## 实例化

您可以像下面这样导入并实例化 `TavilySearch` 工具的一个实例：

```typescript
import { TavilySearch } from "@langchain/tavily";

const tool = new TavilySearch({
  maxResults: 5,
  topic: "general",
  // includeAnswer: false, // 是否包含答案摘要
  // includeRawContent: false, // 是否包含原始文本内容
  // includeImages: false, // 是否包含图片信息
  // includeImageDescriptions: false, // 是否包含图片描述
  // searchDepth: "basic", // 搜索深度
  // timeRange: "day", // 时间范围
  // includeDomains: [], // 包含的域名
  // excludeDomains: [], // 排除的域名
});
```

## 调用 (Invocation)

### [直接使用参数调用](/oss/langchain/tools)

在调用 Tavily 搜索工具时，它接受以下参数：

* `query` (必需): 一个自然语言的搜索查询。

* 在调用时还可以设置以下参数：`includeImages`, `searchDepth`, `timeRange`, `includeDomains`, `excludeDomains`, `includeImages`。

* 出于可靠性和性能考虑，某些影响响应大小的参数在调用时不能被修改：`includeAnswer` 和 `includeRawContent`。这些限制可以防止意外的上下文窗口问题，并确保结果的一致性。

```typescript
await tool.invoke({
  query: "what is the current weather in SF?" // “旧金山目前天气如何？”
});
```

### [使用 ToolCall 调用](/oss/langchain/tools)

我们也可以使用模型生成的 `ToolCall` 来调用工具，在这种情况下，将返回一个 @[`ToolMessage`]：

```typescript
// 这通常由模型生成，但我们在这里直接创建一个 tool call 用于演示目的。
const modelGeneratedToolCall = {
  args: {
    query: "what is the current weather in SF?" // “旧金山目前天气如何？”
  },
  id: "1",
  name: tool.name,
  type: "tool_call",
}

await tool.invoke(modelGeneratedToolCall)
```

## 链式调用 (Chaining)

我们可以通过首先将工具绑定到 [工具调用模型](/oss/langchain/tools/)，然后调用它来在链中使用我们的工具：

```typescript
// @lc-docs-hide-cell

import { ChatOpenAI } from "@langchain/openai"

const llm = new ChatOpenAI({
  model: "gpt-4o",
  temperature: 0,
})
```

```typescript
import { HumanMessage } from "@langchain/core/messages";
import { ChatPromptTemplate } from "@langchain/core/prompts";
import { RunnableLambda } from "@langchain/core/runnables";

const prompt = ChatPromptTemplate.fromMessages(
  [
    ["system", "You are a helpful assistant."], // “你是一位乐于助人的助手。”
    ["placeholder", "{messages}"],
  ]
)

const llmWithTools = llm.bindTools([tool]);

const chain = prompt.pipe(llmWithTools);

const toolChain = RunnableLambda.from(
  async (userInput: string, config) => {
    const humanMessage = new HumanMessage(userInput,);
    const aiMsg = await chain.invoke({
      messages: [new HumanMessage(userInput)],
    }, config);
    // 假设 aiMsg.tool_calls 存在，则传递给 tool.batch
    const toolMsgs = await tool.batch(aiMsg.tool_calls, config); 
    return chain.invoke({
      messages: [humanMessage, aiMsg, ...toolMsgs],
    }, config);
  }
);

const toolChainResult = await toolChain.invoke("what is the current weather in sf?"); // “旧金山目前天气如何？”
```

```typescript
const { tool_calls, content } = toolChainResult;

console.log("AIMessage", JSON.stringify({
  tool_calls,
  content,
}, null, 2));
```
