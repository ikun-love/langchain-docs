`@decodo/langchain-ts` 包允许开发者在 LangChain 应用中集成并使用 Decodo 的 Web Scraper API。

Web Scraper API 的特点：

- 简易化数据访问。简化了从网站和在线资源中检索信息的过程。
- 地理位置灵活性。可以不受地域限制地访问内容。
- 可靠的抓取能力。采用先进技术来避免被检测和封锁。

## 功能特性 (Features)

`@decodo/langchain-ts` 插件的功能包括：

- **网页抓取 (Web Scraping)**：抓取任何 URL 并获取 Markdown 格式的内容。
- **Google 搜索**：搜索 Google 并获取结构化的搜索结果。
- **Amazon 搜索**：搜索 Amazon 并获取结构化的产品数据。
- **地理位置选择 (Geolocation selection)**：用于处理对位置敏感的内容。
- **JavaScript 渲染**：用于需要真实浏览器环境的目标网站。
- **Markdown 输出**：方便地以对 LLM（大语言模型）更友好的、更节省 Token 的格式进行连接。

## 安装 (Installation)

```bash
npm install @decodo/langchain-ts
```

## 快速开始 (Quickstart)

要使用此项目中的工具，您需要一个 [Decodo Advanced Web Scraping API](https://help.decodo.com/docs/web-scraping-api-core-and-advanced-plans) 订阅。[仪表板 (dashboard)](https://dashboard.decodo.com/) 上提供免费试用。

## 示例 (Examples)

针对每个工具的一系列 Agentic 示例。

### 通用工具 (Universal)

```typescript
import dotenv from "dotenv";
import { ChatOpenAI } from "@langchain/openai";
import { createAgent } from "@langchain/agents";
import { DecodoUniversalTool } from "@decodo/langchain-ts";

dotenv.config();

const main = async () => {
  const username = process.env.SCRAPER_API_USERNAME!;
  const password = process.env.SCRAPER_API_PASSWORD!;

  const decodoUniversalTool = new DecodoUniversalTool({ username, password });

  const model = new ChatOpenAI({
    model: "gpt-4o-mini",
  });

  const agent = createAgent({
    llm: model,
    tools: [decodoUniversalTool],
  });

  const result = await agent.invoke({
    messages: [
      {
        role: "user",
        content:
          "scrape the wikipedia NBA 2025 season page and tell me who won in 2025?",
      },
    ],
  });

  console.log(result.messages[result.messages.length - 1].content);
};

if (require.main === module) {
  main();
}
```

更多示例，请参阅 GitHub 上的 [@decodo/langchain-ts](https://github.com/Decodo/decodo-langchain-ts)。

## 配置 (Configuration)

所有工具都接受一个 `DecodoConfig` 对象：

```typescript
type DecodoConfig = {
  username: string; // 您的 Web Advanced 产品用户名
  password: string; // 您的 Web Advanced 产品密码
};
```
