> [Azure 容器应用动态会话](https://learn.microsoft.com/azure/container-apps/sessions) 提供了对安全沙箱环境的快速访问，非常适合运行需要与其他工作负载保持强隔离的代码或应用程序。

您可以在[此页面](https://learn.microsoft.com/azure/container-apps/sessions)上了解有关 Azure 容器应用动态会话及其代码解释功能的更多信息。如果您还没有 Azure 帐户，可以[创建一个免费帐户](https://azure.microsoft.com/free/)开始使用。

## 设置

您需要首先安装 [`@langchain/azure-dynamic-sessions`](https://www.npmjs.com/package/@langchain/azure-dynamic-sessions) 包：

<Tip>
有关安装 LangChain 包的一般说明，请参阅[本节](/oss/langchain/install)。
</Tip>

```bash npm
npm install @langchain/azure-dynamic-sessions @langchain/core
```

您还需要有一个代码解释器会话池实例正在运行。您可以通过遵循[本指南](https://learn.microsoft.com/azure/container-apps/sessions-code-interpreter)，使用 [Azure CLI](https://learn.microsoft.com/cli/azure/install-azure-cli) 部署一个版本。

实例运行后，您需要确保已为其正确设置了 Azure Entra 身份验证。您可以在[此处](https://learn.microsoft.com/azure/container-apps/sessions?tabs=azure-cli#authentication)找到有关如何执行此操作的说明。

添加了对身份的授权后，您需要检索 **会话池管理终结点 (session pool management endpoint)**。您可以在 Azure 门户中，找到实例的“概述 (Overview)”部分来获取它。然后，您需要设置以下环境变量：

```bash .env example
AZURE_CONTAINER_APP_SESSION_POOL_MANAGEMENT_ENDPOINT=<your_endpoint>
```

## 用法示例

下面是一个简单的示例，它创建一个新的 Python 代码解释器会话，调用工具并打印结果。

```typescript
import { SessionsPythonREPLTool } from "@langchain/azure-dynamic-sessions";

const tool = new SessionsPythonREPLTool({
  poolManagementEndpoint:
    process.env.AZURE_CONTAINER_APP_SESSION_POOL_MANAGEMENT_ENDPOINT || "",
});

const result = await tool.invoke("print('Hello, World!')\n1+2");

console.log(result);

// {
//   stdout: "Hello, World!\n",
//   stderr: "",
//   result: 3,
// }
```

这是一个完整的示例，我们使用 Azure OpenAI 聊天模型来调用 Python 代码解释器会话工具来执行代码并获取结果：

```typescript
import type { ChatPromptTemplate } from "@langchain/core/prompts";
import { pull } from "@langchain/classic/hub";
import { AgentExecutor, createToolCallingAgent } from "@langchain/classic/agents";
import { SessionsPythonREPLTool } from "@langchain/azure-dynamic-sessions";
import { AzureChatOpenAI } from "@langchain/openai";

const tools = [
  new SessionsPythonREPLTool({
    poolManagementEndpoint:
      process.env.AZURE_CONTAINER_APP_SESSION_POOL_MANAGEMENT_ENDPOINT || "",
  }),
];

// 注意：您需要一个支持函数调用的模型部署，
// 例如 `gpt-35-turbo` 的 `1106` 版本。
const llm = new AzureChatOpenAI({
  temperature: 0,
});

// 获取要使用的提示模板——您可以修改它！
// 如果您想查看完整的提示模板，请访问：
// https://smith.langchain.com/hub/jacob/tool-calling-agent
const prompt = await pull<ChatPromptTemplate>("jacob/tool-calling-agent");

const agent = await createToolCallingAgent({
  llm,
  tools,
  prompt,
});

const agentExecutor = new AgentExecutor({
  agent,
  tools,
});

const result = await agentExecutor.invoke({
  input:
    "创建一个打印 Python 版本的 Python 程序并返回结果。",
});

console.log(result);
```
