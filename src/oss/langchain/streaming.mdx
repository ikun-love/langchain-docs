---
title: 流式传输 (Streaming)
---

LangChain 实现了一个流式传输系统，用于实时展现更新信息。

对于基于 LLM（大语言模型）构建的应用，流式传输对于增强应用的响应性至关重要。通过**逐步显示**输出，即使在完整响应准备好之前，流式传输也能显著改善用户体验 (UX)，尤其是在处理 LLM 的等待延迟时。

## 概述

LangChain 的流式传输系统可以让你向应用展示来自智能体（Agent）运行的实时反馈。

使用 LangChain 流式传输可以实现以下功能：

* <Icon icon="brain" size={16} /> [**流式传输智能体进度**](#agent-progress) — 在智能体的每一步执行后获取状态更新。
* <Icon icon="square-binary" size={16} /> [**流式传输 LLM Token**](#llm-tokens) — 在语言模型生成 Token 的同时进行传输。
* <Icon icon="table" size={16} /> [**流式传输自定义更新**](#custom-updates) — 发出用户定义的信号（例如：`"Fetched 10/100 records"`）。
* <Icon icon="layer-plus" size={16} /> [**流式传输多种模式**](#stream-multiple-modes) — 可以选择 `updates`（智能体进度）、`messages`（LLM Token + 元数据）或 `custom`（任意用户数据）。

## 智能体进度 (Agent progress)

:::python
要以流式方式传输智能体进度，请将 @[`stream`][CompiledStateGraph.stream] 或 @[`astream`][CompiledStateGraph.astream] 方法与 `stream_mode="updates"` 一起使用。该方法会在每个智能体步骤后发出一个事件。
:::

:::js
要以流式方式传输智能体进度，请将 @[`stream`][CompiledStateGraph.stream] 方法与 `streamMode: "updates"` 一起使用。该方法会在每个智能体步骤后发出一个事件。
:::

例如，如果你的智能体调用了一次工具，你应该会看到以下更新：

* **LLM 节点**: 包含工具调用请求的 @[`AIMessage`]
* **工具节点**: 包含执行结果的 @[`ToolMessage`]
* **LLM 节点**: 最终的 AI 响应

:::python

```python title="Streaming agent progress"
from langchain.agents import create_agent


def get_weather(city: str) -> str:
    """获取给定城市的天气信息。"""

    return f"It's always sunny in {city}!"

agent = create_agent(
    model="gpt-5-nano",
    tools=[get_weather],
)
for chunk in agent.stream(  # [!code highlight]
    {"messages": [{"role": "user", "content": "What is the weather in SF?"}]},
    stream_mode="updates",
):
    for step, data in chunk.items():
        print(f"step: {step}")
        print(f"content: {data['messages'][-1].content_blocks}")
```

```shell title="Output"

step: tools
content: [{'type': 'text', 'text': "It's always sunny in San Francisco!"}]

step: model

```
:::

:::js
```typescript
import z from "zod";
import { createAgent, tool } from "langchain";

const getWeather = tool(
    async ({ city }) => {
        return `The weather in ${city} is always sunny!`;
    },
    {
        name: "get_weather",
        description: "Get weather for a given city.",
        schema: z.object({
        city: z.string(),
        }),
    }
);

const agent = createAgent({
    model: "gpt-5-nano",
    tools: [getWeather],
});

for await (const chunk of await agent.stream(
```

## LLM Token 传输 (LLM tokens)

:::python
要以流式方式传输 LLM 生成的 Token，请使用 `stream_mode="messages"`。下面展示了智能体流式传输工具调用和最终响应的输出。

```python title="Streaming LLM tokens"
from langchain.agents import create_agent


def get_weather(city: str) -> str:
    """获取给定城市的天气信息。"""

    return f"It's always sunny in {city}!"

agent = create_agent(
    model="gpt-5-nano",
    tools=[get_weather],
)
for token, metadata in agent.stream(  # [!code highlight]
    {"messages": [{"role": "user", "content": "What is the weather in SF?"}]},
    stream_mode="messages",
):
    print(f"node: {metadata['langgraph_node']}")
    print(f"content: {token.content_blocks}")
    print("\n")
```

## 自定义更新 (Custom updates)

:::python
要流式传输工具执行时的更新，您可以使用 @[`get_stream_writer`]。

```python title="Streaming custom updates"
from langchain.agents import create_agent
from langgraph.config import get_stream_writer  # [!code highlight]


def get_weather(city: str) -> str:
    """获取给定城市的天气信息。"""
    writer = get_stream_writer()  # [!code highlight]
    # 流式传输任何任意数据
    writer(f"Looking up data for city: {city}")
    writer(f"Acquired data for city: {city}")
    return f"It's always sunny in {city}!"

agent = create_agent(
    model="claude-sonnet-4-5-20250929",
    tools=[get_weather],
)

for chunk in agent.stream(
    {"messages": [{"role": "user", "content": "What is the weather in SF?"}]},
    stream_mode="custom"  # [!code highlight]
):
    print(chunk)
```

```shell title="Output"
Looking up data for city: San Francisco
Acquired data for city: San Francisco
```

<Note>
    如果在工具内部添加了 @[`get_stream_writer`]，则无法在 LangGraph 执行上下文之外调用该工具。
</Note>
:::

:::js
要流式传输工具执行时的更新，可以使用配置中的 `writer` 参数。

```typescript
import z from "zod";
import { tool, createAgent } from "langchain";
import { LangGraphRunnableConfig } from "@langchain/langgraph";

const getWeather = tool(
    async (input, config: LangGraphRunnableConfig) => {
        // 流式传输任何任意数据
        config.writer?.(`Looking up data for city: ${input.city}`);
        // ... 获取城市数据
        config.writer?.(`Acquired data for city: ${input.city}`);
        return `It's always sunny in ${input.city}!`;
    },
    {
        name: "get_weather",
        description: "Get weather for a given city.",
        schema: z.object({
        city: z.string().describe("The city to get weather for."),
        }),
    }
);

const agent = createAgent({
    model: "gpt-4o-mini",
    tools: [getWeather],
});

for await (const chunk of await agent.stream(
    { messages: [{ role: "user", content: "what is the weather in sf" }] },
    { streamMode: "custom" }
)) {
    console.log(chunk);
}
```

```shell title="Output"
Looking up data for city: San Francisco
Acquired data for city: San Francisco
```

<Note>
    如果向工具中添加 `writer` 参数，则在不提供 writer 函数的情况下，无法在 LangGraph 执行上下文之外调用该工具。
</Note>
:::

## 流式传输多种模式 (Stream multiple modes)

:::python
您可以通过将流式模式指定为列表来指定多种流式传输模式：`stream_mode=["updates", "custom"]`：

```python title="Streaming multiple modes"
from langchain.agents import create_agent
from langgraph.config import get_stream_writer


def get_weather(city: str) -> str:
    """获取给定城市的天气信息。"""
    writer = get_stream_writer()
    writer(f"Looking up data for city: {city}")
    writer(f"Acquired data for city: {city}")
    return f"It's always sunny in {city}!"

agent = create_agent(
    model="gpt-5-nano",
    tools=[get_weather],
)

for stream_mode, chunk in agent.stream(  # [!code highlight]
    {"messages": [{"role": "user", "content": "What is the weather in SF?"}]},
    stream_mode=["updates", "custom"]
):
    print(f"stream_mode: {stream_mode}")
    print(f"content: {chunk}")
    print("\n")
```

```typescript
import { tool, createAgent } from "langchain";

const getWeather = tool(
```

## 禁用流式传输 (Disable streaming)

在某些应用中，您可能需要为特定模型的单个 Token 禁用流式传输。

这在 [多智能体](/oss/langchain/multi-agent) 系统中控制哪些智能体流式传输其输出时非常有用。

请参阅 [模型](/oss/langchain/models#disable-streaming) 指南，了解如何禁用流式传输。
