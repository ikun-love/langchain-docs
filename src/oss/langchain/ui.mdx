### 连接到您的智能体

Agent Chat UI 可以连接到[本地](/oss/langchain/studio#setup-local-agent-server)和[已部署的智能体](/oss/langchain/deploy)。

启动 Agent Chat UI 后，您需要进行配置才能连接到您的智能体：

1. **Graph ID (图 ID)**：输入您的图名称（可以在 `langgraph.json` 文件的 `graphs` 部分找到）。
2. **Deployment URL (部署 URL)**：您的智能体服务器的端点（例如，本地开发时为 `http://localhost:2024`，或者您已部署的智能体的 URL）。
3. **LangSmith API 密钥（可选）**：添加您的 LangSmith API 密钥（如果使用的是本地智能体服务器则不需要）。

配置完成后，Agent Chat UI 将自动获取并显示您的智能体中所有已中断的对话线程。

<Tip>
  Agent Chat UI 对渲染工具调用（tool calls）和工具结果消息（tool result messages）具有开箱即用的支持。要自定义显示哪些消息，请参阅[在聊天中隐藏消息](https://github.com/langchain-ai/agent-chat-ui?tab=readme-ov-file#hiding-messages-in-the-chat)。
</Tip>
