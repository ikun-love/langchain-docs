```markdown
---
title: OUTPUT_PARSING_FAILURE
---

输出解析器（[Output Parser](https://reference.langchain.com/python/langchain_core/output_parsers/)）未能按照预期处理模型的输出。

<Note>
    一些预构建的结构（例如，旧版 LangChain 的 Agent 和 Chain）可能会在内部使用输出解析器，因此即使您没有明确地实例化和使用输出解析器，也可能会遇到此错误。
</Note>

## 故障排除

- 如果可能，请考虑使用工具调用（tool calling）或其他结构化输出技术，以避免使用输出解析器也能可靠地输出可解析的值。
- 为您的提示（Prompt）添加更精确的格式化指令。
- 如果您使用的是规模较小或能力较弱的模型，请尝试使用功能更强大的模型。
```
