## 概述

在本教程中，您将学习如何使用 LangChain 的 [智能体](/oss/langchain/agents) 根据 SQL 数据库回答问题。

从高层次上看，该智能体将执行以下操作：

<Steps>
<Step title="从数据库中获取可用表和模式信息" />
<Step title="决定哪些表与问题相关" />
<Step title="获取相关表的模式信息" />
<Step title="基于问题和模式信息生成查询语句" />
<Step title="使用 LLM 对查询语句进行初步检查，以避免常见错误" />
<Step title="执行查询并返回结果" />
<Step title="纠正数据库引擎报告的错误，直到查询成功为止" />
<Step title="根据查询结果整合最终回答" />
</Steps>

<Warning>
构建 SQL 数据库的问答系统需要执行模型生成的 SQL 查询。这样做存在固有风险。请确保您的数据库连接权限始终尽可能严格地限制在智能体所需范围之内。这将减轻（但不能消除）构建模型驱动系统的风险。
</Warning>

## 2. 配置数据库

本教程将创建一个 [SQLite 数据库](https://www.sqlitetutorial.net/sqlite-sample-database/)。SQLite 是一种轻量级的数据库，易于设置和使用。我们将加载 `chinook` 数据库，这是一个代表数字媒体商店的示例数据库。

为方便起见，我们将数据库 (`Chinook.db`) 托管在一个公共 GCS 存储桶上。

:::python
```python
import requests, pathlib

url = "https://storage.googleapis.com/benchmarks-artifacts/chinook/Chinook.db"
local_path = pathlib.Path("Chinook.db")

if local_path.exists():
    print(f"{local_path} 已存在，跳过下载。")
else:
    response = requests.get(url)
    if response.status_code == 200:
        local_path.write_bytes(response.content)
        print(f"文件已下载并保存为 {local_path}")
    else:
        print(f"文件下载失败。状态码: {response.status_code}")
```
:::
:::js
```typescript
import fs from "node:fs/promises";
import path from "node:path";

const url = "https://storage.googleapis.com/benchmarks-artifacts/chinook/Chinook.db";
const localPath = path.resolve("Chinook.db");

async function resolveDbPath() {
  if (await fs.exists(localPath)) {
    return localPath;
  }
  const resp = await fetch(url);
  if (!resp.ok) throw new Error(`数据库下载失败。状态码: ${resp.status}`);
  const buf = Buffer.from(await resp.arrayBuffer());
  await fs.writeFile(localPath, buf);
  return localPath;
}
```

```
sql_db_schema: 此工具的输入是以逗号分隔的表列表，输出是这些表的模式和示例行。请确保表确实存在，方法是首先调用 sql_db_list_tables！示例输入：table1, table2, table3

sql_db_query_checker: 在执行查询之前，使用此工具来仔细检查您的查询是否正确。在用 sql_db_query 执行任何查询之前，请务必使用此工具！
```

```typescript
import { SqlDatabase } from "@langchain/classic/sql_db";
import { DataSource } from "typeorm";

let db: SqlDatabase | undefined;
async function getDb() {
  if (!db) {
    const dbPath = await resolveDbPath();
    const datasource = new DataSource({ type: "sqlite", database: dbPath });
    db = await SqlDatabase.fromDataSourceParams({ appDataSource: datasource });
  }
  return db;
}

async function getSchema() {
  const db = await getDb();
  return await db.getTableInfo();
}
```

## 4. 使用 `create_agent`

使用 @[`create_agent`] 以最少的代码构建一个 [ReAct 智能体](https://arxiv.org/pdf/2210.03629)。该智能体会解释请求并生成一个 SQL 命令，然后由工具执行。如果命令出错，错误消息会返回给模型。然后模型可以检查原始请求和新的错误消息，并生成一个新命令。这可以持续进行，直到 LLM 成功生成命令或达到结束次数限制。这种向模型提供反馈（在本例中为错误消息）的模式非常强大。

使用描述性的系统提示初始化智能体，以自定义其行为：

```python
system_prompt = """
你是一个旨在与 SQL 数据库交互的智能体。
给定一个输入问题，创建一个语法正确的 {dialect} 查询来运行，
然后查看查询结果并返回答案。除非用户指定希望获取的具体示例数量，
否则始终将您的查询限制在最多 {top_k} 个结果。

您可以按相关列对结果进行排序，以返回数据库中最有趣的示例。
不要查询某个表的所有列，只查询给定问题相关的列。

你**必须**在执行查询前仔细检查你的查询。如果执行查询时出现错误，请重写查询并重试。

**不要**对数据库执行任何 DML 语句（INSERT, UPDATE, DELETE, DROP 等）。

开始时，你应该**总是**查看数据库中的表以了解可以查询的内容。**不要跳过**此步骤。

然后你应该查询最相关表的模式信息。
""".format(
    dialect=db.dialect,
    top_k=5,
)
```

现在，使用模型、工具和提示创建一个智能体：

```python
from langchain.agents import create_agent


agent = create_agent(
    model,
    tools,
    system_prompt=system_prompt,
)
```

## 6. 实现人工干预审查

在执行智能体的 SQL 查询之前，检查其中是否存在任何意外操作或效率低下的情况是明智的。

LangChain 智能体支持内置的[人工干预中间件](/oss/langchain/human-in-the-loop)，用于在智能体工具调用中添加监督。让我们配置智能体，使其在调用 `sql_db_query` 工具时暂停以供人工审查：

```python
from langchain.agents import create_agent
from langchain.agents.middleware import HumanInTheLoopMiddleware # [!code highlight]
from langgraph.checkpoint.memory import InMemorySaver # [!code highlight]


agent = create_agent(
    model,
    tools,
    system_prompt=system_prompt,
    middleware=[ # [!code highlight]
        HumanInTheLoopMiddleware( # [!code highlight]
            interrupt_on={"sql_db_query": True}, # [!code highlight]
            description_prefix="工具执行等待批准", # [!code highlight]
        ), # [!code highlight]
    ], # [!code highlight]
    checkpointer=InMemorySaver(), # [!code highlight]
)
```
<Note>
我们向智能体添加了一个[检查点](/oss/langchain/short-term-memory)，以便可以暂停和恢复执行。有关此以及可用中间件配置的详细信息，请参阅[人工干预指南](/oss/langchain/human-in-the-loop)。
</Note>

## 4. 执行 SQL 查询

在运行命令之前，请在 `_safe_sql` 中检查 LLM 生成的命令：

```typescript

const DENY_RE = /\b(INSERT|UPDATE|DELETE|ALTER|DROP|CREATE|REPLACE|TRUNCATE)\b/i;
const HAS_LIMIT_TAIL_RE = /\blimit\b\s+\d+(\s*,\s*\d+)?\s*;?\s*$/i;

function sanitizeSqlQuery(q) {
  let query = String(q ?? "").trim();

  // 阻止多个语句（允许一个可选的尾随 ;）
  const semis = [...query].filter((c) => c === ";").length;
  if (semis > 1 || (query.endsWith(";") && query.slice(0, -1).includes(";"))) {
    throw new Error("不允许使用多个语句。")
  }
  query = query.replace(/;+\s*$/g, "").trim();

  // 只读门禁
  if (!query.toLowerCase().startsWith("select")) {
    throw new Error("只允许 SELECT 语句")
  }
  if (DENY_RE.test(query)) {
    throw new Error("检测到 DML/DDL。只允许只读查询。")
  }

  // 仅在尚未存在 LIMIT 时追加 LIMIT
  if (!HAS_LIMIT_TAIL_RE.test(query)) {
    query += " LIMIT 5";
  }
  return query;
}
```

然后，使用 `SQLDatabase` 中的 `run` 方法与 `execute_sql` 工具一起执行命令：

```typescript
import { tool } from "langchain"
import * as z from "zod";

const executeSql = tool(
  async ({ query }) => {
    const q = sanitizeSqlQuery(query);
    try {
      const result = await db.run(q);
      return typeof result === "string" ? result : JSON.stringify(result, null, 2);
    } catch (e) {
      throw new Error(e?.message ?? String(e))
    }
  },
  {
    name: "execute_sql",
    description: "执行一个只读的 SQLite SELECT 查询并返回结果。",
    schema: z.object({
      query: z.string().describe("要执行的 SQLite SELECT 查询（只读）。"),
    }),
  }
);
```

## 5. 使用 `createAgent`

使用 `createAgent` 以最少的代码构建一个 [ReAct 智能体](https://arxiv.org/pdf/2210.03629)。该智能体会解释请求并生成一个 SQL 命令。工具将检查命令的安全性然后尝试执行它。如果命令出错，错误消息会返回给模型。然后模型可以检查原始请求和新的错误消息，并生成一个新命令。这可以持续进行，直到 LLM 成功生成命令或达到结束次数限制。这种向模型提供反馈（在本例中为错误消息）的模式非常强大。

使用描述性的系统提示初始化智能体以自定义其行为：

```typescript
import { SystemMessage } from "langchain";

const getSystemPrompt = async () => new SystemMessage(`你是一位细致的 SQLite 分析师。

权威模式（不要编造列/表）：
${await getSchema()}

规则：
- 分步思考。
- 当你需要数据时，调用工具 \`execute_sql\` 并提供一个 SELECT 查询。
- 仅限只读；不允许 INSERT/UPDATE/DELETE/ALTER/DROP/CREATE/REPLACE/TRUNCATE。
- 除非用户明确要求，否则限制为 5 行。
- 如果工具返回 'Error:'，请修改 SQL 并重试。
- 限制尝试次数为 5 次。
- 如果 5 次尝试后仍不成功，请向用户返回一条注释。
- 优先使用明确的列列表；避免使用 SELECT *。
`);
```

现在，使用模型、工具和提示创建一个智能体：

```typescript
import { createAgent } from "langchain";

const agent = createAgent({
  model: "gpt-5",
  tools: [executeSql],
  systemPrompt: getSystemPrompt,
});
```

```typescript
import fs from "node:fs/promises";
import path from "node:path";
import { SqlDatabase } from "@langchain/classic/sql_db";
import { DataSource } from "typeorm";
import { SystemMessage, createAgent, tool } from "langchain"
import * as z from "zod";

const url = "https://storage.googleapis.com/benchmarks-artifacts/chinook/Chinook.db";
const localPath = path.resolve("Chinook.db");

async function resolveDbPath() {
  if (await fs.exists(localPath)) {
    return localPath;
  }
  const resp = await fetch(url);
  if (!resp.ok) throw new Error(`数据库下载失败。状态码: ${resp.status}`);
  const buf = Buffer.from(await resp.arrayBuffer());
  await fs.writeFile(localPath, buf);
  return localPath;
}

let db: SqlDatabase | undefined;
async function getDb() {
  if (!db) {
    const dbPath = await resolveDbPath();
    const datasource = new DataSource({ type: "sqlite", database: dbPath });
    db = await SqlDatabase.fromDataSourceParams({ appDataSource: datasource });
  }
  return db;
}

async function getSchema() {
  const db = await getDb();
  return await db.getTableInfo();
}

const DENY_RE = /\b(INSERT|UPDATE|DELETE|ALTER|DROP|CREATE|REPLACE|TRUNCATE)\b/i;
const HAS_LIMIT_TAIL_RE = /\blimit\b\s+\d+(\s*,\s*\d+)?\s*;?\s*$/i;

function sanitizeSqlQuery(q) {
  let query = String(q ?? "").trim();

  // 阻止多个语句（允许一个可选的尾随 ;）
  const semis = [...query].filter((c) => c === ";").length;
  if (semis > 1 || (query.endsWith(";") && query.slice(0, -1).includes(";"))) {
    throw new Error("不允许使用多个语句。")
  }
  query = query.replace(/;+\s*$/g, "").trim();

  // 只读门禁
  if (!query.toLowerCase().startsWith("select")) {
    throw new Error("只允许 SELECT 语句")
  }
  if (DENY_RE.test(query)) {
    throw new Error("检测到 DML/DDL。只允许只读查询。")
  }

  // 仅在尚未存在 LIMIT 时追加 LIMIT
  if (!HAS_LIMIT_TAIL_RE.test(query)) {
    query += " LIMIT 5";
  }
  return query;
}

const executeSql = tool(
  async ({ query }) => {
    const q = sanitizeSqlQuery(query);
    try {
      const result = await db.run(q);
      return typeof result === "string" ? result : JSON.stringify(result, null, 2);
    } catch (e) {
      throw new Error(e?.message ?? String(e))
    }
  },
  {
    name: "execute_sql",
    description: "执行一个只读的 SQLite SELECT 查询并返回结果。",
    schema: z.object({
      query: z.string().describe("要执行的 SQLite SELECT 查询（只读）。"),
    }),
  }
);

const getSystemPrompt = async () => new SystemMessage(`你是一位细致的 SQLite 分析师。

权威模式（不要编造列/表）：
${await getSchema()}

规则：
- 分步思考。
- 当你需要数据时，调用工具 \`execute_sql\` 并提供一个 SELECT 查询。
- 仅限只读；不允许 INSERT/UPDATE/DELETE/ALTER/DROP/CREATE/REPLACE/TRUNCATE。
- 除非用户明确要求，否则限制为 5 行。
- 如果工具返回 'Error:'，请修改 SQL 并重试。
- 限制尝试次数为 5 次。
- 如果 5 次尝试后仍不成功，请向用户返回一条注释。
- 优先使用明确的列列表；避免使用 SELECT *。
`);

export const agent = createAgent({
  model: "gpt-5",
  tools: [executeSql],
  systemPrompt: getSystemPrompt,
});
```
