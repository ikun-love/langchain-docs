一个用于构建具有持久化内存的智能体的终端界面。智能体可以在会话中保持上下文、学习项目约定，并在批准控制下执行代码。

Deep Agents CLI 具有以下内置功能：

* <Icon icon="file" size={16} /> **文件操作** - 使用户体能够管理和修改代码和文档的工具来读取、写入和编辑项目文件。
* <Icon icon="terminal" size={16} /> **Shell 命令执行** - 执行 shell 命令来运行测试、构建项目、管理依赖项以及与版本控制系统交互。
* <Icon icon="magnifying-glass" size={16} /> **网络搜索** - 搜索网络以获取最新信息和文档（需要 Tavily API 密钥）。
* <Icon icon="globe" size={16} /> **HTTP 请求** - 对 API 和外部服务发出 HTTP 请求，以完成数据获取和集成任务。
* <Icon icon="list-check" size={16} /> **任务规划与跟踪** - 将复杂任务分解为离散的步骤，并通过内置的待办事项系统跟踪进度。
* <Icon icon="brain" size={16} /> **内存的存储与检索** - 在会话之间存储和检索信息，使智能体能够记住项目约定和学到的模式。
* <Icon icon="head-side" size={16} /> **人在回路 (Human-in-the-loop)** - 要求人工批准敏感的工具操作。

## 快速开始

<Steps>
  <Step title="设置 API 密钥" icon="key">
    作为环境变量导出：

    ```bash
    export ANTHROPIC_API_KEY="your-api-key"
    ```

    或者在项目根目录创建一个 `.env` 文件：

    ```bash
    ANTHROPIC_API_KEY=your-api-key
    ```
  </Step>

  <Step title="运行 CLI" icon="terminal">
    ```bash
    uvx deepagents-cli
    ```
  </Step>

  <Step title="给智能体分配任务" icon="message">
    ```bash
    > Create a Python script that prints "Hello, World!"
    ```

    在修改文件之前，智能体会提供带有 diff 差异对比的更改建议供您批准。
  </Step>
</Steps>

<Accordion title="其他安装和配置选项">
如有需要，可本地安装：

<CodeGroup>
```bash pip
pip install deepagents-cli
```

```bash uv
uv add deepagents-cli
```
</CodeGroup>

CLI 默认使用 Anthropic Claude Sonnet 4。如需使用 OpenAI：

```bash
export OPENAI_API_KEY="your-key"
```

启用网络搜索（可选）：

```bash
export TAVILY_API_KEY="your-key"
```

API 密钥可以设置为环境变量或保存在 `.env` 文件中。
</Accordion>

## 配置

<AccordionGroup>
  <Accordion title="命令行选项" icon="flag">
    | 选项 | 描述 |
    |------------------------|-------------------------------------------------------------|
    | `--agent NAME` | 使用具有独立内存的命名智能体 |
    | `--auto-approve` | 跳过工具确认提示（使用 `Ctrl+T` 切换） |
    | `--sandbox TYPE` | 在远程沙箱中执行：`modal`、`daytona` 或 `runloop` |
    | `--sandbox-id ID` | 重用现有沙箱 |
    | `--sandbox-setup PATH` | 在沙箱中运行设置脚本 |
  </Accordion>

  <Accordion title="CLI 命令" icon="terminal">
    | 命令 | 描述 |
    |--------------------------------------|----------------------------------------|
    | `deepagents list` | 列出所有智能体 |
    | `deepagents help` | 显示帮助信息 |
    | `deepagents reset --agent NAME` | 清除智能体内存并重置为默认状态 |
    | `deepagents reset --agent NAME --target SOURCE` | 从另一个智能体复制内存 |
  </Accordion>
</AccordionGroup>

<AccordionGroup>
  <Accordion title="交互模式" icon="slash">
    在 CLI 会话中使用以下命令：

    - `/tokens` - 显示令牌使用情况
    - `/clear` - 清除对话历史记录
    - `/exit` - 退出 CLI
  </Accordion>

  <Accordion title="Bash 命令" icon="terminal">
    通过在前面加 `!` 来直接执行 shell 命令：

    ```bash
    !git status
    !npm test
    !ls -la
    ```
  </Accordion>

  <Accordion title="键盘快捷键" icon="keyboard">
    | 快捷键 | 操作 |
    |-------------|---------------------|
    | `Enter` | 提交 |
    | `Alt+Enter` | 换行 |
    | `Ctrl+E` | 外部编辑器 |
    | `Ctrl+T` | 切换自动批准 |
    | `Ctrl+C` | 中断 |
    | `Ctrl+D` | 退出 |
  </Accordion>
</AccordionGroup>


## 使用内存设置项目约定

智能体将信息存储在 `~/.deepagents/AGENT_NAME/memories/` 目录下的 markdown 文件中，采用“内存优先”协议：

1. **研究 (Research)**：在开始任务前搜索内存以获取相关上下文
2. **响应 (Response)**：在执行过程中不确定时检查内存
3. **学习 (Learning)**：自动保存新信息以供将来会话使用

使用描述性文件名按主题组织内存：

```
~/.deepagents/backend-dev/memories/
├── api-conventions.md
├── database-schema.md
└── deployment-process.md
```

只需教一次智能体约定：

```bash
uvx deepagents-cli --agent backend-dev
> Our API uses snake_case and includes created_at/updated_at timestamps
```

它会在将来的会话中记住这些设置：

```bash
> Create a /users endpoint
# 无需提示即可应用约定
```

## 使用远程沙箱

在隔离的远程环境中执行代码，以确保安全性和灵活性。远程沙箱提供以下优势：

  - **安全性**：保护本地机器免受潜在有害的代码执行影响
  - **干净的环境**：无需本地设置即可使用特定的依赖项或操作系统配置
  - **并行执行**：在隔离的环境中同时运行多个智能体
  - **长期任务**：执行耗时的操作而不会阻塞本地机器
  - **可再现性**：确保团队内部执行环境的一致性

要使用远程沙箱，请遵循以下步骤：

1. 配置您的沙箱提供商 ([Runloop](https://www.runloop.ai/)、[Daytona](https://www.daytona.io/) 或 [Modal](https://modal.com/))：

    ```bash
    # Runloop
    export RUNLOOP_API_KEY="your-key"

    # Daytona
    export DAYTONA_API_KEY="your-key"

    # Modal
    modal setup
    ```

2. 运行带有沙箱的 CLI：

    ```bash
    uvx deepagents-cli --sandbox runloop --sandbox-setup ./setup.sh
    ```

    智能体在本地运行，但所有代码操作都在远程沙箱中执行。可选的设置脚本可以配置环境变量、克隆仓库并准备依赖项。

3.（可选）创建一个 `setup.sh` 文件以配置沙箱环境：

    ```bash
    #!/bin/bash
    set -e

    # 使用 GitHub token 克隆仓库
    git clone https://x-access-token:${GITHUB_TOKEN}@github.com/username/repo.git $HOME/workspace
    cd $HOME/workspace

    # 使环境变量持久化
    cat >> ~/.bashrc <<'EOF'
    export GITHUB_TOKEN="${GITHUB_TOKEN}"
    export OPENAI_API_KEY="${OPENAI_API_KEY}"
    cd $HOME/workspace
    EOF

    source ~/.bashrc
    ```

    将密钥存储在本地 `.env` 文件中供设置脚本访问。

<Warning>
  沙箱隔离了代码执行，但智能体仍然容易受到对不受信任输入的提示注入攻击。仅使用人在回路批准、短期密钥以及受信任的设置脚本。请注意，沙箱 API 发展迅速，我们预计会有更多提供商支持代理（proxies），以帮助缓解提示注入和密钥管理方面的顾虑。
</Warning>
