当您在本地使用 LangChain 构建 Agent 时，能够可视化 Agent 的内部运行情况、实时与之交互以及在问题发生时进行调试是非常有帮助的。**LangSmith Studio** 就是一个免费的可视化界面，用于从本地机器开发和测试您的 LangChain Agent。

Studio 会连接到您本地运行的 Agent，向您展示 Agent 执行的每一步：发送给模型的提示（prompts）、工具调用及其结果，以及最终的输出。您可以测试不同的输入、检查中间状态，并在无需额外代码或部署的情况下迭代 Agent 的行为。

本页面将介绍如何为本地 LangChain Agent 设置 Studio。

## 先决条件

在开始之前，请确保您具备以下条件：

- **一个 LangSmith 账户**：请在 [smith.langchain.com](https://smith.langchain.com) 注册（免费）或登录。
- **一个 LangSmith API 密钥**：请遵循 [创建 API 密钥](/langsmith/create-account-api-key#create-an-api-key) 指南。
- 如果您不希望数据被 [追踪](/langsmith/observability-concepts#traces) 到 LangSmith，请在您应用的 `.env` 文件中设置 `LANGSMITH_TRACING=false`。禁用追踪后，不会有任何数据离开您的本地服务器。

## 设置本地 Agent 服务器

### 1. 安装 LangGraph CLI

[LangGraph CLI](/langsmith/cli) 提供了一个本地开发服务器（也称为 [Agent Server](/langsmith/agent-server)），用于将您的 Agent 连接到 Studio。

:::python
```shell
# 需要 Python >= 3.11。
pip install --upgrade "langgraph-cli[inmem]"
```
:::

:::js
```shell
npx @langchain/langgraph-cli
```
:::

### 2. 准备您的 Agent

如果您已经有了一个 LangChain Agent，可以直接使用它。本示例使用一个简单的邮件 Agent：

```python title="agent.py"
from langchain.agents import create_agent

def send_email(to: str, subject: str, body: str):
    """发送一封电子邮件"""
    email = {
        "to": to,
        "subject": subject,
        "body": body
    }
    # ... 邮件发送逻辑

    return f"Email sent to {to}"

agent = create_agent(
    "gpt-4o",
    tools=[send_email],
    system_prompt="You are an email assistant. Always use the send_email tool.",
)
```

### 3. 环境变量

Studio 需要一个 LangSmith API 密钥才能连接您的本地 Agent。请在项目根目录下创建一个 `.env` 文件，并将您从 [LangSmith](https://smith.langchain.com/settings) 获取的 API 密钥添加到其中。

<Warning>
    请确保您的 `.env` 文件未被提交到版本控制系统（如 Git）中。
</Warning>

```bash .env
LANGSMITH_API_KEY=lsv2...
```

### 4. 创建 LangGraph 配置文件

LangGraph CLI 使用配置文件来定位您的 Agent 并管理依赖项。请在您的应用目录下创建一个 `langgraph.json` 文件：

```json title="langgraph.json"
{
  "dependencies": ["."],
  "graphs": {
    "agent": "./src/agent.py:agent"
  },
  "env": ".env"
}
```

`@[`create_agent`]` 函数会自动返回一个编译后的 LangGraph 图（graph），这正是配置文件中 `graphs` 键所期望的内容。

<Info>
有关配置文件的 JSON 对象中每个键的详细解释，请参阅 [LangGraph 配置文件参考](/langsmith/cli#configuration-file)。
</Info>

此时，项目结构应如下所示：

```bash
my-app/
├── src
│   └── agent.py
├── .env
└── langgraph.json
```

### 5. 安装依赖项

:::python
从根目录安装项目的依赖项：

<CodeGroup>
```shell pip
pip install langchain langchain-openai 
```
```shell uv
uv add langchain langchain-openai
```
</CodeGroup>
:::

:::js
```shell
yarn install
```
:::

### 6. 在 Studio 中查看您的 Agent

启动开发服务器以连接您的 Agent 和 Studio：

:::python
```shell
langgraph dev
```
:::

:::js
```shell
npx @langchain/langgraph-cli dev
```
:::

<Warning>
Safari 会阻止到 `localhost` 的连接。为解决此问题，请使用 `--tunnel` 参数运行上述命令，以便通过安全隧道访问 Studio。
</Warning>

一旦服务器运行起来，您的 Agent 就可以通过 API 在 `http://127.0.0.1:2024` 访问，也可以通过 Studio UI 在 `https://smith.langchain.com/studio/?baseUrl=http://127.0.0.1:2024` 访问：

<Frame>
![Agent view in the Studio UI](/oss/images/studio_create-agent.png)
</Frame>

连接到本地 Agent 后，您可以在 Studio 中快速迭代 Agent 的行为。运行一个测试输入，检查完整的执行追踪，包括提示、工具参数、返回值以及令牌/延迟指标。当出现错误时，Studio 会捕获带有周围状态的异常，以帮助您理解发生了什么。

开发服务器支持热重载——对代码中的提示或工具签名进行更改，Studio 会立即反映出来。您可以从任何步骤重新运行对话线程，以测试您的更改而无需重新开始。这个工作流程可以从简单的单工具 Agent 扩展到复杂的多节点图。
