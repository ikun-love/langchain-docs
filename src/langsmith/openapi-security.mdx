本指南将向您展示如何为您的 LangSmith API 文档自定义 OpenAPI 安全架构（Security Schema）。完善的安全架构文档有助于 API 消费者了解如何对您的 API 进行身份验证，甚至可以实现自动化的客户端生成。有关 LangGraph 认证系统的更多详细信息，请参阅 [认证与访问控制概念指南](/langsmith/auth)。

<Note>
**实现与文档**
本指南仅涵盖如何在 OpenAPI 中记录您的安全需求。要实现实际的身份验证逻辑，请参阅 [如何添加自定义认证](/langsmith/custom-auth)。
</Note>

本指南适用于所有 LangSmith 部署（Cloud 和自托管）。如果您没有使用 LangSmith，则不适用于使用 LangGraph 开源库的情况。

## 默认架构

默认的安全架构根据部署类型而异：

<Tabs>
    <Tab title="LangSmith">
    </Tab>
</Tabs>

默认情况下，LangSmith 要求在 `x-api-key` 标头中提供 LangSmith API 密钥：

```yaml
components:
  securitySchemes:
    apiKeyAuth:
      type: apiKey
      in: header
      name: x-api-key
security:
  - apiKeyAuth: []
```

当使用 LangGraph SDK 时，此信息可以从环境变量中推断出来。

<Tabs>
    <Tab title="自托管">
    </Tab>
</Tabs>

默认情况下，自托管部署没有安全架构。这意味着它们只能在受保护的网络中或使用外部认证机制进行部署。要添加自定义认证，请参阅 [如何添加自定义认证](/langsmith/custom-auth)。

## 自定义安全架构

要自定义 OpenAPI 文档中的安全架构，请在 `langgraph.json` 的 `auth` 配置中添加一个 `openapi` 字段。请记住，这**仅**更新 API 文档——您还必须实现相应的认证逻辑，如 [如何添加自定义认证](/langsmith/custom-auth) 中所示。

请注意，LangSmith 不提供认证端点——您需要在客户端应用程序中处理用户认证，然后将生成的凭证传递给 LangGraph API。

<Tabs>
    <Tab title="OAuth2 与 Bearer Token">
    ```json
    {
      "auth": {
        "path": "./auth.py:my_auth",  // 在此处实现认证逻辑
        "openapi": {
          "securitySchemes": {
            "OAuth2": {
              "type": "oauth2",
              "flows": {
                "implicit": {
                  "authorizationUrl": "https://your-auth-server.com/oauth/authorize",
                  "scopes": {
                    "me": "读取当前用户的信息",
                    "threads": "访问创建和管理线程的权限"
                  }
                }
              }
            }
          },
          "security": [
            {"OAuth2": ["me", "threads"]}
          ]
        }
      }
    }
    ```
    </Tab>
    <Tab title="API 密钥">
    ```json
    {
      "auth": {
        "path": "./auth.py:my_auth",  // 在此处实现认证逻辑
        "openapi": {
          "securitySchemes": {
            "apiKeyAuth": {
              "type": "apiKey",
              "in": "header",
              "name": "X-API-Key"
            }
          },
          "security": [
            {"apiKeyAuth": []}
          ]
        }
      }
    }
    ```
    </Tab>
</Tabs>

## 测试

更新配置后：

1. 部署您的应用程序
2. 访问 `/docs` 查看更新后的 OpenAPI 文档
3. 使用来自您的认证服务器的凭证尝试端点（确保您已首先实现了认证逻辑）
