LangSmith 允许您将转换（transformations）附加到数据集 Schema 的字段上，这些转换会在数据被添加到数据集之前应用，无论数据是通过 UI、API 还是运行规则（run rules）添加的。

结合 [LangSmith 的预构建 JSON Schema 类型](/langsmith/dataset-json-types)，这些转换可以实现在将数据保存到数据集之前，对数据进行简单的预处理。

## 转换类型

| 转换类型 | 目标类型 | 功能描述 |
| :--- | :--- | :--- |
| `remove\_system\_messages` | `Array[Message]` | 过滤消息列表，以移除任何系统消息（system messages）。 |
| `convert\_to\_openai\_message` | Message `Array[Message]` | 使用 LangChain 的 [`convert_to_openai_messages`](https://python.langchain.com/api_reference/core/messages/langchain_core.messages.utils.convert_to_openai_messages.html) 工具，将 LangChain 内部序列化格式的任何传入数据转换为 OpenAI 的标准消息格式。如果目标字段被标记为必填，并且在数据进入时未找到匹配的消息，它将尝试从几个知名的 LangSmith 追踪格式中提取一条或多条消息（例如，任何追踪到的 LangChain @[`BaseChatModel`] 运行，或者从 [LangSmith OpenAI 封装器](/langsmith/annotate-code#wrap-the-openai-client) 追踪到的运行中提取），并移除包含该消息的原始键。 |
| `convert\_to\_openai\_tool` | `Array[Tool]` 仅在 `inputs` 字典的顶层字段上可用。 | 使用 LangChain 的 @[`convert_to_openai_tool`] 函数，将任何传入数据转换为 OpenAI 标准工具格式。如果指定的键上未找到工具定义，它将从运行的调用参数（invocation parameters）中提取工具定义。这很有用，因为 LangChain 聊天模型会将工具定义追踪到运行的 `extra.invocation_params` 字段，而不是 `inputs` 字段。 |
| `remove\_extra\_fields` | `Object` | 移除 Schema 中未为该目标对象定义的任何字段。 |

## 聊天模型预构建 Schema

转换的主要用途是简化将生产追踪数据收集到数据集中的过程，使其格式标准化，以便用于评估、少样本提示（few shot prompting）等下游任务，并能兼容不同的模型提供商。

为了简化预构建转换的设置，LangSmith 提供了一个预定义的 Schema，它将执行以下操作：

* 从收集到的运行中提取消息，并将它们转换为 OpenAI 标准格式，这使得它们能够与所有 LangChain ChatModels 和大多数模型提供商的 SDK 兼容，用于下游评估和实验。
* 提取 LLM 使用的任何工具，并将它们添加到示例的输入中，以便在下游评估中实现可重现性。

<Check>
希望迭代系统提示（system prompts）的用户，在使用我们的聊天模型 Schema 时，通常也会对其输入消息应用“移除系统消息”转换，这样可以防止系统提示被保存到数据集中。
</Check>

### 兼容性

LLM 运行收集 Schema 旨在从 LangChain @[`BaseChatModel`] 运行或 [LangSmith OpenAI 封装器](/langsmith/annotate-code#wrap-the-openai-client) 追踪的运行中收集数据。

如果您有正在追踪但与此不兼容的 LLM 运行，请通过 [support.langchain.com](https://support.langchain.com) 联系支持，我们可以扩展支持。

如果您想对其他类型的运行应用转换（例如，表示带有消息历史的 LangGraph 状态），请直接定义您的 Schema 并手动添加相关的转换。

### 启用

当从追踪项目或标注队列向数据集中添加具有 LLM 运行类型的数据运行时，我们将默认应用聊天模型 Schema。

有关在新数据集上的启用信息，请参阅我们的 [数据集管理操作指南](/langsmith/manage-datasets-in-application)。

### 规范（Specs）

有关预构建 Schema 的完整 API 规范，请参阅以下部分：

#### 输入 Schema

```json
{
  "type": "object",
  "properties": {
    "messages": {
      "type": "array",
      "items": {
        "$ref": "https://api.smith.langchain.com/public/schemas/v1/message.json"
      }
    },
    "tools": {
      "type": "array",
      "items": {
        "$ref": "https://api.smith.langchain.com/public/schemas/v1/tooldef.json"
      }
    }
  },
  "required": ["messages"]
}
```

#### 输出 Schema

```json
{
  "type": "object",
  "properties": {
    "message": {
      "$ref": "https://api.smith.langchain.com/public/schemas/v1/message.json"
    }
  },
  "required": ["message"]
}
```

#### 转换（Transformations）

转换的配置如下所示：

```json
[
  {
    "path": ["inputs"],
    "transformation_type": "remove_extra_fields"
  },
  {
    "path": ["inputs", "messages"],
    "transformation_type": "convert_to_openai_message"
  },
  {
    "path": ["inputs", "tools"],
    "transformation_type": "convert_to_openai_tool"
  },
  {
    "path": ["outputs"],
    "transformation_type": "remove_extra_fields"
  },
  {
    "path": ["outputs", "message"],
    "transformation_type": "convert_to_openai_message"
  }
]
```
