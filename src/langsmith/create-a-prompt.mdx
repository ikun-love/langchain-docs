## 撰写你的 Prompt

左侧是 Prompt 的可编辑视图。

Prompt 由多个消息（messages）组成，每个消息都有一个“角色”（role）—— 包括 `system`（系统）、`human`（用户）和 `ai`（AI）。

### 模板格式

默认的模板格式是 `f-string`，但你可以通过点击模型旁边的设置图标 -> Prompt format -> Template format 来将其更改为 `mustache`。请通过 [此处](/langsmith/prompt-engineering-concepts#f-string-vs-mustache) 了解模板格式的更多信息。
![](/langsmith/images/template-format.png)

### 添加模板变量

Prompt 的强大之处在于能够使用变量。你可以使用变量为 Prompt 添加动态内容。可以通过以下两种方式之一添加模板变量：

1. 在 Prompt 中添加 `{{variable_name}}`（对于 `f-string`，两侧各一个花括号；对于 `mustache`，两侧各两个花括号）。![](/langsmith/images/prompt-with-variable.png)

2. 选中你想要模板化的文本，然后点击出现的工具提示（tooltip）按钮。为变量输入一个名称，然后进行转换。![](/langsmith/images/convert-to-variable.gif)

当我们添加一个变量后，我们会看到一个可以为 Prompt 变量输入示例输入值（sample inputs）的区域。请用具体的值填充这些区域，以便测试 Prompt。![](/langsmith/images/prompt-inputs.png)

### 结构化输出

为 Prompt 添加输出模式（output schema）将使输出采用结构化格式。请通过 [此处](/langsmith/prompt-engineering-concepts#structured-output) 了解有关结构化输出的更多信息。![](/langsmith/images/structured-output.png)

### 工具 (Tools)

你也可以通过点击 Prompt 编辑器底部的 `+ Tool` 按钮来添加工具。有关如何使用工具的更多信息，请参阅 [此处](/langsmith/use-tools)。

<Callout type="info" icon="bird">
在 Playground 中使用 **[Polly](/langsmith/polly)** 来生成工具、创建输出模式，并通过 AI 辅助优化你的 Prompt。
</Callout>

## 运行 Prompt

点击 "Start" 运行 Prompt。

![](/langsmith/images/create-a-prompt-run.png)

## 保存 Prompt

要保存 Prompt，请点击 "Save" 按钮，命名你的 Prompt，并决定它是设置为 "private"（私有）还是 "public"（公开）。私有 Prompt 仅对你的工作区可见，而公共 Prompt 可以被任何人发现。

你在 Playground 设置中选择的模型和配置将与 Prompt 一起保存。当你重新打开 Prompt 时，模型和配置将自动从保存的版本中加载。![](/langsmith/images/save-prompt.png)

<Check>
首次创建公共 Prompt 时，系统会要求你设置一个 LangChain Hub Handle。你所有的公共 Prompt 都将链接到此 Handle。在一个共享的工作区中，此 Handle 将为整个工作区设置。
</Check>

![](/langsmith/images/public-handle.png)

## 查看你的 Prompts

恭喜，你已经创建了第一个 Prompt！你可以在 Prompts 标签页中查看 Prompt 列表。

![](/langsmith/images/prompt-table.png)

## 添加元数据

要向 Prompt 添加元数据，请点击该 Prompt，然后点击名称旁边的“编辑”（Edit）铅笔图标。这将带你进入可以添加关于 Prompt 附加信息的地方，包括描述、README 和使用案例。对于公共 Prompt，任何查看其在 LangChain Hub 上版本的人都能看到这些信息。

![](/langsmith/images/pencil.png) ![](/langsmith/images/edit-prompt.png)

# 后续步骤

既然你已经创建了一个 Prompt，就可以在你的应用程序代码中使用它了。请参阅 [如何以编程方式拉取 Prompt](/langsmith/manage-prompts-programmatically#pull-a-prompt)。
