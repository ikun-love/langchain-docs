[Studio](/langsmith/studio) 在 [LangSmith 部署 UI (Deployments UI)](https://smith.langchain.com) 中支持连接到两种类型的图（Graphs）：

- 部署在 [云端或自托管环境](#deployed-graphs) 中的图。
- 使用 [Agent Server](#local-development-server) 在本地运行的图。

## 已部署的图 (Deployed graphs)

Studio 在 [LangSmith UI](https://smith.langchain.com) 的 **Deployments** 导航栏中可以访问。

对于已经 [部署](/langsmith/deployment-quickstart) 好的应用程序，您可以将 Studio 作为该部署的一部分进行访问。为此，请在 UI 中导航到该部署，然后选择 **Studio**。

这将加载连接到您的实时部署的 Studio 界面，允许您在相应的部署中创建、读取和更新其 [线程 (threads)](/oss/langgraph/persistence#threads)、[助手 (assistants)](/langsmith/assistants) 和 [内存 (memory)](/oss/concepts/memory) 配置。

## 本地开发服务器 (Local development server)

### 前提条件

要在本地使用 Studio 测试您的应用程序：

- 首先遵循 [本地应用快速入门指南](/langsmith/local-server)。
- 如果您不希望数据被 [追踪 (traced)](/langsmith/observability-concepts#traces) 到 LangSmith，请在应用程序的 `.env` 文件中设置 `LANGSMITH_TRACING=false`。禁用追踪后，任何数据都不会离开您的本地服务器。

### 设置

1. 安装 [LangGraph CLI](/langsmith/cli)：

    <CodeGroup>
    ```bash pip
    pip install -U "langgraph-cli[inmem]"
    langgraph dev
    ```

    ```bash uv
    uv add langgraph-cli[inmem]
    langgraph dev
    ```

    ```bash npm
    npx @langchain/langgraph-cli dev
    ```
    </CodeGroup>

    <Warning>
    **浏览器兼容性**
    Safari 浏览器会阻止对 `localhost` 的 Studio 连接。为解决此问题，请使用 `--tunnel` 参数运行命令，通过安全隧道访问 Studio。
    </Warning>

    执行以上命令后，Agent Server 将在本地启动，并以内存模式运行。服务器将以观察模式运行，监听代码更改并自动重启。阅读此 [参考文档](/langsmith/cli#dev) 以了解启动 API 服务器的所有选项。

    您将看到以下日志输出：

    ```
    > Ready!
    >
    > - API: [http://localhost:2024](http://localhost:2024/)
    >
    > - Docs: http://localhost:2024/docs
    >
    > - LangSmith Studio Web UI: https://smith.langchain.com/studio/?baseUrl=http://127.0.0.1:2024
    ```

    服务器启动后，您将自动被重定向到 Studio 界面。

1. 对于正在运行的服务器，您可以通过以下任一方式访问 Dbugger：
    1. 直接导航到以下 URL：`https://smith.langchain.com/studio/?baseUrl=http://127.0.0.1:2024`。
    1. 在 UI 的 **Deployments** 页面中，点击某个部署上的 **Studio** 按钮，输入 `http://127.0.0.1:2024` 并点击 **Connect**。

    如果您在不同的主机或端口上运行服务器，请相应地更新 `baseUrl` 的值。

### (可选) 附加调试器 (Attach a debugger)

要进行带有断点和变量检查的逐步调试，请执行以下操作：

    <CodeGroup>
    ```bash pip
    # 安装 debugpy 包
    pip install debugpy
    # 启用调试模式启动服务器
    langgraph dev --debug-port 5678
    ```

    ```bash uv
    # 安装 debugpy 包
    uv add debugpy
    # 启用调试模式启动服务器
    langgraph dev --debug-port 5678
    ```
    </CodeGroup>

然后，连接到您首选的调试器：

<Tabs>
    <Tab title="VS Code">
    将此配置添加到 `launch.json` 文件中：

    ```json
    {
        "name": "Attach to LangGraph",
        "type": "debugpy",
        "request": "attach",
        "connect": {
          "host": "0.0.0.0",
          "port": 5678
        }
    }
    ```
    </Tab>
    <Tab title="PyCharm">
    1. 前往 Run → Edit Configurations (运行 → 编辑配置)
    2. 点击 **+** 并选择 "Python Debug Server" (Python 调试服务器)
    3. 设置 IDE host name: `localhost`
    4. 设置 port: `5678`（或者您在前面步骤中选择的端口号）
    5. 点击 "OK" 并开始调试
    </Tab>
</Tabs>

<Tip>
如果遇到入门问题，请参阅 [故障排除指南](/langsmith/troubleshooting-studio)。
</Tip>
