LangSmith 将数据集中的示例（Examples）按如下方式存储：

| 字段名称 | 类型 | 描述 |
| :--- | :--- | :--- |
| **id** | UUID | 示例的唯一标识符。 |
| **name** | string | 示例的名称。 |
| **created\_at** | datetime | 此示例的创建时间。 |
| **modified\_at** | datetime | 此示例最后一次修改的时间。 |
| **inputs** | object | 此示例的输入（Inputs）地图/字典。 |
| **outputs** | object | 由运行结果（Run）生成的输出（Outputs）的地图或集合。 |
| **dataset\_id** | UUID | 此示例所属的数据集 ID。 |
| **source\_run\_id** | UUID | 如果此示例是从 LangSmith 的 [`Run`](/langsmith/run-data-format)（运行）创建的，则为该运行的 ID。 |
| **metadata** | object | 可以存储在示例上的额外信息地图，这些信息通常由用户或 SDK 定义。 |

要了解更多关于如何在评估中使用示例的信息，请阅读我们关于[评估 LLM 应用](/langsmith/evaluate-llm-application)的操作指南。
