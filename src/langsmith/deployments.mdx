<Callout icon="rocket" color="#4F46E5" iconType="regular">
**如果您正在构建或运维 Agent 应用，请从这里开始。** 本节内容关注于**部署您的应用**。如果您需要设置 LangSmith 基础设施，[平台设置 (Platform setup) ](/langsmith/platform-setup) 部分涵盖了基础设施选项（云、混合或自托管）以及混合和自托管部署的设置指南。
</Callout>

本节内容介绍了如何将您的_Agent_ 和应用打包、构建并部署为 [Agent Server](/langsmith/agent-server)。

典型的部署工作流程包含以下步骤：

<Steps>
  <Step title={<a href="/langsmith/local-server">本地测试</a>}>
    在本地服务器上运行您的应用。
  </Step>
  <Step title={<a href="/langsmith/application-structure">配置部署应用</a>}>
    设置依赖项、项目结构和环境配置。
  </Step>
  <Step title={<a href="/langsmith/platform-setup">选择托管方式</a>}>
    （部署必需）选择云端 (Cloud)、混合 (Hybrid) 或自托管 (Self-hosted)。
  </Step>
  <Step title="部署您的应用">
    - [**云端部署**](/langsmith/deploy-to-cloud)：从 Git 仓库推送代码
    - [**混合或带控制平面的自托管部署**](/langsmith/deploy-with-control-plane)：构建并推送 Docker 镜像，通过 UI 进行部署
    - [**独立服务器部署**](/langsmith/deploy-standalone-server)：无需控制平面直接部署
  </Step>
  <Step title={<a href="/langsmith/observability">监控与管理</a>}>
    跟踪追踪 (traces)、警报和仪表板。
  </Step>
</Steps>

## 您将学到什么

- 配置您的[应用以进行部署](/langsmith/application-structure)（依赖项、[项目设置](/langsmith/setup-app-requirements-txt) 和 [Monorepo 支持](/langsmith/monorepo-support)）。
- 构建、部署和更新 [Agent Server](/langsmith/agent-server)。
- 使用[身份验证和访问控制](/langsmith/auth)来保护您的部署。
- 自定义您的服务器运行时（[生命周期钩子](/langsmith/custom-lifespan)、[中间件](/langsmith/custom-middleware) 和 [路由](/langsmith/custom-routes)）。
- 使用 [Studio UI](/langsmith/studio) 调试、观察和排查已部署的 Agent。
