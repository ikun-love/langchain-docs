LangSmith 提供了使用功能标志（feature flags）的用户管理附加自定义功能。

## 功能

### 工作区级别的组织邀请

LangSmith 的默认行为要求用户必须是“组织管理员”（Organization Admin）才能邀请新用户加入组织。对于希望将此权限委托给工作区管理员的自托管客户，可以设置一个功能标志，该标志允许工作区管理员邀请新用户加入组织，并将其添加到他们特定的工作区，这些邀请操作是**在工作区级别**进行的。

一旦通过下面的配置选项启用了此功能，工作区管理员就可以在 `设置` > `工作区` 下的 `工作区成员` 选项卡中添加新用户。在工作区级别邀请时，支持以下两种情况，而组织级别的邀请功能保持不变：

1. 邀请**尚未**在组织中激活的用户：这将以待定状态（pending）将用户添加到组织和特定工作区。
2. 邀请**已经**在组织中激活的用户：用户将直接以活跃成员的身份添加到工作区（没有待定状态）。

管理员可以同时邀请上述两种情况的用户。

#### 配置

<CodeGroup>

```yaml Helm
config:
  workspaceScopeOrgInvitesEnabled: true
```

```bash Docker
# 在您的 .env 文件中
WORKSPACE_SCOPE_ORG_INVITES_ENABLED="true"
```

</CodeGroup>

### SSO 新成员登录流程

从 Helm **v0.11.10** 版本开始，使用 OAuth SSO 的自托管部署不再需要在 LangSmith 设置中手动添加成员以便他们加入。部署将拥有一个**默认**组织，新用户在首次登录 LangSmith 时将自动添加到该组织。

对于您的**默认**组织，您可以设置新成员被分配到哪个工作区以及分配什么工作区角色。对于**非默认**组织，邀请流程保持不变。一旦用户加入了组织，除默认组织设置之外对其工作区或角色的任何更改，必须通过 LangSmith 设置（和以前一样）或通过 SCIM 进行管理。
<Note>
默认情况下，所有新用户都将以 **工作区编辑者**（Workspace Editor）的角色添加到组织最初配置的工作区（默认情况下为 **工作区 1**）。
</Note>
![更新 SSO 成员设置](/langsmith/images/sso-member-settings-update.png)

<Note>
要更改您的默认组织，请使用组织选择器下拉菜单中的 **设置默认组织**（Set Default Organization）。（在源组织和目标组织中都需要组织管理员权限。）
</Note>


### 禁止创建组织

默认情况下，任何用户都可以在 LangSmith 中创建组织。对于自托管客户，在设置初始组织后，管理员可能希望限制此功能。此功能标志允许管理员禁用用户创建新组织的能力。

#### 配置

<Note>
对于使用 [基本身份验证](/langsmith/self-host-basic-auth) 或 [SSO](/langsmith/self-host-sso) 的组织，`userOrgCreationDisabled` 功能标志默认设置为 `true`。
</Note>
<CodeGroup>

```yaml Helm
config:
  userOrgCreationDisabled: true
```

```bash Docker
# 在您的 .env 文件中
FF_ORG_CREATION_DISABLED="true"
```

</CodeGroup>

### 禁止创建个人组织

默认情况下，任何登录 LangSmith 的用户都会为其创建一个个人组织。对于自托管客户，管理员可能希望限制此能力。此功能标志允许管理员禁用用户创建个人组织的能力。

#### 配置

<Note>
对于使用 [基本身份验证](/langsmith/self-host-basic-auth) 或 [SSO](/langsmith/self-host-sso) 的组织，`personalOrgsDisabled` 功能标志默认设置为 `true`。
</Note>

<CodeGroup>

```yaml Helm
config:
  personalOrgsDisabled: true
```

```bash Docker
# 在您的 .env 文件中
PERSONAL_ORGS_DISABLED="true"
```

</CodeGroup>
