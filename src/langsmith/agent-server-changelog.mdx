[Agent Server](/langsmith/agent-server) 是一个用于创建和管理基于 Agent 的应用的 API 平台。它内置了持久化存储、任务队列，并支持大规模部署、配置和运行助手（Agentic 工作流）。本更新日志记录了 Agent Server 版本发布中的所有重要更新、新特性和修复。

## v0.5.0

此次小版本更新要求 `langgraph-checkpoint` 版本高于 3.0，以防止早期 `langgraph-checkpoint` 库中存在的反序列化漏洞。
`langgraph-checkpoint` 库兼容 `langgraph` 的小版本 0.4、0.5、0.6 和 1.0。

此版本移除了对使用“json”类型保存的有效载荷的反序列化的默认支持，该类型从未是默认值。
默认情况下，对象使用 msgpack 进行序列化。在某些不常见的情况下，有效载荷是使用较旧的“json”模式序列化的。如果这些有效载荷包含自定义 Python 对象，除非您提供 `serde` 配置，否则它们将不再可反序列化：

```json
{
    "checkpointer": {
        "serde": {
            "allowed_json_modules": [
                ["my_agent", "my_file", "SomeType"],
            ]
        }
    }
}
```

## v0.4.0

小版本 0.4 带来了多项改进以及一些破坏性变更。

- 在线程流中正确发出了尝试消息（attempt messages）。
- 通过在集群映射中使用线程 ID 进行哈希处理（优先使用 `stream_thread_cache` 提高效率），减少了集群冲突。
- 引入了线程的流式端点，用于跟踪顺序执行的运行中的所有输出。
- 使 PostgreSQL 中过滤查询构建器对格式错误的表达式更加稳健，并改进了验证以防止潜在的安全风险。

此小版本还包含几项破坏性变更，以提高服务的可用性和安全性：
