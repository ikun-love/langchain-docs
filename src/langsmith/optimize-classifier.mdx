本教程将指导您根据用户反馈来优化分类器。分类器非常适合优化，因为通常很容易收集到期望的输出，这使得根据用户反馈创建“少样本示例”（few-shot examples）变得容易。这正是我们将在本示例中要做的事情。

## 目标

在本示例中，我们将构建一个机器人，根据 GitHub Issue 的标题对其进行分类。它将接收一个标题，并将其分类到多个不同类别中的一个。然后，我们将开始收集用户反馈，并利用这些反馈来影响分类器的性能。

## 开始使用

首先，我们将进行设置，以便将所有跟踪（traces）发送到特定的项目。我们可以通过设置环境变量来实现这一点：

```python
import os
os.environ["LANGSMITH_PROJECT"] = "classifier"
```

然后，我们可以创建初始应用程序。这将是一个非常简单的函数，它只接收一个 GitHub Issue 标题并尝试对其进行标记。

```python
import openai
from langsmith import traceable, Client
import uuid

client = openai.Client()

available_topics = [
    "bug",
    "improvement",
    "new_feature",
    "documentation",
    "integration",
]

prompt_template = """Classify the type of the issue as one of {topics}.
Issue: {text}"""

@traceable(
    run_type="chain",
    name="Classifier",
)
def topic_classifier(
    topic: str):
    return client.chat.completions.create(
        model="gpt-4o-mini",
        temperature=0,
        messages=[
            {
                "role": "user",
                "content": prompt_template.format(
                    topics=','.join(available_topics),
                    text=topic,
                )
            }
        ],
    ).choices[0].message.content
```

然后我们可以开始与它交互。在交互时，我们将提前生成 LangSmith 的运行 ID (run id)，并将其传递给此函数。我们这样做是为了稍后能够附加反馈。

以下是我们如何调用应用程序：

```python
from langsmith import uuid7

run_id = uuid7()
topic_classifier(
    "fix bug in LCEL",
    langsmith_extra={"run_id": run_id})
```

以下是我们如何附加反馈：我们可以收集两种形式的反馈。

首先，我们可以收集“正面”反馈（positive feedback）——这适用于模型判断正确的示例。

```python
ls_client = Client()
run_id = uuid7()
topic_classifier(
    "fix bug in LCEL",
    langsmith_extra={"run_id": run_id})
ls_client.create_feedback(
    run_id,
    key="user-score",
    score=1.0,
)
```

接下来，我们可以专注于收集与生成结果“更正”（correction）相对应的反馈。在这个例子中，模型会将它分类为 `bug`（错误），而我实际上希望它被分类为 `documentation`（文档）。

```python
ls_client = Client()
run_id = uuid7()
topic_classifier(
    "fix bug in documentation",
    langsmith_extra={"run_id": run_id})
ls_client.create_feedback(
    run_id,
    key="correction",
    correction="documentation")
```

## 设置自动化

我们现在可以设置自动化流程，将带有某种形式反馈的示例移到一个数据集中。我们将设置两个自动化流程：一个用于正面反馈，另一个用于负面反馈（更正）。

第一个流程将获取所有带有正面反馈的运行，并自动将它们添加到数据集中。背后的逻辑是，任何带有正面反馈的运行，我们都可以在未来的迭代中将其用作一个好的示例。让我们创建一个名为 `classifier-github-issues` 的数据集来添加这些数据。

![Optimization Negative](/langsmith/images/class-optimization-neg.png)

第二个流程将获取所有带有更正的运行，并使用 Webhook 将它们添加到数据集中。创建此 Webhook 时，我们将选择“使用更正”（Use Corrections）选项。此选项将确保在从运行创建数据集时，它不会使用运行的输出来作为数据点的黄金标准（gold-truth），而是使用 `correction` 中提供的值。

![Optimization Positive](/langsmith/images/class-optimization-pos.png)

## 更新应用程序

我们现在可以更新代码，以下载我们正在向其发送运行的数据集。下载数据集后，我们可以创建一个包含这些示例的字符串。然后，我们可以将此字符串作为提示（prompt）的一部分！

```python
### NEW CODE ###
# 初始化 LangSmith 客户端，以便我们可以获取数据集
ls_client = Client()

# 创建一个函数，它接收一个示例列表并将其格式化为字符串
def create_example_string(examples):
    final_strings = []
    for e in examples:
        final_strings.append(f"Input: {e.inputs['topic']}\n> {e.outputs['output']}")
    return "\n\n".join(final_strings)
### NEW CODE ###

client = openai.Client()

available_topics = [
    "bug",
    "improvement",
    "new_feature",
    "documentation",
    "integration",
]

prompt_template = """Classify the type of the issue as one of {topics}.

Here are some examples:
{examples}

Begin!
Issue: {text}
>"""

@traceable(
    run_type="chain",
    name="Classifier",
)
def topic_classifier(
    topic: str):
    # 我们现在可以从数据集中拉取示例
    # 我们在函数内部执行此操作，以便始终获取最新的示例，
    # 但为了速度，也可以在外部执行并缓存
    examples = list(ls_client.list_examples(dataset_name="classifier-github-issues"))  # <- New Code
    example_string = create_example_string(examples)
    return client.chat.completions.create(
        model="gpt-4o-mini",
        temperature=0,
        messages=[
            {
                "role": "user",
                "content": prompt_template.format(
                    topics=','.join(available_topics),
                    text=topic,
                    examples=example_string,
                )
            }
        ],
    ).choices[0].message.content
```

如果我们现在使用与之前类似的输入运行应用程序，我们可以看到它正确地学习到任何与文档相关的内容（即使存在错误）都应被分类为 `documentation`。

```python
ls_client = Client()
run_id = uuid7()
topic_classifier(
    "address bug in documentation",
    langsmith_extra={"run_id": run_id})
```

## 示例的语义搜索

我们可以做的另一件事是只使用语义上最相似的示例。当您开始积累大量示例时，这一点特别有用。

为了实现这一点，我们可以首先定义一个函数，用于查找 `k` 个最相似的示例：

```python
import numpy as np

def find_similar(examples, topic, k=5):
    inputs = [e.inputs['topic'] for e in examples] + [topic]
    vectors = client.embeddings.create(input=inputs, model="text-embedding-3-small")
    vectors = [e.embedding for e in vectors.data]
    vectors = np.array(vectors)
    # 计算查询向量与所有输入向量的点积，排除最后一个（即查询本身），然后排序
    args = np.argsort(-vectors.dot(vectors[-1])[:-1])[:5]
    examples = [examples[i] for i in args]
    return examples
```

然后我们可以在应用程序中使用它：

```python
ls_client = Client()

def create_example_string(examples):
    final_strings = []
    for e in examples:
        final_strings.append(f"Input: {e.inputs['topic']}\n> {e.outputs['output']}")
    return "\n\n".join(final_strings)

client = openai.Client()

available_topics = [
    "bug",
    "improvement",
    "new_feature",
    "documentation",
    "integration",
]

prompt_template = """Classify the type of the issue as one of {topics}.

Here are some examples:
{examples}

Begin!
Issue: {text}
>"""

@traceable(
    run_type="chain",
    name="Classifier",
)
def topic_classifier(
    topic: str):
    examples = list(ls_client.list_examples(dataset_name="classifier-github-issues"))
    # 使用语义搜索找到最相似的示例
    examples = find_similar(examples, topic)
    example_string = create_example_string(examples)
    return client.chat.completions.create(
        model="gpt-4o-mini",
        temperature=0,
        messages=[
            {
                "role": "user",
                "content": prompt_template.format(
                    topics=','.join(available_topics),
                    text=topic,
                    examples=example_string,
                )
            }
        ],
    ).choices[0].message.content
```
