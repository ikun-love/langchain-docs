当您在自动化操作中添加一个 Webhook URL 时，任何匹配您定义的规则的新运行发生时，系统都会向您的 Webhook 端点发送一个 POST 请求。

![](/langsmith/images/webhook.png)

## Webhook Payload（负载）

我们发送到您的 Webhook 端点的负载（Payload）包含以下内容：

- `"rule_id"`: 这是发送此负载的自动化学的的 ID。
- `"start_time"` 和 `"end_time"`: 这是我们发现匹配运行的时间边界。
- `"runs"`: 这是一个运行（run）的数组，其中每个运行都是一个字典。如果您需要关于每个运行的更多信息，我们建议您在端点中使用我们的 SDK 从 API 中获取这些详细信息。
- `"feedback_stats"`: 这是一个包含反馈统计信息的字典。这个字段的一个示例负载如下所示。

```json
"feedback_stats": {
    "about_langchain": {
        "n": 1,

        "values": {}
    },

        "n": 0,
        "avg": null,

            "CONCEPTUAL": 1
```

<Note>
**从 S3 URL 的数据获取**

根据您的运行时间的新旧程度，`inputs_s3_urls` 和 `outputs_s3_urls` 字段可能包含指向实际数据的 S3 URL，而不是数据本身。

`inputs` 和 `outputs` 可以分别通过 `inputs_s3_urls` 和 `outputs_s3_urls` 中提供的 `ROOT.presigned_url` 来获取。
</Note>

## 安全性 (Security)

我们强烈建议您向 Webhook URL 添加一个密钥查询字符串参数（secret query string parameter），并在接收到任何传入请求时进行验证。这样做可以确保即使有人发现了您的 Webhook URL，您也能将这些调用与真实的 Webhook 通知区分开来。

一个示例如下：

```
https://api.example.com/langsmith_webhook?secret=38ee77617c3a489ab6e871fbeb2ec87d
```

### Webhook 自定义 HTTP Headers

如果您希望在 Webhook 中发送任何特定的 Header，可以为每个 URL 进行配置。要设置此项，请点击 URL 字段旁边的 `Headers` 选项，然后添加您的 Header。

<Note>
Header 会以加密形式存储。
</Note>

![](/langsmith/images/webhook-headers.png)

### Webhook 投递 (Delivery)

当我们向您的 Webhook 端点投递事件时，遵循以下指南：

- 如果我们无法连接到您的端点，我们将重试传输连接最多 2 次后，宣告投递失败。
- 如果您的端点回复时间超过 5 秒，我们将宣告投递失败，并且不会继续。
- 如果您的端点在 5 秒内返回 5xx 状态码，我们将使用指数退避（exponential backoff）重试最多 2 次。
- 如果您的端点返回 4xx 状态码，我们将宣告投递失败，并且不会重试。
- 您的端点在响应体（body）中返回的任何内容都将被忽略。

## 使用 Modal 的示例

### 设置

为了演示如何进行设置，我们将使用 [Modal](https://modal.com/)。Modal 为推理和微调提供自动扩展的 GPU，为代码代理提供安全的容器化，以及提供无服务器的 Python Web 端点。在这里，我们将重点关注 Web 端点。

首先，创建一个 Modal 账户。然后在本地安装 Modal SDK：

<CodeGroup>
```bash pip
pip install modal
```

```bash uv
uv add modal
```
</CodeGroup>

要完成账户设置，请运行以下命令：

```shell
modal setup
```

并按照指示操作。

### 密钥 (Secrets)

接下来，您需要在 Modal 中设置一些密钥（Secrets）。

首先，LangSmith 需要通过传递一个密钥来进行身份验证。最简单的方法是通过查询参数传递一个密钥。为了验证此密钥，我们需要在 *Modal* 中添加一个密钥来进行验证。我们将通过创建一个 Modal 密钥来实现。有关密钥的说明，您可以参阅 [此处](https://modal.com/docs/guide/secrets)。为此目的，我们称我们的密钥为 `ls-webhook`，并让它设置一个名为 `LS_WEBHOOK` 的环境变量。

我们也可以设置一个 LangSmith 密钥——幸运的是，这已经有一个集成模板可供使用了！

![LangSmith Modal Template](/langsmith/images/modal-langsmith-secret.png)

### 服务 (Service)

之后，您可以创建一个 Python 文件作为您的端点服务。下面是一个示例，其中包含解释代码逻辑的注释：

```python
from fastapi import HTTPException, status, Request, Query
from modal import Secret, Stub, web_endpoint, Image

stub = Stub("auth-example", image=Image.debian_slim().pip_install("langsmith"))


@stub.function(
    secrets=[Secret.from_name("ls-webhook"), Secret.from_name("my-langsmith-secret")]
)
# 我们希望这是一个 `POST` 端点，因为我们将向其 POST 数据
@web_endpoint(method="POST")
# 我们设置一个 `secret` 查询参数
def f(data: dict, secret: str = Query(...)):
    # 您可以在 Modal 函数内部导入您本地没有的依赖项
    from langsmith import Client

    # 首先，我们验证我们传入的密钥
    import os

    if secret != os.environ["LS_WEBHOOK"]:
        raise HTTPException(
            status_code=status.HTTP_401_UNAUTHORIZED,
            detail="Incorrect bearer token",
            headers={"WWW-Authenticate": "Bearer"},
        )

    # 这是我们放置此 Webhook 内部应发生逻辑的地方
    ls_client = Client()
    runs = data["runs"]
    ids = [r["id"] for r in runs]
    feedback = list(ls_client.list_feedback(run_ids=ids))
    for r, f in zip(runs, feedback):
        try:
            ls_client.create_example(
                inputs=r["inputs"],
                outputs={"output": f.correction},
                dataset_name="classifier-github-issues",
            )
        except Exception:
            raise ValueError(f"{r} and {f}")
    # 函数体
    return "success!"
```

我们现在可以轻松地使用 `modal deploy ...` 进行部署（请参阅 [此处](https://modal.com/docs/guide/managing-deployments) 的文档）。

您现在应该会看到类似以下内容：

```

└── 🔨 Created f => https://hwchase17--auth-example-f.modal.run
✓ App deployed! 🎉
```

要记住的重要信息是 `https://hwchase17--auth-example-f.modal.run` —— 这是我们创建用于运行的函数。请注意：**这不是最终的部署 URL**，请确保不要意外使用它。

### 连接 Webhook

我们现在可以获取上面创建的函数 URL 并将其添加为 Webhook。我们还必须记得将密钥作为查询参数传递。将所有内容放在一起，它应该看起来像这样：

```
https://hwchase17--auth-example-f-dev.modal.run?secret={SECRET}
```

将 `{SECRET}` 替换为您创建的用于访问 Modal 服务的密钥。
