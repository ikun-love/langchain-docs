要开始使用 LangSmith，您需要创建一个账户。您可以在 [LangSmith UI](https://smith.langchain.com) 上注册一个免费账户。LangSmith 支持使用 Google、GitHub 和电子邮件进行登录。

![Create account](/langsmith/images/create-account.png)

## API 密钥

LangSmith 支持两种类型的 API 密钥：**服务密钥 (Service Keys)** 和 **个人访问令牌 (Personal Access Tokens)**。这两种类型的令牌都可以用于对 LangSmith API 请求进行身份验证，但它们的使用场景不同。

关于服务密钥和个人访问令牌的更多详细信息，请参阅 [管理概览页面](/langsmith/administration-overview)。

## 创建 API 密钥

为了将追踪记录 (traces) 日志记录到 LangSmith 并运行评估，您需要创建一个 API 密钥来验证您的请求。API 密钥可以限定在特定的 [工作区 (workspaces)](/langsmith/administration-overview#workspaces) 集合范围内，或者限定在整个 [组织 (organization)](/langsmith/administration-overview#organizations) 范围内。

要创建任一类型的 API 密钥，请执行以下步骤：

1. 导航到 [设置页面](https://smith.langchain.com/settings)，然后滚动到 **API Keys** 部分。
1. 对于服务密钥，需要在组织范围的密钥和工作区范围的密钥之间进行选择。如果选择工作区范围的密钥，则后续必须指定相应的工作区。

    企业版用户还可以 [为密钥分配特定角色](/langsmith/administration-overview#workspace-roles-rbac)，这会相应地调整其权限。
1. 设置密钥的过期时间；选择天数后，密钥将在该时间后失效，或者选择“永不过期”。
1. 点击 **Create API Key**。

<Note>
API 密钥只会显示**一次**，请务必复制它并将其安全地存储起来。
</Note>

![Create API key](/langsmith/images/create-api-key.png)

## 删除 API 密钥

要删除 API 密钥：

1. 导航到 [设置页面](https://smith.langchain.com/settings)，然后滚动到 **API Keys** 部分。
1. 在表格中找到您需要删除的 API 密钥。根据需要切换 **Personal** 或 **Service** 选项。
1. 在 **Actions** 列中选择垃圾桶图标 <Icon icon="trash" iconType="solid"/>，然后确认删除。

## 配置 SDK

除了 `LANGSMITH_API_KEY` 之外，您还可以设置以下环境变量。

仅在使用欧盟 (EU) 实例时才需要此设置。

`LANGSMITH_ENDPOINT=https://eu.api.smith.langchain.com`

仅当密钥的作用域限定于一个以上的工作区时，才需要此设置。

`LANGSMITH_WORKSPACE_ID=<Workspace ID>`
