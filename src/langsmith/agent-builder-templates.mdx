Agent Builder 包含入门模板，可帮助您快速创建智能体（Agent）。这些模板为常见的用例预定义了系统提示词（System Prompts）、工具以及（在适用情况下）触发器。您可以直接使用这些模板，也可以将其作为基线进行自定义修改。

## 如何使用模板

<Steps>
  <Step title="选择一个模板" icon="squares-plus">
    在 Agent Builder 中，选择一个与您的用例相匹配的模板（例如：Gmail 助手、Linear Slack 机器人等）。
  </Step>
  <Step title="检查工具和提示词" icon="sliders">
    每个模板都带有一个初始的系统提示词和一组工具。请检查这些工具和提示词，以确保它们符合您的需求（您可以稍后编辑它们，或者让智能体为您编辑）。
  </Step>
  <Step title="克隆并认证" icon="key">
    点击右上角的 `Clone Template` 开始克隆过程。如果您尚未对模板中的工具进行 OAuth 认证，系统将提示您完成认证。
  </Step>
  <Step title="添加触发器（可选）" icon="clock">
    如果模板包含触发器，系统将提示您：
    - 如果您是首次使用，则对触发器进行认证和设置
    或
    - 从下拉列表中选择一个现有的触发器
  </Step>
  <Step title="测试和迭代" icon="rocket">
    运行智能体，检查输出结果，并优化提示词或工具。要编辑您克隆的智能体，您可以手动进行更改，或者要求智能体为您进行更改！
  </Step>
</Steps>

<Note icon="sliders" color="#E9D5FF" iconType="regular">
  模板只是一个起点。您可以随时自定义提示词、添加或删除工具、附加触发器以及切换模型。
</Note>
