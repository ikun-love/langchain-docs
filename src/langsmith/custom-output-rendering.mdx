自定义输出渲染允许您使用自己的 HTML 页面来可视化运行的输出（run outputs）和数据集引用输出（dataset reference outputs）。这在以下场景中特别有用：

-   **特定领域格式化**：以其原生格式 [native format] 显示医疗记录、法律文件或其他专业数据类型。
-   **自定义可视化**：根据数值型或结构化的输出数据创建图表（charts）、图形（graphs）或示意图（diagrams）。

在本页中，您将了解如何：

-   在 LangSmith UI 中**配置自定义渲染**（`#configure-custom-output-rendering`）。
-   **构建自定义渲染器**（`#build-a-custom-renderer`）以展示输出数据。
-   **理解自定义渲染出现的位置**（`#where-custom-rendering-appears`）在 LangSmith 中。

## 配置自定义输出渲染

您可以在两个级别配置自定义渲染：

-   **针对数据集（For datasets）**：将自定义渲染应用于与该数据集关联的所有运行，无论它们出现在何处——实验（experiments）、运行详情窗格（run detail panes）还是标注队列（annotation queues）。
-   **针对标注队列（For annotation queues）**：将自定义渲染应用于特定标注队列中的所有运行，而忽略它们来自哪个数据集。此设置**优先于**数据集级别的配置。

### 针对跟踪项目（For tracing projects）

要为跟踪项目配置自定义输出渲染：

![Tracing project settings showing custom output rendering configuration](/langsmith/images/tracing-project-custom-output-rendering-settings.png)

1. 导航到 **跟踪项目（Tracing Projects）** 页面。
2. 点击现有的跟踪项目或创建一个新项目。
3. 在编辑跟踪项目窗格中，滚动到 **自定义输出渲染（Custom Output Rendering）** 部分。
4. 打开 **启用自定义输出渲染（Enable custom output rendering）** 的开关。
5. 在 **URL** 字段中输入网页的 URL。
6. 点击 **保存（Save）**。

### 针对数据集（For datasets）

要为数据集配置自定义输出渲染：

![Dataset page with three-dot menu showing Custom Output Rendering option](/langsmith/images/custom-output-rendering-menu.png)

1. 在 **数据集与实验（Datasets & Experiments）** 页面中导航到您的数据集。
2. 点击右上角的 **⋮**（三点菜单）。
3. 选择 **自定义输出渲染（Custom Output Rendering）**。
4. 打开 **启用自定义输出渲染（Enable custom output rendering）** 的开关。
5. 在 **URL** 字段中输入网页的 URL。
6. 点击 **保存（Save）**。

![Custom Output Rendering modal with fields filled in](/langsmith/images/custom-output-rendering-modal.png)

### 针对标注队列（For annotation queues）

要为标注队列配置自定义输出渲染：

![Annotation queue settings showing custom output rendering configuration](/langsmith/images/annotation-queue-custom-output-rendering-settings.png)

1. 导航到 **标注队列（Annotation Queues）** 页面。
2. 点击现有的标注队列或创建一个新的队列。
3. 在标注队列设置窗格中，滚动到 **自定义输出渲染（Custom Output Rendering）** 部分。
4. 打开 **启用自定义输出渲染（Enable custom output rendering）** 的开关。
5. 在 **URL** 字段中输入网页的 URL。
6. 点击 **保存（Save）** 或 **创建（Create）**。

<Info>当多个级别应用了自定义渲染设置时，其优先级顺序如下：标注队列 > 数据集 > 跟踪项目。</Info>

## 构建自定义渲染器

### 理解消息格式

您的 HTML 页面将通过 [postMessage API](https://developer.mozilla.org/en-US/docs/Web/API/Window/postMessage) 接收输出数据。LangSmith 发送的消息结构如下：

```typescript
{
  type: "output" | "reference",
  data: {
    // 实际的输出或引用输出
    // 结构根据您的应用程序而变化
  },
  metadata: {
    inputs: {
      // 生成此输出的输入数据，用于提供上下文
      // 结构根据您的应用程序而变化
    }
  }
}
```

-   `type`: 指示这是实际输出（`"output"`）还是引用输出（`"reference"`）。
-   `data`: 输出数据本身。
-   `metadata.inputs`: 生成此输出的输入数据，用于提供上下文信息。

<Note>**消息传递时机**：LangSmith 使用指数退避重试机制（exponential backoff retry mechanism）来确保即使您的页面加载缓慢，也能收到数据。消息最多发送 6 次，延迟时间递增（100ms、200ms、400ms、800ms、1600ms、3200ms）。</Note>

### 示例实现

此示例监听传入的 `postMessage` 事件并在页面上显示它们。每条消息都会被编号并格式化为 JSON，便于检查 LangSmith 发送到渲染器的 **数据结构**。

```html
<!DOCTYPE html>
<html>
    <head>
        <meta charset="UTF-8" />
        <title>PostMessage Echo</title>
        <link rel="stylesheet" href="https://unpkg.com/sakura.css/css/sakura.css" />
    </head>
    <body>
        <h1>PostMessage Messages</h1>
        <div id="messages"></div>
        <script>
            let count = 0;
            window.addEventListener("message", (event) => {
                count++;
                const header = document.createElement("h3");
                header.appendChild(document.createTextNode(`Message ${count}`));
                const code = document.createElement("code");
                code.appendChild(document.createTextNode(JSON.stringify(event.data, null, 2)));
                const pre = document.createElement("pre");
                pre.appendChild(code);
                document.getElementById("messages").appendChild(header);
                document.getElementById("messages").appendChild(pre);
            });
        </script>
    </body>
</html>
```

## 自定义渲染出现的位置

启用自定义渲染后，它将替换默认的输出视图，出现在以下位置：

-   **实验比较视图（Experiment comparison view）**：在跨多个实验比较输出时：

![Experiment comparison view showing custom rendering](/langsmith/images/custom-output-rendering-experiment-comparison.png)

-   **运行详情窗格（Run detail panes）**：查看与数据集关联的运行详情时：

![Run detail pane showing custom rendering](/langsmith/images/custom-output-rendering-run-details.png)

-   **标注队列（Annotation queues）**：在标注队列中审查运行时：

![Annotation queue showing custom rendering](/langsmith/images/custom-output-rendering-annotation-queue.png)
