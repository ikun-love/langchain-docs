**反馈 (Feedback)** 是 LangSmith 存储针对特定追踪 (trace) 或中间步骤 (span) 的评估标准和得分的一种方式。反馈可以通过多种方式生成，例如：

1. 从 LLM 应用中随追踪一起上传 [在此处](/langsmith/attach-user-feedback)。
2. 用户在应用中 [内联式地](/langsmith/annotate-traces-inline) 或在 [标注队列 (annotation queue)](/langsmith/annotation-queues) 中生成。
3. 由自动评估器在 [离线评估 (offline evaluation)](/langsmith/evaluate-llm-application) 期间生成。
4. 由 [在线评估器 (online evaluator)](/langsmith/online-evaluations) 生成。

反馈以包含以下字段的简单格式存储：

<FeedbackDataFields/>
