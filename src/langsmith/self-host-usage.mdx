本指南将引导您完成使用自托管 LangSmith 实例的过程。

<Info>
本指南假设您已经部署了一个自托管的 LangSmith 实例。如果您尚未部署，请参考 [Kubernetes 部署指南](/langsmith/kubernetes) 或 [Docker 部署指南](/langsmith/docker)。
</Info>

### 配置要与 LangSmith 配合使用的应用程序

LangSmith 使用单个 API 与 Hub 和 LangSmith 后端进行交互。

1. 部署完实例后，您可以通过 `http(s)://<host>` 访问 LangSmith UI。
2. LangSmith API 将可通过 `http(s)://<host>/api/v1` 访问。
3. LangSmith 控制平面将可通过 `http(s)://<host>/api-host` 访问。

要使用您的实例的 API，您需要在应用程序中设置以下环境变量：

```bash
LANGSMITH_ENDPOINT=http://<host>/api/v1
LANGSMITH_API_KEY=foo # 如果使用 OAuth，请设置为一个合法的 API 密钥
```

您也可以直接在 LangSmith SDK 客户端中配置这些变量：

```python
import langsmith
langsmith_client = langsmith.Client(
    api_key='<api_key>',
    api_url='http(s)://<host>/api/v1',
)
```

设置完上述配置后，您应该能够运行代码并将结果显示在您的自托管实例中。我们建议您运行 [*快速入门指南*](https://docs.smith.langchain.com/#quick-start) 以了解如何使用 LangSmith 的基本操作。

### 自签名证书

如果您为自托管的 LangSmith 实例使用了自签名证书，这可能会导致问题，因为 Python 带有自己的一套受信任证书，其中可能不包含您的自签名证书。要解决此问题，您可能需要使用 `truststore` 等工具将系统证书加载到您的 Python 环境中。

您可以按如下方式操作：

1. `pip install truststore`（或根据您使用的包管理器安装类似的工具）

然后，使用以下代码加载系统证书：

```python
import truststore
truststore.inject_into_ssl()
# 您的其余代码
import langsmith
langsmith_client = langsmith.Client(
    api_key='<api_key>',
    api_url='http(s)://<host>/api/v1',
)
```
