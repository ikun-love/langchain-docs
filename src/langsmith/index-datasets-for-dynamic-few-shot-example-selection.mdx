此功能处于公开测试阶段（open beta）。它仅适用于付费团队计划。如果您对启用此功能有任何疑问，请通过 [support.langchain.com](https://support.langchain.com) 联系支持团队。

配置您的数据集，以便您可以根据传入的请求搜索少样本（few shot）示例。

## 前提条件

1. 您的数据集必须使用 KV 存储（Key-Value Store）数据类型（我们目前不支持聊天模型或 LLM 类型的数据集）。
2. 您必须为数据集定义一个输入 Schema。有关在 UI 中设置 Schema 验证的详细信息，请参阅我们在 [UI 中设置数据集 Schema 验证](/langsmith/manage-datasets-in-application#dataset-schema-validation) 的文档。
3. 您必须使用付费团队计划（例如 Plus 计划）。
4. 您必须在 LangSmith 云端（LangSmith cloud）。

## 为少样本搜索索引您的数据集

导航到数据集 UI，然后点击新的 `Few-Shot search`（少样本搜索）选项卡。点击 `Start sync`（开始同步）按钮，这将为您的数据集创建一个新索引，使其可被搜索。

![](/langsmith/images/few-shot-tab-unsynced.png)

默认情况下，我们同步到数据集的最新版本。这意味着当新示例添加到您的数据集中时，它们将自动添加到您的索引中。此过程每隔几分钟运行一次，因此新示例的索引延迟应该非常短。在下一节中，您可以在屏幕左侧的 `Few-shot index`（少样本索引）下查看您的索引是否是最新的。

## 在少样本 Playground 中测试搜索质量

现在您已经为数据集开启了索引功能，您将看到新的少样本 Playground 界面。

![](/langsmith/images/few-shot-synced-empty-state.png)

您可以输入一个示例文本（sample input），并查看我们的搜索 API 会返回哪些结果。

![](/langsmith/images/few-shot-search-results.png)

每个结果都会包含一个分数和一个指向数据集中该示例的链接。评分系统的工作方式是：0 表示完全随机的结果，分数越高表示相关性越好。结果将根据分数降序排列。

<Note>
搜索使用类似于 BM25 的算法来计算基于关键字的相似度分数。随着我们改进搜索算法，实际分数可能会发生变化，因此我们建议不要仅仅依赖分数本身，因为其含义可能会随时间演变。它们仅用于在 Playground 中方便地进行输出“氛围测试”（vibe-testing）。
</Note>

## 将少样本搜索添加到您的应用程序

点击上一个图中展示的 `Get Code Snippet`（获取代码片段）按钮，您将被带到一个包含不同语言的 LangSmith SDK 代码片段的屏幕。

![](/langsmith/images/few-shot-code-snippet.png)

对于在 LangChain Python 应用程序中使用少样本搜索的代码示例，请参阅我们在 LangChain 文档中的 [操作指南](https://python.langchain.com/v0.2/docs/how_to/example_selectors_langsmith/)。

### 代码片段

<Note>
请确保您使用的 Python SDK 版本 `>= 1.101` 或 TypeScript SDK 版本 `>= 1.43`。
</Note>

为了方便复制粘贴，您可以在此处找到与截图中代码片段相似的代码：

<CodeGroup>

```python Python (Async)
import langsmith as ls
# 从 LangSmith UI 复制此值
dataset_id = "1c5e9c95-dfd4-4dc5-a4b8-df7ea921c913"
async with ls.AsyncClient() as client:
  examples = await client.similar_examples(
      {"question": "knock knock"}, dataset_id=dataset_id, limit=1
  )
  print(examples[0].outputs)  # {"output": "Few shots'll do the trick."}
```

```python Python
from langsmith import Client
client = Client()
# 从 LangSmith UI 复制此值
dataset_id = "1c5e9c95-dfd4-4dc5-a4b8-df7ea921c913"
examples = client.similar_examples(
  {"question": "knock knock"}, dataset_id=dataset_id, limit=1
)
print(examples[0].outputs)
# {"output": "Few shots'll do the trick."}
```

```typescript TypeScript
import { Client } from "langsmith";
const client = new Client();
// 从 LangSmith UI 复制此值
const dataset_id = "1c5e9c95-dfd4-4dc5-a4b8-df7ea921c913";
const examples = await client.similarExamples({question: "knock knock"}, dataset_id, 1);
console.log(examples[0].outputs);
// {output: "Few shots'll do the trick."}
```
