LangSmith 可以使用 OpenTelemetry 仪器（instrumentation）来捕获 [Pipecat](https://pipecat.ai/) 中生成的追踪（traces）。本指南将向您展示如何自动捕获来自 Pipecat 语音 AI 管道的追踪，并将它们发送到 LangSmith 进行监控和分析。

如需完整的实现代码，请参阅 [演示代码仓库](https://github.com/langchain-ai/voice-agents-tracing)。

## 安装

安装所需的软件包：

<CodeGroup>

```bash pip
pip install langsmith "pipecat-ai[whisper,openai,local]" opentelemetry-exporter-otlp python-dotenv
```

```bash uv
uv add langsmith "pipecat-ai[whisper,openai,local]" opentelemetry-exporter-otlp python-dotenv
```

</CodeGroup>

<Info>
如果您计划使用高级音频录制功能，还需要安装：`pip install scipy numpy`
</Info>

## 快速开始教程

请遵循此分步教程，使用 Pipecat 和 LangSmith 追踪功能创建一个语音 AI 代理。您将通过复制和粘贴代码片段来构建一个完整可运行的示例。

### 第 1 步：设置您的环境

在您的项目目录下创建一个 `.env` 文件：

```bash .env
OTEL_EXPORTER_OTLP_ENDPOINT=https://api.smith.langchain.com/otel
OTEL_EXPORTER_OTLP_HEADERS=x-api-key=<your-langsmith-api-key>, Langsmith-Project=pipecat-voice
OPENAI_API_KEY=<your-openai-api-key>
```

### 第 2 步：下载 Span 处理器

添加 [自定义 Span 处理器文件](https://github.com/langchain-ai/voice-agents-tracing/blob/main/pipecat/langsmith_processor.py)，该文件启用了 LangSmith 追踪功能。将其保存为 `langsmith_processor.py` 在您的项目目录中。

<Accordion title="Span 处理器是做什么的？">

Span 处理器会使用与 LangSmith 兼容的属性来丰富 Pipecat 的 OpenTelemetry Span，以确保您的追踪在 LangSmith 中正确显示。

**主要功能:**
- 将 Pipecat 的 Span 类型（stt, llm, tts, turn, conversation）转换为 LangSmith 格式。
- 为消息可视化添加 `gen_ai.prompt.*` 和 `gen_ai.completion.*` 属性。
- 跟踪和聚合跨轮次的对话消息。
- 处理音频文件附件（用于高级用法）。

当您在代码中导入该处理器时，它会自动激活。

</Accordion>

### 第 3 步：创建您的语音代理文件

创建一个名为 `agent.py` 的新文件，并添加以下代码。我们将分段构建它，以便您可以复制和粘贴每个部分。

#### 第 1 部分：导入依赖项

```python
import asyncio
import uuid
from dotenv import load_dotenv

# 加载环境变量
load_dotenv()

# 导入 Pipecat 组件
from pipecat.audio.vad.silero import SileroVADAnalyzer
from pipecat.pipeline.pipeline import Pipeline
from pipecat.pipeline.runner import PipelineRunner
from pipecat.pipeline.task import PipelineParams, PipelineTask
from pipecat.processors.aggregators.openai_llm_context import OpenAILLMContext
from pipecat.services.whisper.stt import WhisperSTTService
from pipecat.services.openai import OpenAILLMService, OpenAITTSService
from pipecat.transports.local.audio import LocalAudioTransport, LocalAudioTransportParams

# 导入 Span 处理器以启用 LangSmith 追踪
from langsmith_processor import span_processor
```

#### 第 2 部分：定义主函数

```python
async def main():
    # 为 LangSmith 生成唯一的对话 ID
    conversation_id = str(uuid.uuid4())
    print(f"Starting conversation: {conversation_id}")

    # 使用语音活动检测（VAD）配置音频输入/输出
    transport = LocalAudioTransport(
        LocalAudioTransportParams(
            audio_in_enabled=True,
            audio_out_enabled=True,
            vad_analyzer=SileroVADAnalyzer(),
        )
    )

    # 初始化 AI 服务
    stt = WhisperSTTService()
    llm = OpenAILLMService(model="gpt-4o-mini")
    tts = OpenAITTSService(voice="alloy")

    # 使用系统提示设置对话上下文
    context = OpenAILLMContext(
        messages=[
            {
                "role": "system",
                "content": "You are a helpful voice assistant. Keep responses concise and conversational."
            }
        ]
    )
    context_aggregator = llm.create_context_aggregator(context)

    # 构建处理管道
    pipeline = Pipeline([
        transport.input(),           # 捕获麦克风输入
        stt,                         # 语音转文本
        context_aggregator.user(),   # 将用户消息添加到上下文
        llm,                         # 生成 AI 回复
        tts,                         # 文本转语音
        transport.output(),          # 通过扬声器播放
        context_aggregator.assistant(),  # 将助手回复添加到上下文
    ])

    # 创建启用追踪的任务
    task = PipelineTask(
        pipeline,
        params=PipelineParams(enable_metrics=True),
        enable_tracing=True,
        enable_turn_tracking=True,
        conversation_id=conversation_id,
    )

    # 运行代理
    runner = PipelineRunner()
    await runner.run(task)
```

#### 第 3 部分：添加入口点

```python
if __name__ == "__main__":
    asyncio.run(main())
```

### 第 4 步：运行您的代理

运行您的语音代理：

```bash
python agent.py
```

通过麦克风与代理对话。所有追踪信息将自动出现在 LangSmith 中。以下是 LangSmith 中追踪的一个示例：[Pipecat 追踪示例](https://smith.langchain.com/public/07721f41-cd27-413e-bc79-90bd23b6807d/r)。

查看完整的 [agent.py 代码](https://github.com/langchain-ai/voice-agents-tracing/blob/main/pipecat/agent.py)。

## 高级用法

### 自定义元数据和标签

您可以使用 Span 属性向追踪中添加自定义元数据：

```python
from opentelemetry import trace

tracer = trace.get_tracer(__name__)

async def run_voice_session():
    with tracer.start_as_current_span("voice_conversation") as span:
        # 添加自定义元数据
        span.set_attribute("langsmith.metadata.session_type", "voice_assistant")
        span.set_attribute("langsmith.metadata.user_id", "user_123")
        span.set_attribute("langsmith.span.tags", "pipecat,voice-ai,stt-llm-tts")

        # 您的 Pipecat 管道代码放在此处
        task = PipelineTask(pipeline, enable_tracing=True)
        await task.queue_frames([TextFrame("Hello")])
```

### 录制和将音频附加到追踪

您可以捕获语音对话中的音频，并将其附加到 LangSmith 中的追踪上。这使您可以在收听转录内容和 AI 回复的同时，收听实际的音频。

#### 完整对话录制

请参阅 [AudioRecorder 实现](https://github.com/langchain-ai/voice-agents-tracing/blob/main/pipecat/audio_recorder.py)，它处理输入（麦克风）和输出（TTS）音频之间的采样率不匹配问题。

捕获从开始到结束的所有音频，并将其附加到对话 Span：

```python
from pathlib import Path
from datetime import datetime
from audio_recorder import AudioRecorder

# 设置录音目录
recordings_dir = Path(__file__).parent / "recordings"
recordings_dir.mkdir(exist_ok=True)
timestamp = datetime.now().strftime("%Y%m%d_%H%M%S")
recording_path = recordings_dir / f"conversation_{timestamp}.wav"

# 创建音频录制器
audio_recorder = AudioRecorder(str(recording_path))

# 注册到 Span 处理器，以便附加到对话 Span
span_processor.register_recording(
    conversation_id,
    str(recording_path),
    audio_recorder=audio_recorder
)

# 添加到您的管道中
pipeline = Pipeline([
    transport.input(),
    stt,
    context_aggregator.user(),
    llm,
    tts,
    audio_recorder,              # 将音频录制器添加到管道
    transport.output(),
    context_aggregator.assistant(),
])

# 运行管道
runner = PipelineRunner()
try:
    await runner.run(task)
finally:
    # 重要提示：在对话 Span 完成之前保存录音
    audio_recorder.save_recording()
```

#### 按轮次录制

请参阅 [TurnAudioRecorder 实现](https://github.com/langchain-ai/voice-agents-tracing/blob/main/pipecat/turn_audio_recorder.py)，它会分别捕获用户语音和 AI 回复的音频片段）。

捕获每个对话轮次的独立音频片段，将用户语音和 AI 回复保存为单独的文件：

```python
from turn_audio_recorder import TurnAudioRecorder

# 创建轮次音频录制器
turn_audio_recorder = TurnAudioRecorder(
    span_processor=span_processor,
    conversation_id=conversation_id,
    recordings_dir=recordings_dir,
    turn_tracker=None,  # 任务创建后设置
)

# 注册到 Span 处理器
span_processor.register_turn_audio_recorder(conversation_id, turn_audio_recorder)

# 添加到您的管道中
pipeline = Pipeline([
    transport.input(),
    stt,
    context_aggregator.user(),
    llm,
    tts,
    audio_recorder,              # 完整对话录制
    turn_audio_recorder,         # 按轮次音频片段
    transport.output(),
    context_aggregator.assistant(),
])

# 创建任务
task = PipelineTask(
    pipeline,
    params=PipelineParams(enable_metrics=True),
    enable_tracing=True,
    enable_turn_tracking=True,  # 按轮次音频录制所需
    conversation_id=conversation_id,
)

# 任务创建后连接轮次追踪器
if task.turn_tracking_observer:
    turn_audio_recorder.connect_to_turn_tracker(task.turn_tracking_observer)

# 运行管道
runner = PipelineRunner()
try:
    await runner.run(task)
finally:
    audio_recorder.save_recording()
```

## 故障排除

### Span 未出现在 LangSmith 中

如果追踪信息未显示在 LangSmith 中：

1. **验证环境变量**: 确保在 `.env` 文件中正确设置了 `OTEL_EXPORTER_OTLP_ENDPOINT` 和 `OTEL_EXPORTER_OTLP_HEADERS`。
2. **检查 API 密钥**: 确认您的 LangSmith API 密钥具有写入权限。
3. **验证导入**: 确保您是从 `langsmith_processor.py` 导入了 `span_processor`。
4. **检查 .env 加载**: 确保在导入 Pipecat 组件之前调用了 `load_dotenv()`。

### 消息未正确显示

如果对话消息未正确显示：

1. **检查 Span 处理器**: 确认 `langsmith_processor.py` 位于您的项目目录中并已正确导入。
2. **验证对话 ID**: 确保在 `PipelineTask` 中设置了唯一的 `conversation_id`。
3. **启用轮次追踪**: 确保在 `PipelineTask` 中设置了 `enable_turn_tracking=True`。

### 音频无法工作

如果麦克风或扬声器无法工作：

1. **检查权限**: 确保您的终端/IDE 具有麦克风访问权限。
2. **测试音频设备**: 验证您的麦克风和扬声器在其他应用程序中是否正常工作。
3. **VAD 设置**: 如果语音未被检测到，请尝试调整 `SileroVADAnalyzer()` 设置。
4. **检查服务**: 确保 OpenAI API 密钥有效，并且可以访问 Whisper 和 TTS 服务。

### 导入错误

如果您遇到导入错误：

1. **安装依赖项**: 运行 `pip install langsmith "pipecat-ai[whisper,openai,local]" opentelemetry-exporter-otlp python-dotenv`。
2. **检查 Python 版本**: 确保您使用的是 Python 3.9 或更高版本。
3. **验证 langsmith_processor**: 确保已下载 `langsmith_processor.py` 并且它与 `agent.py` 位于同一目录下。

### 性能问题

如果响应速度慢：

1. **使用更快的模型**: 将 LLM 切换为更快的模型，如 `gpt-4o-mini`（教程中已包含）。
2. **检查网络**: 确保有稳定的互联网连接以进行 API 调用。
3. **本地 STT**: 考虑使用本地 Whisper 而不是基于 API 的服务。
