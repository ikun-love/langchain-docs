LangSmith 允许您直接在 UI 中运行评估。 **[Prompt Playground（提示词游乐场）](/langsmith/prompt-engineering#prompt-playground)** 使您可以在一系列输入上测试您的提示词或模型配置，以查看它在不同上下文或场景下的得分情况，而无需编写任何代码。

在运行评估之前，您需要有一个 [现有数据集](/langsmith/evaluation-concepts#datasets)。了解如何 [从 UI 创建数据集](/langsmith/manage-datasets-in-application#set-up-your-dataset)。

如果您更喜欢使用代码运行实验，请访问 [使用 SDK 运行评估](/langsmith/evaluate-llm-application)。

![](/langsmith/images/playground-experiment.gif)

<Callout type="info" icon="bird">
**[Polly](/langsmith/polly)** 在游乐场中可用，可以帮助您在运行评估之前优化提示词。
</Callout>

## 在提示词游乐场中创建实验[​](#create-an-experiment-in-the-prompt-playground "Direct link to Create an experiment in the prompt playground")

1.  通过点击侧边栏中的 **Playground（游乐场）**，**导航到游乐场**。
2.  通过选择一个现有的已保存提示词或创建一个新提示词来**添加一个提示词**。
3.  从 **Test over dataset（在数据集上测试）** 下拉菜单中**选择一个数据集**。

*   请注意，数据集中输入的键（keys）必须与提示词的输入变量（input variables）相匹配。例如，在上面的视频中，所选数据集的输入包含键 `"blog"`，这与提示词的输入变量正确匹配。
*   提示词游乐场最多允许有 15 个输入变量。

4.  通过点击 **Start（开始）** 或 **CMD+Enter** 来**启动实验**。这将针对数据集中的所有示例运行该提示词，并在数据集详情页面中为该实验创建一个条目。我们建议在开始实验前将提示词提交（commit）到提示词中心（prompt hub），这样在回顾实验时可以轻松引用它。
5.  通过点击 **View full experiment（查看完整实验）** 来**查看完整结果**。这将带您进入实验详情页面，您可以在其中查看实验的结果。

## 为实验添加评估分数[​](#add-evaluation-scores-to-the-experiment "Direct link to Add evaluation scores to the experiment")

通过添加评估器（evaluators）来根据特定标准评估您的实验。使用 **+Evaluator（+评估器）** 按钮可以在游乐场中使用 LLM 充当裁判（LLM-as-a-judge）或自定义代码评估器。

要了解更多关于通过 UI 添加评估器的信息，请访问 [如何定义 LLM 充当裁判的评估器](/langsmith/llm-as-judge)。
