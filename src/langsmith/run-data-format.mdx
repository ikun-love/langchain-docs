LangSmith 以一种简单易于导出和导入的格式存储和处理追踪数据。

许多字段都是可选的，或者了解它们并不重要，但我们在此列出以确保完整性。**加粗**的字段是最重要的需要了解的。

| 字段名称 | 类型 | 描述 |
| :--- | :--- | :--- |
| **id** | UUID | Span 的唯一标识符。 |
| **name** | string | 与该运行关联的名称。 |
| **inputs** | object | 提供给该运行的输入映射或集合。 |
| **run\_type** | string | 运行的类型，例如 "llm"（大型语言模型）、"chain"（链式调用）或 "tool"（工具调用）。 |
| **start\_time** | datetime | 运行的开始时间。 |
| **end\_time** | datetime | 运行的结束时间。 |
| **extra** | object | 运行的任何额外信息。 |
| **error** | string | 如果运行发生错误，则为错误消息。 |
| **outputs** | object | 运行生成的输出映射或集合。 |
| **events** | array of objects | 与运行关联的事件对象列表。这对于启用流式传输执行的运行非常重要。 |
| **tags** | array of strings | 与运行关联的标签或标记。 |
| **trace\_id** | UUID | 运行所属追踪的唯一标识符。这通常也是追踪的根运行的 `id` 字段。 |
| **dotted\_order** | string | 层次结构的排序字符串。格式为：`run_start_time`Z`run_uuid`.`child_run_start_time`Z`child_run_uuid`... |
| **status** | string | 运行执行的当前状态，例如 "error"（错误）、"pending"（待处理）或 "success"（成功）。 |
| **child\_run\_ids** | array of UUIDs | 所有子运行的 ID 列表。 |
| **direct\_child\_run\_ids** | array of UUIDs | 此运行的直接子运行的 ID 列表。 |
| **parent\_run\_ids** | array of UUIDs | 所有父运行的 ID 列表。 |
| **feedback\_stats** | object | 此运行的反馈统计信息的聚合数据。 |
| **reference\_example\_id** | UUID | 与运行关联的参考示例的 ID。这通常只在评估运行时存在。 |
| **total\_tokens** | integer | 运行处理的 token 总数。 |
| **prompt\_tokens** | integer | 运行提示（prompt）中的 token 数量。 |
| **completion\_tokens** | integer | 运行完成（completion）中的 token 数量。 |
| **total\_cost** | decimal | 与处理该运行相关的总成本。 |
| **prompt\_cost** | decimal | 与提示部分相关的成本。 |
| **completion\_cost** | decimal | 与完成部分相关的成本。 |
| **first\_token\_time** | datetime | 模型输出的第一个 token 生成的时间。仅适用于 `run_type="llm"` 且启用了流式传输的运行。 |
| **session\_id** | string | 运行的会话标识符，也称为追踪项目 ID (tracing project ID)。 |
| **in\_dataset** | boolean | 指示该运行是否包含在数据集中。 |
| **parent\_run\_id** | UUID | 父运行的唯一标识符。 |
| execution\_order (deprecated) | integer | 此运行在追踪中执行的顺序（已弃用）。 |
| serialized | object | 如果适用，执行该运行的对象的序列化状态。 |
| manifest\_id (deprecated) | UUID | 与该 span 关联的清单 (manifest) 的标识符（已弃用）。 |
| manifest\_s3\_id | UUID | 清单的 S3 标识符。 |
| inputs\_s3\_urls | object | 输入的 S3 URL。 |
| outputs\_s3\_urls | object | 输出的 S3 URL。 |
| price\_model\_id | UUID | 应用到该运行的定价模型标识符。 |
| app\_path | string | 此运行在应用程序 (UI) 中的路径。 |
| last\_queued\_at | datetime | Span 最后一次排队的时间。 |
| share\_token | string | 用于共享对该运行数据访问权限的 token。 |

#### 什么是 `dotted_order`？

一个运行的 `dotted_order` 是一个可排序的键，它完全指定了该运行在追踪层次结构中的位置。

以上面的例子为例：

```python
import langsmith as ls

@ls.traceable
def grandchild():
    p("grandchild")

@ls.traceable
def child():
    grandchild()

@ls.traceable
def parent():
    child()
```

如果你打印出每个阶段的 ID，你可能会得到以下结果：

```python
parent	run_id=0e01bf50-474d-4536-810f-67d3ee7ea3e7	trace_id=0e01bf50-474d-4536-810f-67d3ee7ea3e7  parent_run_id=null	dotted_order=20240919T171648521691Z0e01bf50-474d-4536-810f-67d3ee7ea3e7
child	run_id=a8024e23-5b82-47fd-970e-f6a5ba3f5097	trace_id=0e01bf50-474d-4536-810f-67d3ee7ea3e7  parent_run_id=0e01bf50-474d-4536-810f-67d3ee7ea3e7	dotted_order=20240919T171648521691Z0e01bf50-474d-4536-810f-67d3ee7ea3e7.20240919T171648523407Za8024e23-5b82-47fd-970e-f6a5ba3f5097
grandchild	run_id=0ec6b845-18b9-4aa1-8f1b-6ba3f9fdefd6	trace_id=0e01bf50-474d-4536-810f-67d3ee7ea3e7  parent_run_id=a8024e23-5b82-47fd-970e-f6a5ba3f5097	dotted_order=20240919T171648521691Z0e01bf50-474d-4536-810f-67d3ee7ea3e7.20240919T171648523407Za8024e23-5b82-47fd-970e-f6a5ba3f5097.20240919T171648523563Z0ec6b845-18b9-4aa1-8f1b-6ba3f9fdefd6
```

注意以下几个不变的规则：

* `id` 等于 `dotted_order` 的最后 36 个字符（即最后一个 "Z" 之后的后缀）。例如，`grandchild` 中的 `0ec6b845-18b9-4aa1-8f1b-6ba3f9fdefd6`。
* `trace_id` 等于 `dotted_order` 中的第一个 UUID（即 `dotted_order.split('.')[0].split('Z')[1]`）。
* 如果存在 `parent_run_id`，它就是 `dotted_order` 中的倒数第二个 UUID。例如，`grandchild` 中的 `a8024e23-5b82-47fd-970e-f6a5ba3f5097`。
* 如果将 `dotted_order` 按点 (`.`) 分割，每个片段的格式都是 (`<run_start_time>Z<run_id>`)。
