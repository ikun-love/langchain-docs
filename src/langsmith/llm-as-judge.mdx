LLM 应用的评估可能具有挑战性，因为它们通常生成的是对话式文本，不存在唯一的正确答案。

本指南将向您展示如何使用 LangSmith SDK 或 UI 为[离线评估](/langsmith/evaluation-concepts#offline-evaluation)定义一个 LLM-as-a-judge 评估器。注意：要在生产跟踪中实时运行评估，请参阅[设置在线评估](/langsmith/online-evaluations#configure-llm-as-judge-evaluators)。

## SDK

### 预构建的评估器

预构建的评估器是设置评估的有用起点。有关如何将预构建评估器与 LangSmith 结合使用的信息，请参阅[预构建评估器](/langsmith/prebuilt-evaluators)。

### 创建您自己的 LLM-as-a-judge 评估器

为了完全控制评估器的逻辑，请创建您自己的 LLM-as-a-judge 评估器，并使用 LangSmith SDK（[Python](https://docs.smith.langchain.com/reference/python/reference) / [TypeScript](https://docs.smith.langchain.com/reference/js)）运行它。

需要 `langsmith>=0.2.0`

```python
from langsmith import evaluate, traceable, wrappers, Client
from openai import OpenAI
# 假设您已经安装了 pydantic
from pydantic import BaseModel

# 可选：包装 OpenAI 客户端以跟踪所有模型调用。
oai_client = wrappers.wrap_openai(OpenAI())

def valid_reasoning(inputs: dict, outputs: dict) -> bool:
    """使用 LLM 判断推理和答案是否一致。"""
    instructions = """
根据以下问题、答案和推理，判断答案的推理是否在逻辑上有效，并且与问题和答案保持一致。"""

    class Response(BaseModel):
        reasoning_is_valid: bool

    msg = f"问题: {inputs['question']}\n答案: {outputs['answer']}\n推理: {outputs['reasoning']}"
    response = oai_client.beta.chat.completions.parse(
        model="gpt-4o",
        messages=[{"role": "system", "content": instructions,}, {"role": "user", "content": msg}],
        response_format=Response
    )
    return response.choices[0].message.parsed.reasoning_is_valid

# 可选：添加 'traceable' 装饰器以跟踪此函数的输入/输出。
@traceable
def dummy_app(inputs: dict) -> dict:
    return {"answer": "嗯，我不确定", "reasoning": "我没有理解这个问题"}

ls_client = Client()
dataset = ls_client.create_dataset("big questions")
examples = [
    {"inputs": {"question": "宇宙将如何终结"}},
    {"inputs": {"question": "我们是孤独的吗"}},
]
ls_client.create_examples(dataset_id=dataset.id, examples=examples)

results = evaluate(
    dummy_app,
    data=dataset,
    evaluators=[valid_reasoning]
)
```

有关如何编写自定义评估器的更多信息，请参阅[此处](/langsmith/code-evaluator)。

## UI

### 预构建的评估器

预构建的评估器是设置评估时的有用起点。LangSmith UI 支持以下预构建评估器：

* **幻觉 (Hallucination)**：检测在事实层面上不正确的输出。需要一个参考输出。
* **正确性 (Correctness)**：检查与参考的语义相似性。
* **简洁性 (Conciseness)**：评估答案是否是对问题的简洁回应。
* **代码检查器 (Code checker)**：验证代码答案的正确性。

您可以在以下情况下配置这些评估器：

* 使用[ Playground](/langsmith/observability-concepts#prompt-playground) 运行评估时
* 作为数据集的一部分，以便[自动对实验运行评估](/langsmith/bind-evaluator-to-dataset)
* 运行[在线评估](/langsmith/online-evaluations#configure-llm-as-judge-evaluators)时

## 自定义您的 LLM-as-a-judge 评估器

为您的 LLM-as-a-judge 评估器的提示添加特定指令，并配置应将输入/输出/参考输出的哪些部分传递给评估器。

{/* ![playground-evaluator.gif](/langsmith/images/playground-evaluator.gif) */}

### 选择/创建评估器

* 在 Playground 或数据集中：选择 **+Evaluator** 按钮
* 在跟踪项目中：选择 **Add rules**，配置您的规则，然后选择 **Apply evaluator**

选择 **Create your own evaluator** 选项。或者，您可以从选择一个预构建的评估器并对其进行编辑开始。

### 配置评估器

#### Prompt（提示）

创建一个新提示，或从[提示中心](/langsmith/prompt-engineering-quickstart)选择一个现有提示。

* **创建您自己的提示**：在内联创建自定义提示。

* **从提示中心拉取提示**：使用 **Select a prompt** 下拉菜单从现有提示中进行选择。您不能直接在提示编辑器中编辑这些提示，但可以查看提示及其使用的 Schema。要进行更改，请在 Playground 中编辑提示并提交版本，然后将您的新提示引入评估器中。

#### Model（模型）

从提供的选项中选择所需的模型。

#### Mapping variables（变量映射）

使用变量映射来指示要从当前运行或示例传递到评估器提示中的变量。为了辅助变量映射，会提供一个示例（或运行）供您参考。单击提示中的变量，并使用下拉菜单将它们映射到输入、输出或参考输出的相关部分。

要添加提示变量，如果使用 Mustache 格式（默认），则键入带有双花括号 `{{prompt_var}}` 的变量；如果使用 f-string 格式，则键入带有单花括号 `{prompt_var}` 的变量。

您可以根据需要删除变量。例如，如果您正在评估简洁性等指标，通常不需要参考输出，因此可以删除该变量。

#### Preview（预览）

预览提示将显示使用右侧显示的参考运行和数据集示例格式化后的提示外观。

#### 通过少样本示例改进您的评估器

为了更好地使 LLM-as-a-judge 评估器与人类偏好保持一致，LangSmith 允许您收集[人类修正](/langsmith/create-few-shot-evaluators#make-corrections)来获取评估分数。启用此选择后，修正内容会自动作为少样本示例插入到您的提示中。

了解[如何设置少样本示例和进行修正](/langsmith/create-few-shot-evaluators)。

#### Feedback configuration（反馈配置）

反馈配置是您的 LLM-as-a-judge 评估器将用于评分的标准。可以将其视为评估器将依据的评分细则。分数将作为[反馈](/langsmith/observability-concepts#feedback)添加到运行或示例中。定义评估器的反馈：

1. **命名反馈键 (Name the feedback key)**：这是在查看评估结果时将显示的名称。名称在不同实验中应是唯一的。

2. **添加描述 (Add a description)**：描述反馈代表的内容。

3. **选择反馈类型 (Choose a feedback type)**：

* **布尔值 (Boolean)**：True/false 反馈。
* **分类 (Categorical)**：从预定义的类别中进行选择。
* **连续 (Continuous)**：在指定范围内进行数值评分。

在幕后，反馈配置会作为[结构化输出](https://python.langchain.com/docs/concepts/structured_outputs/)添加到 LLM-as-a-judge 提示中。如果您使用的是提示中心中的现有提示，则必须在配置评估器使用它**之前**向该提示添加输出 Schema。输出 Schema 中的每个顶级键都将被视为一个单独的反馈部分。

### 保存评估器

完成配置后，保存您的更改。
