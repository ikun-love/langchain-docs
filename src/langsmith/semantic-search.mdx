本指南说明了如何向部署的跨线程 [存储（store）](/oss/langgraph/persistence#memory-store) 中添加语义搜索功能，以便您的代理可以根据语义相似性搜索记忆（memories）和其他文档。

## 前提条件

* 一个部署（请参阅 [如何设置用于部署的应用程序](/langsmith/setup-app-requirements-txt)）以及有关 [托管选项](/langsmith/platform-setup) 的详细信息。
* 您的嵌入提供商（本例中为 OpenAI）的 API 密钥。
* `langchain >= 0.3.8`（如果您使用下面指定的字符串格式）。

## 步骤

1.  更新您的 `langgraph.json` 配置文件，以包含存储配置：

```json
{
    ...
    "store": {
        "index": {
            "embed": "openai:text-embedding-3-small",
            "dims": 1536,
            "fields": ["$"]
        }
    }
}
```

此配置：

*   使用 OpenAI 的 `text-embedding-3-small` 模型来生成嵌入（embeddings）。
*   将嵌入维度设置为 1536（与模型的输出相匹配）。
*   对存储数据中的所有字段进行索引（`["$"]` 表示索引所有内容，或者您可以指定特定字段，例如 `["text", "metadata.title"]`）。

2.  要使用上述的字符串嵌入格式，请确保您的依赖项中包含 `langchain >= 0.3.8`：

```toml
# 在 pyproject.toml 中
[project]
dependencies = [
    "langchain>=0.3.8"
]
```

或者，如果您使用的是 `requirements.txt`（[查看如何设置](/langsmith/setup-app-requirements-txt)）：

```
langchain>=0.3.8
```

## 用法

配置完成后，您就可以在 [节点（nodes）](/oss/langgraph/graph-api#nodes) 中使用语义搜索了。存储需要一个**命名空间元组（namespace tuple）**来组织记忆：

```python
def search_memory(state: State, *, store: BaseStore):
    # 使用语义相似性搜索存储
    # 命名空间元组有助于组织不同类型的记忆
    # 例如，("user_facts", "preferences") 或 ("conversation", "summaries")
    results = store.search(
        namespace=("memory", "facts"),  # 按类型组织记忆
        query="your search query",
        limit=3  # 要返回的结果数量
    )
    return results
```

## 自定义嵌入

如果您想使用自定义嵌入，可以将指向自定义嵌入函数的路径传递进去：

```json
{
    ...
    "store": {
        "index": {
            "embed": "path/to/embedding_function.py:embed",
            "dims": 1536,
            "fields": ["$"]
        }
    }
}
```

部署将查找指定路径中的函数。该函数**必须是异步的**，并且接受一个字符串列表：

```python
# path/to/embedding_function.py
from openai import AsyncOpenAI

client = AsyncOpenAI()

async def aembed_texts(texts: list[str]) -> list[list[float]]:
    """自定义嵌入函数，必须满足以下条件：
    1. 异步 (async)
    2. 接受一个字符串列表 (list of strings)
    3. 返回一个浮点数组列表 (list of float arrays，即嵌入向量)
    """
    response = await client.embeddings.create(
        model="text-embedding-3-small",
        input=texts
    )
    return [e.embedding for e in response.data]
```

## 通过 API 查询

您也可以使用 LangGraph SDK 查询存储。由于 SDK 使用异步操作：

```python
from langgraph_sdk import get_client

async def search_store():
    client = get_client()
    results = await client.store.search_items(
        ("memory", "facts"),
        query="your search query",
        limit=3  # 要返回的结果数量
    )
    return results

# 在异步上下文中使用
results = await search_store()
```
