运行大型评估作业时，一个常见问题是遇到来自模型提供商的第三方 API 速率限制。有几种方法可以应对速率限制。

## 使用 `langchain` 的速率限制器 (仅限 Python)

如果在应用程序或评估器中使用 `langchain` Python 聊天模型，可以向模型添加速率限制器，该限制器将对发送到模型提供商 API 的请求频率进行客户端控制，以避免速率限制错误。

```python
from langchain.chat_models import init_chat_model
from langchain_core.rate_limiters import InMemoryRateLimiter

rate_limiter = InMemoryRateLimiter(
    requests_per_second=0.1,  # <-- 非常慢！我们每 10 秒只能发出一个请求！！
    check_every_n_seconds=0.1,  # 每 100 毫秒唤醒一次，检查是否允许发出请求，
    max_bucket_size=10,  # 控制最大突发大小。
)

model = init_chat_model("gpt-4o", rate_limiter=rate_limiter)

def app(inputs: dict) -> dict:
    response = model.invoke(...)
    ...

def evaluator(inputs: dict, outputs: dict, reference_outputs: dict) -> dict:
    response = model.invoke(...)
    ...
```

有关如何配置速率限制器的更多信息，请参阅 [`langchain`](/oss/langchain/models#rate-limiting) 文档。

## 使用指数退避进行重试

处理速率限制错误的非常常见的方法是使用指数退避（exponential backoff）进行重试。使用指数退避进行重试意味着在每次重试之间等待时间（呈指数级）增加，并重复重试失败的请求。这会一直持续，直到请求成功或达到最大请求次数。

#### 使用 `langchain`

如果你正在使用 `langchain` 组件，可以通过 `.with_retry(...)` / `.withRetry()` 方法向所有模型调用添加重试功能：

<CodeGroup>

```python Python
from langchain import init_chat_model

model_with_retry = init_chat_model("gpt-4o-mini").with_retry(stop_after_attempt=6)
```

```typescript TypeScript
import { initChatModel } from "langchain";

const model = await initChatModel("gpt-4o", {
    modelProvider: "openai",
});

const modelWithRetry = model.withRetry({ stopAfterAttept: 2 });
```

</CodeGroup>

有关更多信息，请参阅 `langchain` @[Python][BaseChatModel.with_retry] 和 [JS](https://v03.api.js.langchain.com/classes/_langchain_core.language_models_chat_models.BaseChatModel.html#withRetry) API 参考。

#### 不使用 `langchain`

如果你不使用 `langchain`，可以使用其他库，例如 `tenacity` (Python) 或 `backoff` (Python) 来实现带有指数退避的重试，或者你可以从头开始实现它。有关如何执行此操作的示例，请参阅 [OpenAI 文档](https://platform.openai.com/docs/guides/rate-limits#retrying-with-exponential-backoff)。

## 限制 `max_concurrency`

限制应用程序和评估器发出的并发调用数量是减少模型调用频率的另一种方法，从而避免速率限制错误。`max_concurrency` 可以直接在 `[evaluate()](https://docs.smith.langchain.com/reference/python/evaluation/langsmith.evaluation._runner.evaluate)` / `[aevaluate()](https://docs.smith.langchain.com/reference/python/evaluation/langsmith.evaluation._arunner.aevaluate)` 函数上设置。这通过有效地在线程之间分割数据集来实现评估的并行化。

<CodeGroup>

```python Python
from langsmith import aevaluate

results = await aevaluate(
    ...
    max_concurrency=4,
)
```

```typescript TypeScript
import { evaluate } from "langsmith/evaluation";

await evaluate(..., {
  ...,
  maxConcurrency: 4,
});
```

</CodeGroup>
