使用这些内建工具，让您的智能体能够访问电子邮件、日历、聊天、项目管理、代码托管、电子表格/商业智能 (BI)、搜索、社交媒体和通用 Web 工具。

<Info icon="circle-info" color="#DCFCE7" iconType="regular">
  Google、Slack、Linear、GitHub 和 LinkedIn 使用 OAuth 进行身份验证。Exa、Tavily、Pylon 和 Twitter/X 使用工作区密钥（API 密钥）。
</Info>
